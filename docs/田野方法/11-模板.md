# 11 · 工具与模板

> 可直接复用的田野模板，每份标注对应的 OpenField 数据模型实体。标注约定见 [README](README.md)；模板内容为【操作性建议】（通行做法的模板化，非某书逐字主张）。

## 0. OpenField 数据模型速查

| 实体 | 含义 |
| --- | --- |
| FieldEvent | 一次田野活动（半天/一天） |
| Encounter | 一次交流/访谈 |
| Artifact | 采集物（录音/照片/笔记/文档，原始只读，SHA-256 固化） |
| Participant | 受访者档案（化名、抽样理由、同意范围、引荐链） |
| EvidenceLog | append-only 证据日志 |
| Memo | 备忘录（reflexive/analytical，AI 草稿 → 人工确认） |

## 1. 田野计划清单（出发前）

对应 OpenField：FieldEvent 的创建前置。

- [ ] 研究问题（一句话，能对受访者说清）
- [ ] 选点理由与备选（相关、可进入、可持续）
- [ ] 守门人与引荐路径（记录每一步引荐——抽样即资料）
- [ ] 目的性抽样方案（选谁、为什么、先见谁）
- [ ] 同意材料：同意书要点卡（§4）+ 口头同意话术，已按 PIPL 审过敏感项（GPS/录音/肖像）
- [ ] 设备：离线可用（断网演练过）、电量、备份
- [ ] 化名映射方案就绪（真名仅入加密存储）
- [ ] 反身性预设备忘已写（[03 §5](03-进入田野.md)）

## 2. 半结构化访谈提纲模板

对应 OpenField：Encounter 的计划态。

```
# 访谈提纲 · <日期/地点/受访者编号>
## 主题 A（<一句话：想知道什么>）
- 开场问题（过去时+具体）：「你上一次 <关键事件> 是什么时候，怎么发生的？」
- 备用追问：谁在场？之后呢？那次和平时有什么不同？
## 主题 B ...
## 收尾
- 「有什么我没问、但你觉得重要的事？」
- 「我下次应该找谁聊？」
## 提醒
- 不诱导；对方迎合时把迎合记为资料
- 敏感问题后置；对方任何不适信号 → 换话题或终止
```

## 3. 现场速记与成文笔记模板

对应 OpenField：Artifact（note）→ 写详版本（原始件只读，编辑产生新版本）。

```
# 速记 · <时间> @ <地点> （挂接 FieldEvent-<id>）
- 场景：进入时正在发生什么、物理环境、在场者（化名编号）
- 关键片段：
  - 「逐字引语」（说话人编号）——动作/表情注记
  - 行为序列：谁、做了什么、顺序
- 我的即时反应（反身性，与观察分层标注）
---
# 写详（当天）· 版本 2
- 描述层：扩写的场景与片段（可回溯到速记条目）
- 分析层：初步归纳（链接为 Memo，type=analytical）
- 跟进事项：下次问谁、查什么
```

## 4. 知情同意要点卡（现场出示）

对应 OpenField：ConsentRecord（先于采集、版本化、可撤回）。设计原则：像聊天一样自然，10 秒能说完，细节可追问。

- 我是谁、在做什么研究（30 秒自述）
- 会记录什么：录音？拍照？定位？（凡涉敏感项——行踪/健康/宗教/未成年人——单独问，PIPL §28–29）
- 用途：用于研究，发表时匿名化；不会拿去做别的（PIPL §6 最小必要）
- 你的权利：随时反悔，反悔就全删（PIPL §15/§47）；不给姓名；可以拒答任何问题
- 口头同意存证：「好的，我现在开始录音了。」（录音开头即口头同意记录）

## 5. 编码表模板

对应 OpenField：分析层（编码建议经人工确认；互斥性/层级完整性过校验器）。

| 码（code） | 定义（何时用） | 何时不用 | 层级 | 示例片段（Artifact ID # 时间点） |
| --- | --- | --- | --- | --- |
| 现金流压力 | 受访者描述按期兑付困难 | 不含惜售等策略行为 | 现金流 > 压力 | OF-2026-0909-KMG-003#T12:34 |

规则：定义写「何时用/何时不用」两栏；父子码合并检查互斥；每码至少 1 条可回溯示例。

## 6. 每日田野日志模板

对应 OpenField：每日日志自动聚合 + 人工补写。

```
# 田野日志 · <日期> · <地区>
- 今日 FieldEvents 与 Encounters 概览（自动聚合）
- 信息增量：今天学到的最重要的 1–3 件事
- 反身性反思：我的哪个预设被挑战/被强化？谁在迎合我？
- 分析备忘：出现的新模式（→ Memo）
- 明日计划：见谁、补什么、带什么
```
