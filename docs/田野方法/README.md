# 田野调查方法论语料库（Fieldwork Corpus）

> 面向 IT 从业者的田野调查完整中文知识库。OpenField「方法论执行引擎」的知识底座。
> 生成日期：2026-09-09。证据基础见下文「证据说明」，转载或引用前请阅读。

## 这是什么

本语料库假设读者：懂软件工程、实验与数据分析，但**没有人文学科背景**。它回答四类问题：

1. 田野调查是什么、从哪里来——概念、历史、流派（01–02）
2. 到现场怎么做——进入田野、观察、访谈（03–05）
3. 回来怎么处理——分析、信效度、写作（06–09）
4. 我的行业里怎么用——contextual inquiry、netnography 等产业方法（10），以及随身工具（11–12）

它同时服务 OpenField 本身：五层架构（采集 → 取证 → 沉淀 → 分析 → 输出）的每一层，都能在这里找到对应的方法论依据——L1/L2 对应 04–05 与 07，L3 对应 04–06，L4 对应 06 与 08，L5 对应 09。

## 证据说明（必读）

本语料不是自由发挥的产物，证据分三级标注：

1. **【核验】**——经过多源检索 + 逐条对抗式核验（3 票）确认的事实，附来源链接。
   主体来自一轮深度研究：5 路并行检索 → 25 个来源 → 113 条候选声明 → 逐条 3 票对抗核验（24 条确认、1 条否决）；另对 5 个缺口模块（Kozinets、contextual inquiry、中国伦理法条、分析书目、中国田野传统）做了专项一手核验。
2. **【通行共识】**——教科书级背景常识（如某经典著作的作者与年份），编写时未逐条回原文核验，引用进论文前请自行复核原书。
3. **【操作性建议】**——源自方法论文献通行做法的实践建议，不指向某本书的逐字主张。

**已知否决项**：网上流传的「Spradley 田野笔记四分体系」（condensed account / expanded account / fieldwork journal / analysis and interpretation）在本轮核验中被 0–3 否决——**不得引用**，详见 [04](04-观察与笔记.md) 的警告框。

**口径注意**：凡「出版社简介口径」「某文归因」的表述均如实标注；历史「第一人」断言一律保留归因句式（如「Ryan (2017) 将……列为」，而非写成定论）。转引前请回原文复核。

**配套本地文献库**：[参考文献/](参考文献/索引.md) 已下载 13 份开放获取/作者授权/官方文件（Spradley 全书、Beyer & Holtzblatt 全书、《江村经济》1939 年原著扫描、PIPL 等法规全文，均逐份校验过文件有效性）；第三方文件仅限个人学习、不得再分发，已由仓库根 `.gitignore` 排除出版本库。清单与"未能本地化"说明见 [参考文献/索引.md](参考文献/索引.md)。
