## 一、决策原则

**地点选择第一优先**，筛选顺序：

1. **方言无障碍**（普通话 / 官话区可独立完成访谈）
2. **5–6 线县城**（研究覆盖薄，AI 工具增益最大）
3. **交通与安全**（可达、可驻、可撤）
4. **既有关系网**（地方接驳、院校 / NGO 配合）

> **方言铁律**：方言有疑问 → 直接换地点。方言不可现场解决，只能绕开。  
> 这一条否决任何"语言独特性 > 沟通可行性"的诱惑。

### 关键事实核查（2026-09-18）

- **曹县交通**：K106 深圳直达曹县约 22h44m（每日约 1 班，T-7 以 12306 为准）；高铁中转经郑州东/兰考南约 9–11h。曹县目前无高铁站，京雄商高铁曹县西站在建——「高铁开通前」本身就是时效性素材。
- **滑县交通**：深圳北→郑州东 G 约 5.5h + 郑州东→滑浚 45min（¥51–66），当日可达。
- **张北产业事实**：阿里巴巴自 2015 年起建 7 个数据中心项目、总投资 450 亿元，为阿里云最大核心地域节点之一；风电装机容量全国县级第二。

### 评估结论

1. **首发维持曹县**——赢在选题密度与接驳成熟度，不只是出发成本低；5 天内可同时触达电商运营、手艺人、直播从业者三类对象。
2. **张北升为正式第二顺位**，定位是「算力下乡」独立系列的首选点，不是单纯替补。若启用，需先做数据中心侧预接驳（供应链/运维外包团队），补其接驳短板。
3. 岢岚（军工红线）、敖汉旗/延川（方言边缘）按铁律不进首发讨论。

## 六、核心权衡

**得到**：

- 进入快、成本低、转写保真、试点可在 1–2 周内闭环
- AI 工具链可立刻产出显著增益（普通话 ASR、跨案例矩阵无需微调）

**代价**：

- 放弃民族志 / 语言多样性的研究独特性
- 案例偏向"主流社会边缘化"主题（留守 / 老龄 / 生态 / 电商 / 移民）—— 这恰是 AI 工具最易放大的研究类型（大量文本 / 访谈 / 数据已有沉淀）
