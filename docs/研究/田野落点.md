# 田野地点选择方案

> 决策记录 · 2026-09-17  
> 适用范围：OpenField P1 桌面服务层所支持的 AI 田野调查 pilot 选址  
> 与桌面服务层实现无关、与规格文档互补

---

## 一、决策原则

**地点选择第一优先**，筛选顺序：

1. **方言无障碍**（普通话 / 官话区可独立完成访谈）
2. **5–6 线县城**（研究覆盖薄，AI 工具增益最大）
3. **交通与安全**（可达、可驻、可撤）
4. **既有关系网**（地方接驳、院校 / NGO 配合）

> **方言铁律**：方言有疑问 → 直接换地点。方言不可现场解决，只能绕开。  
> 这一条否决任何"语言独特性 > 沟通可行性"的诱惑。

---

## 二、推荐候选（方言无障碍 × 5–6 线）

| # | 地区 | 县城候选 | 方言状况 | 研究切口 |
|---|---|---|---|---|
| 1 | **河北北部** | 张北、尚义、围场 | 普通话标准 | 坝上农耕 / 牧业转型、贫困县治理 |
| 2 | **山西北部** | 岢岚、右玉、灵丘 | 普通话 + 晋语边缘 | 黄土高原生态修复、生态移民 |
| 3 | **陕北** | 延川、佳县、子长 | 普通话 + 晋语 | 黄河流域农耕 / 手工 / 红色文化遗存 |
| 4 | **山东鲁西南** | 曹县、单县、莘县 | 普通话 | 县域电商 / 手工艺（曹县现象） |
| 5 | **河南豫北** | 滑县、内黄、封丘 | 普通话 | 黄河故道农业县、人口流出 |
| 6 | **东北辽西** | 彰武、阜新县、建平 | 东北官话 | 资源枯竭型城市、移民 / 老龄化 |
| 7 | **内蒙古东部** | 库伦旗、奈曼旗、敖汉旗 | 普通话 + 蒙汉双语 | 半农半牧过渡带、汉族移民社区 |

> **共性**：均为普通话官话区、汉族为主、5–6 线、研究覆盖薄、对 AI 工具（方言转写、跨案例分析）依赖度最高。

---

## 三、被排除的方向（已锁定）

- 闽南 / 粤 / 吴 / 湘 / 赣 / 客家方言区（即便研究价值高）
- 西南官话边缘的少数民族县（傣 / 彝 / 苗等需翻译）
- 晋语核心区（太原以南）、徽语区、潮汕区
- 1–3 线核心城市（AI 工具增益边际递减，研究覆盖饱和）

---

## 四、与 OpenField 项目衔接

- **测试 fixture 沿用** `KMG`（昆明，西南官话）做技术验证，与落地选点解耦
- **真田野落点** 从候选表 7 个里选 1 个起 pilot
- **数据 schema 无需调整**：PIPL + evidence_log + refId 通用
- **唯一变动**：方言 ASR 模块可暂用通用普通话模型，避免模型投入黑洞
- **采集 / 校验 / 引用 / 备份** 全链路用现有 P1 服务即可覆盖

---

## 五、核心权衡

**得到**：

- 进入快、成本低、转写保真、试点可在 1–2 周内闭环
- AI 工具链可立刻产出显著增益（普通话 ASR、跨案例矩阵无需微调）

**代价**：

- 放弃民族志 / 语言多样性的研究独特性
- 案例偏向"主流社会边缘化"主题（留守 / 老龄 / 生态 / 电商 / 移民）—— 这恰是 AI 工具最易放大的研究类型（大量文本 / 访谈 / 数据已有沉淀）
