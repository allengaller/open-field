> 版本 V1.0 · 2026-10 · 隶属[西安田野文档套件](README.md)
> 基于[09 路线与访谈备选](09-路线与访谈备选.md)的**默认选型**展开：路线 = 案一（老城锚定）+ 案八（D2 先易）排序；访谈档 = [09 场景配套表](09-路线与访谈备选.md)；黄金周触发则切案六（§5）。选了其他路线案的话，本文骨架照搬、锚点重配即可。

## 1. 角色卡：我在场上是谁，找谁说话

### 1.1 访谈员角色序列（每场景通用）

```
顾客/路人（消费或旁观，观察任务卡十分钟）
  → 熟客姿态（第二次照面：点头、指认昨天的细节）
  → 自述研究者（30 秒四要素自述，提纲 §2.1）
  → 访谈（档位按场景配套表）→ 收束三件套
```

- 角色转换的触发器是**对方主动搭话或第二次照面**，不是时间表——先把「先消费后开口」做足，自述才不突兀（[计划 §3](西安五日计划.md)）。
- 全程**公开研究者身份**，无隐蔽采集（[07 伦理](../../田野方法/07-伦理.md)）；「应聘式」伪装路径禁用。

### 1.2 每场景的目标角色与节点

| 场景 | 主目标 | 备选目标 | 节点人物（先打招呼不急访） | 禁访/慎访 |
|---|---|---|---|---|
| 公园晨练 | 固定队伍成员（太极/合唱/健走） | 独行者 | **队长**：请默许再一对一 | 围观式采访；身体不适者 |
| 早市/菜市场 | 摊主（在场 3 年+） | 采购的餐馆老板 | 市场管理方办公室 / 老摊位 | 高峰期深聊；未成年帮工 |
| 老城作坊 | 手艺人（师傅本人） | 学徒 | 邻铺师傅 | 手上活最忙时；不拍设备先问 |
| 城中村 | 租户/小卖部 | 房东 | 巷口小卖部/修车摊 | **拆迁话题主动澄清**；室内不进 |
| 写字楼 | 中小公司员工/创业者 | 行政、物业 | **物业前台**；楼下咖啡档口 | 楼内拍摄未经物业；推销感 |
| 高校周边 | 文印店主、小吃摊主 | 学生（代际对照） | 文印店老板（信息节点） | **未成年人一律不访谈**；考研考编个人做法不问 |
| 机动：平台劳动者 | 司机/骑手 | — | 骑手聚集点商家（取餐处） | 车内录音单独征求；不影响接单 |

### 1.3 守门人应对一句话版

- 物业前台：「做个普通人怎么用 AI 的小调查，公开身份，想在楼下跟一两位上班族聊聊，15 分钟，不打扰办公。」
- 市场管理方：同上 + 「不挡生意，高峰期绝不占摊」。
- 晨练队长：「想听听叔/姨们这一辈子的经历，队长您点头我才开口。」
- 被拒绝即体面退场（提纲 §8），换点位，**不反问不纠缠**。

## 2. 五日执行路线（默认案 · 老城锚定 + 递进排序）

**住宿锚点**：城墙内钟楼—永宁门地铁圈（2 号线沿线快捷酒店，要求有桌可开笔记本）。此锚点使 D2/D3/D5 全程步行圈内，D4 才动用地铁远征。

### D1（进入日）—— 只踩点不深访

| 时段 | 动作 |
|---|---|
| 抵达后 | 安顿 → 解锁 vault + TIME_SYNC（[计划 §6.1](西安五日计划.md)） |
| 下午踩点线（步行） | 住宿 → **环城公园文昌门—和平门段**（看晨练队伍构成与队长节点，锁 D2 点位）→ **建国门里（信义巷一带）**（早市踩点：只看不聊，锁 D3）→ 钟楼—竹笆市—洒金桥一带（作坊铺面密度踩点） |
| 傍晚 | 洒金桥一带晚市观察（只观察+速记卡，破冰级短交流 ×2–3） |
| 晚 | 日志（无正式访谈也写）→ 次日计划 → 四连锁盘 |

### D2（易场景日 · 公园 + 菜市场）—— 访谈档四 + 档五

| 时段 | 路线与动作 |
|---|---|
| 06:40 起床 | 07:00–09:30 **环城公园文昌门段**（备选：兴庆宫公园，兴庆路交大对面）：旁观 → 队长默许 → 晨练者深访 ×1–2（**档四人生线前置**，长者样本主产地） |
| 09:30–10:30 | 顺路**建国门里早市**：只破冰登记 + 锁定 D3 主攻摊位（档五只开场不展开） |
| 午 | 回住宿休整入库（录音不过夜红线：**未入库音频不过夜**指当日必须入，午休只拷贝不确认） |
| 16:00–18:00 | 住宿圈**社区菜市场**（按「服务周边居民、非旅游型」逻辑现地选定，莲湖区居民区优先）：先买一次 → 摊主深访 ×1（**档五物证导引**） |
| 晚 | 入库确认 → 日志 → 校验 → 双备份 |

### D3（中场景日 · 早市 + 作坊）—— 档五 + 档一

| 时段 | 路线与动作 |
|---|---|
| 07:00–10:30 | **建国门里早市**主攻：昨天锁定的摊位，熟客姿态接续 → 深访 ×1–2（档五）；管理方办公室打招呼 |
| 11:30–14:00 | 午休避饭点 |
| 14:00–16:00 | **洒金桥—西仓一带**老街区手艺铺（莲湖区）：修表/裁缝/配钥匙，买东西顺势聊 ×1（档一/档五）；注：**西仓集市周四/周日开**——若 D3 恰逢周四/日，作坊改为西仓外围手艺摊+观察加厚 |
| 晚 | 四连锁盘 |

### D4（难场景日 · 城中村/高校 + 写字楼远征）—— 地铁日

| 时段 | 路线与动作 |
|---|---|
| 09:00–11:30 | 地铁至城中村锚点（**三选一，存续须核实**：吉祥村/三爻村/沙井村，§4）：巷口小卖部闲聊开场 → 澄清「不是拆迁办」→ 租户或房东深访 ×1（档一） |
| 午 | 地铁午餐休整 |
| 15:00–17:30 | **高新路—科技路写字楼带**：物业前台先打招呼 → 楼下咖啡档口/电梯间切入 ×1–2（**档二裁剪档**，午休已过、用 15:00 窗口；备选小寨—纬二街商务楼） |
| 晚 | 四连 + **样本量盘点**（对照[计划 §1.3](西安五日计划.md) 配额；<8 → D5 必补 1–2 条） |

- **D4 上午机动换位**：城中村与高校周边（兴庆路交大商圈，近老城）二选一——看 D2–D3 长者/摊主完成度：长者不足 → 城中村让位高校；长者已足 → 照上表。
- 高校周边若放 D4 上午：文印店主全天可访，学生对照 11:30 前抢样本（学生窗口 16:00–19:00 与写字楼冲突，默认案下高校配额压至 1——案一固有代价，接受）。

### D5（撤离日）

| 时段 | 动作 |
|---|---|
| 上午（≤1h） | 补访 ×1：最缺配额的场景，用步行圈内最易的公园/菜市场 |
| 之后 | 收纳打包 → verify 终检全绿 → 第三份备份随身 → 撤离 |

## 3. 地址锚点清单（街道级 · 全部三道核实后使用）

| 场景 | 锚点（街道/地标/地铁） | 选点逻辑 | 核实动作 |
|---|---|---|---|
| 公园晨练 | 环城公园文昌门—和平门段（老城东南，步行可达） | 老居民密度高、队伍固定 | D1 下午踩点 |
| 公园备选 | 兴庆宫公园（兴庆路，交大对面；地铁 6 号线沿线） | 学生+退休者混合 | 同上 |
| 早市 | 建国门里早市（信义巷一带，碑林区，环城南路内侧） | 社交平台流传、口碑大——**存续与时段必须现地核实** | D1 踩点 |
| 集市备选 | 西仓集市（莲湖区西仓，**周四/周日**） | 传统档子市，手艺摊+老客群 | 开市日当天核实 |
| 菜市场 | 住宿圈社区型市场（莲湖区居民区优先） | 非旅游型、老年顾客比例、老摊位 | D1 晚地图+D2 现场 |
| 作坊 | 洒金桥—竹笆市—西仓一带老街区（莲湖/碑林） | 「工具即招牌」沿街手艺铺 | D1 踩点 |
| 城中村 | 吉祥村（雁塔区，地铁 3 号线吉祥村站）/ 三爻村（长安南路，地铁 2 号线三爻站）/ 沙井村（雁塔区太白南路沿线） | 三选一；**改造进度不一，存续必须出发前+进村前各核一次** | 地图+现地+进村 |
| 写字楼 | 高新路—科技路—锦业路写字楼带（高新区）；备选小寨—纬二街商务楼（雁塔区） | 产业园区与地铁上盖；楼下咖啡档口为低门槛点 | D3 晚地图选定目标楼，D4 物业先行 |
| 高校周边 | 兴庆路西安交通大学兴庆校区校墙外商业街（近老城，锚定兼容）；备选长安区西长安街高校带（地铁 2 号线南段） | 文印店/自习室=信息节点 | D1 顺路看一眼 |
| 机动 | 小寨商圈骑手取餐点、高峰期地铁口 | 自然遭遇，不占配额 | 无需预设 |

> 以上全部为【通行共识】级地理常识，非实测；任何一条失准都以现地为准。**不出现任何具体店名门牌**——那是 FieldEvent 背景注记里现场记录的事。

## 4. 每日时段预算（默认案 · 通勤量级）

| 日 | 步行/地铁 | 最远单程 | 状态预算原则 |
|---|---|---|---|
| D1 | 全步行 | — | 省体力给踩点 |
| D2 | 全步行（含备选兴庆宫 +20min） | 2km | 早起日，午后必须休整 |
| D3 | 步行为主 | 1.5km | 早市早起，午休硬性 |
| D4 | 地铁 ×4 段 | 45min | 通勤日，只背两个场景 |
| D5 | 步行 | — | 补访 ≤1h |

## 5. 黄金周切换（触发即切，不硬扛）

行程落 10.1–10.7 时按[09 案六](09-路线与访谈备选.md)重配：写字楼窗口清零并入 D4 机动 → D4 上午改为**公园晨练加厚**（假期长者有闲）；大唐不夜城等文旅带**不设访谈**；早市/公园照常但人流结构变（游客占比升），深访窗口提前至 07:00–09:00；平台劳动者机动位启用（假期单量结构变化要标注进日志）。

## 6. 保险丝（触发 → 动作，引用不重写）

- 连续拒 5 次 → 当日停攻换场景（总纲 §8.1）；单日 0 访谈 → 次日只保 1 条完整链路（[计划 §2](西安五日计划.md)）；雨 → 室内场景（作坊/写字楼/高校文印店）；眼睛报警 → 当日终止（总纲 §8.2）。
