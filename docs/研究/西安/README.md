## 3. 本文件夹纪律

1. **合成示例铁律**：所有示例一律「化名 A/B/C」（P-001… 编号）；不出现任何真实受访者姓名、店名、住址、联系方式。返程后回填的实际行程/价格也用量级区间。
2. **真名纪律**：真名只在确需对应时进加密库 `participant_identity` 表；纸面、备忘、聊天记录一律笔名（[计划 §5.3](西安五日计划.md)）。
3. **证据分级**：沿用项目语料库惯例——【核验】（有可靠来源的硬事实）/【通行共识】（公认但未逐一核验）/【操作性建议】（我的预设与经验法则，现场检验）。城市读本与人群画像以【通行共识】与【操作性建议】为主，现场以对方讲述为准。
4. **画像不是剧本**：04/05 的一切「预期」都是为了让我在听得懂、接得住，而不是替对方说——诱导式追问是本轮红线（[提纲 §1](西安访谈提纲.md)）。
5. **伦理先于数据**：同意先于采集、永不补录；未成年人不作为访谈对象；人生线研究者先自我暴露、对方永远有权不答（[提纲 §5](西安访谈提纲.md)、[07 伦理](../../田野方法/07-伦理.md)）。
