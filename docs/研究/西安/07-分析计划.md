# 07 分析计划 — 行前预注册

> 版本 V1.0 · 2026-10 · 隶属[西安田野文档套件](README.md)
> 目的：出发前把「回来以后怎么分析」写清楚。预注册的价值不在锁死自己，而在回来后能分辨**「数据里长出来的」和「我心里本来就有的」**——这正是信效度里可确认性的实操形态（[01-研究设计](01-研究设计.md) §5）。
> 方法论底座：[06-分析](../../田野方法/06-分析.md) · [08-信效度](../../田野方法/08-信效度.md) · 主题编码（[主题编码](../../社会学田野/08-分析/主题编码.md)）· 扎根理论（[扎根理论](../../社会学田野/03-方法/扎根理论.md)）
> 合成示例铁律同[README §3](README.md)。

## 1. 分析策略总览：两段式

- **行中轻分析**（每晚）：信息增量 1–3 条 + 新模式假设 + 反身性备忘（提纲 §7、[06 观察与记录指引](06-观察与记录指引.md) §4 日志模板）。轻分析的产出是**明日抽样调整**（哪类场景加厚、哪类停手，[计划 §4.3](西安五日计划.md) 饱和判断），不是结论。
- **行后集中分析**（返程 72h 起动）：录音与笔记整理 → 主题编码 → 交叉命题检验 → 写作（§6）。
- 总原则：**框架敏感，不框架绑死**——编码框架 v0 是出发前的预期，允许并期待数据推翻它；持续比较贯穿全程（[扎根理论](../../社会学田野/03-方法/扎根理论.md)）。

## 2. 预注册编码框架 v0

> 使用方式：出发前打印随身。田野中**不是拿框架去套，而是拿框架去听**——听对方的话落在哪个族里、哪句话框架接不住；接不住的就是新码的种子。

### 2.1 AI 两问码族（问①②）

| 码族 | 子码示例（举例性质，允许增删） | 对应提纲追问 |
|---|---|---|
| 使用图谱 | 在用-工作 / 在用-生活 / 代际中介使用（子女教） / 停用 / 从未用 / 混合使用 | 问① 追问树 |
| 传播链 | 自学摸索 / 亲友传 / 同事传 / 平台推荐 / 生意伙伴传 | 问① 教与学 |
| 信任与怀疑 | 信而用 / 用而疑 / 事件性信任崩塌 / 隐私顾虑 | 问① 付费与信任 |
| 可及性障碍 | 不会用 / 不信 / 太贵 / 没需求（四类是提纲预设——**允许出现第五类**，原话即码名） | 问② 归因四类 |
| 想象与营销 | 期待具体化 / 期待模糊化 / 被广告塑造的想象 / 「AI=聊天机器人」的窄化理解 | 问② |
| 替代与冗余 | 土办法顶着 / 人情网络顶着 / 设备已够用 | 问② 替代做法 |
| 平台焦虑 | 抢饭碗感知 / 新工具感知 / 无感 | 问② 失业与机会（中性措辞那问） |

### 2.2 人生两问码族（问③④ + 回环）

| 码族 | 子码示例 |
|---|---|
| 遗憾类型 | 行动之憾（做了后悔）/ 不作为之憾（没做后悔）——时间序线索：长期看不作为占比更高 【通行共识】（Gilovich & Medvec；[01-研究设计](01-研究设计.md) §2 透镜表） |
| 遗憾主题 | 事业 / 家庭 / 教育 / 健康 / 情感 / 迁徙 |
| 叙事主题 | 红利叙事 / 代价叙事 / 命运叙事 / 稳定叙事 |
| 时代印记 | 话语中带出的时代事件（下岗、高考、进城、棚改……）——与[05-西安城市读本](05-西安城市读本.md) §3 代际底色对照，但对照只在分析期做，不进访谈 |
| 人生-AI 交叉码 | 人生叙事里长出的 AI 期待（「要是当年有这个就好了」）——回环问题的落点，RQ2 的核心数据 |

### 2.3 方法码（记录研究过程本身）

| 码 | 记什么 |
|---|---|
| 拒访 | 场景 + 一句话原因——拒访本身是资料（[计划 §5.2](西安五日计划.md)） |
| 迎合 | 对方从哪句开始顺着我——连同我上一句说了什么（提纲 §7） |
| 孤证 | 只出现一次、暂不立论的素材，单独标记防误用 |
| 反身性 | 访谈员假设泄漏点（预设自检五问的对照，[08-访谈员自我准备](08-访谈员自我准备.md) §2） |

### 2.4 新码登记规则

- 框架接不住的原话 → 新码候选，登记三件套：**码名（尽量用受访者原语）/ 定义 / 一条锚例（RefId 定位到录音时间戳）**。
- 允许推翻：v0 任何一族在数据面前都可修改、合并、废弃；每次修改写 analytical memo 留痕（[06 §5](06-观察与记录指引.md)）。
- 最终报告的方法论部分必须交代：v0 框架哪些活着、哪些死了、新长了什么。

### 2.5 编码复核（编码者内信度）

单人研究的最低限度信度动作：**同一编码者隔期重编**。

- **时机**：返程集中分析中，隔 ≥7 天抽取 **10% 语料（且 ≥1 条完整访谈）**，不看先前编码结果，按码本重编一遍。
- **判定**：逐码比对两次结果，不一致率 **≤20% 通过**；超线 → 先查原因（多为码本定义含糊或边界重叠）→ 修订码本 → 全量重编 → 再抽 10% 复核一轮。
- **留痕**：不一致率数字、修订了哪些码、重编轮次，写入本文件变更记录与报告方法论部分——这是可确认性的审计材料（[01 §5](01-研究设计.md)）。
- 编码底稿（转写文本）的本地转写与脱敏纪律见[03](03-转写与数据整理纪律.md)。

## 3. 交叉命题 P1–P4（待检验的观察敏感点）

> 不是假设——不预设立场、不做统计检验；是**行中帮助注意到模式、行后帮助组织材料的敏感点**。每条都写明「若被推翻我学到什么」。

| # | 命题 | 若被推翻 |
|---|---|---|
| P1 | **场景分化**：AI 使用图谱随场景类型系统性变化——写字楼与摊主在「入口」与「信任条件」上的差异，大于年龄段内部的差异 | 「社会位置」的解释力弱于「个体特质」→ RQ1 的比较轴需重构（[01 §4](01-研究设计.md)） |
| P2 | **不作为之憾**：长者组的遗憾叙事中，不作为类占比高于行动类（Gilovich & Medvec 线索的中国城市检验） | 记录西安语境下的偏离及其条件——偏离本身就是发现 |
| P3 | **期待与使用的断裂**：「希望 AI 帮我」与「AI 现在帮我」之间隔着可及性障碍（尤其「不会用」与「不信」），断裂在长者组最深 | 归因四类框架需要修——第五类是什么，由数据说 |
| P4 | **回环问题有效**：回环（「回到入行那年就有 AI」）能产出可编码的人生×AI 交叉素材，且不引发迎合 | 回环降级为暖场话头、不入主数据——RQ2 换证据来源（问②的期待结构） |

## 4. 立论纪律与三角验证

- **立论门槛**：同一模式在 **≥3 类人群 × ≥2 类场景**出现，才写入报告正文；否则标「孤证/单场景观察」，只入附录或 memo（方法码「孤证」联动）。
- 三角验证矩阵：使用图谱（问①）× 期待结构（问②）× 人生处境（问③④）——**三源一致的个案优先成案例包**（[计划 §1.2](西安五日计划.md)）。
- 反例是金子：每个立论必须同时记「不支持它的材料」——负例分析是信效度的标配动作（[08-信效度](../../田野方法/08-信效度.md)）。
- 目的性抽样的边界要写进报告：样本按信息丰富度选，不做统计外推（[计划 §4.1](西安五日计划.md)）。

## 5. 饱和记录法

- 每场景连续 2 条访谈给不出新信息 → 该场景停加（[计划 §4.3](西安五日计划.md)）。
- 饱和判断落 analytical memo，写明：**「最后一条新增信息出现在第几条访谈」**——这个数是报告方法论部分必须交代的。
- 全轮饱和概览：返程后按场景×人群做一张「信息增量衰减表」，支撑配额达成度与局限声明（[01 §6](01-研究设计.md)）。

## 7. 引用与发表边界

- **引用规范**：每条引语挂 RefId（`OF-YYYYMMDD-XAN-…#T…`）→ verify 可验 sha256——**引语的可追溯性本身就是信效度**（[01 §5](01-研究设计.md) 审计链；[使用手册](../../工程/使用手册.md)）。
- **发表边界**：整理发表材料前逐条比对拒写清单（[计划 §5.4](西安五日计划.md)）；同意门禁自动拦截未授权类型。
- **化名与可识别性纪律**：报告只用 P-编号与化名 A/B/C；场景模糊化到区级；警惕**组合可识别性**——「城东国棉厂 + 1962 年生 + 钳工」这种组合本身可锁定个人，遇到就再加一层模糊（威胁模型思维移植到发表环节）。
- 真名永不进分析材料：真名只存在于加密库 `participant_identity`（[计划 §5.3](西安五日计划.md)），分析全程只见笔名。
