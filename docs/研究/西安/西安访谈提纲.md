> 版本 V1.1 · 2026-10 · 配套[西安五日计划](西安五日计划.md)（日程、落点、抽样配额、同意流程与数据管线）

> 方法论底座：[05-访谈](../../田野方法/05-访谈.md)（提纲 = 一个开场问题 + 备用追问；追问三板斧：沉默/复述/具体化）、[03-进入田野 §2](../../田野方法/03-进入田野.md)（研究者自述）、[07-伦理](../../田野方法/07-伦理.md)、[11-模板 §4](../../田野方法/11-模板.md)（同意要点卡）

## 1. 设计原则

- **四问的分工**：

| 主轴 | 问题 | 拿什么数据 |
|---|---|---|
| AI 两问（主数据） | ①AI 现在帮到你什么？②你希望 AI 可以帮你啥？ | 技术如何进入普通人的工作与生活：在用/没用、信/不信、盼/怕 |
| 人生两问（情境 + 信任） | ③这辈子有何遗憾？④有没有特别想聊的人生故事？ | AI 答案嵌在什么人生处境里（为什么一个每天站 14 小时的人没空折腾 AI）；收束前的信任峰值段；回环问题反哺 AI 线 |

- **每问只带一个开场问题**，追问靠三板斧（沉默 3 秒 / 复述 / 具体化），不背一串封闭问题（05 §4）。
- **开场问题用「过去时 + 具体」**：不问「你觉得 AI 怎么样」（得到姿态），问「上一次它帮上忙是哪天」（得到过程）。
- **不给选项、不贴假设**：对方说不出工具名时可举一两个例子帮定位，但先让对方说；一旦举例立即追问「在那之前您用的是啥」防锚定。对方开始迎合时，把迎合本身记为资料（05 §4）。
- **口语化变体优先**：字面四问是锚点，现场先用变体进门，谈兴起来后再落回字面问法确认。

## 2. 开场与暖场（前 5 分钟）

### 2.1 30 秒研究者自述（公开身份；07 伦理：无隐蔽采集）

> 「您好，打扰您两分钟。我叫（研究者真名），以前在互联网公司做技术，现在自己做一个普通人怎么用 AI 的调查，一路从深圳过来。今天想跟您聊聊您平时干活过日子的事，纯聊天，我不卖任何东西。您可以说不，也可以中途随时不聊。」

四要素缺一不可：我是谁 / 在做什么 / 为什么找你 / 你可以说不（03 §2）。

### 2.2 录音同意话术（10 秒版，三类逐项）

> 「为了回来整理方便，我想录个音——只录声音、不拍脸，写东西都是匿名的。要是想拍张现场照片我会单独再问您。大概聊 30–40 分钟，您随时喊停，反悔我就全删。您看行吗？」

- 对方点头后**立刻开机**，录音第一句复述口头同意（「好，那我现在开始录了，您刚才同意了啊」）——口头同意存证即此。
- 三类同意逐项取得，落库口径见[计划 §5.1](西安五日计划.md)；对方只愿聊不录音 → 切笔记模式（[计划 §5.2](西安五日计划.md)）。
- **时长承诺要说且守约**。实际跑超 40 分钟而对方谈兴正浓时，先确认再延长：「咱再聊五分钟？您要是忙就到这儿。」——延长权交给对方。

### 2.3 暖场三句（同意之前用）

从眼前场景切入，不谈研究：「您这儿几点开门？」「今天人算多还是少？」「您这摊儿/这店干几年了？」——最后一问同时为过渡段（§4）埋线。

## 3. 主轴一：AI 两问

### 3.1 问 ①「AI 现在帮到你什么？」

**目的**：摸清 AI 在对方工作/生活中的真实占位——用了什么、用在哪、不用什么。

**开场问**（字面）：「AI 现在帮到你什么？」（口语变体）「您平时干活、过日子，有没有哪件事现在是拿 AI 帮着做的？」

**追问树**：

| 分支 | 追问 | 听什么 |
|---|---|---|
| 具体场景 | 最近一次是啥时候？那天具体怎么回事？ | 事件完整链条（谁/何时/干什么/结果）——厚描素材 |
| 工具与入口 | 用的哪个？自己下的还是别人发你的？ | 工具名、入口、获取路径；答不出时才举例定位 |
| 替代与对照 | 没有它之前这事儿怎么弄？老办法还留着吗？为啥？ | 被替换的环节 vs 没被替换的环节——AI 的真实边界 |
| 付费与信任 | 为这个花过钱没？一个月愿意付多少？啥情况您就不信它了？ | 付费意愿与信任条件（区间法降低敏感度） |
| 教与学 | 谁教您用的？您教过别人没？ | 传播链——顺手记引荐线索（[计划 §4.2](西安五日计划.md)） |

### 3.2 问 ②「你希望 AI 可以帮你啥？」

**目的**：需求面与想象面——真实痛点与被营销塑造的期待要分开记。

**开场问**（字面）：「你希望 AI 可以帮你啥？」（口语变体）「要是有个 AI 能把您最烦的一件事包圆了，您希望是哪件？」

**追问树**：

| 分支 | 追问 | 听什么 |
|---|---|---|
| 痛点排序 | 这事平时谁在干？要花多少工夫？出错一回代价多大？ | 痛点的量化轮廓（时间/频次/错误成本） |
| 可及性障碍 | 那为啥现在还没用上？ | 归因四类原话：不会用 / 不信 / 太贵 / 没需求——记原话，不替对方归类 |
| 替代做法 | 这事现在靠谁、靠啥顶着？ | 人的冗余与土办法——AI 需求真伪的对照 |
| 失业与机会（后置） | 「有人说 AI 要抢饭碗，有人说就是个新工具，您在您这行里看到的是啥样？」 | 中性措辞、不给立场、只问所见；放本问最后 |
| 报价测试（慎用） | 真有人帮您做了，您觉得值多少钱一个月？ | 仅对生意人/写字楼用；摊主与退休人群跳过 |

### 3.3 何时开放式、何时具体化

| 对方状态 | 用哪种 | 例 |
|---|---|---|
| 给抽象评价（「AI 挺好的」「都是骗人的」） | 具体化：过去时 + 具体 | 「上一次它帮上忙（或坑了您）是哪天？那天干了啥？」 |
| 给出具体故事 | 开放式跟随，不打断 | 「后来呢？」「再后来呢？」 |
| 停顿、犹豫 | 沉默 3 秒，不填空 | — |
| 跑题超 3 分钟 | 复述 + 借钩拉回 | 「您刚说的 X 我记下了，我想回到刚才那件事——」 |
| 开始迎合（净说好话/顺着我说） | 停追这条线 | 把迎合记为资料：我上一句说了什么让它转向？ |

## 4. 两问之间的过渡衔接

| 段 | 时长 | 可裁剪 |
|---|---|---|
| 暖场 + 自述 + 同意 | 5 | 否（同意不可省） |
| 问 ① | 7–8 | 压至 5 |
| 问 ② | 7–8 | 压至 5 |
| 桥（入行史） | 2 | 否 |
| 问 ③ 遗憾 | 5–7 | 可整段跳过 |
| 问 ④ 人生故事 | 8–10 | 保留（信任峰值段） |
| 回环 | 2–3 | 可跳 |
| 收束 | 3 | 否 |

标准档合计 39–46 分钟；承诺口径仍是「30–40 分钟」，延长须确认（§2.2）。**裁剪档**：砍问 ③ 与回环，保「暖场 → ① → ② →（桥）→ ④ → 收束」约 25 分钟。暖场与收束永不裁。

- **AI → 人生桥**：用问 ① 的「教与学」或入行史自然滑入：「您这摊儿/这行干几年了？当年怎么入的行？」——职业史是人生线的低敏感入口。
- **人生 → AI 回环**（收束前，可选）：「要是回到您刚入行那年就有 AI，您觉得那会儿的您会拿它干啥？」——时间纵深产出一组对照数据（同一人、两个年代、两个答案）。
- **中断处理**：对方情绪波动或长跑题 → 不硬拉回；等对方话头落地，借其话题里的钩子回主线。能用「您刚才说的 X，我想再多问一句」就不用「我们换个话题」——硬转是访谈里最贵的手艺。

## 5. 主轴二：人生两问（降敏感度递进）

> 人生线是高敏感区。原则只有一条：**研究者先自我暴露，对方永远有权不答**。剥洋葱从自己剥起。

### 5.1 问 ③「这辈子有何遗憾？」——三级递进

| 级 | 动作 | 要点 |
|---|---|---|
| 1 先自我暴露 | 研究者用 30 秒讲一个自己真实的小遗憾（出发前写好、先讲一遍） | 示范深度上限——我讲到几分，对方有权利讲到几分；先讲自己的，是给对方台阶而非压力 |
| 2 句式给台阶 | 不直接问「你有什么遗憾」，改从具体事件切入：「这些年有没有哪件事，现在想起来还想『当时要是……就好了』？」 | 要具体事件，不要抽象评价；对方沉默就过——「没有也特别好」 |
| 3 接受轻量答案 | 对方给「没啥遗憾」→ 接住，转问 ④ | 不施压、不复挖；「没有遗憾」本身也是答案，记下来。谈兴好时可回到字面问补一刀：「那要说这辈子，您有啥遗憾？」 |

### 5.2 问 ④「有没有特别想聊的人生故事？」

- 开场（字面问即开场问）：「您这半辈子，有没有哪段事，特别想找人讲讲、平时又没处讲的？」
- 对方反问「你想听啥」→ 给方向不给题目：「您自己的事，您觉得值得讲的就行。」
- 对方讲时**只做两件事**：听、记时间节点。不打断、不比惨、不接「我懂」。

### 5.3 情绪陪伴与退出机制

- **对方停下即停，不打捞眼泪**：沉默 3 秒在 AI 线是提问技术，在人生线一律不用——不追问、不等待答案，自然接一句「这段不容易」即可滑向下一话题或收束。
- **不挖创伤细节**：生死、钱数、人际冲突的细节，对方主动给就收，不主动问。
- **退出话术**：「咱今天先到这儿，您歇会儿。」/「这段咱不写了，您看行吗？」——后者即现场撤回口径（[计划 §5.2](西安五日计划.md)）。
- **访谈后 5 分钟留白**：一起喝口水、看摊、看人下棋，不立刻掏手机走人——人不是素材，是刚把人生讲给你听的人。

## 6. 收束脚本（最后 3 分钟）

1. **感谢 + 具体反馈**：「今天特别谢谢您。您说的『（化名 A 的某句原话）』这句我印象最深。」——引用一句对方自己的话，证明你真的在听。
2. **发表范围再确认**：「刚才聊的整理出来会写进公开的研究，只讲事、不提人。有没有哪段您不想被写进去的？现在跟我说，我记下来。」→ 拒写清单当场速记，当晚入 memo（[计划 §5.4](西安五日计划.md)）。
3. **引荐请求**：「您同行、邻居里头，有没有谁跟您情况不太一样、值得我也去听听的？方便的话帮我引荐一下，或者把我联系方式给 TA 也行。」→ 记录引荐三栏（[计划 §4.2](西安五日计划.md)）；拒引不追问。
4. **告别不带走**：不留材料、不推销；对方主动问「研究发哪儿」→ 如实告知渠道名，并说明「内容都是匿名的」。

## 7. 记录纪律

| 渠道 | 记什么 | 不记什么 |
|---|---|---|
| 当场速记（纸/手机备忘） | 逐字金句、关键数字、场景细节、拒答与情绪节点、我的即时反应 | 真名（只写笔名）；成段对话（那是录音的事——追问时低头写字 = 丢眼神） |
| 录音 | 对话本体全部 | — |
| 当晚 note 入库 | 速记整理成 txt/md 投 inbox 确认入库 | 可识别信息 |
| 每日田野日志 | 信息增量 1–3 条、新模式假设、明日计划 | — |

- 速记与反应**分层标注**：描述层（他做了什么/说了什么）与反应层（我想到了什么）分行写，不混排（[11-模板 §3](../../田野方法/11-模板.md)）。
- **反身性备忘**（每晚日志必写一条；[03 §5](../../田野方法/03-进入田野.md)、[11-模板 §6](../../田野方法/11-模板.md)），三问轮换：
  - 我今天哪个问题里藏着我的假设？
  - 哪个回答我听得特别顺？——顺，可能恰恰因为它确认了我的预设；
  - 对方从哪一句开始迎合我？那一刻我上一句说了什么？
- 「我今天的提问如何塑造了对方的回答」是这三问的总纲：访谈不是提取，是共建——把共建的痕迹写下来，数据才经得起审。

## 8. 常见拒绝与冷场应对

> 同意层面的拒录/撤回流程见[计划 §5.2](西安五日计划.md)；本节只管对话现场。全量现场救场（拒访/信任/失控/伦理/自身失误五类 25 条）见[11 §5](11-街头采访SOP与话术手册.md) 应变手册——本表是最高频七景的速答版。

| 场景 | 话术（照抄可用） |
|---|---|
| 「没空/不聊」 | 「没事没事，占您两分钟都不该，您忙。」——体面退场，不反问不纠缠（总纲 §5.3） |
| 「录音就算了」 | 「行，那咱就随便聊，我拿本子记两笔，您说哪句不想记我就划掉。」 |
| 「你是卖东西的吧」 | 「真不是，我卖东西早饿死了。我就是来听真话的——您要是烦了，随时抬手我就走。」 |
| 「AI 那玩意我不懂」 | 「您不用懂，我就问日子：家里买东西、看新闻，手机上有没有让您觉得『咦这个有意思』的时刻？」 |
| 冷场 / 回答就两三个字 | 沉默 3 秒 → 复述（「您是说……？」）→ 具体化（「那天都有谁在场？」）——三板斧按顺序用（05 §4） |
| 说得太敏感（他人隐私/违法） | 不接、不记细节：「这块咱就不展开了。」转向收束；涉他人可识别信息的录音段，整理时删除 |
| 反问研究目的、起疑 | 重申 30 秒自述 → 主动出示身份证 → 「您要不放心，今天咱就不聊，我下回再来。」——把退出权递回去 |

## 9. 附：访谈执行检查卡（可打印）

