## 1. 为什么观察是另一半数据

- 两问的回答不只在话语里：摊主手机上贴的收款码 vs 台式收款屏、写字楼工位的 AI 周边贴纸、公园合唱队的音响——**物与技术在场的样子本身就是问①的物证**（[04-观察与笔记](../../田野方法/04-观察与笔记.md)：观察与访谈互补而非替代）。
- 场景观察直接服务 Q1 的语境化：同样说「没用 AI」，城中村租户和写字楼白领的「没用」不是一回事——语境让同一段话有不同的分析重量（[01-研究设计](01-研究设计.md) §3）。
- 观察还是破冰与安全的输入：进点前十分钟看到的节奏，决定你几点开口、站在哪、先买什么。

## 2. 进点十分钟：结构化观察任务卡

到点后先做十分钟**不访谈**的观察（买东西/坐着/站着都行），按六格扫描一遍：

| 格 | 扫什么 | 与两问的接口 |
|---|---|---|
| 空间 | 出入口、摊位布局、人流方向、可坐处与遮蔽 | 深访可坐可站？哪个位置不挡生意？（[04 人群画像](04-人群画像与访谈适配.md) 各场景姿势档） |
| 人流 | 谁来谁走、高峰低谷、年龄构成 | 访谈窗口与时段纪律对不对（[计划 §2](西安五日计划.md)） |
| 话语 | 谁在说话、对谁说、说什么（听不懂就记语调情绪） | 本地话头、称呼习惯、生意语言 |
| 物与技术 | 收款码/POS/监控/大屏/智能设备/在场者用手机姿态 | 问①的物证：技术的真实占位 |
| 声音 | 叫卖、广播、音乐、方言比例 | 场景氛围，写案例包时的背景厚描 |
| 节律 | 峰谷切换点、补货、交接、吃饭 | 可裁剪时段；不打扰生意的红线在哪一刻 |

- 记录口诀：**只记看到的，不记猜的**——猜的进反应层（§3.2）。
- 十分钟观察本身不延长在场时间：它是买一次东西的伴随动作，不另起流程。

## 3. 速记卡与笔记分层

### 3.1 速记卡模板（每进点一张，纸或手机备忘）

```
场：____（场景类型/时段/位置粗记）      P：____（在场人构成粗记）
物：____（码/POS/设备；姓名一律略写为「收款码(姓名已略)」）
声：____（一句话声音构成）
语：____（听到的一句原话——只写化名场景，不带可识别信息）
节：____（峰谷/切换点）
疑：____（我的猜测——必须写在「疑」栏，与分析隔离）
```

### 3.2 分层纪律（与提纲 §7 同规则，换个入口再讲一遍）

- **描述层与反应层分行不混排**（[11-模板](../../田野方法/11-模板.md) §3）：「他做了什么」与「我想到了什么」是两类数据，混排后没人能再拆开。
- 速记卡「疑」栏就是反应层的观察版：当晚整理 note 时，疑栏内容**不**进描述性记录，进 memo（analytical 型，§5）。
- 物的记录注意隐私：收款码含经营人姓名、监控屏含他人影像——速记一律略写，拍照默认不拍（§6）。

## 4. 每日田野日志模板（可复制）

```
# 田野日志 D_ · XAN · ____-__-__
## 今日动了哪几类场景（含未成访谈的踩点/破冰）
## 信息增量（1–3 条：今天的田野教了我什么新的）
## 新模式假设（大胆假设，注明「假设待证」，对照 [07 分析计划](07-分析计划.md) 编码框架）
## 反身性备忘（提纲 §7 三问轮换——每晚必答一条）
## 链路卡点（今天管线哪里卡了：登记/入库/确认/引用/备份——服务 Q2）
## 明日计划（场景/时段/目标样本数/裁剪与降级预案）
```

- 日志是 Q2（链路吞吐）的第一手记录：**卡点当场记一行，别指望晚上回忆**——晚饭一吃，上午的卡点细节就没了。
- 日志覆盖范围含「无正式访谈日」（D1 进入过程本身是资料，[03-进入田野](../../田野方法/03-进入田野.md)；计划 §2 已定）。

## 5. memo 三型与 OpenField 操作映射

> memo 是把「想到的」变成「可检的」的机制。OpenField 内建三型，桌面端操作如下。

| 型 | 记什么 | 典型触发 |
|---|---|---|
| reflexive 反身型 | 我的提问如何塑造了回答；迎合起点；假设泄漏自检 | **每晚必一条**（提纲 §7 反身性备忘的正式落库形态） |
| analytical 分析型 | 当天材料里长出来的新码/新假设/交叉线索 | 有就记，不等攒——新码登记走这里（[07-分析计划](07-分析计划.md) §2.4） |
| quicknote 快记型 | 白天手头没有正式入口时的闪念 | 现场随手，回程并入前两型 |

操作落点（配合[计划 §6.2](西安五日计划.md) 每晚沉淀）：

1. 建 memo：桌面端 research 面板新建（选型+正文），正文可带对应 Encounter/P-编号（化名）。
2. 确认入档：**MEMO_CONFIRM**——未确认 memo 不参与后续分析引用。
3. 与日志的分工：**日志=当天完整结构复盘（每日一篇，走 note/inbox）**；**memo=单点想法（随想随记，走 memo 命令）**。两者都是「当晚沉淀」，缺一不可。
4. memo 同样受同意门禁管：引用他人相关内容时走与访谈一致的门禁（[使用手册](../../工程/使用手册.md) §3.4）。

## 6. 照片与场景素材纪律

- **默认不拍清单**：人脸、门牌、收款码、监控屏、城中村内景、任何含他人影像的画面——拍前过一遍：这张照片会暴露谁？（[威胁模型](../../工程/威胁模型.md)）
- 肖像同意单独取得（提纲 §2.2、[计划 §5.1](西安五日计划.md)）：话术「想拍张现场照片放进报告的话，我单独问您」——不给也完全不影响。
- 内容素材线（总纲 §7）：仅限已获同意素材进入内容库；黄金周文旅区只观察不采访也不拍人脸。
- 「这张照片后来不想要了」= 当场删权交给对方；入库后反悔走撤回与清除流程（[计划 §5.2](西安五日计划.md)）。

## 7. 每日收尾检查（观察与记录相关四连）

```
□ 场景速记卡：每进点一张，无遗漏
□ 观察素材并入当晚 note（txt/md 投 inbox 确认）
□ memo（如有）已 MEMO_CONFIRM；反身型今晚写了
□ 明日观察任务卡已预写（进点十分钟六格的对象先想一遍）
```
