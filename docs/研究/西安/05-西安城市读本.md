# 05 西安城市读本 — 访谈员的城市语境底图

> 版本 V1.0 · 2026-10 · 隶属[西安田野文档套件](README.md)
> 目的：出发前把西安装进脑子。不是导游手册，是访谈员的语境底图——城市知识只服务两件事：进点时不露怯、聊天时有钩子。
> 证据分级沿用套件纪律：【通行共识】=广泛流传、稳定可信但未逐一核实；【操作性建议】=预设，现场以实际为准。本文档**不设【核验】级**——凡是需要现地核实的，一律落到【操作性建议】并写明核实动作。
> 合成示例铁律同[README §3](README.md)：不出现任何真实受访者信息；**具体店名、村名、门牌一律不预设**——到现场按[西安五日计划](西安五日计划.md) §3 的选点逻辑现地选定，记入 FieldEvent 背景注记。

---

## 1. 使用纪律（先读这段）

- 城市知识是**背景弹药，不是卖弄素材**。访谈中引用城市知识只有一个合法用途：帮对方把话头接顺；绝不主动展示「我懂西安」。
- **先资料后知识**：对方没讲的，不用自己的城市知识去补——否则你的「知道」会塑造对方的「应该」（[05-访谈](../../田野方法/05-访谈.md)：贴假设问题，提纲 §1 同源）。
- 具体点位、村名、市场名一律现地三道核实后才用（§6.2）。

## 2. 城市结构底图

### 2.1 一城多面 【通行共识】

| 方位 | 板块 | 与本轮场景的接口 |
|---|---|---|
| 城墙内（老城） | 碑林/莲湖/新城三区交界；钟鼓楼、回坊；老居民+小商业+旅游服务业 | 菜市场、老手艺铺富矿（作坊场景） |
| 东郊 | 纺织城（灞桥区）：国棉厂苏式建筑群、1990s 下岗潮记忆浓、旧厂房改造的艺术区 | **人生两问富矿**——「厂」字辈长者样本的语境背景 |
| 南郊 | 高校带（长安路—长安区大学城）+ 文教区 | 高校周边场景（年轻对照组） |
| 西南郊 | 高新区（软件园、写字楼集群） | 写字楼场景主战场 |
| 东南郊 | 曲江：大唐不夜城、大雁塔北广场等文旅带 | 黄金周人潮区**不设访谈**（[计划 §2](西安五日计划.md)）；区内从业者（保洁/保安/摊贩）是潜在机动样本 |
| 北郊 | 大明宫遗址公园一带；铁路以北为原「道北」片区（已大规模棚改） | 见 §2.2 反刻板印象警示 |
| 远郊 | 临潼（兵马俑） | 纯观光区，不设访谈 |

### 2.2 道北：一个必须反着用的历史标签

- 「道北」指陇海铁路以北片区，1930s–40s 黄河水灾后河南难民沿铁路聚居形成，长期背负负面地域刻板印象，近年棚改后原社区已大量拆解 【通行共识】。
- 【操作性建议】若对方自述出自道北或河南移民家庭：**认真听、不接刻板印象话头、不把「河南」当笑点、不主动提「道北人」三个字**——地域标签的防御心是真实的，访谈员碰它没有任何收益。

### 2.3 城中村：存亡不定，先核实再进

- 西安城中村量级大、分布广，近年持续改造 【通行共识】。**具体哪些村还完整存在，出发前一周按地图+社交平台核一遍，进村前再核一遍**——村的存亡直接影响配额（[计划 §1.3](西安五日计划.md)）。
- 误认风险：房东易把陌生人的提问当「拆迁调查」。开场自述加一句「不是拆迁办的，跟拆迁没关系」（见[04 人群画像](04-人群画像与访谈适配.md) §3）。

## 3. 代际生命史底色（人生两问的语境）

> 这是给「听得懂对方在讲哪个时代」用的背景，不是给对方「贴代际标签」用的框架。框架是拐杖不是牢笼——每个人的生命史都是自己写的（[深度访谈](../../社会学田野/03-方法/深度访谈.md)）。**框架只用来听懂，绝不用来提问**（禁句式：「您这代人是不是都……」）。

| 代际 | 西安语境的典型生命历程线索 | 人生线素材方向 | 注意 |
|---|---|---|---|
| 50–60 后 | 三线建设、国营大厂进厂（纺织、军工、电力等）、单位制生老病死、90s 下岗再就业——「厂」是这代西安城市职工的高频词 【通行共识】 | 进厂/下岗/子女出路 | 下岗是重创伤区：对方不主动展开就不深挖（提纲 §5.3 不挖创伤细节） |
| 70–80 后 | 国企改革尾声、下海潮、进城潮、2000s 起买房上车——「折腾」是关键词 | 南下还是留西安的抉择、房贷与家计 | 防把「奋斗叙事」当唯一脚本；对方若讲代价，接住 |
| 90–00 后 | 考学流动、文旅/直播/新消费就业、考公考编热——「稳定性」焦虑是关键词 【操作性建议】 | 留西安还是回老家 | 只问现象不问个人考编做法（[04 §4](04-人群画像与访谈适配.md)） |

- 「厂」与「单位」这两把钥匙：公园晨练的长者若开口讲厂，讲的多半不是怀旧而是身份——「我是 X 厂的」曾经等同于「我是谁」。听到就记时间节点，不纠细节。

## 4. 方言与称呼

### 4.1 方言现状与分寸

- 西安城区普通话互通度高（[计划 §3](西安五日计划.md) 已注记）；关中话（中原官话关中片）在早市、公园、老居民区仍是默认语 【通行共识】。
- 高频词**听懂即可，不必学舌**——刻意学方言容易被当作轻佻或表演 【操作性建议】：

| 词 | 义 |
|---|---|
| 乡党 | 老乡/同乡的泛称，也作套近乎的招呼 |
| 嘹咋咧（嫽扎咧） | 好得很；「嫽」为古字 【通行共识】 |
| 克里马擦 | 快点、麻利些 |
| 制达 / 雾达 / 啊达 | 这里 / 那里 / 哪里 |
| 额 | 我 |

- 听力策略：老年受访者语速快口音重 → 录音贴近、请对方放慢；仍听不懂 → 换对象不硬聊（提纲已有口径，[计划 §3](西安五日计划.md) 方言注记）。

### 4.2 称呼

- 默认「师傅」最稳：不分性别年龄场合几乎通用 【操作性建议】。
- 写字楼/高校语境「老师」通用；明显年长且氛围熟络时「叔/姨」可用。
- 避免「大姐/大妈」类年龄指向称呼——部分人敏感 【操作性建议】。

## 5. 节令物候（10 月）

- 10 月西安入秋，处于华西秋雨影响边缘——连阴雨概率不低、早晚温差大 【通行共识】。装备雨具+外套（[计划 §9.1](西安五日计划.md) 已列）。
- 晨练文化极盛：太极、合唱、暴走团、抖空竹、甩鞭，公园是退休者的主舞台 【通行共识】——公园晨练场景的时段纪律（07:00–09:30，[计划 §2](西安五日计划.md)）与之匹配。
- **黄金周专条**：行程若落 10 月上旬，国庆改变全城节奏——写字楼空、文旅爆、早市公园照常但人流结构变。完整联动预案见[计划 §2](西安五日计划.md)；此处补一句：黄金周本地退休者反而有闲（子女回家、天晴则出门），公园样本可能更好约 【操作性建议】。
- 秋雨对场景的挤压：连阴雨日公园与早市人流骤减——把雨天预留给写字楼/作坊等室内场景（计划 §2 逢雨规则同源）。

## 6. 公园与微观点位

### 6.1 大型公园清单（晨练人口密集）【通行共识】

| 公园 | 区位特点 |
|---|---|
| 兴庆宫公园 | 老城东侧、高校旁——学生与退休者混合 |
| 环城公园 | 顺城墙一周的带状公园——老居民密度极高 |
| 大明宫国家遗址公园 | 北郊——健走/广场群体量大 |
| 曲江池遗址公园 | 南郊——环境好，中产晨练多 |
| 丰庆公园 | 西郊——周边老居民 |

选点逻辑照旧：固定队伍=有队长节点（[计划 §3](西安五日计划.md)）；本清单只是缩小搜索范围，**不替代现地选点**。

### 6.2 微观点位三道核实

- 社交平台与短视频上流传的「西安早市」名单很多（如城墙内某门里早市等说法）——**本文一律不背书、不点名** 【操作性建议】。
- 任何微观点位使用前过三道核实：①地图上还在不在 → ②现地走一遍看人流与构成 → ③管理方/摊主点头（节点人物，[计划 §3](西安五日计划.md)）。三道全过才登记 FieldEvent。

## 7. 吃食：暖场弹药（不是展示品）

- 面食宇宙：biángbiáng 面、油泼面、泡馍、肉夹馍、甑糕、回坊胡辣汤…… 【通行共识】
- 用法：暖场三句（提纲 §2.3）之外，饮食是最自然的本地话头——但**问法必须是请教，不是评价**：「您看哪家的面正宗？」永远安全；「我知道哪家的正宗」永远多余。
- 回坊（北院门一带）旅游化程度高，本地人常去的市场另有其处——不确定就不断言，把判断权留给对方。

## 8. 城市知识误用警示（收尾）

| 误用 | 后果 | 对策 |
|---|---|---|
| 拿城市知识补全对方没说的 | 你的「知道」塑造对方的「应该」 | 先资料后知识（§1） |
| 把代际框架抛给对方 | 「您这代人是不是……」= 贴假设（提纲 §1） | 框架只用来听懂，不用来提问 |
| 接道北/河南等标签话头 | 触发地域刻板印象防御 | 只听不接（§2.2） |
| 断言某市场/某村还活着 | 白跑一趟 + 露怯丢信任 | 三道核实（§6.2） |
| 向对方「科普」西安 | 卖弄毁关系 | 你是来听的，不是来讲的 |
