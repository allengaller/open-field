## 1. 目标与产出定义

### 1.1 本轮要回答的三个问题

| # | 问题 | 回答载体 |
|---|---|---|
| Q1 | 「AI 两问」在不同人群中的回答结构差多大？——写字楼白领、个体摊主、退休人群、高校学生四组对照，谁在用、用什么、盼什么 | 有效访谈 ×12（§1.3）+ 可用 RefId 回溯的原话 |
| Q2 | 城市高密度多场景下，OpenField 单兵全链路（登记 → 同意 → 入库 → 引用 → 日志 → 备份）的日吞吐上限与卡点在哪 | 每日链路卡点记录 → 返程 72h 汇总 |
| Q3 | 四问提纲的通用性边界：哪些追问在哪些场景失效、哪些人群需要裁剪档 | 提纲修订记录 → 回填[提纲](西安访谈提纲.md) |

### 1.2 产出定义

| 产出 | 达标线 | 说明 |
|---|---|---|
| 有效访谈 | 12 目标 / 8 保底 / 6 降级线（§1.3） | 完整链路：同意 + 录音入库 + 当日确认 + 可签发引用 |
| 案例包 | ≥3 条可成文案例（场景 + AI 两问 + 人生线） | 化名 A/B/C，全部可回溯到 RefId |
| 链路卡点清单 | 每日记录，返程 72h 汇总 | 回填使用手册/规格，服务 P2 |
| 提纲修订 | 返程 72h 出提纲 V1.1 | 回填提纲文档变更记录 |
| 内容底料 | 纪实素材若干（仅限已获同意的素材） | 服务总纲 §7 内容线 |

### 1.3 与既有轮次的关系及最少必要样本量

- [路书](../路书.md)（曹县）验证的是县城单点场景；本轮覆盖城市高密度多场景，共用固定章节模板与晚间锁盘纪律。
- 写字楼场景与总纲 §2「咨询换单」兼容：顺带承接咨询机会，但本轮以访谈数据为主、不主动推销（边界见[提纲](西安访谈提纲.md) §2）。
- 样本量依据 Guest, Bunce & Johnson (2006)：元主题要素最早 6 次访谈出现，多数主题 12 次内饱和（[05-访谈 §7](../../田野方法/05-访谈.md)）。据此定 **目标 12、保底 8、降级线 6**：

| 场景 | 目标 | 保底 | 对照价值 |
|---|---|---|---|
| 写字楼 | 3 | 2 | AI 深度用户密集区，问 ① 的上限样本 |
| 菜市场 | 2 | 1 | 个体经营 + 现金流视角 |
| 城中村 | 2 | 1 | 低稳定就业 + 居住形态 |
| 高校周边 | 2 | 1 | 年轻对照组（问 ① 命中率最高） |
| 公园晨练 | 2 | 2 | 退休对照组（与高校组构成代际两极）；保底 2 落实长者纪律（[04 §8](04-人群画像与访谈适配.md)） |
| 小生意作坊 | 1 | 1 | 手艺型生产，AI 边界样本 |
| **合计** | **12** | **8** | 六类全覆盖；写字楼与公园各加厚 1（公园加厚即长者纪律的结构性落实） |

- **有效访谈判定**（四项全满足才计入）：①录音同意有效且未撤回；②录音已确认入库挂 Encounter；③当日田野日志覆盖；④可签发引用。
- 未录音的破冰级短交流照常登记 Encounter（备注「未录音-破冰」），为场景地图与引荐链服务，但不计入样本。
- **降级判定**：D4 晚盘点 < 8 → D5 上午必补 1–2 条；最终 < 6 → 本轮判「中止」而非「失败」，照常带回数据复盘（路书 §8.4 口径）。

## 2. 五日日程骨架

> **定盘**（T-7 选型产出，[09](09-路线与访谈备选.md) 选型矩阵）：路线选**案一·老城锚定**骨架 + **案八·先易后难**排序；访谈档按[09 场景配套表](09-路线与访谈备选.md)分场景执行——公园档四（人生线前置）、菜市场/作坊档五（物证导引）、写字楼档二（裁剪档）、城中村档一、高校档九（演示反差），当日用档写进日志（09 档位纪律）。下表为日程骨架；逐日场景落位与时段以[10 §2](10-采访执行细案.md) 执行细案为准，两者不一致时按 10 执行并回填本表。

| 日 | 主题 | 上午 | 下午 | 晚间 |
|---|---|---|---|---|
| D1 | 进入田野 | 抵西安 → 安顿 → 解锁 vault + TIME_SYNC → 住宿周边预踩点 | 两类场景踩点、破冰级短交流 ×2–3、锁定明日时段与节点人物 | 当日日志（无正式访谈也写——进入过程本身是资料，[03 §2](../../田野方法/03-进入田野.md)）→ 次日计划 → 校验 + 备份 |
| D2 | 主力日 ① 早间场景 | 菜市场 / 公园晨练 访谈 ×1–2（07:00–10:30） | 城中村或作坊 访谈 ×1–2 | 录音入库 → 确认 → 日志 → 校验 → 双备份（§6.2） |
| D3 | 主力日 ② 写字楼日 | 菜市场/城中村补位 + 滚雪球跟进 | 写字楼 访谈 ×1–2（15:00–17:30 主窗口） | 同上 |
| D4 | 主力日 ③ + 机动 | 高校周边 访谈 ×1–2 | **全域机动缓冲**：补访、追引荐链、天气备选场景（§3 机动行） | 同上 + 样本量盘点（对照 §1.3 配额） |
| D5 | 撤离与整理 | 可选补访 ×1（≤1h）+ 收纳打包 | 终检 verify 全绿 → 第三份备份随身 → 撤离（高铁/航班） | 返程途中启动 72h 收尾清单（§6.3） |

**时段纪律**（现场硬规则，与[路书](../路书.md) §9.1 一致）：

- 场景专属窗口：公园晨练 07:00–09:30；菜市场早市 07:00–10:30；写字楼 10:00–11:30 / 15:00–17:30（总纲 §6.2 时间窗口）；高校周边 16:00–19:00；作坊避开饭点。
- D2–D4 至少覆盖一个工作日（写字楼场景仅工作日有效）；若 D2/D3 落周末，写字楼场景与 D4 对调。
- **19:00 后不做一对一访谈**；每晚 22:00 前回住宿并向家人报平安（每日 check-in 硬规则）。
- 逢雨/高温：公园与早市顺延，切换写字楼/作坊等室内场景，时段表不硬扛。
- **若行程落 10 月上旬（国庆黄金周）**：写字楼场景整体失效（假期空楼）→ 该配额并入 D4 机动或砍至 1 条；大唐不夜城等文旅区人流暴涨**不设访谈**（只观察）；公园晨练与早市照常运转但人流结构改变（游客占比升、摊主更忙），深访窗口提前至 07:00–09:00。节令细节见[05 城市读本 §5](05-西安城市读本.md)。

**每日降级方案**：

| 触发 | 降级动作 |
|---|---|
| 单日有效访谈 = 0 | 次日只保「1 条完整链路」为唯一目标；场景换到最易进入的菜市场/公园 |
| 连续被拒 5 次 | 立即停止陌拜，换场景吃饭休息（总纲 §8.1），当日不再强攻 |
| 疲劳/眼睛报警 | 当日计划终止，晚间只做入库与日志（总纲 §8.2） |

## 3. 西安落点建议（类型化场景）

> 城市型落点的优势是密度与代际对照，劣势是守门人多、进入门槛高——用「先消费后开口」「节点人物切入」补偿。以下只给类型与选点逻辑，具体点位到现场按逻辑选定并记入 FieldEvent 背景注记；**不预设、不编造店名门牌**。

> 每类目标对象的「一天画像 · AI 接触面假设 · 人生线素材方向 · 访谈适配」见[04 人群画像](04-人群画像与访谈适配.md)——画像只是预设敏感点，现场一律以对方实际讲述为准。

| 场景 | 目标对象 | 选点逻辑（怎么挑具体的场） | 进入方式 | 注意 |
|---|---|---|---|---|
| 城中村 | 房东、租户、小卖部、维修铺 | 挑有巷口小卖部、电动车与晾衣密度的成片自建房区；避开纯施工区 | 巷口小卖部/修车摊是天然节点人物，先闲聊再自报身份 | 巷内拍照先问；不进出租屋；傍晚与周末上午人气最足 |
| 菜市场 | 摊主、来采购的小餐馆老板 | 挑非旅游型、服务周边居民的老市场；看摊位密度与老年顾客比例 | 先当顾客买一次再开口；市场管理方办公室是第二个节点 | 高峰期不打断生意，只登记不深聊；早市黄金段 07:00–10:30 |
| 高校周边 | 文印店主、小吃摊主、学生 | 校墙外商业街；文印店/自习室是信息节点 | 消费切入；学生组作年轻对照 | 未成年人一律不访谈不拍；留意课表节奏（毕业季/考研期话题差异大） |
| 写字楼 | 初创员工、行政、创业者、物业 | 产业园区与地铁上盖楼；电梯间、楼下咖啡档口为低门槛接触点 | 公开研究者身份自述 + 身份证（见下方注记）；物业前台先打招呼 | 楼内拍摄须物业同意；咨询机会顺带承接但不推销 |
| 公园晨练 | 退休职工、太极/合唱/健走队 | 大型综合公园晨练区；固定队伍有组织 = 有队长节点 | 先旁观一早摸清节奏，从队伍边缘切入；请队长默许再一对一 | 老年人口音 + 听力：录音贴近、语速放慢；避免围观式采访 |
| 小生意作坊 | 裁缝、修表、配钥匙、小型加工间 | 老城区沿街手艺铺与市场配套加工间；「工具即招牌」 | 修东西/买东西顺势聊；师傅手上活不停也能谈 | 作坊内设备多注意站位；拍照须单独取得肖像同意 |
| 机动：平台劳动者 | 网约车/出租车司机、外卖骑手 | 白天短途乘车、商圈骑手聚集点自然遇到 | 乘车/取餐途中自然对话；是否录音单独征求 | 不占 §1.3 配额，D4 机动时段启用；车内录音征得同意方可 |

**身份公开注记**：总纲 §6.2 的守门人话术为咨询场景设计，其中「应聘式」等伪装路径**本研究轮次禁用**（[07 伦理](../../田野方法/07-伦理.md)：无隐蔽采集）；只沿用其时间窗口与体面退场两部分。

**方言注记**：西安城区普通话互通度高，方言铁律（[田野落点](../田野落点.md) §一）风险低；老年受访者口音重时录音贴近、请对方放慢，仍听不懂 → 换对象不硬聊。

## 4. 抽样与引荐链策略

### 4.1 种子受访者怎么选

- 每类场景先找**节点人物**（市场老摊位、文印店老板、晨练队长、物业前台）：节点人物本身不一定受访，但一定登记 Encounter——场景地图与引荐网从节点长出来（[03 §2](../../田野方法/03-进入田野.md)：抽样逻辑本身就是资料）。
- 种子优先级：在场时间长者（能讲变迁）＞有雇佣/师徒关系者（能引出第二人）＞独行者。
- 目的性抽样而非代表性抽样：按信息丰富度选人，不追求统计均匀（[03 §4](../../田野方法/03-进入田野.md)）。

### 4.2 滚雪球记录方式

- 当场记三栏：谁引荐（引荐人笔名）→ 被引荐人笔名 → 引荐语境（当场引荐 / 事后微信约定）。
- 引荐请求话术与时机见[提纲](西安访谈提纲.md) §6；见被引荐人时开场先复述语境（「是化名 A 让我来找您的」——信任迁移）。
- 入库时写入 Participant 引荐链（顺序逗号分隔，如 `P-003, P-007`）——引荐链图即滚雪球抽样的证据（PRINCIPLES §2.5）。
- 引荐衰减处理：同一节点连引 2 人后信息重复 → 该链停，转投新场景种子；拒引不追问，登记「引荐意愿低」即可。

### 4.3 饱和与停手

同一场景连续 2 条访谈给不出新信息 → 该场景停止加样，机动时段转投信息量最大的场景（饱和判断见 [08-信效度 §5](../../田野方法/08-信效度.md)）。

## 5. 知情同意流程

> 原则：同意先于采集、永不补录（[07 伦理 §4](../../田野方法/07-伦理.md)）；流程像聊天一样自然，机制对受访者无感（PRINCIPLES §2.3）。完整开场脚本见[提纲](西安访谈提纲.md) §2，本节只定流程与口径。

### 5.1 三类同意与落库动作

| 类型 | 现场话术要点（一句话版） | 落库 |
|---|---|---|
| 录音 | 「我录个音方便回来整理，只录声音不拍脸，写东西都匿名，您随时喊停，反悔我就全删。」 | 类型=录音；口头同意 = 录音文件第一句，当晚录入 `CONSENT_RECORDED` |
| 肖像 | 「想拍张现场照片放进报告的话，我单独问您；不给也完全不影响。」 | 类型=肖像；不拍脸原则下默认少拍 |
| 发表 | 「整理后的文字会写进公开的研究，只讲事不提人；有不想被写的段落，收尾时告诉我。」 | 类型=发表，范围说明写「仅研究发表、匿名」；拒写清单见 §5.4 |

- 三类**逐项问、逐项记**，不打包默认；对方只同意其中几项就如实勾选——引用门禁会自动管住未授权类型（[使用手册 §3.4](../../工程/使用手册.md)）。
- 敏感项（健康、宗教、行踪轨迹、不满十四周岁未成年人）一律单独问；**未成年人不作为访谈对象**，背景中出镜一律不拍（PIPL §28–29，07 §3.1）。

### 5.2 拒访与撤回处理

| 情形 | 动作 |
|---|---|
| 完全拒访 | 体面退场不纠缠不反问（总纲 §5.3，话术见[提纲 §8](西安访谈提纲.md)）；拒访原因一句话记入当日日志——拒访本身是资料 |
| 拒录音但愿聊 | 切笔记模式，登记 Encounter（备注「拒录音」）；笔记不记可识别信息，引用需另行取得发表同意 |
| 中途要求停 | 立即停录并当面确认已录部分删还是留；要求删 → 当晚走 PIPL 清除流程（危险区两次输入笔名确认，`PURGE_SUBJECT` 留痕）并告知对方结果 |
| 事后反悔（微信联系） | 同上；撤回即刻生效（`CONSENT_WITHDRAW` 入链），已签发引用自动失去资格（门禁） |

### 5.3 真名纪律（同意的孪生规则）

现场纸面与手机备忘只写笔名（P-001…）；真名仅在确需对应时进加密库 `participant_identity`，绝不进笔记、聊天记录、云端备忘（红线清单见 §7.2）。

### 5.4 拒写清单

收束时必问（话术见[提纲 §6](西安访谈提纲.md)）：对方不想被发表的内容 → 当场速记 → 当晚写入该访谈备注或 memo 留痕；发表类材料整理时逐条比对。

## 7. 风险与预案（安全评估 · 路书固定章节）

### 7.1 风险域矩阵

| 域 | 主要威胁 | 硬规则（触发 → 动作） |
|---|---|---|
| 人身 | 一对一访谈场景失控、夜间返程 | 访谈只在白天 + 公开场所；19:00 后不做一对一；22:00 前回住宿向家人 check-in；人生线触发对方情绪失控 → 按[提纲 §5](西安访谈提纲.md) 退出机制处理，必要时当场结束并陪对方回到人群 |
| 健康 | 用眼负荷（高度近视）、秋季肠胃 | 视力模糊/头痛 → 当日计划立即终止（总纲 §8.2）；常用药随身 |
| 设备与数据 | 手机/笔记本/U 盘丢失 | 手机单丢：备用录音设备兜底；笔记本单丢：手机双录 + U 盘至多损失当天；**设备 + 双 U 盘同时丢失 → 采集终止**，按路书 §9.3 口径做数据安全事件复盘；vault 口令不与设备同放 |
| 法律与伦理 | 拍摄越界、身份被质疑 | 未获同意不录不拍；园区/楼内拍摄先经物业；身份自述一句话版 + 身份证配合出示；不承诺报酬、不夸大用途 |
| 被检查/盘问 | 写字楼物业、市场管理方、公共场合盘问 | 服从在先、争执为零：出示自述与证件，不主动展示库内其他受访者数据；被要求停止 → 立即停止换点位；被要求删当次录音 → 当场删（未入库文件直接删；已入库走 PIPL 清除）；人身安全永远优先于数据 |
| 行程中断 | 雨/高温、列车晚点、突发公共事件 | 场景切换规则（§2 时段纪律）；D4 下午全域机动吸收单日中断；连续两天中断 → 提前撤离，按「中止」复盘 |

### 7.2 数据安全红线（一票否决项）

1. **绝不把真名带出加密库**：纸面、微信备注、云端备忘、聊天记录一律笔名；
2. 真实田野数据永不进 git / 云盘 / 网盘（CONTRIBUTING 红线）；
3. 未入库音频不过夜（§6.2）；备份双 U 盘分放；
4. 公共 Wi-Fi 不登录任何敏感账号（全链路本就离线）；口令纸条与设备分放。

### 7.3 撤离红线

- 连续被拒 5 次且情绪明显失控 → 当日停（总纲 §8.1）
- 身体/眼睛报警 → 当日停（总纲 §8.2）
- 设备 + 双 U 盘同时丢失 → 采集终止

### 8.1 交通三档（选一，量级估计，T-7 锁定）

|---|---|---|
| 交通往返 | ¥1700–2200 | 以 12306/航司实时为准 |

### 8.3 单位经济与止损

- 目标 12 条 → ≈¥300–400/条；保底 8 条 → ≈¥500–550/条——城市轮次单位成本高于县城 pilot（住宿与交通更贵），买的是代际对照与场景密度。
- 止损联动（总纲 §8.4 Kill Switch）：实际支出达预算 150% 或出现计划外大额 → 立即返程，判「中止」非「失败」；只动用试错资金包中本额度，核心储备不动。
- 确定性收益：≥6 条完整链路样本、链路卡点清单、提纲 V1.1；期权性收益（咨询线索、内容流量）不计价、不作成本依据（路书 §8.3 口径）。
