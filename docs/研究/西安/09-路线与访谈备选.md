## 0. 共同前提（十案共用的硬约束，先读这段）

- 路线案共用：五日窗口（D1 进入 / D5 撤离）、配额 12/8/6（[计划 §1.3](西安五日计划.md)）、时段纪律（公园 07:00–09:30、早市 07:00–10:30、写字楼 10:00–11:30/15:00–17:30、高校 16:00–19:00）、19:00 后不做一对一、22:00 前回住宿报平安、连续拒 5 次停手、雨天切室内。
- **每晚 SOP 全案一致且不可裁剪**：入库 → 日志 → 校验 → 双备份（[计划 §6.2](西安五日计划.md)）——路线案只改变白天在哪，不改变晚上做什么。
- 访谈案共用：四问骨架、同意三件套逐项、每问一个开场、三板斧、收束三件套、执行检查卡（提纲 §1–2/§6/§9）。
- **变体边界（红线）**：访谈案只许改「问什么、何时问、以什么形式问」；**同意、记录、撤回、收束等伦理动作一律不得变体化**。
- 组合纪律：路线一案为主（可吸一辅）；访谈档**同期并行不超过两档**，当日用档记入日志（方法码联动，[07-分析计划](07-分析计划.md) §2.3）。

## 一、路线十案

### 案一 老城锚定案（城墙内大本营）—— 默认推荐

- **路线骨架**：D1 抵达、住城墙内（钟楼—永宁门一带）+ 周边踩点 → D2 早市 + 环城公园晨练 + 老城菜市场 → D3 老城作坊 + 就近城中村 → D4 唯一远征日：高新/小寨写字楼（15:00–17:30）→ D5 老城补访 + 撤离。
- **设计原理**：单兵最大的隐性成本是通勤耗损。老城一圈内叠合四类场景（早市/公园/菜市场/作坊，[05-西安城市读本](05-西安城市读本.md) §2.1），把每日状态的大头分给访谈而不是地铁。
- **主要考虑**：写字楼与高校只能靠 D4 单日远征，配额压至 1–2 条；若行程落黄金周，D4 报废须切案六；老城旅游化街区（回坊核心带）要绕开。
- **适用判定**：默认首选——体力保守、首轮城市单兵、行程避开黄金周高峰。

### 案二 城南双核案（高新 + 大学城）

- **路线骨架**：D1 住南郊（小寨一带）+ 踩点 → D2 早市/公园 + 高校周边 → D3 写字楼日 + 晚间高校 → D4 菜市场 + 城中村 + 作坊（南郊就近）→ D5 补访 + 撤离。
- **设计原理**：把「AI 深度用户」（写字楼）与「年轻对照」（高校）两大高产场景钉进通勤半径——问①命中率最高的两组优先保产（[04-人群画像](04-人群画像与访谈适配.md) §2/§4）。
- **主要考虑**：长者 ≥2 红线要靠早起跨区（兴庆宫/环城公园）解决，等于连续多日 6:30 出门；退休组数据偏薄，人生线厚度下降。
- **适用判定**：写字楼 3 条是硬指标、且愿意用早起换长者样本时。

### 案三 纺织城专题案（东郊工业记忆纵深）

- **路线骨架**：D1 住东郊（半坡/纺织城一带）→ D2 公园晨练（厂矿长者）×2 + 菜市场 → D3 作坊 + 社区商业 + 城中村 → D4 钟楼 CBD 写字楼远征 + 回程补 → D5 纺织城补访 + 撤离。
- **设计原理**：把 RQ2/人生线做成**同一空间社群的纵深**——「厂」字辈长者（[05-西安城市读本](05-西安城市读本.md) §3）的生命史与 AI 两问天然交织，案例包成色最高；同质社区里滚雪球链条最快。
- **主要考虑**：场景类型学多样性下降，RQ1 的组间对照变弱；引荐链同质化风险（同一节点连引 2 人即停，[计划 §4.2](西安五日计划.md)）；社区集体氛围可能整体偏向命运叙事。
- **适用判定**：本轮以人生线与案例包为最优先产出时。

### 案四 地铁脊柱案（2 号线纵贯）

- **路线骨架**：D1 住钟楼段 → D2 北段（大明宫晨练 + 城中村）→ D3 中段（老城早市 + 作坊）→ D4 南段（小寨写字楼 + 大学城）→ D5 补访 + 撤离。每天一个站段，落点全部钉在站点 1km 步行圈。
- **设计原理**：单兵无车，地铁是唯一可靠的时间骨架；「一天一段」把通勤预算化（每日 ≤60min），且北—中—南的空间纵贯自带代际对照结构。
- **主要考虑**：2 号线黄金周客流爆表，必须早晚错峰；每日换场景 = 每日重建场感，破冰成本高于锚定案；若不换住，中段起通勤损耗最大。
- **适用判定**：想要空间结构自带对照组、且能接受换住或长通勤时。

### 案五 代际两极对角案（北老南青）

- **路线骨架**：D2 北郊（大明宫晨练长者 + 城中村）→ D3 老城（早市 + 作坊 + 菜市场）→ D4 南郊（高新写字楼 + 高校）。代际两极在空间与时间上完全分开。
- **设计原理**：连续同质人群会让提问口吻互相污染——对长者讲完人生线，转天对学生会不自觉复用同一腔调。把最强对照组分开，既是访谈员的状态管理，也是方法防护（反身性，[08-访谈员自我准备](08-访谈员自我准备.md) §2）。
- **主要考虑**：三象限跨度大、通勤总量十案最高；每类场景只有一天机会，天气与拒访冲击无缓冲。
- **适用判定**：状态最好、且已有城市单兵经验时。

### 案六 黄金周规避案（假期重配）—— 黄金周强制

- **路线骨架**：若行程落 10.1–10.7：写字楼配额砍至 1（D4 唯一试投）或清零并入机动；公园晨练加厚至 3（假期长者有闲，[05-西安城市读本](05-西安城市读本.md) §5）；主力 = 早市 + 城中村 + 作坊 + 平台劳动者；文旅区只观察不访谈。
- **设计原理**：[计划 §2](西安五日计划.md) 黄金周联动注记的完整展开——不硬扛失效场景，把配额重分配给假期反而变好的场景。
- **主要考虑**：在业者占比下降，RQ1 的「在用-工作」子码变薄；平台劳动者假期单量结构特殊，记录中必须标注。
- **适用判定**：行程确定落黄金周时为**强制案**，不再与其他路线案竞争。

### 案七 滚雪球优先案（节点人物驱动）

- **路线骨架**：D1–D2 只攻两个节点（一个菜市场老摊位 + 一个晨练队长），其余一切访谈由引荐链生长，每日落点由前晚链况决定。
- **设计原理**：抽样逻辑本身就是资料（[计划 §4.1](西安五日计划.md)）；生人城市里引荐链的信任迁移（提纲 §6）是最稀缺资源——优先把链建起来，后期产能指数化。
- **主要考虑**：前期慢，D3–D4 高峰压力大；必须设硬回退线：**若 D2 晚链长为 0 → D3 回落陌拜**；每晚日志盘点链长。
- **适用判定**：破冰有把握、或 T-7 已接上 1–2 个引荐（[计划 §9.2](西安五日计划.md)）时。

### 案八 强度递进案（由易到难）

- **路线骨架**：D2 菜市场/公园（最易）→ D3 作坊/城中村（中）→ D4 写字楼/高校（最难）。
- **设计原理**：访谈手感是练出来的——先在低门槛场景练熟三板斧、完成拒访脱敏，再攻有守门人的场景（写字楼物业）。
- **主要考虑**：易场景饱和风险（连续 2 条无新信息即停，[计划 §4.3](西安五日计划.md)）；最难的场景恰好落在体力最差的一天。
- **适用判定**：城市单兵经验不足、需要练手期时。

### 案九 强度递减案（先难后易保底）

- **路线骨架**：D2 写字楼（工作日满格窗口）+ 高校 → D3 作坊/城中村 → D4 菜市场/公园收尾 → D5 易场景补访。
- **设计原理**：最不可控的场景放在挫败容忍度最好的最前段；后三天全是高成功率场景垫底——**8 条保底线的稳定性十案最高**。
- **主要考虑**：第一天空手重创士气（须预写空手预案，[08-访谈员自我准备](08-访谈员自我准备.md) §4）；D2 若恰逢黄金周，方案整体作废。
- **适用判定**：写字楼是硬指标、行程确定为工作日、且对自己的韧性有底时。

### 案十 双据点辐射案（老城 + 高新两住宿）

- **路线骨架**：D1–D2 住老城（D2 早市/公园/作坊）→ D3 上午搬家至高新/小寨、下午写字楼 → D4 高校 + 补位 → D5 补访 + 撤离。
- **设计原理**：用一次换住（+¥200–300）把两大据点的早晚双窗口都压进 30 分钟通勤圈——相当于案一与案二的合成，只付一次搬家成本。
- **主要考虑**：搬家耗半天状态；换住当晚锁盘在陌生房间执行（双 U 盘分放规则重排；备份纪律不可破）；订房需可寄存行李、下午入住。
- **适用判定**：预算允许、且老城场景与写字楼都要保产时。

## 二、访谈计划十案

> 十案都是四问骨架的**组装方式**变体；伦理动作（同意/记录/撤回/收束）全案一致，不在变体范围内。

### 案一 标准四问档（基线）

提纲 V1.1 原样执行，39–46 分钟。
- **原理**：经设计平衡的主档，AI 线与人生线时间占比已调匀。
- **考虑**：高峰期摊主与写字楼午休场景 40 分钟难约。
- **适用**：默认档；一切场景。

### 案二 25 分钟裁剪档

砍问③与回环，保「暖场 → ① → ② → 桥 → ④ → 收束」（提纲 §4 已内置）。
- **原理**：高拒绝率场景的存活设计——答应率与时长强相关。
- **考虑**：人生线变薄，RQ2 数据密度下降；**长者样本慎用此档**（人生线是长者组的价值所在）。
- **适用**：写字楼午休、生意高峰时段的摊主。

### 案三 两问纯化档

全程只做问①②，15–20 分钟。
- **原理**：单变量最干净、单日吞吐 6–8 条——Q2（链路压测）的利器，也是破冰级接触升级样本的快筛档。
- **考虑**：RQ2 报废、案例包成色降级；不可整轮使用，只与标准档混用。
- **适用**：链路压力日、场景快速扫样。

### 案四 人生线前置档

④开场 → ①② → ③省略或并入故事。
- **原理**：故事开场绕过「AI」一词对非用户的心理门槛（「AI 那玩意我不懂」，提纲 §8）——先建立信任再谈技术。
- **考虑**：时长失控风险最大，硬收束纪律（「咱今天先到这儿」）必须练熟；AI 数据回收率不稳定。
- **适用**：公园长者为主；其他人群慎用。

### 案五 物证导引档

以现场物件开场（收款屏/手机/设备：「您这屏是新换的？」）→ 滑入① → ② → ④。
- **原理**：把[06 §2](06-观察与记录指引.md) 的「物与技术」观察接口前置为提问入口——具体化提问天然防姿态性回答。
- **考虑**：完全依赖进点十分钟观察的质量；问②的抽象期待仍需标准问法兜底。
- **适用**：菜市场、作坊（物与工具即招牌）。

### 案六 同题双访档

核心场景配对访谈 2 人（相邻摊主/同队晨练者），问法完全一致。
- **原理**：组内差异最小化设计——两人回答之差 ≈ 个体特质之差，直接服务 P1（场景分化 vs 个体特质）的判定（[07-分析计划](07-分析计划.md) §3）。
- **考虑**：样本消耗 ×2，配额内做不满所有场景；相邻者可能互相通气（访谈错开、不向任一方提对方内容）。
- **适用**：P1 是本轮最想要的分析产出口时，选 1–2 个场景用。

### 案七 回环强化档

把回环问题升格为每问的固定追问轴（①「当年没用 AI 这活怎么干」→ ③「当年最想有人帮的事」→ 故事收束到「那时如果有 AI」）。
- **原理**：时间纵深最厚——每个受访者自带两个年代两个答案，人生-AI 交叉码产量最大（[07-分析计划](07-分析计划.md) §2.2）。
- **考虑**：反事实提问易诱导美化过去，需中性锚定（「那是确实，那时候没人有 AI」）；只对谈兴好的受访者全量使用。
- **适用**：谈兴好、在场时间长的样本；与案四叠加效果好。

### 案八 追访二段档

当场 15 分钟（暖场 + 同意 + ①）→ 征得同意次日约第二次 30 分钟（②③④ + 回环）。
- **原理**：把「同意成本」与「深度成本」分摊——生人首访同意率高、深访同意率低，用第一次做跳板。
- **考虑**：失访率高（约到第二次的可能只有一半）；两次 Encounter 的链接让管线翻倍；需引荐链垫底。
- **适用**：滚雪球长出来的样本（案七路线配套）。

### 案九 演示反差档

问②之前请受访者当场试一个具体 AI 工具（语音转文字/拍照识别），再问「这东西您会用吗/想要吗」。
- **原理**：把「想象与营销」码族从话语层拉到行为层——说「不会用」的人现场试一次才知道卡在哪，可及性障碍直接可观察。
- **考虑**：设备在场改变访谈动力学（观察者效应 +1）；**演示工具的选择本身带立场**（带什么 = 暗示什么）；长者分寸极小心，不能变成教学或推销；须事前说明「我给您看个东西」。
- **适用**：高校、写字楼；长者只在对方主动凑近看时用。

### 案十 同行跟随档

不坐下聊，跟着干活聊（摊主理货一小时/骑手接两单），四问嵌进劳动过程。
- **原理**：参与观察与访谈合体（[参与观察](../../社会学田野/03-方法/参与观察.md)）——劳动现场的回答带完整语境，胜过坐谈姿态。
- **考虑**：守门、安全、录音质量（环境噪声）、时长硬控四项全是难点；只适用作坊与机动组；**必须过[计划 §7.1](西安五日计划.md) 安全评估**，19:00 红线照旧。
- **适用**：小生意作坊、平台劳动者机动组。

|---|---|---|
