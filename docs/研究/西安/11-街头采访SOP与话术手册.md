# 街头采访全量 SOP 与话术手册（现场版）

> 版本 V1.0 · 2026-10 · 上游：[西安访谈提纲](西安访谈提纲.md)（问什么）→ [10 采访执行细案](10-采访执行细案.md)（去哪找谁）→ 本文（怎么靠近、怎么控场、怎么救场）
> 「自媒体街头采访」流派的手艺——破冰、接话、救场、收束——全部可以借；它的「先拍后问、隐蔽拍摄」一样都不能借（见 §8）。
> 本文全部话术为【操作性建议】：照着说不是必须，现场以对方反应为准。

## 0. 本文是什么、不是什么

| 文档 | 管什么 |
|---|---|
| [西安访谈提纲](西安访谈提纲.md) | **问什么**：四问原文、追问树、人生线降敏感度、收束脚本、执行检查卡 |

三条不变的红线（全场景通用，任何话术不得越过）：

1. **同意先于采集**——破冰成功 ≠ 可以录音；录音前必须过 §3 同意话术（[提纲 §1](西安访谈提纲.md)、[07 伦理](../../田野方法/07-伦理.md)）。
2. **不诱导**——话术是用来「接得住」的，不是替对方说的；禁语清单见 §4.6。
3. **19:00 后不做一对一访谈；连续拒 5 次停手**（[计划 §2](西安五日计划.md) 时段纪律）。

## 1. 接触单元总流程（十步 + 四个闸门）

一次街头接触的标准流。每一步只做一件事，做不完就停在闸门处换目标，不纠缠。

| 步 | 动作 | 通过 → | 未过 → |
|---|---|---|---|
| 1 | 进点十分钟观察（[06 §2](06-观察与记录指引.md) 任务卡），选定目标 | 目标有「松弛窗口」（等待、休息、闲坐） | 全场都在忙 → 换时段再来 |
| 2 | 对角色（[10 §1](10-采访执行细案.md) 角色卡：主目标/备选/禁访） | 目标在主目标层 | 只有备选可聊 → 降级预期，不硬凑 |
| 3 | 破冰（§2 场景话术） | 对方抬头、回话、有追问 | 无回应 → **G1：换目标，同一人不二试** |
| 4 | 试温（§2 接线句：「能耽误您几分钟吗」） | 「你说」「行啊」 | 犹豫 → 给退路再试一次，仍犹豫 → **G2：体面退场** |
| 5 | 自述身份 30 秒（§3.1） | 对方听完有回应 | 打断/皱眉 → 简短重述一次 |
| 6 | 同意三态（§3.2）+ 录音操作 | 录音同意 → 当面开录、报日期场景 | 拒录音 → 纯聊笔记；全拒 → **G3：谢退** |
| 7 | 四问主体（[提纲](西安访谈提纲.md) 四问，口语化见 §4.1） | 对方在讲自己的话 | 跑题/冷场 → §4.5、§5-C |
| 8 | 控场与救场（§4 + §5 应变编号） | 到档位收口点自然收口（见下方时间预算） | 情绪/失控 → §5-D |
| 9 | 收束三件套（§6） | 对方平静离开 | — |
| 10 | 当场登记 RefId + quicknote（[06 §5](06-观察与记录指引.md)），**音频当天入库** | — | — |

**时间预算**：破冰到同意 ≤3 分钟；主体按[09 场景配套表](09-路线与访谈备选.md)的定盘档位执行——档一标准档 39–46 分钟（档四/档五为其变体，时长同基准、硬收束纪律照练），写字楼档二裁剪档 25 分钟，档三两问纯化档 15–20 分钟为快筛备档；收束 ≤2 分钟。到收口点而对方兴致仍高 → 约回访（§5-B4），不当场拖场。

**进点前装备自检**：手机满电 + 充电宝；录音界面预打开；纸笔；打印件（同意卡 + [计划 §9.2](西安五日计划.md) 材料清单）；小额零钱（早市「先买后问」用）。

## 2. 破冰话术库

### 2.1 通用三式（所有场景的母版）

| 式 | 原理 | 台词模板 |
|---|---|---|
| 求教式 | 低姿态请教最不设防：人人都愿意教外行 | 「师傅，跟您请教个事儿——这个……该咋弄？」 |
| 借景式 | 从对方眼前正在做的事起话，零破绽 | 「您这（菜挑的/手艺/鸟/棋）弄得真地道，这有啥讲究？」 |
| 自嘲式 | 暴露自己的「外乡/外行」，给对方教育位置 | 「我头一回来这片儿，看您像老西安，想跟您聊聊。」 |

破冰三原则：**问题要小**（对方一句话能答）；**姿态要低**（请教，不是审查）；**不憋身份**（第二句就接 §3 自述，不养鱼——先聊十分钟再说来意，对方会有被套路感）。

### 2.2 分场景破冰

| 场景 | 首选台词 | 次选 | 禁忌 |
|---|---|---|---|
| 公园 | 「大爷，您这鞭子/剑抡得真有年头了吧？」（借景） | 「这唱的是秦腔哪一折？我就听个热闹。」（求教；暖场弹药见 [05 §7](05-西安城市读本.md)） | 别拿「您多大岁数」开头；别在合唱/棋局中途打断 |
| 早市/菜市场 | **先买后问**：买份小东西，交易即破冰。「老板，这咋挑？」 | 「您这摊儿摆了几年啦？」 | 别砍狠价再聊（站到对立面）；别问成本利润开头 |
| 作坊 | 站着看活儿两分钟，赞一处**具体**细节：「这个榫咬得真严丝合缝。」 | 「您做这个多少年了？」（「年头」问题在这里是合法的） | 不摸货；别拿「卖多少钱」开头（像砍价的） |
| 城中村 | 小卖部买东西起话最稳。坐着的长者：「师傅，跟您聊聊，这片儿挺有年头了吧？」 | 「这楼是哪年盖的？比周围看着老多了。」 | **第二句必带澄清**：「我是做研究的，不是拆迁办的」；不进院子、不拍照 |
| 写字楼 | 大堂外/楼下咖啡排队：「您好，打扰一下，我在做个城市生活调研，就两个问题。」 | 电梯口等电梯时的天气/楼层闲话（只求眼神交流） | 不进办公区；不装快递外卖；不借工牌名义 |
| 高校 | 社团招新摊：「同学，你们这是招新？都啥社团？」（天然合法话题） | 食堂外围：「同学，打扰一下，做个课程调研，两个问题。」 | 不进宿舍区自习区；对方看着像高中生 → 跳过（本轮不访未成年） |
| 机动（骑手等） | 取餐间隙：「师傅，等餐呢？今儿单子多吗？」 | 「您这车跑一天得换几块电池？」 | 对方在骑行/搬货中不搭话；一开始就声明「就问两句」 |

## 3. 自述身份与同意话术

### 3.1 自述 30 秒台本（四要素：我是谁 · 在做什么 · 为何问您 · 数据怎么用）

完整版（公园、早市、作坊、城中村用）：

> 「是这样——我自己是研究 AI 的，这次来西安，就想听听普通人平时用不用 AI、用它干啥；另外也想听听大家这一辈子经历的事。就当聊天，您不想答的随时跳过。我不写您名字，录音就自己整理用，不外传不上网。您看行吗？」

短版（写字楼、机动等时间紧的场景，15 秒）：

> 「我做个城市生活的小调研，匿名，不拍照不上网，就俩问题，耽误您两分钟。」

素材预写与「熟而不油」排练见 [08 §1–§3](08-访谈员自我准备.md)。

### 3.2 同意三态

| 态 | 台词 | 后续 |
|---|---|---|
| 同意录音 | 「我拿手机录个音，就自己回头整理用。咱开始。」 | 当面开录，口播日期+场景（入库对齐） |
| 只笔记 | 「行，那咱纯聊，我笔记记，您说慢点儿。」 | 全程笔记，当晚补 quicknote（[06 §5](06-观察与记录指引.md)） |
| 全拒 | 「好嘞，那不打扰您了，谢谢您！」 | 走人，不二试；RefId 不建 |

> 本表三态只管**录音档位**；[计划 §5.1](西安五日计划.md) 的三类同意（录音 / 肖像 / 发表）仍须**逐项问、逐项记**——肖像与发表不在本表内，默认不拍不发，需要时另行单独开口并单独记。

### 3.3 身份追问应对

| 对方问 | 台词 |
|---|---|
| 「你们是记者吧？」 | 「不是记者，不上电视不上网，就是做研究的，想听真话。」 |
| 「搞推销的吧？」 | 「我啥也不卖，您看我连个单子都没有。就是想听您聊聊。」 |
| 「查户口的？」 | 「哈哈，比查户口还轻——就聊您愿意聊的，不想答的咱跳过。」 |
| 要求看证明 | 递打印件：「这是我研究计划的一页，您过目。」（[计划 §9.2](西安五日计划.md)） |

## 4. 访谈中控场

### 4.1 四问的口语化开场（原文见[提纲](西安访谈提纲.md)，这里给开口变体）

| 问 | 口语化第一句 |
|---|---|
| ① AI 现在帮到你啥 | 「您平时手机上使不使那些 AI 的玩意儿？比如问它个事儿、让它写个啥、带娃认个字？」 |
| ② 希望 AI 帮啥 | 「要是这玩意儿真能帮上您的忙，您最想让它帮您干点啥？」 |
| ③ 遗憾 | 「咱聊点别的——您这一路走过来，有没有哪个事儿，现在想起来还觉得『当时要是那样就好了』？」 |
| ④ 人生故事 | 「您有没有哪段经历，平时没机会跟人细讲，今天愿意跟我聊聊的？」 |

人生线的完整降敏感度顺序、研究者先自我暴露，照[提纲 §5](西安访谈提纲.md)执行，本文不重复。

### 4.2 三板斧（对方话头浅时的三个接法）

| 斧 | 台词/动作 |
|---|---|
| 沉默 3 秒 | 不接话，点头、身体前倾——多数人会自己往下补 |
| 复述 | 「『老惦记着』——您的意思是现在还会想这事？」 |
| 具体化 | 「能给我讲讲那天具体是咋回事吗？从头说。」 |

### 4.3 追问库（12 条，按需取用，不连珠炮）

| 台词 | 用途 |
|---|---|
| 「那后来呢？」 | 推进叙事 |
| 「那在这之前呢？」 | 往前挖起点 |
| 「为啥是它，不是别的？」 | 决策点 |
| 「那时候您多大？家里啥态度？」 | 年代与关系锚点 |
| 「您身边人都咋说？」 | 他人视角、传播链（AI 两问码族 2 的素材） |
| 「第一次用它是啥时候？谁教您的？」 | 使用起点 |
| 「现在还用吗？多久一回？」 | 使用现状 |
| 「要没它，您这事儿会咋办？」 | 替代与冗余（码族 6 的素材） |
| 「这儿头您掏过钱没？划算不？」 | 付费与信任 |
| 「还有呢？」 | 最便宜的追问，说三次都不过分 |
| 「您给我讲三件，挑要紧的讲。」 | 数字邀请，破「不知道说啥」 |
| 「用您的话说，这是个啥东西？」 | 要原语（新码登记的码名来源，[07 §2](07-分析计划.md)） |

### 4.4 过渡与拉回

| 情境 | 台词 |
|---|---|
| 换话题 | 「咱换个话题，聊点别的。」 |
| 跑题拉回 | 「您刚说的那个（X）我记下了，回头细聊——咱回到刚才那个事儿。」 |
| 对方问「你到底想知道啥」 | 「我不预设答案，您咋想我咋记。您就按自己的话讲。」 |

### 4.5 让对方多说

复述 + 停顿 > 追问；「还有呢？」优于新问题；对方讲长段时不打断，笔记上画钩标记想追问的点，段落收口再回头问。

### 4.6 禁语清单（诱导红线，触发即 §5-E1 自我纠正）

- 「是不是觉得……」／「很多人都觉得……对吧？」——把答案塞嘴里
- 「您肯定也……」——替对方表态
- 「这说明……对吧？」——抢着下结论
- 主动报数据/新闻再问对方感受（先资料后知识是 [05 §1](05-西安城市读本.md) 的纪律）

## 5. 应变手册（现场救场总表）

编号供 §7 速查卡引用。每条给：信号 → 台词 → 退出口径。**所有条目的兜底动作都一样：体面退场比多聊十分钟重要。**

### A. 拒访类

| # | 信号 | 台词 | 退出口径 |
|---|---|---|---|
| A1 | 礼貌拒绝：「没空/不清楚」 | 「谢谢您！打扰了。」 | 立退，点头微笑 |
| A2 | 烦躁/不抬眼 | （不说话，退） | 立退，不解释——解释即纠缠 |
| A3 | 犹豫：「说这个干啥呀……」 | 「不聊也没事，我就在边上，您忙您的。」（30 秒后再试温一次） | 仍犹豫 → G2 退场 |
| A4 | 要好处：「采访给钱不？」 | 「不好意思，我们不花钱采访，就想听您聊聊。」 | 对方坚持 → 退场（本轮一律不付费） |
| A5 | 连续 5 人拒访 | — | 停手，换场景/换时段（[计划 §2](西安五日计划.md) 纪律），记方法码拒访 |

### B. 信任类

| # | 信号 | 台词 | 退出口径 |
|---|---|---|---|
| B1 | 「你是不是骗子/传销/拆迁的？」 | §3.3 对应句 + 递打印件 | 对方仍疑 → 退，不掏证件对峙 |
| B2 | 「录音干啥？要发网上吧？」 | 「不上网不外传，就我自己整理。您要不放心，咱纯聊我笔记记。」 | 仍拒 → 只笔记；再拒 → G3 |
| B3 | 「你说完给我看看写啥了。」 | 「整理好我想请您过目。」（记入回访，[09 档八](09-路线与访谈备选.md) 追访二段） | 当场答应的必须记入日志，否则不承诺 |
| B4 | 要联系方式 / 「下回还来不？」 | 留专用联系方式（研究号，非私人号），记入 participant 记录 | — |
| B5 | 反问「你天天用 AI 吗？你说说」 | 「我也用，也翻车，所以才想听您的——您说说看？」（一句真实短答即拉回） | 对方只对我感兴趣不聊自己 → 顺势收短，不强求 |

### C. 现场失控类

| # | 信号 | 台词 | 退出口径 |
|---|---|---|---|
| C1 | 围观起哄、多人插话 | 「咱俩换个清净地儿说？」（移一步即可） | 移不动 → 收短成 3 分钟版或结束 |
| C2 | 多人抢话 | 挑一人为主线：「您先说，旁位的咱回头也聊。」 | 其他人补充可用，但**记「多人在场」**——迎合风险升，方法码标注 |
| C3 | 冷场超过 10 秒 | 三板斧（§4.2）；借景重启：「您刚说这店，开多久了？」 | 两轮救不回 → 提前收束（§6） |
| C4 | 滔滔跑题 | §4.4 借力拉回，最多拉三次 | 拉不回 → 顺着跑题内容里捞 AI/人生素材，捞完收束 |
| C5 | 访谈中电话/有人叫走 | 「您先接，我等等。」 | 超 2 分钟无回流意愿 → 就地收束 |
| C6 | 方言听不懂 | 「额耳朵笨，您慢点儿说。」改用更「普通话」的表达 | 实在接不住 → 换目标（记一句环境笔记） |

### D. 伦理类

| # | 信号 | 台词 | 退出口径 |
|---|---|---|---|
| D1 | 滑向敏感话题（政治细节、拆迁纠葛、家庭矛盾） | 不接不追：「咱说回您自己的事儿。」 | 对方非要讲 → 只听不记细节，[07 §7](07-分析计划.md) 拒写清单比对 |
| D2 | 哭 | 「咱先停一下，您缓缓。喝口水？」**不追问细节** | 「今天到这儿也挺好，改天想聊了咱再聊。」平静后再问一句要不要继续 |
| D3 | 愤怒/冲我发火 | 「是我不该提这个，不好意思。」 | 立退，不辩解；当晚 reflexive memo 必写 |
| D4 | 求助（借钱/找工作/办事） | 「这个我真帮不上。但您说的这些，对我特别有用。」 | 不承诺任何回报；若对方因无回报终止 → 尊重 |
| D5 | 明显醉酒/状态异常 | （不启动访谈；已在访谈中则提前收束）「您先歇着，咱们改天。」 | 立退 |
| D6 | 未成年人凑过来想聊 | 「等你爸妈在的时候咱再聊，行不？」 | 本轮不访未成年（[README §3](README.md) 纪律） |

### E. 自身失误类

| # | 信号 | 台词 | 退出口径 |
|---|---|---|---|
| E1 | 自己说漏：报了数据/替对方下了结论 | 「刚才我说多了——您别跟着我说，您按自己想的讲。」 | 当晚 reflexive memo 记一笔（[08 §2](08-访谈员自我准备.md) 自检） |
| E2 | 对方明显迎合（看我脸色说话） | 「您按真实感受说，好赖我都想听。」 | 拆不掉 → 记方法码「迎合」，分析时降权（[07 §2](07-分析计划.md)） |
| E3 | 自己疲惫、麻木、走神 | — | 按情绪预算降级：减一场、回住处写日志（[08 §4](08-访谈员自我准备.md)）——硬撑出的访谈是坏数据 |

## 6. 收束与离场

三件套台词（完整脚本见[提纲](西安访谈提纲.md)收束节，这里给口语版）：

1. **复述确认**：「您刚说的我记的是——（一两句概括）。对吧？」
2. **开放补充**：「还有啥想说的没？这会儿想到的都算数。」
3. **感谢 + 去向**：「太谢谢您了！我整理好了想给您看看。您慢忙。」

两种收束：**到点收**（到收口点，借「我约了人」体面收口——比「我问完了」自然）；**情绪收**（触发 D2/D3，直接跳第三句，立退）。**「开放补充」一步必问拒写清单**：「写出来的东西，有没有哪段您不想让它被写进去？现在说都算数。」——当场速记，当晚写入该访谈备注留痕（[计划 §5.4](西安五日计划.md)），发表整理时逐条比对（[07 §7](07-分析计划.md)）。收束后**当场**登记 RefId、标注场景与档位，音频当天入库——「未入库音频不过夜」（[计划 §6](西安五日计划.md)）。

## 8. 自媒体 / 公开发布边界专条

本轮定位是**研究访谈**：借自媒体街采的手艺（话术、控场、救场），不借它的做法（先拍后问、隐蔽拍摄、剪出冲突）。

1. **研究同意 ≠ 发布同意**。§3 的同意只覆盖「录音整理做研究」；任何视频、图文、音频片段的公开发布，需要**另一次明确同意**（口头可以，当场记入 participant 记录）。
2. **默认不拍脸、不露声**。录音仅研究用；若未来发布，声音变声、画面打码、按 [07 §7](07-分析计划.md) 拒写清单逐条比对，组合可识别的再加一层模糊。
3. **偷拍 = 隐蔽采集 = [行动总纲](../行动总纲.md)红线**，任何情况下不做。对不同意发布的人，内容永不公开。
4. 若确有做内容的打算：建议**田野结束后**用 [07 §6](07-分析计划.md) 个案剪影的模糊化文本改写，不用原声原脸；发布前设法给对方过目（回访渠道，§5-B3/B4）。
