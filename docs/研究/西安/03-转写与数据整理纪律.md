# 03 转写与数据整理纪律

> 版本 V1.0 · 2026-10 · 隶属[西安田野文档套件](README.md)
> 定位：补管线缺环。[计划 §6](西安五日计划.md) 到「音频确认入库」为止，[07 §1](07-分析计划.md) 从「主题编码」开始——中间的**录音 → 文本**这一步此前没有纪律条文，本文补上。返程后执行，不占田野时间。全部【操作性建议】。

---

## 0. 为什么这一步需要专门纪律

1. **声纹是敏感个人信息**（PIPL：声纹属生物识别信息）——转写工具的处理方式直接决定合规边界。
2. 同意话术承诺了「录音就自己整理用，不外传不上网」（[11 §3.1](11-街头采访SOP与话术手册.md)）——**把音频上传云端转写 = 向第三方提供**，超出承诺范围；除非对方明确同意，不做。
3. 转写文本是新的泄露面：原始转写含真名、门牌、电话的概率不低——脱敏必须先于编码。

---

## 1. 默认本地转写

| 项 | 口径 |
|---|---|
| 默认方式 | 本地转写（笔记本本地运行的工具），结果不出机 |
| 云端转写 | 仅当对方**单独明确同意**「把录音传到网上由机器转文字」方可使用；默认不问、不用 |
| 话术补丁（确需云转写时） | 收束时加一句：「整理要用机器帮忙转文字，会把录音传到网上去，行不行？」——同意记入 participant 记录 |
| 无工具可用 | 人工听写，按 §2 转写深度分级执行 |

**转写深度分级**（不做全量逐字——性价比与泄露面都不允许）：

| 深度 | 范围 | 用途 |
|---|---|---|
| 摘要级 | 全部访谈：每 2–3 分钟一段的对话摘要 + 关键原话逐字 | 编码底稿（[07 §2](07-分析计划.md)） |
| 逐字级 | 拟成案例的 3 条 + 引语候选段落 | 案例包（[计划 §1.2](西安五日计划.md)）与发表材料 |

量级估计：12 条摘要级 ≈ 每条 45–60 分钟 ≈ 9–12h；3 条逐字级 ≈ 每条 3–4h ≈ 9–12h——合计约两个整工作日，返程 72h 清单里给它留两个整块半天。

## 2. 转写 SOP（返程 72h 内启动）

1. **一条录音一个文件**，文件名用 RefId（如 `OF-YYYYMMDD-XAN-001.md`），正文首行挂 RefId + 笔名 + 访谈日期——与引用链对齐（[07 §7](07-分析计划.md)）。
2. **抽听校验**：每条至少回放 2 处与原音比对；听不清标 `【听不清 mm:ss】`，不猜词——猜出来的「原话」会污染编码。
3. **敏感级等同录音**：转写文本只存本地加密盘，U 盘备份同规则（[计划 §7.2](西安五日计划.md)）；不进 git、不进云盘、不走微信传文件。
4. **原始转写（未脱敏）留存本地加密目录** `raw/`；脱敏后的工作副本才能进分析目录。
5. **耗时记账**：每条转写耗时记入 Q2 链路卡点清单——转写是全链路最耗时的环节，这个数本身是 P2 产品线的需求证据（[计划 §6.3](西安五日计划.md)）。

---

## 3. 脱敏规则（进分析目录之前）

| 类别 | 处理 |
|---|---|
| 受访者真名 | 替换为笔名（P-001…）；真名→笔名对照只存加密库 `participant_identity`（[计划 §5.3](西安五日计划.md)），转写文件内不留对照表 |
| 提及的他人真名 | 一律「化名 X」+ 关系标注（「我工友化名 X」） |
| 门牌/店名/单位名 | 类型化：「南郊某城中村巷口小卖部」级 |
| 电话/微信号/车牌 | 打码或删除 |
| 地名 | 到区级；城中村不写村名（与[07 §6](07-分析计划.md) 场景模糊化同口径） |
| 组合可识别细节 | 「国棉厂 + 1962 年生 + 钳工」式组合 → 再泛化一层（[07 §7](07-分析计划.md)） |

> **脱敏删的是可识别信息，不是「土味」**：方言与原语全保留——码名要的就是原语（[07 §2.4](07-分析计划.md)），把「额们」改成「我们」是过度脱敏。

---

## 4. 与引用链的关系

- **引用以录音为准**：RefId 指向录音与时间戳，不是转写文本；引语签发前对照原音——转写错误不能污染引用（[07 §7](07-分析计划.md)）。
- **脱敏文本只是工作稿**：编码、memo、报告初稿在脱敏稿上做；对外发表的引语再过一遍拒写清单与同意门禁（[计划 §5.4](西安五日计划.md)、[使用手册 §3.4](../../工程/使用手册.md)）。
- 云端转写若经对方同意使用了：该音频的第三方披露事实记入 participant 记录，发表边界评估时单独交代。
