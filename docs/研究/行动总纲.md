## 1. 定位：这是什么行动

表面是"AI 咨询 + 田野调查"，本质是一场用真实场景验证认知、用咨询换资源、用内容建 IP、用案例找工作的多支柱行动。

### 1.1 核心资产盘点

| 资产 | 内容 | 价值 |
| --- | --- | --- |
| 职业背景 | 前阿里 SRE，10 年经验 | 技术信任背书 |
| 技术能力 | AI Agent 开发、自动化工作流 | 可现场交付 Demo |
| 认知优势 | SRE 系统思维 + 对"人"的关注 | 区别于纯技术人员的差异化壁垒 |
| 行动资本 | 时间、体力、真名出镜的勇气 | 项目启动的唯一燃料 |
| 硬约束 | 高度近视（900 度），用眼负荷有限 | 风控设计的一等输入，见第 8 节 |

### 1.2 为什么是"咨询"而不是"卖 Agent"

| 维度 | 卖 Agent | 做 AI 咨询 |
| --- | --- | --- |
| 交易标的 | 标准化产品 | 定制化认知 + 解决方案 |
| 客户感知 | "又一个卖工具的" | "一个懂我业务的专家" |
| 定价权 | 被比价、被压价 | 按价值定价，可换资源 / 人脉 / 认知 |
| 复购逻辑 | 功能用完即止 | 信任建立后持续合作 |
| 能力匹配度 | 低（不是销售） | 高（SRE 诊断思维天然适配咨询） |

核心洞察：SRE 擅长"诊断系统瓶颈"，AI 咨询的本质是"诊断业务流程瓶颈 + 给出 AI 解法"。不是卖东西，是用专业能力换对方的真实场景和反馈。

## 2. 战略判断：跑不通的概率

| 目标定义 | 跑通概率 | 备注 |
| --- | --- | --- |
| 靠帮餐饮小店做 AI 代运营赚钱 | ~10% | 付费意愿极低，逆水行舟 |
| 靠 AI 咨询换单 / 换资源 / 换认知 | ~70% | 咨询门槛低，易建立信任 |
| 靠田野调查找到更好的 AI 工作 | ~99% | 几乎必然跑通 |
| 靠内容建起个人 IP | ~80% | 真名 + 纪实 = 稀缺性 |

### 2.1 为什么放弃餐饮下沉市场

- 餐饮个体户连基础 SaaS 都不愿用，更别提按月付费的 AI Agent；
- AI 产业当前悖论：底层技术供给过剩，应用层商业化严重滞后；
- 用高维能力去打低维市场的价格战，性价比极低。

### 2.2 为什么转向 IT 公司 / 企业拜访

- 企业缺的不是写代码的人，而是"懂 AI 又懂行业"的复合型落地人才；
- 拜访 IT 公司不是卖服务，而是"拿他们当活体简历"；
- 深圳市场支撑：AI 岗位求人倍率 2.67，AI 算法 / 研发年薪 20-40 万+；
- 面试降维打击：别人拿 PPT，你拿"走访 50 家企业、3 个致命卡点、Agent 解决方案"的一手报告。

### 2.3 "咨询换单"交易结构

| 交换对象 | 我提供 | 我获得 | 适用场景 |
| --- | --- | --- | --- |
| IT 公司创始人 | 15 分钟 AI 诊断 + 简易 Demo | 行业痛点情报 + 人脉转介绍 | 暂无预算 / 名额 |
| SaaS 公司高管 | 业务流程 AI 化建议 | 产品合作 / 内推机会 | 业务互补 |
| 传统企业转型负责人 | AI 落地路径规划 | 付费咨询 / 长期顾问关系 | 有明确转型需求 |
| 同行 / 竞品 | 技术交流 + 认知碰撞 | 行业信息差 + 潜在合作 | 双方都是从业者 |

原则：咨询不是免费白嫖，也不是强买强卖——"我用专业换你的真实场景，双方都有所得"。

| 收益层 | 来源 | 变现周期 |
| --- | --- | --- |
| AI 咨询收入 | 企业拜访 + 咨询换单 | 即时 ~ 3 个月 |

## 4. 品牌与频道

### 4.1 定案

| 要素 | 内容 | 理由 |
| --- | --- | --- |
| 频道名 | 曹亚仑（仑） | "仑" = 条理 / 次序，暗合 SRE 系统思维，辨识度高 |
| Slogan | AI 田野调查，让技术回到人性 | "田野调查"定义方法论，"回到人性"定义价值观 |
| 头像 | 本人清晰正面照 | 强化"人"的存在感，不用 logo / 插画 |
| 简介标签 | 前阿里 SRE｜AI 落地咨询｜深圳田野实录｜每周更新 | 快速建立专业信任，突出"咨询"而非"卖工具" |

### 4.2 命名三大理由

1. 零解释成本：人设即品牌，名字就是护城河；
2. 信任感：AI 赛道概念泡沫泛滥，真名是稀缺的诚意——"我为自己的内容负责"；
3. Slogan 双重锚定：既是对观众的承诺，也是每次创作的校准器。

### 4.3 启用前必做 ⚠️

- 全网查重名（B 站 / 抖音 / 视频号 / 小红书 / 公众号），重点排查同名科技 / AI 账号；
- 有重名 → 加后缀："曹亚仑AI" 或 "曹亚仑田野"；无重名 → 直接全平台注册锁定。

### 4.4 内容产出规范

- 风格：纪实 Vlog，保留被拒绝的尴尬、老板皱眉的真实瞬间；
- 更新频率：每周更新；
- 内核：不是炫技，是"让技术回到人性"的真实故事。

## 5. 执行 SOP

### 5.1 核心 KPI

- 触达量：每天有效沟通 10 家企业 / 门店；
- 转化量：收集 3 个真实痛点，完成 1 次免费咨询交付，争取 1 次付费 / 资源置换；
- 内容量：产出 1 条高质量纪实视频素材；
- 认知量：每晚复盘提炼 1 条可复用的行业洞察。

### 5.2 每日时间表

| 时间 | 动作 | 要点 |
| --- | --- | --- |
| 09:00-10:00 | 访前准备 | 地图热力图选区、设备自检、商务休闲装 + 工牌 |
| 10:30-11:30 | 上午陌拜 | 避开饭点，黄金 30 秒破冰 |
| 12:00-14:00 | 午间复盘 | 信息录入、素材筛选 |
| 15:00-17:30 | 下午实战 | 带 Demo 回访、促成微交易 |
| 19:00-22:00 | 晚间复盘 | 数据总结、剪辑 Vlog、认知冥想 15 分钟 |

### 5.3 破冰话术

**IT 公司版（主力）**：

> "X 总您好，我是前阿里的 SRE，现在在做 AI 落地咨询。我正在做一个关于'AI 如何切入真实企业工作流'的田野调查。能不能占用您 15 分钟，我向您请教几个业务痛点，顺便演示一下我搭的自动化工作流？我不卖东西，纯技术交流，也可以帮您做个免费的 AI 诊断。"

关键设计："不卖东西"之后接"免费的 AI 诊断"——为咨询换单埋钩子。

**餐饮版（备用）**：

> "老板您好，打扰一分钟。我是做 AI 技术调研的，正在收集实体店的经营痛点。想请教下您平时最头疼的琐事是什么？不用买东西，纯交流。"

**体面退场（被拒时）**：

> "没关系，完全理解，那我不打扰您了，祝您生意兴隆。"

绝不纠缠，绝不反问。

### 5.4 咨询交付 SOP

| 步骤 | 动作 | 时长 | 产出 |
| --- | --- | --- | --- |
| 1 | 倾听痛点，记录关键词 | 5 min | 痛点清单 |
| 2 | 用 SRE 思维诊断瓶颈 | 5 min | 瓶颈归因 |
| 3 | 给出 1-2 个 AI 解法（不求完美） | 5 min | 简易方案 / Demo |
| 4 | 明确下一步（付费 / 资源置换 / 保持联系） | 2 min | 行动承诺 |
| 5 | 离场后立即记录 | 3 min | 结构化笔记 |

### 5.5 咨询边界风控

| 风险 | 应对 |
| --- | --- |
| 期望过高，要求免费做完整个项目 | 明确边界："今天只做诊断，落地实施另行约定" |
| 只想白嫖，无回馈意愿 | 礼貌结束，标记"低价值客户"，不再跟进 |
| 咨询中暴露知识盲区 | 坦诚告知，承诺补充研究并反馈——真诚本身是信任资产 |

## 6. 扫楼作战路径

核心认知：扫楼是最笨的办法，也是最精准的办法。扫完南山科技园，就拥有深圳最精准的 AI 人脉数据库。

### 6.1 精准选区

- 区域：南山科技园、宝安中心区、福田天安数码城；
- 楼宇：入住率高、与 AI Agent 方向契合的产业园；
- 企业：SaaS 服务商、AI 应用初创、传统企业数字化转型部门；
- 三条线分头扫：AI Agent 类 / SaaS 类 / 传统转型类；
- 备用灰度区（餐饮版话术适用）：龙华 / 宝安城中村餐饮街、南山 / 福田老旧写字楼小微企业。

### 6.2 突破守门人（前台 / 保安）

| 策略 | 话术 |
| --- | --- |
| 业务合作式 | "我是 XX 公司的技术顾问，带了一份 AI 自动化工作流方案，给负责人参考一下，2 分钟就好。" |
| 同行背书式 | "楼上 XX 公司一直在用我们这套 AI 方案，效果不错，过来给负责人也送份资料。" |
| 应聘式（最实用） | "我来找技术部 / HR 负责人沟通合作事宜，麻烦帮忙通报一下。" |

时间窗口：上午 10-11 点 / 下午 3-4 点（避开早会、午休、饭点）。

### 6.3 黄金 30 秒开场

- 痛点狙击型："我了解到咱们行业很多同行都在愁数据流转和人工重复劳动的问题，我搭了一套自动化 Agent，过来简单聊聊。"
- 价值前置型："我们最近帮几家同类企业用 AI 重构了客服 / 排班流程，效率提升了 30%，过来看看有没有能帮上忙的地方。"
- 咨询钩子型："我可以花 10 分钟帮您做个免费的 AI 诊断，看看哪些环节能用 AI 提效，不满意随时打断。"

### 6.4 沟通挖需求（70/30 法则）

- 70% 时间让对方说，30% 时间自己说；
- 开放式提问："您目前业务扩张最看重哪些效率瓶颈？""找 AI 解决方案遇到的最大问题是什么？"
- 真诚不忽悠：解决不了的技术难点坦诚说，可帮忙对接开源社区。

### 6.5 收尾与跟进

- 明确下一步，绝不说模糊的"后续联系您"："我周四下午发您一份专属 AI 方案，周五电话沟通 15 分钟。"
- 即时记录：离开后立刻记录核心需求、技术痛点、关键联系人；
- 分层跟进节奏：当天加微信 → 第 1 天发行业案例 → 第 3 天分享 Demo → 第 7 天邀约深度交流。

### 6.6 陌拜收益模型（四种结果全正收益）

| 结果 | 收益 |
| --- | --- |
| 对方觉得你牛 | 当场 Offer / 引荐 / 付费咨询 |
| 没有名额 / 预算 | 行业情报 + 转介绍 + 咨询案例 |
| 对方很忙 | 通讯录多一个"深圳 IT 圈高管" |
| 被拒绝 | V1.0 的一条真实数据，不是失败 |

## 7. 内容战略

### 7.1 自媒体变现路径

| 方式 | 适配度 | 启动周期 |
| --- | --- | --- |
| 平台创作激励 / 流量分成 | ⭐⭐⭐⭐ | 1-2 个月 |
| 知识付费（专栏 / 课程） | ⭐⭐⭐⭐⭐ | 3-6 个月 |
| 咨询引流（视频即名片，私信转客户） | ⭐⭐⭐⭐⭐ | 即时 |
| 品牌合作 / 商单 | ⭐⭐⭐ | 6-12 个月 |
| 社群 / 会员制 | ⭐⭐⭐⭐ | 3-6 个月 |

关键认知：自媒体不是"教别人做 AI"，是"展示一个前阿里 SRE 如何用 AI 咨询在真实世界里活下来"。观众买的不是知识，是代入感和可能性。

### 7.2 红蓝海判断：行业研究内容化

结论：不做"科普号"，做"田野调查号"。

| 维度 | 传统行业科普 | 田野调查式 |
| --- | --- | --- |
| 信息来源 | 网络资料整合 + 情绪输出 | 亲自走访、现场观察、一手对话 |
| 视角 | 上帝视角 / 懂王姿态 | 参与者视角 / 学徒姿态 |
| 质感 | 精致但悬浮 | 粗糙但真实（保留被拒、尴尬、认知颠覆） |
| 信任建立 | 靠头衔 / 话术 | 靠"我真的去了、真的问了、真的被骂了" |
| 壁垒 | 低（谁都能抄） | 高（时间 + 体力 + 真名出镜的勇气不可复制） |

| 内容类型 | 判断 |
| --- | --- |
| "XX 行业商业逻辑科普" | 🔴 红海：信息过载，同质化严重 |
| "AI 如何赋能 XX 行业" | 🔴 红海：概念泛滥，缺乏实证 |
| "前阿里 SRE 实地走访 XX 行业，用 AI 做了一次真实实验" | 🔵 蓝海：一手数据 + 技术视角 + 人性洞察 + 真名背书 |
| "AI 田野调查系列纪实" | 🔵 蓝海：品类未定义，我们是开创者 |

### 7.3 选题范式（以"卖菜的"为例）

不做《菜市场商业模式分析》，做《我在深圳城中村菜摊蹲了 3 天，发现 AI 连一把葱都帮不上忙》：

1. 现场实录：凌晨进货、定价逻辑、熟客赊账；
2. SRE 式诊断：把菜摊当一个系统，画出输入 / 输出 / 瓶颈 / 冗余；
3. AI 介入实验：尝试用 AI 工具解决某个环节，记录失败过程；
4. 人性洞察：为什么摊主宁愿手写账本也不用 App？因为"信任不在系统里，在人脸上"；
5. 回归 Slogan："让技术回到人性"是蹲了 3 天后才懂的痛。

## 8. 风控与异常处理

### 8.1 情绪风控

| 触发条件 | 处理动作 |
| --- | --- |
| 连续被拒 5 次以上 | 立即停止陌拜，换地方吃饭或回住处休息半天，不硬扛 |
| 遇到态度恶劣的人 | 微笑点头立刻离开，不口角、不教育。你的时间比他的脾气贵 |

### 8.2 身体风控

| 触发条件 | 处理动作 |
| --- | --- |
| 视力模糊 / 头痛 / 眼睛干涩 | 立即终止当天计划，回住处戴框架眼镜休息 |

### 8.3 心理建设

- 每晚睡前 15 分钟"认知冥想"：不带手机，只关注呼吸，清理被拒产生的情绪垃圾，保持系统稳定；
- 被赶出来 = V1.0 的一条真实数据，不是失败。

### 8.4 财务与家庭风控

具体额度与期限为私人参数，不入公开仓库。机制本身必须公开遵守：

| 机制 | 规则 |
| --- | --- |
| 资金隔离 | 核心储备物理隔离、绝对不动；只以独立额度的"试错资金包"作战 |
| 硬止损线（Kill Switch） | 试错资金包设独立额度 + 三个月期限；到期若不能覆盖家庭固定开销底线，立即终止项目进入求职流程，绝不恋战 |
| 强制 Health Check | "每在外一个月，必须回家陪家人一周"写进 SOP——这是系统维护的硬性规定，不是商量 |
| 后方容灾 | 现金流失速、家庭情绪压力是项目级 P0 风险，优先级高于一切业务目标 |

### 8.5 灰度发布与砍伪需求

- 只做"离钱最近"的事：痛点不痛、明确不可能付钱的，立刻放弃。时间是最贵的服务器资源；
- 区域灰度：V1.0 深圳 / 广州（跑通 MVP）→ V2.0 华东 / 华中 → V3.0 华北 / 东北 / 西北。每个大区是一次版本迭代，状态异常随时"回滚"休整；
- 先跑通 V1.0 再谈全国：如果连深圳都赚不到第一个 1000 块、剪不出第一条破万播放的视频，全国的地图就是一张废纸。

## 10. 调研演进史（关键决策记录）

按时间正序沉淀本计划的六个关键转折，避免后续执行时忘记"当初为什么这么定"：

1. **路线收敛**：G318 川藏线徒步 → 全中国漫游 → 收敛为"区域灰度发布"（V1.0 珠三角起步）。收敛原因：单点故障太多——身体硬件、现金流、家庭容灾在宏大路线下全是 SPOF；
2. **冷酷架构评审**：用 SRE 视角自查出四大风险（身体硬件、无正向现金流、家庭容灾缺失、目标过度设计），由此产出 Kill Switch / 强制 Health Check / 区域灰度发布三项硬性机制；
3. **目标市场换道（最大转折）**：餐饮小店 AI 代运营（~10% 跑通）→ IT 公司精准拜访（~99% 跑通）。依据：下沉市场付费意愿 + AI 产业"技术供给过剩、应用商业化滞后"悖论 + 深圳岗位供需数据；
4. **商业模式定型**：卖 Agent → AI 咨询（咨询换单、换资源、换认知）；
5. **品牌修正**：频道名"曹亚伦" → "曹亚仑"（仑 = 条理次序）；简介从"独立开发"改为"AI 落地咨询"；
6. **收益结构扩容**：四位一体 → 五位一体（新增自媒体收入 + 行业研究内容化两条独立变现线）。

## 11. 与 OpenField 的关系

本总纲定义"做什么、去哪里、怎么换"；OpenField 定义"怎么采集、怎么存证、怎么沉淀"。行动对系统的核心需求映射：

| 行动需求 | OpenField 对应层 |
| --- | --- |
| 每日 10 家触达的痛点 / 原话 / 联系人记录 | L1 采集层 + L2 取证层（证据链） |
| "走访 50 家企业 → 3 个致命卡点"的报告资产 | L3 沉淀层（四维索引知识库） |
| 每晚复盘 + 每周 Vlog 的素材流水线 | L3 田野日志自动聚合 |
| 咨询交付的结构化笔记 | L4 分析层（AI 提案 → 人工确认） |
| 求职核武器《深圳 AI 企业落地痛点调研报告》 | L5 输出层（学术级交付） |
