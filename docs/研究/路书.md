## 四、每日 OpenField 工作流（独行闭环）

每天收工固定动作，顺序不可倒：

1. **当场**：录音（手机+备用设备双录）→ 拍照记录场景（征得同意）→ 纸质速记要点
2. **当晚住宿**：录音原件拷入笔记本 `inbox/` → `scanOnce` → 逐条 `confirm` 挂对应 encounter → 补写 memo（当晚 30 分钟内完成，过夜记忆衰减快）
3. **每晚锁盘**：`runVerify` 全绿 → `exportBackup` 生成 OFBK1 → 同时拷贝到两块 U 盘（一块随身、一块放包不同位置）
4. **真名纪律**：受访者真名只进 `participant_identity` 表，分析层一律 pseudonym（P01/P02…），口头承诺不落第二渠道

## 五、访谈提纲骨架（曹县电商/汉服，半结构化）

开场 3 分钟自我介绍（一句话版）：「我在做县域电商的调研，想请您聊聊平时怎么干活，大概 40 分钟，只录音不拍脸，资料匿名处理，随时可以停。」

- **角色定位**：入行几年、在链条哪一环（生产/批发/直播/物流）、淡旺季节奏
- **生意结构**：进货渠道、平台依赖（抖音/淘宝/1688）、一笔单的钱怎么分
- **人与家**：从哪来、为什么回县、家里人怎么分工、收入区间（区间法降低敏感度）
- **工具与数字化**：现在用什么软件记账/接单/剪片，最烦哪个环节 →（顺带观察 OpenField 类工具的真实需求面）
- **收尾**：还有什么我没问但您觉得重要的；能否引荐一位同行

## 六、风险与预案

| 风险 | 预案 |
|---|---|
| 夜车耗损，D1 状态差 | D1 只排踩点+建库，不排正式访谈 |
| 笔记本故障/丢失 | 手机录音全程兜底；U 盘每晚双备份保证至多损失当天；纸质速记记录要点 |
| 网络差 | 全流程离线可用（scanOnce/verify/备份均本地）；需要上传的环节一律返程做 |
| 拒访率高于预期 | 集市/园区自然场景切入；引荐人带 1 人后用滚雪球；单日目标降为 1 条也要保完整链路 |
| 身份被质疑 | 研究者身份一句话版+身份证配合出示；不承诺报酬、不夸大用途 |
| 受访者中途反悔 | 立即停录；数据按 PIPL 流程 purge（confirmToken 流程正好实战演练一次） |
| 逢集日错过 | 到县首日即问清楚下一个逢集日，D3 行程随之微调 |
