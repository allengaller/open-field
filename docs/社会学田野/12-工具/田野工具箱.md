### 2.2 访谈提纲模板

**半结构化访谈提纲**：
```
访谈对象：__________ 日期：__________ 地点：__________
访谈者：__________ 时长：__________

【开场】
- 自我介绍与研究说明
- 获得知情同意
- 建立关系

【背景信息】
1. 能简单介绍一下您自己吗？
2. 您在这个领域工作/生活多久了？

【核心问题】
3. [主题相关问题1]
   - 追问：能详细说说吗？
   - 追问：能举个例子吗？
4. [主题相关问题2]
   - 追问：那是什么意思？
   - 追问：您的感受如何？
5. [主题相关问题3]

【深入探索】
6. 能描述一下[关键事件]吗？
7. 这对您意味着什么？
8. 您如何看待[相关问题]？

【结束】
9. 还有什么想补充的吗？
10. 您有什么问题要问我吗？
- 感谢参与
- 说明后续联系
```

### 4.2 引语使用指南

**引语格式**：
```
短引语（<40字）：直接嵌入文本，用引号
例：如张三所说，"这是非常重要的"（访谈，2024年1月1日）。

长引语（≥40字）：独立段落，缩进，不用引号
例：
    这是非常重要的，因为它影响了我们的整个理解。我们需要
    重新思考这个问题，从不同的角度来看待它。（访谈，2024年
    1月1日）
```

**引语选择原则**：
- 代表性：选择代表性引语
- 准确性：准确引用
- 情境化：提供引语情境
- 分析性：分析引语意义
