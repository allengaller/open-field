# 经典民族志案例

> 田野调查与民族志研究的经典案例分析

## 1. 人类学经典案例

### 1.1 《西太平洋上的航海者》（马林诺夫斯基，1922）

**研究背景**：
- 研究者：布罗尼斯拉夫·马林诺夫斯基（Bronisław Malinowski）
- 研究地点：特罗布里恩群岛（Trobriand Islands）
- 研究时间：1915-1918年

**研究内容**：
- 库拉交换圈（Kula Ring）
- 特罗布里恩群岛的社会组织
- 经济、宗教、魔法

**方法论贡献**：
- 参与观察方法的奠基
- 长期田野调查
- 学习当地语言
- 从当地人的观点看

**理论贡献**：
- 功能主义理论
- 文化整体论
- 互惠交换理论

**影响**：
- 人类学田野调查的奠基之作
- 影响了后续所有民族志研究

**证据等级**：【通行共识】

**研究内容**：
- 努尔人的政治制度
- 无政府社会的秩序
- 亲属制度与年龄组制度

**方法论贡献**：
- 结构功能主义方法
- 政治人类学奠基
- 无文字社会研究

**理论贡献**：
- 结构功能主义
- 政治制度分析
- 社会秩序理论

**影响**：
- 政治人类学的经典
- 无政府社会研究的典范

**证据等级**：【通行共识】
