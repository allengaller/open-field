# 编码与主题分析

> 质性数据分析中的编码与主题分析方法

## 1. 编码的定义与类型

### 1.1 编码的定义

**编码（Coding）**是给数据段落赋予标签的过程，目的是识别概念、类别与模式。

**核心特征**：
- **系统性**：系统化的编码过程
- **迭代性**：编码是迭代的过程
- **解释性**：编码包含研究者的解释
- **理论性**：编码服务于理论建构

**证据等级**：【通行共识】

### 1.2 编码的类型

**描述性编码（Descriptive Coding）**：
- 描述数据内容
- 识别数据的主题
- 适用于初步分析

**过程编码（Process Coding）**：
- 描述行动与过程
- 使用动名词（-ing）
- 适用于过程研究

**情感编码（Emotion Coding）**：
- 描述情感与感受
- 识别情感表达
- 适用于情感研究

**价值编码（Values Coding）**：
- 描述价值观与信念
- 识别价值系统
- 适用于价值研究

**理论编码（Theoretical Coding）**：
- 连接理论与数据
- 识别理论概念
- 适用于理论建构

**证据等级**：【通行共识】

## 2. 编码的过程

### 2.1 初始编码（Initial Coding）

**定义**：
- 对数据进行初步编码
- 识别数据的初步概念
- 保持开放与灵活

**编码策略**：
- **逐行编码**：逐行分析数据
- **逐段编码**：按段落编码
- **整体编码**：整体理解后编码

**编码技巧**：
- 保持简单
- 使用行动词
- 保持开放
- 记录决策

**证据等级**：【通行共识】

### 2.2 聚焦编码（Focused Coding）

**定义**：
- 使用最重要的初始编码
- 对数据进行更聚焦的编码
- 发展类别与概念

**编码策略**：
- 选择最重要的编码
- 使用这些编码分析数据
- 发展类别与子类别

**证据等级**：【通行共识】

### 2.3 理论编码（Theoretical Coding）

**定义**：
- 连接类别与理论
- 发展理论概念
- 建构理论框架

**编码策略**：
- 识别核心类别
- 连接类别之间的关系
- 发展理论命题

**证据等级**：【通行共识】

## 3. 主题分析

### 3.1 主题分析的定义

**主题分析（Thematic Analysis）**是识别、分析、报告数据中的主题（themes）的方法。

**核心特征**：
- **灵活性**：适用于多种理论框架
- **系统性**：系统化的分析程序
- **解释性**：强调意义的解释
- **实用性**：易于学习与使用

**证据等级**：【通行共识】

### 3.2 主题分析的步骤

**Braun & Clarke (2006) 的六步骤**：

1. **熟悉数据（Familiarization）**：
   - 阅读数据
   - 做笔记
   - 标记关键段落

2. **生成初始编码（Generating Initial Codes）**：
   - 系统编码数据
   - 识别数据的特征
   - 组织编码

3. **搜索主题（Searching for Themes）**：
   - 将编码组织成主题
   - 识别模式与关系
   - 收集主题相关数据

4. **审查主题（Reviewing Themes）**：
   - 检查主题与数据的关系
   - 检查主题之间的关系
   - 修正与完善主题

5. **定义与命名主题（Defining and Naming Themes）**：
   - 明确主题内容
   - 命名主题
   - 撰写主题描述

6. **撰写报告（Producing the Report）**：
   - 呈现分析结果
   - 使用数据支持
   - 讨论理论意义

**证据等级**：【核验】

### 3.3 主题分析的类型

**归纳主题分析（Inductive Thematic Analysis）**：
- 从数据中归纳主题
- 不预设理论框架
- 适用于探索性研究

**演绎主题分析（Deductive Thematic Analysis）**：
- 基于理论框架分析
- 使用预设的编码方案
- 适用于验证性研究

**语义主题分析（Semantic Thematic Analysis）**：
- 分析数据的表面意义
- 关注数据的明确内容
- 适用于描述性研究

**潜在主题分析（Latent Thematic Analysis）**：
- 分析数据的深层意义
- 关注数据的隐含内容
- 适用于解释性研究

**证据等级**：【通行共识】

## 5. 编码与主题分析的质量

### 5.1 质量标准

**可信性（Credibility）**：
- 分析结果的可信度
- 策略：长期投入、三角验证、成员检查

**可转移性（Transferability）**：
- 分析结果的可转移性
- 策略：厚描、详细描述情境

**可靠性（Dependability）**：
- 分析过程的可靠性
- 策略：审计轨迹、详细记录

**可确认性（Confirmability）**：
- 分析结果的可确认性
- 策略：反身性、数据支持结论

**证据等级**：【通行共识】

### 5.2 质量提升策略

**三角验证**：
- 使用多种数据来源
- 使用多种分析方法
- 多个研究者独立分析

**成员检查**：
- 将分析结果反馈给研究对象
- 验证解释的准确性
- 修正分析结果

**审计轨迹**：
- 详细记录分析过程
- 记录分析决策
- 便于他人审查

## 6. 编码与主题分析的挑战与策略

### 6.1 常见挑战

**编码困难**：
- 难以识别概念
- 难以发展类别
- 策略：培训、实践、同行支持

**主题发展困难**：
- 难以识别主题
- 难以组织主题
- 策略：系统程序、持续比较、理论对话

**理论建构困难**：
- 难以从数据中建构理论
- 策略：理论抽样、理论饱和、理论对话

### 6.2 提高质量的策略

**培训与学习**：
- 分析方法培训
- 软件使用培训
- 方法论学习

**同行支持**：
- 同行讨论
- 分析小组
- 专家咨询

**持续反思**：
- 分析备忘录
- 反身性日记
- 定期反思
