# 质性数据分析总论

> 质性数据分析的理论、方法与实践

## 1. 质性数据分析的定义与特征

### 1.1 定义

**质性数据分析（Qualitative Data Analysis）**是对质性数据（文本、图像、音频、视频等）进行系统分析，以识别模式、主题、意义与理论的过程。

**核心特征**：
- **归纳性**：从数据中归纳出模式与理论
- **迭代性**：分析是迭代的过程，不断回到数据
- **解释性**：强调对意义的解释与理解
- **情境性**：关注数据的社会文化情境
- **反身性**：研究者对自身分析过程的反思

**证据等级**：【通行共识】

### 1.2 质性数据分析与定量数据分析的区别

| 维度 | 质性数据分析 | 定量数据分析 |
|------|------------|------------|
| 数据类型 | 文本、图像、音频 | 数值、统计 |
| 分析目的 | 理解意义、建构理论 | 检验假设、预测 |
| 分析过程 | 归纳、迭代 | 演绎、线性 |
| 结果呈现 | 主题、模式、理论 | 统计量、模型 |
| 质量标准 | 可信性、可转移性 | 信度、效度 |

## 2. 质性数据分析的主要方法

### 2.1 主题分析（Thematic Analysis）

**定义**：
- 识别、分析、报告数据中的主题（themes）的方法
- 最常用、最灵活的质性分析方法

**步骤**（Braun & Clarke, 2006）：
1. **熟悉数据**：阅读数据、做笔记
2. **生成初始编码**：系统编码数据
3. **搜索主题**：将编码组织成主题
4. **审查主题**：检查主题与数据的关系
5. **定义与命名主题**：明确主题内容
6. **撰写报告**：呈现分析结果

**类型**：
- **归纳主题分析**：从数据中归纳主题
- **演绎主题分析**：基于理论框架分析
- **语义主题分析**：分析表面意义
- **潜在主题分析**：分析深层意义

**证据等级**：【通行共识】

### 2.2 扎根理论分析（Grounded Theory Analysis）

**定义**：
- 从数据中系统建构理论的方法
- 强调理论从数据中"涌现"

**编码过程**：
1. **开放编码（Open Coding）**：
   - 逐行分析数据
   - 识别概念与类别
   - 赋予标签

2. **主轴编码（Axial Coding）**：
   - 连接类别与子类别
   - 识别因果关系、情境、策略

3. **选择性编码（Selective Coding）**：
   - 识别核心类别
   - 整合理论

**核心策略**：
- **持续比较（Constant Comparison）**：持续比较数据与数据、数据与类别
- **理论抽样（Theoretical Sampling）**：根据理论需要选择数据
- **理论饱和（Theoretical Saturation）**：新数据不再产生新理论

**证据等级**：【通行共识】

### 2.3 话语分析（Discourse Analysis）

**定义**：
- 分析语言的使用与意义建构
- 关注话语如何建构现实、身份、权力关系

**类型**：
- **批判话语分析（Critical Discourse Analysis）**：分析话语中的权力与意识形态
- **会话分析（Conversation Analysis）**：分析日常对话的结构
- **叙事分析（Narrative Analysis）**：分析故事的结构与意义

**分析维度**：
- 词汇选择
- 语法结构
- 话语策略
- 权力关系
- 意识形态

**证据等级**：【通行共识】

### 2.4 叙事分析（Narrative Analysis）

**定义**：
- 分析故事的结构、内容、意义
- 关注叙事如何建构身份与经验

**分析维度**：
- **结构分析**：故事的结构（开头、中间、结尾）
- **内容分析**：故事的主题与意义
- **功能分析**：故事的功能与效果
- **表演分析**：故事的叙述方式

**类型**：
- **结构叙事分析**：分析叙事结构
- **主题叙事分析**：分析叙事主题
- **对话/表演叙事分析**：分析叙事的对话性与表演性

**证据等级**：【通行共识】

### 2.5 现象学分析（Phenomenological Analysis）

**定义**：
- 分析意识经验的本质结构
- 关注意义如何被经验

**类型**：
- **描述现象学**：描述经验的本质
- **解释现象学**：解释经验的意义

**步骤**：
1. **现象学还原**：悬置预设
2. **描述**：描述经验
3. **本质还原**：识别本质结构
4. **意义建构**：理解意义

**证据等级**：【通行共识】

### 2.6 内容分析（Content Analysis）

**定义**：
- 系统分析文本内容的方法
- 可以是质性或定量的

**质性内容分析**：
- 归纳内容分析：从数据中归纳类别
- 演绎内容分析：基于理论框架分析

**步骤**：
1. 确定分析单位
2. 开发编码方案
3. 编码数据
4. 分析结果

## 3. 质性数据分析的过程

### 3.1 数据准备

**数据整理**：
- 转录访谈录音
- 整理田野笔记
- 组织文档与图像
- 数据匿名化

**数据管理**：
- 建立数据档案
- 数据备份
- 数据安全存储

### 3.2 数据熟悉

**阅读数据**：
- 多次阅读数据
- 做初步笔记
- 标记关键段落

**写备忘录**：
- 记录初步想法
- 记录问题与困惑
- 记录理论思考

### 3.3 编码

**编码（Coding）**：
- 给数据段落赋予标签
- 识别概念与类别

**编码类型**：
- **描述性编码**：描述数据内容
- **过程编码**：描述行动与过程
- **情感编码**：描述情感与感受
- **价值编码**：描述价值观与信念
- **理论编码**：连接理论与数据

**编码策略**：
- **逐行编码**：逐行分析数据
- **段落编码**：按段落编码
- **聚焦编码**：聚焦特定主题

### 3.4 主题发展

**识别主题**：
- 将编码组织成主题
- 识别模式与关系

**主题审查**：
- 检查主题与数据的关系
- 检查主题之间的关系
- 修正与完善主题

**主题定义**：
- 明确主题内容
- 命名主题
- 撰写主题描述

### 3.5 理论建构

**概念发展**：
- 从主题发展概念
- 建立概念之间的关系

**理论整合**：
- 整合概念与理论
- 建构解释框架

**理论验证**：
- 检查理论与数据的关系
- 寻找反面案例
- 修正理论

## 5. 质性数据分析的质量

### 5.1 质量标准

**可信性（Credibility）**：
- 分析结果的可信度
- 策略：长期投入、三角验证、成员检查

**可转移性（Transferability）**：
- 分析结果的可转移性
- 策略：厚描、详细描述情境

**可靠性（Dependability）**：
- 分析过程的可靠性
- 策略：审计轨迹、详细记录

**可确认性（Confirmability）**：
- 分析结果的可确认性
- 策略：反身性、数据支持结论

**证据等级**：【通行共识】

### 5.2 三角验证

**数据三角验证**：
- 使用多种数据来源
- 访谈、观察、文档

**方法三角验证**：
- 使用多种研究方法
- 质性、定量、混合

**研究者三角验证**：
- 多个研究者独立分析
- 比较分析结果

**理论三角验证**：
- 使用多种理论视角
- 比较不同解释

### 5.3 成员检查

**成员检查（Member Checking）**：
- 将分析结果反馈给研究对象
- 验证解释的准确性

**方式**：
- 反馈访谈转录
- 反馈分析结果
- 反馈最终报告

**注意事项**：
- 研究对象可能不同意
- 需要解释研究目的
- 尊重研究对象的意见

### 5.4 审计轨迹

**审计轨迹（Audit Trail）**：
- 详细记录分析过程
- 便于他人审查与验证

**记录内容**：
- 数据收集过程
- 分析决策
- 编码方案
- 理论发展

## 6. 质性数据分析的挑战与策略

### 6.1 常见挑战

**数据过载**：
- 数据量太大，难以处理
- 策略：抽样策略、聚焦分析

**分析主观性**：
- 分析受研究者影响
- 策略：反身性、同行汇报、审计轨迹

**理论建构困难**：
- 难以从数据中建构理论
- 策略：持续比较、理论抽样、理论饱和

**软件使用困难**：
- CAQDAS软件学习曲线陡峭
- 策略：培训、实践、技术支持

### 6.2 提高分析质量的策略

**培训与学习**：
- 分析方法培训
- 软件使用培训
- 方法论学习

**同行支持**：
- 同行讨论
- 分析小组
- 专家咨询

**持续反思**：
- 分析备忘录
- 反身性日记
- 定期反思
