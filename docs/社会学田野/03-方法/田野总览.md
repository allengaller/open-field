# 田野调查总论

> 田野调查的定义、历史、类型与方法论基础

## 1. 田野调查的定义

### 1.1 核心定义

**田野调查（Fieldwork）**是研究者在自然情境中，通过长期参与观察、深度访谈等方法，收集第一手资料，理解社会现象与文化意义的研究方法。

**核心特征**：
- **自然情境**：在自然发生的社会情境中进行
- **长期投入**：通常需要数月甚至数年的田野工作
- **参与性**：研究者参与研究对象的日常生活
- **整体性**：追求对社会现象的整体性理解
- **反身性**：研究者对自身位置的持续反思

**证据等级**：【通行共识】

### 1.2 田野调查与相关概念

**田野调查 vs 民族志**：
- 田野调查：强调研究过程与方法
- 民族志：强调研究产出与写作
- 关系：田野调查是民族志的方法，民族志是田野调查的产出

**田野调查 vs 质性研究**：
- 田野调查：质性研究的一种方法
- 质性研究：更广泛的研究取向
- 关系：田野调查是质性研究的重要方法

**田野调查 vs 实地研究**：
- 田野调查：人类学与社会学的传统术语
- 实地研究：更广泛的社会科学术语
- 关系：两者高度重叠

## 2. 田野调查的历史发展

### 2.1 前史：早期探索（19世纪）

**殖民语境下的民族志**：
- 欧洲殖民者对非欧洲文化的描述
- 传教士、旅行者、殖民官员的记录
- 特点：疏离的外来者视角

**早期社会调查**：
- 英国：查尔斯·布斯（Charles Booth）的伦敦贫困调查
- 美国：社会改革运动中的社会调查
- 特点：社会改良导向

**证据等级**：【通行共识】

### 2.2 奠基：马林诺夫斯基与参与观察（1922）

**马林诺夫斯基的贡献**：
- 《西太平洋上的航海者》（1922）
- 参与观察方法的奠基
- 长期田野调查
- 学习当地语言
- 从当地人的观点看

**方法论革命**：
- 从书斋到田野
- 从疏离到参与
- 从客观到反身

**证据等级**：【通行共识】

### 2.3 发展：芝加哥学派（1920s-1930s）

**芝加哥学派的贡献**：
- 城市民族志
- 社区研究
- 符号互动论

**代表人物**：
- 罗伯特·帕克（Robert Park）
- 欧内斯特·伯吉斯（Ernest Burgess）
- 威廉·怀特（William Foote Whyte）

**经典研究**：
- 《街角社会》（怀特，1943）
- 《城市》（帕克等，1925）

**证据等级**：【通行共识】

### 2.4 当代发展（1960s-至今）

**反思性转向**：
- 承认研究者主观性
- 强调反身性
- 实验性写作

**数字转向**：
- 数字民族志
- 网络民族志
- 平台研究

**全球转向**：
- 多点民族志
- 全球民族志
- 跨国研究

**证据等级**：【通行共识】

## 3. 田野调查的类型

### 3.1 按学科分类

**人类学田野调查**：
- 强调文化理解
- 长期田野调查
- 参与观察为主

**社会学田野调查**：
- 强调社会结构
- 社区研究
- 多种方法结合

**民俗学田野调查**：
- 强调民俗文化
- 口头传统
- 仪式与节庆

**证据等级**：【通行共识】

### 3.2 按场域分类

**农村田野调查**：
- 农村社区研究
- 农民生活研究
- 农村变迁研究

**城市田野调查**：
- 城市社区研究
- 城市亚文化研究
- 城市问题研究

**组织田野调查**：
- 企业组织研究
- 政府机构研究
- 非营利组织研究

**数字田野调查**：
- 在线社区研究
- 社交媒体研究
- 虚拟世界研究

**证据等级**：【通行共识】

### 3.3 按方法分类

**参与观察**：
- 研究者参与研究对象的日常生活
- 同时进行观察与记录

**深度访谈**：
- 与研究对象进行深入对话
- 探索意义与经验

**焦点小组**：
- 组织群体讨论
- 探索群体观点

**混合方法**：
- 结合多种方法
- 三角验证

**证据等级**：【通行共识】
