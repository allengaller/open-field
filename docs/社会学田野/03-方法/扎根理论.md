# 扎根理论

> 扎根理论的理论、方法与实践

## 1. 扎根理论的定义与特征

### 1.1 定义

**扎根理论（Grounded Theory）**是一种从数据中系统建构理论的研究方法，强调理论从数据中"涌现"，而非从既有理论演绎。

**核心特征**：
- **归纳性**：从数据中归纳理论
- **系统性**：系统化的分析程序
- **迭代性**：数据收集与分析的迭代
- **理论性**：旨在建构理论
- **情境性**：理论根植于具体情境

**证据等级**：【通行共识】

### 1.2 扎根理论的历史发展

**创始（1967）**：
- **格拉斯（Barney Glaser）与斯特劳斯（Anselm Strauss）**
- 《扎根理论的发现》（*The Discovery of Grounded Theory*）
- 挑战当时的研究范式

**发展（1980s-1990s）**：
- **斯特劳斯与科尔宾（Juliet Corbin）**：程序化扎根理论
- **格拉斯**：经典扎根理论
- **查马兹（Kathy Charmaz）**：建构主义扎根理论

**当代发展（2000s-至今）**：
- 批判扎根理论
- 后现代扎根理论
- 数字扎根理论

**证据等级**：【通行共识】

## 2. 扎根理论的主要流派

### 2.1 经典扎根理论（Glaserian）

**代表人物**：巴尼·格拉斯（Barney Glaser）

**核心主张**：
- 理论从数据中自然涌现
- 研究者保持理论敏感性
- 避免先入为主的理论框架
- 强调持续比较

**方法特点**：
- 开放编码
- 理论编码
- 持续比较
- 理论抽样

**证据等级**：【通行共识】

### 2.2 程序化扎根理论（Straussian）

**代表人物**：安塞尔姆·斯特劳斯（Anselm Strauss）与朱丽叶·科尔宾（Juliet Corbin）

**核心主张**：
- 系统化的分析程序
- 三级编码：开放编码、主轴编码、选择性编码
- 使用分析工具（条件矩阵、范式模型）

**方法特点**：
- 开放编码（Open Coding）
- 主轴编码（Axial Coding）
- 选择性编码（Selective Coding）
- 条件矩阵（Conditional Matrix）

**证据等级**：【通行共识】

### 2.3 建构主义扎根理论（Constructivist）

**代表人物**：凯西·查马兹（Kathy Charmaz）

**核心主张**：
- 理论是研究者与研究对象共同建构的
- 强调研究者的反身性
- 关注意义建构过程
- 强调情境与关系

**方法特点**：
- 初始编码（Initial Coding）
- 聚焦编码（Focused Coding）
- 理论编码（Theoretical Coding）
- 反身性备忘录

**证据等级**：【通行共识】

## 3. 扎根理论的核心概念

### 3.1 持续比较（Constant Comparison）

**定义**：
- 持续比较数据与数据、数据与类别、类别与类别
- 扎根理论的核心分析策略

**比较类型**：
- 数据与数据的比较
- 数据与类别的比较
- 类别与类别的比较
- 类别与理论的比较

**证据等级**：【通行共识】

### 3.2 理论抽样（Theoretical Sampling）

**定义**：
- 根据理论需要选择数据
- 而非随机抽样或代表性抽样

**抽样策略**：
- 最大化差异：选择差异最大的案例
- 最小化差异：选择相似的案例
- 理论驱动：根据理论需要选择

**证据等级**：【通行共识】

### 3.3 理论饱和（Theoretical Saturation）

**定义**：
- 新数据不再产生新理论
- 类别与理论已经充分发展

**判断标准**：
- 新数据不再产生新编码
- 类别之间的关系已经明确
- 理论已经充分发展

**证据等级**：【通行共识】

### 3.4 理论敏感性（Theoretical Sensitivity）

**定义**：
- 研究者对数据的理论意义的敏感性
- 识别数据中的理论线索

**培养方法**：
- 文献阅读
- 理论思考
- 分析经验
- 反身性

**证据等级**：【通行共识】

## 4. 扎根理论的分析程序

### 4.1 开放编码（Open Coding）

**定义**：
- 逐行分析数据
- 识别概念与类别
- 赋予标签

**编码策略**：
- 逐行编码：逐行分析数据
- 逐段编码：按段落编码
- 整体编码：整体理解后编码

**编码类型**：
- 描述性编码：描述数据内容
- 过程编码：描述行动与过程
- 情感编码：描述情感与感受
- 价值编码：描述价值观与信念

**证据等级**：【通行共识】

### 4.2 主轴编码（Axial Coding）

**定义**：
- 连接类别与子类别
- 识别因果关系、情境、策略

**分析工具**：
- **范式模型（Paradigm Model）**：
  - 因果条件（Causal Conditions）
  - 现象（Phenomenon）
  - 情境（Context）
  - 中介条件（Intervening Conditions）
  - 行动/互动策略（Action/Interaction Strategies）
  - 结果（Consequences）

- **条件矩阵（Conditional Matrix）**：
  - 分析行动的条件
  - 理解行动的情境
  - 识别行动的结果

**证据等级**：【通行共识】

### 4.3 选择性编码（Selective Coding）

**定义**：
- 识别核心类别
- 整合理论
- 建构故事线

**核心类别**：
- 能够整合所有其他类别的类别
- 理论的核心概念
- 故事线的核心

**理论整合**：
- 连接核心类别与其他类别
- 建构理论框架
- 发展理论命题

**证据等级**：【通行共识】

## 7. 扎根理论的挑战与策略

### 7.1 常见挑战

**理论建构困难**：
- 难以从数据中建构理论
- 策略：持续比较、理论抽样、理论饱和

**分析主观性**：
- 分析受研究者影响
- 策略：反身性、同行汇报、审计轨迹

**数据过载**：
- 数据量太大，难以处理
- 策略：抽样策略、聚焦分析、软件辅助

**理论整合困难**：
- 难以整合类别与理论
- 策略：核心类别识别、理论模型建构

### 7.2 提高质量的策略
