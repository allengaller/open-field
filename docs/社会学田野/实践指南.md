# 知识库实践应用指南

> 如何将田野调查与社会学研究知识库应用于实际研究项目

## 1. 研究设计阶段的应用

### 1.1 确定研究问题

**使用知识库**：
- 查阅 [01-基础/社会学理论.md](01-基础/社会学理论.md) 了解相关理论
- 查阅 [02-理论/](02-理论/) 选择适合的理论框架
- 查阅 [11-案例/](11-案例/) 了解类似研究案例

**实践步骤**：
1. **文献回顾**：
   - 使用 [13-阅读/经典书目.md](13-阅读/经典书目.md) 找到相关经典著作
   - 使用 [13-阅读/journals.md](13-阅读/journals.md) 找到相关期刊文章
   - 使用 [14-术语/术语.md](14-术语/术语.md) 理解关键术语

2. **理论选择**：
   - 根据研究问题选择理论框架
   - 参考 [01-基础/社会学理论.md](01-基础/社会学理论.md) 第5节"理论选择指南"
   - 考虑理论组合策略

3. **研究问题明确化**：
   - 使用 [12-工具/田野工具箱.md](12-工具/田野工具箱.md) 中的"研究问题模板"
   - 参考 [11-案例/](11-案例/) 中的案例研究问题

**示例**：
```
研究主题：外卖骑手的劳动过程
理论框架：劳动过程理论 + 平台经济理论
参考案例：《工厂女孩》（潘毅，2005）
研究问题：
1. 外卖骑手的劳动过程如何被平台算法塑造？
2. 骑手如何抵抗或适应算法管理？
3. 平台劳动对骑手身份认同的影响是什么？
```

   - 使用 [12-工具/田野工具箱.md](12-工具/田野工具箱.md) 中的模板
   - 参考 [03-方法/参与观察.md](03-方法/参与观察.md) 设计观察方案
   - 参考 [03-方法/深度访谈.md](03-方法/深度访谈.md) 设计访谈方案

3. **伦理设计**：
   - 查阅 [07-伦理/概述.md](07-伦理/概述.md)
   - 使用 [12-工具/田野工具箱.md](12-工具/田野工具箱.md) 中的伦理审查清单
   - 准备知情同意书

**示例**：
```
研究方法：参与观察 + 深度访谈 + 数字民族志
- 参与观察：跟随骑手送餐，观察劳动过程
- 深度访谈：访谈20名骑手，了解劳动体验
- 数字民族志：观察骑手在社交媒体上的互动

伦理考虑：
- 获得骑手知情同意
- 保护骑手隐私
- 避免影响骑手工作
```

```
编码过程：

   - 算法管理 → 时间压力 → 收入不稳定
3. 选择性编码：识别核心类别
   - 平台劳动的算法控制

主题发展：
- 主题1：算法管理与劳动控制
- 主题2：骑手的抵抗策略
- 主题3：平台劳动的身份认同

理论建构：
- 平台劳动的算法控制理论
- 骑手抵抗的能动性理论
```
