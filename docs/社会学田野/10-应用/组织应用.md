# 组织与管理研究

> 田野调查在组织与管理研究中的应用

## 1. 组织民族志

### 1.1 定义与特征

**组织民族志（Organizational Ethnography）**是将民族志方法应用于组织研究的方法，研究组织文化、组织实践、组织变迁。

**核心特征**：
- 长期田野调查
- 深入组织内部
- 理解组织文化
- 关注组织实践

**证据等级**：【通行共识】

### 1.2 经典案例

**《工厂女孩》（潘毅，2005）**：
- 深圳工厂的民族志
- 女工的日常生活
- 工厂制度与劳动

**《坏血》（卡雷鲁，2018）**：
- Theranos公司的调查
- 硅谷文化
- 组织欺诈

**《工作场所》（霍克希尔德，1997）**：
- 航空公司乘务员的情感劳动
- 情感管理
- 服务工作的情感维度

## 2. 组织文化研究

### 2.1 组织文化的定义

**组织文化（Organizational Culture）**：
- 组织共享的价值观、信念、规范
- 组织成员的行为模式
- 组织的象征与仪式

**证据等级**：【通行共识】

### 2.2 组织文化研究方法

**参与观察**：
- 观察组织日常实践
- 参与组织活动
- 理解组织文化

**深度访谈**：
- 访谈组织成员
- 理解组织价值观
- 探索组织文化

**文档分析**：
- 分析组织文档
- 理解组织历史
- 探索组织象征

### 2.3 组织文化类型

**强文化 vs 弱文化**：
- 强文化：共享价值观强
- 弱文化：共享价值观弱

**创新文化 vs 保守文化**：
- 创新文化：鼓励创新
- 保守文化：强调稳定

**等级文化 vs 平等文化**：
- 等级文化：强调等级
- 平等文化：强调平等

## 3. 组织变迁研究

### 3.1 组织变迁的定义

**组织变迁（Organizational Change）**：
- 组织的结构、文化、实践的变化
- 组织适应环境的过程

**证据等级**：【通行共识】

### 3.2 组织变迁研究方法

**纵向研究**：
- 长期追踪组织变迁
- 理解变迁过程
- 识别变迁机制

**案例研究**：
- 深入研究单个组织
- 理解变迁的复杂性
- 探索变迁的多样性

**比较研究**：
- 比较不同组织的变迁
- 识别变迁模式
- 理解变迁条件

### 3.3 组织变迁的挑战

**抵抗变迁**：
- 组织成员的抵抗
- 文化惯性
- 利益冲突

**变迁管理**：
- 变迁策略
- 变迁实施
- 变迁评估
