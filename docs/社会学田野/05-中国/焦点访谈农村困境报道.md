# 《焦点访谈》农村困境报道

> 央视《焦点访谈》自 1994 年开播以来涉及农村困境的经典报道索引：农民负担与税费、农业政策与产业困境、农民工权益、土地与城镇化四大主题约二十余期代表节目，及其作为田野研究素材的使用方法。

## 1. 栏目定位与研究价值

**节目简况**：

- 《焦点访谈》1994 年 4 月 1 日在央视综合频道黄金时段开播，是中国电视舆论监督类栏目的标志
- 1994 年 4 月 3 日播出《北京郊区：耕地上建起一座坟茔》，被普遍视为该栏目第一期舆论监督节目，选题正是农村耕地保护
- 三十年间农村议题贯穿栏目史：1990 年代的农民负担，2000 年代的农民工权益，2010 年代的土地流转与城镇化冲突

**对田野研究的价值**：

- 入田野前的背景研究与选题线索：报道提供了村庄困境的典型场景、人物与时间线
- 历史对照基线：同一主题（税费、征地、讨薪）跨越不同年代的报道构成可比对的纵向资料
- 敏感话题的访谈引子：以节目内容为共同参照，可降低受访者谈论切身经历的防御

**证据等级**：【核验】（开播日期与第一期舆论监督节目经多源交叉确认）

## 2. 农民负担与税费问题（1998–2012）

### 2.1 《重负下的村庄》（2000）

- 地点：安徽省太和县郑庄村
- 内容：记录农民面对名目繁多的乱收费、乱摊派，一年收入一半以上被各种税费收走；"种地不赚钱"导致大量土地抛荒
- 影响：农村困境报道的代表作，播出后成为推动农村税费改革的标志性舆论事件
- **证据等级**：【通行共识】

### 2.2 《吹牛"上"了税》（1998）

- 内容：揭露基层虚报产量、按虚数征税，农民被迫为"吹出来的数字"交税
- **证据等级**：【通行共识】

### 2.3 《补贴到手 斧锯出手》（1998）

- 内容：国家发放的农业补贴到手后，随即被各种收费"砍"走
- **证据等级**：【通行共识】

### 2.4 《"减负"必须动真格》

- 内容：持续追踪农民负担反弹与减负政策在基层的落实
- **证据等级**：【通行共识】

### 2.5 《巨额粮款化为水》

- 内容：农民卖粮款被截留挪用；曾获国家级新闻奖项
- **证据等级**：【通行共识】

### 2.6 《收棉怎能付存单》

- 内容：农民卖棉花拿不到现金，只收到存单
- **证据等级**：【通行共识】

### 2.7 《"白条"还要打多久》

- 内容：农产品收购"打白条"、长期拖欠农民款项
- **证据等级**：【通行共识】

### 2.8 《七年一笔糊涂帐》

- 内容：村级财务多年不公开、账目混乱，村民无从监督
- **证据等级**：【通行共识】

### 2.9 《免费农网改造 凭啥农民买单》（2011–2012）

- 内容：国家本应免费进行的农村电网改造，费用被转嫁到农民头上
- **证据等级**：【通行共识】

## 3. 农业政策与产业困境（2000–2014）

### 3.1 《铲苗种烟 违法伤农》（2000）

- 内容：地方政府为完成烟草种植指标，强迫农民铲掉已种好的粮食作物改种烟草
- **证据等级**：【通行共识】

### 3.2 《如此改种要不得》（2001）

- 地点：海南省琼中县
- 内容：县政府违背农民意愿盲目引导改种，导致农产品大量积压、农民损失惨重；播出后引起中央领导高度重视
- **证据等级**：【通行共识】

### 3.3 《神秘的"农业园"》（2010）

- 内容：以"农业园"名义圈占耕地，变相进行房地产开发
- **证据等级**：【通行共识】

### 3.4 《农田里的白色污染》（2013）

- 内容：农村地膜大量残留，造成严重的土壤污染
- **证据等级**：【通行共识】

### 3.5 《扶不起来的梨苗》（2014）

- 内容：农业产业扶贫中盲目推广种植，农民投入后血本无归
- **证据等级**：【通行共识】

### 3.6 《难圆绿色梦》

- 内容：农村生态治理中的困境与反复；曾获国家级新闻奖项
- **证据等级**：【通行共识】

## 4. 农民工权益与人身自由（2007–2013）

### 4.1 《黄河边上的黑砖窑》（2007）

- 地点：山西省洪洞、临汾等地
- 内容：揭露黑砖窑非法拘禁、奴役农民工（包括未成年人与智障者）的行径
- 影响：引发全国震动，国务院随后派出联合工作组彻查
- **证据等级**：【通行共识】

### 4.2 《黑砖窑何以泛滥》（2007）

- 内容：对黑砖窑事件的深度追踪，追问监管缺失与制度漏洞
- **证据等级**：【通行共识】

### 4.3 《讨薪的遭遇》（2013）

- 内容：记录农民工讨薪过程中遭遇的推诿、阻挠和暴力
- **证据等级**：【通行共识】

## 5. 土地与城镇化中的农民权益（1994–2017）

### 5.1 《北京郊区：耕地上建起一座坟茔》（1994-04-03）

- 地点：北京顺义
- 内容：揭露毁坏耕地建陵园出售牟利
- 定位：《焦点访谈》历史上第一期舆论监督节目
- **证据等级**：【通行共识】

### 5.2 《谁动了这里的基本农田》（2007）

- 地点：云南省曲靖
- 内容：在没有用地手续的情况下占用耕地建设
- **证据等级**：【通行共识】

### 5.3 《茅台镇上的强迁之痛》（2011–2012）

- 内容：农村强制拆迁中农民的权益受损
- **证据等级**：【通行共识】

### 5.4 《公益林怎么姓了"私"？》（2015–2017）

- 内容：农村公益林被侵占，农民权益被剥夺
- **证据等级**：【通行共识】

### 5.5 《"农转城"变"假转城"》（2015–2017）

- 内容：一些地方为完成城镇化指标，强迫农民"被上楼""被转户"；农民失去土地却未获得真正的城市保障
- **证据等级**：【通行共识】

## 6. 田野应用：把报道档案变成研究素材

### 6.1 三类用法

- 背景研究：进入田野前通读目标地区相关报道，列出当地的时间线、关键人物与冲突类型，形成访谈提纲的背景假设
- 历史对照：同一主题（税费、征地、讨薪）的报道按年代排列，与田野中收集的口述互相校对时间与叙事
- 访谈引子：对敏感经历，可先谈"电视里那期节目"再过渡到受访者自身，用共同参照降低防御

### 6.2 证据边界与三角验证

- 媒体报道是线索而不是结论：节目画面经过编辑选择，播出版本可能与当事人记忆和田野观察不一致，关键事实必须回到田野一手材料核验
- 注意报道的选择性与议程：舆论监督节目本身有选题偏好，"没有被报道的村庄"同样是研究对象
- 交叉核对：报道、地方志、统计年鉴与受访者口述多源比对，无法互证的表述按孤证标记

### 6.3 入库与引用

- 将节目截图、文字稿或自撰摘录作为 doc 类采集物导入资料库，经哈希封存后以引用 ID 精确引用到某一期、某一段表述
- 引用媒体素材注明节目名、播出机构、播出年份与检索日期；对年份或标题存疑的节目，先复核再入库

### 6.4 检索途径与文献

- 央视网与央视频节目库按节目名称检索；早期节目官方视频多已下架，可检索节目图文页
- 《焦点访谈里的焦点》系列丛书收录历年代表性节目文稿，可作为纸面底本
- 视频平台上的网友存档可作为线索，但真伪与完整性需自行鉴别，引用一律以官方版本为准
- 提示：本清单按公开资料整理主题归类，个别节目标题、年份在不同来源间存在出入，引用前请逐条复核
