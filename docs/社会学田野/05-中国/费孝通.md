# 费孝通与江村经济

> 费孝通的生平、学术贡献与《江村经济》研究

## 1. 费孝通的生平

### 1.1 早年经历（1910-1935）

**出生与教育**：
- 1910年11月2日，江苏吴江人
- 1928年入东吴大学医预科
- 1930年转入燕京大学社会学系
- 1933年燕京大学社会学系毕业

**研究生阶段**：
- 1933年入清华大学研究院
- 师从俄国人类学家史禄国（S. M. Shirokogoroff）
- 1935年清华大学研究院毕业

**证据等级**：【通行共识】

### 1.2 留学英国（1936-1938）

**伦敦政治经济学院（LSE）**：
- 1936年入LSE
- 师从马林诺夫斯基（Bronisław Malinowski）
- 1938年获博士学位
- 博士论文即《江村经济》

**证据等级**：【核验】

### 1.3 回国任教（1938-1949）

**云南大学**：
- 1938-1945年，云南大学社会学系教授
- 主持云南大学社会学研究室
- 开展云南农村调查

**西南联大**：
- 1945-1949年，清华大学社会学系教授
- 兼任西南联大教授

**证据等级**：【通行共识】

### 1.4 建国后（1949-1979）

**中央民族学院**：
- 1952年院系调整后，任中央民族学院教授
- 参与民族识别工作
- 1957年被划为右派
- 文革期间受迫害

**证据等级**：【通行共识】

### 1.5 晚年（1979-2005）

**学术重建**：
- 1979年社会学重建
- 任中国社会科学院社会学研究所所长
- 任北京大学社会学系教授
- 提出"文化自觉"

**逝世**：
- 2005年4月24日逝世，享年95岁

**证据等级**：【通行共识】

## 2. 《江村经济》研究

### 2.1 研究背景

**研究地点**：
- 江苏吴江开弦弓村（江村）
- 费孝通的家乡附近

**研究时间**：
- 1936年7-8月
- 费孝通利用暑假回乡调查

**研究动机**：
- 理解中国农村的经济结构
- 探索中国农村的现代化道路
- 回应马林诺夫斯基的理论问题

**证据等级**：【核验】

### 2.2 研究内容

**经济结构**：
- 土地制度
- 农业生产
- 家庭手工业（蚕丝业）
- 市场体系

**社会组织**：
- 家庭制度
- 亲属关系
- 村落组织
- 地方治理

**文化变迁**：
- 传统与现代的冲突

**证据等级**：【核验】

**功能主义分析**：

## 5. 费孝通的学术思想

**定义**：
- 中国社会的关系结构
- 以自我为中心，像水波纹一样推及出去
- 与西方社会的"团体格局"相对

**理论意义**：
- 理解中国社会的结构特征
- 分析中国社会的运作逻辑
- 探索中国社会的变迁机制

**证据等级**：【核验】

- 对文化的反思与批判
- 对文化的传承与创新

- 探索文化的变迁
- 促进文化的对话

**证据等级**：【通行共识】
