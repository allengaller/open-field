# 田野调查与社会学研究知识库

> 一个面向深度研究者的完整中文知识库，涵盖田野调查与社会学研究的理论、方法、历史、实践与前沿。
> 
> 构建日期：2026-09-12

## 知识库定位

本知识库旨在为研究者提供：

1. **理论深度**：从经典社会学到当代理论前沿的完整谱系
2. **方法广度**：从传统田野方法到数字民族志的全方法覆盖
3. **历史脉络**：学科发展的历史纵深与范式变迁
4. **中国视角**：中国田野调查传统与本土实践
5. **实践工具**：可直接复用的模板、清单与案例分析

## 核心特色

- **证据分级**：所有内容标注证据等级（【核验】/【通行共识】/【操作性建议】）
- **中英对照**：关键术语提供中英对照与学术溯源
- **跨学科整合**：社会学、人类学、传播学、STS、计算社会科学的交叉视野
- **数字前沿**：涵盖数字民族志、计算社会科学、平台研究等新兴领域

### 快速入门路径
1. **新手研究者**：01 → 03 → 07 → 12（基础理论 → 方法 → 伦理 → 工具）
2. **进阶研究者**：02 → 04 → 08 → 09（理论流派 → 学派 → 分析 → 写作）

### 证据等级说明
- **【核验】**：经过多源检索与对抗式核验确认的事实
- **【通行共识】**：教科书级背景常识，引用前请复核原书
- **【操作性建议】**：方法论文献通行做法的实践建议
