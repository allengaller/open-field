# 网络民族志（Netnography）

> 网络民族志的理论、方法与实践

## 1. 网络民族志的定义与特征

### 1.1 定义

**网络民族志（Netnography）**是由罗伯特·科齐内茨（Robert V. Kozinets）提出的研究方法，特指在线社区的民族志研究，强调在线社区的文化与互动。

**核心特征**：
- **在线场域**：研究发生在线上环境
- **社区文化**：关注在线社区的文化
- **参与观察**：研究者在在线社区中的参与观察
- **多模态数据**：文本、图像、视频等多种数据形式
- **反身性**：研究者对自身在线实践的反思

**证据等级**：【通行共识】

### 1.2 网络民族志与相关概念

**网络民族志 vs 数字民族志**：
- 网络民族志：特指在线社区的民族志
- 数字民族志：更广义的数字环境民族志
- 关系：网络民族志是数字民族志的一种

**网络民族志 vs 虚拟民族志**：
- 网络民族志：强调在线社区的文化
- 虚拟民族志：强调虚拟与现实的边界
- 关系：两者高度重叠

**证据等级**：【通行共识】

## 7. 网络民族志的挑战与策略

### 7.1 方法论挑战

**场域边界**：
- 在线场域的边界模糊
- 线上线下的连续性
- 策略：多地点民族志、线上线下整合

**数据规模**：
- 大规模数据的处理
- 数据过载
- 策略：抽样策略、计算方法辅助

**研究者角色**：
- 研究者在在线环境中的角色
- 参与与观察的平衡
- 策略：反身性、角色协商

### 7.2 技术挑战

**平台变化**：
- 平台政策与算法的变化
- 数据访问的限制
- 策略：多平台研究、数据备份

**技术工具**：
- 数据收集与分析工具
- 技术技能要求
- 策略：工具培训、跨学科合作

### 7.3 理论挑战

**线上线下关系**：
- 线上与线下的关系
- 虚拟与现实的边界
- 策略：整合视角、连续性理解

**算法与权力**：
- 算法对社会互动的影响
- 平台权力
- 策略：批判视角、算法民族志
