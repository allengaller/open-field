# 数字民族志

> 数字时代的田野调查方法：理论、方法与实践

## 1. 数字民族志的定义与特征

### 1.1 定义

**数字民族志（Digital Ethnography）**是将民族志方法应用于数字环境的研究方法，研究数字技术中介的社会互动、文化实践与意义建构。

**核心特征**：
- **数字场域**：研究发生在数字空间（社交媒体、在线社区、游戏等）
- **中介互动**：研究通过数字技术中介的互动
- **多模态数据**：文本、图像、视频、音频等多种数据形式
- **线上线下整合**：线上与线下生活的整合理解
- **反身性**：研究者自身数字实践的反思

**证据等级**：【通行共识】

### 1.2 相关概念辨析

**数字民族志（Digital Ethnography）**：
- 最广义的术语，涵盖所有数字环境的民族志研究
- 强调民族志方法在数字环境中的应用

**网络民族志（Netnography）**：
- Kozinets提出，特指在线社区的民族志研究
- 强调在线社区的文化与互动
- 详见[网络民族志](网络民族志.md)

**虚拟民族志（Virtual Ethnography）**：
- Hine提出，研究虚拟世界与在线环境
- 强调虚拟与现实的边界模糊

**在线民族志（Online Ethnography）**：
- 研究在线环境的社会互动
- 强调在线与离线的连续性

**平台民族志（Platform Ethnography）**：
- 研究特定平台（如Facebook、微信、抖音）
- 关注平台架构对社会互动的影响

**证据等级**：【通行共识】

## 2. 数字民族志的历史发展

### 2.1 早期发展（1990s）

**背景**：
- 互联网的普及
- 在线社区的出现（Usenet、IRC、MUDs）

**代表研究**：
- **Rheingold**：《虚拟社区》（1993）——第一个在线民族志研究
- **Turkle**：《屏幕上的生活》（1995）——在线身份研究

**特点**：
- 探索性研究
- 关注虚拟社区的形成
- 线上线下关系的讨论

### 2.2 方法论发展（2000s）

**Kozinets与Netnography**：
- **Kozinets**：《网络民族志》（2010，第二版2015）
- 系统化网络民族志方法
- 强调在线社区的文化研究

**Hine与Virtual Ethnography**：
- **Hine**：《虚拟民族志》（2000）
- 强调虚拟与现实的连续性
- 方法论创新

**特点**：
- 方法论的系统化
- 伦理问题的讨论
- 跨学科对话

### 2.3 当代发展（2010s-至今）

**平台研究**：
- 关注特定平台（Facebook、Twitter、微信、抖音）
- 平台架构对社会互动的影响
- 算法与数据的作用

**移动民族志**：
- 移动设备与移动实践
- 位置与移动性
- 多地点民族志

**大数据与计算社会科学**：
- 大数据与民族志的结合
- 计算方法与质性方法的整合

**证据等级**：【通行共识】

## 5. 数字民族志的伦理

### 5.1 知情同意

**挑战**：
- 在线环境的匿名性
- 公开与私密的边界模糊
- 大规模数据收集的同意问题

**策略**：
- 公开数据 vs 私密数据的区分
- 平台政策的考虑
- 持续协商与透明

### 5.2 隐私保护

**挑战**：
- 数字痕迹的持久性
- 数据的可搜索性
- 隐私泄露风险

**策略**：
- 匿名化处理
- 数据安全存储
- 限制数据访问

### 5.3 伤害避免

**挑战**：
- 网络暴力与骚扰
- 身份暴露风险
- 长期影响

**策略**：
- 风险评估
- 保护措施
- 退出机制

**详见**：[数字研究伦理](../07-伦理/digital-ethics.md)

## 6. 数字民族志的挑战与策略

### 6.1 方法论挑战

**场域边界**：
- 数字场域的边界模糊
- 线上线下的连续性
- 策略：多地点民族志、线上线下整合

**数据规模**：
- 大规模数据的处理
- 数据过载
- 策略：抽样策略、计算方法辅助

**研究者角色**：
- 研究者在数字环境中的角色
- 参与与观察的平衡
- 策略：反身性、角色协商

### 6.2 技术挑战

**平台变化**：
- 平台政策与算法的变化
- 数据访问的限制
- 策略：多平台研究、数据备份

**技术工具**：
- 数据收集与分析工具
- 技术技能要求
- 策略：工具培训、跨学科合作

### 6.3 理论挑战

**线上线下关系**：
- 线上与线下的关系
- 虚拟与现实的边界
- 策略：整合视角、连续性理解

**算法与权力**：
- 算法对社会互动的影响
- 平台权力
- 策略：批判视角、算法民族志

- 数字劳动
