# 从田野素材到影像作品

> 同一批素材要出两种产品：一份可复查的研究记录，一部可看的影像作品。它们对素材的要求方向相反，因此不可能一遍做完——本章给出转换的顺序、必须留下的清单，以及一套贯通田野与拍摄的编号方案。

---

## 1. 两种产品的差别，以及为什么不能一遍过

| 维度 | 研究记录 | 影像作品 |
| --- | --- | --- |
| 成功标准 | 结论可被他人复查、可反驳 | 观众能看完，并留下经验 |
| 对完整性的要求 | 反例、失败检索、未支持的问题必须写入 | 只保留支撑叙事的部分是常态 |
| 对顺序的要求 | 按论证顺序（问题—证据—结论） | 按体验顺序（可能倒叙、可能并置） |
| 对时间的处理 | 时间码是引用坐标，必须精确 | 时间是节奏单位，可以被压缩 |
| 对冗余的态度 | 冗余是必要的（原始引语、上下文） | 冗余要被剪掉 |
| 对不确定的态度 | 必须写明 | 通常被叙述的确定性掩盖 |
| 主要风险 | 无人可读 | 说得比证据多 |

「一遍过」的常见形态是：拍完直接剪，剪完顺手写一段研究结论。**这个顺序会同时损害两边**——剪掉的素材在写作时被遗忘，写作时的结论又反过来被成片当成既定事实。

正确做法是把两者拆成两个独立工序，中间用一份**论证骨架**连接（第 2 节）。

## 2. 正确的转换顺序

| 步 | 做什么 | 产出物 | 不可跳过的理由 |
| --- | --- | --- | --- |
| 1 | 先完成研究侧：把田野材料做完编码与主题归纳 | 主题表 / 编码结果（见 [`../../社会学田野/08-分析/主题编码.md`](../../社会学田野/08-分析/主题编码.md)、[`../../田野方法/06-分析.md`](../../田野方法/06-分析.md)） | 未经分析就剪片，等于用画面替代论证 |
| 2 | 写出论证骨架：每个命题一行 | 骨架表（下例） | 骨架是成片与文稿的共同上游 |
| 3 | 为每个命题找支撑：具体画面时间码 + 原话引语 + 时间码 | 命题—证据对照表 | 找不到证据的命题在这一层暴露 |
| 4 | 反向检查：哪些证据支撑了多个命题、哪些命题只有单点支撑 | 缺口清单 | 单点支撑要在两边都标注不确定 |
| 5 | 决定影像侧的取舍 | 未呈现清单（第 3 节） | 省略必须被记录，否则日后无法回答「你为什么不放这段」 |
| 6 | 写解说词、做结构 | 成片 | 见 [`../05-叙事结构/解说词写作.md`](../05-叙事结构/解说词写作.md) |
| 7 | 把证据链落到交付物 | 附包（第 6 节） | 学术侧与法律侧共用同一份 |

论证骨架的最小格式：

| 命题编号 | 命题（一句话） | 证据类型 | 素材 ID / 时间码 | 强度 | 未覆盖之处 |
| --- | --- | --- | --- | --- | --- |
| P-07 | 摊位的报价随顾客身份变化，而非随成本变化 | 同期声 + 行为序列 | A-114 @ 00:12:40；A-114 @ 00:19:03–00:19:55 | 中（两个场地、四个案例） | 未见对老顾客的报价；无法排除记忆偏差 |

这张表是本章最重要的操作物：它同时是研究的证据表和成片的合法性检查表。

## 3. 「未呈现清单」：省略必须被记录

| 字段 | 填什么 |
| --- | --- |
| 编号 | 与被剪素材的素材 ID 对应 |
| 内容摘要 | 一句话，不含评价 |
| 未呈现原因 | 时长／节奏／与主题无关／同意状态未定／风险／当事人请求／技术质量 |
| 决策者 | 你／共同作者／应参与者请求 |
| 决策日期 | 必填 |
| 是否影响结论 | 是／否；若为「是」，说明结论被限定在哪一部分 |

为什么这条最要紧：**研究者被追问的从来不是「你放了什么」，而是「你手里的东西为什么没放」。** 一份诚实的未呈现清单，比多拍十小时素材更能支撑你的结论。它与撤出记录（见 [`../10-伦理法律/知情同意与拍摄授权.md`](../10-伦理法律/知情同意与拍摄授权.md)）分开维护：前者是你的编辑取舍，后者是当事人的撤回。

## 4. 影像能承载什么主张，不能承载什么

| 影像擅长承载 | 影像无法承载 |
| --- | --- |
| 「这件事发生了」（动作、在场） | 「因为这件事，所以那件事发生了」——因果 |
| 「他说过这句话」（原话 + 语气 + 停顿） | 「大多数人如此」——比例与分布 |
| 「现场是这个样子」（空间、距离、光线、物件） | 「制度／结构导致了这个结果」——机制 |
| 「这个顺序是这样」（谁先谁后） | 「他当时想的是什么」——动机 |
| 「这次互动的强度」（音量、身体朝向、沉默时长） | 「一般情况如何」——代表性 |

| 无法承载的主张要怎么办 | 做法 |
| --- | --- |
| 因果 | 用文字或口述明确表述，并说明依据来自何处（文件、访谈、推论） |
| 比例 | 用你自己的计数表或统计，作为图形或文字给出；不要用「到处都在」的画面暗示总体 |
| 机制 | 用图文（结构图、流程图）或明确的分析段落，并在骨架表中指向田野结论 |
| 动机 | 只引当事人自己的说法；不得用画面 + 解说替他归因 |
| 代表性 | 明确写「以下为个案」「未做系统抽样」，别靠配乐和蒙太奇暗示普遍性 |

**解说词不得指向画面里没有的东西**，也不得用画面去证明解说里的因果。两侧的对应关系用第 7 节的检查表逐条核。

## 5. 素材—结论对齐检查

| 检查项 | 通过标准 |
| --- | --- |
| 每一条画面对应的主张 | 都能指向至少一个时间码 |
| 每一条解说的主张 | 要么有画面内证据，要么明确标为推理／引自访谈／引自文件 |
| 画面断言与影像内容 | 一致（不要把 A 场地的画面配 B 场地的事件） |
| 拼接产生的因果 | 相邻两段之间如果构成因果，需在第 4 节意义上有独立依据 |
| 时间压缩 | 标注「时间有压缩」；跨时段素材不得暗示为同一时刻 |
| 引语完整性 | 截断后的意思与原句一致；不一致则重剪 |
| 未呈现清单 | 与本次改动同步更新 |
| 授权状态 | 每个被使用的时间码对应素材行都标注授权范围与撤回窗口 |

剪辑层面的操作见 [`../08-剪辑后期/剪辑方法论.md`](../08-剪辑后期/剪辑方法论.md)；解说词写作见 [`../05-叙事结构/解说词写作.md`](../05-叙事结构/解说词写作.md)。本节只负责**证据是否支持你说的那句话**，不管那句话好不好听。

## 6. 把证据链带进交付

交付不只是成片一条。影像交付的规格与附包见 [`../08-剪辑后期/交付母版与规格.md`](../08-剪辑后期/交付母版与规格.md)；素材表字段见 [`../08-剪辑后期/素材管理与日志.md`](../08-剪辑后期/素材管理与日志.md)。

| 交付物 | 字段要求 |
| --- | --- |
| 成片 | 版本／日期；引用编号与时间码的对照说明（可放在附包而非片内） |
| 字幕文件 | 每条字幕带原素材时间码，便于回溯原话 |
| 引语清单 | 每条被使用引语：发言人、素材 ID、起止时间码、是否匿名、授权状态 |
| 图注表 | 截帧编号、时间码、来源、拍摄者、授权声明（格式见 [`视觉社会学.md`](视觉社会学.md) 第 3 节） |
| 未呈现清单 | 第 3 节格式 |
| 骨架表 | 第 2 节格式，含结论强度与缺口 |

这四份合起来构成**可审计的证据链**。它的必要性不是学术礼节，而是：当有人质疑你某一处剪辑时，你要能在几分钟内指出证据来自哪一秒，以及你当时的取舍记录在哪。仓库宪章对可审计链的要求见 [`../../../PRINCIPLES.md`](../../../PRINCIPLES.md)。

## 7. 一料多出的产品矩阵

| 产品 | 服务对象 | 承载什么 | 不得越过的边界 |
| --- | --- | --- | --- |
| 长片／系列片 | 公众 | 经验、人物、场所感 | 不得承载未经支撑的因果与总体判断 |
| 短切（平台版本） | 公众、算法 | 单个场景、单句原话 | 不得脱离原语境成为「结论」；标注「摘编自第几集」 |
| 图文报告 | 读者、合作者 | 画面 + 三层描述 + 论证 | 图注不得含糊；不得用截图暗示未发生的因果 |
| 数据表／计数表 | 自己、可复查者 | 分布与频次 | 必须写明计数定义与覆盖时段 |
| 备忘录／田野札记 | 自己、未来研究 | 观察、假设、待查问题 | 不得在日后被当作已证实结论引用 |

| 一致性风险 | 表现 | 处理 |
| --- | --- | --- |
| 版本漂移 | 短片里的说法与长片不同，长片与文稿不同 | 所有文本口径以骨架表为唯一上游；改口径要改上游 |
| 结论强度被平台稀释 | 短片把「可能」说成「就是」 | 短切文案中保留限定词，不追求肯定句 |
| 素材授权按产品分列 | 同意长片不同意短视频 | 授权表按用途分列，每次发布前单独核一遍 |
| 匿名处理不一致 | 同一人在不同产品中可识别度不同 | 以最长尾的产品为准，取最严的处理 |
| 时间线冲突 | 不同产品发布时间不同，事件后续已变化 | 每份产品标注素材截止拍摄日期 |

一料多出的收益是降低成本，代价是**任何一份产品出错都会污染其他几份的可信度**。矩阵越大，越要守住「上游唯一」这一条。

## 8. 什么时候该停止拍摄，先回去做研究

| 信号 | 说明 | 动作 |
| --- | --- | --- |
| 素材反复出现你无法归类的内容 | 你的分类框架不覆盖现场 | 暂停拍摄，重读文献与笔记，修订编码框架 |
| 你开始只拍能证明既有假设的段落 | 拍摄在替结论服务 | 停止一周，改做反例检索（见 [`../../田野方法/06-分析.md`](../../田野方法/06-分析.md)） |
| 同一场景拍了很多但说不出它在回答什么 | 研究问题不清 | 回到问题定义，重写骨架表 |
| 当事人的解释与你的框架持续冲突 | 前提可能有误 | 这是好事：优先做访谈与回看，而不是继续拍 |
| 素材量增长而结论不变 | 边际产出趋零 | 设定停止条件；把「再拍一次」与「再查一次」排在同一张日程上比较 |
| 你无法判断还缺什么 | 分析落后于采集 | 强制进入分析期，禁止新开机 |

对一人作业尤其重要的一条：**拍摄是最容易做的事，也是最容易用来回避分析的事。** 每周留出不开机、只处理已有材料的时间，并把这段时间视为与拍摄同等优先。时间安排与他自己的止损线和回家周期一致，见 [`../../研究/行动总纲.md`](../../研究/行动总纲.md)。

## 9. 田野日志与拍摄日志合并方案

两套日志分开维护的典型后果：写作时要查「这句话哪天说的」得跨两份文件猜，事后核对不上；素材授权状态与田野同意记录接不上。合并方案的核心是**一套编号走到底**。

| 层级 | 编号格式 | 谁生成 | 例子 |
| --- | --- | --- | --- |
| 田野单元 | F-<场地码>-<序号> | 一次进入现场即一个单元 | F-MKT-07（菜市场第 7 次到场） |
| 素材 | A-<场地码>-<序号> | 一个连续录制文件／一盘 | A-MKT-114 |
| 素材内时间锚 | A-114 @ hh:mm:ss | 打点或事后定位 | A-114 @ 00:19:42 |
| 笔记条目 | N-<场地码>-<序号>，并标 F 与 A | 事后立即写 | N-MKT-031（F-MKT-07，A-MKT-114） |
| 引语 | Q-<序号> | 转录时编号，指向 A + 时间码 | Q-088 → A-MKT-114 @ 00:19:42 |
| 命题 | P-<序号> | 骨架表 | P-07 → Q-088；A-MKT-114 @ 00:12:40 |
| 决策 | D-<序号> | 未呈现清单／伦理取舍 | D-042（剪除 Q-088，原因：当事人请求） |

| 规则 | 说明 |
| --- | --- |
| 编号只增不改 | 素材被剪掉或撤出，编号保留并标状态，不复用 |
| 每个编号必须可反查 | 从 P 能追到 Q，从 Q 追到 A 与时间码，从 A 追到 F 与同意记录 |
| 单一登记表 | 所有编号在同一张表的同一列体系内登记，不分两份 |
| 时钟统一 | 现场记录表时间与机器时间必须同源，每次开机前对齐一次 |
| 授权挂在 A 与 Q | 而不是挂在「这个人同意了」，因为撤回通常针对具体片段 |
| 缺项显式留空 | 写「未知」而不是不填，日后才知道当时确实不知道 |

字段级的表格模板不在此重复，见 [`../15-工具与模板/`](../15-工具与模板/) 与 [`../08-剪辑后期/素材管理与日志.md`](../08-剪辑后期/素材管理与日志.md)。

## 10. 常见误区

| 误区 | 为什么错 | 修正 |
| --- | --- | --- |
| 拍完直接剪，边剪边想结论 | 用剪辑替代分析，剪掉的证据永久消失 | 先骨架、后剪辑（第 2 节顺序） |
| 解说说出了画面没有的东西 | 观众把画面当作那句话的证据 | 第 5 节逐条核，解说不得超出画面 |
| 把当事人的话当未经处理的事实 | 引语是陈述，不是事件本身；说法可能是自我辩护或记忆重构 | 与行为序列、其他来源对照；按口述材料处理 |
| 用画面并置暗示因果 | 相邻不等于相关，更不等于因果 | 因果只用文字承担并说明依据 |
| 用「到处都在」的画面暗示总体 | 你的拍摄不是抽样 | 比例主张需计数表或明确标为个案 |
| 未呈现的东西不记录 | 无法回答质疑，也易在日后被误当作从未拍到 | 维护未呈现清单 |
| 两种产品口径各写各的 | 版本漂移，互相拆台 | 骨架表为唯一上游 |
| 素材越多越安心 | 素材量不是研究进度 | 用结论推进而非文件量衡量进度 |

## 11. 实操要点

- [ ] 开始剪辑前，论证骨架表必须存在，且每个命题都有证据列或明确的「无证据」标注。
- [ ] 每个命题的强度与未覆盖之处写出，不用「有待进一步」代替具体内容。
- [ ] 未呈现清单与剪辑同步维护，每条省略写明原因与日期。
- [ ] 因果、比例、机制三类主张一律由文字承担，并说明依据来源。
- [ ] 解说词按第 5 节检查表逐句过，不通过的句子改写或删除。
- [ ] 字幕文件与引语清单带素材 ID 与时间码，能在几分钟内回溯到原句。
- [ ] 多产品发布前各自核授权范围，以最严处理为准。
- [ ] 合并编号：F/A/Q/P/D 在同一登记表内贯通，禁止双轨日志。
