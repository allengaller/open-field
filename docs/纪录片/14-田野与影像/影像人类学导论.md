# 影像人类学导论

> 这一章不教你怎么拍，教你怎么同时当一个研究者和一个纪录片作者而不撒谎。入口篇要回答一个问题：影像进入田野之后，你到底多出了什么证据，又欠下了什么债。

---

## 1. 学科位置：它是人类学的方法分支，不是纪录片的一个题材

「影像人类学 / 视觉人类学」（visual anthropology）在学科树上是**人类学下面的一支**，与亲属制度、经济人类学、语言人类学并列；它回答的是「视觉材料如何产生人类学知识」。「影像民族志」（visual ethnography）更窄，指具体的做法与成果：用影像完成一次民族志描写。在影视一侧，同一批片子被归入纪录片分类下的「人类学题材」或「田野片」——**这是外部标签，不是学科位置**。

| 维度 | 学术一侧（人类学） | 影视一侧（纪录片） |
| --- | --- | --- |
| 好作品的定义 | 论证成立、材料可复核、前提被交代 | 好看、有推进、有作者的观点与形式感 |
| 裁判是谁 | 同行、评审、被研究者本人 | 观众、平台数据、选片人 |
| 失败长什么样 | 结论超出材料、方法说明缺失、未经同意发表 | 节奏拖沓、信息重复、没有可跟的人 |
| 对「没说话的画面」的估值 | 可能是核心证据（沉默、迟疑、距离） | 通常是剪掉的对象 |
| 引用方式 | 文件编号＋时间码（[../../工程/架构.md](../../工程/架构.md) 的 `OF-…#Tmm:ss`） | 片段、截图、看点 |
| 对当事人的义务 | 成员核对、可撤回、匿名化 | 授权签完即视为交付 |

两套判据**互相不否定，但互不代偿**：拍得好看不能让论证成立，论证严密不能让片子成立。你一个人交付两边，就必须**显式选主判据**，另一个降为约束。

【操作性建议】选主判据的三条规则：

1. 这份产出要交给谁，谁那一侧就是主判据。给评审、给报告、给咨询客户 → 学术侧为主；给 B 站 / 抖音 / 视频号观众 → 影视侧为主。
2. 主判据在动笔前写下，一行即可：「本片主判据＝影视侧；论证强度以文字稿承担，画面不承担证明责任。」写在不发布的位置（提案、说明文件），不是写给观众看的口号。
3. 降为约束的那一侧要有一条**不可越界项**，不是「尽量」。典型例子：影视侧为主时，不可越界项是「不得让画面冒充它没有证明的因果」。

[影像民族志案例](../13-案例/影像民族志案例.md) §7 已经从发表侧列了评审不认影像、引用困难等四条处境，此处不重复；本篇给的是正面判据与开机判断表。

## 2. 一条简要问题史：五步，每步都对应你明天现场会撞上的事

| 阶段 | 通行称谓 | 核心信念 | 被指出问题时 | 你今天对应的现场问题 |
| --- | --- | --- | --- | --- |
| 一 | 拯救式拍摄（salvage ethnography） | 相机能抢救正在消失的真实，先拍下来就赢了 | 被拍的人早已不在他所拍的状态里；画面成为一种摆置 | 你拍老市场、老城中村时的「再不拍就没了」——它既是真理由，也是放弃追问的借口 |
| 二 | 他者的制造（making of the Other） | 记录异文化即可传达异文化 | 「谁定义了这个群体」无人回答；被拍者无名、作者署名 | 你把一群人剪成一个类型（「流水线工人」「厂里的人」）时，你在制造 |
| 三 | 自反转向（reflexive turn） | 把作者与拍摄条件放进作品 | 走向自恋：片子变成作者的内心戏，当事人成了道具 | 你在镜头前出镜、说出你的判断时——必须同时说出你的位置，否则自反只是姿态 |
| 四 | 参与式与共享（participatory / shared） | 记录权与编辑权应重新分配 | 「共同创作」变成名义：机器给了对方，剪辑权没收 | 你请对方自拍、答应让他先看片——承诺给出去了就要能执行 |
| 五 | 数字与多模态（digital, multimodal） | 手机、平台、屏幕已是田野的一部分 | 材料暴涨、语境剥离、可追溯性反而下降 | 你每周发片、素材上万条、别人拿你的手机拍你——全在这一档里 |

第三、四步的学科史争论常以《写文化》一系著作为标志（Clifford 与 Marcus 编，1986 年前后；【通行共识】，**出版年份请复核**）。这里取的是它的**方法后果**，不是它的名人名单。

## 3. 影像独有的能力，以及影像天生记不住的东西

判断要不要开机，靠的是这张对照表，不是「拍下来总没错」。

| 只有影像留得住的 | 说明 | 只有影像留不住的 | 说明 |
| --- | --- | --- | --- |
| 语调与音高变化 | 同一句「挺好的」，三种说法是三种意思 | 气味 | 车间、菜市场、出租屋的判定级信息，影像零记录 |
| 停顿的时长与位置 | 谁在哪一个字前停住，是关系信息 | 语境前提 | 他们默认双方都知道的那些规矩，不会出现在画面里 |
| 身体朝向与距离 | 谁对着谁坐、谁被隔在一米外 | 未说出口的判断 | 他心里怎么评价这件事，机器无从得知 |
| 多人同时说话 | 文字转写只能串行，声音是并行的 | 你当时的推理 | 你为什么此刻按下录制键——只有笔记记得 |
| 动作的时序 | 一个活儿的手顺、错在哪一步 | 不在场者的作用 | 老板没来之前他们怎么说的，画面无法证明 |
| 可见的物质条件 | 光线、密度、防护、设备新旧 | 制度的运行过程 | 「规定」是文字对象，画面只有它的痕迹 |

**这张表右列的六项，全部只能靠田野笔记与研究问题意识补**。反过来说：如果一个问题落在右列，你开机的意义主要是给左列做辅证，不是给结论做证据。笔记侧的手艺见 [../../田野方法/04-观察与笔记.md](../../田野方法/04-观察与笔记.md)，本篇不重述。

## 4. 影像不是更客观的记录，是一种新的建构

「有录像就有真相」是这套工作最贵的错觉。相机做了四件无法取消的事：选框、选时长、选视角、选保留哪一段——每一次都在做判断。因此画面不是「原始数据 + 一点加工」，它是**在特定位置、特定关系、特定设备上生成的一份记录**，其客观性不高于笔记，只是可核对的方式不同。

这一点直接接 [真实契约](../01-理论/真实契约.md)：纪录片的信任不寄存在画面上，寄存在**制作过程的可追问性**上。落到影像进入田野的语境里，推论是一句：**你必须把影像当作一份需要交代产生条件的材料来对待，而不是一份免检材料**。产生条件写在哪里，见 [田野素材到影像](./田野素材到影像.md) 与 [相机在场效应](./相机在场效应.md)。

【操作性建议】开机前的三行登记，缺一行这段素材日后就不该进论证：在场者（编号化名）／你的位置与谁同意你在这里／这段素材打算回答什么问题。

## 5. 影像进入田野之后，具体改变了什么

纯文字田野的产出是一份描述。加上摄影机之后，五件事同时发生变化——这五条是全章的分项依据，不是修辞。

| 变了什么 | 变好的部分 | 变坏的部分 | 对应篇目 |
| --- | --- | --- | --- |
| 证据的形式 | 时序、共现、姿态可被反复核对，别人能看同一段得出或推翻你的判断 | 材料不可累加，一万分钟与十分钟在论证上是同类；检索成本压垮个人研究者 | [视觉社会学](./视觉社会学.md) |
| 现场的关系 | 有了一台「不必一直看着对方」的中间物，某些话题反而更好开口 | 你的注意力被机器分走；对方把你的注意力当作评价信号来读 | [相机在场效应](./相机在场效应.md) |
| 同意的内容 | 可以按「录音／肖像／发表」分档谈，比口头承诺清楚 | 同意变成一件有版本、可撤回、要留痕的持续事务，不再是一次签字 | [知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md) |
| 风险的形态 | 现场争议事后可自证（谁说了什么、你当时在不在） | 一旦公开便不可收回：画面里的人脸、门牌、工牌、车牌都是永久暴露 | [中国法律边界](../10-伦理法律/中国法律边界.md) |
| 产出的义务 | 能给当事人留下可交付的东西，关系不再是单向取用 | 你欠下回看、异议登记、按约定删改这些必须还的债 | [视频回看与反馈访谈](./视频回看与反馈访谈.md) |

一句总括：**相机给你的每一种能力，都同时给你一项必须履行的义务**。这也是本篇反复要求「登记、编号、标注」的原因——它们不是文书癖，是义务的记账方式。

## 6. 研究问题 × 是否值得开机：判断表

| 你的问题类型 | 影像是否优于笔记 | 怎么下手 |
| --- | --- | --- |
| 这个活儿的手顺与身体技术 | **明显优于** | 固定机位长录，一次动作序列一条，不切 |
| 谁在跟谁说话、谁能打断谁 | 优于 | 收音分轨或至少保证方位可辨 |
| 沉默、迟疑、话到一半咽回去 | 优于（且只有影像） | 事件未闭合不许关机，见 [观测电影](./观测电影.md) |
| 空间密度、光线、设备新旧、防护有无 | 优于 | 空镜承担记录职能，见 [空镜与环境影像](../07-拍摄执行/空镜与环境影像.md) |
| 多人同时在做什么 | 优于 | 广角＋全景优先，别追求构图 |
| 这件事多久发生一次、多少人经历 | **明显更差** | 计数、访谈、台账；影像只能给个例 |
| 他们为什么这么做（动机与理由） | 更差 | 访谈为主，见 [../../田野方法/05-访谈.md](../../田野方法/05-访谈.md) |
| 制度、规则、流程如何运行 | 明显更差 | 文件、单据、口述；画面只有痕迹 |
| 事件的时间线与先后因果 | 两者都不够 | 影像给锚点，笔记给顺序，交叉验证 |
| 价格、工资、时长等具体数值 | 更差（易误读） | 拍到实物再核，画面里的数字要单独确认 |
| 对方没说出口的判断 | 影像无法触及 | 靠长期关系与笔记，见 [信任与被摄者心理](../06-采访方法/信任与被摄者心理.md) |

一句口诀：**时序、身体、共现交给相机；理由、频次、制度交给笔记与访谈**。开机前先问自己这张表里的哪一行——答不出来，就不该开机。

## 8. 常见误区

1. **把拍了很多当研究了。** 素材量与研究无关，编码与论证才有。一万分钟没被检索过的素材，在学术上的价值是零，在心理上的价值是让你觉得工作在进行。
2. **把影像当原始数据。** 数据意味着可累加、可复核；影像意味着可核对但不可累加。一段视频不能变成「一条观察」，它必须先被描述、编号、时间码切分，才能进编码表（接口见 [视觉社会学](./视觉社会学.md)）。
3. **把学科史当名人录。** 知道谁发明了什么对你现场没有任何帮助；知道「每一次声称客观都曾被人指出它在选择」才有。本库一律不写生平与年份堆叠。
4. **以为视觉人类学就是「拍少数民族」。** 它是关于方法位置的争论，题材不决定学科属性。拍城中村小店和拍高原牧区在这门方法上没有等级差。
5. **两边都要、不设主次。** 结果是片子观众说闷，评审说没有论证。主判据不写下来，它仍然会起作用，只是以失控的方式。
6. **把「有画面」当「有证据」。** 画面证明的是它在被拍摄时那样发生了，不证明它通常如此，也不证成为什么如此。
7. **把两套语料库的方法讲法在本章重写一遍。** 本章的价值恰恰在于它只写交叉的那一条缝；缝以外的内容一旦重写，两处版本就会开始互相矛盾，而你分不清哪一份是新的。
8. **等关系到位了再开机。** 习惯化不是开机的资格，是素材的属性；你在场第几天开始录，会永久地写进那批素材的性质里，标注出来就够用（见 [相机在场效应](./相机在场效应.md)）。

## 9. 实操要点

- [ ] 每个长期项目开头写一行主判据声明（学术侧／影视侧），并写下这一侧不可越界的那一条。
- [ ] 开机前跑 §6 判断表：这段素材落在哪一行；落在「明显更差」的行，改用笔记或访谈。
- [ ] 每次开机做三行在场登记：在场者编号／你的位置与被谁同意／本段要回答的问题。
- [ ] 把 §3 右列六项写进当天的田野笔记模板，作为强制补写项，防止影像挤掉笔记。
- [ ] 引用影像一律「文件编号＋起止时间码」，与 [../../田野方法/09-写作.md](../../田野方法/09-写作.md) 的 `OF-…#Tmm:ss` 格式对齐。
- [ ] 每季度检查一次：素材库里有多少段落至今没有任何一行说明它回答什么问题——那部分就是你误认为「研究了」的量。
- [ ] 术语首现在自己的文稿里补英文对照，并与 [总览术语表](../00-总览/术语表.md) 的译法保持一致。
