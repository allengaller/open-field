# 视频回看与反馈访谈

> 让当事人看回放（video feedback / member check）不是礼节，而是一种独立的数据生产方式：它同时纠正你的记忆、记录当事人对影像本身的反应，并把一部分解释权交回给对方。本章给出三种回看形式、提问设计、现场操作细节，以及看完之后的四种处置与其执行义务。

---

## 1. 为什么回看是方法，不是客气

| 回看能产出的东西 | 为什么只有回看能产出 |
| --- | --- |
| 纠正你的记忆偏差 | 你会记错谁先开口、谁在场、原话是什么；画面不受你当时的情绪影响 |
| 当事人对影像的反应 | 「这段我看起来像在骗自己」这类话只在他们看到自己时才出现 |
| 被重新说出的解释 | 同一件事，看过画面后当事人常给出第二种说法——两种都要留 |
| 你未察觉的细节 | 他们能指出你注意不到的东西（画面外的人、被遮挡的动作、当时的规矩） |
| 争议点的显性化 | 你不认同的解读，只有在对方口中说出来才能被记录为分歧 |
| 解释权的再分配 | 分析不再是你单方面的动作，这是成员校验的核心（见 [`../../田野方法/08-信效度.md`](../../田野方法/08-信效度.md)） |

【通行共识】在田野方法一侧，这一步通常叫「成员校验（member checking）」；它在这一层的具体形态就是回看。方法论本身不在此重述。

一句实话：回看也会**削弱**一些东西——当事人知道你会给他们看之后，说话可能更谨慎、更表演。所以不要对所有场地都用同一种回看承诺，也不要在开机前把「一定会给你看成片」当作换取信任的话术（第 8 节）。

## 2. 三种回看形式

| 形式 | 时机 | 主要产出 | 主要风险 | 适配你的场合 |
| --- | --- | --- | --- | --- |
| 同场回看 | 当天、现场、录制刚结束 | 立即纠错；「刚才那句能不能不放」；你漏掉的语境 | 他们当场要求删除，你必须能立刻删；最容易变成「改进表演」 | 车间、店铺、摊位等日常重复型现场 |
| 隔期回看 | 数周之后 | 冷却后的叙述；更深一层的解释；他们愿意承认当初否认的部分 | 时间差导致期待落差；关系可能已变化 | 长期跟踪的村庄、家庭、个体户 |
| 素材回看访谈 | 拿旧片段作为访谈刺激物 | 触发被遗忘的段落；暴露前后不一致；获得第二次叙述 | 他们可能拒绝旧日的自己；也可能把新版本说成唯一版本 | 口述史型、工序史型、跨年份对照 |

### 2.1 同场回看：价值最高、风险也最高

| 必须做到 | 说明 |
| --- | --- |
| 能当场删 | 现场必须准备好可立即删除的操作（卡内删除 + 记录删了什么）。做不到就不要承诺同场回看 |
| 删完仍可自查 | 删除动作进入撤出记录，编号与被删片段一致（第 7 节） |
| 不要看整段 | 只看有争议的、你不确定听到什么的几十秒；看完整段会把现场会变成审片会 |
| 提前定好谁有权要求删 | 在场的人不止一个时，谁的要求生效（雇主？当事人本人？）——不定就会出现当场冲突 |
| 防止「改进表演」 | 一旦他们看过回放并开始调整下一次的自我呈现，当天的后续素材性质已变，必须在日志里标出分界时间 |

最后一项是同场回看最大的方法学代价：**它会把观测式拍摄变成半表演式拍摄**。处理办法不是不用，而是把「首次回看的时点」当作田野事件记录下来——从这一刻起，现场性质改变了，这件事本身就是数据（详见 [`相机在场效应.md`](相机在场效应.md)）。

### 2.2 隔期回看：更适合挖第二层

| 要点 | 做法 |
| --- | --- |
| 间隔多长 | 以当事人情绪与关系状态为准，不以你的日程为准；数周通常比数日更有话说，但太久会失去现场感 |
| 看什么 | 不看全片，看 3–8 个片段；每个片段前先问「你记得这天吗」 |
| 谁在场 | 有无第三人在场会显著改变他们说什么（老板在场时不会说同一套话），并把在场者记下来 |
| 承诺边界 | 明确说明「这是给你看，不是最终版本，看完你的意见会记录并处理」，避免被理解为审片 |

### 2.3 素材回看访谈：把旧片段当作提问工具

| 步骤 | 说明 |
| --- | --- |
| 选段 | 选信息量低但情境明确的段落（一个动作、一处场所、一次搬运），不选冲突最激烈的段落作为开场 |
| 播放 | 一次只放一段，放完立刻停，等对方开口 |
| 提问 | 「这是哪天的事」「那时候你担心什么」「现在回头看，这段说明什么」 |
| 记录分歧 | 新说法与旧说法并列登记，不裁决、不当场反驳 |
| 用途 | 触发记忆、找不一致、把沉默的事说出来；与口述史访谈的衔接见 [`../06-采访方法/口述史访谈.md`](../06-采访方法/口述史访谈.md) |

【操作性建议】不一致不是失败，是材料。前后说法不同常常正说明处境变了；把它登记为一条田野单元，而不是去「纠正」对方。

## 3. 回看访谈的提纲设计

| 原则 | 具体做法 | 不要做什么 |
| --- | --- | --- |
| 先看后问 | 播完再开口；中途不停下来解释 | 边播边讲你的观点 |
| 问反应，不问评价 | 「看到这一段，你身体什么感觉」「你想插话的地方在哪」 | 「这段好不好」「有意思吗」 |
| 用「哪里不像你」 | 「这里面有没有哪一处，你觉得不像你」——比问「有没有失真」更容易得到真话 | 「我拍得客观吗」（无法回答，且引出客气话） |
| 问可见的选择 | 「你为什么当时没有说出声」 | 「你是不是同意了」（把沉默说成同意） |
| 问画面外 | 「那时候镜头后面还站着谁」 | 假定你看到的就是全部 |
| 允许沉默 | 播完等，至少留足一次呼吸的时间 | 用说话填满空白 |
| 收尾固定 | 「还有什么我完全没问到」+ 明确下一步与时间 | 结束时留下未答复的期待 |

提纲模板见 [`../15-工具与模板/`](../15-工具与模板/)，不在此重复。

## 4. 现场操作细节

| 项目 | 建议 | 理由 |
| --- | --- | --- |
| 播放设备 | 优先大屏或投影；无屏时用平板而非手机 | 小屏会让注意力落在声音上，画面细节被放弃；也让对方看不清你的表情 |
| 人数 | 一到三人最稳；人多则表态趋于一致 | 人多时他们说的是「给众人听的话」，不是给你听的话 |
| 是否录制这次回看 | **必须单独征得同意**，与素材拍摄的同意是两回事 | 回看对话是新的发言，需要新的授权 |
| 对方是否可以录 | 允许，并说明你也可以要求不录 | 单方面禁止录制是一种权力使用，说清理由 |
| 座位与朝向 | 并坐而非对坐，同看一个屏 | 面对面的布局会把回看变成审问 |
| 片段长度 | 单段控制在几十秒到两三分钟；总时长宁短 | 对方的注意力与眼疲劳决定上限，不是你的素材量 |
| 停顿控制 | 每段之间明确停顿，给对方说话的机会 | 连续播放会让人放弃插话 |
| 读屏负担 | 现场准备好字幕或大字提纲；关键问题打印出来 | 对视力的负担会同时落在你与对方身上；靠记忆提问会漏 |
| 场地 | 不在工作场所做敏感段落的回看 | 见第 2.2 节「谁在场」 |
| 时间 | 预留比预计多一半的时间；不要卡在对方要开工前 | 被时间压着的回看只会得到客气话 |

【操作性建议】对当事人眼睛的照顾很实际：屏幕亮度调低、避免在强光下看屏、每几段停一次。回看是为了让他们说话，不是为了让他们看完你的片子。

## 5. 会后四种处置

| 处置 | 触发条件 | 执行义务 | 留痕 |
| --- | --- | --- | --- |
| 1 原样保留 | 无争议，或争议已被记录为分歧 | 记录当事人的异议原文，即使不采纳 | 回看记录表 + 未呈现清单不新增条目 |
| 2 匿名／模糊处理 | 内容可留但身份可留问题；或涉及第三人 | 声音与面貌同时处理（只处理一项通常无效）；改名后全片一致 | 处理项清单 + 生效版本号 |
| 3 撤出该段 | 明确要求不放某段；出现私密内容；风险过高 | 在所有交付物中移除（成片、短切、字幕、截图、图文稿）；按时间码定位，逐份核对 | 撤出记录（含时间码与请求人） |
| 4 撤出全片 | 当事人撤回整体授权；出现重大风险；关系破裂且内容高度依赖其本人 | 停止发布并下架；已分发部分尽力回收但如实说明不可完全回收；不得改头换面重新发布 | 撤出记录 + 下架时间 + 通知对象清单 |

四种处置的**决定权分配要事先说清**：哪些你当场就能答应（第 3 类通常可以），哪些必须回去处理（第 2、4 类涉及整体结构，当场承诺会导致返工），哪些不能答应（「全部不放」若涉及你已依赖的其他授权与共同作品，须回去核）。

第 3、4 类与知情同意的撤回机制对齐，见 [`../10-伦理法律/知情同意与拍摄授权.md`](../10-伦理法律/知情同意与拍摄授权.md)。删除的可审计要求见 [`../../../PRINCIPLES.md`](../../../PRINCIPLES.md)：删的要能说明删了什么、何时、受谁请求、影响哪些版本。

## 6. 发布前必须给当事人看这件事

| 问题 | 回答 |
| --- | --- |
| 是义务还是选择 | 在长期田野与涉及弱势或可识别个体的场合，应视为义务：一旦发布，撤回成本远高于放映前 |
| 看什么 | 看涉及自己的段落，不看全片；如给全片，须说明版本非最终 |
| 何时 | 留足修改时间，不要在上线前一天 |
| 看完怎么算 | 明确「你提出 X，我处理为 Y，原因是 Z」，并把这条链写下来 |
| 无法联系／不愿看 | 记录你尝试的时间与方式，据实说明；不要把沉默当同意 |
| 放映与社区场合 | 群体性回看、放映与后续讨论见 [`../12-发行传播/社区放映与参与式传播.md`](../12-发行传播/社区放映与参与式传播.md) |

## 7. 把回看对话写成研究材料

回看时你会得到极其丰富的材料——问题是，**这段对话本身需要新的同意才能引用**。

| 情形 | 处理 |
| --- | --- |
| 已获准录制回看并授权引用 | 正常登记为田野单元，编号进合并体系（见 [`田野素材到影像.md`](田野素材到影像.md) 第 9 节） |
| 只同意录制、未同意引用 | 可自用分析，不可直接引语发表；引用需事后单独再问 |
| 未录制、仅笔记 | 笔记是你的记录，可写；但被人的原话作为直接引语发表仍需同意 |
| 对方要求「这段别写进去」 | 与素材撤出同等对待，进入撤出记录 |
| 引用会暴露对方曾反对你的剪辑 | 这是最有价值也最敏感的材料；匿名化处理并如实说明存在分歧 |

【操作性建议】把「回看内容是否可引用」做成一句固定问话，在回看结束时问，而不是等到写作时再联系——事后追要同意的成功率明显更低，也更容易被理解为添麻烦。

## 8. 常见误区

| 误区 | 为什么错 | 修正 |
| --- | --- | --- |
| 回看是礼貌，看完点点头就算 | 放弃了唯一的纠错与二次叙述机会 | 按第 3 节提纲问反应 |
| 给对方看成片 | 期待失控，且全片信息量压过具体争议 | 只看片段；说明这是过程版本 |
| 问「你觉得拍得好吗」 | 只会得到客气话，且暗示你希望被肯定 | 换成「哪里不像你」「你想插话在哪」 |
| 当场承诺一切修改 | 后续返工与结构冲突，最后一条也做不到 | 区分当场可答／需回去处理／不能答应 |
| 同场回看后继续按观测式记录却不标注 | 现场性质已变，素材被混用 | 记下首次回看的时点，之后素材标为「已知会被回看」 |
| 认为当事人说的就是更正确的版本 | 他们的当下解读也是建构，也受在场者影响 | 新旧说法并列，不裁决 |
| 回看对话直接引用 | 需要新的授权 | 第 7 节固定问话 |
| 用回看代替反例检索 | 对方不会替你检查你的论证 | 校验与反例检索是两件事（见 [`../../田野方法/08-信效度.md`](../../田野方法/08-信效度.md)） |

## 9. 实操要点

- [ ] 承诺回看前先确认自己能兑现：能否当场删、能否按时出现、是否留有返工时间。
- [ ] 一次会话按固定流程走：说明来意与边界 → 播片段（每段几十秒到两三分钟）→ 停顿提问 → 收意见 → 当场登记处置类别 → 问「回看内容可否引用」→ 约定下一步与时间。
- [ ] 记录表至少填：日期场地、在场人员、播放片段与素材 ID／时间码、当事人原话、处置类别、执行责任人与期限。
- [ ] 每次回看都要产出可核对的处置结果，不接受「以后再说」；未执行的项在下一次会话开头复查。
- [ ] 撤出类处置逐份交付物核对（成片、短切、字幕、截图、图文），并记录生效版本。
- [ ] 发布前把涉及本人的段落给当事人看，尝试联系的时间与方式如实记录。
- [ ] 把「首次同场回看」当作田野事件记录：从这一刻起现场性质改变。
- [ ] 表格模板不在本节扩展，统一维护在 [`../15-工具与模板/`](../15-工具与模板/)。
