# 参与式影像

> 参与式影像（participatory video）的判据只有一条：谁决定哪些画面被公开。机器交出去不算，决定权交出去才算。这一篇讲三档做法、每一档的前置条件，以及承诺给出去以后怎么还。

---

## 1. 定义与谱系：这一支从哪儿来

**参与式影像（participatory video）**：研究或创作的采集与制作环节中，被记录者承担一部分原本由作者承担的工作——看、拍、或决定成品如何组织。它的近亲有三个，界清楚才知道自己在做哪一件：

| 近亲 | 通行称谓 | 与参与式影像的差别 | 已有讲法在 |
| --- | --- | --- | --- |
| 参与式行动研究 | participatory action research | 目标是改变被研究的状况，产出不止一部片子；影像只是手段之一 | 本库不重述，属方法论一侧 |
| 影像发声 | PhotoVoice | 以拍照＋当事人解读为主，起点是社区需求评估，常见于公共卫生语境 | [../../田野方法/05-访谈.md](../../田野方法/05-访谈.md) §6（含原始文献条目） |
| 共享式做法 | shared anthropology | 强调影像回到被研究者手里并被他们使用与评判 | [影像民族志案例](../13-案例/影像民族志案例.md) §3 |

这一支的动机表述常带一个「给予能力」一类的口号词。**本库不用这类词写作**，因为它不说明任何一件具体要做的事。用可执行的说法替代：

| 口号式说法 | 换成这一句才算说清楚 |
| --- | --- |
| 让对方变强 | 让对方掌握表达工具：一台他能独立操作的机器，和一次他可以说「这不是我」的机会 |
| 让弱势群体发声 | 把记录权交回当事人：他们决定拍什么、什么时候停、哪些段落不公开 |
| 共同创作 | 共同决定成品的具体范围：是选题、是素材取舍，还是最终剪辑权 |
| 深度参与 | 写清参与的事项与频次，以及他退出时已发布的东西怎么处理 |

## 2. 三档做法：从易到难，承诺递增

[影像民族志案例](../13-案例/影像民族志案例.md) §5 已按「风险由谁承担」列过交机器一族的做法，此处不重复那张表；本篇按**前置条件与承诺强度**分档，因为你的失败几乎都发生在承诺超过履行能力这一处。

| 档 | 你承诺了什么 | 兑现它需要什么 | 难度 |
| --- | --- | --- | --- |
| 一、让当事人**看** | 我会把拍到的放给你看，你的异议我会登记并给出处置 | 一次回看的时间与设备，以及真的能删的权限 | 低（但不可跳） |
| 二、让当事人**拍** | 我给你一台机器，你按你的意思拍；拍什么我不干涉 | 最小器材培训、素材归属约定、损坏与责任约定 | 中 |
| 三、让当事人**决定怎么剪** | 成品的取舍由他参与定，重大异议可以改结构 | 共同编辑流程、时间预算、冲突裁决规则、署名与撤回安排 | 高，**做不到就别承诺** |

### 2.1 第一档：让当事人看

这是三档里唯一**无条件该做**的一档——它同时是伦理义务（发布前先给本人看，见 [社区放映与参与式传播](../12-发行传播/社区放映与参与式传播.md) §2）和研究方法（回看能查出你记错的事，见 [视频回看与反馈访谈](./视频回看与反馈访谈.md)）。操作细节全部在后者，本篇只提参与式视角下的一条区别：**在第一档里，看的人有权要求删，你有权解释为什么建议保留，但决定权在他的要求一侧**——你只能问「我保留并做模糊处理，你接受吗」，不能默认「他没反对」。

### 2.2 第二档：让当事人拍

**最小器材培训集**（不要超过这一项，超过就变成教学任务，你把培训当交付）：

- [ ] 开机与停止、怎么拿稳、什么时候没电、存储满了怎么办——四项，各演示一次，让他独立做一遍。
- [ ] 一句纪律：**按下去之前先问一句**。教不会这一条，就不要给机器。
- [ ] 不教构图、不教运镜、不教「拍点有用的」。你一旦给了他一套取景标准，他拍回来的就是你的视角的复制品，这一档的意义当场归零。

**素材归属约定**（给机器之前谈完，口头也要留录音）：这批东西是谁的、你打算做什么用、他随时可以要回原件、你能不能公开。**四条缺一，事后必然反目**（展开见 §3）。

**真实收益**：你会拿到你永远拍不到的位置与时刻——班后的宿舍、家属在场时的谈话、同行之间不设防的玩笑。这不是画质问题，是**准入问题**：有些画面只有持有那种身份的人能拍到。

**真实风险**：

| 风险 | 具体表现 | 事前处置 |
| --- | --- | --- |
| 设备损坏与责任 | 掉进水池、被没收、被人抢 | 事先约定：非故意损坏不向对方追偿，且把这句话当着他的面说出来。追偿一次，这条合作线永久结束 |
| 拍到无法公开的东西 | 他人裸身、病历、证件、内部文件、第三方隐私 | 交机时明确「哪些一律不拍」的三到五条清单；接收素材时你先做一次敏感筛，不删，转入 `X_不可发布` 并告知对方 |
| 交付预期落差 | 他以为你会替他传播某件诉求 | 明说你能做什么：片子不承载诉求、不上热搜、不做交涉工具；能给的是原件与一次放映 |
| 社交风险由他承担 | 他拍到了工友，工友骂的是他不是你的机器 | 让他知道：被拍的人有权要求删，他需要自己处理这件事，你会兜技术但兜不了他的关系 |
| 素材不可控 | 时长、格式、质量完全不齐 | 只约定主题与命名，不约定规格；后期统一转码（见 [编码存储与备份](../09-技术与设备/编码存储与备份.md)） |

### 2.3 第三档：共同编辑

最高一档，也最难，因为它是**把你的叙事决定权分出去**。它要求你具备以下全部条件，缺一就不成立：

1. 你能接受结构被推翻重剪，且这段工期你排得下。
2. 你有明确的裁决规则：他坚持保留、你认为会造成误读时，谁说了算——事先写，不是现场吵。
3. 双方同意**意见分歧可以留在片内**（把两种说法并置），而不是必须谈成一致。
4. 署名与撤回机制先定：他以什么身份出现（共同作者／受访者／协助者），他能否撤回署名，撤回后已发布版本怎么处理。

【操作性建议】对一个人的项目，第三档的**现实上限通常是「一次结构级协商」**：粗剪出一个骨架版本，请他看一次，允许他要求换掉或撤下某一个段落主线，你按约定执行。这已经是真正的共同编辑，且不依赖你没有的机构资源。全流程剪辑侧的接口见 [粗剪到精剪](../08-剪辑后期/粗剪到精剪.md)。

## 3. 权利与归属：交机器之前必须说清的四件事

这是参与式做法最容易在事后崩掉的地方。**本库只识别风险并要求把约定固定下来，不给法律意见**；具体归属规则随法域、作品类型与约定内容而变，涉及实际发布前先过 [版权链与E&O](../10-伦理法律/版权链与E&O.md)。

| 事项 | 你必须回答的问题 | 最低限度的做法 |
| --- | --- | --- |
| 当事人拍的内容归谁 | 素材的作者是谁、原件给谁、谁有权许可公开 | 约定优先，书面或录音留痕；不要依赖任何「默认规则」。约定里必须包含「他随时可取回全部原件」 |
| 作者能否单独发布 | 你需不需要他每一次都点头 | 分档授权：一次性授权范围（哪个版本、哪个平台、多久）写清；用途变更即新增一版同意（[知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md) §7 的台账） |
| 集体同意可行吗 | 社区／班组／家庭能否代替个人同意 | **不能代替。** 集体表态可以证明你被这个群体接纳，但被画面清楚识别的每一个个人仍需自己那一份。群体同意＋个人不同意时，个人不同意生效 |
| 收益怎么算 | 有收入时是否分、以什么名义分 | 提前谈，不谈也是决定，而且是最坏的那种。至少要说明：你自费、你发布、你不因发布向他付费——把这句话在交机时说出口 |

**关于集体同意的限度**：场所的守门人（厂方、房东、市场管理方）同意你拍，不等于被拍的人同意你拍；群体的领袖同意公开某件事，不等于当事人同意。这条与进入田野时的守门人问题在结构上同源，见 [../../田野方法/03-进入田野.md](../../田野方法/03-进入田野.md) §2。

## 4. 最小可行参与式设计：一个人的三步

不承诺你做不到的事，是这一节的全部目的。

| 步骤 | 做什么 | 时间成本 | 完成判据 |
| --- | --- | --- | --- |
| 一 | 给对方一台易上手的机器（他不需要学任何摄影概念），只约定**一个主题**和**三到五条不拍清单** | 一次交机，20 分钟内 | 他能独立开关机、能在拿不准时先问一句 |
| 二 | 约定**任务边界**：拍几天、大概多少段、什么时候交回、你能做什么不能做什么 | 一次谈话，留录音或书面 | 双方对「这批素材最后会变成什么」的说法一致 |
| 三 | 回看时对谈：一次放给他看，请他挑「这不是我」和「这个不能让别人看见」，逐条登记并给处置 | 1—2 小时，可分批 | 每一条异议都有落点：删／模糊／保留并注明分歧 |

**这三步不包含共同剪辑，也不承诺替他传播任何诉求。** 它是你今晚就能启动的版本，而且它已经完成了参与式最核心的那一件事：把「哪些画面可以被公开」的决定，交回给被画面涉及的人。

每季度可以在这个骨架上试加一项，不加第二项：给两台机器让两个人互相拍／请对方替你剪一分钟／让他自己写一段图注。加一项就是一次结构级协商，不是加一项就变成共同作者。

## 5. 什么时候不该做参与式

参与式不是美德清单上的一项，它是一项有交付义务的工程。以下六种情形下**不做比做了好**，因为它会制造一个无法履行的承诺。

| 情形 | 为什么不该做 | 改做什么 |
| --- | --- | --- |
| 你近期会离开这个田野点 | 承诺了回看与共同处置，人却走了；对方只剩一个失联的文件传输 | 只做第一档（回看），且在他同意下把原件留下 |
| 对方正处在急难中（欠薪、纠纷、疾病） | 此刻递上机器等于把表达任务压给最没余力的人，且极易被读成「你要帮我」 | 先做能做的实际事；影像的事等到状态稳定再谈（[弱势群体与儿童](../10-伦理法律/弱势群体与儿童.md)） |
| 涉及未成年人 | 培训、归属、撤回三件事的复杂度都翻倍，且同意结构不由本人完整掌握 | 不交机器，只走监护人同意与分层授权 |
| 场所存在明确的监控与追责风险 | 他手里的机器会变成他的风险敞口，而承担后果的不是你 | 只由你自己拍，且承担全部暴露后果 |
| 你没有可交付的复制件 | 素材原件只有一份而对方要拿走，等于把证据链交出去 | 先解决双备份（[编码存储与备份](../09-技术与设备/编码存储与备份.md)），再谈交机 |
| 你其实只是想要更好的画面 | 这是取用，不是参与；对方会感觉被利用，你无法自证清白 | 老实做委托拍摄，按 §3 谈清楚署名与酬谢 |

**判据一句**：如果你无法在他说「删」的时候删，你就不能给他机器。这不是道德评判，是可执行性检查。

## 6. 这一支在你的五条收益线上落在哪

[../../研究/行动总纲.md](../../研究/行动总纲.md) §3 的五条线里，参与式做法只在两条上直接生效，其余三条它反而是成本——这一点必须承认，否则你会在错的场景上做参与式。

| 收益线 | 参与式的直接作用 | 说明 |
| --- | --- | --- |
| 纪实内容 | 中：素材视角不可替代，但剪辑与沟通耗时 | 唯一稳定的收益是「你拍不到的位置」 |
| 知识付费／研究 IP | 高：它是方法上的差异化，写进说明就成立 | 只有做了归属约定与回看登记，才敢说这一条不是话术 |
| 咨询换单 | 低，且有风险 | 客户在意的是判断力，不是参与度；在写字楼陌拜场景做交机器只会失控 |
| 求职与人脉 | 间接：关系强度上升，但周期长 | 不可当作短期指标 |
| 流量收入 | 不确定 | 平台侧的不稳定与参与式的稳定性要求相互冲突，见 [自媒体分发](../12-发行传播/自媒体分发.md) |

结论【操作性建议】：**把参与式放在长期作品与研究报告上，不放在周更内容上**。周更靠观测式与访谈，长期作品才养得起回看与协商的时间成本。

## 7. 常见误区

1. **把参与式当口号，实际仍是作者独断。** 最典型的形态：对外写「与社区共创」，剪辑表上只有你一个人。这不是修辞过头，是**虚假陈述**，且它会被当事人先发现。
2. **以为交了机器就是交出了权力。** 主题是你定的、清单是你给的、能用哪些还是你筛的——那台机器只是你的另一条手臂。真正的分水岭在决定公开哪一段。
3. **教他怎么拍。** 一旦你的取景标准进去了，这一档的产出就退化成你素材的低质版本。
4. **不做归属约定就借出设备。** 事后所有争议都会变成关系争议，而关系争议没有可核对的凭据。
5. **把集体同意当个人同意用。** 见 §3；厂方签字不产生对工人的肖像授权。
6. **承诺共同剪辑以换取当场配合。** 你此刻拿到的是配合，日后拿到的是无法履行的承诺和一个被你激励出来的错误预期。
7. **把回看当成走流程。** 让对方看完点头，比不给他看更糟：它把「他有机会反对但没反对」写进了你的记录里，而这句话不成立。

## 8. 实操要点

- [ ] 动笔与开口前先自查：这一版里有没有出现「给予能力」「发声」一类的口号而没有说明具体动作；有就替换成 §1 表里的可执行表述。
- [ ] 交机器前完成四件事：最小培训四项、不拍清单三到五条、任务边界一次谈话、素材归属四条约定（含「随时可取回原件」）。
- [ ] 约定非故意损坏不追偿，并当着他的面说出来。
- [ ] 接收素材先做敏感筛，标记不删除，转入 `X_不可发布` 并告知对方筛掉了什么。
- [ ] 承诺第三档前先数 §2.3 的四个条件；不齐就把承诺降级为「一次结构级协商」。
- [ ] 集体表态一律不作为个人同意的替代；可识别的个人逐人有记录，进同意台账。
- [ ] 每季度只在 §4 的三步骨架上加一项试验，一次一项，做完记录后果。
- [ ] 收益与署名问题在第一次交机时谈，不谈也要把「不谈」这个决定写进日志。
