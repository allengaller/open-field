# 观测电影：连续记录作为方法

> 观测电影（observational cinema）是你在这种条件下最可用的一条路：它不要求团队、不打断现场，只要求你守住一条纪律——不指挥、不补拍、不搬动当事人，同时明白「不介入」只是修辞上的克制，不是物理上的中立。

---

## 1. 先破一个误解：不介入 ≠ 不选择

观测电影常被说成「摄影机不动、不说话、不干预」。这三条都是关于**你与事件之间**的关系，不是关于**中立**。你只要开机，就已经做了四个选择，一个都消不掉：

| 你已经做的选择 | 为什么它本身就是介入 | 你唯一能做的 |
| --- | --- | --- |
| 何时按录制、何时停止 | 事件的哪一段被留下、哪一段被丢弃，由你决定 | 把判据写下来，并记录实际停止时间 |
| 站在哪、坐哪 | 位置决定谁能被看清、谁被挡住、谁背对镜头 | 在同一场里少换位置，换要在记录表上写明 |
| 用什么焦段、画幅 | 广角扩大空间关系，长焦压缩并把人放大，两者给出不同的「谁重要」 | 记下所选焦段；避免在事件进行中变焦 |
| 是否入画、是否答话 | 你的存在方式改变现场，你的回答改变下一句 | 统一处置方式，别一会儿在画内一会儿藏起来 |

所以准确的说法是：**观测电影是一种有纪律的选择方式，而不是一种无选择的状态。**
它的价值不在「更真实」，在于**不制造原本不会发生的动作与台词**。

由此推出观测式拍摄的两条边界，这两条比「不喊 action」重要得多：
- **不诱导**：不能为了要一个画面说「你再走一遍」「你刚才那句话再说一次」「你说一句……」。
- **不安排**：不能把人挪位置以改善构图，不能要求某人坐在特定位置，不能推迟或提前一件事来配合光线。

补拍、摆拍本身不是罪，那是另一种方法（见第 2 节）。**错的是在声称观测的段落里做安排，然后在成片里把它当观测呈现**——这是真实契约的违约，参见 [`../01-理论/真实契约.md`](../01-理论/真实契约.md)。

## 2. 观测式的定义范围：哪三种「在场」都算观测

| 类型 | 你的角色 | 现场性质 | 适用 |
| --- | --- | --- | --- |
| 纯记录式 | 在场，不互动 | 自然进行的事件 | 车间日常、交易、会议、仪式 |
| 自述式 | 在场，由当事人自己说 | 无提问的独白 | 讲述工序、指认物件、带你看某处 |
| 互动式 | 在场，你的对话被留下 | 你参与的对话 | 他们主动问你意见、跟你商量 |

第三类最容易被误删。**你参与的对话也是观测材料**——它记录了「他们如何对待一个带着机器的人」，这个信息只有留着互动才拿得到。不要为了形式上的纯粹，把自己从素材里抹掉。

## 3. 连续记录真正的产出是时间序列

很多人以为多拍的价值是「素材量大、挑得出好镜头」。在研究这一侧，价值完全不同：**它把事件的顺序变成了可核验的东西**，而顺序是笔记无法提供的。

| 时间序列留下的东西 | 举例 | 为什么笔记替代不了 |
| --- | --- | --- |
| 完整动作序列 | 一个人先看了哪个货架、和谁对了一眼、才开口报价 | 笔记按记忆分段，顺序常被打乱或省略 |
| 非语言互动的先后 | 老板进门前两分钟说话密度骤降 | 你很难在事中意识到这是「前两分钟」 |
| 因果与前后状态 | 检查人员到达前后同一空间的行为差别 | 前后对照需要同一时间轴上的两段 |
| 沉默与停顿的时长 | 一个问题后有六秒没人接话 | 笔记里的「沉默」不带时长 |
| 同时发声 | 两个人同时说话，谁盖过谁 | 转录时容易被拆成先后 |
| 未完成的动作 | 话说到一半被叫走，之后没回来 | 笔记通常只记「说了什么」 |

这一列的每一项都是**证据形态**，不是你日后一定会剪进片子的内容。这也是观测式拍摄与研究的关系：你提供的不是一段好看的画面，是一条别人可以复查的时间轴。分析框架见 [`视觉社会学.md`](视觉社会学.md) 三层描述，复用方式见 [`田野素材到影像.md`](田野素材到影像.md) 第 3 节。

同时要说清它的代价：以上全部价值**建立在你真的会看回去**。连续记录不留笔记的话，最后只是一堆没人能检索的时间。

## 4. 身体与机位的纪律

| 情形 | 具体做法 | 原因 |
| --- | --- | --- |
| 位置选定后 | 用胶带、地砖缝、脚架标记固定站/坐点 | 便于日后解释画面时精确复述「从何处看」 |
| 事件进行中 | 不移动机位，不跟摇，不手持走动 | 运动镜头会把你变成画面作者，且易造成误判 |
| 需要换视角 | 等事件自然中断，或接受一次明显的移动 | 偷偷换位会破坏画面的空间一致性 |
| 有人挡在镜头前 | 不出声提醒，等人自然走开或接受遮挡 | 提示就是指挥 |
| 光线不好 | 不加灯、不挪人、不改变拍摄时间 | 补光是明显的安排；确需补光须记录并说明 |
| 声音被机器噪声污染 | 先解决收音（换麦位、关风扇挡），不停止记录 | 见第 5 节 |
| 现场要求你出去 | 无条件配合，出去后立刻补记 | 见第 6 节 |

另外两条容易漏：
- **画幅优先固定**：广角能同时保留人和空间关系，观测式拍摄里通常比长焦特写更有信息量。特写是表达，不是记录。
- **不要把镜头对准自己觉得重要的那一个人**：这会使画面变成你的论点。留出带空间的画面，让人在画面里进出。

## 5. 声音优先于画面

这是本章最实际的一条判断：**画面糊了仍有信息，声音丢了事件就没了。**

| 损失 | 还能补救什么 |
| --- | --- |
| 画面失焦、过曝、构图差 | 仍可辨认是谁、在做什么、说了什么；可作为时间序列与证据 |
| 同期声丢失、爆音、只收到机器噪声 | 事件内容基本消失；事后重述是另一种材料，不能顶替 |
| 画面与声音时间错位 | 可修，但要记录；错位超过可修范围则等同声音丢失 |

所以优先级是：**先保声，再保画**。当两者冲突时（例如为了收音必须走近、为了画面必须站远），保声。

对你的眼睛，这条尤其省事：**画面只需偶尔核对**（构图、曝光、是否还在拍），注意力留给现场与声音。把「盯着监视器」当作观测的前提，是把自己累坏且看不见现场的最快方法。核对方法见第 9 节。

声音的采集细节在 [`../04-声音/同期声与收音.md`](../04-声音/同期声与收音.md)，不在此重述。这里只保留一条与观测式直接相关的规则：**每个机位都要有独立的声音轨**（机身麦 + 无线麦 + 现场录音），否则后期无法分辨谁在说话——观测式拍摄的对话常常是多人同时、无提示发生的。

## 6. 「继续录」与「停止」的判断

| 继续录 | 立即停止 |
| --- | --- |
| 事件在自然收尾（人在收拾东西、话头在慢下来） | 当事人明确要求停止 |
| 一句话说到一半被打断 | 出现明显与拍摄无关的私密内容（病历、私人电话、身体） |
| 情绪上升、语速变化、有人开始压低声音 | 涉及未成年人且现场无同意安排 |
| 现场有人进出，空间关系正在变化 | 出现法律风险动作（交易违禁物、明显违规作业） |
| 冲突刚发生、后续沟通正在展开 | 你的身体或精神状态已到无法承担判断的程度 |
| 你不知道会不会结束 | 场地要求你离开 |

| 补充规则 | 说明 |
| --- | --- |
| 事后必须停止时，补一条标记 | 记录表写下停止原因（当事人要求/私密/法律/自身状态），这条记录是伦理链条的一环 |
| 「再录三十秒」原则 | 事件看似结束时多留一小段，很多关键内容发生在「正片」之后 |
| 「先录后想」不适用 | 判断是否继续可以在事中做，但不许为了判断而停机；判断期间机器保持运行 |
| 无法当场决定时的默认 | 继续录，事后标记待审。默认值要固定，否则你会在压力下随机决定 |

## 7. 被提问时怎么办

当事人转向你说话，是最常见也最难处理的时刻。四种处置各有代价：

| 处置 | 你保住了什么 | 你付出了什么 |
| --- | --- | --- |
| 正常回答，被录下 | 关系、真实互动、他们如何对待你 | 你进入画面，事件被你的话改变 |
| 简短回答后不接话 | 事件继续 | 可能被觉得冷淡 |
| 回答但事后剪掉 | 观感上「你没出现」 | **删掉了重要数据**，且构成形式上的不诚实 |
| 沉默不答 | 事件不被你打断 | 关系受损，且沉默本身是一种回应，同样被录下 |

推荐：**默认回答，并把回答留下**。第二种处置只在问题涉及你的判断（例如「你觉得我说的对吗」）时适用——这时含糊或不答本身就是信息。

绝对不要做的一件事：**假装没听见**。它同时损害关系和素材，而且会被拍到。

## 8. 长镜头的代价

观测式拍摄必然产生长镜头。把代价算清，不要事后才发现。

| 代价 | 具体表现 | 缓解 |
| --- | --- | --- |
| 时间成本 | 一件事现场可能是一小时，成片三十秒 | 只在值得的段落用连续录，日常转场用短录 |
| 素材量 | 一天一万多秒，回看需要数倍于拍摄的时间 | 靠日志与音频定位，不靠看 |
| 观众疲劳 | 无剪辑的长时间会让观感掉下来 | 成片保留必要的时长即可，其余留作证据 |
| 体力与注意力 | 单机位长时间不动，判断力在四十分钟后明显下降 | 分段记录，中途允许自然停机 |
| 事后错判 | 长段素材里更容易把不同时段的事混成一件 | 时间码引用必须精确，见 [`视觉社会学.md`](视觉社会学.md) 第 2 节 |

**最关键的一句：长镜头不天然等于诚实。**
一个七分钟的镜头如果被安排在事件之外（让人等机器架好、为了长镜头而推迟开始），它比一个两分钟的自然段落更不诚实。诚实来自「不制造原本不会发生的东西」，与时长无关。
同样，长镜头也不等于完整：它常常意味着你什么都没判断，把判断成本推到后期。

## 9. 近视 + 单机条件下的观测式变通

你的视力条件使「边录边用眼睛核对画面」这项常规要求成本极高。以下是可用的变通方案，不是妥协清单。

### 9.1 声音主导、画面作证（推荐作为默认）

| 做法 | 说明 | 收益 |
| --- | --- | --- |
| 录制期间不核对构图 | 只确认机器在录（见 9.3） | 注意力全部留在现场与声音 |
| 画面只承担作证功能 | 「谁在场、空间什么样、动作顺序」由画面给出，内容判断依赖同期声 | 事后不必逐帧分析画面 |
| 靠音频理解事件 | 回看时先听，只在需要确认位置或动作时看 | 回看成本大幅下降 |
| 位置信息用文字补足 | 记录表写下机位与朝向，弥补你没核对构图的缺口 | 保持可复述性 |

代价：会出现废画面。接受它——**在观测式拍摄里，画面完整度不是首要指标**，事件被录下来才是。

### 9.2 固定机位长录 + 事后检索

| 环节 | 做法 |
| --- | --- |
| 机位 | 提前选一个能覆盖空间入口与主要活动区的广角位置，固定不动 |
| 收音 | 该机位不指望收到对话，因此说话人必须独立佩带麦克风 |
| 录制 | 整个时段一次长录，不做现场判断 |
| 检索 | 先转录音频，用关键词与时间戳定位；只在定位到的段落看画面 |
| 时间锚 | 在长录中制造你自己的锚（在记录表上写时间点，或按下机的打点功能） |
| 适用 | 你无法持续观察的场合、多人分散活动的场合、你需要参与对话的场合 |
| 不适用 | 空间关系本身是研究对象（此时广角固定机位可能恰好够用）；单场事件时长极长（文件与电量限制） |

这套方案的实质是**把「看」的工作量从拍摄日转移到事后，并且只转移给耳朵**。对你的条件是划算的。

### 9.3 用机器状态而不是画面内容来确认在录

| 检查 | 方法 |
| --- | --- |
| 是否在录 | 红灯/电量/剩余容量，用触觉或大字号显示确认 |
| 是否在收音 | 电平表（最实用的眼睛友好型检查：只需判断条是否在动） |
| 卡是否插好 | 开机提示音、录制启动提示 |
| 打点 | 每次现场发生你要记住的事，按下打点键并在表上记同一时间 |

注意：**打点时间要与你记录表的时间对齐**（同一时钟源），否则两套时间对不上。合并的编号与时钟方案见 [`田野素材到影像.md`](田野素材到影像.md) 第 7 节。

## 10. 与直接电影、真实电影的历史差别

| 流派 | 主张 | 技术前提 | 对你的意义 |
| --- | --- | --- | --- |
| 直接电影（Direct Cinema） | 不干预、不提问，作为「墙上的苍蝇」 | 轻便同步录音设备使单机跟拍成为可能 | 方法上的近亲；但其「不介入即客观」的立场已被批评 |
| 真实电影（cinéma vérité） | 主动提问、挑衅，把拍摄当作引发真相的手段 | 同上，但态度相反 | 你如果要做困难采访，走的是这条路，不是观测式 |
| 观测电影（observational cinema） | 承认视角存在，用序列与语境而非「客观」作为主张方式 | 对剪辑与时长要求高 | 本章主体 |

三者关系与更细的历史脉络见 [`../02-历史/直接电影与真实电影.md`](../02-历史/直接电影与真实电影.md)。**这里只保留一句实用结论：不要把这三条路混在同一个段落里声称。** 用观测的方式拍，就承认你的段落是观察；用提问去撬，就承认那是介入。混合声明比任何单一选择都更容易失信。

## 11. 常见误区

| 误区 | 为什么错 | 修正 |
| --- | --- | --- |
| 「我不干预，所以我的素材中立」 | 记录/停止、位置、焦段都是选择 | 承认选择，把选择标准写下来 |
| 「镜头长就是诚实」 | 诚实来自不制造，不来自时长 | 检验是否为了长镜头安排了事件 |
| 「画面清楚最重要」 | 同期声丢了事件就没了 | 声音优先，画面作证 |
| 「我的回答不重要，剪掉」 | 他们如何对待你正是数据 | 保留互动，别抹掉自己 |
| 「连续录了很多就是研究做完了」 | 不检索、不编码的记录只是存储 | 每段长录必须有定位手段 |
| 「观测式就是什么都不做」 | 判断是否继续、是否离场都是主动决策 | 用第 6 节清单承担判断 |
| 「补一句拍没拍到无所谓」 | 事后补问的话不能顶替当时未说出的话 | 若确需补问，标注为回应式提问 |
| 「假装没听见能保持中立」 | 沉默也是一种回应，且伤关系 | 默认回答并保留 |

## 12. 实操要点

- [ ] 每个拍摄单元开始前定好：机位、焦段、是否入画、声音配置，写在合并记录表上。
- [ ] 遵守两条硬边界：不为画面说「再来一遍」，不为构图挪人。
- [ ] 需要补光、挪机位、改变事件时点时，当场记录并在图注/素材表中标为安排而非观察。
- [ ] 先保声后保画；每个机位有独立声轨；电平表作为主要核对手段。
- [ ] 用 9.1 作为默认模式：不核对构图，画面只作证，回看时先听。
- [ ] 多人或分散场合用 9.2：广角固定长录 + 说话人独立麦 + 转录后按关键词检索。
- [ ] 停止录制的六种理由各记一次实际案例，形成自己的判据；每次停机在记录表写原因。
- [ ] 事件看似结束后默认再留一小段，并在日志中注明这段是「收尾段」。
