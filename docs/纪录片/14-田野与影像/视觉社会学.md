# 视觉社会学

> 影像作为研究证据，不是「拍到了就用」，也不是「写得漂亮就行」。这一篇给的是分析方法：一份画面怎么被拆开、被编号、被分层、被引用、被质疑。这是你和「只做片子的人」之间真正的差距所在。

---

## 1. 影像资料的两种身份

同一段素材可以同时是两种东西，混着谈是最常见的错误。**先确定你现在按哪一种身份处理它**，后面的操作规则完全不同。

| 身份 | 作为田野记录 | 作为文化产物 |
| --- | --- | --- |
| 它是什么 | 论证材料：证明某事在某一时刻如此发生 | 研究对象本身：一件被制作、被流通、被观看的东西 |
| 要问的问题 | 可见的是什么、能推到哪一步、和哪条判断有关 | 谁拍的、给谁看、为什么这么排、发行后谁反应了 |
| 有效性依据 | 采集条件可交代、时间码可回查 | 制作与流通的条件本身构成解释对象 |
| 典型误用 | 把它当「事实本身」，不问产生条件 | 拿它当证据去证明外面的世界，而它只证明了这个作品的存在 |
| 你的对应场景 | 工厂作业序列、菜市场交割、陌拜现场 | 企业宣传片、平台上的工地短视频、监控画面、他人替你拍的部分 |

**第二种身份是你自己项目里最容易被漏掉的一块**：一个村把来访者拍成什么样的宣传片、一家公司在年会上放什么样的短片、工友自己在抖音上怎么拍自己——这些不是你的旁证材料，它们就是研究对象：一个群体如何呈现自己、以及他们预期的观看者是谁。这条与 [相机在场效应](./相机在场效应.md) 的「观众想象」直接接得上。

【操作性建议】给每段素材的日志加一个 `身份` 字段，取值 `RECORD`／`ARTIFACT`／`BOTH`。标 `BOTH` 时必须写两句：一句说它证明了什么，一句说它是谁为谁做的。

## 2. 画面分析的三层分离法

三层必须**分开写**。混写是这套方法里最常见的不严谨，而且它一旦被指出，整批材料的可信度连坐。

| 层 | 名称 | 允许出现的话 | 禁止出现的话 | 例 |
| --- | --- | --- | --- | --- |
| 一 | 可确认的物理事实 | 数量、位置、姿态、物件、可见文字、声音事件 | 形容词、动机、评价 | 「画面左起第二人背对说话者，距离约一步半；桌上有六只碗」 |
| 二 | 可辨认的行为与交互 | 谁对谁做了什么、轮次、动作序列、可听到的语调变化 | 因果、意图 | 「A 说话时 B 三次插话，三次均未完成句子；A 未停顿」 |
| 三 | 需要外部信息才能成立的解释 | 明确标为推断，并写出依赖哪一条外部信息 | 冒充第一、二层 | 「推测这是班组内的非正式分工（依据：同日另一场访谈中 A 自述……）」 |

[影像民族志案例](../13-案例/影像民族志案例.md) §2 给出的三列报告格式（编号／可见／推断）是本法在图文报告里的最简版；本篇把它扩到分析全过程，并加上第三层的**外部信息登记**这一硬性要求。

第三层的操作细节：

- 每条解释后面必须跟一个括号，写明它靠什么成立：另一段素材（给编号）、访谈（给编号与时间码）、文件（给名称）、你自己的现场笔记（给笔记编号）、领域文献（给条目）。
- 括号填不出来的解释，就是无根据猜测，不进报告。允许它进研究备忘录，标注为待查。
- 第二层与第三层的边界最容易失守，典型句式是「他显然不情愿」「看得出来是在敷衍」。**「显然」一词在本库分析稿中禁用**：它出现的每一处，都是在把第三层偷渡进第一层。

## 3. 图像序列与截图在报告里的使用规范

| 项 | 规则 | 不做会怎样 |
| --- | --- | --- |
| 编号 | 沿用素材命名（`D03_S12_A_1430`），引用时补起止时间码；一条引用只指向一个可回查文件 | 读者无法核对，等于没引 |
| 时间码 | 一律 `文件编号 #Tmm:ss`（与 [../../工程/架构.md](../../工程/架构.md)、[../../田野方法/09-写作.md](../../田野方法/09-写作.md) 同格式） | 平台链接会失效，编号不会 |
| 截图 | 必须来自被编号的原始文件；截图文件名保留源时间码；不得二次修图 | 截图脱离源即不可追问 |
| 图注 | 三句话结构：这是什么场景／画面里可见什么（第一层）／作者用它说明什么（第三层，标为推断） | 图注写成品德描述，读者自行加戏 |
| 序列 | 多帧并置须标每帧时间码与间隔；跨时段并置必须交代跨度 | 「三张照片」被读成「同一时刻的三个角度」——这是伪造 |
| 许可声明 | 每张图标注可否公开、是否需模糊、授权档位；不可发布者不进交付包 | 交付即违约 |
| 引用格式 | 影像作为文献引用时给：作者／标题／制作年份或范围／载体与时长／可获取方式；本库不断言他人片目的具体年份，写不出就不写 | 引不出处的影像，评审按传闻处理 |
| 附包 | 图文报告与片子的引用清单一起进交付附包 | 见 [交付母版与规格](../08-剪辑后期/交付母版与规格.md) §2 |

**跨时段并置是这套规范里唯一会真正毁掉你的一条**：把三月的市场和十一月的市场并排放在一页上，构成一个未声明的断言「市场一直如此」——这个断言你没有证据。规则：**并置即主张，主张须标注**（原理在 [真实契约](../01-理论/真实契约.md) §4 第 3、4 项，本篇不重述其论证）。

## 4. 把影像接入编码与主题分析

影像不是不能编码，是不能**整段**编码。可用的操作路径是把画面变成可定位的文本单元，再进正常编码流程。

| 步 | 做法 | 与已有方法的接口 |
| --- | --- | --- |
| 一 | 转写与描述：音频出转写（方言按 [../../田野方法/05-访谈.md](../../田野方法/05-访谈.md) §8 处理），画面部分写第一层描述，逐段挂时间码 | 描述即速记的成文版，见 [../../田野方法/04-观察与笔记.md](../../田野方法/04-观察与笔记.md) §3 |
| 二 | 以时间码段为最小分析单位（不是一整个文件，不是一整个场景） | 一个 Artifact 多段引用，与 `OF-…#Tmm:ss` 一致 |
| 三 | 开放编码在描述文本上做；画面本身只做核对，不做编码对象 | 编码类型与流程见 [../../社会学田野/08-分析/主题编码.md](../../社会学田野/08-分析/主题编码.md) |
| 四 | 视觉专属维度单独一组码：在场者构成、身体朝向、距离、可识别物、可见文字、镜头与设备状态 | 这一组是你的自研码本，进备忘录（[../../田野方法/06-分析.md](../../田野方法/06-分析.md) §6） |
| 五 | 主题层面把视觉材料与访谈、笔记、文件并列比较（同一主题下的三种证据） | 三角验证，见 [../../田野方法/08-信效度.md](../../田野方法/08-信效度.md) |

**核心提醒**：编码的是你的**描述**，不是画面。因此描述质量决定分析质量，而描述受 §2 三层分离法的约束。这也是为什么这套方法要求你写第一层写到手酸——它是可复核性的地基。

数字场域里自产影像（平台短视频、群聊图片）的分析，本库不重述，见 [../../社会学田野/06-数字/数字民族志.md](../../社会学田野/06-数字/数字民族志.md) 与 [网络民族志](../../社会学田野/06-数字/网络民族志.md)。

## 5. 照片启发式：让影像成为访谈刺激物

**图像引谈（photo elicitation / photo-elicitation interview）**：不是你自己分析画面，而是把画面交给当事人，请他讲。它把解释的主动权交出去一部分，因此它能问到你看画面永远问不到的东西。

| 用法 | 具体操作 | 适合问什么 | 风险 |
| --- | --- | --- | --- |
| 看你自己拍的 | 给他看一段现场画面，请他描述「这里发生了什么」 | 你不理解的流程、规矩、人物关系 | 他会顺着猜你想听什么（另述，见 [相机在场效应](./相机在场效应.md)） |
| 看他自己的位置 | 请他指认「这张里哪个是你、你在做什么、你为什么在那儿」 | 分工、可见性、谁被排除 | 涉及他人时先做模糊处理再问 |
| 看别人拍的 | 拿同业的视频、平台上的工地短片、企业宣传片给他看 | 他们如何想象自己的行业被观看；对「谁有权这么拍」的看法 | 别把某张具体可识别他人的图直接投屏给一群人看 |
| 看旧素材 | 拿几个月前的片段请他重新讲当时 | 变化、前后不一致、他此刻的解释 | 时间码与场次必须当场记录，否则引用错位 |
| 看照片阵列 | 一组编号照片摊开，请他挑「最像这里的三张」并说理由 | 群体的自我评价与内部差异 | 挑图理由比挑图结果更有价值，务必追问「为什么不是那张」 |

问法要点与访谈通用规则一致，见 [../../田野方法/05-访谈.md](../../田野方法/05-访谈.md) §4；影像一侧的额外一条：**问画面，不要问结论**。「这不对吧」会诱导否定，「这一处我没看懂，你能说说吗」不会。

## 6. 视觉材料的信效度：你该怎么交代不确定性

| 问题 | 本库的处理要求 |
| --- | --- |
| 可观察性等级 | 每个判断标等级：直接可见／可听得到／需推断／不可知。与 [解说词写作](../05-叙事结构/解说词写作.md) §8 的证据分级同一路数，报告侧沿用同一套标记以免两套并立 |
| 观察者推断 | 你写下的每一句关于关系的判断都要自问：这句话是我看出来的，还是我从别处知道再回填到画面上的？后者必须显式声明（这是反身性日志的内容，见 [../../田野方法/08-信效度.md](../../田野方法/08-信效度.md)） |
| 可复核性 | 别人拿着你的编号与时间码，能不能看到同样的东西？能，才算一条证据；不能，算一句感想 |
| 单例问题 | 一段素材证明「发生过」，不证明「常见」。写「我见过两次」和写「通常如此」是两种句子，后者需要计数或其他来源支撑 |
| 在场造成的失真 | 相机改变了什么，必须随素材一并交代（专篇 [相机在场效应](./相机在场效应.md)），这是视觉材料特有的一条效度威胁 |
| 不确定性交代 | 三层分离法的第三层与 §2 的外部信息括号，就是你的不确定性交代机制；不要写成「可能」「或许」这类无法核查的软判断 |

信效度四标准（可信性、可转移性、可靠性、可印证性）及其操作化，本库在 [../../田野方法/08-信效度.md](../../田野方法/08-信效度.md) 已成篇，此处只补一条视觉侧的增量：**对影像而言，「可审计的决策链条」的最小单位是时间码，不是页码。**

## 7. 写作时的呈现选择

厚描（thick description）与画面细节的关系经常被误解为「有画面就不用写」，或「写了就不用给画面」。两者是互相支撑，且**各自补对方的短板**。

| 目的 | 靠画面 | 靠文字 | 组合要求 |
| --- | --- | --- | --- |
| 传递身体技术、节奏、距离 | 强 | 弱 | 文字给出该看哪一处与时间码，画面负责被看 |
| 传递语境前提与未说出口的判断 | 无 | 强 | 画面在此处可以撤，不要为了配图而配图 |
| 建立可复核性 | 强（有编号） | 中 | 每个关键判断都要有一个能查的对象，图或文皆可 |
| 让读者感受现场 | 中 | 强 | 细节的选取规则比数量重要：选能承载关系细节的那一个 |
| 承载因果与制度 | 无 | 强 | 影像不承担因果论证（见 [田野素材到影像](./田野素材到影像.md) §3） |

厚描的写法与引语处理规则本库已详述，见 [../../社会学田野/09-写作/民族志写作.md](../../社会学田野/09-写作/民族志写作.md) §3；学术写体的引用规范另见 [学术写作](../../社会学田野/09-写作/学术写作.md)。本篇只加一条视觉侧的纪律：**图不代替论证，图不重复正文**。同一句话在图注里再说一遍，等于既浪费版面又制造了两次可能不一致的机会。

## 8. 常见误区

1. **读图过度。** 一张照片看出权力结构与集体无意识，多数是分析者的能力表演，不是材料的主张。判据：第三层解释填不出外部信息括号，就是过度。
2. **把画面当证据链终点。** 时间码不是结论，它只是让结论可以被查。终点的格式是「主张—证据—推理」三段齐备。
3. **用截图制造未发生的因果。** 两帧并排即是一个因果暗示。这是本领域最常见的造假形式，且做的人往往自认为只是「排版」。
4. **让截图脱离源文件。** 一张无编号的截图在报告里的证据价值低于一句有笔记编号的描述。
5. **整段视频进编码表。** 编码单位必须是可定位段；「这条素材讲加班」不是编码，是归档。
6. **用形容词代替第一层描述。** 「疲惫的神情」不可核对；「第三次坐下后没有再站起来，双手放在桌上未动」可核对。
7. **把当事人对自己画面的反应当结论。** 图像引谈拿到的是他的解释，不是事实的另一半；两种解释并置时不要替你选边，把选择写进备忘录。
8. **两套证据分级并行。** 报告一套、片子一套，最后互相引用不上。统一用一套标记。

## 9. 实操要点

- [ ] 每段素材日志补 `身份`（RECORD/ARTIFACT/BOTH）与「谁为谁制作」两项，标 BOTH 时写两句。
- [ ] 分析稿一律按三层分离书写，第三层每条解释带外部信息括号；出现「显然」就重改那一句。
- [ ] 图像引用统一 `文件编号 #Tmm:ss`；跨时段并置必须在图注写明跨度。
- [ ] 编码前先做转写与第一层描述，以时间码段为最小单位；视觉专属维度单独一组码。
- [ ] 每个关键判断配一个可回查对象；无法配出的判断降为备忘录里的待查项。
- [ ] 每月一次随机抽 5 条已发布断言，回查其时间码段，看画面是否真能支撑那句话——这是你唯一自费的同行评审。
- [ ] 图注三句话结构固定：场景／可见（第一层）／用它说明什么（标为推断）。
- [ ] 交付附包收录像引用清单与许可状态，与 [交付母版与规格](../08-剪辑后期/交付母版与规格.md) §2 对齐。
