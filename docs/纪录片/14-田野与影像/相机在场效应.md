# 相机在场效应

> 摄影机不是中立的记录装置，它是现场的一个新变量。本篇讲这个变量按什么机制起作用、你能把它压到多低、以及必须承认它存在时怎么写下来。这是全章最难的一篇，也是你每周都会撞上一篇。

---

## 1. 问题的准确表述

常见的错误表述是「镜头让人紧张」。它对，但它解释不了你现场真正看到的三件事：

- 有人在机器开着时说得比平时**更多**，而不是更少。
- 有人在机器开着时说出的话，明显是说给某个不在场的人听的。
- 同一个人在你一个人来时和带着机器来时，对你**态度不同**，但对内容同样经过筛选。

所以准确的表述是：**摄影机改变了现场的可见性结构**——它让在场的人意识到自己正在被记录，而「被记录」意味着被一个此刻不在场的、身份不明的观看者看到。人们会针对那个观看者说话。这个机制比「紧张」强得多，而且它可以解释上面三种现象。

质性研究里有一组相邻的概念，边界要分清，否则容易把两件事混成一件：

| 概念 | 通行含义 | 与相机在场的关系 |
| --- | --- | --- |
| 观察者效应 | 被观察本身改变被观察者的行为 | 相机是它的一种强化形式（因为你不能假装不在看） |
| 社会期望偏差（social desirability bias） | 受访者给出符合预期规范的答案 | 相机把「预期规范是谁」这个问题具象化了——见 §3 |
| 霍桑效应（Hawthorne effect） | 因受到关注而改变表现 | 常被泛用；其原始出处是工厂生产效率研究，且后世对「究竟证明了什么」有明确争议。本库只在「因被注意而改变」这一最窄含义上使用（【通行共识】，**原始实验的结论请复核，勿据此引用于正式报告**） |

## 2. 习惯化（habituation）：曲线形状与判断方法

**习惯化（habituation）**：在场者对新元素的注意力反应随重复暴露而衰减。[长期跟拍](../07-拍摄执行/长期跟拍.md) §4 已经把田野关系中摄影机角色的四阶段（好奇—习惯—无视—依赖）写成表，此处不重复；本篇只补三件那张表没有的事。

**第一件：曲线高度依赖场所与人数，不给天数。** 常见说法是「第三天就自然了」——这类伪精确在真实田野里不成立。至少要按下面四个变量调形：

| 变量 | 影响方向 | 为什么 |
| --- | --- | --- |
| 场所的日常性与拥挤度 | 人多、节奏快的场所衰减更快（没人有空管你的机器）；安静、少人的场所慢得多 | 注意力是稀缺资源，人多时相机抢不过生意 |
| 你的身份是否已经稳定 | 已被当作「常来的那个人」→ 快；每次都被重新介绍 → 慢，且每次回访都要重走一遍 | 习惯化的对象首先是**你**，其次才是机器 |
| 机器的可见性与体积 | 越小越安静衰减越快；大三脚架、外置麦、补光灯会持续拉回注意力 | 见 §5 |
| 是否存在利益相关者 | 有老板、房东、客户在场时，习惯化几乎不发生，且会倒退 | 见 §4 |

**第二件：习惯化会倒退。** 四个确定的倒退触发点：来了新面孔；项目被第三人评价（「你还在拍啊」）；你答应过的事情没做到；作品的一个版本发布了。特别是最后一条——**发布是一次全站重置**，之后的一到两周你要按早期状态对待现场。

**第三件：判断「现在自然了吗」的三个可用信号**（不要看天数，看这三条）：

- 有人当着机器抱怨你、催你、让你让路——他们不再管理自己在镜头前的形象。
- 有人忘记调整你的机位方向，直接在你面前走过。
- 出现了**与你研究问题毫无关系、也不提供任何好看内容的段落**：无事发生的三十分钟。这条最可靠，因为它没人会演。

【操作性建议】习惯化的正确预期是：你会得到一批**干扰较少的素材**，永远得不到**无干扰的素材**。因此方法上的要求不是等到完美再拍，而是每批素材都标注拍摄时处在哪个阶段（场记表加一项），让后期和读者按阶段读它。

## 3. 观众想象（imagined audience）：本篇的核心机制

当事人说出的话里，有一部分不是对你说的，是对他想象中的一个观看者说的。这个观看者可以是邻居、老板娘、老家的父母、前同事、未来的自己、或者「网上的人」。

| 他想象的观众 | 现场表现 | 素材里的形态 | 你的正确用法 |
| --- | --- | --- | --- |
| 同村／同厂的人 | 维护体面、否认困难、强调自己混得不差 | 夸耀、抢先答、话术化 | 记为「呈现」的证据，不记为处境的证据 |
| 雇主／管理者 | 谨慎、留后路、避免被识别 | 答一半、突然改口、要求关机 | 别追；这是权力关系，不是配合度问题 |
| 家人 | 报喜不报忧、跳过风险 | 大段跳过关键环节 | 事后一对一补访，不要当场戳 |
| 平台上的陌生人 | 找镜头、给金句、要梗 | 明显为剪辑准备的话 | 这类话往往是最不可复用的；标为表演段 |
| 未来的自己 | 陈情、留证据、交代立场 | 极长的独白、指名时间地点 | **可能是最有史料价值的部分**，值得逐字转写 |
| 你（想象中的你） | 迎合你的假设、给你想听的答案 | 用你的用词回答你的问题 | 反身性检查项；迎合本身记为材料 |

**为什么这一条比「镜头让人紧张」解释力强**：紧张是无对象的，只解释抑制；而田野里最普遍的现象是**表达的增加与调整**——他要说给某人听。识别出他想象的那个观众，你等于拿到了他所属群体的规范清单：他觉得谁有权评判他。这件事本身就是一个研究结论（此处与 [../../社会学田野/06-数字/数字民族志.md](../../社会学田野/06-数字/数字民族志.md) 的自我呈现讨论相接）。

【操作性建议】现场只问一个问题就够：「你觉得谁会看到这个？」他的回答会告诉你他想象中的观众是谁。这个问题在**开机前**问比在回看时问更有效，因为答案本身就是你今天拍摄方式的说明。

## 4. 权力关系放大效应

相机不是平摊地作用于每个人，它按现场已有的权力梯度加重。最典型：**老板在场时员工说的话，不是平时说的话**——这条与「镜头」关系不大，与「谁看着谁」关系极大，但相机把这件事永久固定了下来，因而放大了它。

| 放大器 | 机制 | 现场处置 |
| --- | --- | --- |
| 记录感即「留证感」 | 员工怀疑自己的话会被拿去对质 | 明说留存与不外发；仍不安心则关机谈（可信度不由你宣称，由你关机证明） |
| 上位者的表达欲望更强 | 老板、房东、工头更习惯面对镜头，占据更多时长 | 素材统计里做发言时长核算，别默认时长多等于材料多 |
| 下属在镜头前被代表 | 领导替员工回答 | 每次都要单独问一句本人；单独问的时候关机 |
| 许可的错置 | 场地方的同意被当成个人的同意 | 结构性问题，见 [参与式影像](./参与式影像.md) §3 关于集体同意的限度 |
| 对抗性场景 | 你手里的机器在对方眼里是威胁或筹码 | 技术与话术一律以 [困难采访与对抗性采访](../06-采访方法/困难采访与对抗性采访.md) 为准，本篇不重述 |

一句判断【操作性建议】：**同一句话在有权者口中与在无权者口中，证据分量不同；同一句话在有权者在场与不在场时说的，属于两段不同的材料。** 日志里要分开编号，不可合并为一条引语。

## 5. 设备、声音、红点、你的视线：在场感的来源与降低

| 来源 | 为什么它持续制造在场感 | 降低办法 |
| --- | --- | --- |
| 体积与外形 | 三脚架、稳定器、兔笼、外置麦克风都是「专业身份」的宣告，人会自动调整对你的称呼 | 小机身、少附件；能不上架就不上架（器材取舍见 [摄影机与镜头选择](../09-技术与设备/摄影机与镜头选择.md)） |
| 快门与马达声 | 声音提示「此刻正在录」，让人按录制周期管理自己 | 静音快门／无机身马达方案，或干脆用独立录音机＋安静机型（见 [同期声与收音](../04-声音/同期声与收音.md)） |
| **红点与录像指示灯** | 这是现场最被盯着看的一个元素；它的亮灭直接改变语速与用词 | 不要用胶带遮蔽或用关闭显示的办法骗过在场者（这等于隐蔽拍摄）。要么正大光明录，要么关机；实在需要小机位时把机器转向不显眼角度，**但仍要告知在录** |
| 补光灯 | 宣告拍摄正在进行，且改变场所性质（别人会绕开这块光） | 优先用现场光与环境光（见 [非虚构摄影](../07-拍摄执行/非虚构摄影.md)） |
| **你的视线** | 你看屏幕时，你在场感最强，因为你的注意力被观察到离开了人 | 看人不看屏（近视条件下的做法见 [观测电影](./观测电影.md) §9）；开机确认后交给机器 |
| 你的记录动作 | 掏笔记本、按表、频繁看时间，都比机器更显眼 | 把动作合并：一次开机、一次记场记，不在谈话中间做 |
| 围观者 | 机器引人围观，围观把现场变成一次事件 | 提前筛掉凑热闹的人（见 [长期跟拍](../07-拍摄执行/长期跟拍.md) §4 好奇期处置） |

## 6. 关掉机器之后的那二十分钟

最重要的话常常不在素材里。这不是段子，是结构：最敏感的内容需要**证据之外的东西**——他得确认说了不会有后果，而唯一能向他证明「此刻不会被记录」的动作，是你当面关机、拔卡或翻过机器。**这件事只能你做，机器做不了。**

| 处置 | 具体做法 |
| --- | --- |
| 立刻补笔记 | 停机后当场写，不要留到路上。写：谁说的、大致原话（标为转述）、他说这话时是关机后第几分钟、你问了什么才引出来的 |
| 硬标注 | 笔记首行加一个固定标记 `OFFREC`，与素材编号并列，永不省略 |
| **不得作为可发布引语** | `OFFREC` 内容不进口播、不进解说、不进字幕、不做截图引用。要用，必须在他知情的前提下**重新取得一次可发布的说法**（重述即新素材，另编号） |
| 可以用于分析 | `OFFREC` 参与编码与主题构建，也可作为线索去指导你下次开机问什么。它是研究材料，不是发表材料——这条界线不可糊 |
| 可以用于自证 | 当有人指称你「断章取义」或「他明明不是这个意思」时，你的 `OFFREC` 记录说明你知道有他没说的部分。这提高你的方法可信度，但引用它需要他再次同意 |

**为什么不干脆全程录**：这是新访客最常有的冲动，也是这个项目最快的结束方式。把「全部记录」当安全感来源，等于要求当事人永远不关闭节。你不需要更长的录制时间，你需要**更清楚地区分可发布与不可发布**——上面那套标记就是干这个的。

## 7. 什么时候相机在场是不可接受的

以下六类，判据不是「画面好不好」，而是**继续录会让一个人承受他事后无法撤回的后果**。

| 情形 | 判据 | 现场动作 |
| --- | --- | --- |
| 私密哀恸 | 哭到失去自我呈现能力、家属明确表示不想被记住这样 | 立刻停机，且不当场解释「这对片子很重要」 |
| 身体 | 伤病、身体检查、如厕、更衣、裸露；病历与药袋特写亦算 | 不拍；已在画面内的转 `X_不可发布`（做法见 [素材管理与日志](../08-剪辑后期/素材管理与日志.md) §6） |
| 违法风险 | 正在进行的违法行为、被要求出示许可、有人反手拍你 | 停机优先，人身安全高于素材（见 [不可重复事件现场](../07-拍摄执行/不可重复事件现场.md) §5、§9） |
| 当事人已明确表示不适 | 说过一次「别拍这个」以后同类情形，不需要再问第二次 | 关机；并在日志记一条「他在哪一处要求停」 |
| 无有效同意的第三方 | 画面里可识别的人没有档位记录 | 事后处理不能替代现场避免；不确定的段落默认不公开（[知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md)） |
| 你自己在失控状态 | 愤怒、恐惧、极度疲惫时你的判断不再服务于现场 | 停机、离场、冷静后再决定今天是否继续（[一人团队与单机作业](../07-拍摄执行/一人团队与单机作业.md) §9） |

## 8. 与参与观察的关系

相机在场效应不是田野方法之外的一个新问题，它是**参与观察里「参与程度」这条轴上的一个变量**。你在多大程度上被当作参与者、在多大程度上被当作记录者，决定了现场把你算进哪一类人。分类与角色伦理见 [../../社会学田野/03-方法/参与观察.md](../../社会学田野/03-方法/参与观察.md) 与 [../../田野方法/03-进入田野.md](../../田野方法/03-进入田野.md) §3；本篇不重述那套分类，只加一条：**带机器时你的参与程度会被低估**——现场倾向于把你归为「来采风的」，而不是「常来的那位」，这会推迟 §2 的习惯化，也会改变他们对你承诺的严肃性评估。对策不是藏机器，是把承诺做小做具体并逐条兑现。

## 9. 在场效应记录法：你自己的对照

这是本篇唯一要求你长期执行的动作，成本每天两分钟。

| 项 | 做法 |
| --- | --- |
| 频次 | 每次拍摄日结束前一条，不补写（补写等于污染） |
| 固定问句一 | 「今天哪些话是因为我在拍才说的？」——逐条列，一句一行，写清是谁说的 |
| 固定问句二 | 「今天哪些话明显是说给某个不在场的人听的？我猜那个观众是谁？」 |
| 固定问句三 | 「今天有没有因为我的机器而没说的事？」（沉默也要记，格式：`未说-谁-大约何时`） |
| 归档 | 进反身性日志，与田野笔记分开；分析时可与 `OFFREC` 笔记对照 |
| 月度对照 | 每月回看：这批「因为我在拍才说」的话，是否比「关机后说的」更接近我最初的假设？如果是，说明你在被迎合，不是被说服 |

【操作性建议】这张记录表是本章与 [../../田野方法/08-信效度.md](../../田野方法/08-信效度.md) 反身性日志要求之间的接口：**你不消除在场效应，你把它变成一份可查的材料。**

## 10. 常见误区

1. **把镜头当成透明。** 「他们都不理摄像机了」这句自豪的话，唯一确定含义是你失去了观察他们如何处理被拍摄这件事的机会。
2. **把表演当成作假。** 人在被看见时如何呈现自己，本身就是研究对象（与 [后纪录片](../01-理论/后纪录片.md) 的表演性讨论相接）。把它判为「不真实然后丢掉」，等于扔掉了 §3 整张表的产出。
3. **把不干预当成中立。** 见 [观测电影](./观测电影.md) §2；在场效应是条件，不是可以靠良好意愿取消的属性。
4. **等到自然了再开机。** 结果是你永远不开机，或者第一次开机就撞上最不该拍的段落（届时你会更没有处理能力）。
5. **用遮蔽指示灯换素材。** 这是隐蔽采集的变体，本库不提供任何此类做法；且一次被发现，你在该场所的全部授权同时作废。
6. **把关机后的话当素材用。** 它没有同意结构支撑；它对你的用处是让你知道往哪儿问。
7. **以为在场效应会随时间单调下降。** 会倒退，尤其是发布之后（§2 第二件）。
8. **统计发言时长时不加权力维度。** 最长的那段话往往来自最有底气说的人，不来自最懂这件事的人。

## 11. 实操要点

- [ ] 场记表加两项：当日习惯化阶段（好奇／习惯／无视／依赖／倒退）与「有利益相关者在场」（是／否，是谁）。
- [ ] 开机前问一句「你觉得谁会看到这个」，记下答案，作为这批素材的观众说明。
- [ ] 现场动作合并化：一次开机、一次记场记；确认后看人不看屏。
- [ ] 停机后二十分钟内的笔记一律首行标 `OFFREC`，且永不作为可发布引语；要发布就重新取一次可发布说法并另编号。
- [ ] 遇到 §7 六类情形立即停机，先停再解释，不承诺「这段我不会用」之外的任何事。
- [ ] 每个拍摄日结束写一条在场效应记录（§9 的三个问句），不补写。
- [ ] 每月一次月度对照，检查自己是否在被迎合；每季度一次查有无「因发布而倒退」未记录的情形。
- [ ] 有权者与无权者、及其在场与不在场时说的同一件事，分开编号，永不合并成一条引语。
