# 世界经典案例

> 这一篇不按年代、也不按国别排片，只按你身上真实发生的卡点排。每一条的落点是一句话：**它在什么约束下做了什么选择，代价是什么，你在什么条件下可以照抄、什么条件下照抄必死。**

理论、史实与判据一律在 [01 理论](../01-理论/理论谱系.md)、[02 历史](../02-历史/起源与三大源头.md)、[10 伦理法律](../10-伦理法律/伦理总论.md) 里已经写过，本篇不重述，只讲片例。证据等级标法见 [体例与证据等级](../00-总览/体例与证据等级.md)。

## 1. 如何开头：把一个人的劳动过程完整交给你看

**片例**：《北方的纳努克》（*Nanook of the North*，Robert Flaherty 弗拉哈迪，1922）。

| 项 | 内容 |
| --- | --- |
| 约束 | 无声片时代，没有同期录音、没有解说可用；胶片贵、拍摄者一人一队；观众对因纽特人毫无概念 |
| 选择 | 不解释文化，只给一件完整的、可看懂的事：**造一座冰屋、猎一次海豹、布一张网**。用字幕卡断句，用劳动过程本身当结构 |
| 代价 | 为了拍得清楚，冰屋切掉一半顶、猎捕在可控条件下重演；把一个人当成一个民族的样本，从此背上「摆拍」与「代言」两笔账，被后来的人类学长期批判（详见 [影像民族志案例](./影像民族志案例.md)） |
| 可迁移 | 你第一集不知道拍什么时，**拍一件完整的事**：从开门到收摊、从领料到出货。观众不需要理解你的对象，只需要看懂一个动作的起止 |

弗拉哈迪后来的《阿兰人》（*Man of Aran*，1930 年代）与《路易斯安那的故事》（1940 年代末）把同一手法换了场景，代价也一样：为了让「真实」好看，必须事先安排真实。这条路线到今天仍然有效，因为它解决了纪录片最贵的问题——**没有解说时靠什么推进**。答案是靠过程的完整性。

照抄条件：你有的是时间，且被摄者的动作本身有可读的节奏（重复、有起止、有可见的结果）。
照抄必死：现场不可控（事故、谈判、突访），或动作内核对当事人重要、对外人无关；这时硬套「完整劳动过程」只会得到一段十分钟的无聊工序。

## 2. 摄影机如何面对苦难：三条路线，三种代价

同一处境（别人在受难，你端着机器），史上有三条清晰分岔。它们不是风格差别，是**伦理取舍的三种定价**。

| 路线 | 片例（大致年代） | 做了什么 | 代价 |
| --- | --- | --- | --- |
| 宣教式 | 英国纪录片运动，约翰·格里尔逊（John Grierson）一脉，《漂网渔船》（*Drifters*，1920 年代末）、《夜间邮车》（*Night Mail*，1930 年代中期） | 把个体的劳动与困苦剪进一个集体叙事，配音乐与（后期版本的）解说，指向「值得尊敬、应当支持」 | 人成为论据。常见读法是它把工人拍成了荣誉化的符号，而不是有诉求的人；一旦你替对象定义了他为什么值得同情，你随时可以替他定义别的 |
| 观察式克制 | 直接电影（Direct Cinema）一脉，梅索斯兄弟《推销员》（*Salesman*，1960 年代末）、《灰色花园》（*Grey Gardens*，1970 年代中期） | 不提问、不解说、不配乐，让处境自己渗出意义 | 看似中立，实则把「不介入」变成一种立场；观众会问「他为什么不放下机器去帮忙」。参见 [直接电影与真实电影](../02-历史/直接电影与真实电影.md) |
| 介入式提问 | 真实电影（cinéma vérité，术语通常归功于让·鲁什与埃德加·莫兰），《夏日纪事》（*Chronique d'un été*，1961）；以及迈克尔·摩尔《罗杰与我》（*Roger and Me*，1980 年代末）把作者本人写成追讨者 | 摄影机是挑衅器（provocateur）：提问、把机器亮出来、拒绝被拍者去追问 | 你的意图压过对方的材料；一旦失去证据纪律，就从记录滑成主张。摩尔路线的常见争议正是「论点先于事实」 |

**给你的定价表**：单机一人、长期跟拍、拍的是工厂与城中村的困窘——三条路线你只能主要走第二条，在极少数场合用第三条（且必须留下提问的原话），完全不要第一条（专题片的语法在中国观众那里已被用坏，见 [电视专题片传统](../02-历史/电视专题片传统.md)）。伦理侧的硬线在 [弱势群体与儿童](../10-伦理法律/弱势群体与儿童.md)。

## 3. 极少技术手段承载极复杂结构

**片例**：弗雷德里克·怀斯曼（Frederick Wiseman），《提提卡蠢事》（*Titicut Follies*，1960 年代末）及其后数十年的机构系列（学校、医院、法院、图书馆、城区）。

| 项 | 内容 |
| --- | --- |
| 约束 | 拍一个机构内部的权力关系，不能靠解说（一说就变论文），不能靠访问（人一面对机器就说官方话） |
| 选择 | 「四无」：无解说、无访谈、无字幕解释、无配乐（各片细节略有出入，标【通行共识】）。全部论证交给**顺序**：谁在说话、对谁说、被打断几次、镜头停多久 |
| 代价 | 片长普遍两小时以上，节奏劝退；无语境导致观众误读单场戏；《提提卡蠢事》上映后在该州以被摄者隐私为由被长期限制公映，成为「记录价值 vs 当事人权利」的教科书式争论（细节请复核） |
| 可迁移 | 你的菜市场、车间、写字楼陌拜系列，可以完全不解说——但**必须靠剪辑顺序做论点**：把「定价」「被砍价」「被罚款」「收摊算账」按这个顺序排，论点自然出现，一句台词都不用写 |

方法对应 [蒙太奇与长镜头](../03-电影语言/蒙太奇与长镜头.md)（并置产生意义）与 [粗剪到精剪](../08-剪辑后期/粗剪到精剪.md)（结构靠排序不靠补写）。怀斯曼路线的成本不在设备，在**素材量与剪辑工时**：它要求你敢拍大量看似无用的段落，并敢在剪辑台上把它们砍到只剩能排序的那几段。

## 4. 如何把作者自己放进片子：自反传统的几种典型手法

「把机器交出去」这一族做法的具体片例容易记错，本节按**手法**而非按人名组织；能确证的片例标注如下。

| 手法 | 可靠片例 | 机理解析 |
| --- | --- | --- |
| 放映回看：把片子放给被拍者看，并把这个场面留在片里 | 《夏日纪事》（1961）结尾的安排放映与讨论 | 被研究者从材料变成评审；拍摄关系本身成为片子的一部分。操作程序见 [视频回看与反馈访谈](../14-田野与影像/视频回看与反馈访谈.md) |
| 叙述者自疑：解说是「我在想」而不是「这是」 | 克里斯·马克《日月无光》（*Sans soleil*，1980 年代前期），以他人来信作为解说文本 | 把全知声音降格为一个具体的人在猜测，观众因此接受不确定性。对照 [解说与静默](../04-声音/解说与静默.md) |
| 作者的手与处境入画 | 阿涅丝·瓦尔达《拾穗者与我》（2000 年前后）：小型数字机器、手、眼镜、口音都在片里 | 轻量设备让作者可以既是拍摄者又是被摄者；结构可以散文化（见 [散文电影与诗性结构](../05-叙事结构/散文电影与诗性结构.md)） |
| 全档案、零实拍 | 马克《红色的空气》（1970 年代后期）由新闻纪录片素材重新剪接成一部历史论证 | 复杂结构可以完全由二次素材承载，代价是**权利链**（[版权链与E&O](../10-伦理法律/版权链与E&O.md)、[档案与二次素材](../07-拍摄执行/档案与二次素材.md)） |
| 摄影机交给对方 | 影像教育与参与式影像的一族实践（含健康促进领域的 PhotoVoice 方法，1990 年代后期提出；中国境内亦有「让村民自己拍」的影像计划，2000 年代中期） | 具体片名与作者不在此断言；机制与失败模式见 [参与式影像](../14-田野与影像/参与式影像.md) |

## 5. 长镜头与时间的证据

先讲清一件事：**调度式长镜头是故事片手法，被纪录片借用了。** 西奥·安哲罗普洛斯（Theo Angelopoulos）在 1970 年代中期以后的作品里，用极慢的横移与纵深调度把历史排进同一个画面；这不是纪录片，但纪录片借的是它的一个观念——**时长本身是证据**，观众在一个镜头里待得够久，就会开始相信画面里有自己没看见的东西。

纪录片侧真正可迁移的三条：

1. **不剪的代价换取信任**：香特尔·阿克曼（Chantal Akerman）《东》（1990 年代初）以固定机位长时间拍排队与人群，无解说；它证明「停留」可以取代「说明」。
2. **调度要付的钱你付不起**：故事片长镜头靠排练、群演、灯光与美术；你一人单机，能借的只有**机位选择与停留时长**，不能借运动调度。看到「一镜到底」就上手买稳定器是典型误区（对照 [稳定器与特种拍摄](../09-技术与设备/稳定器与特种拍摄.md)）。
3. **前提是内容有可承载的时间**：见 [失败与教训](./失败与教训.md) §8——抄长镜头却没有可承载的时间，得到的是慢，不是深。理论在 [蒙太奇与长镜头](../03-电影语言/蒙太奇与长镜头.md)。

## 6. 声音先行的结构实验

| 片例（大致年代） | 声音做了什么结构工作 |
| --- | --- |
| 《听不列颠》（*Listen to Britain*，1940 年代前期） | 常见读法：把工厂汽笛、音乐厅、田间广播作为段落的接缝与推进力，画面跟随声音切换，而不是反过来 |
| 《夜间邮车》（1930 年代中期） | 高潮段把分拣、抛信、火车节奏与配乐对齐，用声音节奏替代解说来完成「说服」 |
| 《持摄影机的人》（*Man with a Movie Camera*，1920 年代末） | 无声片时代的乐队现场混音传统；今天拉片要按「声音如何能剪这批画面」重看（[声音设计](../04-声音/声音设计.md)） |
| 《细细的蓝线》（*The Thin Blue Line*，1980 年代后期） | 重演段落 + 反复出现的配乐主题，用听觉母题取代论证；同时把「访问的建构性」摆在明面 |

**这条线对你的用处最直接**：每周更新时你没有时间做画面级精修，但可以先做声音级排序——把同期声、环境声、门声、机器声排成一张表，段落结构常常就出来了。做法见 [同期声与收音](../04-声音/同期声与收音.md)。

## 7. 无人声、无对白时怎么办

**片例**：《不平衡生活》（*Koyaanisqatsi*，Godfrey Reggio，1980 年代前期）与《持摄影机的人》（1920 年代末）代表同一族做法：全片无对白、无解说，靠画面密度与音乐律动做论证。

| 项 | 内容 |
| --- | --- |
| 约束 | 无语言材料可用（跨国、无共同语，或拍的对象根本不说话） |
| 选择 | 把抽象判断交给并置与节奏：自然与建成环境并排、速度递增、音乐主题反复 |
| 代价 | 常见批评是「什么都能往里装」：没有可反驳的具体陈述，因此也无法被证实；观众各取所需 |
| 可迁移 | 你的空镜段落与转场承担情绪时可用；但**任何你想让人同意的事实判断，都不能只靠这一族手法**——它只能造气氛，不能造证据（[空镜与环境影像](../07-拍摄执行/空镜与环境影像.md)） |

对你的具体意义：城中村、市场收摊、厂区夜色这类素材最适合这种处理，也最容易被你用成「没有内容的漂亮」。判据是问一句：**这一段如果拿掉，观众少知道了什么？** 答不出，就是装饰。

## 9. 常见误区

| 误区 | 为什么错 | 更正动作 |
| --- | --- | --- |
| 把风格当技术抄 | 「无解说」是一套认识论加几百小时素材，不是一句设置 | 抄之前先回答：我不解说时，论点靠什么成立 |
| 只学构图不学取舍 | 拉片笔记写满「中景、固定、留白」，没写「这里为什么不 cut」 | 每次拉片只记**切与不切的理由**（[片单](../16-学习资源/片单.md) §观看方法） |
| 把低成本浪漫化 | 弗拉哈迪的「一个人一台机器」有机构与资金支撑，且代价由被摄者付 | 每个案例先查它的生产条件，再判断可迁移性（[预算与制片管理](../11-生产与资金/预算与制片管理.md)） |
| 拿奖项当质量证明 | 奖项是策展口味与首映政策的函数，不是技术评分 | 只用「它解决了什么问题」筛选片单 |
| 把介入当勇敢 | 提问式采访的成效取决于对方是否还能承受后果 | 介入前先做伤害预估（[困难采访与对抗性采访](../06-采访方法/困难采访与对抗性采访.md)） |
| 断言创作者意图 | 在世作者的自述与其文本经常被混用 | 统一写「常见读法是…」，见 [真实契约](../01-理论/真实契约.md) |

## 10. 实操要点

- [ ] 本周只拉一部片，按 §观看方法 的四遍法处理；选题是「它如何开头」这一个问题。
- [ ] 给你的长期项目写一份「三选一」声明：我主要走观察式克制，偶尔用介入式提问，不用宣教式；写出违约时的处理办法。
- [ ] 试着做一集零解说版本，论点完全由段落顺序承担；做完自问：观众能否只用画面与同期声复述我的判断。
- [ ] 每个想抄的手法，先写下它的代价与你的支付能力（时间、素材量、关系成本），再开机。
- [ ] 长期项目至少安排一次回看放映，把当事人的反应记进素材并归档（程序见 14 章）。
- [ ] 每周更新时优先做声音排表，画面精修降级；把这条写进 [单集制作SOP](../15-工具与模板/单集制作SOP.md)。
- [ ] 涉及仍在世的创作者与其作品，公开文案里只用「通常被认为」「常见读法是」，不写「他想表达」。

## 请复核条目

以下为写作中无法逐条核验的事实，采用年代区间或【通行共识】表述，引用前请回查一手资料：

1. 「documentary」一词由格里尔逊在 1920 年代中期评论弗拉哈迪作品时提出——年份与刊物未核。
2. 《漂网渔船》初版是否完全无解说、《夜间邮车》的诗与配乐作者归属——通行说法，未逐字核验。
3. 怀斯曼各片的「无解说、无访谈、无配乐」是否为其全部作品的恒定做法，以及《提提卡蠢事》被限制公映的具体年份、理由与法律后果。
4. 《提提卡蠢事》之后怀斯曼是否单人完成拍摄与录音、其从业前背景。
5. 《日月无光》《红色的空气》《东》《拾穗者与我》《细细的蓝线》《灰色花园》《推销员》《夏日纪事》《罗杰与我》《听不列颠》《持摄影机的人》《不平衡生活》（含其导演与作曲归属）的准确年份，本篇一律以年代区间表述。
