# 采访设计与提纲

> 本篇只讲镜头前采访的场合搭建与问题写法：抽样与访谈类型学见 [05-访谈](../../田野方法/05-访谈.md)，伦理原则全文见 [研究伦理总论](../../社会学田野/07-伦理/概述.md)，此处只补「摄影机在场」带来的特殊执行动作。

## 1. 一次镜头前采访的七个设计项

采访失败大多不在临场，而在现场之前。开工前把七项定死：

| 设计项 | 要决定的事 | 常见错误 |
| --- | --- | --- |
| 对象 | 他手里有什么别人拿不到的东西（经历、单据、判断、情绪） | 因为「好约」而拍 |
| 时长 | 单人单次 40–90 分钟；老人与病人见 [口述史访谈](口述史访谈.md) | 约 20 分钟，刚热场就结束 |
| 地点 | 在他的地盘，且是他干活/生活的位置 | 会议室、白墙、逆光窗 |
| 机位 | 一个方向锁死，中途不换视线 | 拍一半改看镜头 |
| 收音 | 主麦 + 备份轨 + 监听 | 只有一台相机的内建麦 |
| 许可 | 知情同意 + 口播确认 + 记录留档（§3） | 事后补，或口头「你随便用」 |
| 收尾 | 留 3–5 分钟做三件事（见 [提问与追问技术](提问与追问技术.md)） | 一说完就关机器 |

## 2. 提纲的四层结构

不要用问题清单，要用一棵树。四层：

```
第一层 三个必得答案（这一场没拿到就算失败，写在纸最上面）
   ├─ 例：他为什么离开那条流水线 / 他手上现在有多少单 / 他说这句话时会不会哭
第二层 主题块（4–6 个，每块一个入口问题 + 备用追问）
第三层 追问树（每个入口问题下预设 2 层：具体化、比较、代价）
第四层 收尾问（情绪回接 + "还有别的吗" + 授权复述）
```

【操作性建议】纸上手写，不要平板。三层好处：对方看到你手里是纸，攻击性低；你自己不会照屏幕逐字念；平板上顺手改问题会让追问变机械。每场只写四个主题块——超过五个必然每个都问浅。

## 3. 许可与知情同意的现场执行

原则与要素见 [研究伦理总论](../../社会学田野/07-伦理/概述.md)（信息、理解、自愿、能力四要素）与 [知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md)。摄影机在场时的特殊之处只有三条【操作性建议】：

1. **同意要发生在开机之前，且要被录下来**。签完书面文件后，在机器内、镜头里再要一次口播确认：「我同意曹亚仑拍摄并公开播映。」口播既是凭证，也让对方当场体会「对着机器说这句话」是什么感觉——很多人是在这一刻才真正理解自己在做什么。
2. **同意内容必须包括「会被公开播放」和「在哪些平台」**。学术访谈的保密承诺在这里不成立：纪录片要发出去。含糊的「我就随便用一下」是最危险的同意。
3. **给一个可执行的退出承诺**：明确「哪一段你说别播，我就不播」，并当场说清怎么通知你（微信文字，不要口头）。

- [ ] 书面授权已签（模板见 [授权文书模板](../15-工具与模板/授权文书模板.md)）
- [ ] 机器内口播确认已录
- [ ] 平台范围、化名方式、可撤回段落，三项都讲过
- [ ] 有未成年人或在场的第三方（同事、家属）——单独处理，见 [弱势群体与儿童](../10-伦理法律/弱势群体与儿童.md)
- [ ] 敏感内容（劳务纠纷、病情、举报）已提醒「公开后可能被认出」

## 4. 提纲该不该提前发给对方

默认**不发**。一份被提前看过的提纲会生产三样东西：准备好的稿子、被删掉的意外反应、以及对方对你的错误预期（以为你会按稿问，于是等你念稿）。纪录片的价值恰恰在第一次反应。

| 情形 | 是否发 | 发到什么程度 |
| --- | --- | --- |
| 一般素人、工人、摊主 | 不发 | 只说「我会聊哪几件事」（话题，不是问题） |
| 机构高管、外企、发言人 | 必须发主题块 | 给 4–6 个议题，不给逐条问题 |
| 律师在场 / 法务预审 | 必须发全文 | 与律师谈定后再发，留发送记录 |
| 学术伦理审查要求事先披露 | 按批准版发 | 与 IRB/伦理委员会文本一致 |
| 对方极度焦虑、需要可控感 | 发话题不发问题 | 换信任，别换深度 |

【操作性建议】对方坚持要全文时，给「议题 + 我会问到的三类事实」，并说明「具体问题我会根据你说的话追问，这是采访的正常做法」。

## 5. 问题排序心理学

四条排序律：先易后难、先事实后判断、先外部后内在、结尾回到情绪。

| 顺序 | 类型 | 例子 | 为什么在这里 |
| --- | --- | --- | --- |
| 1 | 动作与流程 | 「早上到店里第一件事做什么？」 | 无风险，启动叙述肌体 |
| 2 | 事实与数量 | 「现在一天卖多少斤？请几个人？」 | 建立「我可以答」的惯性 |
| 3 | 关键事件 | 「还记得那次被查的日子吗？」 | 有事实打底，才敢回忆 |
| 4 | 判断与归因 | 「你觉得这事怪谁？」 | 判断放前面会显得质问 |
| 5 | 内在状态 | 「那几天你睡得着吗？」 | 最内层，需要前面的许可 |
| 6 | 情绪回接 | 「现在说起这个，你身体哪里不舒服？」 | 不要以「你怎么看行业前景」收尾 |

**结尾回到情绪**不是煽情，是安全：把人从回忆里接出来，带着一个被听到的感觉离开，才有第二次采访。

## 6. 问题写法的硬性规则

本篇核心。规则不是风格偏好，是素材可用性问题：写法错了，回答就一定不可剪。

| 规则 | 坏例子 | 为什么坏 | 好例子 |
| --- | --- | --- | --- |
| 不用「为什么」开头 | 「你为什么要辞职？」 | 听感是质问，逼人辩护，给出理由式套话 | 「那天发生了什么，让你决定走？」 |
| 不问复合问题 | 「你什么时候来的深圳，在哪个厂做过，工资多少？」 | 只会答最后一个，或只答第一个 | 拆成三句，一句一问，问完闭嘴 |
| 不问是非问题 | 「辛苦吗？」 | 两个字答完，沉默开始 | 「辛苦在哪儿，给我说说？」 |
| 不用形容词提问 | 「那段日子是不是很难？」 | 你把词塞给他，他只能借用你的词 | 「那段日子里，最难受的一天是怎么过的？」 |
| 不用专业术语 | 「你们的用工弹性怎么安排？」 | 对方听不懂，会装懂并给出空话 | 「活儿多的时候你们怎么加人？」 |
| 不暗示正确答案 | 「AI 应该会取代你们吧？」 | 对方顺着你说，你得到自己观点的回声 | 「上个月有没有哪件事，是你觉得机器做不了、非人不可的？」 |
| 避免引导 | 「老板是不是不太管你们安全？」 | 一旦引导，整段素材在事实核查时作废 | 「安全这块，平时谁在管？怎么管的？」 |
| 不抢结论 | 「所以你就是被坑了？」 | 替对方下判断，剪出来是你的声音不是他的 | 「这件事你怎么定性，你自己说。」 |

【通行共识】引导性问题在质性访谈中破坏材料的可信度（见 [08-信效度](../../田野方法/08-信效度.md)）；在纪录片里多一重后果：一旦对方顺着你的词说，这段素材在质疑面前几乎无法自证。

**写进提纲的每一句问题，自检三问**：这句话里有我的形容词吗？这句能一句话答完吗？对方答完，我能想象出画面吗？

## 7. 「具体到能被拍下来」的提问法

判据：一个问题的理想回答里，有没有可以直接配画面的动作、地点、数量、时间点。观众记不住判断，只记得住细节。

| 抽象问法（得到判断） | 具体问法（得到画面） |
| --- | --- |
| 「你们辛苦吗？」 | 「那天几点起床？几点出门？」 |
| 「通勤方便吗？」 | 「路上坐几站？在哪一站换？车上能睡着吗？」 |
| 「工作环境差吗？」 | 「进门第一件事做什么？车间里要戴什么？」 |
| 「老板严厉吗？」 | 「他上次在群里发消息是几点，写的什么？」 |
| 「生意不好做吧？」 | 「昨天卖剩的怎么处理？谁付这笔钱？」 |

【操作性建议】手上没有具体问法时，一律回到「上一次」句式：「你上一次遇到（这件事）是什么时候？从头说一遍那天。」「上一次」逼出个案，「一般人会怎么做」逼出套话。

## 8. 时间线追问法

人回忆的方式是概括，采访需要的是顺序。方法是把话题拆成一条时间轴，逐点重建：

1. 定端点：「从你决定干这行说起，到哪一天为止？」
2. 找拐点：「中间有哪几次是你差点不干的？」
3. 逐点展开：「那次之后，第一个月你是怎么过的？」
4. 排前后：「这件事在（另一件事）之前还是之后？」
5. 校外部锚点：「那年春节你回村里了吗？」（用公共事件校准年份）

**对方一旦说「一般」「都是」「反正」，就是概括化的信号**，立刻回到某一次：把一类打回一次（见 [提问与追问技术](提问与追问技术.md)）。

## 9. 沉默的使用

问完之后数 3 秒再动。对方在 2–4 秒的沉默之后说出的话，通常比第一答更真。**你填补沉默，就是替他解围，也是毁掉这一场最好的那句**。数数的另一好处是不显得急切。若对方确实答完了，就用复述末句或换话题，不要用新形容词去撬。

## 10. 采访前 30 分钟检查清单

- [ ] 电量、存储卡余量（≥ 预计时长 2 倍）、时间码/日期正确
- [ ] 双轨录音测试 + 耳机听 30 秒环境底噪（冰箱、空调、马路、施工）
- [ ] 白平衡与曝光锁定；试坐一次，检查构图与逆光
- [ ] 位置与椅子高度先摆好，避免开机器后大动作
- [ ] 手机静音并翻面；关窗、关电视或说明关不掉
- [ ] 环境风险确认：能否锁门、有无第二条路线、附近是否有人可能介入
- [ ] 许可：文件、口播脚本、化名，三样在心里过一遍
- [ ] 开场话术（不朗读，只说一句）：「今天不赶时间，你说乱了我就再问一遍。」
- [ ] 纸上写下**今天必须拿到的三句话**（原话，不是主题）
- [ ] 最后一个主题块讲给自己一遍，避免现场只记得开头和结尾

## 11. 10 个万能入口问题

按「过去时 + 具体 + 无形容词」写成的可直接照读版：

1. 「我第一次来这儿，你带我走一遍你今天的一天，从几点开始都行。」
2. 「你上一次加班到最晚是哪天？那天几点到家？」
3. 「这行你最早是怎么进来的？谁带你入的行？」
4. 「手机里有没有你那天拍的照片，给我看看。」
5. 「你手上现在最急的一件事是什么？它什么时候到期的？」
6. 「去年这个时候你在干什么？」
7. 「这里有没有哪个人，是你不想再碰见的？为什么，说说事。」
8. 「如果有人出钱请你继续干，你还干不干？」
9. 「你父母/孩子知道你是这么过的吗？他们看到会说什么？」
10. 「如果这片子给你看，你最怕里面出现哪句话？」

第 9、10 两问兼具伦理功能：前者探情感重量，后者把撤回权主动交回去。

## 12. 常见误区

| 误区 | 后果 | 纠正 |
| --- | --- | --- |
| 提纲写成问卷，逐条念 | 对话变成填表，全程无意外 | 四个主题块 + 追问树 |
| 提前发全文提纲 | 得到发言稿 | 只发议题（§4） |
| 用形容词提问 | 素材里全是你的词汇 | 换成动作与时间点 |
| 在办公白墙前采访 | 有内容没环境，观众不信 | 在他的地盘 |
| 把情绪问题放在最后临时加 | 对方已收心，答不出 | 结尾回接是设计好的第 6 步 |
| 相信「现场再想」 | 追问变浅，节奏乱 | 每个入口预设两层追问 |

## 实操要点

1. 每场只写四个主题块，纸上手写，最上面钉三个必得答案。
2. 默认不发提纲；机构与律师在场必须发议题版，留发送记录。
3. 提问前跑一遍三自检：有没有我的形容词、能不能一句答完、能不能配画面。
4. 「上一次」是最省力的万能句式，把一类打回一次。
5. 问完数 3 秒再开口，把最好的那句留给对方的沉默。
6. 顺序固定：动作 → 事实 → 事件 → 判断 → 内在 → 情绪回接。
7. 许可要「签 + 录 + 给退出权」三件齐全，口播确认必须在机器内完成。
8. 开场前 30 分钟清单逐项打勾，尤其「今天必须拿到的三句话」要写成原话。
