# 困难采访与对抗性采访

> 本篇只处理镜头前最难的那几场：上位者、不情愿者、美化者、加害者、公关在场。采访提纲的通用设计与许可流程见 [采访设计与提纲](采访设计与提纲.md)；伦理原则全文见 [伦理总论](../10-伦理法律/伦理总论.md)。本篇全程不给规避监管或违法的建议，涉及中国法律的部分只做事实性风险提示。

## 1. 先改目标：困难采访的成败不取决于对方说什么

普通采访的目标是「让他讲出真相」。困难采访的目标要降级重设——**目标设错，一场本可成立的采访会被判为失败**。

| 类型 | 错误目标 | 可行目标 | 判定成功的标志 |
| --- | --- | --- | --- |
| 权力上位者（老板／甲方／官员） | 让他认错或表态 | 拍到他的**回避方式本身** | 观众能看出他如何回答问题，而不只是回答了什么 |
| 不情愿者 | 说服他配合 | 拿到他能给的那一层 + 记录他为何不给 | 一段克制的、边界清楚的话 |
| 说谎或美化者 | 当场戳穿 | 让他的说法与可核材料同框 | 矛盾被并置，不由你评论 |
| 加害者 | 审判 | 拿到他的解释框架与事实细节 | 他的逻辑自陈，而非他的忏悔 |
| 公关／律师在场 | 绕过他们 | 在规则内问完必问清单 | 问题被完整提出并留痕，答复是长是短不重要 |

【操作性建议】对上位者，最有信息量的常不是答案，而是**他改换了你的哪个词、他用了多长时间绕开、他把责任移给了谁**。所以机位要稳、要包含他的脸和手，不要在回避处剪掉——回避正是素材。

## 2. 五类困难采访的现场要点

### 2.1 权力上位者

时间会被压缩（「我只给你 20 分钟」）、地点由他定（办公室、会议桌）、有第三人在场。应对：把必问清单前置到第 5 分钟；接受压缩但不接受顺序被换（把最重要的三问放在最可能被中断的位置，即前面）；他给你名片式的稿子时，用「要一次而非一类」打回（[提问与追问技术](提问与追问技术.md) §2）。

### 2.2 对方不情愿

不情愿多为**后果恐惧**（被开除、被追责、被同行孤立），不是不信任你。给三样：删剪权（「这段别播」）、时间（「这次不谈那件事」）、结构（「我只问流程，不问评价」）。**不要用「我们要为弱势群体发声」去说服**——那是拿他的风险换你的片子。

### 2.3 对方说谎或美化

不要当场指认。三种不指控的处置：
- 要细节：谎言在细节层最脆弱（「那天谁在场？会开了多久？谁记的？」）
- 要反例：「有没有哪次不是这样？」
- 并置：把他的说法与可核材料（价签、公告、日期、另一位在场者的说法）先后剪在一起，不写评论字幕。

### 2.4 对方是加害者

你的风险不是被反驳，是**被读成背书**。规则：必问清单完整问、不当场辩论、不做点头式附和（点头会被剪成认同，见 [提问与追问技术](提问与追问技术.md) §5）、事后书面记录你问过什么与他答了什么。是否使用其素材、是否露脸，见 [事实核查与更正](../10-伦理法律/事实核查与更正.md) 与 [伦理总论](../10-伦理法律/伦理总论.md)。

### 2.5 公关或律师在场

前置沟通时把问题清单发出去（这是 [采访设计与提纲](采访设计与提纲.md) §4 里「必须发全文」的情形）。现场三句：
> 「这个问题我还是要问一遍，回答由您决定。」
> 「如果这里不方便答，我们记一下，稍后书面回我。」
> 「这段是录音留档，不一定播。」

## 3. 对抗性采访（adversarial interview）的四项技术

对抗性的对象是**说法**，不是人。四项：

| 技术 | 做法 | 注意 |
| --- | --- | --- |
| 沉默 | 他答完不动、不点头、不复述，看住 4–6 秒 | 他要么补充，要么暴露不耐烦——两种都有用 |
| 重复同一问题 | 原样、同语气重问，不改词、不解释 | 最多三次；第四次就是审讯，且观众开始同情他 |
| 并置矛盾 | 「您刚说裁员是自愿的。这里有一份通知，日期是三月五号。」 | 只呈材料，不下判断；不问他「这怎么解释」以外的问题 |
| 要具体数字 | 「多少人？哪一天？谁签的字？」 | 数字答不出是重要素材，剪进去 |

**不辩论**。辩论会把片子变成你的赛场，观众记住的是谁口才好。你说一句：「这不是我要讨论的，我想把事实收全。」然后把问题再放回去。

## 4. 不利问题的礼貌问法与必问清单

礼貌不等于软化。结构固定：**承认成本 + 说明必要 + 给退出权 + 问题本体**。

> 「这个问题可能不太好回答，但片子里必须有它，不然观众只听到一面。您可以拒答。——（问题）」

必问清单（对任何掌握权力或资源的一方，一项不能少）【操作性建议】：

- [ ] 事实：哪一天、多少人、多少钱、谁决定
- [ ] 依据：按什么制度、谁定的、有没有书面
- [ ] 异议：当时有谁不同意，说了什么
- [ ] 后果：受影响的人后来怎么样，你知道过吗
- [ ] 责任：这件事该谁负责——请他用一句话回答，不许绕
- [ ] 反悔：重来一次会怎么做
- [ ] 回应：对方（工人／客户／被报道者）的说法是 X，你听到后什么反应

最后一条最重要：**把他人的指控原样送到他面前**，这是对抗性采访唯一不可替代的功能。

## 5. 被要求审片怎么办

给看不给剪。可谈的三类、不可让的两类，边界写死：

| 可谈（可以改） | 不可让（不能改） |
| --- | --- |
| 事实错误：日期、数字、职务、引用错 | **结论**：片子最终说出什么判断 |
| 人身安全：住址、车牌、孩子学校、可被识别的定位信息 | **证据取舍**：删掉对你不利的材料、加进对你有利的材料 |
| 重大隐私：与主题无关的疾病、家庭、性、财务细节 | |

【操作性建议】三条纪律：审片只给**用到的段落**，不给全片粗剪（否则对方会开始要求结构）；只走**一次**书面意见，一轮为准；修改决定权在你，但**改了什么要留记录**。完整伦理依据见 [伦理总论](../10-伦理法律/伦理总论.md)；文书与措辞见 [知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md)。

## 6. 被施压删除、被起诉时的处置

以下为事实性流程，不是法律意见；具体条文与平台规则以 [中国法律边界](../10-伦理法律/中国法律边界.md) 和平台条款为准，不确定时咨询执业律师。

- [ ] **原始素材完整保留**，不剪辑、不重命名、不格式化存储卡（含你不打算用的部分）
- [ ] **时间戳与来源链留档**：拍摄日期时间、地点、设备、在场人、许可凭证（书面 + 口播）
- [ ] 收到下架／停止传播要求时，先**书面回应并记录收悉时间**，不在社交平台即兴互怼
- [ ] 不临时改口供：不要为了平息压力说「我可能记错了」；要更正就按 [事实核查与更正](../10-伦理法律/事实核查与更正.md) 走正式更正
- [ ] 平台投诉与法律程序并行准备；对独立创作者，一次败诉的代价往往大于一条片子的收益，因此 §8 的止损判断要提前做

## 7. 录音证据与使用合法性（只做风险提示）

- **秘密录音在成片中直接使用属于高风险**：素材取得方式若无同意，可能被质疑合法性，并可能触及他人权益与平台规则；对方亦可能主张你违反承诺。不要以「取证」为目的设计偷录环节。
- **单方保存与公开播放是两件事**：把原始素材留档以自证，与把它播出去，风险等级完全不同。播出去前回到 §5、§6 与 [版权链与E&O](../10-伦理法律/版权链与E&O.md)。
- **不要把采访当法律证据来问**：你一旦扮演取证者，对方的语言会收缩，素材质量下降，同时你的身份从记录者变成指控者。若确实需要举证，指引他去找能办事的机构（[信任与被摄者心理](信任与被摄者心理.md) §5 的转介边界）。
- 涉及他人在场的录音视频，公开前的同意与打码要求见 [中国法律边界](../10-伦理法律/中国法律边界.md)。

## 8. 「我不想播了」：撤回请求的处理

先分类型再决定，别一律答应，也别一律拒绝：

| 请求性质 | 判断 | 处置 |
| --- | --- | --- |
| 已签书面同意，事后单纯后悔 | 你不欠一次反悔，但关系值钱 | 优先尊重，代价是片子少一段；实在关键则给替代方案（挡脸、变声、化名、只留手部） |
| 出现你未告知的用途（商业投放、节展、二次分发） | 你的告知不完整，请求成立 | 无条件按承诺处理，或补一次明确同意 |
| 他处境变了（被辞退、被家里发现、进入纠纷） | 伤害可预期且不可逆 | 撤。这条优先级高于片子完整性（[伦理总论](../10-伦理法律/伦理总论.md)） |
| 第三方（单位、家属）施压而非本人意愿 | 不能由代信者决定 | 找本人确认，一次文字即可；确认后按上面三条处理 |

【操作性建议】承诺要提前给、且给得窄：只承诺「你不想播的段落我不播」，不要承诺「全片给你审」。事后被扩大解释的多是当场随口的好话。

## 9. 止损判断：什么时候放弃这条采访线

【操作性建议】困难采访最贵的不是被拒，是投入。四条中两条成立即转线：

1. 三次正式请求（含书面）后，仍拿不到任何新增事实——你已有的是「他不愿说」，这本身可以是素材，但不是继续投入的理由；
2. 已取得内容 80% 可由公开材料替代（公告、年报、判例、他人叙述）；
3. 现场安全或法律风险不可控（被扣设备、被要求删卡、有人身威胁）；
4. 这条线要付的情绪与关系成本已开始污染其他线（你在别的采访里心不在焉）。

这与 [行动总纲](../../研究/行动总纲.md) §8.5 「只做离钱最近的事、时间是最贵的服务器资源」是同一套逻辑：**换的是信息，不是面子**。转线的标准动作是——把已有素材按 §6 留档，给对方一句体面的收尾，然后从公开材料与他人叙述里补这个位置。

## 10. 困难采访决策树

```
这场采访值得开机器吗？
├─ 从未给过任何事实 / 无任何独占信息 ─────────── 不做，转公开材料（§9）
└─ 有独占信息
   ├─ 对方同意但可能敷衍（上位者／机构）
   │   ├─ 能问到必问清单 ≥4 项 ───────────── 做，目标=回避方式（§1）
   │   └─ 只允许提问 3 个 ───────────────── 做，但先书面发全清单+要求书面回复（§2.5）
   ├─ 对方不情愿
   │   ├─ 拒绝源于后果恐惧 ─────────────── 给删剪权+分层，再约一次（§2.2）
   │   └─ 拒绝是明确而稳定的 ────────────── 停。记录"拒绝"本身，不追
   ├─ 对方说法与材料冲突
   │   ├─ 能拿到可核材料 ──────────────── 做，用并置（§2.3、§3）
   │   └─ 只有双方说法 ────────────────── 不做成指控；标注为未证（§7）
   └─ 现场出现安全／法律风险 ─────────────── 立即收工（§6、§9）
```

## 11. 常见误区

| 误区 | 后果 |
| --- | --- |
| 追求「让他当场认错」 | 整场变成对峙，素材两头不讨好 |
| 用道德动员换配合（「为大家说句话」） | 拿他的风险换你的片子，事后必反弹 |
| 当场戳穿谎言 | 他闭嘴，剩余素材全失；并置更有效 |
| 让公关代答后当成他的回答 | 事实核查时说不清谁说的 |
| 答应「全片给你审」来换开机 | §5 的边界从此立不住 |
| 把偷录当取证手段 | 合法性与素材质量双损（§7） |
| 不停投入直到拿到回应 | 挤掉三条可行的线（§9） |

## 实操要点

1. 先重设目标：对上位者，拍到他的回避方式就是成功。
2. 必问清单七项，一项不少；最后一项是把指控原样送到他面前。
3. 对抗性技术只用四样：沉默、重问、并置、要数字；绝不辩论，绝不点头附和。
4. 不利问题固定结构：承认成本 + 说明必要 + 给退出权 + 问题本体。
5. 审片给看不给剪：可谈事实错误、人身安全、重大隐私；不可让结论与证据取舍。
6. 遇施压先留档：原始素材、时间戳、许可凭证三样齐全，书面回应，不即兴互怼。
7. 撤回请求分四类处理，处境变化的优先级高于片子完整性。
8. 四条止损判据中两条成立就转线；转线时把已有素材留档并给对方体面收尾。
