# 口述史访谈

> 本篇只讲「影像化口述史」的特有层。口述史的访谈类型学、抽样、转录与编码一律不重写：见 [05-访谈](../../田野方法/05-访谈.md)（谱系、七阶段、提纲与追问、样本量）、[深度访谈](../../社会学田野/03-方法/深度访谈.md)（转录、成员检查、主题与叙事分析）、[田野总览](../../社会学田野/03-方法/田野总览.md)（进入田野与分析阶段）、[08-信效度](../../田野方法/08-信效度.md)（可信性四标准与三角验证）。

## 1. 生命史为什么能当系列片的骨架

口述史的基本单位是一个人的一生；纪录片的单位是一段时间。二者能接上，是因为生命史自带结构：出生地、入行、转折、衰落、现在。对独立创作者，这比「一个议题＋五位受访者」的组织方式更省，也更强【操作性建议】：

| 组织方式 | 素材来源 | 优点 | 风险 |
| --- | --- | --- | --- |
| 议题式（「AI 会不会取代工人」） | 多人横切 | 观点丰富 | 变成街采式归纳（见 [街头采访与素人](街头采访与素人.md) §9） |
| 生命史式（一个人的四十年） | 单人纵切 + 现场回访 | 时间跨度自带戏剧性；可信度由细节堆出 | 此人若无表达力，全靠你的结构能力 |
| 混合（一人主线 + 两人旁证） | 主线生命史 + 交叉验证 | 既纵深又可核 | 旁证易被剪成「反对意见」标签 |

一个可用的比例：单集 8–12 分钟里，一个人占 60% 以上说话时间，其余留给地点、旧物与旁证。生命史素材的另一好处是**可反复使用**：同一次采访，能切成三条短视频、一集长片、一段论文引文。

## 2. 时间跨度怎么拍

口述史的难点是：他讲 1984 年，你手上没有 1984 年的画面。四条供给路径：

| 路径 | 做法 | 注意 |
| --- | --- | --- |
| 历史影像与文献 | 报纸、台标、旧纪录片、单位录像带 | 版权链与二次素材规格见 [档案与二次素材](../07-拍摄执行/档案与二次素材.md) |
| 地图与空间 | 手绘地图、卫星影像年份对比、村界变化 | 让他自己在地图上指，比你的动画有力 |
| 实物 | 工牌、粮票、结婚证、第一台机器、老照片 | 翻拍规格：正拍、平整、无反光、RAW 或 600dpi 以上、原件不裁切不书写；细节见 [档案与二次素材](../07-拍摄执行/档案与二次素材.md) |
| 地点回访 | 带他回到现场，边走边说 | 这是最高性价比的一招：位置会替他说话 |

**地点回访的操作要点**【操作性建议】：机器开着但他不说话，先让他走一段；旧地址拆了就把他现在站在废墟/停车场上的画面留下——「这里原来是几号」这种句子必须在现场问。翻拍老照片时用固定光源、垂直机位、灰卡或白卡一次校准，把「翻拍」与「实拍」分开记录在场记里，后期标注来源才做得清。

## 3. 记忆是研究对象，不是待清理的障碍

口述史的理论前提在学术库中已充分说明（见 [05-访谈](../../田野方法/05-访谈.md) 与 [08-信效度](../../田野方法/08-信效度.md) 关于回忆偏差与可信性的处理）；影像层的规矩只有一条：**记忆的重构性不是素材缺陷，是内容**。

「他说错了怎么办」的三步固定处置【操作性建议】：

1. **保留**：不按你的判断改掉他的年份、数字、因果。他记成 1998 年，成片里就是 1998 年。
2. **标注**：三种标注强度，按错处的重要性选——字幕不改（无伤大雅的口径差异）；旁白或字幕说明分歧（「他记得是三月，档案上是六月」）；结构上并置（把档案画面与他说的段落前后相接）。
3. **交叉验证**：外部锚点（春节、奥运会、某次洪水、孩子的出生年）、单据与档案、另一位在场者。方法即三角验证，见 [08-信效度](../../田野方法/08-信效度.md)。

禁止的处置：当场纠正（「您记错了吧，那是 2003 年」）。纠正一次，之后他会开始校对自己的记忆来迎合你——你既毁了素材，也毁了他叙述的权威。把疑问记在场记上，回访时以「我回去查了一下，有个地方想再请您说说」开口。

## 4. 老人、病人、识字很少的受访者

| 约束 | 现场技术 |
| --- | --- |
| 语速慢、句子长、话题漂移 | 不打断；用回声式应答把话题带回来（[提问与追问技术](提问与追问技术.md) §5、§7） |
| 听力衰减 | 先测：normal 音量说一句让他复述；把领夹麦放到他这一侧，别喊；关掉冰箱、抽油烟机 |
| 疲劳与注意力窗口 | **单次采访上限：60–75 分钟（含休息）；75 岁以上或有慢病者 30–45 分钟**，之后改聊天、吃饭。分段优于延长（参考值，非医学结论）【操作性建议】 |
| 药物与治疗时段 | 服药后 1–2 小时内、透析/化疗后当天不采；时间由他定，不由你的行程定 |
| 不识字 | 不走书面提纲、不递文件让他读；用照片、地图、物件作为提问媒介；授权改为口播 + 录像见证（见 [知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md)） |
| 记忆断片 | 允许「想不起来」，跳过后从别的入口回来；不要替他补年份 |

## 5. 方言与译者：谁在说话

口述史常需第三人（子女、同村人、翻译）。两种方案：

| 方案 | 好处 | 代价 | 什么时候选 |
| --- | --- | --- | --- |
| 翻译入镜（同期双声） | 保留原声与语气；「有人替他说话」这件事本身可见 | 节奏慢、画面多一个人 | 方言是内容的一部分、或内容有争议需要见证 |
| 后期配音字幕 | 干净、平台友好 | 原声被替换，情感重量与可信度同时下降；且译者的措辞由你决定 | 材料无争议、方言观众可懂度高 |

【操作性建议】默认**原声 + 字幕**，配音只用于完全听不懂的方言。译者要事先交代三句：不修饰、不合并句子、不确定就原样译出并说「这里我没听清」。译者的名字在片尾署名——这是学术伦理（转述者归属）与影像诚实共同的要求。

## 6. 遗言式采访：等不到成片的人

病人、高龄者、即将被拆除的村子里的人，属于**抢救性记录**。三条优先次序【操作性建议】：

1. **先拿他没给别人讲过的部分**，不要按提纲顺序从头走——时间可能不够走完一生，但一定够讲一件事。
2. **事实与意愿同场问**：他要谁看到这片子、哪段不希望公开、老照片给谁。这些问题平时问是冒昧，在此刻问是责任。
3. **交付提前**：不等成片。当天或次日就给他一段可用的粗剪或音频，让他在还能听的时候听到自己说的话。

若他可能等不到发布：**发布计划要当面讲清并请他确认**（「如果我不在了，这段您希望放还是不放」），并把回答留下。这个答复的效力高于家属后来的意见，但不高于他本人的撤回（[困难采访与对抗性采访](困难采访与对抗性采访.md) §8）。相关情绪现场纪律见 [信任与被摄者心理](信任与被摄者心理.md) §6。

## 7. 家庭影像与私人档案的授权

私人相册、录像带、书信的所有权与肖像权、著作权、隐私是四件不同的事，且常分属不同家庭成员。【操作性建议】：

- [ ] 问清**东西在谁手上、是谁拍的、里面有谁**，三者可能不同
- [ ] 画面中所有可识别的在世者，逐个取得同意或做处理
- [ ] 涉及已故者的敏感内容，请直系亲属共同确认；一人点头不等于集体同意
- [ ] 家庭内部有分歧时（兄妹对某事说法不同），要么不用，要么把分歧如实呈现，不替任何一方裁决
- [ ] 书面留档：谁授权、授权什么用途、原件归谁；模板见 [授权文书模板](../15-工具与模板/授权文书模板.md)
- [ ] 借出的原件当面清点、拍照记录状态、约定归期；扫描件不等于归还

## 8. 同一批材料，两套产出

一篇学术论文加一部片子，是口述史最划算也最容易出事的结构。三组规范必须分开管理【操作性建议】：

| 维度 | 学术产出 | 影像产出 |
| --- | --- | --- |
| 匿名化 | 化名 + 去除识别信息，永久 | 露脸出声即不可匿名；化名只能靠打码变声 |
| 转录 | 逐字、含停顿与笑声标记（方法见 [深度访谈](../../社会学田野/03-方法/深度访谈.md)） | 挑选、压缩、允许重组顺序，但不得改变意思 |
| 同意 | 伦理审查批准的研究用途 | 平台公开播映、可能商业投放 |
| 风险 | 声誉、退稿 | 被认出、被家人看到、被单位看到 |

**必须披露的三件事**：材料双用途（同意书与片尾都要说明）；你在片中的位置（拍摄者、被邀请者、帮忙办事的人——见 [作者与风格](../01-理论/作者与风格.md)）；任何资金或机构关系（[版权链与E&O](../10-伦理法律/版权链与E&O.md)）。同一次采访同时给论文和片子用时，同意书要写明两种用途；只签了学术研究同意，就不能播。

## 9. 给受访者的交付

口述史的补偿通常不是钱（也常常给不起），是**他自己的话回到他手上**：

- [ ] 至少一段可用视频或音频文件，能在他手机上播放的格式
- [ ] 光盘或 U 盘：给不会用云盘的年长者，本地留一份，附一张写着日期与内容的纸
- [ ] 家谱式整理：把他讲的时间线打印成一页（谁、哪一年、什么事），当面读一遍核对
- [ ] 翻拍的照片归还原件，并给一份扫描件
- [ ] 发布后回访一次，问有没有被认出、有没有带来麻烦（[信任与被摄者心理](信任与被摄者心理.md) §8）

## 10. 可执行流程：三次 40 分钟拍完一个人的生命史，剪成 8 分钟

三次共 120 分钟采访，成片 8 分钟约需 15:1 的采访素材比，其余由空镜、实物、地点回访补足（比例依据见 [采访方法论](采访方法论.md) §7）。

| 次序 | 现场 | 拿什么 | 不问什么 |
| --- | --- | --- | --- |
| 第 1 次（40 分钟，不开机或只录音） | 他家／他干活的地方 | 生命周期分段（§11）走一遍，标出他眼睛亮起来的三处 | 不问创伤细节、不问评价 |
| 第 2 次（40 分钟，开机） | 第 1 次标出的三段 + 实物 | 每段一个完整叙述 + 一个具体日子 + 一件旧物翻拍 | 不追问「你为什么这样想」 |
| 第 3 次（40 分钟，地点回访） | 老厂、老村、老宅原址 | 边走边说；补前两次讲不清的时间线；收尾问「还有什么没讲」 | 不加新话题，只补与收 |

剪辑分配参考（8 分钟）：开场现场 45 秒（不说话，只有人和地方）→ 三段叙述各 90–120 秒 → 一段地点回访 60 秒 → 收尾一句他本人的判断 30 秒 → 片尾标注与译名/授权说明 30 秒。三段叙述必须各有一个可核对的细节（一个日期、一个数字、一个人名），否则整集没有证词层（[采访方法论](采访方法论.md) §2）。

## 11. 口述史采访提纲模板（生命周期分段）

每段一个入口问题 + 两个追问；入口一律无形容词、以「上一次／哪一年」式收口。

| 段 | 入口问题（照读） | 追问 |
| --- | --- | --- |
| 出生与家里 | 「说说你小时候那个家，几口人，房子什么样？」 | 家里谁最会说话；你帮家里挣的第一笔钱 |
| 上学与学徒 | 「你上过几年学？最后一节课是什么？」 | 谁带你入的行；学徒第一年做什么 |
| 入行 | 「第一次进（厂／市场／矿）是哪天？门口到车间怎么走？」 | 第一个月工资多少、怎么花的 |
| 手艺与日常 | 「带我走一遍你最熟的那道工序，边走边说。」 | 哪一步最容易出错；教过谁 |
| 转折 | 「这地方什么时候开始不一样了？哪一天你最先看出来？」 | 那天谁在场；你当时手上在做什么 |
| 得失 | 「为了干这行，你错过了什么？」 | 有没有哪次差点不干了、什么留住了你 |
| 现在 | 「现在这一天是怎么过的？」 | 谁还在干；年轻人为何不干 |
| 留给镜头的话 | 「如果以后有人给你孙子看这段，你想让他们知道哪一句？」 | 有没有你不希望播出去的话（必须问） |

## 12. 常见误区

| 误区 | 后果 |
| --- | --- |
| 一次采完一生，六小时不休息 | 后半段全是疲劳与套话；素材不可用 |
| 当场纠正他的年份 | 他开始迎合你，叙述权威崩塌（§3） |
| 只靠说话镜头（talking head）凑时间跨度 | 没有地点、旧物、档案，历史影像缺位即无跨度 |
| 拿学术研究同意去播 | 同意范围不足，事后不可追补（§8） |
| 方言一律配音 | 情感重量与可信度一起掉（§5） |
| 不交代发布计划就做遗言式采访 | 他来不及表达意愿，家属后来代他做主（§6、§7） |

## 实操要点

1. 生命史一人占 60% 以上说话时间，旁证只做交叉验证，不做「反对意见」标签。
2. 跨度靠四路供给：档案影像、地图、实物翻拍、地点回访；回访性价比最高。
3. 他说错了：保留、标注、交叉验证；绝不当场纠正。
4. 老人单次不超过 40–45 分钟，75 岁以上分段优于延长【操作性建议】。
5. 原声 + 字幕优先于配音；译者交代「不修饰、不合并、不确定就说」，片尾署名。
6. 抢救性记录先拿「他没讲过的」，同场问发布意愿，粗剪当天就给。
7. 私人档案要问「谁的手、谁拍、里面有谁」三件事，一人点头不等于集体同意。
8. 双用途必须双披露：同意书写明两种用途；只签研究同意就不能播。
