# 提问与追问技术

> 本篇是镜头前采访的临场技术：追问、沉默、应答纪律、收尾。学术访谈的提问谱系与转录编码见 [05-访谈](../../田野方法/05-访谈.md) 与 [深度访谈](../../社会学田野/03-方法/深度访谈.md)，不重写；这里只处理「话要被剪进片子里」这一层的现场操作。

## 1. 追问是采访的全部技术含量

第一问几乎不重要——它只是把对方请进场。片子里那 20 秒能用的话，九成来自第二、第三问。而第二问的时机不在你的提纲里，在对方上一句的尾巴里。

## 2. 八种追问手法

可直接照读的原文话术。**每一句问完，闭嘴数 3 秒**。

| 手法 | 现场话术（照读） | 什么时候用 | 拿到什么 |
| --- | --- | --- | --- |
| 复述末句 | 「——'他们没打招呼就把线停了'。」（把最后几个字原样送回，尾音上扬，然后沉默） | 万能，最省 | 展开解释 |
| 要具体例子 | 「能举个具体的例子吗？」 | 对方讲道理、讲感受、讲评价 | 个案 |
| 要一次而非一类 | 「我说的不是平时，就说上一次。哪一天？」 | 出现「一般」「都是」「反正」 | 可核查事件 |
| 时间戳追问 | 「那天几点？」「这事儿在春节之前还是之后？」 | 任何回忆、任何冲突叙述 | 时间线与因果 |
| 要感官细节 | 「你当时手上拿着什么？」「那个房间什么味道？」 | 情绪上不来、叙述发空 | 可配画面的细节 |
| 要反例 | 「有没有例外的情况？哪次不是这样？」 | 对方说法过于整齐、像宣传 | 复杂度、破绽 |
| 要比较 | 「跟去年比，哪一年更难？难在哪一项上？」 | 评价类回答（「还行」「不容易」） | 差别特征 |
| 要代价 | 「为了这个，你放弃了什么？」 | 对方在讲成绩、讲选择 | 重量与后果 |

【操作性建议】八种里最被低估的是**要代价**和**要反例**。前者把决定变成有成本的决定（观众才信），后者是对美化的最低成本检测——不加指控，只做记录。

## 3. 三层追问法：事实层 → 意义层 → 情绪层

| 层 | 你要拿的 | 话术 | 违规后果 |
| --- | --- | --- | --- |
| 事实层 | 发生了什么、几次、几个人、多少钱 | 「那天具体做了什么？」 | — |
| 意义层 | 他怎么理解这件事 | 「这件事在你看来算个什么事儿？」 | — |
| 情绪层 | 他身体的、说不清的反应 | 「说这个的时候你现在是什么感觉？」 | — |

**不许跳层**。直接跳到情绪层（「你当时是不是很绝望」）会得到两种坏结果：对方拒绝，或者对方表演一段哭。跳层的采访在剪辑台上表现为「情绪来得没有道理」——观众感到被操纵，这就是操纵。三层走完，情绪自己会到。

反向也不许：只停在事实层，素材是一份口述报告，没有片子。

## 4. 倾听的三个障碍

1. **在想下一个问题**。表现为对方话没说完就接，以及眼神飘向提纲。解法：把提纲折起来放口袋，只在收尾前打开一次。
2. **在脑子里组织解说**。你想的是「这段可以配我那句总结」，于是放过了他真正强调的东西。解法：只在纸上记**他的词**，不记你的概括。
3. **被打断的冲动**。对方说到你不同意的判断，你本能要纠正。纠正一次，之后他说的每句话都会先预判你的反应——这场采访就归你了，不再归他。

【操作性建议】判断自己有没有在听，有一个硬指标：**你的下一句问题，是不是从他上一句话里长出来的**。如果不是，你在执行提纲。

## 5. echo 与最小应答的纪律

采访者的声音是素材里的杂质，且是最贵的那种：它和同期声在同一轨上，去不掉。

- **「嗯嗯对对」为什么毁剪辑**：剪辑要在对方句子之间做切口，而你的「嗯」正好落在切口上；更糟的是，观众听到一个不出现的人在不断附和，会明显感到有人在推他说话，可信度反噬。
- **纪律一：要么不出声，要么用点头**。点头是画面上可见的、不占音轨的应答。身体前倾、目光不躲，效果等同于「嗯」，且免费。
- **纪律二：需要接话时，用他的原话 echo**（§2 第一行），声音压到比对方低一档；一旦出声，就在句子边界出声，绝不在他句子中间。
- **纪律三：不要在对方说完后立刻说话**，数 3 秒（见 [采访设计与提纲](采访设计与提纲.md) §9）。
- **纪律四：机位在你一侧时，你的头不要入画点头**；要点头就退到画框外，或干脆用第二机位（无机体）承担反应。

- [ ] 本场我打算全程不出声，只在句子边界 echo
- [ ] 耳机里监听的是自己这一轨，确认我的呼吸/舌头声不构成噪音
- [ ] 若我确实出声过多，本场结尾用同一批问题再走一遍（明确告知对方「这段我问得不好」）

## 6. 对方说空话时

空话的表现：「都是这样」「没办法」「现在大环境不好」。

| 不要做 | 要做 |
| --- | --- |
| 纠正他：「其实也不全是吧」 | 「能举个昨天的例子吗？」 |
| 换问题（当成答完了） | 「你说的'这样'，具体是哪样？」 |
| 自己补答案 | 沉默，等他把这句说完 |
| 表现出失望（叹气、看提纲） | 记下「此处他给了套话」，回头从别的路径进 |

空话是有功能的：挡问题、护同行、怕担责、不愿在镜头前说真话。**把空话本身记为材料**，这就是反身性在采访现场的具体用法（另见 [05-访谈](../../田野方法/05-访谈.md) §4 关于迎合的提醒）。

## 7. 对方跑题时

先判这三秒的跑题有没有价值——很多真实信息藏在跑题里（详见 [街头采访与素人](街头采访与素人.md) §5）。有价值就让它跑 30–60 秒，再收；无价值就切回。

收回话术（三句任选，不道歉）：
- 「那件事我们等下回来讲。先说回那天——」
- 「我记下了，一会儿还聊这个。刚才你说的那个数字是多少？」
- 「这条剪不进去，我想留你能用的那句。」（对老练受访者）

## 8. 对方沉默时的三种读法

| 读法 | 信号 | 你的动作 |
| --- | --- | --- |
| 在想 | 眼睛动、嘴唇动、身体未收 | 数 3 秒以上，别碰 |
| 在忍 | 呼吸变重、摸脸、腿停止动、看地面 | 给出口：「这里可以不谈，我们绕一下。」 |
| 结束了 | 目光找别人、身体转向外、开始微笑收尾 | 收尾三动作（§10），不要硬问 |

在忍与崩溃之间有时只有一问的距离。**判据：他是被问题推向更难说的地方，还是被推向可以说出口的地方**。前者退，后者等。停机规则见 [信任与被摄者心理](信任与被摄者心理.md) §6。

## 9. 问对方不愿答的问题

三步固定结构：**预告 + 给退出权 + 允许「这段别播」**。

> 「接下来这个我有点难开口，但我得问，因为片子需要它的另一面。你可以不答，也可以只答一半；如果你觉得哪句不要播，现在告诉我，或者剪之前你划给我。」

要点：预告降低突袭感；退出权让「答」变成选择而非压力；「这段别播」是最有效的开门话——多数人在拿到删剪权之后会说出来。这条不是话术技巧，是让渡一部分剪辑权的伦理动作（另见 [困难采访与对抗性采访](困难采访与对抗性采访.md) §5 关于审片边界）。

## 10. 打断长篇自夸 / 长篇独白

不停在句尾，停在换气处，用他的词做转接：
- 「等等——刚才那句'我自己带出来的队伍'，我想留一句，你再说一遍。」
- 「先停一下。你讲的这些里面，哪一件是你最不确定当时做对了的？」
- 「这块很清楚了。我要问一件你可能不想聊的事。」

对自我表彰型发言，最有效的不是打断而是**要代价**与**要反例**（§2）：他继续自夸，你的素材就自动出现裂缝。

## 11. 对方反问你的时候

「你是哪个学校的？」「这片子能给多少钱？」「你觉得我们这样对不对？」

**先答再拉回**。含糊回避会被读作傲慢或心虚，信任当场掉一档。答要短、要实、不承诺做不到的：

> 「我是做技术出身的，前阿里做运维，现在全职跑田野，这片子发在我自己频道上，没有平台买。你说的这个对不对，我可能有判断，但我不想到这儿就下判断——我想先把你这边说全。刚才你提到押了三个月工资，那三个月怎么过的？」

这一瞬间是建立信任的关键时刻：你被问的是「你是谁、你会怎么用我说的话」。撒谎或打太极换来的顺利，之后全是假素材。

## 12. 两句最值钱的话

- **「你说完了吗？」**——用在对方给出一个短答之后。多数人的真话在第一答之后的第二答里。
- **「还有别的吗？」**——用在每个主题块结尾、以及全场结束前。它会稳定产出两类素材：你完全没预料到的信息，以及最好的那句点题话。问完继续沉默，直到对方说「没了」是带着摇头说的。

对称地，有五句要戒：

| 戒掉 | 为什么 |
| --- | --- |
| 「我特别理解你」 | 你不可能在此刻理解；说了就把话题合上 |
| 「太不容易了」 | 替对方下结论，且给了他想听的反应，后面全是迎合 |
| 「那你想对镜头前的人说什么？」 | 直接生产表演，剪出来像宣传片 |
| 「还有最后一个问题」 | 永远不是最后一个；对方从此开始收心 |
| 「这个可能剪不进去啊」 | 现场评价素材，等于告诉他哪些话不重要 |

## 13. 结尾必做的三个动作

- [ ] **补拍反应镜头**：请他重复 2–3 句关键话（换构图，或只拍手、只拍侧脸），并录 30 秒纯环境底噪；这两样决定你能不能剪。
- [ ] **确认关键句**：把今天最想用的三句念回给他听——「我准备这样用，是这样吗？」这一步同时是事实核查与同意复述。
- [ ] **约定回看**：给一个可执行的下一步（「片子上线前我给你看这一段，你不点头我不发」），并留文字联系方式。

三件事都要在**机器还开着或刚关**的当下完成；人一起身，谈话就变成社交，拿不到确认。

## 14. 追问话术卡

打不开提纲时只带这一张。全部为可照读原文，每句后停 3 秒。

| 情况 | 说这句 |
| --- | --- |
| 不知怎么接 | 「——'（他最后几个字）'？」 |
| 回答太抽象 | 「昨天呢，昨天那一天怎么过的？」 |
| 回答太短 | 「你说完了吗？」 |
| 情绪上不来 | 「你当时手上拿着什么？」 |
| 说法太整齐 | 「有没有哪一次不是这样？」 |
| 评价类套话 | 「跟去年比，哪一年更难？难在哪一项？」 |
| 讲成绩 | 「为了这个你放弃了什么？」 |
| 跑题要收 | 「那件等下讲。先说回那天——」 |
| 敏感问题 | 「这个我有点难开口，但我得问。你可以不答。」 |
| 全场收尾 | 「有什么我没问到、但你觉得重要的？」 |

## 15. 常见误区

| 误区 | 后果 |
| --- | --- |
| 追问时给新假设（「是不是因为老板克扣？」） | 素材变成你的观点的回声，核查时作废 |
| 出声应答过多 | 同期声不可剪，被迫全消或重录 |
| 沉默时立刻补话 | 把对方最好的那句堵回去 |
| 跳层问情绪 | 表演式哭泣，观众感到被操纵 |
| 纠正对方的错误说法 | 之后他先预判你的反应，材料失真（处理方式见 [口述史访谈](口述史访谈.md) §4） |
| 结尾不做三动作 | 缺反应镜头与确认，剪辑时才发现问题 |

## 实操要点

1. 你的第二问必须从他的上一句里长出来，否则你在念提纲。
2. 八种追问里先练三种：复述末句、要一次而非一类、要代价。
3. 三层追问不许跳层；情绪只能等，不能问出来。
4. 应答纪律：不出声，或点头；非要出声就在句子边界 echo，声音比对方低一档。
5. 空话不当垃圾，当材料记下来；跑题先听 30–60 秒再收。
6. 沉默有三种读法：在想就等，在忍就给出口，结束了就收尾。
7. 敏感问题固定三步：预告、给退出权、允许「这段别播」。
8. 收尾三动作必做——反应镜头、关键句确认、约定回看，缺一算这场没拍完。
