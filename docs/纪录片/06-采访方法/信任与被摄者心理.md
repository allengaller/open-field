# 信任与被摄者心理

> 本篇讲摄影机在场时人的心理变化与现场判断。研究伦理的原则与知情同意要素见 [研究伦理总论](../../社会学田野/07-伦理/概述.md)，弱势群体的完整规程见 [弱势群体与儿童](../10-伦理法律/弱势群体与儿童.md)；这里只写采访现场怎么识别、怎么处置，以及创作者自己的心理成本。

## 1. 摄影机不是中性的

同一句心里话，饭桌上说得出口，机器前说不出口。相机至少改变四件事【通行共识】（此为纪录片实践的普遍经验，与「观察者效应」在质性研究中的位置相当，见 [08-信效度](../../田野方法/08-信效度.md)）：

| 变化 | 表现 | 后果 |
| --- | --- | --- |
| 观众席被实体化 | 感到「有一群未来的人在看」 | 语言向公共形象收敛，措辞变官腔 |
| 话有了不可撤回性 | 说出去会被反复播放、可能被熟人认出 | 敏感内容自动封口或美化 |
| 权力不对等被放大 | 上位者更自在，弱势者更谨慎 | 你的提问被读成检查或审讯 |
| 注意力被分割 | 一半在想自己看起来怎样 | 叙述变浅、句子变整齐 |

两种相反方向：**去抑制**（少数人有了机器反而敢说，把镜头当树洞，甚至夸大）与**过度自控**（更多人语速变慢、答句变短、频繁看你脸色）。判断对方在哪一端，决定你今晚该问多深。

**权力不对等如何被相机放大**：阶层、学历、年龄、性别、口音、有无固定职业这些差异，在饭桌上可以被喝酒、递烟、开玩笑抹平，在相机前抹不平——因为多出来三样东西：一台你带来的贵设备、一套你说得出而他说不出的流程（「授权」「播映」「化名」）、以及最终由你决定他留下哪二十秒的剪辑权。放大表现为三种具体动作：他改用书面语回答；他反反复复问「这个要不要紧」；他把回答看向现场唯一「懂这套东西」的人（往往是你在场的朋友、他的工头或他儿子）。【操作性建议】压不平等靠三件小事：机器由他来碰（让他按录制键）、术语先翻译成人的话、以及把剪辑权的一部分当场交出去（「这段你觉得不合适就不播」）。你无法取消这个不对等，只能让它不污染素材。

## 2. 镜头前四种典型状态

| 状态 | 识别信号 | 现场处置 | 禁忌 |
| --- | --- | --- | --- |
| 官方话术型 | 排比、四字词、「我们一贯重视」、眼神找宣传口 | 打碎模板：要一次、要数字、要昨天（[提问与追问技术](提问与追问技术.md) §2）；把机器撤到不显眼处再问一轮事实 | 别当场指出「这是套话」 |
| 表演型 | 声音压低、面向镜头说话、主动要求重来、看构图 | 顺着他：他要表演就给他一场完整表演，通常是很好的开场素材；然后从道具、实物切入拉回私人 | 别配合他喊「这条太棒了」 |
| 防御型 | 反问你的意图、答「这个不方便说」、身体后靠、频繁看时间 | 降风险：先只问流程与动作，把敏感块挪到最后；给出删剪权（「这段别播」） | 别用逻辑说服他开口 |
| 崩溃风险型 | 说起某事后开始摸脸/清嗓/长时间沉默、呼吸变重、话题回避突然变快 | 立刻降速，把问题从人挪回事：「那天车间里一共几个人？」 | 别递话、别追结论、别在他哭时问「你什么感觉」 |

## 3. 长期信任的建立节奏

【操作性建议】对长期跟拍对象（工厂、村庄、菜市场摊主、写字楼老板），不要指望第一次见面拿到能用的采访。三次递进：

| 次序 | 机器状态 | 谈什么 | 成功标志 |
| --- | --- | --- | --- |
| 第一次 | **不开机**（只带笔和本，手机也别举） | 干活、递烟、看他做事；只聊流程，不聊判断 | 他问你叫什么、做什么的 |
| 第二次 | **只开录音**，机器收包里 | 时间线、事实、数字；不追问情绪 | 他开始纠正你之前的理解 |
| 第三次 | 开机，但先拍他不拍他说话 | 正式采访，敏感块放最后 | 他会说「这句你别播」 |

为什么不第一次开机：第一次的表达质量最差，而素材会留在硬盘上——你会不舍得删，最终剪进去一条他最不像他的采访，他自己每次看到都会想起来。

## 4. 「给我看你的东西」：信任跃迁

从说到看，是从表演到本人的最短路径。开口就一句：「能给我看看吗？」

| 物件 | 能拿到什么 | 现场动作 |
| --- | --- | --- |
| 账本 / 手写单据 | 数字、时间线、赊账关系 | 先拍他翻页，再拍纸面特写 |
| 手机聊天记录 | 语气、时间戳、第三方声音 | 只拍他愿意给的那条；旁边人入镜要处理 |
| 老照片 | 生命史、家庭结构、年代 | 翻拍规格见 [档案与二次素材](../07-拍摄执行/档案与二次素材.md) |
| 工牌 / 合同 / 体检单 | 身份、雇佣关系、健康代价 | 关键页打码规则先讲清 |
| 药盒 / 工具 / 奖杯 | 身体、手艺、失败的证据 | 让他拿着说，比摆在桌上好 |

【操作性建议】给看的东西一律先录「他递过来」的手部镜头，再录特写。这一步既是画面，也是同意的影像凭证。屏幕上的第三方姓名、群聊内容、位置信息，在提出请求时就当面说明你会怎么处理。

## 5. 对方把采访当成求助

做久了必然遇到：坐下的第三分钟开始讲欠薪、讲病情、讲家里的事，最后问你「你有没有认识的人能办这个」。

你的位置：不是社工，不是律师，不是资源方。三步处理【操作性建议】：

1. **给出去处的边界，说清楚**：「我拍片子，我能做的是让别人看到这件事；我不能帮你办成事，也不能给你承诺结果。」（这句话要在开机前就说，见 [采访设计与提纲](采访设计与提纲.md) §3）
2. **不空承诺，但做转介准备**：出发前查好当地可公开查询的援助渠道（工会服务、法律援助中心、公开热线），把名字告诉他比安慰他有用。转介本身要记录，不要当成采访素材。
3. **区分求助与素材**：他求你办的事，如果不是片子需要的表达，就不要为了让他继续说而点头。用你的沉默换来的真话，代价是他日后的合理期待。

## 6. 情绪激动的现场纪律与停机规则

这一节是研究伦理在镜头前的具体化：不做无能力评估的伤害，不停在有利可图的机器上。

| 规则 | 具体动作 |
| --- | --- |
| 不递话 | 不要说「你是不是很恨他」；他的情绪要用他自己的词出来 |
| 不追结论 | 情绪峰值时把问题从「为什么」降级为「那时候有谁在」 |
| 不擦泪不握手 | 除非他先伸手；你碰到他会改变录像里的身体关系，也可能改变他的情绪走向 |
| 机器不撤 | 除非他要你停；撤机器的动作本身会被读成「这件事见不得人」 |
| 停机后不聊刚才 | 别问「刚才是不是太难受了」，改聊晚饭、聊工具、聊他孩子 |

**必须停机的判据**（任一成立即停，且这条素材默认不用）【操作性建议】：

- [ ] 对方明确说「别播」「关了」或做出关机手势——立刻停，不商量
- [ ] 出现解离样表现：叫名字反应延迟、说不出自己在哪、时间感混乱
- [ ] 呼吸急促到说话断句、手抖、起身要走却被对话困住
- [ ] 第三方（家属、工头、保安）进入并要求停止——涉及他人在场的授权，见 [弱势群体与儿童](../10-伦理法律/弱势群体与儿童.md)
- [ ] 涉及自伤或伤人风险的语言出现——停止采访，转为当下安全处理

停机不损失素材，损失的是第二次机会。这条账要算长。

## 7. 特殊对象的现场注意（心理与判断层）

详细规程在 [弱势群体与儿童](../10-伦理法律/弱势群体与儿童.md)，此处只列采访现场要当场决定的事：

| 对象 | 现场注意 |
| --- | --- |
| 未成年人 | 监护人在场会让孩子改口：先单独聊，再由监护人补授权；不问家庭隐私细节 |
| 老年人 | 一次谈不满，分段；不催，不替他补句子（详见 [口述史访谈](口述史访谈.md)） |
| 精神障碍者 | 判断「此刻他能否理解这段话会被谁看到」；不能就不录，改拍日常 |
| 重病患者 | 体力与情绪双约束；治疗中/服药后不采 |
| 劳务纠纷中的人 | 他可能把你当证据方；说明你只保存原始素材，不承担举证义务，见 [困难采访与对抗性采访](困难采访与对抗性采访.md) §7 |

## 8. 事后义务

- [ ] 回看：按约定把用到的段落给他看，留文字记录
- [ ] 给拷贝：至少给一段可用的音频或视频文件（他有权留自己的说法）
- [ ] 告知发布计划：平台、时间、是否含商业投放、是否可能进节展
- [ ] 处理删改请求：区分「事实错误 / 人身安全 / 重大隐私」与「结论与取舍」，边界见 [困难采访与对抗性采访](困难采访与对抗性采访.md) §5
- [ ] 发布后回访：被认出来的后果往往在上线之后才发生

## 9. 创作者自己的心理成本

长期听苦难、被拒、被依赖，会留下账。这不是软弱，是职业风险，和你近视 800 度是一个级别的问题。

| 症状 | 信号 | 处置 |
| --- | --- | --- |
| 苦难疲劳 | 开始觉得「又是这个」、剪辑时麻木 | 减量；同一周内插入一条与主题无关的拍摄 |
| 替代性创伤 | 反复回想别人的现场、失眠、做相关梦 | 停止跟这条线，找人说；必要时找专业咨询 |
| 被依赖的压力 | 对方天天发求助信息，你不敢不回 | 把 §5 的边界话术写进微信自动回复；固定回应时段 |
| 被拒的钝痛 | 一天被赶出四家门，晚上问自己凭什么 | 见 [行动总纲](../../研究/行动总纲.md) 第 8 节情绪风控：连续被拒立即收工，不硬扛 |
| 剪辑期的自我怀疑 | 觉得自己在消费别人的苦 | 回看开机前那句承诺，删掉只为你的表达服务的段落 |

【操作性建议】把情绪风控做成硬规则，不靠自觉：每晚复盘 15 分钟不带手机；每次深访后写三行「今天我拿走了什么、留下了什么」；同一对象的崩溃段落，一年内不复看。呼应 [行动总纲](../../研究/行动总纲.md) §8 的身体与情绪风控机制——机器可以连轴，人不行。

## 10. 采访关系阶段表

| 阶段 | 你能问的 | 你拿到的语言 | 机器 | 退出信号 |
| --- | --- | --- | --- | --- |
| 陌生 | 流程、动作、物件 | 角色模板 | 不开 | 他客气、给你倒水 |
| 熟 | 事实、数字、时间线 | 部分本人语言 | 录音 | 开始纠正你 |
| 可信 | 判断、归因、代价 | 本人语言 | 单机采访 | 主动说「这段别播」 |
| 共谋 | 后悔、秘密、身体感受 | 不说出口的那部分（沉默、脸） | 第二机位 + 特写（须再授权） | 他反过来问你怎么办 |
| 透支 | — | 迎合、疲劳、表演 | 停 | 他见你就谈「片子什么时候发」 |

【操作性建议】阶段只能前进，不能倒退一次以上：反复要求同一人重讲创伤，是从可信滑向透支最快的路。

## 11. 常见误区

| 误区 | 后果 |
| --- | --- |
| 第一次见面就开机，追求「真实初遇」 | 一条最不像他的素材，永远删不掉 |
| 用共情话换深度（「我懂你」） | 话题合上，且他开始给你想要的回答 |
| 情绪峰值时把机器凑近 | 伦理与画面双失，见 §6 |
| 答应帮忙办事以换取开口 | 材料变质，且欠下一笔无法兑现的债 |
| 把删改请求一律视为干涉创作 | 失去回访通道与后续素材 |
| 只记录对方的变化，不记录自己的消耗 | §9 的症状半年后集中爆发 |

## 实操要点

1. 相机改变的是话的公开性，不是话的真假；先判断对方在去抑制还是过度自控那一端。
2. 四种状态四种处置；官方话术用细节打碎，防御给删剪权，崩溃风险降问题到「事」。
3. 长期对象守三次递进：不开机 → 只录音 → 第三次才谈正式采访。
4. 「给我看你的东西」是最短路径，先录他递过来的手，再录特写。
5. 求助要当场划边界：你只负责让别人看到，不负责办成事；转介要预先查好渠道。
6. 停机判据写死五条，任一成立立刻停；这条素材默认不用。
7. 事后四件义务：回看、给拷贝、告知发布计划、回访。
8. 你自己的消耗按风控机制管理，不按心情管理。
