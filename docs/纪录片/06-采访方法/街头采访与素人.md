# 街头采访与素人

> 本篇只处理影像采集层：街头的拦截、许可口播、素人素材的可用性。破冰话术与咨询交付见 [行动总纲](../../研究/行动总纲.md) 第 5–6 节，此处不重复其销售逻辑；学术访谈的抽样与类型学见 [05-访谈](../../田野方法/05-访谈.md)。

## 1. 街采是什么，不是什么

街采（vox pop，vox populi）是一种**低成本获取说法多样性**的手段，不是获取证据的手段。它的正当用途有三：给观众一面镜子（别人怎么说）、找到值得深访的人（街采是漏斗口）、抓现场语态（一个市场里十个人的语气，比解说词更能说明气氛）。它的滥用只有一种：把「十个路人都说 X」当作「X 是真的」。§9 展开。

## 2. 与伦理法律底线的三条硬线

| 硬线 | 具体含义 |
| --- | --- |
| 不许偷拍陌生人回答 | 机器必须可见、身份必须自报。偷偷收音得到的回答不能进片，也不能作为事实依据（详见 [中国法律边界](../10-伦理法律/中国法律边界.md)） |
| 口头许可要收进同期声 | 街头来不及签书面文件，就用口播把同意录进素材里（§10 模板）；口播许可是最低凭证，不是完整授权 |
| 拒绝要体面退场 | 一句「没关系，不打扰您」，不追问原因、不劝、不追上去拍背影 |

【操作性建议】公共场所的拍摄仍可能涉及他人肖像与个人信息权益，公开播放前请回看 [中国法律边界](../10-伦理法律/中国法律边界.md) 与 [版权链与E&O](../10-伦理法律/版权链与E&O.md)；本篇只做风险提示，不给规避做法。原则很简单：**能问就不偷，能挡脸就挡脸，说了不播就不播**。

## 3. 30 秒判断：要不要开机器

| 开机的信号 | 不开机的信号 |
| --- | --- |
| 手上有活（正在称重、正在搬、正在修） | 在等人、在刷手机、明确赶路 |
| 主动问你「拍这个干什么」 | 眼神回避 + 后退半步 |
| 用方言回答你第一句，且句子超过 10 个字 | 只回答「还行」「不清楚」 |
| 同伴在旁边起哄让他说 | 身边有小孩、有正在处理的事务纠纷 |
| 他说的第一句里出现具体数字或地名 | 开始向你推销、要求加钱、要你删掉重来 |
| 你能一句话说清这条素材用在片子的哪个位置 | 你只是「缺素材」 |

判断标准不是「这人有意思」，是**「我能不能在 15 秒里问出一个他能答的具体问题」**。不能就别开机，改为观察式段落（[观测电影](../14-田野与影像/观测电影.md)）。

## 4. 极短采访的结构：三件套

街头素材的上限是 60–120 秒，所以结构必须极简：**一个问题 + 一个身份交代 + 一句意外回答**。

| 件 | 干什么 | 话术 |
| --- | --- | --- |
| 一个问题 | 只能一个，且是具体的 | 「今天早上几点到的？」／「这摊儿干第几年了？」 |
| 身份交代 | 让观众知道说话的是谁 | 「怎么称呼？做什么的？今年多大？」（三样，可给化名） |
| 一句意外回答 | 全片的价值所在 | 听到不对劲时只追一句：「等等，你再说一遍刚才那个数？」 |

- [ ] 机器内完成许可口播（§10）
- [ ] 拍到他的脸 + 他的手/摊/工牌（身份可核）
- [ ] 录到 30 秒环境底噪（街采素材的缝合靠这个）
- [ ] 结束时问一句「我可以播吗」，得到清晰答复并留在音轨里

## 5. 素人素材的可用性

非职业表达者（素人）不会给你「完整的段落」，但给的东西比职业发言人贵。可用的四类：

| 特征 | 为什么可用 | 处理 |
| --- | --- | --- |
| 口头禅 | 是节奏标记，也是人物标签 | 保留，不剪掉重复的「就是说」「我跟您讲」 |
| 跑题里的真信息 | 跑题往往指向他真正在意的事 | 追一句再收（[提问与追问技术](提问与追问技术.md) §7） |
| 方言与口音 | 地点、代际、阶层的直接证据 | 见下 |
| 数字与专名 | 只有他本人说得出的东西 | 必须核准一次，别自己复述 |

**方言的字幕与保留策略**【操作性建议】：

1. 原声永远保留，方言是内容不是障碍；
2. 字幕走「直译优先」：语序可微调，语气词不删，脏字不美化；
3. 实在听不懂时，加一行意译并在片尾说明「经整理」；
4. **不要为了「可懂」把人的话洗成标准话**——把「俺那儿」改成「我们那里」，被摄者就消失了，剩下的是你的转述。洗掉口音，也洗掉了观众判断「这是谁在说话」的能力。

## 6. 身份交代的取得

三样：怎么称呼、干什么、多大。话术：

> 「片子开头得说一句你是谁。你说个称呼就行，真名、姓加职业、随便起个，都行，你定。」

- 可给真名的选项必须**主动**给出来，并说明代价：「用真名更有说服力，但以后可能有人认出来。你想用哪个都行，我现在就录你说的那个。」
- 化名要在场记里同步记下映射关系（真名 → 化名），只存在加密处（另见 [05-访谈](../../田野方法/05-访谈.md) §8 关于真名映射的做法）；成片里怎么挡脸、变声，见 [交付规格表](../15-工具与模板/交付规格表.md) 与 [字幕与无障碍](../08-剪辑后期/字幕与无障碍.md)。
- 未交代身份的话，最好别用：观众无法判断「这话凭什么信」。

## 7. 多人围观与群体采访

菜市场、村口、厂门口常会自然形成围观。收益与风险并存【操作性建议】：

| 收益 | 失控风险 |
| --- | --- |
| 互相纠正，出现「你们上次不是这么说」的分歧（分歧比共识有信息量） | 有人替别人说话，被代答者失去自己的声音 |
| 群体语言有真实现场感，比单人采访松弛 | 最外向的人垄断话筒，形成一条「意见」 |
| 现场能找到下一个受访者 | 有人起哄要你拍他，素材变热闹但无内容 |
| 一个人说的时间线会被旁人补全 | 出现指向第三方的指控，公开播放风险大 |

处置：机器对着说话最少的那个人的手；主动递话给安静者（「大哥你没说，你那边呢？」）；一旦有人说「别录我」，把机器转开并且不解释。群体场面在方法上接近焦点小组，其互动价值与主持要点见 [05-访谈](../../田野方法/05-访谈.md) §5。

## 8. 被围观与反拍

在城中村、厂区、写字楼大堂，你很快会成为被拍摄对象。**你自己也是素材，而且别人也有权拍你。**

- [ ] 事前准备：手机存一句可照读的说明——「我在做一个纪实项目，记录（这里）的日常。您要拍我可以，别说我骂人就行。」
- [ ] 被围住时不举机器：先收机、盖子扣上、双手可见；解释优先于拍摄
- [ ] 有人反拍你：不停止、不抢、不遮挡对方镜头（可能引发冲突，也构成对你的素材）；把他拍进你的画面即视为默认公共场合可拍，公开使用前打码处理（见 [中国法律边界](../10-伦理法律/中国法律边界.md)）
- [ ] 被要求删除：可以答应「这一段我不播」，但**不要当场在对方手机上删除素材**；回住处按流程处理，保留原始文件（理由见 [困难采访与对抗性采访](困难采访与对抗性采访.md) §6）
- [ ] 出现安保、管理人员、警察等要求停止：停止拍摄优先于争辩；离场后记录时间、地点、对方身份与要求内容

## 9. 街采滥用的批评（这条要写重）

「问了十个人，八个说 X」，不构成任何证据。它的问题是三层：

1. **抽样不成立**：路过的人不是总体，街采样本无法描述来源分布。学术访谈对抽样的要求见 [05-访谈](../../田野方法/05-访谈.md) §1、§7，即便那套抽样也只是「信息密度」逻辑，与街采的「方便样本」完全不是一回事。
2. **提问效应未计**：你的语气、你的穿着、你举着机器，都会塑造答案（§1、[相机在场效应](../14-田野与影像/相机在场效应.md)）。街采把这种塑造做到了最大，因为它连建立关系的 20 分钟都不肯花。
3. **剪辑制造共识**：从 10 条回答里挑 8 条同向，屏幕上就出现「大家都这么说」。这是对观众的明确误导，属于事实层面而非风格层面（见 [事实核查与更正](../10-伦理法律/事实核查与更正.md)）。

**可用的写法**是把街采标成它所是的东西：「我在 XX 市场问了 12 个人，他们这么说」——它是**一处现场的说法分布**，不是**全国的结论**。需要结论时，去找能核的东西：账本、公告、统计、多个独立来源（[事实核查与更正](../10-伦理法律/事实核查与更正.md)）。

| 坏字幕 | 改后 |
| --- | --- |
| 「大家都说今年更难」 | 「我在三档摊位问了 12 个人，8 人提到订单减少」 |
| 「工人们普遍不满」 | 删掉，换成一个有名字有日期有单据的具体事件 |
| 「顾客都说涨价了」 | 「近三个月价签变化（拍摄于 3 月/6 月，同一家）」 |

## 10. 街采许可话术模板（收进同期声的口播版）

开机后先录这段，语气平、不催促，让对方原样答一句「可以」或「不可以」。

> **你**：「您好，我是曹亚仑，自己在做一个记录（菜市场／工厂／写字楼）日常的纪实视频，会发到 B 站、抖音、视频号上。相机现在就开着，画面里是您的脸和您的摊儿。我想问您两个具体问题，几十秒。您同意我拍、并且同意我把您说的话播出去吗？」
>
> **对方**：「可以。」
>
> **你**：「好，那称呼上您想用真名还是不方便？」
>
> **（若对方犹豫）**：「不方便就不拍，完全没事。」
>
> **（结束时）**：「刚才说的这些我准备播，您有没有哪句不想播的？」

要点：**平台要说出名字**、「会播出去」要在许可之前说清、拒绝之后不再追问。模板完整版可参照 [授权文书模板](../15-工具与模板/授权文书模板.md)；涉及未成年人、患者、纠纷当事人时改用书面同意（[知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md)）。

## 11. 街采的收音

街头是收音的噩梦：风、车流、喇叭、瓷砖回声、同时说话的多个人。原则与装备见 [同期声与收音](../04-声音/同期声与收音.md) 与 [收音装备](../09-技术与设备/收音装备.md)。街采特有的四条【操作性建议】：

- [ ] 防风毛套永远装在麦上，别信机内降噪
- [ ] 让被访者背对主噪声源（马路、音箱）站，你自己侧身挡
- [ ] 一句话录不好就重问一遍——街采允许重来，这是它与观察段落的区别
- [ ] 每条素材录 30 秒纯环境声；没有它，街采剪起来会断气

## 12. 常见误区

| 误区 | 后果 | 纠正 |
| --- | --- | --- |
| 拿街采当调查结论 | 事实层面站不住，且易被要求更正 | 标成「某地某人这么说」（§9） |
| 偷拍路人回答 | 素材不可用，且有法律风险 | 可见拍摄 + 口播许可 |
| 只问「你觉得怎么样」 | 得到情绪，得不到信息 | 问一个具体到能配画面的问题 |
| 不要身份交代 | 观众不知该不该信 | 三件套里的第二件 |
| 把方言洗成普通话式表达 | 人被抹平，且失真 | 原声 + 直译字幕（§5） |
| 一被围住就吵 | 你的现场安全与名声同时受损 | §8 预案 |

## 实操要点

1. 开机前 30 秒只判断一件事：我能不能问出一个他能具体回答的问题。
2. 结构固定三件套：一个问题、一个身份、一句意外回答；60–120 秒封顶。
3. 许可必须录进同期声，平台名字要在同意之前说清。
4. 主动给化名选项，并讲清真名的代价；映射表只存加密处。
5. 群体场面把机器转向说话最少的人，分歧比共识值钱。
6. 原声保留方言，字幕直译优先，不为了可懂洗掉一个人的说法。
7. 被反拍时先收机、双手可见；答应「不播」可以，当场删素材不行。
8. 「十个人里有八个说 X」不是证据，是分布；要结论就去拿能核的东西。
