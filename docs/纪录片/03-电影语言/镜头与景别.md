# 镜头与景别

> 景别不是构图习惯，而是信息分配方案：先决定这一帧要交代什么，再决定用什么焦段去交代。

标注约定：【核验】＝可回溯到公开文献或标准的事实；【通行共识】＝教材级常识；【操作性建议】＝面向单人纪实作业的做法建议，不指向某书逐字主张。器材参数（机型、传感器、镜头型号）见 [../09-技术与设备/摄影机与镜头选择.md](../09-技术与设备/摄影机与镜头选择.md)，本文只谈语言与决策。

## 1. 先把术语钉死：景别由画幅占比定义

景别（shot size / frame size）由**被摄主体在画面高度中的占比**决定，而不是由「离得远近」或「用了什么镜头」决定。

这一步必须先分清，否则后面所有沟通都会错位。同一种人物占比，可以用 35mm 走近拍，也可以用 135mm 退后拍：两者景别相同，透视完全不同（见 §3）。所以在现场说「再远一点」是无效指令，要说「人物只留半身」。

焦段一律写「全画幅等效焦距」并标出换算；跨传感器讨论时不给绝对数值，避免把 1 英寸、M4/3、Super 35、全画幅混进同一句话。具体机型与镜头参数见 [../09-技术与设备/摄影机与镜头选择.md](../09-技术与设备/摄影机与镜头选择.md)。【操作性建议】

## 2. 七级景别与非虚构功能

| 景别 | 人物画幅高度占比（参考） | 叙事功能 | 在田野里什么时候能拍到 | 滥用症状 |
| --- | --- | --- | --- | --- |
| 极远（大远景 / extreme long shot） | <5% | 交代地理、给出人与环境的比例、段落呼吸 | 厂区全景、村庄航拍、山路、市场开市前的空场 | 用它开场却不含信息，成了「我在拍纪录片」的签名 |
| 远（远景 / long shot） | 5%–15% | 建立空间关系：谁离谁多远、动线、出入口 | 车间工位排布、院坝人群、写字楼大堂 | 全片都在这个区间，观众认不出谁是谁 |
| 全（全景 / full shot） | 约 60%–75%（含头顶留白） | 维持人物识别、交代身体与工具的关系 | 访谈带手部、摊位前站定的人物、演示操作 | 切掉手，等于扔掉了最有信息量的部分 |
| 中（中景 / medium shot） | 腰部以上，约 40%–50% | 默认叙述位：既认脸又读动作，采访主力 | 坐下聊天、柜台交易、办公桌对话 | 无动机地一直用它＝画面没有起伏，像会议记录 |
| 近（近景 / medium close-up） | 胸/肩以上 | 进入情绪，读表情与迟疑 | 深度访谈的高潮段、克制的哭泣与愤怒 | 全程贴近＝情绪疲劳，观众失去判断参照 |
| 特（特写 / close-up） | 面部或一件工具占满 | 揭示细节、给出证据级信息 | 手上的裂口、工牌、药盒、缝纫机针、屏幕 | 拿特写当「电影感」装饰（虚化的手＋慢动作） |
| 大特（大特写 / extreme close-up） | 眼、嘴、指尖、刻度 | 把某一处从时间中取出，强制注视 | 只有在被摄者允许、且这个细节承担论断时 | 无信息量的器官特写＝伪深刻 |

占比为**参考区间**而非行业标准，作用是让你在监视器前有一个可读的判据。【操作性建议】

一条经验规则：**观众需要在任何一帧都能回答「我在看谁、他在哪儿、他在做什么」**。景别切换的价值，就是依次回答这三个问题。

### 2.1 现场决策顺序：先问功能，再选景别

到了现场才想「构图怎么摆」一定来不及。按这个顺序走，四步之内开机：【操作性建议】

1. 这场戏的核心信息是什么？（地理／关系／动作／表情／某个物件）
2. 这条信息在画幅里最小的可读尺寸是多大？（字要能看清、表情要能看见）
3. 有没有非人元素必须同框？（机器、货、门口、另一个人）→ 决定横竖与留白方向
4. 这一档拍满多久？（给出秒数上限，见 [./摄影机运动与节奏.md](./摄影机运动与节奏.md) 的起幅落幅余量）

## 3. 焦段：改变的不是远近，是世界的样子

### 3.1 广角（24 / 28mm 等效）

广角的物理后果：透视夸张（近大远小被放大）、边缘拉伸畸变、景深天然更深、**工作距离被迫缩短**。在纪实现场，最后一条代价最大。

- 你在 0.5–0.8m 处拍一个坐着说话的人，这个距离在县域熟人社会里属于**亲密距离**，等同于「我要跟你发生关系」，被摄者会开始表演、后退或讨好。这不是画质问题，是社交事件。【通行共识】（人际距离分区见人类学 proxemics 传统）
- 24mm 拍人脸在 0.4m 内会明显变大鼻子、瘦太阳穴——被摄者看到回放时常说「我不长这样」，这是真的：是镜头没长这样。
- 你自己的影子、手、麦克风会进入画面下缘与侧缘。要么利用（自我反射，见 [./观看位置与视点.md](./观看位置与视点.md)），要么解决（更高机位、更广的入射光方向）。
- 广角的正面价值：**纵深与层次**。市场、走廊、厂区道路在 24–28mm 下才成立（见 [./构图与场面调度.md](./构图与场面调度.md)）；小空间里它是唯一能拍到「人和他周围全部物」的选择。

### 3.2 标准（35 / 50mm 等效）

35mm 是「坐着能拍到人带环境」的极限，50mm 接近单眼中央视野的空间感，因此被称作**观察者自然视角**。它的语义是：有人在这里，用接近正常的距离看着。长期跟拍里它是最少争议的默认位——不夸张、不美化、不指责。代价是弱：在人群里 50mm 很难把你从杂乱中摘出来，你会一直跟背景搏斗。

### 3.3 中长焦（85 / 135mm 等效）

中长焦把前后景压缩、贴到主体背后，空间变「薄」，纵深被压平。在叙事上它产生两种读法：**专注**（把人的表情从环境中提纯）或**窥视**（远距离、压缩、你不在场内的证据）。后一种读法是可用的，但必须被承认：85mm 以上的远距离抓拍，观众能算出你在四十米外，于是「你为何在此」成为问题——这个要么由解说、要么由被摄者自己、要么由片头的距离设定交代。若被追问，见 [../10-伦理法律/知情同意与拍摄授权.md](../10-伦理法律/知情同意与拍摄授权.md)。

### 3.4 变焦（zoom）在纪录片里的语义

变焦在剪辑语言里是一个**可见的作者标记**：推近＝「注意这个 / 我发现了这个」，拉远＝「回到上下文」。它不像剧情片的 dolly 那样被身体经验所预期，因此观众读得出「有一个人选择了强调」。

- 定焦不变焦＝拒绝替你标注重点，是观察式长镜头的常规配置（[../14-田野与影像/观测电影.md](../14-田野与影像/观测电影.md)）。
- 变焦的唯一不可替代用途：**单机、不可重复事件**中，你来不及换镜头或走位（[../07-拍摄执行/不可重复事件现场.md](../07-拍摄执行/不可重复事件现场.md)）。此时它是工具，不是风格。
- 判据：如果你的变焦是**为了构图微调而持续发生**（每秒都在呼吸式推拉），那是失控，不是节奏。修法是变焦环限位、或干脆胶 taped 死焦段。【操作性建议】

## 4. 光圈与景深：谁被迫只看一个东西

浅景深在纪实里是双刃的。它把观众的注意力强制锁定在主体上，代价是**抹掉了环境信息**——而环境往往正是你要论证的东西（他在什么样的屋子里活着）。

- 浅景深的三宗罪：① 在 1.4–2.0 大光圈 + 近距离下，焦点误差以厘米计，人物前后移动即失焦，废片率直线上升；② 它制造一种与内容无关的「电影感」伪饰，把贫穷现场拍成精致现场，这属于表征问题（[../01-理论/表征模式.md](../01-理论/表征模式.md)）；③ 虚化的背景仍可辨认为某地，却不足以让人读出这个人**在做什么工作**——细节被抹掉、隐私风险还在，两头不讨好。
- 传感器差异要算进来：同一等效焦距、同一画幅占比下，小传感器的景深天然更深。用 1 英寸口袋机在车间里拍到 f/2.8 也能保住背景可读，是**技术给语言帮的忙**；反过来，全画幅 + 大光圈需要主动抵抗。参数交给 [../09-技术与设备/摄影机与镜头选择.md](../09-技术与设备/摄影机与镜头选择.md)。
- **深焦的场合**：当你希望观众自己找信息时（一屋子人的权力关系、生产线的节奏、家里墙上的奖状与药盒共存），用 f/5.6–f/11、24–35mm、把人物与背景都留在景深内，让视线在画内游动。这是长镜头观察美学的技术基础（[./蒙太奇与长镜头.md](./蒙太奇与长镜头.md)）。
- 【操作性建议】单机访谈默认档位：50–85mm 等效、f/2.8–f/4，背景在 1.5m 之外——既保住人物分离，又保留环境可辨识；不要为了「奶油虚化」把 f/1.4 用满。

## 5. 单机作业的两条铁律

### 5.1 为什么必须「先决定景别，再开机」

1. 现场不重复。开机后再想「要不要推近」，那个表情已经过去了。
2. REC 期间的景别调整会被录进素材，成为剪辑时无法剔除的作者动作（[./摄影机运动与节奏.md](./摄影机运动与节奏.md)）。
3. 场记要能索引。日志里写「中景／特写」比写「那段他说话」有用得多（[../08-剪辑后期/素材管理与日志.md](../08-剪辑后期/素材管理与日志.md)）。
4. 剪辑语法要求差异。同机位、相似景别的两条素材相接会触发跳切感（30 度规则，见 [./蒙太奇与长镜头.md](./蒙太奇与长镜头.md)）；只有事先规划好「远—中—特」的阶梯，才接得顺。
5. 时间预算。单机一天可录时长有限（电池、卡、体力），把预算花在三五个已决定的景别上，还是花在三十分钟无目的的推拉上，差别在剪辑台上一眼可见。

### 5.2 一个机位如何靠重新构图拍出三个景别

同一副三脚架、同一支镜头，靠**三件事**换景别：机身位置（前后 1–2m）、变焦环（分档：广/中/特三档固定，不许连续微调）、被摄者位置（请他往前一步＝改变可见性，属合法调度，边界见 [./构图与场面调度.md](./构图与场面调度.md)）。

【操作性建议】单场戏的「三档循环」：事件间隙（换人、搬货、喝水、段落停顿）才动手改档；每次改完先在心里确认新画框下缘与眼睛位置；改完拍够 20 秒再走。这样一天下来你有一机位三份素材，剪辑台上前后景别不同、可拼接。

## 6. 画幅与分辨率实战

### 6.1 把 4K 裁切当第二机位

3840×2160 画面在**每边各取一半**（2× 裁切）后正好是 1920×1080。这意味着：交付 1080 时，2× 裁切后的像素是 1:1，**你失去的正是 4K 下采样带来的锐度与噪点余量**，同时视野变窄一半（50mm 等效变 100mm 等效，景深不变、透视不变）。【操作性建议】

- 合理用法：单机跟拍中「多一个特写机位」、事后重构图救回歪的地平线、给竖屏二次取景留余量。
- 1.3–1.5× 是安全区（下采样后仍优于原生 1080）；超过 2× 锐度与噪点开始明显劣化，2.5× 以上只当「有比没有强」的备份。
- 裁切**不能**替代机位：它不动视角，透视与你所在之处完全绑定。想要不同透视，必须走过去。

### 6.2 竖屏不是裁切，是重写

横屏转竖屏丢掉的是**水平方向的全部关系**：两人并排变成上下叠（权力关系读反）、动线与出入口消失、视线留白被切掉（人物朝画右看时留白在画右，竖屏里只剩一巴掌宽）、框中框的门窗结构失效。

因此：抖音/视频号内容必须**重新取景拍摄**，而不是后期裁切；B 站横屏素材要出竖屏预告时，先确认人物在竖框内有完整的头顶留白与视线留白，否则重拍。【操作性建议】竖屏的构图红利是纵深——走廊、货架通道、厂区道路在 9:16 里比横屏更好用，前景遮挡（人群、门框）也更常帮到你。分发规则见 [../12-发行传播/自媒体分发.md](../12-发行传播/自媒体分发.md)。

### 6.3 16:9 / 2.35:1 / 4:3 的历史语义

- **16:9**：电视与流媒体的通用容器，语义是「给你看的画面」，无风格主张，代价是横向空间小。
- **2.35:1 上下遮幅**：影院宽银幕的比例残留，语义是「这是一部作品」。在手机小屏上有效画面高度被压到很小，人物特写损失最大，系列内容慎用于平台首发。【操作性建议】
- **4:3（约 1.33:1）**：早期电视与 16mm 学院画幅的比例。今天故意使用它有四种诚实理由：① 与档案素材/老电视同形，把观众放进某个年代；② 把人物「关」在竖长的框里，头顶与脚下留白变成压迫感；③ 采访密度：4:3 里一张脸占的面积远大于 16:9，靠近不必靠长焦；④ 拒绝展示环境——**只给你这么多世界**，这本身是一种立场声明。风险：如果内容上没有承担这个立场，它就只是复古装饰。【通行共识】（比例史与学院画幅）

## 7. 常见误区

- 用长焦虚化把县城拍成「质感大片」，环境信息全丢，等于自证没有论点。
- 变焦代替走动：靠推近获得景别变化，画框在动、透视不变，暴露的是你不想靠近。
- 全程中景：安全但无阶梯，剪辑时无法拼接，只能靠解说撑住。
- 一开机就构图：先开机再找画框，前半段全是废片，且现场被你的调整打断。
- 竖屏＝横屏裁中间，于是两人对话变成一个人加一块空地。
- 把 4K 裁切当「第二机位」用到 3×，交付时画面既糊又窄。
- 以为景别是摄影师的事。景别是你**在这一帧想让观众知道什么**的决定，属于叙事，不属于器材。

## 8. 单人拍摄景别保底清单

每场戏结束前自查，缺一项就别收机器。这是「能不能进剪辑」的门槛，不是愿望清单。【操作性建议】

- [ ] **地理／空间**：一个极远或远，或一条能建立空间关系的空镜（观众进得来）。
- [ ] **人物识别**：一个全景或中景，包含手与其工具（认得出是谁、在干什么）。
- [ ] **情绪通道**：一个近景（或访谈主机的中近景）。
- [ ] **证据细节**：一个特写，承担一条具体论断（伤、钱、单据、机器、屏幕）。
- [ ] **反应**：一个听的人／被谈论的人的反应镜头（接得上话，见 [./蒙太奇与长镜头.md](./蒙太奇与长镜头.md)）。
- [ ] 以上五项中至少两项来自**不同景别阶梯**，否则本场戏在剪辑台上无法自接。

## 实操要点

1. 开机前把当场的景别阶梯写在纸上（远／中／近／特），贴在机器监视器边；不按阶梯拍到的素材一律补拍。
2. 固定三档变焦（如 24 / 35 / 50 等效），除不可重复事件外不许连续推拉。
3. 访谈默认 f/2.8–f/4、背景距离 ≥1.5m、机位与眼睛同高；先确认手在画内。
4. 每次换景别只在事件间隙动手，改完至少拍 20 秒稳定素材再离开。
5. 需要特写时走近两步，而不是把 50mm 推到 135mm——透视变化会替你说出「我在观察」还是「我在放大」。
6. 竖屏另拍一套：重画框、重留白，别把横屏裁中间。
7. 每天收工前用 §8 清单核一遍素材；缺项在第二天补，长期跟拍里补拍的成本几乎总低于没有的成本。
8. 每次开机前问一句：这一帧要观众知道什么？答案决定景别，景别决定焦段，焦段决定你站哪儿。
