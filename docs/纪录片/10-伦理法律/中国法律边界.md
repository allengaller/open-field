# 中国法律边界

> 这篇不替你判断「会不会被告」，只帮你回答三个问题：哪里可能有问题、下一步该找谁、现在该准备什么材料。

**定位声明（先读这个）**：本篇是**风险识别清单与正当程序路径**，不是法律意见，更不是规避方法。中国法律更新频繁，**具体条文一律以现行有效文本为准**；重大发布（发行、参赛、商业合作、涉纠纷题材）前应咨询执业律师。本篇不提供任何绕过审核、伪装身份、隐瞒拍摄目的的做法——那是 [../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.4 层面的禁止项，不是「风险提示不足」。与未成年人、个人信息删除、监护相关的具体义务，同样以现行文本与律师意见为准。

你有的优势是 SRE 式的合规直觉：把法律风险当作**依赖关系与故障域**来管理——识别暴露面、留证据、定升级路径。按这个思路用本篇。

## 1. 肖像权与名誉权：出镜人物的两条主线

| 风险点 | 识别信号 | 你的动作 |
|---|---|---|
| 可识别性 | 正脸、侧脸 + 工牌、姓名口播、家门牌号、口音 + 职务组合 | 「认得出是他」即进入肖像权评估，打码不彻底=仍暴露（可定位性评估见 [弱势群体与儿童](./弱势群体与儿童.md) §5） |
| 未经同意的公开使用 | 台账里没有覆盖「该发布渠道 + 该版本」的同意记录 | 回到 [知情同意与拍摄授权](./知情同意与拍摄授权.md) 补确认；补不到就不发 |
| 「没商用就不算」的误解 | 以为不接商单就安全 | 【通行共识】现行民法典框架下肖像权保护不以「以营利为目的」为前提，是否盈利不是免责判据；条文表述以现行有效文本为准 |
| 名誉权 | 旁白、字幕、剪辑顺序对具体人形成负面**事实陈述**（偷、黑、骗、克扣） | 事实陈述须有证据链支撑（[事实核查与更正](./事实核查与更正.md) §2）；意见表达与事实陈述分开措辞 |
| 「合理使用/公共利益」的误用 | 以为「揭露即免责」 | 【通行共识】合理使用与公共利益情形是法定例外、范围有限，不解释成「我觉得有价值就行」；拿不准找律师 |

## 2. 隐私权与个人信息：PIPL 语境

影像中的可识别自然人信息属于个人信息处理范畴【通行共识】。本篇不逐条重述条文——**逐字核验过的条款笔记在 [../../田野方法/07-伦理.md](../../田野方法/07-伦理.md) §3.1**，其引用官方文本，以现行有效文本为准。你只需要记住四个工作区分：

| 区分 | 含义 | 落点 |
|---|---|---|
| 合法性基础 | 同意是第一路径；新闻报道等例外有严格条件，别拿来给自己当默认豁免 | 台账里每个发布动作能指回一条同意记录 |
| 敏感个人信息 | 健康、债务纠纷、身份、行踪类内容需单独同意【通行共识】 | 按 [知情同意与拍摄授权](./知情同意与拍摄授权.md) §2 高档处理 |
| 委托处理 vs 公开传输 | 把素材交给转写/打码服务商是委托处理，要能说明其数据政策；公开发布是另一回事 | 禁令一（[AI工具链](../09-技术与设备/AI工具链.md) §三） |
| 删除权 | 当事人要求删除→全链路可审计清除 | 产品承诺与操作见 [../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.4、[../../工程/使用手册.md](../../工程/使用手册.md) §3.7 |

【操作性建议】把「最小必要」当默认参数：只录与主题相关的，不顺手拍身份证、合同全文、病历、聊天记录——这些素材 99% 用不上，却 100% 构成暴露面；真需要单据入画证明事实时，特写关键行、遮其余。

## 3. 著作权与邻接权：素材侧的四条线

| 线 | 场景 | 风险等级【操作性建议】 |
|---|---|---|
| 建筑与场所 | 独特外观建筑作为主体反复出现 | 低—中：以现行文本核「室外公共场所艺术作品」类例外边界，别背结论 |
| 街头偶遇 | 路人入画、街头艺人表演被录进 | 中：路人即第 1 节当事人；艺人表演涉邻接权，作主体用需授权 |
| 音乐与画面 | 店里音响外放、KTV 歌声进同期声 | 高：意外收录也要处理，路径见 [音乐与版权](../04-声音/音乐与版权.md) §8 与 [版权链与E&O](./版权链与E&O.md) |
| 职务作品 | 你在公司拍的产品、内部资料、同事创作物 | 中—高：归属看劳动关系与约定，素材台账记清权利来源 |
| 平台协议二次授权 | 用户协议里「授权平台及其合作方使用内容」类条款 | 中：**上传即签一次**，读当期协议、存档截图（方法见 [版权链与E&O](./版权链与E&O.md) §4），别凭记忆 |

## 4. 商标与商号

| 情形 | 一般判断【操作性建议】 | 处理 |
|---|---|---|
| 店铺招牌、工服 logo 在纪实画面中自然出现 | 记录真实环境的必要组成，通常可保留 | 不刻意给特写、不美化成广告位即可 |
| 用他人商标做自己的栏目包装、头像、封面主打 | 混淆性使用，风险高 | 不用 |
| 负面报道中突出某品牌 logo | 名誉/商誉纠纷入口 | 必要性自问：遮掉 logo 是否损失证据价值？不损失就遮 |
| 拍到的假冒商品特写 | 涉他纠纷连带压力 | 记录来源与哈希，发布判断交给律师 |

## 5. 场所与拍摄：谁的楼谁说了算

| 场所 | 规则 | 你要拿到的东西 |
|---|---|---|
| 完全公共空间（马路、广场） | 可拍摄，但被拍者权利不因「公共」消失 | 见 §1、§2；场地本身无授权方 |
| 经营性场所（市场、餐馆、店面） | 经营者有场所管理权：他同意你**进门**，不等于你有权把**他店内的人和物**发布 | 店主同意（他本人也是当事人）+ 店内其他可识别顾客单独处理 |
| 私人场所（住宅、宿舍） | 进入与拍摄均须居住者同意；房东同意不等于住客同意 | 实际居住者点头，按在场人头算 |
| 企业/工厂内部 | 许可链条：场地管理方 + 雇主，常涉商业秘密与安保规定 | 书面场地许可（模板见 [拍摄许可与场地](../11-生产与资金/拍摄许可与场地.md)）；产线工艺、订单、未发布产品按保密处理——泄密纠纷不看你有没有恶意 |

**陌拜写字楼的口径**：前台/物业同意你进电梯，不等于同意你拍走廊里每个人。逐层逐门单独问，被拒即走——拒绝不是异议要解决，是结论（[伦理总论](./伦理总论.md) §3）。

企业内部拍摄的许可链条最短也要三环【操作性建议】：

| 环节 | 拿到什么 | 防止什么 |
|---|---|---|
| 场地管理方 | 允许入内与架设的书面/聊天确认 | 「谁让你进来的」类纠纷 |
| 雇主/经营方 | 允许拍摄其场所与经营活动，含负面呈现可能性的知情 | 「断章取义损害商誉」指控时你有「他们知道片子会批评」的凭证 |
| 在场的每个可识别个人 | §1 的人物授权（雇主同意不替代员工同意） | 员工出镜后主张「老板让我上的镜头」 |

三环缺一环，缺的那一环就是发布前台账里的「未清」项。**商业秘密不是「拍了才算」：你无意拍到、但成片里看得清的工艺参数与单据数字，同样是暴露面**——发现即遮（最小必要与遮法见本篇 §2 末行），遮不了的段落不进导出。

## 6. 言论与内容的常见风险类别：只做命名

下列类别**存在且真实**，你应当知道它们存在，以便在选题与发布时评估暴露面。本篇只列类别与后果性质，不提供任何规避方法——规避不是正当路径，理解边界后才谈得上合法表达（另述于 [../../社会学田野/07-伦理/中国法规.md](../../社会学田野/07-伦理/中国法规.md)）：

| 类别 | 性质 | 你侧的正当动作 |
|---|---|---|
| 诽谤/名誉侵权 | 对具体人的不实陈述 | 事实核查 + 证据链（[事实核查与更正](./事实核查与更正.md)） |
| 隐私侵权 | 公开私密信息，真实也可能侵权 | §2 的最小必要 + 单独同意 |
| 不正当竞争/商业诋毁 | 对经营主体的贬损性陈述缺乏依据 | 涉企业题材的每个指控性陈述都回到证据 |
| 涉他纠纷的连带压力 | 你的片子被一方当枪使、另一方找你删 | §7 程序，不站队式发声 |
| 平台社区规则 | 各平台自定标准，随时变化 | 以当期规则为准，不逐条背诵 |

## 7. 被要求删稿 / 收到律师函 / 被投诉：正当程序清单

按顺序执行，**不要在情绪下公开发声**【操作性建议】：

- [ ] **第一步：保全**。冻结当前版本（成片 + 工程 + 导出记录），原始素材与哈希证据链完整性立刻校验一次（操作见 [../../工程/使用手册.md](../../工程/使用手册.md) §3.4）；投诉往来记录全部留存。**不先删**——删除毁证据，且「删了就没事」是误区（§8）。
- [ ] **第二步：核对台账**。同意覆盖到这个渠道、这个版本吗？证据链里每句争议陈述有时间码可指吗？（[知情同意与拍摄授权](./知情同意与拍摄授权.md) §7、[事实核查与更正](./事实核查与更正.md) §2）
- [ ] **第三步：算清时限**。函件载明的答复期限、平台投诉的申诉窗口，写进日程；不确定就**按最短的那条准备**。
- [ ] **第四步：决定是否需要律师**。出现以下任一情形即咨询执业律师：涉及金额主张、涉及未成年或敏感个人信息争议、多方同时施压、你可能被诉的公开指控性内容。
- [ ] **第五步：书面、单渠道、一次性答复**。陈述事实与依据，引用台账与证据编号；不与对方在评论区对线，不发「声明体」泄愤。
- [ ] **第六步：该撤则撤，撤也要留痕**。依据更正机制处理（[事实核查与更正](./事实核查与更正.md) §7）：下架或修改时记录版本与原因——**撤回是处置，不是销毁**；只有当事人行使删除权才走全链路清除（[../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.4）。

## 8. 找谁：升级路径表

风险事件不是一级直升律师，按暴露面升级【操作性建议】：

| 阶段 | 情形 | 找谁 | 你要准备的材料 |
|---|---|---|---|
| L0 自查 | 只是「感觉不对劲」 | 自己：跑本篇 §1–§6 + [伦理总论](./伦理总论.md) §4 | 断言清单、同意台账导出 |
| L1 平台内 | 内容被限流、被投诉、被要求删 | 平台申诉通道（条款以当期为准） | 授权凭证截图、原始素材哈希校验报告 |
| L2 对方来函 | 收到律师函/投诉函/口头威胁起诉 | 先完成 §7 六步，再评估 | 台账全量导出 + 时间码可回连的证据链目录 |
| L3 律师介入 | 金额主张、涉未成年、敏感信息、多方施压、已被起诉 | **执业律师**（按纠纷类型选影视/娱乐法或人格权方向，通过律协公开名录自寻，不背任何「熟面孔」） | L2 材料打包；按律师要求补原始文件与哈希 |
| L4 长期整改 | 同类纠纷两次以上 | 回到错误台账找流程缺陷（[事实核查与更正](./事实核查与更正.md) §9） | 错误台账 + 本篇 §6 类别分布 |

**给律师看之前，先把材料整理成律师能直接用的样子**——断言清单、台账、凭证目录三件套齐了，咨询费至少省一半；三件套没齐之前，不要在电话里向任何人（包括律师）口头复述对方隐私。

## 常见误区

| 误区 | 为什么错 | 更正 |
|---|---|---|
| 「公共场合随便拍」 | 公共空间拍的是人，肖像与个人信息权利不因地段消失（§1、§5） | 公共只免「场地授权」，未免「当事人授权」 |
| 「打码了就安全」 | 可识别性来自组合信息：口音 + 工序 + 地名足以定位到人（§2） | 按可定位性评估，打码是手段之一 |
| 「我删了就没责任」 | 损害在发布期间已发生；删除还可能毁掉对你有利的证据（§7） | 保全→核对→正当程序，删不删是结论不是本能 |
| 「平台协议无所谓」 | 上传即签，二次授权条款会与你将来的发行安排冲突（§3） | 逐条读当期协议并截图存档（[版权链与E&O](./版权链与E&O.md)） |
| 「我不盈利就不侵权」 | 肖像权保护不以营利为前提【通行共识，§1】 | 盈利只影响赔偿量级，不影响定性 |
| 「真实就不构成名誉侵权」 | 隐私类侵权恰以真实为前提；指控性陈述的「真实」还要可证明（§6） | 事实核查是法律动作，不只是职业洁癖 |
| 「律师函=吓唬人，不理」 | 期限与后果以函件与法律为准 | §7 六步走完再谈判断 |
| 「条文我背过」 | 法律更新频繁 | 一切以现行有效文本 + 律师意见为准 |

## 实操要点

- [ ] 每次大发布前跑 §1–§6 六节自查：每节能说出「本条素材的暴露点是什么、凭证在哪」。
- [ ] 敏感信息最小必要：身份证、合同全文、病历、聊天记录不进镜头；非证不可时特写关键行并遮其余。
- [ ] 场所授权与人物授权分开记录：店主/物业同意入场 ≠ 店内顾客出镜授权。
- [ ] 上传任何平台前读当期协议，截图存入项目 `05_DOC/协议存档/`，标日期。
- [ ] §7 六步清单抄进项目置顶笔记；收到任何函件当天完成第一步（保全 + 哈希校验）。
- [ ] 涉未成年、敏感个人信息、金额主张、多方施压的争议，第一时间咨询执业律师，不自行解释法律。
- [ ] 情绪最上头的 48 小时内不做任何公开回应、不删任何素材（删除决定也等过 48 小时）。
- [ ] 每季度把本篇与现行有效文本对照一次，发现表述过时就在文件里更新——知识库的法律部分默认会过期。
