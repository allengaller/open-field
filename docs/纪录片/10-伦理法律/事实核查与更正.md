# 事实核查与更正

> 把事故响应搬进内容生产：发布前是变更评审，出错是事故，更正是复盘产物——全部留档，同类复发就是流程缺陷，不是你的疏忽。

证据日志的机制（仅可追加、SHA-256 + 可信时间戳、原件永不覆盖）在 [../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.1 已定死，本篇不重述工程细节，只回答**内容侧怎么用**。方法学同源内容见 [../../田野方法/08-信效度.md](../../田野方法/08-信效度.md) 与 [../../社会学田野/08-分析/概述.md](../../社会学田野/08-分析/概述.md)，本篇只做引用不重述。

## 1. 发布前核查：先给陈述分级

不是所有句子承担同样的证据义务。发布前把旁白、字幕、解说词里每个可争议陈述归入一级【操作性建议】：

| 级 | 类型 | 例（句式） | 最低证据要求 |
|---|---|---|---|
| S1 | 画面/原话可直接引用 | 「他说了这句话」「这家店开在巷口」 | 时间码 + 素材引用编号，能回连原始文件 |
| S2 | 需第二来源的事实 | 「这条街有 40 家档口」「工厂 2019 年搬迁」 | 两个独立来源，或一个档案来源 + 现场观察 |
| S3 | 推断 | 「押薪可能是这里行业的常态」 | 标注为推断；给出推断依据链（你观察到了什么） |
| S4 | 观点 | 「我认为这是不公的」 | 标明是作者观点（真实契约见 [真实契约](../01-理论/真实契约.md)） |
| S5 | 比喻与修辞 | 「流水线像刑具」 | 不承担事实义务，但**不许暗含可证伪的事实陈述**（「每天工作十六个小时」不是比喻，是 S2） |

**核查对象主要是 S1、S2**；S3、S4 的义务是「说清自己在推断/观点」，S5 的义务是「别冒充事实」。最常见的失守是 S5 混进 S2：修辞里藏着数字。

## 2. 证据链：每个可争议陈述指向一个编号

【操作性建议】成片定稿前，把全部 S1/S2 陈述拉一张**断言清单**，每行三列：

| 列 | 内容 |
|---|---|
| 断言 | 成片里的那句话/那行字幕，带成片时间码 |
| 依据 | 原始素材引用编号（`OF-` 或 `D03_S12_A_1430`）+ 素材内时间码 |
| 级别与来源数 | S1 或 S2；S2 另列第二来源编号 |

规则：

- 依据必须落到**带哈希与可信时间戳的原始文件**（[../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.1；剪好的时间线不是证据，原始素材才是——接口边界见 [素材管理与日志](../08-剪辑后期/素材管理与日志.md) §9）。
- 断言清单本身只可追加、不可抹行：删掉的陈述留「已删除 + 原因」行。这是把 §2.1 的日志纪律用在文字上。
- **答不出「依据」列的句子就是没核完的句子**——删、降级成 S3/S4 措辞、或推迟发布，三选一，没有第四项。

用眼成本说明【操作性建议】：核查**不靠逐帧盯屏**，靠结构：断言清单先定位时间码，你只看该段落前后各 30 秒；S1 引语优先**听**不优先看（闭眼听原声对字幕，比盯波形和省）；整轮核查查完一次休息一次，单次不超 40 分钟——这份清单是纸面工作，打印出来对着看比在达芬奇里滚时间线便宜得多。

## 3. 数字与时间：不接受记忆，也不接受口误

| 情形 | 规则 |
|---|---|
| 你自己的记忆 | 「我记得是三千人」不是 S1，连 S2 都不算；回到笔记/素材/档案重新得出 |
| 当事人说「反正就是那几年」 | 口述模糊时间按原样呈现（「大概是 08 年前后」），不许替他把「大概」剪掉变确定 |
| 口误与听错 | 数字、人名、厂名、日期一律回原声核对；方言数字（「二十三/三十二」连读）是高发错区（词表机制见 [素材管理与日志](../08-剪辑后期/素材管理与日志.md) §5） |
| 口述时间与档案时间冲突 | 两个都保留，标注法【操作性建议】：成片按叙事需要选一个呈现，断言清单里记「口述 2015，档案 2013，差异未消解」；字幕可用「据他本人回忆」限定语 |
| 无法核实的数字 | 降级为区间或主观量（「几十家」「人最多的一年」），或删；不许向上取整凑震撼 |

## 4. 交叉验证与当事人回看：引用方法，不重述

- **三角验证**：同一主题并列访谈、观察、文档三类证据，标出孤证——框架与操作见 [../../田野方法/08-信效度.md](../../田野方法/08-信效度.md) §3；OpenField 的三角验证视图即其工程化。孤证可以拍进片子，但必须在断言清单里被认作孤证，措辞相应降级（S2 的孤证按 S3 处理）。
- **成员核对（member check）**：把结论拿回当事人处核对，方法与 PIPL 注意事项见 [../../田野方法/08-信效度.md](../../田野方法/08-信效度.md) §3；影像版做法（组织当事人看素材并记录反馈的访谈程序）见 [视频回看与反馈访谈](../14-田野与影像/视频回看与反馈访谈.md)。
- 主题编码与分析步骤的规范动作在 [../../社会学田野/08-分析/概述.md](../../社会学田野/08-分析/概述.md)，做长期题材需要体系化分析时查它，本篇不重复。

## 5. 引语：逐字性与语境完整，两条都硬

| 硬线 | 含义 | 允许的操作 |
|---|---|---|
| 不拼接 | 不许把不同时间、不同问题的两句拼成一句「新意思」 | 同一次呼吸内删填充词（嗯、啊、重复）属正常清理；改句子边界即改语义，禁止 |
| 不断章 | 引语脱离语境会反转含义的（他后面说了「开个玩笑」），要么补语境要么不用 | 字幕加「（后同场补充：……）」是最低成本的补救 |
| 不改字 | 字幕必须逐字于校对后的原声；方言按词表规范转写并保留当事人用词 | 翻译/普通话化在字幕中标注为转述（处理规范见 [字幕与无障碍](../08-剪辑后期/字幕与无障碍.md)） |
| 观点归位 | 把当事人的推断标成事实 = 替他说了他没说的程度 | S3/S4 限定语（「他相信」「据他说法」） |

拼接是纪录片最不可辩护的手法：它制造了一个**没有发言人的陈述**——出了错，原话都在素材里，你却说不出是谁说的。这条线在 [剪辑方法论](../08-剪辑后期/剪辑方法论.md) 与 [纸剪与结构重组](../05-叙事结构/纸剪与结构重组.md) 的红线清单里同样存在。

## 6. 错误分级与更正形态

发布后出错按级处置【操作性建议】：

| 级 | 定义 | 例 | 形态 | 时限 |
|---|---|---|---|---|
| E1 | 不影响事实理解的小错 | 字幕错别字、时间码笔误 | 平台允许则改，不改则登记台账 | 随下次更新 |
| E2 | 影响单条陈述但不影响结论 | 「40 家」实为「26 家」 | 片内字幕卡更正 + 视频简介置顶一行 | 72 小时内 |
| E3 | 影响结论或冤枉了具体人 | 把 A 厂的事安到 B 厂头上 | 下架重制或置顶更正 + **必须通知全部受影响当事人** | 24 小时内先止损再更正 |
| E4 | 造成不可逆伤害风险 | 暴露身份、公开敏感信息 | 立即下架 + 通知当事人 + 走正当程序（[中国法律边界](./中国法律边界.md) §7），必要时咨询律师 | 即刻 |

更正形态的强度排序：**片内字幕卡 < 平台置顶说明 < 下架重制**。级别决定下限，E3 不允许只用字幕卡交差。**何时必须通知当事人**：更正内容与「他」有关时，无论级别，先发人再发公告——他应当从你嘴里知道出错，而不是从评论区。

**更正记录公开留档**：每片建一条「更正日志」区（视频简介固定尾注或合集说明页），列日期、错误、更正版、影响版本；下架的片子其更正记录不许一起删——留档记录只可追加，与 §2 断言清单同一纪律。

## 7. 更正模板骨架

可直接抄，占位符自填；**不要在任何示例位编造真实机构或个人名**【操作性建议】：

> 【更正说明】关于《××》（发布日期：20xx-xx-xx）
> 一、错误：第 xx 分 xx 秒处，本片陈述「……」，与事实不符/证据不足。
> 二、事实：经查证，……（依据：×× 档案编号 / 两位当事人访谈编号，可回查时间码）。
> 三、影响：该错误涉及/不涉及具体当事人；已于 x 月 x 日通知相关当事人。
> 四、处置：本片已替换为 v0x 版本/已下架；旧版本仅存档不再分发。
> 五、责任：以上核校疏漏由本片作者承担。联系方式：××。
> 作者 ××，20xx-xx-xx

骨架五段固定：错误—事实—影响—处置—责任。「深表遗憾」式外交辞令不要写，道歉的效力来自具体。

## 8. AI 参与披露与 09 章同一条线

凡影响事实断言的 AI 参与（转写、翻译、摘要、打码、检索）逐项写入处理登记，口径与 [AI工具链](../09-技术与设备/AI工具链.md) §2.8、禁令三完全一致，不另立标准。补充一条本篇独有：**AI 转写稿永远不是 S1 陈述的依据列**——依据是带时间码的原声文件，转写只是找到它的索引（同一立场见 [编码存储与备份](../09-技术与设备/编码存储与备份.md) 所在章的素材证据规则）。

## 9. 错误台账：复发即流程缺陷

【操作性建议】每个错误在断言清单外再记一行，进 `05_DOC/错误台账.md`：

| 字段 | 内容 |
|---|---|
| 日期与版本 | 发现日、涉及的成片版本号 |
| 级别 | E1–E4 |
| 错误类型 | 数字/时间/人名/归属/语境/引语/权利/其他 |
| 逃逸路径 | 它穿过了哪道本该拦住它的工序（L1 日志？断言清单？回看？） |
| 流程补丁 | 给那道工序加的规则，**必须具体到可执行**（「下次仔细点」不算补丁） |

这是你从 SRE 带来的最大优势：复盘问的是**防线为什么没拦住**，不是**你怎么又粗心**。同类错误类型复发一次，即认定流程补丁无效，重开一条：两次复发同一类型，本周停更做流程修订。台账季度看一次分布，错得多的类型就是你工作流的结构性弱区。

## 常见误区

| 误区 | 为什么错 | 更正 |
|---|---|---|
| 「纪录片不是新闻，不用核查」 | 真实契约下观众按事实对待你的每句话（[真实契约](../01-理论/真实契约.md)） | S1/S2 全量建断言清单 |
| 「当事人说的就是事实」 | 口述是 S2 级来源不是 S1 级证据（§3、§4） | 孤证标孤证 |
| 「剪掉的那句他反正也说了」 | 不同语境的两句话拼出来的是第三句话（§5） | 不拼接是硬线 |
| 「错了悄悄替换，没人发现」 | 悄悄替换不可审计，且对当事人不诚实（§6、§9） | 更正留档、通知在先 |
| 「删视频就是最高级更正」 | 下架不解释=事实真空，谣言比错误跑得快 | 下架 + 更正说明成对出现 |
| 「数字差不多就行」 | 差的那部分恰好是最容易被对方抓住的把柄 | 区间化或删除，不取整凑效果 |
| 「AI 转写稿对得上就算有依据」 | 转写是索引，原声才是证据（§8） | 依据列只填带哈希的原始文件 |
| 「我又不是机构，哪来核查资源」 | 断言清单是按时间码分工的纸面活，不需要团队（§2） | 一次 40 分钟，分轮做 |

## 实操要点

- [ ] 每片建断言清单（§2 三列），只可追加；依据列填不出编号的句子当天处理掉。
- [ ] 数字、日期、人名、厂名在精剪前全部回原声核对一遍；口述与档案时间冲突按 §3 双保留标注。
- [ ] 引语核查用「听不盯屏」：闭眼对原声校字幕，打印清单纸面作业，单轮不超 40 分钟。
- [ ] 关键结论至少一次成员核对，影像项目走 [视频回看与反馈访谈](../14-田野与影像/视频回看与反馈访谈.md) 流程。
- [ ] 发现错误先定级（§6），E3 以上先通知当事人再发更正；更正用 §7 骨架五段。
- [ ] 每次更正进错误台账，写「逃逸路径 + 流程补丁」；同类型复发一次即重做补丁，两次即停更修流程。
- [ ] AI 参与项与处理登记核对一遍（§8），转写稿不作为任何断言的最终依据。
- [ ] 发布前最后一问：如果这条断言是错的，我最迟会在哪道工序发现它？答不出，说明这道工序不存在。
