# 版权链与E&O

> 权利链（chain of title）就是素材的依赖关系清单，E&O（Errors & Omissions）就是上线前的责任兜底——用你管发布的方式管发行。

音乐的权利语义与授权路径细节在 [音乐与版权](../04-声音/音乐与版权.md)，档案素材的获取流程在 [档案与二次素材](../07-拍摄执行/档案与二次素材.md)，素材编号与日志主键在 [素材管理与日志](../08-剪辑后期/素材管理与日志.md)。本篇只管一件事：**证明你有权用你用出去的每一秒。** 本篇不是法律意见；许可合同与平台协议的解读，重大发行前咨询执业律师或专业发行方。

---

## 1. 两个概念，翻译成你的语言

| 影视发行概念 | SRE 等价物 | 核心动作 |
|---|---|---|
| 权利链（chain of title） | 依赖清单 + 每个依赖的许可证：你的成片是根节点，每个素材是叶子，权利文件是凭证 | 每个素材入库时把凭证路径写进台账，缺一环即标记不可发布 |
| E&O 保险 / 权利审查 | 上线前门禁 + 责任险：交付方/平台要求你证明无侵权风险，或买保险兜底 | 发行前按 §7 材料包自查；保险费率与条款以当期报价为准，本篇不写数字 |

**「权利链断裂」和「依赖里有一个来路不明的包」是同一类故障**：平时没人问，出问题时每一秒都要你回答。回答方式是台账，不是记忆。

## 2. 哪些素材需要权利证明

| 素材类型 | 需要的凭证 | 常见断裂点 |
|---|---|---|
| 自拍画面（含同期声） | 当事人同意/授权记录（[知情同意与拍摄授权](./知情同意与拍摄授权.md) §7 台账） | 发布范围扩大后旧同意不覆盖新版本 |
| 第三方画面、档案影像、照片 | 许可合同/授权邮件/曲库或图库订单 + 允许媒介清单 | 只买了「可以剪进去」，没买「可以发行/投流/海外」 |
| 音乐 | 见 §4 | 同步权与录音权只买了一边 |
| 字体 | 商用授权（含字幕、海报、平台封面图） | 用个人授权字体出商业物料 |
| 画面内受版权内容 | 海报墙、画、雕塑、游戏画面、电视屏幕内容 | 「拍到的算背景」不总成立，主体化呈现即风险 |
| 场地与道具 | 场地许可、道具来源 | 道具服装带他人商标（[中国法律边界](./中国法律边界.md) §4） |
| AI 生成成分 | 工具条款 + 处理登记（[AI工具链](../09-技术与设备/AI工具链.md) §2.8） | 条款说不清能否商用即不可依赖 |
| UGC（网友投稿素材） | 作者本人授权 + 作者对画面内他人的权利陈述 | 投稿者并非拍摄者 |

**自拍素材也要凭证**——凭证就是同意台账；「自己拍的所以不用登记」是权利链第一大漏洞。

## 3. 素材权利台账：字段表

【操作性建议】一张表管所有素材权利，与 [素材管理与日志](../08-剪辑后期/素材管理与日志.md) 共用文件名/`OF-` 引用编号主键，单独存 `05_DOC/权利台账.md`：

| 字段 | 取值示例 | 说明 |
|---|---|---|
| 素材/条目 | `D03_S12_A_1430` 或 `ARCH-2026-001` | 与日志主键一致 |
| 来源 | 自拍/购自 ×/网友投稿/公共渠道 | 来源决定凭证类型 |
| 许可范围 | 剪辑+发布+发行+投流（逐项） | 未列出的媒介=未获许可，默认不可用 |
| 期限 | 起始日 / 永久 / 至 20xx | 到期前 60 天进复查队列 |
| 地域 | 中国大陆 / 全球 | 参赛海外单元先核这一列 |
| 媒介 | 网络 / 院线 / 电视 / 短视频 / 全媒介 | 「全媒介」最值钱，最常买错 |
| 可否商用 | 是/否/限投流 | 与个人账号变现（恰饭、分成）口径对齐后再买 |
| 可否二次分发 | 是/否 | 平台转载、授权切片宣传物料都算二次分发 |
| 凭证文件路径 | `05_DOC/凭证/xxx-合同.pdf` | **路径为空=无凭证=不可发布**，没有例外 |
| 到期日期与提醒 | 2027-06-30 | 与日历同步 |
| 状态 | 可发布 / 受限 / 未清 / 已过期 | 「未清」状态素材禁止进导出 |

导出前扫描按「状态 + 凭证路径非空」双条件过滤，机制同 [素材管理与日志](../08-剪辑后期/素材管理与日志.md) §6 的硬标记——**权利管理和授权管理共用一套门禁，不靠自觉**。

## 4. 音乐：权利链上最密的依赖

音乐在一秒画面里叠了多层权利【通行共识】：**作曲/作词（词曲著作权）→ 录音制品（录音制作者权）→ 表演（表演者权益）**；把你选的曲子同步到画面上用到的是**同步权**，平台公开传播另触**表演权/广播权/信息网络传播权**类问题。细节与三条获取路径（原创委托/授权曲库/直接授权）见 [音乐与版权](../04-声音/音乐与版权.md)，本篇只立两条台账规则：

1. **一首曲子在台账里是一组行，不是一行**：词曲一行、录音一行，各自有许可范围/期限/地域/凭证。曲库订单通常打包，也要把订单号与允许媒介逐项抄进两行。
2. **曲库与免费音乐的条款按「当期协议」认定，不按「平台名气」认定**【操作性建议】：常见的坑是「曲库可用于个人账号，但不可用于投流、商业项目、线下放映」这类限制条款。本篇不写任何具体平台的条款细节——条款会变，**每次使用时逐条读当期协议并整页截图存档进凭证目录**，日期写进台账。截图存档是你未来唯一能出示的「当时版本」。

「用了 15 秒应该没事」「改了速度就查不到」这类说法：不存在安全秒数，规避识别更不是权利方案（[音乐与版权](../04-声音/音乐与版权.md) §7、[AI工具链](../09-技术与设备/AI工具链.md) §二末段的同一立场）。

## 5. 免费/开放许可素材的合规

| 条款元素 | 含义 | 你的动作 |
|---|---|---|
| CC0 / 公有领域 | 无权利要求 | 仍记录来源与获取日期——「找不到来源的 CC0」等于没有来源 |
| 署名（BY） | 必须按要求署名 | 署名信息进台账，成片署名位落实（规范见 [字幕与无障碍](../08-剪辑后期/字幕与无障碍.md)） |
| 非商用（NC） | 商业使用不允许 | **先定义自己的「商用」**：接商单、平台分成、投流、参赛收费放映，任一命中按商用处理 |
| 禁止演绎（ND） | 剪辑、调色、配字幕可能构成演绎 | 有 ND 的素材要么原样使用要么不用 |
| 相同方式共享（SA） | 衍生作品需同许可开放 | 对整片适用传染性条款，个人作者慎用他人 SA 素材 |

硬规则一条【操作性建议】：**来源不明的素材即不可用**——包括「网上找到的无水印图」「AI 搜出来的视频」。查不到权利人，就没有凭证路径可填；填不出这一列，素材进「未清」，永不进导出。

## 6. 自开授权与创意共用的边界

你自己拍的素材，你是权利人，可以给别人开许可【操作性建议】：写明允许媒介、商用与否、署名要求、期限；用标准 CC 协议可以省去解释成本，但注意 **CC 的 irrevocable（不可撤回）特性**——你的授权 irrevocable，不等于别人对你画面里当事人的授权义务 irrevocable：素材含可识别人物时，你对外授权的范围不能超过当事人同意你的范围。给粉丝二创、给媒体引用，都先过 [知情同意与拍摄授权](./知情同意与拍摄授权.md) §6 的档位表。

## 7. 发行要求的权利文件包与清权工序

面向电影节、平台、发行方的交付，权利文件包通常包括【操作性建议】：权利链总表（即 §3 台账导出）、全部凭证文件、当事人授权书汇总、音乐清单（每曲：词曲/录音来源 + 凭证）、无侵权声明或保证函、（被要求时）E&O 保单或自留风险决定记录。**具体清单以当期合约附件为准，签约前逐项核对，别背旧模板。**

**清权（clearance）工序**——谁签字：

| 步骤 | 动作 | 签字人 |
|---|---|---|
| 1 | 粗剪锁定后跑时间线权利扫描（台账逐行对照导出片段） | 你（剪辑侧） |
| 2 | 「未清/受限/过期」三类处理：替换、补凭证或删 | 你（制片侧） |
| 3 | 音乐逐曲核凭证与允许媒介 | 你 + 必要时作曲/编曲方书面确认 |
| 4 | 发行合同签署前，权利文件包外发前的终审 | 你本人签；有合作方时各权利持有人分签 |
| 5 | 到期项复查（§3 提醒列）与版本变更后的重扫 | 每次新版本导出前 |

一个人也要有「签字」这一步——**在台账末尾写一行「v03 权利终审：曹亚仑，日期」就是签字**。没有这个仪式，清权就退化成「感觉应该没事」。

## 8. 替换与静默的成本，永远低于纠纷

冲突预判：某段音乐权利买不起或谈不拢时，成本排序永远是——**换原创/换曲库可负担项 < 静默处理（同期声顶上，见 [解说与静默](../04-声音/解说与静默.md)） < 结构上删掉这段 < 赌一把发出去 < 纠纷后的下架、赔偿、信誉损失**。【操作性建议】在粗剪阶段就标「贵音乐占位」，不要等到精剪后才发现整段结构长在一首买不起的曲子上；占位曲与替换方案同进台账，替换即更新凭证行。

## 9. 签发行/合作合同前：权利条款三核对

合同条款的逐条解读请律师（升级路径见 [中国法律边界](./中国法律边界.md) §8）；本篇只管你在签字前必须能回答的三个问题【操作性建议】：

| 核对 | 问题 | 回答不了的代价 |
|---|---|---|
| 授予范围 | 我授予对方的媒介、地域、期限，是否超过我当事人同意我的范围 + 我素材凭证覆盖的范围？ | 你对第三方做了你其实无权做的承诺，违约与侵权两头 |
| 保证条款 | 合同要求我「保证无侵权、权利完整」时，我的 §3 台账有没有一行对得上一秒素材？ | 空口保证=E&O 风险自留，纠纷时全由你兜 |
| 回授权与存续 | 合作终止后我的片子还能不能自己发？对方还能不能再发？ | 长期作品被单一渠道锁死，或素材外流收不回 |

与制片侧合同管理（谁签、怎么签）见 [团队组建与合同](../11-生产与资金/团队组建与合同.md) 与 [拍摄许可与场地](../11-生产与资金/拍摄许可与场地.md)；本篇视角始终是**权利凭证**，不是商业条款。

## 常见误区

| 误区 | 为什么错 | 更正 |
|---|---|---|
| 「自拍素材没有权利问题」 | 当事人授权就是你的权利凭证（§2） | 同意台账进权利链 |
| 「曲库订阅=全场景可用」 | 个人账号、投流、商业项目、线下放映常被区分对待（§4） | 读当期协议 + 截图存档 |
| 「CC 素材随便用」 | BY/NC/ND/SA 各有硬约束（§5） | 逐要素核，商用定义从严 |
| 「找不到来源但画面好看，先用」 | 无凭证=不可发布（§5 硬规则） | 宁缺毋滥 |
| 「买了录音就买了同步权」 | 多层权利互相独立（§4） | 词曲/录音分行记账 |
| 「E&O 是大公司的事」 | 发行方与平台会要求权利保证；无保险=自担风险 | §7 文件包是你自己的门禁 |
| 「授权我随手给别人就行」 | 对外授权不能超过当事人给你的范围（§6） | 过档位表再开 |
| 「发布后再补凭证」 | 事后补不到就是补不到，风险已发生 | 清权在导出前 |
| 「小账号没人管侵权」 | 通知与投诉不以粉丝数计 | 平台协议 + 正当程序（[中国法律边界](./中国法律边界.md) §7） |

## 实操要点

- [ ] 建 `05_DOC/权利台账.md`（§3 十一列），凭证路径列空着即「未清」，未清永不进导出。
- [ ] 每首音乐拆词曲/录音两行；每次使用曲库前逐条读当期协议并整页截图入 `05_DOC/协议存档/`，记日期。
- [ ] 商用定义写死在台账首页：含平台分成、商单、投流、付费放映；NC 素材对照此线使用。
- [ ] 无来源素材设自动淘汰：入库两周内查不到权利人即移出可用池，保留在档案位但不进时间线。
- [ ] 粗剪锁定后跑一次全片权利扫描；每个新版本导出前重扫（§7 步骤 1–2）。
- [ ] 每次发行签约前，把 §7 权利文件包按当期合约附件清单核一遍，核完签字留名。
- [ ] 买不起的音乐当场换或静默，不赌（§8 成本排序）；占位曲替换后同步更新台账。
- [ ] 含可识别人物的素材对外授权时，先核当事人同意覆盖范围，再开许可。
