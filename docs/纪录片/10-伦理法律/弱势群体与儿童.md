# 弱势群体与儿童

> 权力不对称越高，「他同意了」这句话的证明力就越低——这一档的同意不是签字动作，是一套需要你自己搭起来的保护机制。

框架判据见 [伦理总论](./伦理总论.md) §4 三层判据，本篇处理其中第二层得分最高的对象。同意流程、台账、撤回的通用机制见 [知情同意与拍摄授权](./知情同意与拍摄授权.md)，本篇只写**差异项**。

**本篇不是法律意见**；涉监护、涉未成年人的具体法律义务，以现行有效文本为准，重大事项咨询执业律师（风险识别路径见 [中国法律边界](./中国法律边界.md)）。

---

## 1. 本项目语境下的弱势清单

不按「可怜程度」排，按**同意能力与后果承担是否分离**排【操作性建议】：

| 类别 | 你的典型场景 | 不对称来源 | 附加机制（本篇对应节） |
|---|---|---|---|
| 外来务工者 | 工厂、城中村、劳务市场 | 雇佣链、居住不稳定、怕丢活 | §4、§6 |
| 小摊贩 | 菜市场、夜市、城管边缘 | 经营场所不稳定、执法敏感 | §7 暂停检查表 |
| 性少数 | 访谈中自述身份 | 出柜风险不可逆、熟人社会 | §5、§8 |
| 疾病与残障 | 职业病、工伤、慢病访谈 | 身体状况影响同意持续性 | §4 能力受限 |
| 欠债与纠纷中的人 | 欠薪、借贷、拆迁争执 | 素材可能被对方当武器 | §5、§8 |
| 未成年人 | 城中村孩子、工友子女 | 同意能力未完成 | §3 |
| 被拍摄地的少数者 | 民族、方言、信仰差异 | 误读与标签化风险 | [表征的政治](../01-理论/表征的政治.md) |
| **反向情形：你的下属在场** | 你带助手拍；或受访者本身是你雇的人 | 他在你面前没有拒绝自由 | §4 权力污染 |

最后一行容易漏：**弱势不是身份，是处境**。平时强势的老板，在他上游的甲方面前是弱势；你镜头下的「硬汉」在离婚诉讼中是弱势。每次开机前重估一遍处境，不贴永久标签。

## 2. 核心原则：「对方答应了」在这一档不构成充分条件

【通行共识】研究伦理对同意能力不足者的处理是双重保护：合法代理人的许可 + 本人能力范围内的拒绝权。落到你一个人身上，规则化为三条【操作性建议】：

1. **代理同意不能替代本人表态**：监护人签了字，孩子当面扭头走开——走开有效，停。
2. **本人的拒绝具有对任何同意的优先否决权**：包括他自己此前签过的、其监护人选过的档位。
3. **同意是过程不是节点**：能力受限者的「当下同意」可能随状态失效（§4），所以要设冷却期与二次确认。

## 3. 儿童

| 事项 | 规则 | 理由 |
|---|---|---|
| 同意结构 | 监护人同意（书面为宜，[知情同意与拍摄授权](./知情同意与拍摄授权.md) §2 高档处理）**加**儿童本人当场愿意配合的可观察信号；缺任何一边不开机 | 代理同意 + 本人 assent 双轨 |
| 提问方式 | 不诱导：不问「你想不想上电视」「阿姨给你拍个照好不好玩」；允许用孩子语言重述「我在拍视频，会发到网上」 | 诱导取得的表态不可靠 |
| 表达后果 | 不让孩子承担任何表达后果：不追问家里收入、父母矛盾、成绩排名；孩子主动说的敏感话，默认不用 | 他们没有评估传播后果的能力 |
| 可爱素材 | 「萌娃」段落是**复用风险最高**的素材：今天的小爆款，五年后还在网上 | 发布确认按 [伦理总论](./伦理总论.md) §5 跑，且默认约定孩子成年后要求删除的路径 |
| 就学与健康 | 拍摄不占用上课、治疗、吃饭睡眠；一次访谈时长对儿童减半 | 你在提取他们的时间 |

**儿童本人拒绝的现场识别信号**（他没有说「不」的义务，你有看懂的义务）【操作性建议】：扭头、后退、往监护人身后躲、突然安静、反复看大人脸色、要玩具要离开——任一再认即停拍。**年龄分段的具体法律义务（几岁以下需要何种监护人形式同意）以现行有效文本为准，本篇不写岁数线，重大事项咨询执业律师**；不确定时按更严的一档执行永远不亏。

**「可爱素材」的二次检查**：萌娃段落最容易被顺手发出去（涨粉最快、当事人最小），所以给它单设一道闸——发布确认必须由监护人**点名这一条**，不接受项目级总授权自动覆盖（总授权机制见 [知情同意与拍摄授权](./知情同意与拍摄授权.md) §8）。

眼睛的账也算：儿童素材极碎，回看筛选耗时最长——**用现场多录标签代替事后逐帧找**，孩子说了关键话立刻喊「记一条」入日志（做法见 [现场工作流与安全](../07-拍摄执行/现场工作流与安全.md)），后期只回看标过的段落。

## 4. 能力受限者：当下同意无效，设冷却期

认知障碍、疾病晚期、重度疼痛、情绪崩溃中（哭喊、歇斯底里、反复说「随便你」）——这些状态下人仍能点头，但点头不构成同意【操作性建议】：

| 状态信号 | 现场动作 | 事后动作 |
|---|---|---|
| 无法复述「这是拍什么的、发哪里」 | 停办同意手续，只聊 | 状态平稳日再谈 |
| 情绪崩溃（采访中段突然哭到说不出话） | 问一句「继续还是歇会儿」，答案含糊一律停 | 素材冷却：本次不剪不导出 |
| 病情波动/药物影响明显 | 本次不采集该主题 | 由长期照护者 + 本人分别确认，缺一不可 |
| 反复说「你们怎么弄都行」 | 这不是同意，是放弃；主动把档位摊开让他选 | 摊不开就按最保守的 B/D 档处理 |

**冷却期规则**：上表任何一行触发的素材，至少冷却一个发布周期（你的周更节奏=7 天），期间不剪、不导出；到期后按 [伦理总论](./伦理总论.md) §4 重跑判据。**权力污染同样适用**：员工在老板在场时的表态、家属在病床边替病人做的「都行」，全部重新单独确认。冷却要落到台账上才成立：在同意台账对应行追加「冷却至 20xx-xx-xx + 触发条目」（表结构见 [知情同意与拍摄授权](./知情同意与拍摄授权.md) §7），素材文件名带 `_COOLING` 标记进染色分组——一个人工作没有同事提醒你，**标记就是你留给下周三的自己的提醒**。

## 5. 尊严优先于戏剧性

这是本片最硬的一条规则：**崩溃、哭喊、窘迫、身体细节，默认不发布；要用，必须过双重门槛**【操作性建议】。

| 素材类型 | 默认 | 发布需同时满足 |
|---|---|---|
| 哭喊、情绪失控 | 不进导出 | 本人（非家属代签）明确点名同意这一段落 + 最坏情况测试无不可逆伤害 |
| 身体细节（伤口、病体、如厕、换衣） | 只可拍叙事必需且即时评估 | 医学或劳动安全信息价值明确 + 本人同意具体镜头 + 无更弱替代镜头 |
| 窘迫（被训斥、被拒、出丑） | 化名或删 | 该窘迫即主题本身（如欠薪当面讨要）+ 当事人回看过这段 |
| 疾病/残障的日常 | 可拍，禁猎奇化 | 呈现的是生活不是奇观，自检见 [表征的政治](../01-理论/表征的政治.md) 套路表 |
| 性少数身份暴露 | 绝对不先于本人出柜 | 本人书面点名同意公开范围（平台、搜索可见性）；身份暴露不可逆，撤回形同虚设——发布前多犹豫一次 |

判据记一句话：**这段素材的戏剧性，是从他的尊严上撕下来的吗？是，就撕小一点或者不撕。**「剪掉之后片子会弱」不构成发布理由——片子弱了是你的成本，尊严碎了是他的。

## 6. 付费与给好处：补偿与诱导的界线

| 问题 | 判据 |
|---|---|
| 给不给钱？ | 不因拍摄致其误工而分文不给是常态性不对等；**补偿性**给付（交通费、误工费、饭钱）合理 |
| 什么时候变诱导？ | 金额大到「同意与否主要取决于钱」，或你在对方困难时开价（欠薪工人正缺钱，你出 2000 元买他讲欠薪经过——这是诱导）【操作性建议】 |
| 怎么给？ | 在谈同意时**同步**说清：给多少、什么名目、与内容无关、说了不满意的段落也会给；写进同意书收益条款（[知情同意与拍摄授权](./知情同意与拍摄授权.md) §3） |
| 不给怎么办？ | 明确说「我没有预算，只有片尾致谢/将来发行时再谈报酬」——**诚实的不给优于含糊的欠账**；不给造成期待落差的主因是你回避谈钱 |
| 给之后 | 钱不买到「不许撤回」；给付是补偿，不是买断 |

长期跟拍者另有一条：**对方记住你给过多少**。同一项目内补偿标准不一致，会在素材还没剪之前先毁掉田野关系。

## 7. 高风险场景暂停拍摄检查表

出现下列任一信号，把机器放下（镜头盖盖上、录音键停），花 30 秒过表【操作性建议】：

- [ ] 现场出现对抗：争吵升级、肢体逼近、执法或管理人员介入清场
- [ ] 当事人进入情绪临界：哭到无法连贯说话、解离式发呆、反复「随便」
- [ ] 出现第三方：孩子、醉酒者、明显不愿意被拍的旁观者入画
- [ ] 信息超出本次同意范围：对方开始说疾病、债务、报案、身份秘密
- [ ] 你自己的状态：害怕、愤怒、想「抓住这个瞬间」的手感
- [ ] 场所风险：正在营业的灶台边、行车动线、楼顶、水边

30 秒内依次问：**这个瞬间不可重复吗？**（不可重复的现场处置见 [不可重复事件现场](../07-拍摄执行/不可重复事件现场.md)）→ **拍下去最坏发生什么？**（[伦理总论](./伦理总论.md) §4 第三层）→ **有没有不拍的记法？**（口头记录、事后补记笔记，见 [../../田野方法/04-观察与笔记.md](../../田野方法/04-观察与笔记.md)）。三个问题答完再决定开不开。默认值：**犹豫就不拍。**

## 8. 成名之后的义务

素材一旦公开，撤回不等于消失——转载、录屏、搜索缓存都不在你手里。所以【通行共识】：

1. 播放量越大，**发布前**的门槛越要提高：小爆款阶段可以「发布确认靠微信」，账号变大后高档位素材一律回看 + 书面点名段落。
2. 建立**当事人联系通道**并保持有效（换手机号要更新台账）；对方几年后找你处理，你的义务不因「早就下架了」而消灭。
3. 从对方身上长出来的流量收益（商单、平台分成、发行）按事先约定兑现；事先没约定的，事后主动给一个说法（[知情同意与拍摄授权](./知情同意与拍摄授权.md) §3 收益条款）。

## 常见误区

| 误区 | 为什么错 | 更正 |
|---|---|---|
| 「家长签了字就能拍孩子」 | 代理同意不能替代本人表态（§2） | 孩子本人的拒绝有优先否决权 |
| 「他自己说要讲的，我有什么办法」 | 崩溃中的表态不是同意（§4） | 冷却期 + 二次确认 |
| 「哭的这段最有力量」 | 尊严优先于戏剧性（§5） | 双重门槛，过不了就删 |
| 「打码了就安全」 | 身份暴露常靠口音、工序、地名组合（§5 性少数行）；打码是手段不是判据 | 按可定位性评估，不按有没有脸 |
| 「给钱就没伦理问题」 | 给付可能是诱导，也不买到撤回权（§6） | 同步、名目清楚、与内容无关 |
| 「不给钱显得抠，含糊过去算了」 | 含糊欠账比诚实不给破坏更大 | 明说预算与替代致谢 |
| 「弱势是身份，认出来就行」 | 弱势是处境，随场景翻转（§1 末行） | 每次开机重估 |
| 「红了以后再补同意」 | 事后再无同意，只有补救（[伦理总论](./伦理总论.md) §6） | 门槛随传播范围同步提高 |

## 实操要点

- [ ] 开机前花 10 秒过 §1 清单重估在场者的**处境**（含你自己的助手、受访者自己的下属），命中任一行即启用本篇附加机制。
- [ ] 儿童素材：监护人书面同意 + 本人现场愿意信号，缺一不开机；萌娃段落默认约定成年后的删除通道。
- [ ] 情绪临界即停，素材进冷却期（≥7 天不剪不导出），到期重跑三层判据。
- [ ] 崩溃、身体细节、窘迫、身份暴露四类素材按 §5 表逐条对照，默认值是「不进导出」。
- [ ] 补偿标准在项目内统一，谈同意时同步讲清并写入同意书。
- [ ] §7 检查表打印贴箱盖内侧；「犹豫就不拍」执行到形成肌肉记忆。
- [ ] 台账里给每位当事人留「联系通道有效」字段，每半年核一次。
