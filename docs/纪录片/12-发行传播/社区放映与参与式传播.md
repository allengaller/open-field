# 社区放映与参与式传播

> 放映是最小、最快、也最诚实的一次发行：它把「我做完了」变成「有人看了，并且当面说了话」。对一个人跑田野的项目来说，放映不是宣发的附属环节，它是研究的一部分。

参与式传播（participatory communication）在本篇指一件事：把成片与素材交回被拍的人，并让他们有可能用自己的渠道说自己的话。方法与田野层的展开在 [../14-田野与影像/参与式影像.md](../14-田野与影像/参与式影像.md)，本篇只处理**已经拍完之后怎么放映、交回什么、权利怎么说**。

## 1. 为什么还做线下放映

【操作性建议】先承认它不赚钱。放映的现金回报通常低于同等工时的跑场拍摄，所以要用别的东西算账。

| 放映能给的 | 放映给不了的 | 判据 |
| --- | --- | --- |
| 当场、不可修饰的接受反应 | 传播量 | 观众听完就说「哪里不像」，比上线后两百条评论更有信息量 |
| 当事人看到成片的确定场合 | 分账收入 | 回场是伦理动作，见 §2 |
| 本地关系的固化（场地、同行、潜在合作方） | 算法友好度 | 一场二十人等于一次受众访谈，见 [./受众与传播效果.md](./受众与传播效果.md) §3 |
| 可核查的「有人完整看过」记录 | 素材再生产 | 归档与自述材料里，这是唯一能证明作品完成度的现场证据 |

## 2. 给当事人先看：义务，也是质量控制

这是硬顺序：**先给当事人看，再给公众看**。伦理层的完整规范在 [../10-伦理法律/知情同意与拍摄授权.md](../10-伦理法律/知情同意与拍摄授权.md) §8 的发布确认流程，回看访谈的做法在 [../14-田野与影像/视频回看与反馈访谈.md](../14-田野与影像/视频回看与反馈访谈.md)。本篇关心的是：放映档期怎么给这一步留出返工余量。

**先看不是审片**。界线与场地一侧完全一致（[../11-生产与资金/拍摄许可与场地.md](../11-生产与资金/拍摄许可与场地.md) §8）：

| 可以接受 | 不可接受 |
| --- | --- |
| 当事人指出事实错误、指代错误、字幕错字 | 当事人有权要求把不利于他的部分全部删掉 |
| 当事人撤回同意、要求不拍某段 | 场地或客户以「放过片」为条件给钱 |
| 当事人补充他要说的一句话（另录，不改原话） | 由当事人替你决定哪些人可以看 |

【通行共识】先看真正能查出的东西，几乎都不是「他会不会不高兴」，而是只有本人在场才能识别的信息：工种黑话听错、同音人名写错、画面里可被反推到个人的细节（门牌、工位、工牌、票据）。这类错误上线后只能更正，放映前是一次免费修补。

三种回看反应的处置：**否认说过**（按 §6 的切片硬线回查原始素材与时间码，错在我则改，无误则当面放原始时间码，不争吵）；**要求删段**（按已签授权的范围处理，不临时重新谈判，超出范围则接受撤回）；**指出事实错误**（记入断言清单，按 [../10-伦理法律/事实核查与更正.md](../10-伦理法律/事实核查与更正.md) 分级重定）。

【操作性建议】回看是盯屏工序，长片分两到三次看，用纸面时间码表记（一行一条：时间码 / 他的原话位置 / 问题类型 / 处理）。不要靠记忆，也不要靠软件里打字——那会让你把一次本可以谈事情的面谈变成一次校对。

## 3. 一场小型放映的最小配置

| 项 | 最低要求 | 绝不可省 | 可以省 |
| --- | --- | --- | --- |
| 场地 | 能遮光、能坐定、有电、出口清楚 | 放映前亲自去看一次场地并试放 | 体面 |
| 画面 | 投影仪或大电视 + 一根够长的信号线；白墙可用 | **提前一小时完整试放**（含字幕、含片尾） | 分辨率 |
| 声音 | 外接音箱或场地音响，人声听得清 | 声音 | 画面色彩 |
| 字幕 | 烧录进画面的版本，不依赖播放器 | 有字幕 | 多语种 |
| 秩序 | 座位数不超过你能主持讨论的量 | 人数上限自己定 | 签到表 |
| 记录 | 一台录音 + 一张反馈纸表 | 事先告知并同意 | 摄影 |

【操作性建议】判断顺序：**听不清就没人看，看不清还有人看**。设备预算永远先给声音。若场地的音响不可用，宁可减到十人以内的笔记本围坐，也不要在两百人的空场里用笔记本外放。人数上限按「你能听完每个人说话」定，不按场地容量定。

## 4. 免费、收款、以及钱的边界

| 做法 | 适合 | 失败模式 | 必须事先说清的一句话 |
| --- | --- | --- | --- |
| 完全免费 | 首作、当事人所在地的回场 | 你的工时无人承认，自己也失去价值感 | 「本场不收费，场地费由我承担」 |
| 场地 AA / 门口自由付 | 半公开场次 | 到账不稳定、事后争议 | 钱给谁、怎么分，开场即当众说明 |
| 收款售票 | 有稳定受众后 | 当事人被当成收费的招牌 | **涉及当事人的场次若收款，钱的去向必须公开说一句** |
| 机构出场地费 | 与美术馆、书店、高校合作 | 隐性审片要求随之而来 | 放映范围与剪辑终审仍归我（界线见 §2） |

不给当事人带来「被拿来卖」的印象，是这一节的全部要点。具体分配不承诺数字，按你自己的试错资金包上限换算；所有放映收支进同一张现金流表（[../11-生产与资金/预算与制片管理.md](../11-生产与资金/预算与制片管理.md) §3），不要留在微信零钱里当作没发生。

## 5. 现场告知与二次拍摄规则

开场用固定的一段话，长度六十秒即可（片长九十分钟的场也一样），四句结构：**这部片拍了多久、在哪里**；**当事人今天在场或不在场**；**允许不允许拍摄、允许拍什么**；**片子和拷贝后续怎么取得**。

二次拍摄分三档，开场就宣布是哪一档：全部不拍；可拍屏幕与讲者，不可拍观众正脸；可拍但不得发布含当事人可识别面貌的现场影像。你若录像，进门时告知并保留一个「不录像座位区」——观众同意也是同意，不能因为「大家都这么拍」就默认。

合影与联系方式：当事人不是公共资源。任何人索取其微信、电话、店铺地址，当场拒绝并事后告知本人；这条与 [../11-生产与资金/团队组建与合同.md](../11-生产与资金/团队组建与合同.md) §8「当事人联系方式不外给」一致。

## 6. 讨论引导问题清单

| 类型 | 示范问法 | 为什么这样问 |
| --- | --- | --- |
| 不解释你没拍的 | 「这部分我没拍，我只有别人的转述，所以我不回答」 | 与节展 Q&A 同一条纪律（[./电影节与展映.md](./电影节与展映.md) §6） |
| 问感受不问结论 | 「哪一段你坐不住了」 | 结论会被人替你说，生理反应不会 |
| 问本行共鸣 | 「你们厂里也有这样的事吗，怎么处理的」 | 这是唯一能测出「行内人认不认」的场合 |
| 问哪里不像 | 「有没有哪里一看就不像」 | 比「你觉得怎么样」有效十倍 |
| 问下一步 | 「你们还想看到什么」 | 直接喂给下一次田野的问题清单 |

主持三条纪律：不演讲；不答你没拍的东西；不知道就说不知道。现场谁说了什么，记下时间点（谁 + 一句话 + 时刻），事后按 [../15-工具与模板/场记表与素材日志.md](../15-工具与模板/场记表与素材日志.md) 的格式补一行；口头同意的录音记录也要标注同意方式。

## 7. 把放映当研究方法：田野—影像—放映—再进入

这不是一条流水线，是一条循环链条：每一圈把上一圈的假设变成被验证或被推翻的东西。

```
田野 → 影像 → 放映 → 再进入 → （新）田野
 ↑                                      ↓
 └──────── 断言清单与素材日志的修订 ←────┘
```

| 环节 | 产出 | 验证什么 | 下一圈要问 |
| --- | --- | --- | --- |
| 田野 | 观察记录、疑问清单 | 我能不能进去、谁愿意说 | 该拍的没拍到的在哪 |
| 影像 | 粗剪、母版 | 素材能否支撑我想说的那句话 | 我的解释是不是唯一读法 |
| 放映 | 现场反应、问题清单 | 观众实际读到什么（常与你以为的共识不同） | 谁的反应最反常，为什么 |
| 再进入 | 新访问、补充拍摄 | 反常反应回到当事人处是否成立 | 该升的升、该降的降 |

【操作性建议】放映暴露的最大一类错误，是**把只在你圈子里成立的判断当成常识**。三层反应要分开记：当事人怎么说、同行（本行业的人）怎么说、外行怎么说。三者不一致时，把外行的误读当预告——上线后的评论区一定会那样读。

写回机制：放映后的每一条实质反馈，要么变成断言清单里的一次降级（[../10-伦理法律/事实核查与更正.md](../10-伦理法律/事实核查与更正.md)），要么变成素材日志里的一个补拍条目（[../08-剪辑后期/素材管理与日志.md](../08-剪辑后期/素材管理与日志.md)）。放映频率不设指标，作为质量闸门插在结构复盘处（[./数据复盘与迭代.md](./数据复盘与迭代.md) §4），几次一圈由你自己的复盘周期定。

## 8. 素材交回：权利怎么说

| 交回什么 | 后果 | 建议 |
| --- | --- | --- |
| 成片拷贝 | 最轻，几乎无条件给 | 每次放映后都给，并附一行说明（拍于何时何地、你的署名方式） |
| 原始素材片段 | 他可自由再剪，可能出现你不认得的版本 | 给，但附「剪辑后的表述不代表我方解释」一句话，不禁止他发布 |
| 工程文件 | 你失去单一事实源，且无法保证版本一致 | 不给（与 [./流媒体与平台发行.md](./流媒体与平台发行.md) §2 第 1 格同理） |

约定三条即可，写成一张纸：他用自己的影像与话语时**不需要你许可**；他若标明「出自 ×× 纪录片」，你有权要求标注准确或撤下署名；你的发布仍受当事人同意约束，双向不对称是有意为之——**你有权力，所以你有义务**。以上非法律意见，涉及权利转让、许可范围的重大安排请咨询执业律师并以书面文本为准。

【操作性建议】技能不对等时不要「教他剪」。给他真正用得上的三样：一段可用的原始素材、一句可直接复制的说明文字、他自己的名字。交回不等于共同决定发布：他自己公开发布的内容，是你素材库之外的独立行为，不代言、不切割，需要引用时按档案与二次素材的规则标注（[../07-拍摄执行/档案与二次素材.md](../07-拍摄执行/档案与二次素材.md)）。

## 9. 线下放映的风险

| 风险 | 识别信号 | 事前一步 | 事后一步 |
| --- | --- | --- | --- |
| 场地临时取消 | 口头约定、无书面档期 | 提前确认 + 备一个小规模替代场地 | 当天公开改期，不隐瞒原因 |
| 设备故障 | 未做过完整试放 | 试放 + 自带线材与备份片（U 盘 + 手机各一份） | 降级为笔记本围坐，继续 |
| 无人 / 超员 | 报名不确认、渠道单一 | 人数上限写在通知里；报名超额即截止 | 超员不加座，安全出口不能被占 |
| 提问越界 | 追问当事人隐私、要求表态 | 主持人开场规则里说明「可以问作品」 | 三句收场：「这个问题涉及他的私人处境，我不代他回答；他本人在场可以自己决定；我们可以回到作品本身」 |
| 二次传播失控 | 现场录像可被识别出当事人 | §5 规则开场宣布 | 联系发布者要求删除含可识别面貌的片段，走平台正式渠道 |
| 行政与备案类要求 | 场地被要求提供材料 | 以场地与主管部门当期要求为准，走正式流程；不构成内容改动承诺 | 记录并要求书面化 |

有人要求「先看过片再决定能不能放」——回到 §2 的界线：**可以给内部放映，不给审片权**。若对方坚持要删，答案是取消放映，不是改片。

身体约束：一场放映等于「讲 + 答 + 收 + 记录」四个工序，当晚不排剪辑，次日不排长途驾驶（[../../研究/行动总纲.md](../../研究/行动总纲.md) §8.4 的强制回家周期同样不可替换）。

## 常见误区

| 误区 | 为什么常见 | 怎么改 |
| --- | --- | --- |
| 把放映当宣发，只算到场人数 | 数字好看、可截图 | 放映的产出是问题清单，不是照片（§7） |
| 先公开放映，再补当事人回看 | 场地档期难约、怕来不及 | 当事人回看先于任何公众场次，排期时先占位 |
| 现场接受一切提问 | 怕显得回避 | 不解释你没拍的东西，是纪律不是失礼（§6） |
| 「交回素材」停在口头 | 觉得一家人不谈两家话 | 三条约定一张纸，双方各留一份（§8） |
| 收款却不说明去向 | 觉得钱不多无所谓 | 涉及当事人的场次，钱的去向开场当众说一句（§4） |
| 一场办成大型活动 | 难得聚一次 | 一次一场，人数按你能主持讨论的量定（§3） |

## 实操要点

- [ ] 任何公众放映前，完成当事人回看并留出可返工的余量（时间码纸面记录，分次看）。
- [ ] 开场六十秒说清四件事：拍了多久在哪、当事人在不在场、能否拍摄、拷贝怎么拿。
- [ ] 宣布二次拍摄档位，保留不录像座位区；索取当事人联系方式的请求当场拒。
- [ ] 放映收支写进现金流表；涉及当事人的场次若收款，当众说明钱的去向。
- [ ] 提前一小时完整试放，含字幕含片尾；声音不足就减人数，不减字幕。
- [ ] 讨论只用五类问题；记下「谁 + 一句话 + 时刻」，会后补进日志。
- [ ] 交回成片拷贝与可用原始素材，附一句说明与他的名字；不给工程文件。
- [ ] 每圈放映结束写一份「反常反应清单」，作为下一次进入田野的问题来源。
