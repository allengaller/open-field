# 流媒体与平台发行

> 平台不是渠道，是一套用权利换触达的交易。你要判断的不是「上不上」，是「让出哪一格、留住哪一格、什么时候必须回退」。

本篇给**条款判据与核对程序**，不复述任何平台的当期细则（规则常改，以平台现行规则逐条核对，§5）。法律内容不构成法律意见，重大签约前咨询执业律师。交付规格见 [../08-剪辑后期/交付母版与规格.md](../08-剪辑后期/交付母版与规格.md)，权利链见 [../10-伦理法律/版权链与E&O.md](../10-伦理法律/版权链与E&O.md)。

---

## 1. 先分清三件事

| 形态 | 你得到 | 你让出 | 适合阶段 |
| --- | --- | --- | --- |
| **平台定制 / 采购（买断、预付）** | 确定的现金、制作资源、稳定排播 | 题材方向、审片与终审、较长期限与较宽媒介范围 | 有作品、需要一次稳定回款 |
| **平台分账 / 合作** | 按播放或收入的分成、平台推荐位的可能性 | 独家或首发、数据披露义务、格式与规范服从 | 有受众、能承受收入波动 |
| **自己上传公开平台** | 完整控制权、即时发布、账号资产归自己 | 触达的天花板、无预付、需自己做技术与合规 | 全程，尤其周更主阵地 |

【操作性建议】三者不互斥，但**顺序不可逆**：先在公开平台建账号资产，再谈分账，最后才谈定制——反过来，你会在最没有议价能力的时候签最长期限。

## 2. 条款逐条看什么：十二格判据表

| # | 条款 | 要看的具体问题 | 判据 |
| --- | --- | --- | --- |
| 1 | 授权标的 | 授的是「这部片」还是「本片及素材、衍生版本、后续剪辑」 | 只授成片的必要版本，素材与工程不外授 |
| 2 | 媒介（media） | 电视 / 院线 / 网络 / 移动端 / 播客 / 航空 / 教育，各格分开列 | 未列出的媒介默认保留，不写「全部媒介」 |
| 3 | 地域与语言 | 大中华区 / 全球；配音字幕语言版本谁做、谁付 | 你未确认的市场不放；分地域切，别一次放全 |
| 4 | 期限 | 几年；到期后权利如何回退 | 期限越短越好，且**写明到期即终止、不需另行通知** |
| 5 | 自动续约 | 有无需明示同意的自动续 | **默认续 = 不可接受**，要写明须双方书面同意 |
| 6 | 独家性 | 独家 / 非独家 / 分窗口独家（window） | 独家必须有对价（预付或保证推荐位）且必须有窗口期终点 |
| 7 | 可否自行分发 | 你能否在自己的账号上放、能否给节展放映、能否给当事人拷贝 | **必须保留**：现场放映与当事人拷贝（[./社区放映与参与式传播.md](./社区放映与参与式传播.md)） |
| 8 | 剪辑权与审片 | 谁有权改；改的范围；争议如何解 | 保留终审，或至少保留「要求删除署名」的权利；**把改动的最终决定权交给对方不可接受** |
| 9 | 署名与作者信息 | 署名位置、顺序、能否要求删除署名 | 不得放弃署名；也不允许对方擅自加名 |
| 10 | 下架与违约 | 谁可下架、通知期、下架后你还能否使用自己的内容 | 必须有一条**主动下架/回退通道**，且违约定义不能包含「平台规则变化」 |
| 11 | 结算口径 | 计费口径（播放/有效观看/广告分成）、结算周期、对账数据、扣除项 | **要求可核对的原始数据**，无数据的分成条款等于赠与 |
| 12 | 数据披露与合规义务 | 你要向平台提供什么、平台向观众展示什么；备案与标识类要求的承担方 | 义务分工写清；当事人个人信息不承担披露义务 |

## 3. 绝不签的四条红线（判据，不是条款原文）

【操作性建议】以下四项没有「先签后补」的版本，谈不下来就不签：

1. **转让全部著作财产权**（或「永久、全球、全媒介、不可撤销」的组合）——你把作品的所有后续可能性一次性卖完，包括再剪、教学、出版、修复。
2. **放弃署名**，或允许对方无限制匿名使用你的作品。署名是纪实作品的可信度本体，真名出镜更是（[../../研究/行动总纲.md](../../研究/行动总纲.md) §4.2）。
3. **无限期独家且无回退通道**：没有终止日、没有未达承诺时的解除权、没有主动下架权。独家可以谈，必须带终点与触发式回退。
4. **让渡剪辑终审权而不设补救**：对方可以改结构、加解说、换结论，而你只能保留署名。若确实要让出终审，最低补救是**「有权要求删除署名并停止以你为作者的宣传」**——这一条几乎没人主动给，必须提。

另外两条属于伦理而非商业【操作性建议】：**不得授出超出当事人同意范围的用途**（纪实栏目的同意不覆盖广告、教育、商用；用途变更即需重新同意，见 [../10-伦理法律/知情同意与拍摄授权.md](../10-伦理法律/知情同意与拍摄授权.md) §1）；**不得承诺播出**（审核、排播、当事人确认都可能让它播不出去，承诺播出是最容易失信的一句话）。

## 4. 三种形态各自的额外问题

| 形态 | 额外必问 |
| --- | --- |
| 定制/买断 | 制作费是否覆盖全部成本（含你的工时，见 [../11-生产与资金/预算与制片管理.md](../11-生产与资金/预算与制片管理.md) §8）；超支谁担；素材归属；验收标准由谁定；尾款触发条件 |
| 分账/合作 | 有效播放如何定义；扣除项有哪些；推广资源是承诺还是「视情况」；独家窗口多长；能否同时在自有账号发布切片 |
| 自上传 | 平台协议里的授权范围与期限（**默认协议常写得很宽**，逐条读）；内容标识与声明要求；变现资格与结算门槛（以当期规则为准）；账号违约处置与申诉路径 |

## 5. 平台侧技术要求：按类别核对，不背细则

【操作性建议】技术合规只有四类要核对，每类都**以平台当期规则为准逐条比对**，任何二手经验（含别人的截图）都不作依据：

| 类别 | 你要做的 |
| --- | --- |
| 画面与声音规格 | 分辨率、帧率、码率、响度、声道：按平台要求另导一版，母版不动（母版是单一事实源，见 [交付母版与规格](../08-剪辑后期/交付母版与规格.md)） |
| 内容标识与声明 | 是否需标注 AI 生成/合成内容、商业合作、纪实类声明；标注口径按当期平台规则执行并留档 |
| 备案与资质类要求 | 长片、系列、上线分发的登记与资质要求，**以现行规定与平台流程为准**，走正式流程；不确定就暂缓上线，不猜测 |
| 字幕与无障碍 | 见 §6，各平台差异最大的一格 |

## 6. 字幕与无障碍的平台差异

【操作性建议】三件事在各平台规则不同，投递/上传前分别确认：**内嵌字幕 vs 独立字幕文件**（平台是否支持后者、是否会自动压制）；**语言档位**（是否需双语、哪种为默认轨）；**无障碍要求**（听障字幕的完整度、是否需要口述影像/audiodescription 轨）。制作规范见 [../08-剪辑后期/字幕与无障碍.md](../08-剪辑后期/字幕与无障碍.md)。**平台不支持时的正当做法**是提供符合要求的替代版本或说明，而不是降低字幕完整度。

## 7. 内容审核未通过：正当处理路径

【操作性建议】被驳回、限流、下架提示时，按这个顺序，**不要跳过任何一步，也不要寻找规避性表述**：

1. 读**具体驳回理由原文**并存档（截图带日期），不要凭转述行动；
2. 自查三类事实问题：可识别个体是否有有效同意、陈述是否核得到依据（[事实核查与更正](../10-伦理法律/事实核查与更正.md) §2）、商业合作与 AI 生成内容是否按规定标注；
3. 需要修改就**改内容本身**（删段、遮脸、化名、改字幕），并同步更新同意台账的版本号；
4. 认为判定有误，走**平台官方申诉通道**一次，陈述事实与依据（引用你的许可与核查记录），按平台要求补充材料；
5. 申诉不成，接受结果：改版本、换形态，或不发布。**不采用**任何规避审核的做法（改词、拆条、暗语、绕道分发）——这类做法一旦被认定，损失从「一条内容」升级为「整个账号资产」，而账号资产是你五条收益线里不可再生的一格（[../../研究/行动总纲.md](../../研究/行动总纲.md) §3）；
6. 涉及当事人权益的驳回（可能伤害到被摄者的内容），处理顺序是**先通知当事人、再处理版本**。

## 8. 聚合发行与自发行的取舍

聚合发行（aggregator）= 中间人替你对接多个平台的分发与结算。判断只看四格【操作性建议】：

| 维度 | 走聚合 | 自发行 |
| --- | --- | --- |
| 覆盖 | 你无力逐平台对接与格式适配时，覆盖更多 | 只覆盖你手动维护的渠道 |
| 成本 | 抽成或年费，实际到手比例下降 | 无抽成，成本高在工时 |
| **数据归属** | 原始数据常在对方案里，你可能只能看到报表 | 数据在你手里，可核对、可复算 |
| 权利 | 授权链变长（你→聚合→平台），转授范围必须写死 | 一对一，范围可控 |

**决策点只有一个：数据与回退。** 若合同不给你可核对的原始数据、不给你主动下架权，抽成再低也不签；反之，若你能承担工时（每上一个新平台约需一到两日的规格与物料工作，见 [../11-生产与资金/预算与制片管理.md](../11-生产与资金/预算与制片管理.md) §1 发行线），自发行更划算。**无论哪种，素材原件与工程文件不出手**（同 §2 第 1 格）。

## 9. 长视频与中视频平台对纪录片的适配判断

【操作性建议】这一格要写清冲突并明确让步线：

- **时长与完播率（completion rate）的张力**：完播率随时长下降，因此分账模型天然奖励短、快、钩子密集的内容（平台通用机制只写到「完播、互动、关注转化、分享」这一层，具体权重不属本库内容，见 [./自媒体分发.md](./自媒体分发.md) §4）。纪实价值的来源恰恰相反：等待、重复、无解的段落、必须熬过才出现的真实（[../07-拍摄执行/长期跟拍.md](../07-拍摄执行/长期跟拍.md) §1）。
- **让到哪一步（可让）**：切分集数与重排前 60 秒的信息顺序；把结论性的一句提前做小标题；给长版做中版与短切片；在封面与标题上直白但不失实。
- **不让（不可让）**：不改变当事人话语的结论；不加不存在的冲突与戏剧；不为了节奏拼接引语（红线见 [../10-伦理法律/事实核查与更正.md](../10-伦理法律/事实核查与更正.md) §5）；不用当事人痛苦做悬念；不把「安排好的现场」当日常呈现。
- **判断法**：任何一处「为平台改」，问一句——**这一改动如果当事人看到，会不会认为我说了他没说的话？**会，就不改；不会，就可以改。

## 10. 窗口顺序：节展、平台、自有账号谁在前

【操作性建议】这三类渠道互相抢的是「首次」，所以顺序要在投递前定死并写进日历（与 [../11-生产与资金/预算与制片管理.md](../11-生产与资金/预算与制片管理.md) §4 的 G5 同一时点决定；首映条款的读法见 [./电影节与展映.md](./电影节与展映.md) §5）：

| 目标优先 | 建议顺序 | 代价 |
| --- | --- | --- |
| 节展优先 | 定剪 → 投递（保住首映状态）→ 结果明朗后再谈平台独家 → 自有账号收尾 | 数月空窗且无现金流入，落选时要有兜底版本 |
| 现金流优先 | 分账或采购先签 → 放弃需首映的条件 → 只投不设首映限制的展映类 | 节展筹码下降，权利期容易被锁长 |
| 自有受众优先 | 自有账号首发 → 再谈非独家分发 → 按「非首映」类别投节展 | 账号已有量级会反过来压低平台报价 |

三条不变：**给任何一方的首发或独家都写期限与回退**；窗口顺序一旦向观众公开承诺就不静默改动；当事人所在社区的放映排在一切公开首发之前（[./社区放映与参与式传播.md](./社区放映与参与式传播.md) §2）。

## 常见误区

| 误区 | 事实 |
| --- | --- |
| 「先签了，以后再谈回来」 | 到期回退、终止权、数据披露这些空格事后要不回来 |
| 「独家给久一点平台更重视」 | 期限越长你的期权越便宜；独家必须有对价与终点 |
| 「分账就是被动收入」 | 没有可核对数据的分账条款等于赠与（§2 第 11 格） |
| 「素材给对方一起管更省事」 | 素材与工程一旦出手，换人、再剪、参赛全部受限（§8） |
| 「审核没过就想办法绕」 | 绕行的代价落在账号资产上，账号是五条线里最不可再生的一格（§7） |
| 「平台要求背下来就行」 | 规则每期变；只按当期页逐条核对并留档（§5） |
| 「为了完播率必须砍掉慢的段落」 | 可让节奏，不可让语义；砍掉等待会砍掉作品本身（§9） |
| 「自上传没有合同就不用读协议」 | 默认协议常授权很宽；上传前读授权范围、期限、标识与申诉路径 |

## 实操要点

- [ ] 顺序：先自有账号建资产 → 再谈分账 → 最后谈定制/买断；在最弱的时候不签最长期。
- [ ] §2 十二格逐条填判据表，空白格带去问律师（本篇非法律意见）。
- [ ] 四条红线写在谈判纪要首页：不转全部财产权、不弃署名、无回退的无限期独家不签、让出终审必须有删除署名的补救。
- [ ] 保留现场放映与当事人拷贝的权利，以及一条主动下架通道。
- [ ] 分账要求可核对数据；聚合发行先确认数据归属与转授范围。
- [ ] 技术合规按 §5 四类核对当期规则并留档，母版不动、另导一版。
- [ ] 审核未通过按 §7 六步走，只改内容本身、只走官方申诉；不采用规避做法。
- [ ] 每处为平台的改动过一遍 §9 的判断法：当事人会不会认为那是他没说的话。
