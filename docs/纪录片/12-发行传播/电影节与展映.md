# 电影节与展映

> 对一个人的长期项目，节展的主要价值不是流量，是同行反馈、权利与后续资金、以及作品被正式归档。想清楚你要哪一样，才不会把投递当成抽签。

本篇给**判断方法与核实程序**，不列具体节展名单、年份、费用与期限——这些每期都变，写进知识库就会变成错误（§2 给核实方法）。交付件的技术规格见 [../08-剪辑后期/交付母版与规格.md](../08-剪辑后期/交付母版与规格.md)。

---

## 1. 节展能给什么，不能给什么

| 能给 | 不能给 |
| --- | --- |
| 同行与策展人的当面反馈（比评论区有效一个量级） | 大量观众；绝大多数展映的在场人数以百计，不以万计 |
| 后续资金的入口（提案会、创投、基金评审人常在同一批人里） | 传播量承诺；节展曝光与算法推荐是两套完全不同的分发 |
| 作品被正式归档与可引用的履历事实 | 权利保护本身——保护来自你的权利链档案（[../10-伦理法律/版权链与E&O.md](../10-伦理法律/版权链与E&O.md)） |
| 一次「必须交卷」的外部期限，逼你定剪 | 事实可信度的加持；节展不替你核查（[../10-伦理法律/事实核查与更正.md](../10-伦理法律/事实核查与更正.md)） |
| 与同类作者的关系网 | 观众对长期项目的耐心；一部 90 分钟的观察型作品在节展也未必被看完 |

【操作性建议】投递前先定一句「这一次我要的是哪一格」，写在报名表上方。要反馈和要归档的项目，投法完全不同。

## 2. 类别梯度，以及如何自己核实当期清单

【操作性建议】按四类理解结构，不记名单：

| 类别 | 特征 | 适合你的阶段 | 判断要点 |
| --- | --- | --- | --- |
| 国际大型节与区域节 | 首映要求严、流程长、拷贝规范复杂 | 有完整长版、权利链齐 | 首映条款与地域资格是硬门槛 |
| 纪录片专项节 | 同行密度高、单元细分、常有提案单元 | 首作至有作品 | 看它的单元是否真的收你这类（观察型/系列纪实/短片） |
| 学生与独立影展 | 门槛低、排片灵活、反馈直白 | 早期与试剪阶段 | 适合作为第一次公开放映，注意授权范围别写太宽 |
| 行业创投与提案日 | 拍的是「项目」不是成片 | 预研—首作 | 材料是提案文档，见 [../11-生产与资金/项目开发提案.md](../11-生产与资金/项目开发提案.md) |

**核实当期清单的方法**（不依赖任何二手汇总）：

1. 只以**当期官方征片页面**为准，把条款原文存成 PDF 或带日期的网页快照，命名进 `05_DOC/节展投递/`；
2. 与**上一期章程对比**：改了费用、期限、首映条款，说明规则在漂，你的投递计划要按最新一版；
3. 存疑条款**写一封邮件问主办方**，把回复留档（口头答复、社交软件答复不作为条款依据）；
4. 报名平台的中继信息（简介、聚合页面）只用于发现，不用于判断；
5. 二次核实**转授链条**：某节展把作品转给其他展映，需你书面同意（授权范围与期限见 §3）。

## 3. 读征片章程：六件事，逐条抄成一张表

| 要读的事 | 看什么 | 你的动作 |
| --- | --- | --- |
| **首映要求**（premiere status） | 世界首映 / 国际首映 / 地区首映 / 本国未公映；线上发布是否算公映 | **先查清「B 站发过算不算公映」**，这直接决定你的周更与长版能否共存（§5） |
| 地域与时长资格 | 出品国、导演身份、片长档位、完成年份 | 不符就别投；时长档位可能要求重出一版 |
| 报名费与免费通道 | 金额、减免政策、早鸟期限 | 只从官方页读；预算科目见 [../11-生产与资金/预算与制片管理.md](../11-生产与资金/预算与制片管理.md) §1 |
| 拷贝与字幕要求 | 分辨率、编码、声道、字幕语言与格式、DCP 与否、寄递与回邮 | 按当期规格再导一版（[交付母版与规格](../08-剪辑后期/交付母版与规格.md)） |
| **授权范围与期限** | 你授予的是放映权还是包含传播/存档/在线；几年；能否转授；能否宣传切片 | 只给「本届时必要的放映与宣传」；超出部分另谈 |
| 奖金与权利保留 | 奖金性质、税后口径、版权归属是否变化、母版与档案留存要求 | 权利链不因参赛而改动；有疑问先咨询执业律师 |

**最贵的一格是首映要求**。一次不合适的投递，可能锁死你后面所有节的入口——**首投慎重，不是挑最好的，是挑与你权利状态匹配的**。

## 4. 报名材料包：一次做全，复用到换

【操作性建议】一套标准材料，改片长与措辞，不改结构：

| 材料 | 规格 | 复用要点 |
| --- | --- | --- |
| 一句话（logline） | 一到两句 | 与提案同一份，不每次重写；判据见 [../11-生产与资金/项目开发提案.md](../11-生产与资金/项目开发提案.md) §3 |
| 导演阐述 | 300–600 字 | 写位置与方法，不写感悟（作者位置见同文 §6） |
| 短简介 / 长简介 | 150 字 / 400 字两档 | 长简介含方法与拍摄周期，短简介给印册子用 |
| 剧照 | 3–5 张横构图 + 分辨率冗余 | **不含未同意内容与可识别个体敏感画面**（[../08-剪辑后期/素材管理与日志.md](../08-剪辑后期/素材管理与日志.md) §6） |
| 技术参数表 | 片长、画幅、帧率、声道、字幕、完成日期、语言 | 从母版校验值与交付清单直接生成，不手打 |
| 观看链接 | 带时间码 + 临时访问凭证 + 有效期 | 用主办方指定的平台或临时加密链接；**凭证不外流到社交渠道** |
| 主创与联系方式 | 一人项目也要写全 | 明确谁可被联系、谁可决定放映 |
| 权利与同意状态说明 | 一句话：许可与同意现状 | 与台账一致；不隐瞒「部分素材待确认」 |

时间码纪律【操作性建议】：在观看链接页首做一屏时间码索引（章节 + 分钟点），让评审能在三分钟内跳到你最想被看到的那八分钟——评审的注意力是按分钟分配的，这一屏的成本是十分钟。用眼成本：整理这一屏靠日志与时间轴，不靠逐帧回看。

## 5. 投递策略：节奏、首映、被拒率、选送

- **先定版本线**：长版（节展用）与中版（周更用）是**两个交付物**，不要用同一支片子两头兼顾。发布顺序一旦定了，改不回来（周更平台是否算公映决定长版还能不能投首映单元，见 §3）。
- **投递节奏**【操作性建议】：按「一次一档、三到五家为限、每轮之间留改片窗口」。同一片子一次性投二十家，等于放弃了根据反馈修订的能力，且报名与物料成本集中爆发。
- **被拒是默认结果**：任何一期的入选率都远低于 1/10【通行共识】，被拒不构成对作品质量的判断，只构成「这一届这一单元装不下」。**读被拒的方式**：若多家给同一句评语，那是结构问题；若只说「档期已满」，那是排队问题。
- **选送与推荐机制**：部分地区与专项单元采用机构选送、推荐人制，而非公开报名——这类入口靠同行关系，不靠邮件。**能进候选名单的唯一方法是你持续出现在同类的放映与工作坊里**（关系管理方法与长期跟拍同源，见 [../07-拍摄执行/长期跟拍.md](../07-拍摄执行/长期跟拍.md) §4）。
- **不要为投递改题材方向**：改到能中的那一稿，通常已经不是你唯一能拍的东西（不可替代性见 [../11-生产与资金/项目开发提案.md](../11-生产与资金/项目开发提案.md) §6）。

## 6. 放映现场：Q&A 的纪律

【操作性建议】Q&A 是唯一能被记住的部分，也是最容易出事的部分。

| 纪律 | 怎么说 |
| --- | --- |
| 不解释你没拍的东西 | 「这一段我没拍到，我不知道当时的情况。」——不猜、不补设定 |
| 承认未知 | 「我不知道这个问题现在的答案，我拍到的部分到 ×× 为止。」 |
| 不替当事人下结论 | 说「他当时是这样说的」，不说「所以他就是这样的人」 |
| 不透露当事人身份与所在地 | 涉及可识别信息、住址、单位、纠纷进展的问题，一律不当场答 |
| 不承诺未做的拍摄 | 被问「后来呢」，只说已知事实与你已同意的计划 |
| 不评价其他作者与评审 | 现场听众会转述你的话 |
| 承认方法本身 | 被问技术细节时讲方法（单机、许可、同意分层），这往往是最有价值的回答 |

**被问住时唯一正确的动作是承认**：一次含糊的即兴解释，会在之后的任何一次放映里被拿来追问（更正义务见 [../10-伦理法律/事实核查与更正.md](../10-伦理法律/事实核查与更正.md) §6）。

## 7. 到场成本与身体约束

【操作性建议】把「去不去」算成三笔：**现金**（交通住宿，算法见 [../11-生产与资金/预算与制片管理.md](../11-生产与资金/预算与制片管理.md) §8）、**工时**（往返两日 + 现场一日，等于三个拍摄日）、**身体**（连续长途 + 夜间放映 + 次日访谈，是视力与睡眠最集中的压力时段）。约束写进排期：单场放映后不得次日安排高强度盯屏工序；外场行程不与强制回家周期冲突（[../../研究/行动总纲.md](../../研究/行动总纲.md) §8.4）。**不去的正当说法**：「我无法到场，请安排映前录制或请当地作者主持」——这是常规做法，不是失礼。

## 8. 同一素材的两套评价体系（投递前必须决定走哪条）

【操作性建议】纪实作品里的**反思性露馅**——三脚架入画、导演出声、摄影机被看见、现场有人对镜头说话——在自媒体与纪实语境里是真实感的来源；在节展评审语境里，常被当作**技术瑕疵或方法不自洽**扣分。同一支片子在两条线上的处理不同：

| 元素 | 自媒体线（周更） | 节展线（长版） |
| --- | --- | --- |
| 出画的支架与设备 | 保留，是「我真的在那儿」的证据 | 通常在定剪前拿掉，或在声音上做规整 |
| 导演提问出声 | 保留，对话感强 | 可保留，但需全片一致；忽隐忽现才是问题 |
| 手持晃动 | 容忍度高 | 需要能说明的理由；无理由的晃会被读成不讲究 |
| 字幕与解说 | 高密度信息，随时提示 | 少字少说，让画面承担（[../04-声音/解说与静默.md](../04-声音/解说与静默.md)） |
| 节奏 | 前 30 秒必须给钩子 | 允许慢起，但需结构理由（[../05-叙事结构/叙事弧与结构模型.md](../05-叙事结构/叙事弧与结构模型.md)） |

**关键不是哪种对，而是别混**：一条片子里「一半讲究一半随意」最伤，因为它让评审判断你不懂自己在做什么。做法【操作性建议】：**先出节展版母版并定剪，再从母版向下切自媒体版**（切分规则见 [./自媒体分发.md](./自媒体分发.md) §1）；反过来（先发完再剪长版）会同时丢掉首映与结构完整性。**全片一致地保留或全片一致地拿掉**，是你唯一需要守的规则。

## 常见误区

| 误区 | 事实 |
| --- | --- |
| 「投节展是为了流量」 | 节展给的是反馈、资金入口与归档；流量与它是两套分发系统 |
| 「先上平台再说，反正都能投」 | 平台公映可能直接消灭首映资格（§3） |
| 「被拒说明片子不行」 | 默认结果是拒；读评语比改片子重要 |
| 「名单靠别人整理的合集」 | 只信当期官方页 + 留档；二手信息用于发现不用于判断（§2） |
| 「授权范围差不多就行」 | 放映、在线、存档、切片宣传是四件事，期限与转授要写清 |
| 「Q&A 要显得什么都懂」 | 承认未知才是可信度；即兴解释会变成永久的追问 |
| 「自媒体那套直接投出去」 | 两种评价体系混在一版里最伤（§8） |
| 「每场都得去」 | 三个拍摄日 + 身体成本；可录制、可托当地主持（§7） |

## 实操要点

- [ ] 投递前写一句「这次要的是反馈、资金还是归档」，写在报名表上方。
- [ ] 章程六件事抄成表并留 PDF 快照；存疑条款用邮件问主办方并把回复归档。
- [ ] 先确认「已发布的中版是否构成本片公映」，再排投递顺序，首投选与权利状态匹配的项目。
- [ ] 材料包一次做全并按 §4 复用；观看链接用临时凭证、带时间码索引屏。
- [ ] 长版与周更版分两条交付线，**节展版先定剪**，再向下切自媒体版。
- [ ] 反思性元素全片一致：要么都留，要么都拿掉，不混。
- [ ] Q&A 七条纪律提前写在纸上带进会场；涉及当事人身份的问题一律不当场答。
- [ ] 授权只给届时必要范围；奖金与版权归属条款有疑问时咨询执业律师，不在本库内求结论。
