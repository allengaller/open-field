# 自媒体分发

> 周更是这个项目的生产系统，不是灵感输出。能持续每周发的从来不是「有灵感」，是一条从素材到成片的流水线，加一套不让自己为难的切分规则。

这是主战场：B 站 / 抖音 / 视频号三端、每周更新（[../../研究/行动总纲.md](../../研究/行动总纲.md) §4.4）。工序与档期见 [../15-工具与模板/单集制作SOP.md](../15-工具与模板/单集制作SOP.md)；伦理硬线来自 [../10-伦理法律/事实核查与更正.md](../10-伦理法律/事实核查与更正.md)，本篇不重述其分级，只给分发层的操作。

---

## 1. 同一批素材的三种形态

【操作性建议】一次田野行程 → 三条产物，这是单人项目摊薄成本的核心杠杆（成本算法见 [../11-生产与资金/预算与制片管理.md](../11-生产与资金/预算与制片管理.md) §8）。

| 形态 | 用途 | 典型时长量级 | 结构约束 | 破点在哪 |
| --- | --- | --- | --- | --- |
| **长版** | 沉淀、节展投递、档案 | 数十分钟至小时级 | 允许慢起与等待；结构理由必须自洽（[../05-叙事结构/叙事弧与结构模型.md](../05-叙事结构/叙事弧与结构模型.md)） | 为周更牺牲长版节奏，两头不成立 |
| **中版** | 主更新（周更） | 数分钟至十余分钟 | 前 60 秒给出「这集回答什么问题」；单集一个论点；结尾留未解 | 把长版压成中版 = 节奏断裂；把中版当长版投 = 显得不讲究 |
| **短切片** | 引流、单独成立的一条 | 数十秒至三分钟 | 一个完整意思一个动作；必须自含（不看主更新也能懂） | 切片最容易失真——一句话被切出来就换了结论 |

三条线各自有母版，全部从**同一份已核事实层**派生；先定长版与中版，再切短（与节展线的顺序判断见 [./电影节与展映.md](./电影节与展映.md) §8）。

## 2. 切片的硬底线：不得改变当事人话语的结论

【操作性建议】切片前后各问三句，任一句不过就不发：

1. **删掉的部分会不会反转结论？**（他后面补了「开个玩笑」「不过也不是没办法」——必须补语境或不用，规则见 [事实核查与更正](../10-伦理法律/事实核查与更正.md) §5）
2. **换了他没说的程度吗？**（「有时候拖两三天」→ 切成「他就是不给你结账」，是把 S2 说成 S1）
3. **当事人看到这条会不会否认自己说过？**（这是唯一有效的检验，与长版同一标准）

允许的操作：在同一次呼吸内删填充词、调整段落顺序但保留限定语、加一条把上下文写进字幕的「前情/后情」。**禁止**：跨场合拼句、把推断剪成断言、把 A 的话配 B 的画面（这三条都是不可辩护的，见同文 §5）。

## 3. 标题与封面：可以直白，不可以失实

| 可以做 | 不能做 |
| --- | --- |
| 把已发生的事实前置（「他在流水线上站了 11 个小时」，且这是可核查的） | 把可能性写成确定性（「他被裁了」而实际是传闻） |
| 用你自己的判断并标明是判断（「我认为这家厂的问题不在工资」） | 用疑问句暗示结论（「是不是只有我这么觉得？」） |
| 呈现具体动作、地点、数字（数字须过断言清单） | 数字向上取整凑震撼 |
| 让当事人自己的话做标题（逐字） | 改字、拼句、加他没用的词 |
| **不许**：用当事人痛苦、疾病、家庭冲突做悬念钩子；不许拿「他哭了」当封面 | **不许**：把未同意的可识别个体放进封面（同意范围见 [../10-伦理法律/知情同意与拍摄授权.md](../10-伦理法律/知情同意与拍摄授权.md) §6） |

封面伦理补一条：封面是**最容易被单独截图传播的一格**，它脱离视频存在。判断法：把封面图单独拿出来给一个不认识的人看，他会以为这条视频讲了什么？如果他以为的内容与视频不符，就是失实（更正机制见 [事实核查与更正](../10-伦理法律/事实核查与更正.md) §6）。

## 4. 平台推荐机制：只用到通用信号这一层

【通行共识】可依赖的认知只有四个通用信号：**完播（含平均观看时长）、互动（评论、点赞、收藏）、关注转化、分享/转发**。机制细节、权重与阈值不在本库写——它们每期都变，任何声称具体的数值都不可信（复盘如何用这四个信号，见 [./数据复盘与迭代.md](./数据复盘与迭代.md) §2）。

【操作性建议】由这四个信号推出的**正当优化**与**不做的事**：

| 正当优化 | 不做的动作 |
| --- | --- |
| 前 60 秒交代问题；结构清楚、段落可跳 | 诱导互动（「不点赞就……」「评论抽 ×× 送」） |
| 让信息密度分布均匀，减少无信息空段 | 用虚假稀缺逼关注（「本条仅存 24 小时」而实际长期在） |
| 标题封面直白、可核对 | 标题失实、封面误导 |
| 固定节律发布，利用观众的日程习惯 | 一天多发刷量、同一条多号重复铺 |
| 评论区做信息补充（§6） | 拿当事人数据做增长（禁止，见 [../../../PRINCIPLES.md](../../../PRINCIPLES.md) §6 非目标） |

## 5. 更新节律是生产系统问题

每周一条能不能持续，取决于流水线，不取决于灵感【操作性建议】：

- **库存优先**：目标不是「今天剪出来」，是「任何一周都不必为发布赶工」。保持 **≥2 条成片库存 + ≥1 条已拍未剪**；库存低于此，本周停止接新合作与新增访问。
- **工序分日**：拍摄日 / 整理日 / 剪辑日 / 发布日分开，**剪辑日不与长途驾驶同日**，盯屏工时设上限（近视约束与纸面替代见 [../11-生产与资金/团队组建与合同.md](../11-生产与资金/团队组建与合同.md) §5）。
- **发布档期固定**：选定一周中的固定时间与一天中的固定时段，写进日历并长期不变；变更节律要提前告知观众，不要静默消失——长期项目的观众靠节律建立信任。
- **一周中断是允许的**：预先说明的休整比突然断更便宜；不说明的断更会把关系消耗掉（关系的阶段与承诺管理见 [../07-拍摄执行/长期跟拍.md](../07-拍摄执行/长期跟拍.md) §4–§5，常见的断法见同文 §10）。
- **强制回家周不排发布任务**（排期约束，见 [../11-生产与资金/预算与制片管理.md](../11-生产与资金/预算与制片管理.md) §5）：用库存覆盖，不用深夜剪辑覆盖。

## 6. 评论区：三种内容，三种处理

| 类型 | 识别 | 处理 |
| --- | --- | --- |
| **信息补充**（同行、本地人、前员工提供事实） | 具体、可核、常带自身位置（「我在同一条街上过」） | 追问到可核查；有价值则更新到置顶说明或字幕卡更正，并记进断言清单与素材日志；这类评论常常是**下一条选题的入口** |
| **挑衅与立场攻击** | 无具体事实，只有评价；常见「资本家的走狗」「洗地的」 | 一句纪律：不口角、不教育、不反问（对齐 [../../研究/行动总纲.md](../../研究/行动总纲.md) §8.1）；只处理涉事实错误的（「你说的人数不对」→ 给依据或更正）；重复人身攻击按平台规则处理 |
| **当事人出现在评论区** | 被摄者、其亲属、厂方、纠纷对方来留言 | **优先级最高**：当日内回应，先私聊再公开；涉及撤回、要求删除、身份暴露的，按 [../10-伦理法律/知情同意与拍摄授权.md](../10-伦理法律/知情同意与拍摄授权.md) §8 的发布确认与撤回流程处理；不在评论区与第三方争论当事人的说法；处理结果记台账 |

还有一类要单独盯：**替别人认人**（评论区猜测某人是哪家哪厂）。这是可识别性风险的放大器，处置是澄清 + 相关段落匿名化处理，而不是删评了事。

## 7. 私信：从内容到咨询的转化路径

这是「咨询换单」模式的入口（[../../研究/行动总纲.md](../../研究/行动总纲.md) §2.3、§7.1）。【操作性建议】把私信当线索管理，而不是当聊天：

| 私信类型 | 意图 | 正当动作 |
| --- | --- | --- |
| 求诊断 / 求合作（潜在客户） | 有明确业务问题 | 一次结构化回复（他说的瓶颈、你能做什么、不能做什么）；转正式沟通渠道；报价方式不写在本库 |
| 求内推 / 求职信息 | 人脉资产方向 | 如实说明你能与不能；不给未核实的公司信息 |
| 同行交流 | 认知与情报 | 优先响应，这是行业研究的复利来源 |
| 素材使用请求（他人想剪你的片子） | 二次传播 | 查同意范围与权利链，超范围即拒（[../10-伦理法律/版权链与E&O.md](../10-伦理法律/版权链与E&O.md)） |
| 挑衅、索要隐私、代拍请求 | 风险 | 不回应实质内容；代拍与隐蔽采集一律拒（[../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.4） |

**边界三条**：不把观众当客户池运营（不群发、不诱导、不做虚假稀缺）；不在私信里承诺播出或传播量（融资诚实清单同规则，见 [../11-生产与资金/资金渠道地图.md](../11-生产与资金/资金渠道地图.md) §6）；**当事人不是内容资源**，不向客户出售当事人联系方式与场景信息（[../../../PRINCIPLES.md](../../../PRINCIPLES.md) §6）。

## 8. 跨平台同步与账号安全

【操作性建议】

- **同步不等于复制**：三端节奏与形态不同（竖屏优先切片、中长版给 B 站，见 §1、§9），首发顺序要一致地维持，别今天 A 平台明天 B 平台抢先。
- **母版留档、分发件带标识**：公开分发件加**轻微、不可一键裁掉的标识**（角标 + 片尾作者信息），不损害画面但不给搬运者便利；母版绝不加水印（母版是单一事实源，见 [../08-剪辑后期/交付母版与规格.md](../08-剪辑后期/交付母版与规格.md)）。
- **被盗用的取证与投诉**：按顺序做——录屏/截图存档（含对方 ID、链接、时间）、下载对方版本、比对时长与画面确认为同源、走**平台官方侵权投诉通道**提交权属证明（权属证明来自权利链档案，见 [版权链与E&O](../10-伦理法律/版权链与E&O.md)）。**不私下对线、不悬赏人肉、不做「以盗制盗」**；若对方商用规模较大，咨询执业律师评估正当维权路径。
- **账号本身是资产**：双因子开启、绑定手机与邮箱分离、不共用登录、不把登录交给任何代运营或合作机构（授权登录也要限定范围与期限）；账号被盗或被封的恢复期，是内容不可再生损失（呼应 [./流媒体与平台发行.md](./流媒体与平台发行.md) §7）。
- **发布前最后一次授权自检**：从台账拉当次状态，未同意、撤回、待确认一律硬排除（机制见 [../08-剪辑后期/素材管理与日志.md](../08-剪辑后期/素材管理与日志.md) §6）。

## 9. 字幕与竖屏改编的画质损失判断

【操作性建议】三种常见改编，各自的损失与底线：

| 改编 | 损失 | 底线 |
| --- | --- | --- |
| 横屏 → 竖屏（9:16） | 构图被切、横向关系信息丢失（机器与人的位置关系消失）、字幕带压画面 | 需要横向关系说明的段落**不做竖屏**，改用上下分栏或保留黑边；不在竖屏里重排画面主体 |
| 重编码上传（多平台各压一次） | 暗部断裂、运动模糊糊、同期声被压成单声道 | 每次只从母版导出一版分发件，**不从分发件再导出**；导出前用示波器与响度检查一次（[../08-剪辑后期/交付母版与规格.md](../08-剪辑后期/交付母版与规格.md)） |
| 平台自动加字幕 / 机翻 | 专名、方言、数字错；把当事人原话改字 | 机翻字幕一律逐条校对后才允许对外；逐字性是硬线（[../08-剪辑后期/字幕与无障碍.md](../08-剪辑后期/字幕与无障碍.md)） |

判断「画质是否可接受」的方法不靠盯屏：选一帧暗部最重的画面 + 一段运动最快的镜头 + 一段同期声最密的部分做**三点抽检**，逐平台各看一次；抽检结论记进交付规格表，不靠感觉。

## 常见误区

| 误区 | 事实 |
| --- | --- |
| 「切片不重要，随便剪」 | 切片脱离语境，是失真风险最高的形态（§2） |
| 「标题狠一点没关系，内容正就行」 | 绝大多数观众只看到标题封面；封面失实等于内容失实 |
| 「研究算法权重比研究内容有用」 | 权重每期变且不可核查；能控的只有四个通用信号（§4） |
| 「灵感来了再更」 | 周更靠库存与工序分日，不靠状态（§5） |
| 「评论区都是噪音」 | 补充信息里藏着下一题；挑衅按纪律处理；当事人来了优先级最高（§6） |
| 「私信就是销售」 | 私信是四种线索的混合，同行与补充信息同样值钱（§7） |
| 「被盗就骂一顿」 | 走取证 + 官方投诉；对线只消耗你自己（§8） |
| 「竖屏是格式问题，随便改」 | 有的段落一旦竖屏就不成立（横向关系是信息不是构图，§9） |

## 实操要点

- [ ] 每次外拍产出按长版/中版/切片三条线规划，全部从同一份已核事实层派生。
- [ ] 切片过 §2 三问；跨场合拼句、推断剪成断言、A 话配 B 画一律禁止。
- [ ] 封面单独给一个人看，检验他以为的内容与实际是否一致，再发布。
- [ ] 维持 ≥2 条成片库存 + ≥1 条已拍未剪；低于此先停新增承诺。
- [ ] 发布档期长期固定；休整提前说明，不静默断更；强制回家周靠库存覆盖。
- [ ] 当事人出现在评论区：当日回应、先私聊、按撤回流程处理并记台账。
- [ ] 私信五类分流；不出卖当事人信息与联系方式，不承诺播出与传播量。
- [ ] 分发件从母版一次导出；三点抽检画质与字幕；被盗按取证 + 官方投诉路径处理。
