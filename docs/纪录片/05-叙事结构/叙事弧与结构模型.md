# 叙事弧与结构模型

> 结构不是把素材塞进模板，而是把素材里已经存在的顺序找出来。模板的价值只有一条：让你知道自己在用什么，从而知道违反了什么。

本篇给模型与判据。选完结构之后的物理执行方法在 [纸剪与结构重组](./纸剪与结构重组.md)；「想清楚这条片子要回答什么」见 [冲突悬念与信息节奏](./冲突悬念与信息节奏.md)。

## 1. 先摆正立场：模型的地位

必须区分两类东西：

- **认知规律**：人会在信息缺口前保持注意、会追踪他人的意图与面孔、会对重复与变化产生节奏感。这类是硬的，任何结构都建立在其上。
- **工业化叙事惯例**：三幕、节拍表、「救猫咪」式的情节点位置、主角必须在第 25 分钟给出动机。这类是好莱坞长片为了可复制生产而发明的行业约定，【通行共识】其理论化主要源自 Fieldman/Campbell 神话学经 Vogler 等剧作教材转译后的产业应用。它们不是必然规律，与「事实如何展开」没有天然关系。

一句可执行的话：**当你发现自己在「为了结构」而调整事实顺序时，停下，去 [纸剪与结构重组](./纸剪与结构重组.md) 重排卡片，而不是去改事实。**

## 2. 三幕结构在纪实里的真实可用性

可用之处：观众确实需要「进入—胶着—出来」的时间感；第一幕交代处境与未决问题、第二幕升级与受阻、第三幕给出结果或明确的悬置，这套骨架对 8–25 分钟的单条片子非常好用。

局限（在纪实里三条都是硬伤）：

| 三幕的默认承诺 | 现实常见情况 | 处理办法 |
|---|---|---|
| 问题会被解决 | 工厂没关、诉求没批、病没好 | 把「解决」换成「代价被看清」；或用第二、三幕改讲人如何与之共存 |
| 人物会转变 | 人常常不变，或变化在两年后才发生 | 变的是处境、观众的认识，或你自己的认识；把这个转移动到人身上要交代时间 |
| 冲突会升级 | 事情往往是拖平、稀释、不了了之 | 用「拖延本身」作为第二幕的内容：重复、等待、行政流程 |

强行三幕的结果通常是：把最戏剧化的一天当高潮，把剩下的素材压成说明，最后不得不靠解说补因果。这是自媒体纪实最常见的结构失败（诊断表见 [纸剪与结构重组](./纸剪与结构重组.md)）。

## 3. 人物弧

弧光（arc）在非虚构里必须有可拍的证据，否则是剪辑者的想象。

- want vs need：人物自己说要的东西（想要回欠薪、想在县城买套房、想让儿子回来），与他真正需要的东西（被当作人对待、家里那口气、不再被当成麻烦）通常不一致。这个落差是纪录片最好的引擎，因为它不需要你编，只需要你等。
- 转变的可见证据（至少满足两项）【操作性建议】：同一空间/同一动作在片中出现两次且状态不同；人物自己的说法前后矛盾并被时间戳记录下来；他人的说法与人物说法不一致；实物发生变化（厂房拆了、机器卖了、头发白了、合同签了）；语言从「我们厂」变成「那个厂」。
- 不许做的：把采访里事后总结的话，剪成「他当时就想明白了」。事后理解不等于当场转变，标注时间即可（「2024 年 3 月，他在电话里说」）。

## 4. Hero's Journey：为什么在纪实里要慎用

约瑟夫·坎贝尔的单一神话（monomyth）经产业剧作学转译成「英雄旅程」阶段表【通行共识】。它套在纪录片上的问题不是不准，而是**代价由被摄者支付**：

- 它要求一个出发、受训、凯旋的个体。真实的劳动经验多为集体、重复、无凯旋——套用会把集体行动剪成一个人的成长故事，把结构问题剪成个人励志问题。
- 对劳工、少数族裔、残障、灾害幸存者题材，套用「英雄之旅」隐含一个结论：苦难是他冒险的「召唤」。这是把别人的处境编排成你的叙事奖励机制。
- 它偏爱可识别的「导师」「守门人」「变身」，于是领导、家属、客户容易被剪成阻碍角色（另见 [人物与主角](./人物与主角.md) §5）。
- 长期跟拍里最常见的真相是：没有人赢，事情没有结束，摄影机还在原地。这本身可以是结构，只是不是那个结构。

如果非要用它的某一部分，只用两样：拒绝召唤（人物一开始不愿被拍、不愿说话）与回归后的不适（回到日常后一切都变了）。这两条在田野里确实高频发生。

## 5. 常用结构模型清单

| 模型 | 一句话 | 适合什么素材 | 失败模式 |
|---|---|---|---|
| 问题—解决（investigative） | 抛出一个未决事实，跟着一层层材料走 | 欠薪链条、算法派单、污染来源、数据类 | 结论先行、只挑支持证据（对策见 [事实核查与更正](../10-伦理法律/事实核查与更正.md)） |
| 人物旅程 | 一个人 + 一段时间 + 一件未成的事 | 深度访谈 + 跟拍充足 | 人物不变、素材变成流水账 |
| 平行结构（多线交叉） | 2–3 条线并置，靠对照产生意义 | 同一链条上的不同位置：老板/工人/求职者；几户人家 | 线一多就每条都浅；切换点全靠音乐硬转 |
| 群像 | 无单一主角，以空间为骨架 | 菜市场、车站、厂区宿舍；周浩《高三》（2005）式的毕业班跟拍【通行共识】 | 记不住人；需要「重复出现的面孔」做锚 |
| 章节式/散文式 | 无中心冲突，以问题与母题组织 | 空间、概念、长期观察 | 散漫、无推进；判据见 [散文电影与诗性结构](./散文电影与诗性结构.md) |
| 圆形结构 | 回到开头的地点或动作 | 有强空间标志物时（村口、那台机器、那条班车） | 变成「首尾呼应」的形式表演；回到原点必须有新信息 |
| 倒叙/结果前置 | 先给结局再讲过程 | 事件有明确终点：搬迁完成、判决下达、店铺关门 | 观众不再关心过程细节；需用「为什么变成这样」接住悬念 |
| 时间框架 | 一天 / 一季 / 一年 | 有自然节奏的工作：收麦、春运、夜班、学期 | 平均用力；需在时段之间做取舍 |
| 系列片结构 | 每集自足 + 跨集钩子 | 长期项目（见第 6 节） | 每集都像第一集；跨集钩子变成断更预告 |

时间框架的可用性来自身体的日常：清晨、正午、夜里，声音与光线自带节拍（见 [光线与色彩](../03-电影语言/光线与色彩.md)）。不要为了对称硬凑「凌晨四点」的空镜。

## 6. 系列片结构（做「AI 田野调查」这类长期项目必读）

单条片子的成败在开头 90 秒，系列的成败在**第二集**。观众决定是否长期跟看你，靠的是第二、三集是否兑现第一集承诺的观看方式。

每条必须同时做到三件事：

1. 本集自足：只看完这一集的人，能得到一个完整的结论、一段完整的人物经历或一个明确的答案。不许用「下集揭晓」当本集内容。
2. 系列增量：给长期观众一样只有看过前作才值钱的东西——一个人物第二次出现的反应、一个你上次留下的判断被证明错了、同一空间在不同季节的变化。
3. 跨集钩子：钩子的合法形式是**未问题（下一集要问什么）**，不是悬念（下一集会发生什么）。用前者你忠于事实，用后者你在赌事实配合你。

结构层设计【操作性建议】：

- [ ] 先定系列总问题（一句话，例如「AI 调度怎样改变了一个县城工人的日薪与尊严」），再分集——每集回答总问题的一个侧面：算法、工资、身体、家庭、抵抗、失效、共谋。
- [ ] 每集换一个「证据类型」：这一集靠数据，下一集靠两个人，再一集靠一趟班车。避免十集都在做「访谈 + 空镜 + 我出镜」。
- [ ] 定一条你自己在系列里的线：你的判断如何变化。这是长期系列真正的叙事弧，比任何被摄者的弧都更可控，也更诚实（见 [观看位置与视点](../03-电影语言/观看位置与视点.md)）。
- [ ] 每 5–8 集做一次回顾结构（把前面素材重新剪进一集），给新观众上车的门。
- [ ] 平台分发上的现实约束：单集时长、片头 3 秒、封面与标题的承诺一致性（见 [自媒体分发](../12-发行传播/自媒体分发.md)）。承诺过度是系列片最常见的失信方式。
- [ ] 存档纪律：系列越长，「我上次说过什么」越重要。每集结尾写 5 行本集主张与证据索引，下一集开场前先读它。

## 7. 开头 90 秒的任务

不是「抓人」，是给观众三样东西，缺一样他就划走。

- [ ] 抛出人物：一个具体的人，正在做一件具体的事（不是航拍县城全景，是有人在削一根管子）。
- [ ] 抛出一个未决问题：观众看完想知道答案的那一句（可以只用画面提，不必说出来）。
- [ ] 证明「我在现场」：至少一个只有在场才能得到的东西——一句方言、一段无法安排的声音、一个你手上有油渍的特写、背后有人喊你名字。
- [ ] 承诺观看方式：这片子是跟人、跟事、还是讲数据。观众据此决定要不要长期投入。
- [ ] 不要在前 90 秒做完：自我介绍、设备说明、地点全名加行政区划、字幕动画、系列 logo、上一集回顾超过 10 秒。
- [ ] 数值参考【操作性建议】：90 秒内至多 3 个新信息点；解说字数不超过 200 字（约 180–240 字/分钟）；第一个镜头长度控制在 2–6 秒，随后放一个 15 秒以上的长镜头让观众安定。

## 8. 结尾的类型

| 类型 | 做法 | 什么时候诚实 |
|---|---|---|
| 解决方案式 | 问题以某种方式被处理，给出结果 | 你真的看到了结果 |
| 悬置式 | 事情没结束，把人留在进行状态 | 现实中就是没结束——这是纪实最常见的正当结尾 |
| 时间流逝式 | 用季节、身体、物件的变化收束 | 有跨时间素材支撑；不要靠字幕「一年后」硬造 |
| 反讽式 | 让人物的话与画面结果并置，不作声 | 并置关系是你观察到的，不是你在剪辑里造的（见 [蒙太奇与长镜头](../03-电影语言/蒙太奇与长镜头.md)） |
| 自反式 | 交代你与这段关系的位置、你不知道什么 | 长期项目、伦理复杂的项目应当考虑用它 |
| 后续交代式 | 字幕说明人物现状与知情同意处理 | 人物命运已被公开改变、或存在风险时 |

避免「最后一条解说把结论嚼碎」（见 [解说词写作](./解说词写作.md) §9）。

## 9. 内容类型 → 推荐结构决策表

| 你的素材长这样 | 优先试 | 备用 | 别用 |
|---|---|---|---|
| 一个厂的算法/工资/考勤数据 + 多人零散说话 | 问题—解决 | 章节式 | 英雄旅程 |
| 一户人家，跨季节，有明确事件（搬迁、生病、婚礼） | 人物旅程 + 时间框架 | 圆形结构 | 平行结构 |
| 一个空间里二十个人，谁都不突出 | 群像（以空间为骨架） | 散文式 | 三幕 |
| 一次陌拜、一趟班车、一天夜班 | 一天式时间框架 | 结果前置 | 章节式 |
| 三小时深度访谈为主 | 问题—解决 + 人物旅程 | 自反式 | 平行结构 |
| 不可重复事件现场（讨薪、强拆、事故） | 结果前置或倒叙 | 人物旅程 | 时间框架 |
| 你去了三次才知道怎么回事 | 自反式/散文式（把你的理解过程当结构） | 圆形结构 | 解决方案式 |
| 系列第 4–10 集 | 每集自足 + 换证据类型 | 回顾集 | 连续剧式悬念 |

## 10. 常见误区

- 把结构当外壳，先定「三幕」再找素材填——结果是解说承担全部因果。
- 用事件密度代替结构：一集里发生八件事，观众一件记不住。
- 把最戏剧化的一天当高潮，其余素材当说明文（诊断见 [纸剪与结构重组](./纸剪与结构重组.md) §11）。
- 迷信模板节拍表，把纪录片剪成预告片节奏：全是重音等于没有重音。
- 系列片用「下集更精彩」当结构，长期观众会离开，因为他们来看的是你怎么看，不是你会不会吊胃口。
- 让主角「表演变化」：拍一个「他终于想通了」的镜头，比事实更假。
- 开头放航拍 + 大字幕 + 音乐，把观众带到「宣传片」的阅读姿态里，之后再怎么真实都会被怀疑。
- 不敢悬置：为了有个结尾而给事情扣一个它没有的结论。

## 实操要点

1. 动手之前用一句话写下本片的未决问题；写不出来就先别剪，回素材里找（[纸剪与结构重组](./纸剪与结构重组.md)）。
2. 从第 5 节表里选主结构 + 一个备用结构，做两个不同顺序的版本各看一遍再定。
3. 用第 3 节的「可见证据清单」检验人物弧，凑不满两项就放弃弧光，改用问题—解决或散文式。
4. 劳工、群体、灾难题材默认不套英雄旅程；要借用只借「拒绝召唤」与「回归后不适」。
5. 开头 90 秒按第 7 节清单逐项打勾，缺「我在现场」这一项就去补拍一个可用长镜头。
6. 系列项目先写总问题与分集侧面的对照表，再定每集证据类型，并把「你自己的判断变化」列为主线。
7. 结尾优先在悬置式、自反式、后续交代式里选；写「解决方案式」结尾前先确认结果确实被拍到。
8. 结构定稿后回头检查解说：所有靠解说撑起的因果，都应当在结构层重做一遍（[解说词写作](./解说词写作.md) §5）。
