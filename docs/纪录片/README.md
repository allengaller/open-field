# 纪录片语料库（Documentary Corpus）

> 一个人也能做完整的非虚构影像：理论、历史、电影语言、声音、叙事、采访、拍摄、剪辑、技术、伦理法律、生产资金、发行传播、案例、工具模板与学习资源。
> 生成日期：2026-09-23。**转载或引用前请先读 [体例与证据等级](00-总览/体例与证据等级.md)**——本库的证据分布与其他两个库不同。

## 这是什么

17 章 98 篇（另有本篇 README），约 61 万字符的中文非虚构影像知识库。它假设读者：会做田野、懂软件与数据，但**没有受过影像训练**，且**是一个人干活**。

它回答四类问题：

1. 凭什么信、要说什么——本体、理论、历史（00–02）
2. 怎么说才能被看懂——电影语言、声音、叙事、采访（03–06）
3. 怎么把它做出来——拍摄执行、剪辑后期、技术设备（07–09）
4. 怎么发出去并且能继续做——伦理法律、生产资金、发行传播、案例、模板、资源（10–16）

**它不是教材，是工作手册。** 判据是：明天要出门拍摄的人，能不能今天早上从里面拿走三张表和两个决定。

## 给谁用

本库为一个具体处境写：一人、单机、长期跟拍工厂与村庄与集市与写字楼，周更一条纪实视频发在 B 站／抖音／视频号，同时在做田野调查并需要把这些材料沉淀成可引用的东西。

因此本库的默认假设与多数纪录片教材不同：

| 常见教材假设 | 本库假设 | 影响 |
| --- | --- | --- |
| 有 crew，可以分工 | 只有你，且你在现场同时担任摄影、录音、记者与制片人 | 一切工序按单人可用时间重排（[一人团队与单机作业](07-拍摄执行/一人团队与单机作业.md)、[单集制作SOP](15-工具与模板/单集制作SOP.md)） |
| 有电力、有网、有器材箱在车上 | 电力有限，网络不可靠，重量与体积是本人承担 | 离线优先、续航底线、装备按身体约束选 |
| 交付对象是制片方或电视台 | 交付对象是平台观众，且没有合同保护你 | 合规与授权没有第三方替你把关，凭证全归你管（[版权链与E&O](10-伦理法律/版权链与E&O.md)） |
| 拍摄周期以月计 | 周更，且必须留出休整与家庭时间 | 降级顺序明写，不允许靠无限加班交付 |
| 伦理由机构审查承担 | 你就是伦理审查，且被摄者可能长期住在你下次要去的那个村 | 可持续性作为完成判据之一 |

## 证据说明（必读）

三级标注【核验】／【通行共识】／【操作性建议】，含义与 [田野方法库](../田野方法/README.md) 一致，**但分布不同**：

- 本库主体是【操作性建议】：工序、判据、表格、检查项。它不声称外部有依据，只声称可用。
- 【通行共识】次之：理论谱系、历史脉络、术语译法。这部分读起来最像事实，**风险也最高**——进提案、进自述、进对外文案前请回原书复核。
- 【核验】只出现在编写时实际查证过的零星断言上。

因此一条使用规则：**不要从本库抄句子进对外文本，要从本库拿动作进拍摄日。**

**反编造策略**：编写过程中对无法核验的具体信息采取删除而非补齐——被删掉的包括期刊名、奖项届次与奖金、片长集数、票房、出版年、ISBN、若干中文片名、若干无法确定归属的历史细节，以及全部法条条号与平台具体参数。留下空缺是刻意的。各文件末尾的 `## 请复核条目`（若有）是**待办**，不是已解决。

**内容边界**：涉及中国大陆法律与政策的部分只作风险提示与流程说明，不构成法律意见，不评价政策，不涉及规避审查、规避权利人或规避监管的方法；凡「不能拍」的判断一律给出可核查的判据与替代做法。全库不出现可识别的真实被摄者信息，示例一律用化名编号与可公开地名。

## 维护

- 单一事实源：数值与枚举只在定义处写一次（音频＝04，素材字段与授权枚举＝08，同意档位与台账＝10，许可判断＝11，规格＝08＋15 表格）。改定义时顺藤改所有引用。
- 章间冲突按 [体例与证据等级](00-总览/体例与证据等级.md) §4.1 的五步裁决，禁止静默分歧。
- 链接发出前先确认目标存在；目标未写成时写纯文本「另述」，不留占位链接。相对路径到仓库根是 `../../../`（三级）。
- 每篇收尾节固定为「常见误区」「实操要点」；改动后更新该篇「最后更新」日期。
- 新增篇章前先查 [知识地图](00-总览/知识地图.md) §1 分层与 §6 分工，避免把工序写进概念层，或把田野库的内容搬进来。
