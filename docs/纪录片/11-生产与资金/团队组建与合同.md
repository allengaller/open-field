# 团队组建与合同

> 你不需要团队，你需要的是几个「在特定环节替代你自己」的人。每一次找人都是三件事的交换：把工序交出去、把风险分出去、把权利写清楚。

本篇讲**什么时候必须找人、找来的关系怎么定性、必须签哪三份文件**。合同条款的通用风险在 [../10-伦理法律/中国法律边界.md](../10-伦理法律/中国法律边界.md)，权利链在 [../10-伦理法律/版权链与E&O.md](../10-伦理法律/版权链与E&O.md)。**本篇全部内容非法律意见，凡涉及合同签署、权属约定、纠纷处理的重大事项，请咨询执业律师。**

---

## 1. 何时必须找人：六个环节的判断表

【操作性建议】solo 的默认状态是对的——每加一个人都会增加沟通衰减与权利复杂度。只在下面六种情况下加人：

| 环节 | 必须找人的信号 | 不找人的代价 | 找谁 |
| --- | --- | --- | --- |
| 录音 | 同期声是主角，现场噪声高、走位复杂 | 画面可补，声音不可补；废一条访谈 | 录音师按日租，或先学无线麦+挑杆的固定配置（[../09-技术与设备/收音装备.md](../09-技术与设备/收音装备.md)） |
| 剪辑 | 素材量超过你可在两个月内核完的量；或你需要**不爱你素材的人** | 剪不动、剪不舍、结构靠感觉 | 剪辑按项目外包，先做 10 分钟试剪 |
| 翻译 / 方言转写 | 出现你听不懂或不能逐字校对的语言 | 字幕逐字性失守（[../10-伦理法律/事实核查与更正.md](../10-伦理法律/事实核查与更正.md) §5） | 本地译者 + 词表协作（[../08-剪辑后期/字幕与无障碍.md](../08-剪辑后期/字幕与无障碍.md)） |
| 驾驶 / 长途 | 单日转场长、夜间路、山区 | 疲劳驾驶是唯一会把项目清零的风险 | 司机或包车，你不做当日驾驶 + 当日粗剪 |
| 法务 | 出现商业合作、平台定制、纠纷通知、撤回争议 | 事后补条款成本远高于事前一次咨询 | 律师按次咨询，不买常年服务 |
| 放映组织 | 场地、设备、秩序、二次拍摄规则需人管 | 你在台上，现场无人处理突发 | 本地协作者按场次（[../12-发行传播/社区放映与参与式传播.md](../12-发行传播/社区放映与参与式传播.md)） |

判据一句话：**这个环节出错，我能不能事后修？**不能修（录音、安全、权利）就先加人；能修的（调色、图形）可以先自己扛。

## 2. 用工形式：外包与雇用的真实差别

【操作性建议】两种关系的差别不在「谁便宜」，在**责任与义务落在谁身上**。具体税费、社保、发票口径随身份、地区与政策变化，本篇只写「要问哪一句」：

| 维度 | 雇佣（劳动关系/劳务关系） | 外包（承揽/服务，按交付物） |
| --- | --- | --- |
| 义务负担 | 用人单位侧承担社保与代扣代缴等法定义务（**是否构成劳动关系以实际用工形态认定，不由合同标题决定**） | 主要由承接方自行申报与缴纳，你要的是发票或合规收款凭证 |
| 成本结构 | 按时间付，长期固定支出 | 按交付物付，可中断 |
| 交付责任 | 过程管理在你；结果责任模糊 | 结果责任写进验收判据，返工规则明确 |
| 权利归属 | 职务作品/职务成果有法定默认，需约定 | 委托作品需**书面约定归属**，未约定时默认利于承接方【核验】（《著作权法》关于委托作品归属可由合同约定；条文以现行有效文本为准） |
| 解约 | 有法定程序与补偿义务 | 按合同约定，通常更干净 |
| 该问律师的一句 | 「这个人跟我之间会不会被认定成劳动关系？」 | 「这份合同是不是承揽，验收和返工怎么定义？」 |

结论【操作性建议】：一个人项目**默认用按交付物的外包**，只有当你需要一个人长期、每天、按你指令工作时，才考虑用工关系——而那是另一个量级的承诺，不该在缺钱时发生。

## 3. 协作方必须签的三份文件

【操作性建议】不论对方是朋友、同好还是专业公司，三份文件一份不能少（文本骨架见 [../15-工具与模板/授权文书模板.md](../15-工具与模板/授权文书模板.md)，本篇只给条款要点）。

### 3.1 内容制作服务合同

| 项 | 必须写明 | 常见坑 |
| --- | --- | --- |
| 交付物 | 文件级清单：工程文件、导出片、字幕文件、混音分轨、素材整理表 | 只写「成片一支」，验收时争「什么叫完成」 |
| 验收判据 | 客观可查：时长、规格、声道、字幕逐字率、通过谁的哪一轮检查 | 用「满意为止」当判据 |
| 修改轮次上限 | 轮次数 + 每轮范围（结构性修改与微调分开算） | 无上限 → 无限返工 → 对方停工或加价 |
| 付款节点 | 定金/中期/尾款与各节点触发条件（对齐闸门，见 [./预算与制片管理.md](./预算与制片管理.md) §4） | 全款前置，失去返工杠杆；全款后付，对方失去现金流 |
| 违约与终止 | 终止时已付款与已交付如何处理、素材归还与删除期限 | 「双方协商解决」等于没写 |
| 延期 | 延期定义、通知义务、谁的原因谁承担 | 把你的素材不到位算成对方违约 |

### 3.2 著作权与授权条款

必须逐项落到文字【操作性建议】：**署名方式与位置**；**素材原件与工程文件的归属与交付**（工程文件不给，你就永远依赖这个人）；**后续衍生权利**（短片、海报、课程、再剪辑各自归属）；**使用范围与期限**（对方能否把参与作品放进个人作品集、多久之后可以）；**第三方素材谁负责清权**；**未使用素材的处置**（不得留存、不得外发，删除留记录）。**不得约定转让全部著作财产权、不得要求你放弃署名**——这条与发行合同的红线一致（[../12-发行传播/流媒体与平台发行.md](../12-发行传播/流媒体与平台发行.md) §3）。

### 3.3 保密与个人信息条款

协作方在素材里看到的，是可识别的个人、未公开的经营信息、纠纷中的人事。**这三样都不能因「他帮我剪片」而变成他的信息**。要点【操作性建议】：不得留存素材副本、不得上传到公共网盘或在线工具（工具链的数据边界见 [../09-技术与设备/AI工具链.md](../09-技术与设备/AI工具链.md)）、不得向第三方播放（含朋友）、项目终止后限期删除并留记录、个人信息处理遵循最小必要（对齐 [../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.4：真名默认化名、可审计删除）。再加一条**内容边界**：不得对外谈论未发布内容与当事人身份——社交场合的一句剧透是你无法追悔的事故（更正与事故响应见 [../10-伦理法律/事实核查与更正.md](../10-伦理法律/事实核查与更正.md) §6）。

## 4. 合同评审五问

拿到任何一份对方给的文本，先答这五问；答不出就带去问律师【操作性建议】：

1. **素材原件与工程文件在谁手上，最终归谁？**（决定你能否换人、能否再剪）
2. **修改算谁的？**（轮次、范围、超时费率，决定返工归责）
3. **终止时已付款与已交付怎么算？**（决定最坏情况的损失上限）
4. **我能不能把它给别人看？**（保密与展示范围，决定你还能不能参赛、放映、接下一单）
5. **发生纠纷在哪解决、用什么语言、多久？**（管辖与成本；个人项目耗不起远距离程序）

## 5. 一个人团队的隐性成本：两项必须用钱解决

| 隐性成本 | 机理 | 花钱的解法 |
| --- | --- | --- |
| **无人复核** | 你写旁白、你剪、你打字，事实错误没有第二双眼睛；错误率随熟悉度上升（越熟越看不出） | 至少买一次外部核查：断言清单交叉核对、字幕逐字校对、放映前一人次试看（流程见 [事实核查与更正](../10-伦理法律/事实核查与更正.md) §2） |
| **无人在场** | 无人看路、无人看护设备、无人处理现场冲突，事故响应时间等于你一个人的反应时间 | 高风险现场必须两人；不可得则改期，不用运气换素材（[../07-拍摄执行/现场工作流与安全.md](../07-拍摄执行/现场工作流与安全.md)） |

两条都指向同一件事：**在「复核」与「在场」上省钱，是把风险从预算表挪到了别处**——错误台账、事故、关系破裂。

用眼与工时补充【操作性建议】：长时间盯屏的工序（逐字校对、达芬奇节点检查、字幕对轴）优先外包或改为纸面/听觉工序，这是 900 度近视下的排产约束，不是效率偏好。

## 6. 自由职业者的现实：付款、验收、试工

- **付款节奏**：对方要定金是理性的（他们没有积蓄缓冲）；你能做的是把节点切小、尾款比例别太高、按闸门释放（[./预算与制片管理.md](./预算与制片管理.md) §4）。压尾款过高会毁掉合作关系，全款前置会毁掉你的返工能力。
- **验收费率与轮次**：按次、按天、按项目三种报价不可直接比较；比较前先统一「交付物清单 + 轮次上限 + 超时费率」，否则报价差异其实是范围差异。
- **试工小任务**：用一支 3–5 分钟的真实小任务判断人（一次字幕校对、一条 60 秒切片、一段 10 分钟素材的日志整理），付小额费用，看三件事：**是否按时、是否主动报问题、是否遵守保密**。试工不合格不进入长项目——长期跟拍项目换人的代价是全盘返工。可用任务与判据【操作性建议】：

| 试工任务 | 时长 | 你在看什么 | 不合格信号 |
| --- | --- | --- | --- |
| 10 分钟素材写日志（含时间码与主题字段） | 半天 | 是否照你的字段规范、有没有偷懒合并 | 字段自创、时间码含糊 |
| 一段 60 秒方言/外语字幕逐字校对 | 数小时 | 逐字纪律、不确定处是否标注 | 擅自意译、不标注疑问 |
| 一条 60 秒切片（给素材与口径） | 一天 | 是否守住不改变结论这条底线 | 为节奏改了原话含义 |
| 一次放映现场协助 | 一晚 | 秩序处理、是否拍照外传 | 未经许可记录当事人 |

- **不要用「以后有钱」找人**：这是把项目成本转嫁给最弱势的合作方，也是你自己选题质量下降的信号。

## 7. 交付验收单

【操作性建议】外包结束前，填一张验收单再付尾款，五项都过才结：

| 验收项 | 通过判据 | 证据 |
| --- | --- | --- |
| 文件齐 | 对照合同交付物清单逐条勾选 | 交付目录列表 |
| 规格对 | 时长、分辨率、声道、字幕文件与母版一致 | 规格核对表（[../08-剪辑后期/交付母版与规格.md](../08-剪辑后期/交付母版与规格.md)） |
| 工程可续 | 工程文件、媒体链接、插件与字体清单可打开 | 你在自己机器上打开一次 |
| 事实无误 | 断言清单相关条目已过 | 核查记录（[../10-伦理法律/事实核查与更正.md](../10-伦理法律/事实核查与更正.md) §2） |
| 无留存 | 对方已删除自用副本并书面确认 | 删除确认一行 |

## 8. 志愿者与熟人帮忙

无合同 → 无边界 → 反目，这条链条几乎是必然【操作性建议】。熟人帮忙至少写一页纸：做什么、多久、给什么（钱、署名、拷贝）、什么时候结束、素材能不能留存、退出怎么说。**不给报酬也要书面写清是无偿**，并在署名里体现；否则事后「我帮你那么多」无法对齐。三样东西不给熟人：素材原件访问权、当事人联系方式、发布决定权。

## 9. 一个人能带多少协作方，以及怎么换人

【操作性建议】单人项目的管理幅度**同时活跃的协作方以 2–3 人为上限**。超过之后，你会发现自己在做日程、催稿、解释素材背景——这些工序不产生任何素材，且必须在你唯一的高效时段（白天精力最好的几小时）里做。判断「不能再加人」的信号：连续三天没有推进自己的剪辑或访问；同一个问题被两个人问第二遍。

**加人与换人的顺序**：先加复核角色（剪辑助理、校对、录音）→ 再加技术角色（调色、混音、图形）→ 最后才考虑制片型角色（有人替你管日程）。**制片型最晚加**，因为他需要完整理解素材，而素材的判断权是你唯一不可让渡的部分。

**换人流程**（每一步都留记录）：

1. 结清当期已完成部分的款项，按交付物比例，不按印象；
2. 收回工程文件与素材，**当面或视频见证删除对方留存副本**（合同 §3.3 是这一步的依据）；
3. 向被换掉的人说明项目信息不得外传，包括当事人身份；
4. 给接手人的是**素材日志 + 结构文档**，不是口头讲述——如果这份文档不足以让人接手，问题不在人，在你没有沉淀；
5. 换人后重做一次断言清单核查，因为前一版的判断没有被复核过。

## 常见误区

| 误区 | 事实 |
| --- | --- |
| 「合同是不信任的表现」 | 合同是长期合作的前提；不写清楚才是给关系埋雷 |
| 「工程文件谁做谁拿着」 | 工程与源文件归属必须书面约定，否则你永远被一个人锁定 |
| 「外包便宜所以随便找」 | 交付责任全在条款里；条款空白=最贵的返工 |
| 「朋友帮忙不用签」 | 无边界 → 反目；一页纸也要签（§8） |
| 「我一个人不需要复核」 | 无人复核是非虚构事实错误的第一来源（§5） |
| 「先干活后补合同」 | 素材一旦交出去，谈判地位就换了；先签再给文件 |
| 「口头说好不外传」 | 保密、留存、删除、终止后义务都要成文（§3.3） |
| 「以后有大项目再说合同」 | 第一次合作写的版本可以复用，第一次合作没写会毁掉项目 |

## 实操要点

- [ ] 只在「出错不可事后修」的环节加人：录音、安全、权利、复核。
- [ ] 默认按交付物外包，不用「满意为止」当验收判据；写轮次上限与超时费率。
- [ ] 三份文件齐全再交素材：服务合同 + 著作权与授权条款 + 保密与个人信息条款。
- [ ] 工程文件与源素材的交付与归属写进条款；不转让全部著作财产权、不放弃署名。
- [ ] 任何文本先答 §4 五问，答不出就带去咨询执业律师（本篇非法律意见）。
- [ ] 长盯屏工序（校对、对轴、节点检查）优先外包或改纸面/听觉做法。
- [ ] 高风险现场不接受一人制；不可得就改期。
- [ ] 熟人帮忙签一页纸，注明无偿与署名；素材原件、当事人联系方式、发布决定权不外放。
