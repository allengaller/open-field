# 拍摄许可与场地

> 大多数人说「我打过招呼了」，其实只拿到了四层许可里的第一层的一半。许可是一张分层清单，不是一句话。

人员同意（第三层）的完整规范在 [../10-伦理法律/知情同意与拍摄授权.md](../10-伦理法律/知情同意与拍摄授权.md)，本篇不重述；文书文本骨架在 [../15-工具与模板/授权文书模板.md](../15-工具与模板/授权文书模板.md)，本篇给**谈判与判断**。法律边界只作风险提示，不构成法律意见，具体条文以现行有效文本为准（见 [../10-伦理法律/中国法律边界.md](../10-伦理法律/中国法律边界.md)）。

---

## 1. 四层许可：一层没拿到就有一层的事故

| 层 | 回答的问题 | 谁能给 | 拿不到的后果 |
| --- | --- | --- | --- |
| **场所准入**（premises access） | 我能不能带着机器进这个门 | 经营者、管理方、物业、业主 | 中途被请出、素材合法性争议、关系破裂 |
| **内容准入**（content scope） | 我进去之后能拍什么、哪些不能拍 | 管理方 + 其上级/法务；涉密内容没有「能给」的人 | 触碰商业秘密与内部规定，风险落在你和当事人身上 |
| **人员同意**（individual consent） | 每个可识别个体愿不愿意被拍、被用到哪 | 只有本人（员工不能由老板代答） | 同意无效，素材不可发布（[知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md) §4 权力污染） |
| **特殊活动许可**（special permits） | 这一种拍法本身要不要报批 | 主管部门 | 行政责任、当场中止、连带牵连场地 |

**这四层互相独立**：老板同意 ≠ 工人同意；管理方同意你进大门 ≠ 同意你拍车间；拿到场所准入 ≠ 拿到空域或道路使用许可。台账里分层记录（字段沿用 [../10-伦理法律/知情同意与拍摄授权.md](../10-伦理法律/知情同意与拍摄授权.md) §7 的同意台账，加「场所」与「范围」两列）。

## 2. 公共空间与私人空间的界线

【操作性建议】判据不是「有没有围墙」，是**谁有权设定行为规则**：

| 类型 | 规则设定者 | 你要拿的东西 | 注意点 |
| --- | --- | --- | --- |
| 真正公共的开放空间（街道、广场、市场公共通道） | 公共秩序规则 | 通常无需场所同意，但需遵守现场管理要求 | 仍需处理可识别个体的同意与反对（第三层不可跳） |
| 半公共经营性场所（菜市场摊位、门店、餐馆） | 经营者 + 市场管理方 | 经营者的准入 + 管理方规定 | 摊位往往「房东—市场—摊主」三方，三层都要问清 |
| 私人/单位封闭场所（工厂、写字楼、园区、村内设机构） | 管理方 + 上级 | 书面场所准入 + 内容范围 | 有门禁、有内部规定的，一律走管理方正式渠道 |
| 涉密与关键基础设施场所 | 不属于你能谈判的范围 | **不拍** | 识别为禁区即放弃，不试探、不寻找替代角度；不提供任何规避门禁或管理方审查的方法 |

**识别禁区的做法**：入口有安保审查、要求登记、张贴禁止摄影标识、涉及公用设施与交通枢纽核心区、医疗机构特定区域、司法监管场所——出现任一特征，先按禁区处理，不做「只拍外面一点」的自我说服。

## 3. 特殊活动许可：一律走正式申请

【操作性建议】四类常见，处理方式相同——**以现行规定与主管部门要求为准，走正式申请与登记流程，取得书面许可后再拍**；未取得就取消该拍法，不用变通手法。

| 拍法 | 涉及事项 | 你要做的 |
| --- | --- | --- |
| 无人机航拍 | 空域使用、实名登记、操作人员资质、场地起降许可 | 查当期规定 → 走申报 → 拿批准文件 → 场地书面同意 → 现场可被质询时出示 |
| 道路与公共秩序 | 占用道路、影响通行、人群聚集 | 向主管部门申请；不改期就取消，不「先拍了再说」 |
| 未成年人相关机构 | 学校、培训机构、儿童活动场所 | 需机构与监护人双侧书面同意（[../10-伦理法律/弱势群体与儿童.md](../10-伦理法律/弱势群体与儿童.md)） |
| 医院、司法与监管场所 | 特定敏感场景 | 正式申请 + 主管批准；批准不到即不拍，且不用候补方案绕开 |

无人机另有机身与操作层面的技术要求（[../09-技术与设备/稳定器与特种拍摄.md](../09-技术与设备/稳定器与特种拍摄.md)）；本篇只管许可这一层。

## 4. 怎么谈准入：给什么、不给什么

【操作性建议】谈准入的核心不是话术，是**让对方看到他能得到什么、会承担什么**。

**对方的好处（挑真实的那几条）**：一次成体系的记录（他会成为这个行业/地方的档案）、内部培训或招商可用的素材（可以给他一份不含未同意内容的拷贝）、被认真描述的机会（多数经营者从没被人完整说过自己怎么干活）、以及你带来的专业视角本身（你的咨询能力可换准入，见 [./资金渠道地图.md](./资金渠道地图.md) §2.7、[../../研究/行动总纲.md](../../研究/行动总纲.md) §2.3）。

**可以给的四类承诺**：事先告知拍摄范围与用途；现场可停（对方说停就停，不问理由）；可要求去除某段（按承诺表处理，见 [../07-拍摄执行/长期跟拍.md](../07-拍摄执行/长期跟拍.md) §5）；发布前告知发布渠道与时间，并按约定做放映回场。

**绝不能给的六类承诺**：

| 不给 | 原因 |
| --- | --- |
| 「播不播由你定」/ 审片权 | 一给就毁掉作品，且你无法对每个合作方都履行（界线见 §8） |
| 「一定播、一定什么时候播」 | 发布取决于当事人同意与平台流程，不由你定 |
| 「会把你拍得很体面/很好看」 | 是形象承诺，等于隐性审查授权（诚实清单见 [./资金渠道地图.md](./资金渠道地图.md) §6） |
| 「绝不拍到任何风险信息」 | 你无法事前识别哪些是风险信息 |
| 「数据/流水我不会用」 | 承诺要覆盖得住；改成「涉及经营数字的表述一律回原声与凭证核对，核不实不上片」 |
| 「不给同行/别人看」无限期 | 期限可给，无限期不可给 |

谈判节奏【操作性建议】：先约一次不带机器的拜访（只谈，不拍）；第二次带机器但不开机（走一遍动线）；第三次才开机。三层许可分别取得时点写在日历上，不要指望一次谈完。

## 5. 企业参观式拍摄的陷阱

对方安排好的现场，是**企业想让外界看到的那一面**：临时清理、调走不该在场的人、把复杂工序简化成一条可讲解的动线、车间主管全程陪同。这不是「拍不到」，是拍到了不该当证据的东西——**它记录的是展演（performance），不是日常**（相机在场效应见 [../14-田野与影像/相机在场效应.md](../14-田野与影像/相机在场效应.md)）。

争取非安排时段的正当做法【操作性建议】：

1. **谈时段，不谈权限**：直接说「我希望有一次不在安排的参观动线上，我自己按安全规定走」，请求的是时间，不是越权。
2. **固定重复访问**：同一个人每周同一时间到场，安排的成本升高，日常会自己回来（习惯化阶段见 [../07-拍摄执行/长期跟拍.md](../07-拍摄执行/长期跟拍.md) §4）。
3. **拍工序不拍讲解**：讲解内容按展演处理，不进事实层；把讲解单独存为「对方自我呈现」的一层素材，这本身是有价值的材料。
4. **交叉验证**：安排现场说的话，必须与非安排时段的观察、单据、第二来源对照（[../../田野方法/08-信效度.md](../../田野方法/08-信效度.md)）。
5. **争取不到就降级使用**：参观式素材可以用，但要在断言清单里标为「对方安排的呈现」，不据它写事实结论（分级规则见 [../10-伦理法律/事实核查与更正.md](../10-伦理法律/事实核查与更正.md) §1）。

陪同人员的存在会抑制工人说话：**老板在场时员工签的字无效**（[知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md) §4），单独确认不是技巧，是效力要件。

## 6. 现场标识与告知

【操作性建议】让不在场的人也有机会知道这里在拍：

- **入口张贴**：一张纸写「此处正在拍摄纪录片《××》，拍摄者 ×××，联系电话 ×××，如不愿入镜请联系，我们按您的意愿处理」。这既是告知，也是你自己出事时的凭据。
- **口播提示**：涉及人群的场景，开拍前口头 announce 一次，录进同期声（这段口播本身就是可核查的告知证据）。
- **静止机位/延时摄影**：无人值守时必须有标识与联系方式；出现明确反对者按其意愿处理，无法排除可识别第三人时不保留（规则见 [../07-拍摄执行/长期跟拍.md](../07-拍摄执行/长期跟拍.md) §7）。
- **禁止任何隐蔽拍摄**：不藏机器、不假借身份、不无同意录音（[../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.4）。**没有「来不及告知」的正当版本**——来不及，就只拍不涉人的空镜，或者放弃这一场。

## 7. 许可书面化的最小要素

文本骨架在 [../15-工具与模板/授权文书模板.md](../15-工具与模板/授权文书模板.md)；这里给**判断清单**——一张场所准入书面文件缺任何一项，就不算拿到（【操作性建议】）：

| 项 | 写什么 |
| --- | --- |
| 双方与权限 | 谁同意、他有权决定到哪一层（能否代表上级/业主） |
| 范围 | 具体地点、可拍与不可拍区域、可涉人员范围 |
| 方式 | 手持/脚架/无人机/延时；是否允许录音；可否使用灯光与电源 |
| 期限 | 起止日期、可否重复、可否转给下一次访问 |
| 保密与排除 | 对方主张不可拍的具体对象（设备型号内部代号、单据、屏幕）；你如何现场执行 |
| 发布与致谢 | 你承诺给什么（放映、拷贝、致谢），不承诺什么（见 §4） |
| 撤回 | 对方如何撤回、撤回后你怎么处理（§9） |
| 责任 | 场地损坏与安全责任的归属（§10）、保险要求 |

拿不到正式书面时，退一档留证：现场负责人签字的备注页、往来消息截图、开场口播说明入同期声。**退档要记进台账，不能替代第三层人员同意。**

## 8. 「你先给我们看一遍再决定」

企业、机构、地方常会提这个要求。给一条清晰界线【操作性建议】：

> **可以给内部放映，不给审片权。**

具体表述：「我可以给贵方一次内部放映，针对**事实性错误**和**贵方主张的商业秘密/内部管理信息**提出意见，我逐条核对并书面回复；但**内容取舍与最终剪辑由我定**，这是纪录片的基本前提。如果贵方需要决定成片内容，那这不是我能承接的项目。」

| 可给 | 不可给 |
| --- | --- |
| 放映、事实错误清单、涉密与内部信息核对、法律风险提示后的修改 | 逐段删改权、预先批准权、以「不给播」为条件的交换 |
| 书面回复每条意见（采纳或不采纳及理由） | 口头承诺「按您意见改」 |

**为什么这条界线必须硬**：一旦一处给过审片权，你的所有合作方都会要求同样待遇，作品就不存在了；同时你无法对当事人兑现「我会照你说的改」（他们要求的往往正是对方要删的）。当事人一侧的对应机制是发布确认与放映回场（[../12-发行传播/社区放映与参与式传播.md](../12-发行传播/社区放映与参与式传播.md)），那是对**被拍的人**负责，与向**给了场地的人**交审是两件不同的事。

## 9. 许可被撤回时怎么办

【操作性建议】顺序不可乱：**立刻停 → 已拍分层 → 按约处置 → 记录**。

1. **立刻停**：撤回提出当场停止使用与继续拍摄；不追问理由、不说服、不用关系施压。
2. **已拍素材分层**：撤回只覆盖撤回人/撤回方有权决定的范围。管理方撤回场所准入 → 停止再进入；**员工个人的可识别素材不因老板撤回而自动可删**，个人是否继续使用按本人同意状态判定（台账逐条查）。
3. **按约处置**：书面文件里承诺过什么就做什么（下架、匿名化、删除、重制），无法做到部分如实书面说明能力边界。
4. **记录**：台账追加变更行，注明所撤版本与处置结果；同类撤回第二次出现，说明准入谈判有问题（回到 §4）。

**当事人权利优先于场地许可**：两者冲突时，先满足个体的撤回与删除请求，再与场地方另行处理——这是 [../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.4 的要求，也是你唯一不会后悔的排序。

## 10. 场地损坏与第三方责任

【操作性建议】事前四句、事后三句。事前：**明确是否需买保险**、设备进出与摆放谁负责、损坏如何认定（拍照留现场状态）、有无易燃/粉尘/洁净区等设备使用限制（电力与灯光见 [../09-技术与设备/灯光与电力.md](../09-技术与设备/灯光与电力.md)）。事后：**当场承认并记录**（不当场争论责任比例）、书面报价与赔付路径、不让当事人替你的责任与厂方交涉——**你造成的争议由你自己承担，是保住关系唯一的方式**。

## 常见误区

| 误区 | 事实 |
| --- | --- |
| 「老板同意就是全同意」 | 四层独立；老板答不了员工个人的同意，也答不了主管部门的许可 |
| 「公共场合想拍就拍，所以不用管同意」 | 场所开放不等于个体无权利；第三层与告知义务仍在（§6） |
| 「先拍，出了事再解释」 | 无隐蔽采集的正当版本；一次解释不清，整条引荐链条关闭 |
| 「对方安排的现场就是他们的日常」 | 那是展演，需交叉验证并降级使用（§5） |
| 「给他们看一遍又不改，无所谓」 | 一次放映换不来免审；开了口子就要对所有合作方履行（§8） |
| 「口头打过招呼，不用写」 | 期限、范围、方式、撤回全在书面里；口头只能退档留证（§7） |
| 「涉密场所拍外围总没事」 | 识别为禁区即放弃，不做「只拍一点」的自我说服（§2） |
| 「许可被撤，素材全删了事」 | 撤回范围有边界；个体同意与管理方许可分开判（§9） |

## 实操要点

- [ ] 进场前把四层许可逐项打勾：场所、内容、个体、特殊拍法，缺一层就缺一层的动作。
- [ ] 禁区识别即放弃：涉密、关键基础设施、医院与司法场所、无批准的空域与道路。
- [ ] 无人机、道路占用、机构与未成年人场景一律正式申请，取得书面后执行。
- [ ] 准入谈判分三次：不带机器谈 → 带机器不开机走动线 → 开机；§4 六不给承诺背熟。
- [ ] 争取非安排时段是「谈时间」不是「谈权限」；参观素材在断言清单里标为安排呈现。
- [ ] 入口张贴 + 口播入同期声；静止机位无人值守必须有标识与联系方式。
- [ ] 书面许可缺 §7 任一项即视为未拿到；退档留证并记入台账。
- [ ] 「可放映、不可审片」一句话说清；撤回按四步执行，当事人权利优先于场地许可。
