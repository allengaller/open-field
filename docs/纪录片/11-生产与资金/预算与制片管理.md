# 预算与制片管理

> 一个人拍片最容易死法不是没钱，是没有阶段闸门：钱在第十周花完，片在第三十周才有结局。把片子当一次发布来管——每个阶段有通过判据，未过不推进。

本篇管**组织与钱**：预算怎么拆、估算怎么做、日历怎么排、范围怎么守、什么时候必须停。提案阶段的价值判断见 [./项目开发提案.md](./项目开发提案.md) 与 [../../研究/行动总纲.md](../../研究/行动总纲.md) §8.5。**本篇全程不写金额数字**：具体额度与期限属私人参数，一律以你自己的试错资金包上限为准（该文 §8.4 已定此规）。

---

## 1. 预算结构：六条线，只看科目

【操作性建议】先把科目列全，再谈估算；科目漏一项，钱就从那一项漏光。

| 线 | 包含科目 | 最常见的漏项 |
| --- | --- | --- |
| 开发 | 预研差旅、访谈前研究、试拍、提案与材料制作、法律咨询 | 把「想清楚」当成零成本 |
| 制作 | 交通、住宿、餐饮、场地与准入相关支出、耗材（存储、电池、胶带）、设备租赁或维护、道具性支出、被摄者时间与误工补偿（如你承诺） | 重复到达的成本（一次不等于一路） |
| 后期 | 剪辑、调色、混音、字幕与翻译、音乐授权与制作、图形与档案素材授权、备份与介质 | 用「我自己剪所以免费」掩盖真实工时 |
| 发行 | 报名与投递费用、放映设备与场地、字幕与技术拷贝、物料与版权登记、争议处理准备金 | 交付物返工（每上一个新渠道都要重出一版规格） |
| 管理 | 通信、软件订阅、账务与票据工具、保险、你自己生活成本 | 不给「项目管理」列预算 = 用无偿劳动补 |
| 应急 | 设备损坏/丢失、行程变更、医疗、加拍、法务紧急响应 | 被当成可挪用余额花掉 |

**六条线各自独立记账**，应急不许挪作他用；挪用一次，下次出事就只能砍拍摄日。

## 2. 估算方法：四种，全部可复算

| 方法 | 适用线 | 怎么做 | 误差控制 |
| --- | --- | --- | --- |
| 自下而上按拍摄日 | 制作 | 单个拍摄日 = 当日交通 + 住宿 + 餐饮 + 耗材折旧 + 准入成本；乘以预计拍摄日数 | 拍摄日数从 [../07-拍摄执行/长期跟拍.md](../07-拍摄执行/长期跟拍.md) §12 的周期表反推，不凭感觉 |
| 按素材量估后期小时数 | 后期 | 先用日志统计原始素材总时长（[素材管理与日志](../08-剪辑后期/素材管理与日志.md)），再按你试剪得到的「每小时素材 → 若干小时整理 + 剪辑」系数外推 | 系数必须来自**你自己的第 12 周试剪实测**，不用别人说的数 |
| 单价 × 数量 × 风险系数 | 单件大额（租赁、授权、外包） | 单价与数量取可核查报价；风险系数反映延期与返工概率 | 系数只放大已知不确定性，不给「大概」加成 |
| 固定比例应急 | 应急 | 在合理总额之外预留一个事先定死的比例（数值由你按自己的资金上限自定，本篇不代你定） | 写进预算表，不与任何科目混记 |

【操作性建议】所有估算保留三档：悲观 / 基准 / 乐观。**决策用悲观档**，宣传用基准档，乐观档只用于判断「最顺的时候能省多少」。

## 3. 现金流：真正的难点不在总额，在时序

个人项目没有对公账期，你的现金流有三种典型错配【操作性建议】：

| 错配 | 机理 | 处置 |
| --- | --- | --- |
| 垫付在前、回款在后 | 平台结算、分账、奖金、采购款都有账期，而车票在昨天就要付 | 按月做**支出前瞻表**：未来八周必须付的现金，对照你愿意垫付的上限 |
| 收入不规则 | 一笔激励到账不能当经常收入 | 收入分「已到账 / 应计 / 承诺未付」三态，只有第一态能进预算 |
| 一次性支出伪装成经常支出 | 设备、授权费一次性大额 | 单列，不参与月度均摊，避免把资本支出当生活费 |

**「应计收入不算收入」是纪律，不是保守**：任何以「应该会有」为前提的拍摄计划，都要有一个「如果不来」的备用版本（缩到本地拍摄、或延后一周）。

## 4. 里程碑与阶段闸门（用你熟悉的语言）

【操作性建议】每个闸门写三件事：**判据（可核查）/ 证据（在哪里）/ 未过怎么办**。未过就停，不许「先干了再说」——这就是变更评审在内容生产里的等价物（对齐 [../../../PRINCIPLES.md](../../../PRINCIPLES.md) §3 的「确认再动手」）。

| 阶段 | 通过判据 | 证据 | 未过怎么办 |
| --- | --- | --- | --- |
| G0 预研 | 拿到口头准入 + 三层时间框架成文 | 承诺表、场地图、笔记 | 不开机，换点或换题 |
| G1 进入 | 有效同意覆盖 ≥1 名可识别主角；素材日志运转 | 同意台账（[知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md) §7） | 停止拍人，只拍不涉人的场景 |
| G2 沉底 | 完成 10 分钟试剪且能说明结构 | 试剪文件 + 断言清单 | 不加拍摄日，回结构（[粗剪到精剪](../08-剪辑后期/粗剪到精剪.md)） |
| G3 转折 | 主角事件发生或明确不发生；撤回风险已排查 | 时间轴、素材日志状态位 | 启用备用形态，不追拍 |
| G4 定剪 | 权利链齐、核查通过、母版归档 | 权利链档案（[版权链与E&O](../10-伦理法律/版权链与E&O.md)）、断言清单 | 不进发行，先补证 |
| G5 发布 | 逐版发布确认完成、交付规格核对 | 台账版本号、交付件清单（[交付母版与规格](../08-剪辑后期/交付母版与规格.md)） | 不发布，不「先发再补」 |

**每个闸门配一次资金释放**（阶段预算随闸门开）：闸门未过而钱已花完，就是排期设计错了，不是意外。

## 5. 制片日历：把身体和家庭写成硬约束

【操作性建议】排期从外往里填，不从想要往里填。固定四道约束：

1. **强制回家周期**：每在外一个月必须回家陪家人一周，这一周**写进日历占位、不可用任何事由替换**（[../../研究/行动总纲.md](../../研究/行动总纲.md) §8.4）。回场周不得安排访问、剪辑定档、交付；它是排期约束，不是休息建议。
2. **用眼负荷约束**：单日盯屏工时设上限，超时改纸面工序（打印脚本、纸质断言清单、听原声对字幕，见 [事实核查与更正](../10-伦理法律/事实核查与更正.md) §2）。长途驾驶与高强度剪辑不排同一天。
3. **不可动事件日**：发薪日、赶集日、庭审、年检等按 [../07-拍摄执行/长期跟拍.md](../07-拍摄执行/长期跟拍.md) §7 的年历提前锁定，这些日子优先于任何计划内拍摄。
4. **缓冲日**：每次外拍前后各留一天，用于备份、台账、失败重访；缓冲日不排新事件。

日历最小单元用「拍摄日 / 整理日 / 交付日 / 缺席日」四类。**缺席日必须存在**：连续在场会摧毁关系与判断力。

## 6. 进度与风险可视化：一张表就够

【操作性建议】不要上工具，就用一张周更表（与仪表盘做法同源，见 [../12-发行传播/数据复盘与迭代.md](../12-发行传播/数据复盘与迭代.md) §3）：

| 目标 | 实际 | 偏差 | 应对 | 下一步责任人 |
| --- | --- | --- | --- | --- |
| 本周完成 2 次访问 + 10 分钟试剪 | 1 次访问，试剪未开始 | 落后 | 试剪推到下周二，取消下周三的补拍 | 我 |

规则三条：**偏差必须能归到某一项原因**（无归因的偏差就是没记录）；**应对必须是动作不是态度**（「更努力」不算）；每四周把「连续两周偏差」的条目提出来做一次结构变更（对齐 §7 的范围控制）。

## 7. 范围控制：非虚构第一大坑

素材只会多不会少，因此砍线判据必须事先写好【操作性建议】。四条「这条线不加」：

- 该线**没有必须等的结果**（拍了也只是过程）；
- 该线**没有独立准入**（要新增一层许可才能拍，而许可拿不到手）；
- 该线**只为满足你的好奇**，与已定主题之间讲不出一句可核查的因果；
- 该线**要重开一轮素材整理**而当前日志结构不支持。

【通行共识】中途扩线最典型的伪装是「反正顺路」。顺路增加的采集目标会击穿每次访问 2–3 件的目标上限（[长期跟拍](../07-拍摄执行/长期跟拍.md) §3），后果不是多拍一点，是原有素材质量下降。

## 8. 单集成本与「值不值得飞一次」的算法

不写数字，写可复算的四步【操作性建议】：

1. **算全成本**：本次行程现金支出 + 你自有的工时折算 + 被摄者时间成本 + 分摊的设备折旧。
2. **算可替换性**：这个问题**能否用远程访谈、一次本地访问、或已有素材回答**？能，则不飞。
3. **算素材独占性**：这段素材是否只有这个时点、这个地点、这个人能给你？不可替换才成立。
4. **算用途数**：同一次行程能否同时喂长版、中版、短切片三条线（切分规则见 [../12-发行传播/自媒体分发.md](../12-发行传播/自媒体分发.md) §1）？一次行程三用途，是单人项目摊薄成本的唯一杠杆。

判据一句话：**「不可替代性 × 用途数 ÷ 全成本」**，同一预算下横向排序取高者。这项算法与「只做离钱最近的事」同源（[行动总纲](../../研究/行动总纲.md) §8.5），差别是非虚构的分母里必须放上你自己的工时——不给自己算工时的成本法，最终都由健康还。

## 9. 供应商、凭证与留档

【操作性建议】个人项目最容易在两年后查不清一件事：这笔钱给了谁、换了什么。三条最小纪律：

- **每笔外部支出留三项**：付款记录、对方身份（能联系到人）、对应交付物文件名或素材编号。做不到就不付。
- **供应商分级**：给个人收款的自由职业者与给企业开票的服务方，凭证与责任不同；后者可要求发票与合同，前者靠合同 + 收款记录（合同条款见 [./团队组建与合同.md](./团队组建与合同.md)）。
- **报销凭证与素材同库不同层**：票据进项目文书目录，命名含日期与事项；不得与素材混放（公开仓库禁放可识别个人信息与家庭财务参数，边界见 [../08-剪辑后期/交付母版与规格.md](../08-剪辑后期/交付母版与规格.md)）。

## 10. 止损线执行纪律

止损是**机制**不是心情，触发条件一旦设定就要能自动执行（[../../研究/行动总纲.md](../../研究/行动总纲.md) §8.4：试错资金包独立额度 + 期限 + 到期判据，具体参数不入库）。执行动作写死四步【操作性建议】：

1. **停新增支出**：先停差旅与外包，不后停。
2. **收关系**：按 [../07-拍摄执行/长期跟拍.md](../07-拍摄执行/长期跟拍.md) §11 做末次访问与当面关机，不用「不去了」代替告别。
3. **素材处置**：已拍素材按同意台账状态分层——无效或已撤回的一律永久排除（[素材管理与日志](../08-剪辑后期/素材管理与日志.md) §6）；当事人行使删除权时全链路可审计清除（[../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.4）。**项目终止不减轻撤回义务**：撤回请求照做，哪怕片子不再存在。
4. **承诺结清**：误工补偿、拷贝交付、致谢承诺在终止时结清并留记录；结不了的书面说明原因。

**转求职不是失败，是计划的另一半**——田野积累的案例、人脉与素材仍是资产（[行动总纲](../../研究/行动总纲.md) §3）。止损执行得干净，下一段合作还有人愿意跟你。

## 常见误区

| 误区 | 事实 |
| --- | --- |
| 「我一个人，不用做预算」 | 没有预算表的结果是把生活费和项目钱混在同一张卡上，一次超支就吃掉家庭固定开销 |
| 「后期我自己做，成本为零」 | 工时是唯一不能事后补的资源；不计工时 = 用健康和家庭时间付款 |
| 「先拍完再算钱」 | 没有阶段闸门的项目，钱在第 10 周花完、片在第 30 周才有结局 |
| 「应急款可以临时挪一下」 | 挪一次就会挪第二次；应急是最后两道防线之一 |
| 「被摄者的时间不要钱」 | 误工与占用是真实成本，承诺过就要结清（与 §10.4 一致） |
| 「顺路多拍一条线不亏」 | 击穿访问目标上限，损耗落在原有素材上（§7） |
| 「应计的钱等于钱」 | 到账前不是收入；以应计为基础排产是最常见的资金链断点 |
| 「止损就是全删素材」 | 处置按同意状态分层，撤回义务在项目终止后仍然有效（§10） |

## 实操要点

- [ ] 六条预算线一次列全科目，每条线独立记账，应急不许挪用。
- [ ] 所有估算出悲观/基准/乐观三档，决策只看悲观档。
- [ ] 后期工时系数来自你自己的第 12 周试剪实测，不用外部经验值。
- [ ] 六道闸门各写判据 + 证据 + 未过动作，资金随闸门释放。
- [ ] 强制回家周写进日历占位，不可用任何拍摄或剪辑理由替换。
- [ ] 每周更新一张「目标/实际/偏差/应对」表；连续两周偏差即触发结构变更。
- [ ] 每笔外部支出留付款 + 对方身份 + 交付物编号，缺一项不付。
- [ ] 止损触发动作四步提前写好并打印，包括「项目终止后仍兑现撤回义务」。
