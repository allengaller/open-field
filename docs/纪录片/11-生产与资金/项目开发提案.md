# 项目开发提案

> 提案不是给别人的表格，是你自己第一次把「我想拍什么」写成一份能被反驳的东西。写不清楚，就不是别人不肯投，是你还没想清楚要拍什么。

**为什么值得先想清楚再动手**：项目提案（proposal / pitch document）的唯一功能是**在花钱之前暴露模糊之处**。一条写不出来的句子，代表现场一定拍不出来的东西。产品侧的立项逻辑与「只做离钱最近的事」的判据见 [../../研究/行动总纲.md](../../研究/行动总纲.md) §8.5，本篇把它翻译成非虚构项目的语言。文书骨架见 [../15-工具与模板/提案与Treatment模板.md](../15-工具与模板/提案与Treatment模板.md)，本篇只讲**每一节要回答什么问题、评审者在哪一节失焦**。

---

## 1. 提案的骨架：十三节，每节一句话任务

【操作性建议】下面这张表就是提案的目录。左列写「这节回答什么」，右列写「读这节的人在哪里走神」——后者决定你把最好的材料放在哪一行。

| 节 | 回答的问题 | 评审者在哪失焦 |
| --- | --- | --- |
| 片名与工作标题 | 别人怎么用三个字复述它 | 不看，只记标题 |
| 一句话（logline） | 这到底是什么片子 | **前两行决定他要不要继续读** |
| 类型与时长形态 | 这是一集还是三部、几分钟 | 不知道自己该拿它怎么办 |
| 为什么是现在 | 晚两年拍会失去什么 | 到这里开始判断值不值得 |
| 为什么是你 | 凭什么是你拍 | 找「换个人也能拍」的证据 |
| 对象与方法 | 你打算怎么拍到 | 看你会不会现场出事 |
| 人物与场景 | 谁是主角、他要什么 | 记不住主角名字就是失败 |
| 结构与结局未知性 | 故事往哪走、你不知道什么 | 怀疑你在编 |
| 视觉与声音设想 | 看起来和听起来什么样 | 跳过形容词，找参考片 |
| 观众与发行路径 | 给谁看、怎么抵达 | 判断这项目能不能回本 |
| 风险与合规 | 会不会出事、出事怎么办 | 一处含糊就整份打折 |
| 预算概要 | 多少钱、花在哪 | 想看有没有漏项，不想看数字 |
| 里程碑与止损判据 | 做到哪算成、什么情况下停 | 判断你是否可控 |

页数控制【操作性建议】：完整提案 6–10 页，一页纸版（one-pager）1 页，路演稿 8–12 页。超过十页说明你在替代思考，不在提供信息。

## 2. 片名与工作标题

工作标题（working title）允许改，但它必须**能指认对象**，不能只有情绪。「金属与灰尘」这类标题什么也没说；「××厂的最后一条线」把地点、对象、时间性都放进了五个字。【操作性建议】起名规则：先用「地点 + 对象 + 正在发生的变化」造一个描述性短语，再从中截出标题；改名只在粗剪后做一次，不在拍摄前反复改——前期改标题往往意味着选题在漂。

## 3. 一句话（logline）：判据是空词表

【操作性建议】写完大声读一遍，出现下表左列任何一词，判不合格：

| 空词 | 为什么失效 | 换法 |
| --- | --- | --- |
| 探索 / 展现 / 呈现 | 这是摄影机的默认动作，不是内容 | 删掉，直接说拍的是谁在干什么 |
| 真实的力量 / 真实记录 | 纪录片的前提，不是卖点 | 换成具体的可核查事实 |
| 关注某群体命运 | 没有对象、没有事件、没有时态 | 换成一个人名 + 一个正在办的事 |
| 深刻揭示 / 引发思考 | 把成果写在承诺里 | 换成成片里能被指着的那一段 |
| 试图还原 | 你自己都不确定 | 换成你确定有的那部分素材 |

合格句式【操作性建议】：**「谁，在什么地方，正在经历什么，而什么在阻拦他」**。一句话里出现具体的人、具体的场所、具体的时间压力，就基本成立。

## 4. 类型与时长形态

写清三件事：体裁（观察型 / 访谈型 / 散文电影 / 系列纪实，判据见 [../00-总览/体例与证据等级.md](../00-总览/体例与证据等级.md) 与 [../05-叙事结构/叙事弧与结构模型.md](../05-叙事结构/叙事弧与结构模型.md)）、形态（单片 / 剧集 / 系列短纪）、体量（成片分钟数与集数）。【操作性建议】同时给一句「**不做成什么**」：不做解说主导的专题片、不做体验类 Vlog——排除项比形容项更能让人知道你在做什么。

## 5. 为什么是现在（时间性）

长期项目最容易被问倒的一节。【操作性建议】三条合格答案：**(1) 有一个必须等三个月才有答案的问题**（跟拍方法见 [../07-拍摄执行/长期跟拍.md](../07-拍摄执行/长期跟拍.md) §1）；**(2) 现场正在消失**——拆、搬、关、退，错过即无；**(3) 人愿意说**——当事人此刻肯讲，两年后身份变了就不讲。不合格答案：这个题材很热、这个行业很重要。热是别人的时钟，你要给的是你自己的时钟。

## 6. 为什么是你：作者位置与不可替代性

【操作性建议】你的真实优势是可核查的三件事：**十年运维的系统思维**（把作坊、菜摊、车间当输入输出与瓶颈来读，这套读法不是文科训练能给的）、**能自己拍自己剪**（无团队 = 无沟通衰减，也 = 单机作业的技术门槛，见 [../07-拍摄执行/一人团队与单机作业.md](../07-拍摄执行/一人团队与单机作业.md)）、**真名出镜并承担后果**（公众账号上写真名，是最低成本的可信度证明，见 [../../研究/行动总纲.md](../../研究/行动总纲.md) §4.2）。

用法上的纪律：**技术履历只在改变故事成立条件时才写**。如果片子讲的是一个车间的产量与工资，「前阿里 SRE」只在两处成立——它能解释你为什么能问到别人问不到的问题，以及你为什么知道哪些数字是假的。写成第三段就变成炫耀，评审者的反应是「这人想回到大厂」。同时写清你的位置局限：外来者、短期停留、没有本地语言与关系网——**承认局限是提案里最便宜的可信度**（反身性要求见 [../../田野方法/03-进入田野.md](../../田野方法/03-进入田野.md) 与 [../10-伦理法律/伦理总论.md](../10-伦理法律/伦理总论.md)）。

## 7. 对象与方法

这一节把「我会拍到」变成「我按这个节奏拍」。【操作性建议】至少给四项：访问频次与单次时长（沿用 [../07-拍摄执行/长期跟拍.md](../07-拍摄执行/长期跟拍.md) §3 的 2–4 小时、开机不超过其中的 60–90 分钟）、预计访问次数与总周期（对齐该文 §12 的周期表）、进出场方式（谁引荐、守门人是谁，见 [../../田野方法/03-进入田野.md](../../田野方法/03-进入田野.md)）、许可路径（场所准入与内容准入怎么拿，见 [./拍摄许可与场地.md](./拍摄许可与场地.md)）。

再加一条**采集方法的可核查性**：数字与陈述如何核验（两级来源规则见 [../10-伦理法律/事实核查与更正.md](../10-伦理法律/事实核查与更正.md) §1）。评审者真正担心的是你拍到一堆情绪却拿不出一个事实。

## 8. 人物与场景

主角判据三条，缺一不立：**他要东西**（具体，不是「想要更好的生活」）、**有障碍**（障碍是结构性的最好，因为它不可一次解决）、**他能表达或他的行动可被拍到**（沉默者也可作主角，但你必须有画面语言补足，见 [../05-叙事结构/人物与主角.md](../05-叙事结构/人物与主角.md)）。场景写「可拍性」而不是「意义」：哪里能站、光从哪来、有没有环境声、能否重复到达。不可到达的场景等于不存在。

## 9. 结构与结局的未知性

长期项目隐瞒未知 = 埋雷；公开未知 = 买保险。【操作性建议】固定写法四句：

> 目前的故事走到 A，我判断它可能走向 B 或 C，两种都在我的拍摄计划里。
> 我承诺的不是某个结局，是**结局出现时我在场**。
> 我的结构会在第 × 周做一次试剪后修订，修订不改变对象与承诺。
> 如果结局不来（人走了、厂搬了、事没了），我的备用形态是 ××。

让人放心投钱不靠承诺结局，靠这四样：**已知的第一批素材**（列出已拍分钟数与可看链接）、**可验证的准入**（谁同意你进、拿到的是哪一层许可）、**阶段闸门**（见 [./预算与制片管理.md](./预算与制片管理.md) §5）、**止损判据**（你自己在什么条件下会停）。这四样把「我不知道结局」从风险变成方法。

## 10. 视觉与声音设想

形容词无效，参考有效。【操作性建议】给三到五部参考，每部只说借它什么：**长镜头观察的节奏**（如怀斯曼一类无解说结构，见 [../02-历史/战后革新与新纪录片.md](../02-历史/战后革新与新纪录片.md)）、**工厂空间的时间纵深**（如王兵《铁西区》一类的车间与劳动场景，见 [../13-案例/世界经典案例.md](../13-案例/世界经典案例.md)）、**同期声的环境底**（见 [../04-声音/同期声与收音.md](../04-声音/同期声与收音.md)）。参考之后必须补一句差异——「我不学它的是 ××」。只列参考不写差异，会被读成模仿。可用截图或 3 分钟试剪做「视觉样片」（sizzle reel），但**样片不许用未同意素材**（硬排除规则见 [../08-剪辑后期/素材管理与日志.md](../08-剪辑后期/素材管理与日志.md) §6）。

## 11. 观众与发行路径

先想清楚给谁看，路径才有意义（受众分层见 [../12-发行传播/受众与传播效果.md](../12-发行传播/受众与传播效果.md)）。【操作性建议】提案里只写三条：主受众一句话、首发的两个渠道（周更自媒体 + 一次现场放映）、后续形态（长版投递节展与否，见 [../12-发行传播/电影节与展映.md](../12-发行传播/电影节与展映.md)）。**不得在提案中承诺播出**——你能承诺的只有「按发布确认流程逐版征求当事人同意后发布」（见 [../10-伦理法律/知情同意与拍摄授权.md](../10-伦理法律/知情同意与拍摄授权.md) §8）。

## 12. 风险与合规：四条线各一句

| 线 | 一句话风险 | 一句话应对 |
| --- | --- | --- |
| 伦理 | 素材涉及可识别个体与劳资敏感信息 | 同意分层、发布逐版确认、撤回可执行（[知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md)） |
| 法律 | 场所准入、商业秘密、肖像与名誉 | 书面准入、涉密不拍、权利链留档（[版权链与E&O](../10-伦理法律/版权链与E&O.md)、[中国法律边界](../10-伦理法律/中国法律边界.md)） |
| 身体 | 长时间盯屏与独行现场 | 排期约束 + 强制回家周期 + 单机安全规程（[现场工作流与安全](../07-拍摄执行/现场工作流与安全.md)） |
| 资金 | 垫付周期长、单一来源断流 | 阶段闸门 + 多来源组合 + 止损线（[./预算与制片管理.md](./预算与制片管理.md)、[./资金渠道地图.md](./资金渠道地图.md)） |

四条线各一句，各引一篇。**不要在提案里写风险分析长文**，评审者只会检查你有没有把它当回事。

## 13. 预算概要、里程碑与止损判据

预算在提案里只给结构不给明细（科目与估算方法见 [./预算与制片管理.md](./预算与制片管理.md) §1–§3）。里程碑表给「阶段 + 通过判据 + 未过怎么办」三列，止损判据写明触发条件与终止动作——**止损是承诺，不是情绪**。金额、额度、期限属私人参数，提案里以「以我自己的试错资金包上限为准」表述，机制本身可公开（[../../研究/行动总纲.md](../../研究/行动总纲.md) §8.4）。

## 14. 提案被拒的三种真实原因及修法

| 真实原因 | 表现信号 | 修法 |
| --- | --- | --- |
| 不清楚要拍什么 | 对方问「那具体拍哪些场景」你答不上 | 补 §7 方法表，把访问频次、场景清单、可拍性写死 |
| 不确定能不能拍成 | 对方问「你能进到哪里、谁同意」 | 补书面准入与已拍样片时长；缺样片就先拍十分钟再说 |
| 不放心你这个人 | 对方关心你会不会出事、会不会半途停 | 补 §9 四句与 §13 止损判据；把「我知道自己不知道什么」写出来 |

至于「对方没预算」「题材不合」这类答案，属于渠道不匹配，改渠道不改稿（渠道结构见 [./资金渠道地图.md](./资金渠道地图.md)）。**同稿连投五家以上都没反馈**，回到 §3 与 §6，一句话与作者位置是唯一的复利来源。

## 常见误区

| 误区 | 事实 |
| --- | --- |
| 写情怀不写方法 | 情怀是 §5 的一句话，方法才是 §7 一整节；只有情怀的提案在别人眼里等于没有计划 |
| 把提案写成宣传稿 | 宣传稿隐藏困难，提案暴露困难并给出应对；读者是决策者不是观众 |
| 承诺一个还不存在的故事 | 结局未到时承诺结局，等于在拍摄中期被迫去制造结局（最贵的造假诱因） |
| 用形容词代替参考片 | 「有电影感的、克制的、有力量的」不可核查，三片参考可核查 |
| 怕暴露未知而写得肯定 | 越肯定越像没做过田野；承认未知 + 阶段闸门才是专业信号 |
| 提案写完就交 | 提案至少改三轮：写完放一周自查模糊处、给一个懂内容的人读、给一个懂钱的人读 |
| 一稿多投不做裁剪 | 平台、基金、企业、节展四种读者关心四件事；共用的是一到三节，其余按读者重排 |

## 实操要点

- [ ] logline 过空词表：出现「探索 / 展现 / 真实 / 关注 / 揭示」任一，重写。
- [ ] 十三节骨架一次填满，写不出来的那节就是你的未知所在，先补未知不动身。
- [ ] 「为什么是现在」必须落在等待、消失、意愿三者之一，不落在热度。
- [ ] 作者位置写三件可核查的事实，并写一条自己的局限。
- [ ] 方法节引 [../07-拍摄执行/长期跟拍.md](../07-拍摄执行/长期跟拍.md) 的时长与周期区间，别自创数字。
- [ ] 结构节写「结局还不知道」四句式，附已拍素材分钟数与试剪计划。
- [ ] 风险四条线各一句 + 各一条链接；资金一律写「以我自己的试错资金包上限为准」。
- [ ] 提案打印在纸上读一遍再发；屏幕通读容易漏掉自己脑补的连贯处（用眼成本控制）。
