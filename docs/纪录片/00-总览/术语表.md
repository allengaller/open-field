# 术语表（Glossary）

> 中英对照，学界通用译法优先（PRINCIPLES §4）；每条一句定义，「详解」指向本库展开位置。译名分歧时在括注里给出另译，不裁决。

读法提示：本表按域分组，不按字母序——查词时你想的是「这个声音的事」，不是「S 开头」。同一词在不同传统里含义不同时，条目里写明「与 X 相对」。

## 常见误区

| 误区 | 为什么错 | 怎么办 |
| --- | --- | --- |
| 把 Direct Cinema 与 Cinéma Vérité 当一个东西 | 一个主张不干预，一个主张激起，工序和伦理都不同 | 查 §2 两条，再读 [直接电影与真实电影](../02-历史/直接电影与真实电影.md) |
| 把「观测电影」当「观察型模式」的同义词 | 前者是人类学方法传统，后者是表征分类 | 分别见 §2 两条 |
| 「空镜就是 B-roll」 | B-roll 预设填充功能，空镜在本库是论证单位 | 查 §3 两条 |
| 把 feedback 一律译成「反馈」 | 声学的啸叫、研究的回看、平台的互动是三件事 | 本表分别列条，用词按语境定 |
| 用「真实」定义纪录片 | 真实是材料属性，纪录片是契约关系 | [真实契约](../01-理论/真实契约.md) |
| 把 member check 与 video feedback 混用 | 前者核对解释，后者用影像唤起材料 | §5 两条 |
| 认为 E&O 是「有钱就能买」 | 保险公司要的是可查凭证链 | [版权链与E&O](../10-伦理法律/版权链与E&O.md) |
| 只看中文列不看英文列 | 检索外文资料时需要英文词形 | 遇到译名分歧以英文为准回查 |

## 实操要点

- [ ] 把本表当校对表：写完一篇后，检查同一概念是否换过词。
- [ ] 新增术语时，先查是否已有条目，再决定归入哪一组。
- [ ] 译名不统一时，第一次出现写成「中文（English，另译 X）」，之后只用主译。
- [ ] 若你的项目里一个词的用法与本表不同（例如分轨命名），在项目文档写一行定义并说明差异。
- [ ] 每季度做一次「术语覆盖检查」：本季度各章新出现的重要概念有没有进本表。
- [ ] 检索英文资料前，先在 §2 与 §6 里找到对应的标准英文词，再搜。
- [ ] 本表不含数值；需要数值时去 [04-声音](../04-声音/声音设计.md) 与 [08-剪辑后期](../08-剪辑后期/交付母版与规格.md)。
