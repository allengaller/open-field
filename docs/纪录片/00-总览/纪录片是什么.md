# 纪录片是什么

> 不是定义一个词，而是确定一套约束：你手上这些东西凭什么算纪录片，它和新闻、自媒体、田野笔记的区别在哪，哪些区别是要命的。

本篇是本语料库的入口。它不给你答案，给你一个判断框架：以后遇到「这还算不算纪录片」「我该站哪一边」这类问题，回到本篇的三条判据上，而不是回到别人的说法上。

## 1. 为什么定义问题不能跳过

因为定义决定工序。你把纪录片当成「记录真实」，你的核心工序就是核查与留痕；你把纪录片当成「讲故事」，核心工序就是结构与节奏；你把纪录片当成「内容」，核心工序就是分发与数据。三种定义都不算错，但混在一起用会出事——你在剪辑时按故事走，发布后被人按事实追问，这时候你手上没有支撑事实断言的材料。

本语料库的立场是：**纪录片是一种关于证据的叙事**。叙事与证据两边都要，缺哪边都会在具体环节上付出代价。

## 2. 三条判据

| 判据 | 内容 | 缺了会怎样 |
| --- | --- | --- |
| **索引性**（indexicality） | 画面与声音来自一次真实的拍摄事件——摄影机在那个时刻确实在那个地方。这是纪录片无法被凭空伪造的核心资产【通行共识】 | 素材可以与任何生成内容互换，影片失去「有人在场」这一层说服力 |
| **主张**（assertion） | 影片对世界说出可被反驳的话：这些人这样生活，这个流程是这样运转的，这件事有这些原因 | 只剩氛围与私人感受，无法承担公共讨论的素材 |
| **组织**（construction） | 以上二者通过选择、排序、并置、声音处理被组织成一个论证结构，而这个结构对观众是可知的 | 假装「原样呈现」，把剪辑意图藏起来，被识破后连带损失前两条 |

三条同时成立时，你做的才是纪录片，而不是影像素材、宣传片或剧情片。

第三条最容易被跳过，因此单说一句：**所有纪录片都是建构的**。承认这一点不是给自己找麻烦，恰恰是唯一能长期保住前两条的办法。观众迟早会看出安排；你说过一次的「这是重演」不会毁掉片子，被发现的隐瞒会。

## 3. 它不是什么：边界表

| 邻近类型 | 与纪录片的实质差异 | 本语料库的处理 |
| --- | --- | --- |
| 新闻报道 | 时效优先、机构署名、单条事实为单元、周期以天计 | 只在事实核查与更正工序上共用方法（见 [事实核查与更正](../10-伦理法律/事实核查与更正.md)） |
| 专题片／宣传片 | 委托方预先持有结论，拍摄为结论配图 | 作为历史与产业事实描述（见 [电视专题片传统](../02-历史/电视专题片传统.md)），伦理层单列 |
| 自媒体 vlog | 作者自我呈现为主，真实性由人设维持而非证据维持 | 不排斥：周更纪实 vlog 可以同时满足三条判据（见 [自媒体分发](../12-发行传播/自媒体分发.md)） |
| 剧情片 | 事件的产生方式是被编写的 | 仅共享电影语言与后期工序（03、08 两章） |
| 学术影像／研究素材 | 不以观众为必要条件，交付对象是同行 | 归入田野交叉层（14 章），与本库双向链接 |
| 家庭录像、监控、随手拍 | 无传播意图 | 可成为素材，成为作品需要另三条判据补齐 |

**自媒体这一行需要展开，因为它是本库读者的主战场。**「我在拍 vlog」不是免除证据责任的理由，反过来「我拍的是短视频」也不构成质量降级的许可。周更、十五分钟、竖屏，与索引性、可反驳主张、诚实建构没有任何一条互相排斥。真正的冲突只有一处：**时间预算**。证据工序是要花时间的，而档期不等人。本语料库对这条冲突的答复集中在 [单集制作SOP](../15-工具与模板/单集制作SOP.md)：规定降级顺序，而不是取消工序。

## 4. 纪录片与田野工作的关系

这两件事在本库读者的实践中是同一条路的两个输出端，因此必须讲清楚它们哪里同、哪里不同。

| 维度 | 田野工作 | 纪录片 |
| --- | --- | --- |
| 现场角色 | 参与者，卷入程度高 | 观察者，卷入程度可高可低但需被承认 |
| 理解发生的时刻 | 主要在离场之后（笔记、编码、比较） | 主要在拍摄现场（决定摇向哪里）＋剪辑台 |
| 原始材料 | 笔记、录音、图像 | 素材、声音、时间线 |
| 交付物 | 分析，读者是能核实你的人 | 作品，观众多数无法核实你 |
| 失败的代价 | 结论错 | 结论错 **且** 被误伤者具体 |
| 关系责任 | 对同行 | 对被摄者与观众，双向 |

**关键差异在交付环节。** 田野写作面向可以被追问的同行；纪录片面向无法追问你的陌生人，他们看完就形成了对那群人的印象，而这个印象不会因为你后来发现了误解而自动修正。所以纪录片的伦理重量并不低于田野工作，尽管它看起来「只是拍了个片子」。这条差异是本库把伦理与法律单列一章（10 章）而非散在正文里的原因。

**关键共同点在证据纪律上。** 田野要求你能说清某个判断来自哪一次观察、哪一份笔记；纪录片同样要求你能说清某句解说、某个结论、某张图，来自哪一段素材、哪一次访谈、哪一个时间码。这两套要求在 OpenField 里被同一个机制承载：素材与笔记进入 append-only 的证据链（[PRINCIPLES §2.1](../../../PRINCIPLES.md)），每个引用编号可以指回原始文件。本语料库在 08、10、15 三章把这套机制落到影像工序上。

因此本库与既有两个田野语料库的关系不是重叠，而是分工：

| 库 | 负责什么 | 位置 |
| --- | --- | --- |
| 田野方法 | IT 从业者视角的田野调查全流程，12 章 | [../../田野方法/README.md](../../田野方法/README.md) |
| 社会学田野 | 学术社会学传统、理论、方法与写作 | [../../社会学田野/README.md](../../社会学田野/README.md) |
| 纪录片（本库） | 影像的制作、伦理、发行全流程 | 本目录 |
| 交叉层 | 相机如何改变田野、影像如何进入分析、被摄者回看 | [14-田野与影像](../14-田野与影像/影像人类学导论.md) |

交叉层是唯一为本库重写的内容。凡是「如何进入田野」「如何做访谈」这类已由两个田野库充分展开的问题，本库只给影像侧的特有增量并链接过去；重复写一遍会制造两套会各自漂移的同一个方法。**这是本库最硬的一条编辑约束。**

## 5. 四种问法：纪录片史上真正有用的一个分类

用 [本库的章节](../01-理论/表征模式.md) 的语言说，纪录片之间的分歧几乎都不是技术分歧，而是下面这四问的分歧。这四问答得越早，后期返工越少。

| 问题 | 可选答案（举例） | 影响哪道工序 |
| --- | --- | --- |
| 摄影机与被摄者的关系是什么 | 保持距离的观察者／激起反应的挑衅者／共同工作者／缺席只留声音 | 现场行为、机位、是否收声给被摄者 |
| 凭什么让人相信 | 我在场的画面／访谈的证词／档案文件／可复核的数据／作者的个人经验 | 日志字段、核查表、附包构成 |
| 结论由谁给出 | 作者解说给出／人物自己说／并置让观众得出／不下结论 | 解说词写不写、结构怎么排 |
| 对当事人的义务到哪一层 | 只到不伤害／到呈现准确／到放映给对方看并允许他反驳／到成片之外继续承担 | 同意档位、回看工序、后续联系 |

本库把这四问统称为**真实契约**（indexical contract / pact of representation），展开在 [真实契约](../01-理论/真实契约.md)。

四问不要求你一次答对，要求你**在开机前有一份写下来的答案**。写下来与没写下来的差别不在道德，在工序：写下来的答案会直接生成字段——可信来源生成日志表里的证据列，当事人义务生成同意档位，结论由谁给出生成解说词写不写。没写下来的答案在剪辑台上会被临时答案替换，而临时答案通常是最省事的而不是最负责的那个。

## 6. 「完成」的判据

三条判据回答「这是不是纪录片」，不回答「这片子能不能交出去」。下面五件事同时成立，本库才认为一部片子完成；它们分别由五章负责，任何一项空缺都能在发布后单独爆掉。

| 判据 | 成立的条件 | 承载章节 |
| --- | --- | --- |
| 可回指 | 每个事实性断言能指回具体素材与时间码，或已被标为推断 | [事实核查与更正](../10-伦理法律/事实核查与更正.md) |
| 可授权 | 出现的人和物都有对应档位的同意记录，撤回通道可用 | [知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md) |
| 可交付 | 母版、分发版、附包三者齐备，规格逐项核对过 | [交付母版与规格](../08-剪辑后期/交付母版与规格.md) |
| 可理解 | 观众在不看任何外部说明的情况下知道影片凭什么可信 | [真实契约](../01-理论/真实契约.md) |
| 可持续 | 这一部做完之后，你还能回到那个现场，那个人还愿意跟你说话 | [长期跟拍](../07-拍摄执行/长期跟拍.md) |

最后一条最容易被当成 soft 指标，其实是唯一直接决定你能不能做第二个项目的条件。**「可回指」和「可持续」是长期创作者与一次性投稿者的分水岭**——前者决定你的材料能不能被追问，后者决定你还有没有材料。

## 7. 这个词的历史包袱

顺带说明，避免你在阅读中文材料时被同一个词的不同用法绊倒：

- 早期中文语境里「纪录片」「纪实片」「专题片」「教育电影」长期混用，功能定位差异很大——「纪录片」逐渐指作者主导的作品，「专题片」指机构主导、结论先行的作品。这个区分在中国产业语境里比在西方语境里更要紧。
- 「non-fiction」（非虚构）比「documentary」（纪录片）外延更宽，包含解说读物、广播特稿、舞台化搬演，本库在涉及方法归属时优先用「非虚构影像」。
- 「fieldwork」（田野）与「documentary」在英文学界各有一套制度与语汇，交集有专名，见 14 章。

对实际工作者，这段历史只留一个可用结论：**「纪录片」不是一种风格，是一种承诺**。你向被摄者承诺什么、向观众承诺什么，就决定了你要做哪些工序。

## 常见误区

| 误区 | 为什么错 | 怎么办 |
| --- | --- | --- |
| 「纪录片的定义早就过时了，无所谓」 | 定义之争会落到具体工序上：要不要标注重演、要不要留授权凭证 | 以 §2 三判据自查 |
| 「真实的东西不需要解释来源」 | 观众无法区分「真实但被安排」与「真实」，你不说他就自己猜 | 主动标注（[真实契约](../01-理论/真实契约.md)） |
| 「我拍的是短视频，不用按纪录片的规矩」 | 判据与时长无关，风险与时长成反比——碎片传播更难更正 | 走 15 章 SOP 的降级顺序 |
| 「素材就是记录，记录就是纪录片」 | 缺主张与组织 | §2 逐条核对 |
| 「有伦理章节就够了」 | 伦理若不成文字、不成可交付物，就只是表态 | 用 10 章与 15 章文书模板 |
| 「田野和拍摄是一回事」 | 交付对象与失败代价不同 | 见 §4 |
| 「把被摄者当朋友就不需要授权文件」 | 关系越久，越需要可回溯的约定 | 承诺表（[授权文书模板](../15-工具与模板/授权文书模板.md)） |

## 实操要点

- [ ] 开机前用一句话说清本片的**可信来源**：观众凭什么相信这片子说的是真的。写进项目提案。
- [ ] 为每个成片版本填一份 [交付规格表](../15-工具与模板/交付规格表.md)，含标注清单与授权状态列。
- [ ] 对「重演／摆拍／合成／AI 参与」建立标注清单，交付前逐项核对。
- [ ] 用 §2 三条判据给手上每个进行中项目打一次分，哪条最弱就补哪条的工序，不要补最强的那条。
- [ ] 用 §5 四问写一份不超过一页的契约声明，同一个项目的所有版本共用一份；改了就换版本号。
- [ ] 每次对外发布时，把承诺范围写进 [授权文书模板](../15-工具与模板/授权文书模板.md) 的同意档位并在台账留痕。
- [ ] 每季末重读 §4，检查影像输出与分析输出是否互相指得回。
- [ ] 遇到「这算不算纪录片」的判断困境时，回到 §2 三条判据。三条全中就是，缺哪条就补哪条工序，补不上就承认它属于 §3 边界表里的邻近类型——后者不是失败，是分类错误带来的工序错配。
