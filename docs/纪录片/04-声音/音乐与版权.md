# 音乐与版权

> 音乐是全片唯一可以合法「说谎」的一层：它不记录任何东西，却在观众心里制造「这件事很重要」的错觉。所以它必须先过版权关，再过审美关。

## 1. 音乐在纪录片里的合法功能

先给判据，再谈授权。一段音乐成立，必须满足下面之一；只满足「这里感觉有点平」的，一律撤掉。

- 交代真实存在的声音来源：现场有人在放、在唱、在演（且这属于同期声层，见第 8 节的许可问题）。
- 标记结构边界：段落转换、时间跳跃、系列片头尾，用固定的音乐动作做「这是新的一段」的提示。
- 提供画面给不了的信息：音乐作为调查对象本身——厂区广播里放的歌、殡仪馆的哀乐、直播间背景曲，它们是有内容含量的音响。
- 处理无法用画面和语言承担的时间流逝：一整年的等待、康复的三个月。

反面清单——音乐在这些地方是在替你没拍到的东西说话【操作性建议】：

- 人物说完一句很重的话，立刻进弦乐「抬」情绪：这是你在替他感动，观众会察觉。
- 空镜配氛围 pad 撑满时长：这是你在用音乐填镜头缺口，正确做法是砍掉这个空镜。
- 用鼓点给田野工作「提速」，让剪辑显得有推进：节奏感来自剪辑本身（见 [冲突悬念与信息节奏](../05-叙事结构/冲突悬念与信息节奏.md)）。
- 一场争吵结尾进钢琴做「和解感」：这是对事实的解释，属于主张，需要解说或人物自述来表达，不该由音乐偷偷做。

判据一句话：**静音掉这段音乐，段落是否仍然成立。**

## 2. 音乐类型的语义

观众不是读乐谱，是读类型联想。选音乐等于选了一套默认结论。

| 类型 | 观众读到的 | 在纪实里的副作用 |
|---|---|---|
| 管弦/弦乐群 | 庄严化、历史化、「这件事有分量」 | 把普通人的日常抬成悲剧，容易变成俯视 |
| 钢琴独奏（慢） | 孤独、内省、抒情 | 万能套路，一用即「专题片腔」（见 [电视专题片传统](../02-历史/电视专题片传统.md)） |
| 电子/合成器 | 技术化、未来感、冷 | 给工厂与算法题材合适；给村庄题材会立刻虚假 |
| 地方戏曲、民歌、唢呐、鼓乐 | 在地性、归属感 | 最容易被用成「地方风味调料」；若非现场真实存在，慎用，且注意它自带价值判断 |
| 独立摇滚/lo-fi | 青春、行动、快节奏 | 短视频最泛滥，语义已被磨损到接近「无意义」 |
| 无版权曲库的通用配乐 | 什么都能配，等于什么都没说 | 代价是「通用感」：观众能闻出流水线味道，且与你的画面气质不对位 |
| 流行歌曲 | 时代坐标 + 强私人联想 | 会劫持段落：观众开始想自己的初恋，不再想被摄者的处境；且授权最贵最难 |

## 3. 版权三条路

先建立最小认知框架：一首歌用在片子里，通常涉及**两层权利**，必须分清。

- 音乐作品著作权：词作者、曲作者（或其所属出版方/协会）。
- 录音制作者权（邻接权）与表演者权益： whoever 制作了那段录音、以及演唱演奏者享有的权利。

**用别人录的那版歌，你要同时拿到两层许可；你自己重新录一版（翻唱），只需要第一层。** 这是中国创作者最常踩的坑——以为「我在曲库里下载了这首歌」或「我买了这首歌的伴奏」就解决了问题，实际上伴奏版本与原版录音的权利链条完全不同。权利清单与署名规范见 [版权链与E&O](../10-伦理法律/版权链与E&O.md)。

### 3.1 原创委托

流程【操作性建议】：先写清音乐需求文档（不是「要感人的」，而是「第 12 分钟到 14 分钟，画面是流水线夜班，希望有 60 bpm 的机械感，30 秒后退出」）→ 请作曲人交 30–60 秒 demo → 依据 demo 反馈定稿 → 交分轨（stems，至少把打击、和声、独奏分开）→ 签合同。

合同必写项：

- [ ] 使用范围：媒介（院线/电视/网络/短视频/放映活动）、地域、期限（一年、五年、永久）、是否独家。
- [ ] 权利归属与是否买断；署名方式与署名位置。
- [ ] 后续用途：投电影节、参加展映、被平台剪辑号二剪、商单同款，是否另行付费。
- [ ] 录音制作者权归属（谁拥有那份录音）。
- [ ] 修改权：你能否剪短、变速、加效果；能否再委托他人改编。
- [ ] 违约与撤回条款：对方日后把同一首曲子卖给你的竞品怎么处理。

成本参考：波动极大，从数千元（新人、限网络非商业使用）到数万元（含乐手录音、全媒介买断）都有。把它当作谈出来的数字，不要当作行情；预算写法见 [预算与制片管理](../11-生产与资金/预算与制片管理.md)。

### 3.2 授权曲库（royalty-free / production music）

「royalty-free」是不用按播放量续付版税，**不是免费**。要逐条读许可的四个维度：

| 维度 | 典型陷阱 |
|---|---|
| 平台覆盖 | 许可只写「社交媒体个人频道」，你却用于院线/电视/客户交付；或只覆盖某个平台 |
| 地域 | 有的库只授权中国大陆，出海或投国际电影节需另购 |
| 期限 | 订阅制下「下载期间有效」：退订后已发布视频多数可保留，但要看到明文；未发布的工程文件可能被要求删除 |
| 用途 | 商单/品牌内容/政治与宗教内容/他人作品再发行常被单独排除；二创与混剪归责不同 |

另一件高频事故：曲库方或权利人把你的视频做了内容识别认领（Content ID 类机制），于是**你自己的片子被判定侵权、被静音或被分走收益**。对策【操作性建议】：下载时保存许可凭证（含曲名、作者、许可证编号、下载日期），并在平台后台提交白名单/申诉，同时把凭证发给曲库方请求解除认领。

### 3.3 直接授权

用于你确实需要那首已有的歌（流行歌曲、老唱片）。链条最长：找到词曲权利人（出版方/代理/协会）→ 找到录音权利人（唱片公司）→ 分别要同步使用许可与母带使用许可 → 报价通常按「用途×媒介×地域×期限」计算，短影音用途也可能被报高价或被直接拒绝。

现实判断：单人创作者做网络纪实，走到这一步的成功率低、周期长（数周到数月）、成本高。**如果一段内容非某首歌不可，多半说明它应该是被摄者自己哼出来、或者现场音响里正在放——那样它就成了同期声，问题性质改变（见第 8 节）。**

## 4. 免费音乐人协议与 CC 许可的可执行性

- 独立音乐人邮件授权的「随便用」：把邮件、许可证全文、歌曲音频哈希与日期一起归档。口头/私信聊天不构成可举证链条。
- CC 许可（署名 BY、非商业 NC、禁止演绎 ND、相同方式共享 SA）：其性质更接近附条件的授权，实践中可主张，但成立与否取决于你能证明来源页面当时载明的条款与版本，且上传该曲的人是否真的有权发放。注意三点【操作性建议】：
  - ND（禁止演绎）：把音乐配进视听作品、剪短、变速、加效果，可能被认定为演绎。含 ND 的曲子不要用于成片。
  - NC（非商业）：一旦视频有商单、平台分成、打赏、众筹回礼、付费放映，商用属性即成立。
  - SA（相同方式共享）：可能对整个交付物提出开放许可要求，务必先确认自己能否接受。
  - 署名要按条款要求的格式与位置写；CC 材料建议整页存档（截图 + HTML + 抓取时间）。

## 5. 集体管理组织（中国）

中国音乐著作权协会（音著协，MCSC）与从事音像节目著作权及邻接权集体管理的组织（如中国音像著作权集体管理协会，音集协）按章程对会员作品在特定使用方式上发放许可并收转报酬【通行共识】。要点：

- 集体管理的许可范围是**分项目、分使用方式**公示的，不必然覆盖「网络视听配乐」「短视频商用」「线下放映」每一种场景；能否一纸解决，以该组织现行章程与公示的许可业务范围为准，签约前直接索取书面确认。
- 找协会不等于找齐所有权利：非会员作品、录音制作者权、表演者权益常仍需逐一联系。
- 报酬付给了协会，不等于拿到了摄制与网络传播的完整授权链。

## 6. 翻唱、法定许可与获酬权

- 自己组织录唱一版：仍需要词曲著作权人的许可（录制、复制、网络传播，若改词改曲另涉改编）。原唱与唱片公司那一层不需要，因为你没使用原版录音。
- 不要依赖「已发表作品可法定许可录制」的说法：该制度的适用对象与条件有严格限制，且视听作品配乐是否落入其中存在争议；作者声明不许使用的更不得使用。
- 现行《著作权法》为录音制作者增设了广播与机械表演等场景的获酬权（条文表述请以官方公布的现行文本核对）。它解决的是「播放录音要付酬」，不解决「我要把某首歌剪进我的片子」。
- 广告、品牌合作、公益项目的配乐许可通常单独计价，不要因为「我是纪录片」而假设会被免费放行。

## 7. 「我用了 15 秒应该没事」：必须纠正

这是流传最广的错误。事实是：

- 中国现行《著作权法》对合理使用采取**列举式**规定（例如为个人学习研究欣赏而使用、为介绍或评论某一作品或说明某一问题而适当引用、为报道新闻不可避免地再现、免费表演已发表作品等情形），并附带「不得影响该作品的正常使用，也不得不合理地损害著作权人的合法权益」的限制。**法律里不存在「15 秒」「8 小节」「不超过全曲 30%」「注明出处即免责」这类标准。**【通行共识】
- 「三段/几秒不侵权」是网络误传的产物，与任何成文法条款都对不上。判断「适当引用」要看引用目的、被引部分占双方作品的必要性与比例、是否替代了对原作的欣赏，而不是看秒数。
- 完整条文的列举项与表述请在用于任何公开交付前逐字核对官方文本，并优先做一次法律咨询；本篇不构成法律意见。

## 8. 现场意外收录与平台机制

现场音响、婚宴乐队、街边喇叭、被摄者唱歌被同期声一起录进来了——这属于纪实创作的常态，但法律上并不自动免责。处理方式【操作性建议】：

- 保留并记录：写进素材日志（曲目可辨识的就写可辨识到的部分），标注为现场偶然收录。
- 不要为「能听清是什么歌」而专门去放大或重录那段音乐，那会把偶然使用变成主动使用。
- 交付前评估：平台内容识别可能静音或限制部分地区播放；电影节版本可准备一个替换音轨（把该段音乐做遮蔽处理）与一份说明。
- 平台机制认知【通行共识】：主流视频平台的识别系统一般允许权利人选择屏蔽、限制地区、静音或主张收益；被识别不等于被认定侵权，但处理成本由你承担。国内平台也常见「该音频因版权限制不可用」的提示。

被投诉后的动作顺序：

1. 停止争论前先取证：截图投诉内容、时间、被指片段、平台编号；导出该片段的时间码清单。
2. 核对自己手里的凭证（许可、发票、合同、CC 页面存档、下载记录）。
3. 凭证齐→按平台流程反通知/申诉，一次说清事实并附证据；凭证不齐→不要硬申诉，评估替换音轨或下架重发。
4. 全程留痕归档，纳入项目的版权链文件（[版权链与E&O](../10-伦理法律/版权链与E&O.md)）。
5. 若涉商单或被主张赔偿，尽早咨询执业律师，不要在私信里作书面自认。

## 9. 最小音乐方案（推荐给大量纪实内容的创作者）

现实是：以工厂、村庄、菜市场、陌拜、长访谈为内容的片子，全片不用音乐通常更好。替代手段：

- 环境声设计代替情绪提示：车间停机的三秒、雨打在棚顶、走廊尽头的水声，比任何弦乐都准确（[声音设计](./声音设计.md) §2）。
- 节奏来自剪辑：镜头时长曲线与声画节拍本身就是音乐性（[剪辑方法论](../08-剪辑后期/剪辑方法论.md)）。
- 留白与静默做重音（[解说与静默](./解说与静默.md)）。
- 真实音乐优先于配乐：现场那台收音机、那支唢呐、那个人唱的两句，是素材，不是装饰。
- 如果一定要有一首，就只在片尾或系列片主题位用一个短动机（不超过 60 秒），并把这一处当成长期资产去谈清授权。

## 10. 常见误区

- 把「买了曲库会员」当成「全媒介永久可用」。
- 以为「我不是商业目的」就自动免责。平台分成、引流、涨粉后接单，都可能被认定为商业性使用。
- 用伴奏带/K 歌版本以为绕开了原唱——伴奏本身是一份录音，有自己的录音制作者权。
- 把「注明作者与出处」当作获得了许可。署名是义务，不是对价。
- 靠「我先发出去，被投诉再删」赌运气：账号权重、商单资格与片子的展映资格可能一并受损。
- 音乐盖过对白：混音纪律见 [混音与终混](../08-剪辑后期/混音与终混.md)。
- 用地方戏曲给村庄段落「加味道」，把在地的声音变成审美消费。

## 实操要点

1. 每一处音乐先问「静音后是否成立」，不成立就撤；把答案写进剪辑说明文档。
2. 建立音乐登记表：曲名/用途/时长/来源/权利层（词曲、录音、表演）/凭证路径/许可范围（媒介·地域·期限·可否商用）。
3. 优先走原创委托或独立音乐人书面协议，合同必写权利归属、使用范围、后续用途与分轨交付。
4. 用曲库前逐条核对平台覆盖、地域、期限、商单排除四项，并保存下载凭证用于解除误认领。
5. 含 ND 或 NC 的 CC 音乐不进成片；来源页面整页存档（截图 + 版本 + 日期）。
6. 彻底放弃「15 秒/几小节/注明出处即免责」的想法；需要合理使用时逐字核对现行法条并咨询律师。
7. 现场意外收录要记录、不放大、不主动重录，并准备一个可替换音轨的交付版本。
8. 系列片确定「至多一处音乐」的自制规则，把精力从找配乐转移到环境声设计与剪辑节奏上。
