# 解说与静默

> 解说是一种主张，静默是一种尊重。观众对这两件事的敏感程度，远高于创作者的想象。

## 1. 解说：纪录片里的第三种声音

一部纪实片的声音世界通常由两类构成：人物说的话（同期对白与采访）与环境本身的声音（ambience）。解说（voice-over / commentary）是第三类——它不属于现场，它来自一个不在画面里的、知道更多的位置。

这个「位置」就是它的代价所在。Nichols 把以解说为主导、画面作为图解的做法称为解释型模式（expository mode）【通行共识】，它的特征是权威声音在前、观众被引导；与之相对的是观察型（observational）让现场自行呈现。中国电视专题片传统留下了极强的解说习惯（见 [电视专题片传统](../02-历史/电视专题片传统.md)），也留下了观众对「配音+空镜」的条件反射式不信任——这是今天做纪实内容时必须考虑的历史包袱。

判断解说是否越界，只有一个问题：**这句话是谁在说，他凭什么在这里说。**

## 2. 解说的四种职能与各自的可信度成本

| 职能 | 做什么 | 可信度成本 | 控制办法 |
|---|---|---|---|
| 信息交代 | 时间、地点、人物身份、事件前因、数字 | 最低，几乎是必要的 | 能进字幕卡的优先给字幕卡；每次交代控制在 8 秒内 |
| 结构转场 | 「三个月后」「另一边的车间」 | 低，但用多了像小说旁白 | 优先用画面与环境声本身的变化承担转场 |
| 论证串联 | 把证据 A 与证据 B 连成一个判断 | 中到高：这是你在下结论 | 每一句判断都要能指回素材里的证据；能让人物自己说就让人物说 |
| 抒情 | 替观众感动、给苦难点缀 | 最高，且直接损害可信度 | 默认删掉；确需表达，用你自己出镜的口播承担（第 4 节） |

规律：**越靠近信息，解说越便宜；越靠近判断与情感，解说越贵。**

## 3. 什么时候解说会毁掉一段现场

现场自己说得清的，绝对不要解说。判据做成五条即时检查（对每一句已写的解说问一遍）：

- [ ] 这段画面或同期里是否已经出现了同样的信息？出现即删。
- [ ] 这句是否在解释已经看得见的事（「他正在焊最后一根钢筋」）？是即删。
- [ ] 这句是否在下判断（「这就是底层劳动者的坚韧」）？是则改成人物自述，或删掉让人物自己活。
- [ ] 这句是否提前交出答案，拆掉了尚未兑现的悬念？是则后移到答案该出现的位置。
- [ ] 这句是否盖住了现场某个重要但微弱的声音（一句话、一声机器报警）？是则让位，把解说挪到声音的间隙。

反面判据：现场说不清的地方确实需要解说——时间跨度无法用画面承担、政策与合同条款、数字与规模、被摄者无法自行表达的前后因果。这时解说不可替代。诚实的写法是承认缺口：「这段没有拍到，据他事后讲述……」（与 [事实核查与更正](../10-伦理法律/事实核查与更正.md) 一致）。

同一条信息交给哪一层，有一个稳定的分工判断：

| 信息种类 | 交给 | 理由 |
|---|---|---|
| 人名、地名、时间、职务、数字 | 字幕卡 | 需要精确、可暂停回看，念出来反而记不住 |
| 方言内容与不可懂语音 | 字幕（译文） | 见 [字幕与无障碍](../08-剪辑后期/字幕与无障碍.md) |
| 因果与前后串联 | 解说或口播 | 画面无法承担 |
| 情绪、判断、处境的分量 | 人物自述 + 现场声 | 由当事人说才有证据价值 |
| 你与现场的关系、你的困惑 | 出镜口播 | 这是唯一只能由你说的东西 |

## 4. 口播与解说：为什么自媒体纪实更适合口播

口播（presenter on camera）是解说的一种「有身体」的版本：你出镜、面对面、声音与画面同源。

| 维度 | 画外解说 | 出镜口播 |
|---|---|---|
| 位置 | 隐身的全知声音 | 一个具体的、有限的人 |
| 信任来源 | 语气权威、信息准确 | 看见人：你的表情、你的疲惫、你身后的现场 |
| 出错成本 | 观众怀疑片子 | 观众怀疑你这个人（但也更容易原谅你，因为你能当场更正） |
| 风险 | 变成「上帝视角」、专题片腔 | 你的形象盖过被摄者，你成了主角 |
| 制作 | 需要安静房间与录音 | 需要光线、收音、走位，环境噪声现场即暴露 |

在短视频与 B 站的纪实内容里，口播的优势主要是**信任来自看见人**：观众看到你站在厂房外、坐在村口台阶上，这段信息的「我到过现场」这一层就不需要辩解。同时它天然打断全知感——你可以说「我当时不明白」，这句话从画外解说里说出来是修辞，从你嘴里说出来是事实。

风险要认：一旦你成为叙述主体，被摄者容易退成你故事的道具。补偿办法是把口播集中在「我是怎么知道的」，把「事情是什么样」交回给人物（另见 [人物与主角](../05-叙事结构/人物与主角.md)、[观看位置与视点](../03-电影语言/观看位置与视点.md)）。

## 5. 写解说词的时机：先剪后写

**先写解说、再按解说词找画面，是专题片遗留的最典型错误。**它造成三种必然损伤：

1. 画面沦为插图，观众的眼睛只需要确认你已经说过的话；
2. 结构被文字预设锁死，现场提供的更好顺序被浪费；
3. 时长失控：写稿时一句「随着产业转移的推进」，画面上需要 20 秒才站得住。

正确顺序【操作性建议】：粗剪定结构 → 找出真正说不清的缺口清单 → 只为缺口写解说 → 对着画面念（计时）→ 再剪一次，把因解说而多余的镜头删掉 → 最后按 [解说词写作](../05-叙事结构/解说词写作.md) 的句法纪律改文字。

## 6. 自己录解说：底线与技巧

设备与环境底线【操作性建议】：

- 话筒：动圈手持或 USB 电容均可；距嘴 15–25 cm，轴向偏开 15–30°，减少喷音与齿音；配防喷罩。
- 设置：48 kHz / 24-bit；低切 80 Hz；峰值 -12 ～ -6 dBFS；不要开压缩与噪声门做「成品感」，留给混音（[混音与终混](../08-剪辑后期/混音与终混.md)）。
- 环境：关空调、冰箱、风扇；手机静音并放到门外；选挂满衣服的卧室或衣柜前——**手机 + 衣柜可以接受**，原理很简单：小空间 + 大量软吸声材料把早期反射压掉，混响尾巴一短，观众就不追究话筒是什么。用录音质量极差的手机做录音机也比用差话筒接好环境更糟，所以先补空间，再补设备。
- 但别把房间做得太「死」：完全无反射会让口水音与呼吸全部暴露。做法是一侧软（被子/衣柜）、一侧留一点正常墙面。
- 录 60 秒房间音（同 [声音设计](./声音设计.md) §4 的理由），解说段落之间的接缝需要它。
- 每条录两遍：一遍照稿，一遍不看稿用自己的话说。第二遍通常有更好的语气，且往往能挑出稿子里说不出口的句子（那些句子本身就是写坏了的）。

语速与气口【操作性建议】：

| 项目 | 参考值 |
|---|---|
| 纪实解说正文语速 | 180–240 字/分钟 |
| 出镜口播/短视频 | 260–320 字/分钟（快但会削思考感） |
| 一句与下一句之间 | 0.3–0.5 秒停顿 |
| 段落之间 | 1.0–1.5 秒（给画面呼吸） |
| 一次连续可剪长度 | 12–18 秒后必须留一个可下剪的换气点 |
| 30 秒解说对应字数 | 约 90–120 字 |

避免「播音腔」的实操：播音腔不是口音问题，是**姿态问题**——把声音抬到胸腔、把每个字咬满、语调上扬收束。改法：录音前先用打电话的语气把稿子说一遍给旁人听；站着录但想象对面坐着一个你熟的人；在稿子里保留你的口语习惯词（「你看」「说实话」「那时候我还不懂」）；遇到「因此」「由此可见」「伴随着」这类书面连接词一律换成短句；每条只念两三句就停，不要一口气念三分钟——念长了必然会开始「演」。

## 7. 静默的设计

静默有三种层次，效果与风险各不相同。

- 无解说的段落：把整段交给现场。这是最便宜也最被低估的手法；观众会短暂不适（没有人告诉他该想什么），两三秒后开始自己看。
- 无对白的段落：只有环境声与人做事的声音。用来承担情绪的落点。数值参考【操作性建议】：一句很重的话结束后留 2–3 秒再切走，观众「接住」它大约需要这个长度；留 5 秒以上，画面里必须有可见的变化（有人动、有光变、有机器启动），否则观众以为播放器卡住了。
- 抽掉全部声音的段落：视觉静默。慎用——它强烈暗示「这是建构」，在非虚构里等于自认编排；若要用，只用于一两次结构性节点（开场、结尾、时间跳跃），并保证下一段立刻恢复厚重的现场声。

留 3 秒的意义：它把判断的时间交还给观众。一场戏里人物说完「厂里说不干就不干了」，随后 3 秒只有机器声，这三秒不是空，而是观众把这句话放进自己经验里的时间。把它用解说填满，等于宣布你不信任观众，也不信任你拍到的人物。

什么时候观众需要不被说话打扰：暴力与冲突的当场、人物哭泣或长时间停顿、需要观众自己比对画面证据的时刻、以及信息密度已经饱和之后（连续 5 条新信息之后给 10 秒静默）。

## 8. 「没有解说，观众会不会看不懂」——诚实回答

会。一部分观众会看不懂一部分段落，这是非虚构的固有代价，不是需要修复的缺陷。可替代手段各有代价：

| 替代手段 | 擅长 | 代价 |
|---|---|---|
| 字幕卡 | 时间、地点、身份、数字，冷而准 | 有官方口吻；用多了像 PPT；观众会把它当成不可质疑的结论 |
| 人物自述 | 有体温，天然带立场 | 必须拍到，且人物未必能讲清因果；容易变成「借人物之口念解说」 |
| 结构重复 | 同一件事在不同场景再出现，观众自己完成归纳 | 费时长，短视频环境里可能被当成啰嗦；需要观众保持注意 |
| 画面秩序 | 把有因果的两段并置，让观众看出关系 | 最依赖剪辑功力，也可能被读成完全不同的关系（见 [蒙太奇与长镜头](../03-电影语言/蒙太奇与长镜头.md)） |

还有一个应当被保留的选项：**承认看不懂是田野的一部分。**长期跟拍的价值之一，正是观众被迫停留在一个不理解的场景里，这与你作为研究者当时的处境相同（另见 [田野素材到影像](../14-田野与影像/田野素材到影像.md)）。

## 9. 解说使用配额【操作性建议】

按内容类型给参考区间（解说语音时长占成片时长比例）：

| 内容类型 | 解说+口播占比 | 备注 |
|---|---|---|
| 观察式现场（罢工、拆迁、赶海） | 0–5% | 只在必要处交代身份与时间 |
| 深度访谈片 | 3–8% | 引入、转场、背景各一次 |
| 调查与数据类（欠薪链条、平台算法） | 15–30% | 论证确实需要串联，每句判断配证据 |
| 散文电影 | 10–25% | 读自己的田野笔记（见 [散文电影与诗性结构](../05-叙事结构/散文电影与诗性结构.md)） |
| 自媒体跟拍 Vlog | 10–20% | 以口播为主、画外解说为辅 |
| 学术存证版本 | 0–3% | 只用字幕卡，全部判断留给论文 |

执行纪律：粗剪结束时把解说全部静音重看一遍，若 80% 的段落仍然成立，则配额合理；若必须靠解说才看得懂，那是结构问题，加解说只会掩盖它（另见 [纸剪与结构重组](../05-叙事结构/纸剪与结构重组.md)）。

## 10. 常见误区

- 先写稿再配画面（第 5 节）。
- 用解说表达情绪，用音乐抬升判断——两层都在替观众下结论。
- 解说与画面重复：最大的浪费，改法见 [解说词写作](../05-叙事结构/解说词写作.md) §图文关系。
- 全程无解说当作立场，结果观众连人物是谁都记不住：不用解说是一种选择，用不用都要付代价。
- 录音时追求「干净」把房间做得过死，或者在噪声没治理的房间硬录（先按 [同期声与收音](./同期声与收音.md) §6 换房间）。
- 语速一律推快：短视频快语速会挤压观众对画面的注意，重要段落反而应当降速。
- 把「没有解说的观众会不会看不懂」当成唯一决定因素——真正该问的是「这段值不值得让不懂的人看懂」。
- 用播音腔念田野笔记，一开口就把现场推远。

## 实操要点

1. 解说一律在粗剪定结构之后写，只为「画面与同期说不清」的缺口写，先列缺口清单再动笔。
2. 每句解说跑五条判据（重复、图解、下判断、抢答案、盖现场），中一条即改或删。
3. 需要交代事实优先用字幕卡与人物自述；把画外解说留给因果与结构。
4. 自媒体形态优先用出镜口播替代画外解说；口播讲「我怎么知道的」，把「事情是什么」交回人物。
5. 自录解说：小空间 + 软吸声、话筒 15–25 cm 偏轴、低切 80 Hz、峰值 -12～-6 dBFS、录 60 秒房间音、每段照稿与脱稿各录一遍。
6. 语速控制：解说 180–240 字/分钟、口播 260–320 字/分钟；30 秒只写 90–120 字；每 12–18 秒留一个换气点。
7. 重话之后留 2–3 秒静默，超过 5 秒必须在画面里给一个可见变化。
8. 精剪后做一次「静音解说重看」，用第 9 节的配额表核对比例，超标即删。
