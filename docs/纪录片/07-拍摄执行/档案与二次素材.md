# 档案与二次素材

> 用别人的影像，第一个动作不是查内容，是查权利。这一篇是流程手册：怎么问价、怎么留档、怎么把一段 1987 年的胶片翻拍到能用、以及拿不到授权时有什么正当替代。

法律分析（权利归属、保护期、侵权风险、E&O 保险）在 [../10-伦理法律/版权链与E&O.md](../10-伦理法律/版权链与E&O.md)，本篇不重复；本篇只管从「找到素材」到「写进片尾来源表」的操作顺序。

## 1. 五类来源

| 类别 | 典型载体 | 权利状态常态 | 第一联系人 |
| --- | --- | --- | --- |
| 机构与企业档案 | 地方志办、档案馆、电视台资料库、企业宣传科、行业报图片库 | 有明确权利人，多数可授权但流程长 | 档案/资料部门书面申请 |
| 新闻库存素材 | 通稿视频、通讯社图片库、电视台新闻带 | 商用授权通常另计价，期限与地域受限 | 库存销售方 |
| 家庭相册与私人胶片 | 家中照片、8mm/Super 8、家用 DV、老光盘 | 权利人常已不可查，需继承人同意 | 当事人本人 + 其家属 |
| UGC 与平台视频 | 抖音/快手/B 站用户视频、贴吧与群聊转发、监控录像 | 授权最不稳定，平台条款不覆盖你的用途 | 原作者（必须单独谈） |
| 公开数据与地图 | 统计年鉴、公开数据集、卫星图与街景、政府公示图 | 数据本身与可视化作品权利不同；街景有平台条款 | 出处机构 / 平台条款 |

【操作性建议】监控录像与执法记录仪类素材属于「场所持有、非你所有」，需场地方许可与合法调取程序，不要按私人影像处理。

## 2. 第一动作是查权利，不是查内容

【通行共识】素材可用性 = 权利可用 × 技术可用 × 伦理可用，三项是乘法，一项为零整体为零。新手顺序刚好相反：先被画面打动，再倒推权利，于是所有后续工作都建在未落实的许可上。

【操作性建议】固定三步，按序做完才允许进时间线：

1. **可查则查**：出处水印、片尾、图片来源页、档案馆编目号——先确定「权利人是谁」。
2. **查不到就当作需要授权**（这是流程默认，不是法律结论）。孤儿作品（orphan work，权利人不明或无法联系）在多数法域**并不因为找不到权利人就可自由使用**；具体定性与例外情形见 [../10-伦理法律/版权链与E&O.md](../10-伦理法律/版权链与E&O.md)。
3. **书面留痕**：每一次联系、每一次拒绝、每一次口头同意都要落成文字（邮件优先，其次微信文字确认截图）。留痕本身就是将来应对争议的最有效材料。

【通行共识】CC 与公有领域的三个常见误解：(1) CC 各版本条件不同，**CC BY-NC 不含商用**，而你的频道有收益；(2) 「公有领域」按法域与年份分别成立，一国公有不等于他国公有；(3) 底片公有不代表你拿到的那一版扫描/复原件自动公有，也可能涉及邻接权。【操作性建议】判定一律回文件与来源核对，不看转发时的标签。

## 3. 许可流程七步

【操作性建议】询价一次问全，避免二次议价：

- [ ] 1. **用途范围**：院线/电视/网络/自媒体/短视频切片/宣传片/课堂/展览，逐项列明，不要用「全媒体」。
- [ ] 2. **期限**：一次买断或 1/3/5 年；到期后是否需下架，写清。
- [ ] 3. **地域**：大陆、全球、是否含海外平台。
- [ ] 4. **剪辑权**：可否裁切画幅、变速、调色、去水印、与其他素材混剪、是否需回报原方审看。
- [ ] 5. **署名与水印条款**：要求什么形式、字号时长、位置；有强制台标的，确认能否遮盖。
- [ ] 6. **独家与竞品限制**：同类题材是否被独占授权（长期项目最容易被这条卡住）。
- [ ] 7. **留档**：授权书、发票、来源截图、联系记录，全部进项目档案，与承诺表同处存放（模板见 [../15-工具与模板/授权文书模板.md](../15-工具与模板/授权文书模板.md)）。

【操作性建议】预算纪律：单条素材许可费超过本项目总预算的 5%，就要问自己这条是否不可替代。替代成本通常远低于许可费。

## 4. 规格与可用性判定

【操作性建议】先做技术判定再谈许可，避免为用不了的素材付钱。

| 载体 | 能用到什么程度 | 主要代价 |
| --- | --- | --- |
| 35mm/16mm 胶片扫描 | 2K 扫描可支撑院线；4K 更宽松 | 贵、划痕与霉斑需修复 |
| 8mm / Super 8 | 通常按 1080p 或标清采集即可 | 抖动、褪色、收缩；稳定处理后细节更差 |
| Betacam / VHS / DV 带 | 标清（约 720×576 或 720×480），放大会露出磁迹与色度噪点 | 需采集设备与时基校正，采集窗口不可重现 |
| 网图 / 平台视频 | 低码率、被多次转码，多数只能作中近景小尺寸使用 | 放大与稳定的代价见下 |
| 监控与手机视频 | 帧率低、动态模糊重、视角固定 | 通常作为「来源证据」而非「影像质感」使用 |

- **放大的真实代价**：标清放大到 1080p 只是把缺陷放大；升频（upscaling）工具能补细节但会造出**并不存在的细节**，作为证据使用时必须在片上说明做过何种处理（处理边界见 [../08-剪辑后期/调色与画面处理.md](../08-剪辑后期/调色与画面处理.md)）。
- **稳定的代价**：防抖与稳定跟踪会裁掉画面边缘、产生果冻效应；老素材上的字幕条与安全框要一并算进裁切余量。
- **判定动作**：先在目标交付分辨率上 1:1 看一帧，再决定要不要这段。不要在小窗预览上签字。

## 5. 翻拍与扫描的实操

【操作性建议】三种常见情形的操作顺序：

**A. 老照片 / 带玻璃相框的翻拍**

1. 拆玻璃（一定先拆；拆不了就侧移相框，避免正面反光）。
2. 相机**垂直正对**照片，光轴过画面中心；用直角支架或脚架中轴水平仪保证平行。
3. 布光：两灯左右 **45 度对称**，灯位高于画面平面，让反光落在画面之外；深色照片可加大入射角。关掉现场顶灯与自身白衣（会成镜面）。
4. 手动对焦到照片表面（不是玻璃），小光圈（景深足够即可，过大光圈会产生衍射损失锐度），最低原生 ISO，三脚架 + 快门线或延时自拍。
5. 留边缘：拍一张含画面外标注物（写有编号的纸片）的全幅，便于日后对编号。
6. 分辨率参考：翻拍/扫描按目标交付反推——预计最远只作全景使用，取到可满 4K 帧的宽度即可；会被裁成特写的照片，取到画面短边 ≥2000 像素。**先问用途，再定分辨率。**
7. 当场回看：放大到 100% 查四角是否糊、有无色偏、有无扫到的指纹与灰尘。

**B. 录像带采集**

- [ ] 先确认接口与制式，同一盘带只做一次全带采集并保存无压缩或高码率中间格式；此后一律从数字文件工作。
- [ ] 采集前做一盘测试带，检查时基、色彩、音量是否有直流噪声；记录带子编号与采集时间。
- [ ] 借带拍带：物主在场时一次采完，当场归还并留交接记录。带子是单向损耗品，每次过机都有风险。

**C. 手机照片 / 数字原片**

- [ ] 尽量要**原文件**，不要要聊天软件里的转发件（转发已被重编码并剥离元数据）。
- [ ] 索取时同步登记：谁拍的、什么时候、地点、原设备、是否有同批其他照片。
- [ ] 拿到后立刻计算哈希并写入日志（§6）。

## 6. 元数据与拍摄时间：EXIF 不可单独作为证据

【通行共识】EXIF 等内嵌元数据（拍摄时间、机型、GPS）可以帮你在成百上千张照片里快速排序，也可以作为**线索**；但它可被轻易改写或批量伪造，且经社交平台转发后常被剥离。

【操作性建议】用于证据链时的三条要求：

1. **时间来源分层**：文件内嵌时间 → 设备时钟时间 → 当事人陈述时间 → 影像内容可推断的时间（照片里的报纸日期、日历、季节、建成的楼）。写记录时把「依据哪一层」写出来。
2. **原始文件固化**：接收瞬间计算 SHA-256 并写入仅可追加的证据日志（[../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.1 证据链；§2.4 亦禁止任何隐蔽采集，档案使用不得成为绕过同意的通道）。此后任何修复、去噪、转码都生成新版本，原始件永不覆盖。
3. **主张分层**：档案影像证明的是「这张图在某时刻存在且未被改动」，不自动证明画中所说的时间地点为真。要主张时间地点，需要第二来源印证（见 [../../田野方法/08-信效度.md](../../田野方法/08-信效度.md) 的三角验证）。

## 7. 标注规范：让引用可见

【操作性建议】观众有权知道哪一段不是你拍的。四项最低标注：

- **来源角标**：画面左下或右下的常驻小字，「来源：××市档案馆」「影像：××提供，1998」，全片同一位置、同一字号，出片前逐条核对。
- **年代说明**：档案影像第一次出现时给时间；跨时长的段落在变化处再给一次。
- **复演与合成必须标明**：插画、三维重建、声音演绎、AI 生成或补帧的段落，一律显式标注，不与同期素材混成同一镜头。理由见 [../01-理论/真实契约.md](../01-理论/真实契约.md)。
- **黑白与低画质的诚实性**：不要给自拍的彩色素材做「去色 + 加噪 + 4:3」让它看起来像老档案。这既是欺骗观众，也会让你其他**真的**档案失去可信度。若为了区分层次而做风格化处理，必须在片上说明这是处理效果。

## 8. UGC 授权：最难的一段

【操作性建议】流程与替代方案：

1. **找到原作者**（不是搬运号）：以画面水印、账号名、原视频标题、时间戳反查；评论区常有人指认。
2. **一次说清六件事**：你是谁、用在什么片子、发布在哪个平台、是否商用、需要哪些权利、你愿意付什么（费用或署名 + 拷贝）。私信、评论、平台内消息同时留记录。
3. **不要把平台条款当授权**：平台的转发与推荐条款一般只覆盖平台内部传播，**不覆盖你把内容下载后剪进自己的商用作品**。条款全文以平台公布版本为准，不要凭记忆解释。
4. **口头同意的补救**：拿到同意后补一份书面授权（电子签或文字确认截图 + 可核实的身份），并保存原对话。
5. **拿不到授权时的正当替代**（都不使用他人影像）：
   - 转成**插画 / 动画 / 图示**，片上标明「根据 ×× 描述绘制」；
   - **复演（re-enactment）**，由当事人或你自己重演，画面或字幕明确标注「情景再现」；
   - **声音演绎 + 文字**：把该事件的话语用朗读呈现，配你自己的空镜与字幕，标注来源；
   - **静态示意**：地图、时间轴、数据图（§9）；
   - **只谈不演**：把它变成访谈里当事人自己讲的一段，用你拍摄的说话人镜头承载。
   共同底线：**必须让观众分辨得出这是再现，不是当时的影像。**

## 9. 数据、地图与图表作为影像

【操作性建议】图表做错不是瑕疵，是一个**主张错误**。四条纪律：

- 标明数据出处、统计口径、时间区间、单位；口径不同的两条线不要画在同一张图上。
- 地图只画你能证明的边界；未核实的路径、地块范围一律用示意与虚线，并在片上写「示意」。
- 街景与卫星图带时间标签，且平台条款可能限制导出使用；平台水印不得遮盖。
- 数据可视化的动画不要制造不存在的因果；先给结论，再给图。发布前的核对流程见 [../10-伦理法律/事实核查与更正.md](../10-伦理法律/事实核查与更正.md)。

## 10. 档案的叙事功能

- **时间证据**：把「三年前这里就是这样」变成可见。
- **对比**：同机位今昔、同一人前后、同一厂开工与停产——档案是纪录片里唯一能真正做共时对比的材料。
- **缺席证明**：这里原来有一栋楼；这个岗位原来有 40 人。缺席只能用曾经存在的证据呈现。
- **权威借用与反向使用**：官方档案的语气可被用来对照当事人说法（工资表 vs 口述），这种并置本身就是论述。
- **代际与继承**：家庭相册的传递过程常是一条叙事线（谁保管、谁撕掉了哪张）。

## 11. 学术与影像的双重标注

【操作性建议】同一段素材若同时进论文和成片，需要两套记录，缺一套就会在评审或授权环节暴露：

| 用途 | 标注形式 | 必备字段 |
| --- | --- | --- |
| 影像 | 画面来源角标 + 片尾来源表 | 权利人、授权编号、期限、地域、署名文字 |
| 学术 | 正文引注 + 图版说明 + 素材鸣谢 | 档案全名、档号/卷号、馆藏机构、日期、数字化版本、使用许可声明 |

- 图版说明里写明采集地点、日期、拍摄者与授权状态；未公开的田野影像需按匿名化规则处理（见 [../../田野方法/07-伦理.md](../../田野方法/07-伦理.md)）。
- 引用格式与可引用的方法论文献清单见 [../../社会学田野/13-阅读/方法论文献.md](../../社会学田野/13-阅读/方法论文献.md)；OpenField 的引用号（`OF-…#T14:30`）可把论文引用精确指向某一秒。

## 12. 二次素材权利自查表

【操作性建议】每条素材进入时间线之前过一遍；任何一项「不确定」即视为未通过。

| 项 | 自查问题 | 通过条件 |
| --- | --- | --- |
| 1 权利人 | 我能写出权利人姓名/机构吗 | 有明确名称与联系方式 |
| 2 链条 | 权利人是从哪里取得权利的 | 有前手文件或合理说明 |
| 3 用途 | 我的用途在授权范围内吗（平台、商用、期限、地域） | 逐项对应，无「未列明即默许」 |
| 4 剪辑权 | 可否裁切、调色、变速、遮盖水印 | 书面许可，或不做该处理 |
| 5 肖像与隐私 | 画面中的可识别个人是否另有权利 | 与授权无关的第二层权利已处理 |
| 6 署名 | 要求什么形式、是否全片一致 | 片尾来源表已建并核对 |
| 7 原件留档 | 授权书、发票、沟通记录、来源截图齐备 | 归档位置可写出来 |
| 8 到期 | 项目发布/停映与授权期是否冲突 | 有余量，或续期条款明确 |
| 9 技术 | 在交付分辨率上 1:1 检过一帧 | 可辨识、无过度假造细节 |
| 10 标注 | 画面标注、年代、复演说明是否到位 | 逐条列在 shot list 上 |

## 13. 常见误区

| 误区 | 事实 |
| --- | --- |
| 「找到合适的素材再谈权利」 | 顺序反了；权利不确定的素材会毁掉已完成的叙事 |
| 「网上公开的就是可以用的」 | 公开 ≠ 授权，浏览条款不授予下载与再发布权 |
| 「注明出处就不算侵权」 | 署名不替代许可；许可与署名是两件事 |
| 「找到作者同意，平台条款也覆盖了」 | 平台转发条款一般不覆盖你的商用剪辑 |
| 「孤儿作品没人管」 | 无人认领不等于可自由使用，风险由使用者承担 |
| 「EXIF 写了日期就能当证据」 | 可改写、可剥离；证据要靠哈希与第二来源 |
| 「老素材放大一下就行」 | 放大与稳定都有可见代价，先按交付分辨率判 |
| 「给自拍素材做旧，更有历史感」 | 这是伪造档案性质，会连带损害你真档案的可信度 |

## 实操要点

- 顺序固定：查权利 → 查技术 → 查伦理 → 才进时间线；三项是乘法。
- 询价一次问全六项（用途、期限、地域、剪辑权、署名水印、独家），全部书面留档。
- 翻拍老照片四要素：拆玻璃、垂直正对、双灯 45 度对称、手动对焦到照片表面；分辨率按用途反推。
- 手机照片要原文件不要转发件；接收即算哈希写日志，处理只出新版本。
- EXIF 只作线索：时间来源分层记录，主张为真需第二来源印证。
- 引用必须可见：来源角标 + 年代；复演、插画、AI 处理一律标明；不给自拍素材做旧。
- UGC 拿不到授权时改手段（插画/情景再现/声音演绎/示意图），底线是观众能分辨这不是当时影像。
- 双重标注：片尾来源表（影像）与图版说明 + 引注（学术）各一份，字段见 §11。
