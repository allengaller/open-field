# 不可重复事件现场

> 事故、冲突、被赶出门、分娩、死亡——这些事只发生一次。这一科的训练目的不是让你拍到更多，而是让你在极短的时间里把「该做的判断」提前做完了，现场只剩执行。

## 1. 这一科为什么残酷

【操作性建议】前面各篇的所有余地在突发事件里同时消失：没有时间读光、没有位置可以预演、没有第二机位、关系可能正在被这场事件摧毁。而且损失是单向的——**多拍 30 秒浪费一点卡，少拍 3 秒永久失去一段证据**。

因此本篇的写法与别处不同：先给排序，再给动作，最后给退出条件。现场不解释道理。

## 2. 开机优先级的极端排序

【操作性建议】不可重复事件里的优先级只有一行：

> **先按录制键，再决定构图。按错了可以剪掉，没录上就永远没有。**

顺序：开录 → 主体是否在录进范围内 → 焦点 → 曝光 → 其他一切（水平、构图、美感、运镜、音质）。

【操作性建议】这条判断有明确的伦理边界，越界就不成立：

- **适用**：你已获准在场；事件涉及公共利益或正在发生的处置行为；对象是**事件本身**而不是某个人的私密时刻。
- **不适用（先取得同意，再决定拍不拍）**：可识别的未成年人、正在被救治的人、死者、纯家庭私密场景、他人身体创伤的特写、他人哭泣且与你无既定关系的陌生人。
- **不构成理由**：「以后可能查不到」「这画面很难得」——这些是自我说服，不是判据。判据只有两条：**你有权在这里** + **拍这件事不额外造成伤害**。
- 无论哪种情形，事后都必须走 §8 的沟通与 §10 的使用判据。「拍到了」不产生「可以播」。

## 3. 事前准备：把决定做完在昨天

【操作性建议】突发能力 90% 来自事前。逐日执行：

- [ ] **机器常年处于「3 步可开机」状态**：电源开关不锁、录制键不隐藏、包不压在最底层。
- [ ] **盲开机演练 15 秒/天**：不看屏幕完成「开机—对焦—确认在录」。判据是你能在余光被占满时凭手感完成。
- [ ] **预置参数冻结**：快门、光圈、ISO 上限、自动曝光锁、峰值对焦/斑马纹常开、录音电平预设留足余量（§6）。进现场不改菜单。
- [ ] **电池常备 ≥ 当日预估 2 倍**，且有一块在口袋里而不是包里（伸手可换）。
- [ ] **卡位常清**：任何一张卡的已用容量不超过 50%。满了的卡不会给你时间。
- [ ] **麦位预设**：领夹麦常挂、备用录音机在身上而不是包里。
- [ ] **一句标准应答**背熟：「我是独立记录者，我在做 ×× 的记录，你有权要求我不拍你。」

## 4. 你在现场凭什么拍

【操作性建议】进场前 3 秒自问四题，答案决定你的动作：

| 问题 | 三种答案与处置 |
| --- | --- |
| 这是公共事件还是私人事件？ | 公共（处置、执法现场、公开冲突、事故影响公众）→ 可拍，但需处理旁观者；私人 → 先同意 |
| 我是受邀、被允许，还是闯入？ | 受邀 → 关系是你最大的保护，事后必须告知；允许 → 允许范围即上限；闯入 → 不拍，先解决在场资格 |
| 当事人在场吗，同意吗？ | 在场且能表达 → 说一句再拍；在场但不能表达（伤、幼儿、崩溃）→ 不以其为对象；不在场 → 不以其物品/影像做指认 |
| 有无关旁观者吗？ | 有 → 取景回避为先；回避不了 → 记录为素材，后期做遮脸/去声处理 |

同意流程与书面留痕见 [../10-伦理法律/知情同意与拍摄授权.md](../10-伦理法律/知情同意与拍摄授权.md)；场地与管理方许可见 [../11-生产与资金/拍摄许可与场地.md](../11-生产与资金/拍摄许可与场地.md)；法律边界的事实性提示（自媒体拍摄不当然等同于新闻采访资质）见 [../10-伦理法律/中国法律边界.md](../10-伦理法律/中国法律边界.md)。

## 5. 拍摄者自身安全：素材与人之间，人永远优先

【操作性建议】进任何紧张现场前先做三件事：**找两个出口**（主出口与侧向出口）、**定一个集合点**（若在安全距离外有车，车就是你的集合点）、**把卡的内袋位置确认一次**。

- **人群动力学**：不站在人流汇聚点（门口、楼梯口、通道尽头）；不站在人群与墙之间；**永远不背对开阔地**。人群挤压时把机器抱在胸前贴身体，不要外伸。
- **被针对的信号**：三人以上朝你走来且视线集中在机器上；有人开始用手挡镜头并回头招呼同伴；有人问「你是哪个媒体的」且语气在变硬。
- **设备被抢的瞬间**：**松手，不硬抗。**设备的价值永远低于人。被抢后不追，退到安全位置，记住对方体貌与所在，交给正当程序（§9）。

【操作性建议】「先保素材还是先保人」的答案写死：**先保人，卡先保。** 具体动作序列——感到威胁时：

1. 停止把机器举向对方（垂下，但不要在他面前按停止键，那会被理解为销毁证据）；
2. 双手让机器可见，说明「我只记录，不干涉，你要我停我就停」；
3. 若对方要求删除：**不撒谎，也不当场交出原始卡**（说法见 [现场工作流与安全.md](现场工作流与安全.md) §4）；
4. 后退撤离，不转身跑，眼睛留在对方身上；
5. 到安全位置后第一件事：把卡取出放内袋，检查是否仍在录。

## 6. 冲突现场的技术

【操作性建议】冲突中你既不能参战也不能被卷入，物理与技术方案：

- **距离**：不要靠近战团。经验线是 **≥10–15 米**，或用长焦补回景别。靠近只会让战团多一个目标，且你会拍到无法使用的晃动。
- **机位**：固定优于移动——靠墙、抱柱、车后。手持在肾上腺素下必然抖；**脚架在冲突现场是累赘，不要展开**。地面震动会传给脚架，用身体当缓冲（手肘撑膝、脚踩实地面）。
- **景别取舍**：拍**关系与规模**（谁在对峙、多少人、谁在拦）优先于拍脸部。事件证据的价值在于结构与人数，不在特写。
- **声音比画面更容易毁掉这段素材**：喊叫、金属撞击、近距离爆破式音量会瞬间削顶（clipping），削顶的音频不可恢复。预防动作：录音电平预设低于正常对话 6–10dB 余量、开启低切、**把备用录音机放在自己身上而不是领口**（离声源越近越容易爆）、不要将指向麦对准喊叫方向。具体参数属器材，交给 [../09-技术与设备/收音装备.md](../09-技术与设备/收音装备.md)。
- **不要出声**：不喊话、不劝架、不复述。你的声音会进素材，也会改变现场。

## 7. 情绪现场的停机规则

【操作性建议】出现下列任一项，**立刻处理**，不等这个镜头拍完：

| 情形 | 具体动作 |
| --- | --- |
| 当事人崩溃（哭到无法说话、过度换气、说出失控的话） | 第一选择是**手掌遮住镜头**而不是关机——保持录制但切断画面，同时你的手告诉他「我不看了」；他若要求关机，立即关机并当着他的面把机器转向一侧 |
| 涉及儿童（可识别、无监护人在场、正在受责骂或受惊） | 立即停机，镜头落地；不在现场讨论，事后按 [../10-伦理法律/弱势群体与儿童.md](../10-伦理法律/弱势群体与儿童.md) 处置 |
| 有人明确反对（「别拍我」「把机器关掉」） | 停机，不辩解、不还价；把该时段记进场记，标注「应 ×× 要求停机 ×× 分钟」 |
| 需要救护（有人受伤、昏倒、抽搐、产程、自伤） | **停止拍摄，转为求助**：呼叫急救、让出通道、指引人群。不作为拍摄对象记录被救治过程；事后如涉公共利益，只保留事件前后非伤者的画面 |
| 你自己无法判断（震惊、发呆、手不听使唤） | 关机，退开十步，站稳 30 秒再决定。僵硬状态下的画面既不可用，也会让你做出坏判断 |

【操作性建议】停机不等于失去一切：录音机可以只停画面不停声，但**前提是声音内容不加重对当事人的伤害**。崩溃时的哭声、求饶、涉及第三方的隐私话语，同样不该留。

## 8. 事后 30 分钟流程

【操作性建议】事件结束后 30 分钟是一个硬窗口——记忆在 30 分钟后开始结构性衰减（写详的时限依据见 [../../田野方法/04-观察与笔记.md](../../田野方法/04-观察与笔记.md)）。顺序不可倒：

- [ ] 1. **离开现场到可安心操作的位置**（不在当事人视线内整理设备）。
- [ ] 2. **备份双份**：卡 → 便携 SSD 一份 + 手机一份；原件保留不删。
- [ ] 3. **哈希固化与日志写入**：在采集/入库瞬间生成 SHA-256 哈希、时间戳、位置与设备标识，进入仅可追加的证据日志。**原始文件此后永不覆盖、不重编码、不「顺手清理」**（[../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.1；操作实现见 [../../工程/使用手册.md](../../工程/使用手册.md)）。
- [ ] 4. **写事实记录**（15 分钟，纯描述层）：起止时间线、在场者与位置、谁先说了什么（尽量逐字）、你说了什么、谁同意拍摄、谁反对、谁要求停机及持续多久、你停机几次、有无第三方拍摄、事件后续处置（谁带走谁、来了几辆车）。分析层另写一段并标「推测」，两层分开。
- [ ] 5. **当事人沟通与撤回选项**：让他知道你有这段、你会怎么用、他有权要求不出现；把答复写进承诺表（模板见 [../15-工具与模板/授权文书模板.md](../15-工具与模板/授权文书模板.md)）。**不承诺你做不到的一次性删净，也不隐瞒你已持有的副本。**
- [ ] 6. 只在第 5 步完成后，才允许自己看回放。先看记录，再看素材，顺序反了会让素材改写你的记忆。

## 9. 法律与平台风险处置

【操作性建议】本节只给正当程序路径。涉及具体条文与管辖的事实性提示见 [../10-伦理法律/中国法律边界.md](../10-伦理法律/中国法律边界.md)，本篇不重复。

- **不删原始素材**。任何情况下不在现场删除、不格式化、不交出原件。若司法机关依法调取，配合并索取**书面手续与凭证**，保留自己的一份完整哈希记录以备校验。
- **不私下传播**。未经核实的现场素材不发群、不发给当事人对立一方、不做「先发出去再说」的处理；发布口径见 [../12-发行传播/自媒体分发.md](../12-发行传播/自媒体分发.md)，事实核查与更正见 [../10-伦理法律/事实核查与更正.md](../10-伦理法律/事实核查与更正.md)。
- **设备被抢、被强行要求删除、人身受威胁**：离开现场后立即报警并做报案记录，保留伤痕照片与时间线；这是事实性救济通道，不是谈判筹码。
- **需要证据保全**：走公证或第三方时间戳存证，不要自建「可信」叙事。哈希与日志只证明「这段素材在某时刻未被改动」，不证明画面内容为真——后者需要事实核查与多源印证（见 [../../田野方法/08-信效度.md](../../田野方法/08-信效度.md)）。
- **咨询顺序**：涉及可识别个人、纠纷双方、未成年人、进入受限场所的素材，发布前找一次执业律师做书面意见，成本远低于事后下架与诉讼。
- **平台侧**：素材被他人搬运传播时，用平台的侵权通知通道处理并留记录；不要以对方违规为由自行扩大传播。

## 10. 最难的一问：有些素材你最后不该用

【操作性建议】「能拍」≠「该剪进去」。使用判据七条，任一条不过即封存：

1. **必要性**：这段是否承担叙事或证据功能？删掉它，主张是否仍成立？若成立，它多半只是奇观。
2. **不可替代**：有没有同意更充分、伤害更小的替代素材能承担同一功能？有则用替代。
3. **伤害比例**：这段带来的公共信息量，与它对可识别个人造成的损害，哪个大？把两边都写下来再比。
4. **语境完整**：剪进去之后，观众是否会得出与现场事实相反的判断（把崩溃剪成软弱、把沉默剪成默认）？语境补不齐就不用。
5. **当事人当下状态**：他今天是否处在能为自己辩解的状态？崩溃中、酒后、被拘押、病中的话，同意能力要单独评估。
6. **30 天复看**：存放 30 天后重看一次，问自己现在是否仍愿用。仍犹豫，就不用。
7. **他能看到吗**：如果这个人能看到成片，你是否敢当面放给他看？不敢，就说明你自己知道这段有问题。

【操作性建议】不使用的素材**保留不删**（证据链要求），标注「已封存，理由：××」，并写进日志。封存也是一种使用决定，它需要理由和记录。

## 11. 突发现场决策卡

【操作性建议】把这张卡抄在纸质场记背面。

| 时间 | 动作 |
| --- | --- |
| 0–3 秒 | 按录制。不思考构图。同时确认脚下有支撑、背后有出口 |
| 3–30 秒 | 定主体（谁在被看）、给焦点、给曝光锚；不挪位置；不出声 |
| 30 秒–5 分钟 | 判断在场资格（§4）与安全（§5）：能不能留、该退到哪；处理停机条件（§7）；冲突现场退到 ≥10 米固定机位 |
| 5–30 分钟 | 保住声音（电平余量、爆音预防）；拍关系与规模；打一次口头场记（「10:24，×× 开始××」）；开始留意结束信号——事件结束后的沉默常比过程更有价值，别提前关机 |
| 30 分钟之后 | 按 §8 顺序：备份 → 哈希 → 事实记录 → 当事人沟通 → 才看回放；当天写使用判据初稿 |

## 12. 常见误区

| 误区 | 事实 |
| --- | --- |
| 「先想好构图再开机」 | 想好的那 3 秒，事件已经过去了 |
| 「拍都拍了，不用可惜」 | 素材价值与使用正当性是两个判断，后者独立成立 |
| 「对方要求关机我就当场删掉」 | 停机是尊重，删除是处置，处置走 §8 第 5 步，不当场表演 |
| 「靠得越近越有现场感」 | 近身会让你成为一方，且画面因抖动不可用 |
| 「先把画面保住，声音有相机麦就行」 | 冲突现场最先毁掉的是削顶的同期声 |
| 「事发当晚就发出去最安全」 | 未经核实的现场传播会把你的记录变成争辩对象 |
| 「我有哈希，就能证明事情是真的」 | 哈希只证明文件未被改动，内容真伪需另做核查 |
| 「人没事，素材没了可以再拍」 | 后半句在不可重复事件里恰恰不成立——但优先次序仍是人先于素材 |

## 实操要点

- 排序写死：开录 > 在录不中断 > 焦点 > 曝光 > 一切美学；但「先按录制」只适用于你有权在场且不额外造成伤害时。
- 每天 15 秒盲开机演练；卡常年 ≤50% 用量；电池一块在口袋；参数在住处冻结。
- 进场三件事：找两个出口、定集合点、确认卡的内袋位置；被抢时松手，不硬抗。
- 冲突现场：≥10–15 米、固定不移动、不展脚架、拍关系与规模、录音电平留 6–10dB 余量。
- 停机四情形（崩溃、儿童、明确反对、需救护）用「手掌遮镜头」代替关机，当事人要求关机则立刻关机。
- 事后 30 分钟顺序不可倒：备份 → 哈希固化 → 事实记录 → 当事人沟通与撤回 → 才看回放。
- 只走正当程序：不删原始、不私下传播、必要时报警与律师书面意见；哈希证明未改动，不证明为真。
- 使用判据七条，任一条不过即封存并写理由；封存也是决定，也要留记录。
