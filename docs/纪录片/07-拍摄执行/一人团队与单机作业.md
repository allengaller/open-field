# 一人团队与单机作业

> 一个人背着机器进现场，最大的瓶颈不是设备，是注意力。这篇讲的不是「怎么省人」，而是「注意力只有两份时，你把它花在哪」。

## 1. 单人的不可兼得清单

【操作性建议】一个拍摄现场同时存在五个需要持续照看的科目：

1. 画面（焦点、构图、水平、曝光变化）
2. 声音（电平、监听、麦位、环境噪声）
3. 关系（说什么、什么时候说、对方的情绪拐点）
4. 环境与自身安全（动线、谁在看你、出口、脚下、车辆）
5. 设备状态（电量、卡容量、过热、时间码）

【操作性建议】人的注意力可靠并发上限是 **2 项**，第 3 项开始出错，第 4 项之后是丢素材。所以任何「我这次都要」的场次计划，都是失败的计划。剧情片的分工不是审美偏好，是认知约束的工程解法。

## 2. 每场戏指定一个第一任务：优先级轮转表

【操作性建议】进场前把这一场的第一任务写死，其余科目降级为「不出大错即可」。轮转表：

| 场景 | 第一任务 | 第二任务 | 本场明确放弃 |
| --- | --- | --- | --- |
| 陌拜、首次见面 | 关系（可以全程不开机） | 声音 | 构图、画面质量 |
| 坐下来长谈 | 声音 + 焦点 | 听下一句、准备追问 | 摄影机运动、换角度 |
| 突发事件 | 在录（不中断） | 焦点 | 水平、构图、音质、美感 |
| 转场、走路、通勤 | 安全与环境观察 | 常开记录 | 一切画面质量 |
| 多人会议 / 班组 | 谁在被看 | 麦位覆盖 | 第二机位、精细构图 |
| 空镜采集 | 观察两分钟再决定拍什么 | 五件套齐采 | 同期声（另录） |
| 需要入镜主持 | 说清楚 + 看镜头 | 设备看护 | 跟焦、构图、现场跟随 |

【操作性建议】把第一任务写在纸质场记的第一行，而不是记在脑子里。疲劳到第四小时，脑子里的优先级会先消失。

## 3. 设备穿戴与预设：把注意力从机器上撤下来

【核验·原则】OpenField 的宪法要求「从掏出设备到开始采集不超过 3 步操作——现场转瞬即逝，软件不许浪费它」（[../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.2 离线优先）。单机拍摄用同一标准衡量自己的机器。

- [ ] **快速开机 ≤3 步**：拉开包 → 拨开机开关 → 按录制。任何需要进菜单才能开始的设置，都不要留到现场做。
- [ ] **预设冻结**：快门角度、光圈、ISO 上限、白平衡、录音电平、监视器亮度，全部在住处定好。现场只允许两个动作：**对焦、开关机**。
- [ ] **参数分级解锁**：日常场景 0 个可调项；光线剧变场景解锁曝光补偿一项；不可重复事件解锁全部，代价是放弃构图。

【操作性建议】四种挂载方式的选择：

| 挂法 | 适用 | 代价 |
| --- | --- | --- |
| 三脚架固定 | 访谈、静止事件、长时间跟拍 | 重、需预置、不灵活 |
| 胸挂 / 颈挂 | 行走跟随、第一人称视角 | 视角低且固定，转身即甩 |
| 肩挂系统 | 需要移动又要稳的手持 | 重量直接压在同侧颈肩 |
| 手持贴身 | 需要极快换向 | 抖、累、最容易暴露情绪 |

【操作性建议】肩挂重量参考线：整机含镜头与附件 **≤2.5kg** 可稳定持握约 40 分钟；**2.5–3.5kg** 约 15 分钟后开始动作变形；**>3.5kg** 不要用于跟随拍摄，改脚架或分体。重量参数以你实际负重走 3 公里后的手感为准，别信标称。鞋、衣着与降噪细节见 [非虚构摄影.md](非虚构摄影.md) §6。

## 4. 双系统工作流：相机与录音机的同步纪律

【通行共识】独立录音机 + 相机内录（dual-system）是纪录片标准配置：录音机负责质量，相机麦负责同步参考（guide track）。单人作业必须把它变成固定流程，否则后期对码会吃掉你一晚。

- [ ] **同一时间源**：每天出发前两机时间对齐一次（网络校时或同一手机；无法对齐时记录两机偏差秒数，写进场记）。
- [ ] **打板**：每个镜头开始都打。没有场记板时：在镜头前拍手一次，或让一句话同时出现在两个设备里（「现在开始，第 3 场」）。
- [ ] **录音机不停机**：相机可以随便开关，录音机整场一直转。这是单人作业最省时间的一条。
- [ ] **命名一次成型**：`D03_S12_A`（拍摄日_场次_机位），素材入库不改名，改名的成本在剪辑期会翻倍（规范见 [../08-剪辑后期/素材管理与日志.md](../08-剪辑后期/素材管理与日志.md)）。
- [ ] **当晚对点**：把关键引语的时间点从音频侧回标到画面侧，形成可引用位置。OpenField 的引用号（如 `OF-20260925-CX-001#T14:30`）就是为这一步准备的，流程见 [../../研究/路书.md](../../研究/路书.md) §四。

## 5. 「你既是采访者又是摄影师」的解法

这是单人作业最难的一题：镜头对着别人时，你不在对话里，你在操作机器。四条办法，按有效性排序：

1. **三脚架固定 + 不再移动。** 把构图这件事在 5 分钟内一次性做完，然后永久放弃它。机器不动，你的双手和眼睛全部回到对话。
2. **长时间不开机，只看和只听。** 每次访问的前 10–20 分钟不放机器（与 [长期跟拍.md](长期跟拍.md) §3 的开机节奏一致）。关系建立阶段最好的素材往往不在这里，但这段决定了后面有没有素材。
3. **坐得近、同高度、镜头偏一侧。** 不要隔着桌子对坐（审讯位）；坐 45 度侧向，摄影机在两人视线的一侧。
4. **给自己一个明确的「操作时段」。** 只在对方讲完一个段落、或你去续电池时才调整机器；说话中途挪动机器，观众一定察觉。

【操作性建议】什么时候放弃画面质量保住关系——出现以下任一信号，立刻停止拍摄：

- 对方明确说「别拍了」「关掉」。→ 关机，且把镜头朝向自己一侧，让他看到机器是关的。
- 对方开始看镜头而不是看你（表演化）。→ 关机或换更小的机器，重新聊天三分钟。
- 话题进入其隐私、家庭冲突、就医、被欠薪的屈辱感。→ 先问，再决定。
- 现场出现第三方（管理层、保安、家人）开始施压。→ 停机比保住这段素材更值。

授权与同意流程见 [../10-伦理法律/知情同意与拍摄授权.md](../10-伦理法律/知情同意与拍摄授权.md)；摄影机在场效应的机制分析见 [../14-田野与影像/相机在场效应.md](../14-田野与影像/相机在场效应.md)。

## 6. 声音优先：单机作业的第一原则

【通行共识】画面可以重拍、可以补、可以用空镜遮；**同期声不可重来**。一句在现场说出的话，第二天不会有人再对你用同样的语气说一遍。

- [ ] **判断规则**：当「画面质量」与「这段声音」只能保一个时，保声音——把机器举到不合适的角度、放弃稳定、放弃构图，只要麦还在正常收。
- [ ] **别麦先于开机**：进现场谈妥之后第一件事是把领夹麦别上，即使你今天不打算拍画面。
- [ ] **监听不可省**：一副封闭耳机是单机作业性价比最高的一件设备。不监听等于把整天的声音押在运气上（装备清单交给 [../09-技术与设备/收音装备.md](../09-技术与设备/收音装备.md)）。
- [ ] **底线**：声音优先不意味着可以偷录。知情同意先于任何采集发生，见 [../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.4；法律边界只做风险提示见 [../10-伦理法律/中国法律边界.md](../10-伦理法律/中国法律边界.md)。

## 7. 补位策略：当天做不到的，用什么代替

【操作性建议】单机一定会丢东西。补位是有边界的：可以用别的影像**说明**没拍到的事，不能用别的影像**冒充**拍到了。

- **自己入镜当主持人**：把没拍到反应的地方改成「我在现场讲述我看见的」，用自拍位出镜。代价是镜头前你也要练。
- **空镜 + 字幕代替未拍到的反应**：字幕写清「当事人后来告诉笔者」，标明信息来自后补。空镜采集法见 [空镜与环境影像.md](空镜与环境影像.md)。
- **第二天重访补第一天的缺口**：最正当的补拍。明说原因——「昨天我手抖了，能再让我拍一遍你开门吗」；搬演式重现必须标明（诚实性问题见 [../01-理论/真实契约.md](../01-理论/真实契约.md)）。
- **用照片替视频**：事件已过，拍现场照片并在片中标注拍摄时间，比留一段假同期诚实。
- **不可补的东西**：情绪拐点、事故、决定、第一次见面的反应。这些只能靠 §3 的常开和提前到位解决。

## 8. 电力与存储的冗余下限

【操作性建议】只定最低配置，具体规格与型号交给 [../09-技术与设备/编码存储与备份.md](../09-技术与设备/编码存储与备份.md)：

- [ ] 电池总量 ≥ 当日预估拍摄时长的 **2 倍**，且分散在两个包（一份丢了三份还能拍）。
- [ ] 卡总量 ≥ 单日预估素材量的 **2 倍**；每次访问结束即换卡，**不在现场格式化旧卡**。
- [ ] 备份三份：相机卡（原始）+ 现场一份（手机或便携 SSD）+ 晚间两份（不同物理位置）。对齐 [../../研究/路书.md](../../研究/路书.md) T-3 的「U 盘 ×2 每晚双备份」。
- [ ] 录音机与相机分别有独立电源，不共用一块充电宝。

## 9. 体能与心理

【操作性建议】参考值来自单人长时间作业的经验规律，不是生理常数，请按自己的体感下调：

| 时段 | 状态 | 处置 |
| --- | --- | --- |
| 开机 0–90 分钟 | 状态最好 | 把最难的戏（跟焦、访谈高潮）排在这里 |
| 90–180 分钟 | 注意力明显下降 | 强制 10 分钟离屏休息，换电池时起身走两步 |
| 3–6 小时 | 判断力下降，开始「为了拍而拍」 | 只跑常开机位，不做精细构图 |
| 6 小时以上 | 废片率与安全风险同时上升 | 收工；例外只给不可重复事件 |

- **心理侧**：连续被拒之后最明显的症状不是难过，是不想开机。规则与 [../../研究/行动总纲.md](../../研究/行动总纲.md) §8.1 一致——连续被拒 5 次立即停止当日陌拜，换环境或回住处半天；身体信号（视力模糊、头痛）按 §8.2 终止当日计划。
- 反身性检查（今天我是不是在把自己看到的写成我希望看到的）见 [../../田野方法/03-进入田野.md](../../田野方法/03-进入田野.md) §5。
- 负重与距离要提前换算：背 8kg 走 6 公里之后，不要安排需要精密跟焦的戏。

## 10. 当日粗筛：别把素材攒成再也不会打开的文件夹

【操作性建议】单人作业最典型的死法不是拍砸，是「拍了 40 小时没整理，第五周再也不会打开」。规则：

1. 当日素材**当晚只打三级标记**：留 / 废 / 待看。不做精剪，不调色。
2. 4 小时以内的素材，标记耗时约 30–40 分钟；超过这个比例说明你当天开机过多（见 [长期跟拍.md](长期跟拍.md) §3）。
3. 场记当晚补全——记忆衰减以小时计，路径见 [../../研究/路书.md](../../研究/路书.md) §四第 2 步。
4. 连续两日素材未过标记，则第三天先补标记、不开新机。
5. 日志与检索结构见 [../08-剪辑后期/素材管理与日志.md](../08-剪辑后期/素材管理与日志.md)。

## 11. 什么时候必须找人

【操作性建议】出现下列任一项，单机方案在物理上就不成立，必须加人或加机：

- **三方及以上会互相接话的对话**：单机位必然丢反应，要么加一台固定机，要么加一个人管机。
- **危险现场**：人群挤压、冲突、夜间、高处、水域、吊装与车辆动线。判据见 [现场工作流与安全.md](现场工作流与安全.md) §5。
- **超过 8 小时或跨夜的连续跟拍**：你需要有人替你守一次机器，好睡 20 分钟。
- **需要你入镜、需要空手搬东西、需要有人看管设备**：任何一项都把你从摄影位上抽走。
- **需要同步操作两台机器 + 一台录音机**：这是三个持续任务，超出 §1 的上限。

【操作性建议】反向判据：一场戏的**不可重复度**越高，越不能靠单人硬扛。宁可放弃拍摄，也不要交出一份既没保住人也没保住素材的结果。

## 12. 单人拍摄日 SOP

【操作性建议】以下为一天 6–10 小时拍摄的骨架，时间可按出发距离平移。完整设备检查项见 [现场工作流与安全.md](现场工作流与安全.md) §1。

- [ ] 06:30 起床，看昨日笔记最后一行：今天的第一任务是什么
- [ ] 07:15 出门前：电池 ×3（分两包）、卡 ×2、麦与耳机、清洁布、雨护、纸质场记
- [ ] 07:45 车上：两机时间对齐、参数预设冻结、今日场次命名写好
- [ ] 08:30 到场：不进场地，先在原位看两分钟（环境与光）
- [ ] 08:35 打招呼、说明来意、取得同意；先聊 15 分钟不开机
- [ ] 08:50 别麦、架机、定构图、打板、开录 → 之后进入「只对焦与开关机」模式
- [ ] 每 90 分钟：换电池即休息 5 分钟，离屏、喝水、记一条场记
- [ ] 每场结束：口头报场次号（给录音机留对点）、换卡、卡放固定内袋
- [ ] 17:00 收工前 20 分钟：跑空镜六条保底清单（[空镜与环境影像.md](空镜与环境影像.md) §8）+ 每个地点补一条正式房间音（60–120 秒，口径见 [声音设计.md](../04-声音/声音设计.md) §4）
- [ ] 18:30 住处：素材入库 → 哈希固化 → 双备份 → 转写 → 当晚 30 分钟内补场记与笔记
- [ ] 20:30 当日粗筛（留/废/待看），并写明天的 shot list（3 条以内）
- [ ] 22:00 设备充电归位，包按明日顺序重摆
- [ ] 23:00 前睡。睡眠不足直接换算成第二天的废片率。

## 13. 常见误区

| 误区 | 事实 |
| --- | --- |
| 「我一个人可以多线操作」 | 可靠并发 2 项；第 3 项开始丢东西，且你不知道丢了哪项 |
| 「先把画面拍好，声音有就行」 | 同期不可重来；画面能补，声音不能 |
| 「机器一直开着，反正是素材」 | 常开必须配场记，否则 40 小时素材等于 0 小时 |
| 「关系到位了，随时能拍」 | 关系决定你能进场，不决定你能开机（见 [长期跟拍.md](长期跟拍.md)） |
| 「今天太累，回去再整理」 | 「回去再整理」在单人项目里几乎从不发生 |
| 「加人太贵，先自己扛」 | 三方对话、危险现场、跨夜跟拍不是成本问题，是可行性问题 |
| 「重一点的机器画质更好，我背得动」 | 超过负重线之后画质优势会被动作变形和收工提前全部抵消 |

## 实操要点

- 每场戏只定一个第一任务，写在纸质场记第一行；其余科目降级为「不出大错」。
- 开机 ≤3 步、现场只动「对焦与开关机」，其余参数在住处冻结（对齐 PRINCIPLES §2.2）。
- 双系统三铁律：同一时间源、每镜必打板、录音机不停。
- 关系优先于画面的四个停机信号：对方要求关、对方开始看镜头、话题入隐私、第三方施压。
- 声音优先于画面：画面可补、同期不可重来；但同意永远先于采集。
- 冗余下限：电池 2 倍、卡 2 倍、备份 3 份；不在现场格式化。
- 当日素材当晚打「留/废/待看」三级标记，不精剪；连续两日积压就先清积压再开机。
- 三方对话、危险现场、跨夜跟拍、需人看管设备——四种情况必须加人，不硬扛。
