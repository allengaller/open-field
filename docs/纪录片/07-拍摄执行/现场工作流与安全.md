# 现场工作流与安全

> 素材丢失的原因极少是「运气不好」，几乎全是流程缺一环。这一篇把一天的动作固定下来：进场前查什么、录完先做什么、出事怎么说、丢了怎么记。

出发前的行程、预算、证件、票据与预研清单已在 [../../研究/路书.md](../../研究/路书.md) §三，本篇不重复，**只补影像项**。收工后的 OpenField 数据流程见同文 §四。

## 1. 进场前的 20 项检查

【操作性建议】每天出门前一次过完，全部在住处完成，不到现场补。

- [ ] 1. 电池：相机 ≥2 块 + 录音机 ≥1 块 + 充电宝，分散在两个包，至少一块在口袋
- [ ] 2. 卡：总容量 ≥ 当日预估素材量 2 倍，且每张已用不超过 50%
- [ ] 3. 镜头与传感器清洁：气吹、镜头笔、无绒布；现场擦不掉的灰会毁掉全部素材
- [ ] 4. 麦克风：领夹麦、指向麦各做一次 10 秒试录并**回放**（只听不回放等于没测）
- [ ] 5. 监听耳机：有线优先，确认左右都响
- [ ] 6. 备用线缆：相机—麦、麦—录音机、转接头各一份，现场最常见问题是线，不是机器
- [ ] 7. 时间码对齐：相机与录音机两机时间校准一次，偏差写进场记
- [ ] 8. 录音电平预设：常态对话电平与峰值余量定好，现场不再调菜单
- [ ] 9. 遮光：遮光罩、小黑旗或硬纸板（监视器在阳光下读不出曝光）
- [ ] 10. 雨护：防水袋/大雨衣 + 一块干布；机器进水只有一次
- [ ] 11. 脚架垫：砖块、旧地毯或专用垫（土地、积水、斜坡上不垫必沉必歪）
- [ ] 12. 鞋：软底、静音、防滑、已磨合；新鞋不进现场
- [ ] 13. 参数预设冻结：快门、光圈、ISO 上限、白平衡、峰值对焦（见 [非虚构摄影.md](非虚构摄影.md) §7）
- [ ] 14. 开机路径实测一遍：3 步内能开始录
- [ ] 15. 场记纸笔：防水笔记本 + 两支笔，电子设备会没电
- [ ] 16. 同意与许可材料：授权/知情同意文书、身份证明、被引荐人联系方式
- [ ] 17. 备份介质：便携 SSD 有空间、手机清出 ≥20GB（对齐 [../../研究/路书.md](../../研究/路书.md) T-1）
- [ ] 18. 标记工具：内袋、标签贴、卡包（防丢卡，也防混卡）
- [ ] 19. 个人信息：水、常用药、充电宝满电、紧急联系人写在纸上
- [ ] 20. 今日第一任务写在场记第一行（见 [一人团队与单机作业.md](一人团队与单机作业.md) §2）

## 2. 进场前 5 分钟

【操作性建议】到了门口不进，按顺序做五件事，每件约一分钟：

1. **录环境音 30 秒**（先录，因为一进去就有门、人、机器声；做法见 [空镜与环境影像.md](空镜与环境影像.md) §7）。
2. **读光**：主光方向、强度差、色温混合、云遮蔽趋势，定人脸曝光锚（[非虚构摄影.md](非虚构摄影.md) §7）。
3. **机位预演**：站到你打算站的位置，走一遍，看影子落在哪、有没有挡动线、退路在哪。
4. **许可确认**：今天有谁在场可能反对你拍？管理方是否需要再打一次招呼？（场地许可见 [../11-生产与资金/拍摄许可与场地.md](../11-生产与资金/拍摄许可与场地.md)）
5. **任务优先级复述一遍**：今天第一任务是什么、放弃什么。

## 3. 录完即备份：铁律与删除的唯一前提

【操作性建议】三层时间线，一层都不能跳：

| 时点 | 动作 | 最低份数 |
| --- | --- | --- |
| 每一场录完（现场） | 换卡；卡立刻放入标记内袋；有空隙就把这场的卡拷一份到手机或便携 SSD | 卡（原始）+1 |
| 收工回到住处（当晚） | 全部素材入库、重命名、写日志；生成 SHA-256 并写进仅可追加的证据日志（[../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.1） | 再 +2，物理位置分开 |
| 离开该城镇前 | 全量核对一次清单（当日场次号 ↔ 卡号 ↔ 文件数 ↔ 时长） | 总数 ≥3 份 |

- **命名规范**：`D03_S12_A_1430` （日_场_机位_开始时间），一次定死不改；细则与日志字段见 [../08-剪辑后期/素材管理与日志.md](../08-剪辑后期/素材管理与日志.md)。
- **删除卡上素材的唯一前提**（四条同时成立才允许格式化）：(1) 已拷入两处且校验通过（文件数、时长、可播放抽验）；(2) 哈希与日志已写入；(3) 场记已补全，场次可回溯；(4) 你人已离开该现场、不需要回去补录。**任一条不满足，卡就留着。**
- 原始文件永不覆盖、不重编码、不「顺手清理」；任何处理生成新版本。

【操作性建议】每日收工流程（顺序不可倒，理由见 [../../研究/路书.md](../../研究/路书.md) §四）：

1. 素材入库 + 重命名 + 哈希 → 2. 转写（先转，语音检索比看素材快 20 倍）→ 3. 当日粗筛「留/废/待看」→ 4. 场记补全 → 5. 笔记（描述层 + 分析层分开）→ 6. 明日 shot list（≤3 条）→ 7. 设备充电、包按明日顺序归位。

## 4. 设备被抢与被要求删除素材时

【操作性建议】先给三条不动的底线：**先保人，不硬抗；不当场交原始卡；不撒谎。**

- **有人要求你删除**，标准应答（照读即可，全程不升高音量）：
  > 「我不动手删。这段的原始文件在卡上，卡我不会给；我另外有拷贝。你可以要求我不公开使用，我会记下你的要求并按流程处理；如果你认为需要走法律程序，可以报警，我会配合。」
- 对方动手抢：**松手**。设备可买，素材丢了不可复得，但人不可替换。被抢后不追、不围堵、不上网直播对方样貌，退到安全位置后报警并做报案记录，交由正当程序处理。
- **不撒谎**：不要说「我没拍」「已经删了」。虚假陈述会让后续的每一次沟通都变难，也会让你之后无法为他争取任何东西。
- **可正当依赖的技术前提**（只说明能力，不作为对抗手段）：本地数据库为加密存储、云端同步默认关闭且端到端加密、支持远程擦除与可审计删除（[../../../PRINCIPLES.md](../../../PRINCIPLES.md) §3 工程标准；具体攻击面与残余风险见 [../../工程/威胁模型.md](../../工程/威胁模型.md) §1、§3、§5）。加密保护的是当事人数据不被第三方取得，**不构成对合法调取的对抗**；依法配合调取并索取书面凭证（流程见 [不可重复事件现场.md](不可重复事件现场.md) §9）。
- **不做的四件事**：不现场删除、不销毁卡、不以「你有证吗」质问执法人员、不用公开传播施压。

## 5. 人身与关系安全

【操作性建议】判据：**这场戏的不可重复度越高，越不能单人**（详见 [一人团队与单机作业.md](一人团队与单机作业.md) §11）。分区风险提示：

| 情境 | 主要风险 | 处置 |
| --- | --- | --- |
| 夜间 | 视线、路况、判断力同步下降 | 21:00 后不安排新场地；只跑固定机位常开；走灯亮的路线 |
| 陌生村镇 | 引荐链断裂即失去保护 | 每次进场前告知一名当地联系人你的位置与离开时间；不单独进入封闭院落 |
| 劳务纠纷现场 | 双方都会把你当作对方的武器 | 不站队、不出声、不接「帮我们说一句」的请求；被围住时按 §4 应答并撤离 |
| 酒后人群 | 语言不受控但攻击性上升 | 只远距离固定机位，不手持靠近；有肢体接触迹象即离开 |
| 犬只 | 突然窜出，躲闪会掉机器 | 机器收到身体前侧、慢退、不直视、不奔跑；绕行按当地人的路线走 |
| 路况与工地 | 车辆动线、吊装区、地面开孔 | 永远不进车辆与吊装的正下方；沿人行道一侧走；不戴降噪耳机过马路 |
| 长途驾驶 | 微睡眠 | 连续驾驶 2 小时强制停 20 分钟；睡眠不足次日不开长途 |

【操作性建议】身份被误认时的澄清方式（一句话 + 一个动作，不辩论）：

- 被当成**记者**：「我不是记者，没有记者证，是独立做记录和研究，个人项目。」不借记者身份取便利——这既是诚实问题，也会带来真实法律后果（采访资质提示见 [../10-伦理法律/中国法律边界.md](../10-伦理法律/中国法律边界.md)）。
- 被当成**骗子/推销**：出示引荐人姓名与电话，当场让对方拨过去；东西不接、字不签、钱不收。
- 被当成**竞品/公司派来的人**：说明你要拍什么、给谁看、什么时候可以给当事人看；必要时当场给他看已拍内容。
- 被当成**执法人员**：你无权冒充，也必须澄清不是；被要求配合时，配合身份核验，说明自己在做什么、受谁邀请，并联系引荐人。
- 引荐人是最重要的安全资产：进入任何新场地前，先让一个有身份的人知道你是谁。

## 6. 素材安全的物理风险清单

| 风险 | 触发场景 | 预防 |
| --- | --- | --- |
| 失窃 | 车里、酒店前台、民宿、候车厅 | 机器不过夜离开身体或上锁；车里绝不留任何设备；住处分两处放 |
| 进水/潮气 | 雨、菜市场冲洗、南方回南天 | 雨护 + 干燥剂密封箱；进屋前先擦干再开电池仓 |
| 高温 | 夏天车内、曝晒机身、充电宝 | 车内在出发前 5 分钟才放机器；电池不过夜高温存放 |
| 沙尘与金属屑 | 工地、粮库、厂区 | 换镜头背风侧、朝下；进屋前吹沙；金属屑远离磁介质 |
| 机场与车站安检 | 锂电池、充电宝、脚架 | 锂电池与充电宝**随身携带、不放托运行李**，容量与件数按航司与机场现行规定执行；不确定就提前一天查官方页面，别凭记忆 |
| 卡损坏 | 带电拔卡、满卡继续拍、劣质卡 | 关机再取卡；单卡拍满即换；同型号卡混用时贴标签区分 |
| 单一备份的侥幸 | 「回去再拷」 | 见 §3 三层时间线；今晚不做完，明天就没有明天 |
| 人为误删 | 现场整理、借给别人看 | 卡与已备份盘物理分开存放，不混在一格 |

## 7. 健康纪律

【操作性建议】长时间盯屏与高近视是本项目的硬约束，规则与 [../../研究/行动总纲.md](../../研究/行动总纲.md) §8.2 一致：**出现视力模糊、头痛、眼干，立即终止当日计划**。

- 取景器/监视器连续使用 **≤45 分钟**，离屏 5 分钟看 6 米外；晚间剪辑每 **50 分钟**起身活动 3 分钟。
- 单日屏幕累计（拍摄 + 剪辑）**≤10 小时**；连续开机跟拍 **≤6 天**，第 7 天不开机。
- **高近视者的取景替代方案**（按优先级）：(1) 外接监视器或手机监看，放在胸前视线高度，头部基本不动；(2) 戴隐形眼镜 + 相机屈光度调节，或戴眼镜时使用眼点距（eyepoint）较长的取景器；(3) 干脆不取景——用超焦距 + 固定机位 + 预演走位，把「看清」的责任交给位置设计而不是眼睛。三脚架长时任务一律用第 3 种。
- **颈椎与腰**：取景时低头角度 >30 度的姿势不维持超过 20 分钟；脚架高度调到平视（宁可站椅子上）；负重包用腰承带，重量压到髋部。
- 单肩背机与三脚架**左右交替**，同侧连续不超过 40 分钟。
- 累到开始「为了拍而拍」是收工信号，不是意志问题（疲劳曲线见 [一人团队与单机作业.md](一人团队与单机作业.md) §9）。

## 8. 素材不可逆丢失的复盘机制

【操作性建议】规则：**每丢一次素材，写一条事故记录，并把结论改进本 SOP。**不写记录的丢失等于白丢，且必然重演。这与其他领域的事故复盘同构——审计轨迹的可追溯要求见 [../../田野方法/08-信效度.md](../../田野方法/08-信效度.md)。

- 24 小时内写，凭当时的现场记忆写。
- 只写事实与时间线，不写自责；结论必须落成一条可执行的动作（进 §1 清单或 §3 时间线）。
- 每季度回看事故记录一次，统计同类是否重复；重复即说明上次的改进没进流程。

## 9. 一个拍摄日的时间轴 SOP

【操作性建议】按「07:00 出发、19:00 收工」的常态日排；不可重复事件优先，其他都可顺延。

| 时间 | 动作 | 卡点判据 |
| --- | --- | --- |
| 06:20 | 起床、看昨日笔记最后一行 | 明确今日第一任务 |
| 06:40 | 过 §1 二十项 | 任一项缺则不出发 |
| 07:00 | 出发；车上两机校时、默念今日 3 个采集目标 | — |
| 08:20 | 到场，门口停 5 分钟做 §2 五项 | 未完成不进场地 |
| 08:30 | 打招呼、说明来意、取得同意；聊 15 分钟不开机 | 麦未别上不谈正事 |
| 08:50 | 架机、定构图、打板、开录 | 之后只动「对焦与开关机」 |
| 每 90 分钟 | 换电池即休息 5 分钟，补一条场记 | 离屏、看 6 米外 |
| 每场结束 | 口头报场次号给录音机、换卡入内袋 | 卡不混放 |
| 16:40 | 收工前 20 分钟跑空镜六条保底 + 环境声 | 见 [空镜与环境影像.md](空镜与环境影像.md) §8 |
| 18:00 | 回住处：入库 → 重命名 → 哈希 → 双备份 | 未完成不吃饭 |
| 19:00 | 转写 + 30 分钟内补场记与笔记 | 记忆过夜衰减 |
| 20:00 | 当日粗筛（留/废/待看）+ 明日 shot list ≤3 条 | 素材 >4 小时未标记则次日先清积压 |
| 21:00 | 设备充电、包按明日顺序归位；卡与备份盘分处 | — |
| 22:30 | 停屏。睡眠不足直接换算成明日废片率 | — |

## 11. 常见误区

| 误区 | 事实 |
| --- | --- |
| 「试录过了就不用回放」 | 不回放等于没测；最常见的损失是一整天的底噪 |
| 「回去再备份」 | 「回去再」是本表第一号事故原因 |
| 「卡上腾点空间没事」 | 只有 §3 四条同时成立才允许格式化 |
| 「有人要删，我当场删给他看」 | 停机是尊重，删除是处置，处置走流程不当场表演 |
| 「加密能挡得住调取」 | 加密防第三方取得当事人数据，不是对抗合法程序的理由 |
| 「夜间跟一段没事，我精神好」 | 视线、路况、判断力同时下降，且无人替你 |
| 「丢了素材记下来丢人，算了」 | 不记录的事故必然重演，记录才是专业 |
| 「近视就贴紧取景器」 | 越贴越累；改用外接监视器或不取景的固定机位 |

## 实操要点

- 出发前 20 项在住处做完；任一项缺就不出发。
- 门口停 5 分钟，按「环境音 → 读光 → 机位预演 → 许可确认 → 复述第一任务」顺序。
