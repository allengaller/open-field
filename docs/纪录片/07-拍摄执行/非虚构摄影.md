# 非虚构摄影

> 剧情片的摄影是把预设的画面拍出来，纪录片的摄影是在画面还不存在的时候等住它。这篇讲操作：机器在转的每一秒，你的注意力和身体该放在哪里。

本文与 [../03-电影语言/光线与色彩.md](../03-电影语言/光线与色彩.md) 分工明确：那篇讲影像作为一种语言（色温、色调、反差在表达什么），本篇讲现场怎么读光、怎么跟住光。器材参数一律交给 [../09-技术与设备/摄影机与镜头选择.md](../09-技术与设备/摄影机与镜头选择.md)，本篇只讲流程与判断。

## 1. 职责差异：从「设计画面」到「接管画面」

【通行共识】直接电影（Direct Cinema）传统的摄影师——Robert Drew 组的 Leacock、Pennebaker、Maysles 兄弟——的共同做法是：不布光、不排演、不机位调度，摄影机跟随事件。这不是穷困的美化，而是一条职责定义：**在纪实现场，画面是事件带来的，不是你放进去的。**

由此推出三条与剧情片相反的工作方式：

| 剧情片摄影 | 非虚构摄影 |
| --- | --- |
| 先设计构图，再让人走进画面 | 先知道人要去哪，再决定镜框给谁 |
| 灯光组控制光，摄影机只管接收 | 光在变，你必须在变之前调 |
| 现场可以 NG 重来 | 现场不能重来，废片即永久损失 |
| 摄影师听导演 | 摄影师自己判断「这一刻值不值得留」 |

## 2. 预判式摄影（anticipating）

【操作性建议】纪实摄影的胜负手不是手速，是理解。反应快只能拍到事件的第二秒之后；预判能拍到前因。具体训练法：

- **拍之前先问三个问题**：这件事谁是主体？主体下一步要起身、转身、伸手、递东西，还是离开？谁会被叫到名字？把答案变成身体准备——重心换到前脚掌、手指压在录制键附近。
- **用「动作序列常识」补时间差**：说「起」之后约 0.5–1 秒人开始动；问工资数额之前对方会先看一眼旁边的人；老板推门时最先抬头的是最近的那名员工；有人哭之前先有一段沉默加一次吸气。把这些规律记在脑子里，比记曝光参数更值钱。
- **让当事人替你预告**：现场最常发生的是「口述下一步」——「等会儿货车来了我们一起去卸」。听到这种话，立刻把它当作 shot list（分镜清单），提前 5 分钟到位。
- **预判失败的代价不对称**：早开机 5 秒浪费一点卡；晚开机 1 秒丢掉整段。所以任何预判失误都朝「早」的方向偏。

## 3. 开机先于事件

【操作性建议】纪实素材最大的损失来源不是拍糊，是**没录上**。摄影机从触发到真正写入有 1–3 秒的建立过程，而现场的关键动作常在 2 秒内完成；加上人从「注意到异常」到「手按下去」的反应时间，一次事件的损失窗口通常有 3–5 秒。三条抵消办法，按优先级：

1. **常开（run-and-roll）**：在低风险、低敏感、电力允许的场景里让机器一直转。工厂流水线、集市、走路、装卸、开车，都是常开的合法区间。代价是后期需要靠日志找点，所以常开必须配合场记（见 [../15-工具与模板/场记表与素材日志.md](../15-工具与模板/场记表与素材日志.md)）。
2. **预录缓存（preload / buffer）**：部分机型可保留开机前若干秒的画面。是否可用、可缓存多少秒属器材能力，去 [../09-技术与设备/编码存储与备份.md](../09-技术与设备/编码存储与备份.md) 与摄影机篇查；本篇只定纪律：**能开缓存就一直开**，并把「缓存时间」记进设备预设清单。
3. **两秒原则**：一旦出现任何异常信号（音量升高、有人起身、有人说反话、灯灭了、门外有响动），**先按录制，再决定拍什么**。按错了事后剪掉即可，没录上的事后再剪辑也变不出来。这条与 [不可重复事件现场.md](不可重复事件现场.md) 的极端情形一致，本篇负责日常版本。

敏感场景是这条例外的唯一理由：涉及他人隐私、儿童、就医、内部会议时，「常开」会让当事人误以为一切都被记录，反而压制真话。此时用短开短关，并把每次开关的时间点记进场记。

## 4. 实时取舍：一张优先级表

【操作性建议】构图可以放弃，焦点和曝光不能。现场冲突按此顺序解决，越靠前越不可让步：

| 序 | 优先级 | 允许的妥协 |
| --- | --- | --- |
| 0 | 人身安全（当事人与你自己） | 无。人优先于素材 |
| 1 | 录制没有断 | 无。宁可画面烂也要在录 |
| 2 | 焦点（主体是清晰的） | 无。失焦素材基本不可用 |
| 3 | 曝光（脸有细节、暗部不糊） | 无。后期救不回死黑死白 |
| 4 | 地平线水平、头顶留白 | 可在现场妥协，后期微调 |
| 5 | 构图美感、纵深、前景 | 随时可弃 |

【操作性建议】焦点失败是纪实素材最常见的废片原因，两个技术兜底：小光圈 + 超焦距（hyperfocal，把景深压到不需要跟焦的区间）；或在可接受范围内把主体距离固定（你自己站定、对方坐定）。**当「跟焦」和「换更好的构图」冲突时，永远选前者。**

## 5. 长镜头期间的画面责任

【操作性建议】镜头在转，责任没在休假。一个 10 分钟的长镜头里，摄影师要做四件事，按发生频率排序：

1. **跟焦**：主体每移动一次距离都要确认。景深浅时，「伸手递烟」和「靠墙坐下」这两个动作最容易跑焦。
2. **跟光**：云、屋檐、门、车影都会改亮度。每 30–60 秒扫一眼曝光指示；不要等自动曝光把脸拍成剪影。
3. **重新构图**：新人物入画、有人挡在中间、主体走出画框——这三类必须处理。原则是**让观众的视线有地方放**：给说话者的视线方向留出空间（looking room），比把两人排得好看更重要。
4. **不要越轴**：同一场戏里换角度时保持左右关系一致，否则后期剪不成对话。纪实里不能喊停，所以只能靠你不动或绕大半圈。

【通行共识】长镜头的价值在于时间的连续，不在镜长本身。**为了「长」而不肯停机，会把可用素材变成不可剪素材**——一段 12 分钟里有 8 分钟是无事发生的等待，剪辑时它就是垃圾。判断依据：这段是否含至少一个不可重复的瞬间。

## 6. 不干预与不成为障碍

【操作性建议】「不干预」是不改变事件的走向；「不成为障碍」是不降低现场质量。前者是伦理，后者是技术。身体管理的具体项：

- **位置**：进场后先定一个「不挡动线」的位置并记住它。人流动线（门口、过道、装货口）永不占；墙边、柱后、门口斜外侧可以占。移动前想清楚往哪退，别在事件高潮时挪。
- **影子**：你的身体一定会进画面或进光路。测一遍：站在机位上，看你的影子落在地上还是落在主体身上。落在主体上就换角度，或者把机位抬高。
- **呼吸与说话**：录制中不评价、不笑出声、不复述对方的话（见 [../06-采访方法/提问与追问技术.md](../06-采访方法/提问与追问技术.md)）。想问问题就等段落结束，或者把问题写成下一场的开场。
- **衣服**：穿与现场环境同明度、低彩度的衣服，避免纯白（反光进画面、破坏曝光）与强色（在浅景深里也会抢注意）。工厂、工地、车间一律避免反光条与金属饰件。
- **鞋子**：木地板、碎石、老屋楼梯的鞋噪直接进同期声。软底、无金属跟、无硬塑料底，是长期跟拍的必备。这是被大量拍摄者低估的一项。
- **机器贴脸**：能贴身的挂法（颈挂/胸挂）比手举更不压迫现场，见 [一人团队与单机作业.md](一人团队与单机作业.md)。

## 7. 光线的现场读取与迁移

【操作性建议】纪实现场的光不能布，只能读和跟。四步：

1. **进场 30 秒读光**：主光从哪来（窗、天窗、日光灯、手电）、强度差多少（室内与门口常差 3 档以上）、色温混不混（日光 + 钨丝灯同框，白平衡只能取一边）。
2. **定一个「曝光锚」**：把人脸的曝光锁为基准，之后只允许在这个基准上下浮动一档。**宁可欠半档也不要过曝**：纪实高光溢出不可挽回。
3. **跟位移**：同一场戏里人物从窗边移到门口、从室内走到走廊，就是三次曝光调整。提前告诉对方「我去那边拍你」，让位移变成你的调度而非意外。
4. **处理遮挡**：云、柱子、车、人，都会造成瞬间明暗跳。跳变超过两档时优先跟人脸；跟不住就把这段留成「光的真实变化」，不要在镜头里猛调参数。

【操作性建议】同一地点不同时间的差别值得记录：早/中/下午/夜各拍一次同景，作为固定机位重拍法的副产品（见 [空镜与环境影像.md](空镜与环境影像.md) §5）。

## 8. 多人场景：谁在被看

【操作性建议】多人现场的难点是「该拍谁」。三条判定：

- **谁在说话不重要，谁在被看很重要。** 群体里所有人视线聚焦的那个人，是这一秒的戏剧主体，即使他一个字没说。
- **权力关系决定重心。** 中国现场的常见结构：老板说话，工人沉默看老板；工人说话，老板看手机。前一种拍工人；后一种拍老板。
- **反应优先于发言。** 发言者你已经有了，反应只有这一次。见 §9。

【操作性建议】单机位时不要追镜头扫全场。定一个能同时容纳关键两人、且留出第三人回头空间的机位，让画面内调度代替摄影机运动。

## 9. 拍反应：纪实摄影的第一优先

【通行共识】反应（reaction）镜头是纪实影像不可替代的部分：语言可以重复，脸上的那一下不能。剪辑时一个反应镜头能改写前一句话的意思。

【操作性建议】五个固定执行时机，练成条件反射：

- [ ] 有人说完一句自我评价（「我这边做得最差」）——立刻看听者。
- [ ] 报出一个数字（工资、产量、面积、赔款）——看旁边人的表情。
- [ ] 被问到无法回答的问题——看谁替他回答，以及他自己怎么接。
- [ ] 有人哭、笑、骂、沉默超过三秒——不要停机，不要换景别。
- [ ] 主角离场/进门/转身——这三件事各有一次可拍的表情窗口。

## 10. 横屏、竖屏与双机位

【操作性建议】画幅在现场一次决定，事后不改。判断顺序：

| 问题 | 决定 |
| --- | --- |
| 这段需要横向关系（谁站在谁旁边、空间布局、并排坐）吗 | 横屏 |
| 这段的核心是一张脸的手持特写，或口播式讲述吗 | 竖屏 |
| 这段要在 B 站/长视频做正片，也在抖音/视频号分发吗 | 横屏拍，后期裁切；构图把所有关键动作压进中部 9:16 区 |
| 事件会发生在镜头左右两侧吗 | 横屏 |

单机位时**不做竖屏正片**——竖屏裁掉的正是纪实最有价值的空间关系。双机位（一部固定 + 一部跟）只在你确定「这场戏丢了不可惜」时才启用：多一台机器意味着多一份注意力、多一份同步与备份负担，见 [一人团队与单机作业.md](一人团队与单机作业.md) §1 与 §11。

## 11. 丑但必要

【操作性建议】判定顺序：先看这段是不是**不可重复的事实证据**，再谈它好不好看。

- 丑但必须留：当事人签字、被磨破的手、事故现场、欠薪的账本、医院走廊的等待、临时住的铁皮棚。这些是内容的骨架，删了就等于主张没有证据。
- 丑且可弃：抖动到无法辨认、主体完全出画、全程失焦且无信息量。
- 例外（不属「丑」，属「不该拍」）：他人的痛苦被拍成奇观、死者、可识别未成年人、就医细节。这类素材不是画质问题，是使用问题，处置见 [../10-伦理法律/弱势群体与儿童.md](../10-伦理法律/弱势群体与儿童.md) 与 [不可重复事件现场.md](不可重复事件现场.md) §7。

## 12. 每日拍摄量的健康纪律

【操作性建议】本节是给「一个人、戴深度近视、一天拍 6–10 小时」的读者的硬性约束，与 [../../研究/行动总纲.md](../../研究/行动总纲.md) §8.2 的身体风控一致：出现视力模糊、头痛、眼干即终止当日计划。

- 盯取景器/监视器**每 45 分钟强制离屏 5 分钟**，看 6 米外；晚间剪片每 50 分钟起身一次。
- 单日屏幕累计（拍摄 + 剪辑）不超过 10 小时；连续高强度跟拍不超过 6 天，第 7 天不安排开机。
- 长焦手持与脚架高举交替，避免同一颈肩姿势维持超过 20 分钟；取景替代方案（外接监视器、不戴眼镜策略）见 [现场工作流与安全.md](现场工作流与安全.md) §7。
- 电量与存储的休息同步纪律：换电池就是你的 90 秒休息，不要用来刷屏幕。

## 13. 非虚构摄影十条现场戒律

1. 先按录制，再决定构图；两秒原则高于一切美学。
2. 焦点与曝光不让步，构图与水平可以让步。
3. 镜头在转，你就在上班：跟焦、跟光、重新构图，不许松。
4. 拍反应优先于拍发言。
5. 不挡动线，不投影子，不出声，不评价。
6. 光不能布，只能读；先定人脸这个曝光锚。
7. 宁可欠曝半档，不要过曝一档。
8. 预判来自理解现场，不来自手速。
9. 丑但必要的证据，不许因为不好看而丢掉；该停的痛，不许因为珍贵而不肯停。
10. 身体是这台机器最贵的部件，45 分钟一次，不许违约。

## 14. 常见误区

| 误区 | 事实 |
| --- | --- |
| 「拍纪录片靠反应快」 | 靠预判与常开；反应快只能拍到第二秒 |
| 「构图可以后期再裁」 | 裁掉的正是空间关系；现场没留够就永久没了 |
| 「画面糊了重拍一遍」 | 同期声不可重拍，事件不可重拍，能重拍的只有空镜 |
| 「越长的镜头越真实」 | 长镜头的价值是时间连续，不是时长 |
| 「光线不够就加灯」 | 加灯会改变现场行为；先读光、跟光，最后才考虑补光 |
| 「先拍好看的环境」 | 环境是副产品，人和事才是主体；空镜见另一篇 |
| 「反应镜头等下补」 | 反应只有当下一秒有，第二天补出来的不是反应 |

## 实操要点

- 开机永远早于事件：常开 + 预录缓存 + 两秒原则，三样同时启用，敏感场景例外。
- 冲突解决用固定优先级：安全 > 在录 > 焦点 > 曝光 > 水平 > 美感；前三项零妥协。
- 长镜头里做四件事：跟焦、跟光、重新构图、不越轴；每 30–60 秒扫一次曝光。
- 身体管理六项：位置、影子、呼吸、衣服、鞋子、挂法；其中鞋噪最易被忽略。
- 进光现场先定「人脸曝光锚」，只允许一档浮动；位移即调光。
- 多人场景看谁被看、看权力关系，五个反应时机练成条件反射。
- 横竖屏现场一次定；单机位不做竖屏正片；「丑但必要」按证据价值判，不按美观判。
- 每 45 分钟离屏 5 分钟，连续跟拍不超 6 天，视力模糊即收工（对齐 [../../研究/行动总纲.md](../../研究/行动总纲.md) §8.2）。
