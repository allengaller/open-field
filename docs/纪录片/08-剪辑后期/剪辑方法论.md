# 剪辑方法论

> 剧情剪辑是执行，非虚构剪辑是发现。素材在你动手之前已经把可能的结构限定死了，你能选的只有它允许的那几种。

本篇管判断，不管工序。工序（阶段划分、通过条件、版本记录）在 [粗剪到精剪](./粗剪到精剪.md)；把素材摊到桌面上比顺序的方法在 [纸剪与结构重组](../05-叙事结构/纸剪与结构重组.md)；镜头之间的语法（动作匹配、J/L-cut、跳切的合法性）在 [蒙太奇与长镜头](../03-电影语言/蒙太奇与长镜头.md) §5。本篇只回答一件事：面对一堆已经拍完的东西，一个判断凭什么成立。

## 1. 根本差异：谁先存在

| | 剧情剪辑 | 非虚构剪辑 |
| --- | --- | --- |
| 剧本 | 先于拍摄存在 | 后于拍摄被你写出来 |
| 覆盖比（shooting ratio） | 通常 4:1–10:1，每拍一条都有替代方案 | 一部长期跟拍可到 50:1 以上【操作性建议】，且没有替代方案 |
| 废片 | 可重拍，所以可弃 | 不可重拍，所以「废」字要重新定义 |
| 剪辑师的角色 | 实现既定意图 | 找出素材里已经存在但没人知道的意图 |
| 判断的对象 | 这条表演对不对 | 这件事实际是怎样的 |
| 失败模式 | 戏没拍出来 | 你剪出了一个现场没有的版本 |

由此得到第一条纪律：**不要用「素材没给到我想要的」来描述处境**。素材没给，说明你对这件事的假设错了，而不是它错了。正确的动作是回去读转录、重排卡片，不是去补一个你想要的镜头。补拍可以补信息，补不出已经过去的因果。

一人团队还要再加一句：你就是那个「没有剪辑指导」的人。剧情片剪辑有导演在旁边兜底，非虚构单人创作者唯一的兜底是**可回溯**——每个切点能说出理由，说不出就当作不存在。

## 2. 节奏由什么决定

节奏不是快慢，是变化的分布（这一点 [冲突悬念与信息节奏](../05-叙事结构/冲突悬念与信息节奏.md) §5 已展开，此处只取剪辑结论）。纪实素材的切点有三个合法依据，按可靠性排序：

1. **呼吸与话尾**：一句重话说完之后的那半口气，是最自然的切点。它的价值不在好看，在于它把「这句话落完了」交给了观众。提前切走，观众没接住；拖太久，你在等他哭。
2. **动作与空间事件**：门推开、机器停转、秤归零、手离开纸面。动作完成的瞬间切，观众不觉得有剪刀。
3. **信息密度**：一个新信息点落地之后可以给 2–3 秒空场（每 90 秒新信息不超过 3 个的原则见 [冲突悬念与信息节奏](../05-叙事结构/冲突悬念与信息节奏.md) §7）。密度决定的是段落长度分布，不是单个切点。

**配乐鼓点不是节奏依据。** 用鼓点定切点等于把结构外包给一段与现场无关的录音。判据：把音乐静音，段落边界是否还在。不在，那这个段落本来就不成立（同 [声音设计](../04-声音/声音设计.md) §3 的「纯声音小样」检验）。

## 3. 最好的版本是删出来的

组装剪（assembly edit）的长度通常是成片的 3–6 倍（工序定义见 [粗剪到精剪](./粗剪到精剪.md) §2）。这个数字的含义不是「要多剪几刀」，而是：**从组装剪开始，你唯一的工作是减法。**

加法冲动有三种，都必须在结构剪阶段禁掉：

- 加空镜补过渡 → 过渡本来不该存在，这段和那段之间可能没有因果关系。
- 加解说补信息 → 画面不承重。缺的是素材或结构，不是字。
- 加音乐补情绪 → 你在替现场没有的情绪作证（见 [音乐与版权](../04-声音/音乐与版权.md) §1 反面清单）。

删的顺序固定为「最贵 → 最好 → 最爱」，判据是「有没有别处能替代」，方法见 [纸剪与结构重组](../05-叙事结构/纸剪与结构重组.md) §7，本篇不重复。补充一条剪辑台独有的判据：

> **这一刀是否改变观众对事实的理解？**

它和「好不好看」完全不是一回事。三种典型情形：

| 情形 | 删还是留 | 理由 |
| --- | --- | --- |
| 六秒的沉默，期间他把手边的杯子转了半圈 | 留 | 观众读到的是「他不想说」，这是事实的一部分 |
| 同一段话里最清晰的一句，但从另一次录音里挑出来拼上 | 不拼 | 音色、房间、气息全部错位，你造了「他当场说了这句」 |
| 解释清楚流程但拍得很平的三分钟固定机位 | 压缩，不删 | 信息必须落地；用字幕交代跨度而不是靠镜头撑 |
| 最好看的一个逆光剪影，讲的是另一件事 | 删 | 它把片子从 A 议题拽到 B 议题 |

## 4. 忠于现场的边界

可以做的（不改变事实的理解）：

- 调整场景顺序，前提是不制造新的因果（「先看到结果、再回头给原因」是叙述策略，「因为 A 所以 B」是主张）
- 压缩时间，并在跨度可能误导时用字幕交代
- 去掉口癖、重复、礼貌性寒暄——这是可读性处理，不是篡改
- 同一场内合并两次讲述的**同一段内容**（且标注「某日某地」不精确）
- 选择更好的那条表演——非虚构里没有「更好的表演」，只有**更少自我意识**的那条

不可做的（改变了观众接收到的主张）：

| 手法 | 观众收到什么 | 你为什么不能做 |
| --- | --- | --- |
| 把 X 的问话接在 Y 的回答前 | X 与 Y 交谈过 | 你造了一场没发生的对话 |
| 在人说好消息之后接坏消息的脸 | 有人为此受害 | 这是因果暗示，需要证据支撑 |
| 补读、顶替听不清的同期声 | 这句话在现场被说出 | 见 [声音设计](../04-声音/声音设计.md) §9 |
| 用搬演、情景再现但不用明确标识 | 这是当时的画面 | 边界与标识要求见 [真实契约](../01-理论/真实契约.md) §5 |
| 把跨数月的素材剪成「同一天」 | 一天之内发生了这些 | 时间跨度是事实，不是包装 |

原则一句话：**你可以决定观众什么时候知道，不可以决定他知道的是什么。**

## 5. 情绪连续性优先于轴线严谨

剧情片有第二次机会：越轴了可以补一条、可以挪机位。纪实现场没有。所以优先级要反过来——

**一场戏里，「这个人的状态有没有被连续地呈现」比「视线方向、银幕方位是否严格一致」更重要。** 具体取舍【操作性建议】：

- 一个人从克制到崩溃，中间那条「还在忍」的镜头即使机位跳、景别不理想，也要留。删了它，观众看到的是「他忽然就哭了」，那是对他的第二次伤害。
- 反之，两个不同天拍的素材，情绪强度接近、内容承接自然，可以直接相接，不需要为「同一天」多插一张字幕卡。
- 唯一不许让步的是**归因**：情绪连续性可以跨时空拼，但「让他产生这个情绪的事」必须是他当场说过的、或画面里确实发生的。把 A 天的眼泪接在 B 天的坏消息之后，即使情绪真实，因果是你给的。

## 6. 工作法：先跑快，再跑准

solo 可执行的四轮读法【操作性建议】，每轮只做一件事，不许合并：

1. **3 倍速通读全部素材**，不剪、只打点。目标是知道「有什么」，不是判断「好不好」。素材按场次顺序过，每场打一个「这里有事/这里没事」。倍速下语音听不清没关系——你已经有转录（[纸剪与结构重组](../05-叙事结构/纸剪与结构重组.md) §2），这一轮测的是视觉密度与事件分布。
2. **只看每场最好的那条。** 非虚构里「最好」的定义是**自我意识最低的一刻**：他忘了机器在转、话说得最不整齐、笑最难看的那条。同一件事他讲过三遍，通常第一遍最警惕、第三遍最疲惫，第二遍往往是最好的。选完就在日志里写死「本条为主条」，之后的调整都在主条内部做。
3. **静音看一遍。** 查画面是否承重。静音状态下看不懂在讲什么的地方，是画面缺口，不是解说缺口。
4. **只听声音版。** 用 [声音设计](../04-声音/声音设计.md) §3 的声音小样，听段落边界是否自然。

第三、四轮各花不了二十分钟，但它们是唯一能在放映之前发现「这条片子离开解说就不成立」的手段。

## 7. 试映：问哪三个问题

工作版放映（work-in-progress screening）的对象是 3–5 个没看过素材的人，看的是粗剪或结构剪。纸剪阶段有另外五个问法（测「未决问题有没有传到」），见 [纸剪与结构重组](../05-叙事结构/纸剪与结构重组.md) §9；本篇的三问在素材已经变成时间线之后问，测的是**事实有没有落地**：

| 问 | 它在测什么 | 听到的答案怎么用 |
| --- | --- | --- |
| 「看完你能说出这个人的处境哪里变了吗？变好还是变坏？」 | 事件有没有推进；你的论点是否需要你口头解释才成立 | 说不出「变化」，就是结构剪要处理的段落问题 |
| 「哪一处你觉得画面和话对不上，或者觉得我在替你下结论？」 | 可信度与立场暴露，也就是第 4 节的边界有没有漏 | 记时间点，不解释、不辩护 |
| 「从哪一秒开始，你不再觉得这是素材，而是在看一条片子？」 | 契约生效点：观众什么时候接受了你的叙述 | 这个点之前是你的问题——开头没进去；找不到这个点说明全片都是素材堆 |

**为什么不能问「好不好看」。** 三个理由，都不是客套问题：

1. 工作版没有可评判的完成度——声音是临时混的、字幕是草稿、调色没做。对方只能拿「像不像成片」打分，那不是你要的信息。
2. 「好看/不好看」是一个总评，总评不可执行。你不能因为「不好看」去改第四十分钟。
3. 它会引发辩护。你一解释，对方就从观众变成评审，之后所有反馈都是礼貌的。

同样不要问引导性问题（「这里是不是太长」「你觉得感人吗」）。规则与纸剪一致：只记原话与时间点，同一位置被三次放映重复提到才动。

## 8. 一个人可跑的迭代循环

【操作性建议】每轮两到三天，一轮只做一件事：

| 步 | 动作 | 时间 | 产出 |
| --- | --- | --- | --- |
| 1 | 放映（对 1–3 人，不解释，直接放） | 60–90 分钟 | 对方在场时的反应 |
| 2 | 放映后 10 分钟内记点位：只写时间戳 + 现象 | 20 分钟 | 一份点位表 |
| 3 | 分类：每个点位归入「事实不清 / 段落不承重 / 节奏拖 / 只是我不满意」 | 30 分钟 | 前两类才处理 |
| 4 | 只改结构性问题，不改台词、不加东西 | 半天 | 下一版 |
| 5 | 记录本版改了什么、为什么改（版本记录表见 [粗剪到精剪](./粗剪到精剪.md) §10） | 10 分钟 | 可回溯 |

**沉默与走神的点位怎么记。** 放映时你在场，但尽量不解释。可记的观测点：说话的人停止说话（不是片子停了）、身体后靠或拿起手机、笑出现在你没预期的位置、有人开始问「这是什么时候拍的」。这些都算一个时间戳。**你自己打字的停顿也算**：如果你发现某一处你忘了记，多半那里观众整体掉出去了。

改到第几轮该停：同一处连续两轮改动都让你不满意，说明你不知道要什么，别再修——去放映（判据见 [粗剪到精剪](./粗剪到精剪.md) §9）。

## 9. 常见误区

| 误区 | 事实 |
| --- | --- |
| 从最好看的一镜开始剪 | 先被看到的素材会伪装成结构（[纸剪与结构重组](../05-叙事结构/纸剪与结构重组.md) §1）；从事件最强的场次开始，会让全片变成高潮之后一路下滑 |
| 以为节奏问题可以用音乐解决 | 音乐填的是内容洞；静音检验（第 2 节）会立刻揭穿 |
| 剪不动时加东西 | 加空镜、加解说、加字幕卡都是加法冲动（第 3 节） |
| 把「贵」当「重要」 | 蹲了四天的素材在片子里的功能可能只是交代一句时间 |
| 追求轴线、构图绝对严谨 | 纪实里不可重拍；情绪连续性优先，除了不许造归因（第 5 节） |
| 试映前先自我导览一遍 | 等于请人给你的结论盖章，三问全部失效 |
| 按观众反馈逐条改 | 只改重复出现的位置；单个观众的偏好不是证据 |
| 相信「最后一版再说」 | 没有 picture lock 的意识，永远在改第 4 分钟，第 40 分钟没人看过（锁版条件见 [粗剪到精剪](./粗剪到精剪.md) §6） |
| 用 AI 摘要决定取舍 | 摘要是别人对素材的理解，判断权与署名都是你的（[纸剪与结构重组](../05-叙事结构/纸剪与结构重组.md) §2 红线） |
| 认为剪辑伦理是技术问题 | 「顺序可以调、因果不能造」是承诺问题，见 [真实契约](../01-理论/真实契约.md) |

## 实操要点

- [ ] 剪之前先做完一轮 3 倍速通读 + 「只看主条」选择，并在日志里把每场主条写死，之后只在主条内部调整。
- [ ] 每场只问一句：「这一刀是否改变观众对事实的理解？」答案影响事实理解的改动全部回滚。
- [ ] 结构剪起禁止加法：不加空镜、不加解说、不加音乐；想用音乐时先静音检验段落是否仍成立。
- [ ] 情绪连续性优先于轴线与景别严谨，唯一不让步的是归因——不许把 A 天的反应接在 B 天的事件后面。
- [ ] 每轮迭代固定跑「放映 → 10 分钟内记时间戳 → 只改结构性问题 → 写版本理由」，一轮只改一类问题。
- [ ] 试映只问三句（处境变了什么 / 哪里觉得我在下结论 / 从哪一秒开始像在看法片），不问「好不好看」，不先解释。
- [ ] 每版导出前记录改动清单与理由；连续两轮在同一处不满意即停手去放映。
- [ ] 与结论相反的证据、当事人的犹豫与沉默，保留在观众记得住的位置，不当作废片处理。
