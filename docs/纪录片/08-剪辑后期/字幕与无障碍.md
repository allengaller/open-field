# 字幕与无障碍

> 在纪实内容里，字幕不是附加层，是内容层。方言、口音、嘈杂现场加上手机外放的静音观看，意味着没有字幕的片子有一半观众根本没接收到。

本篇管三件事：转写与校对流程、字幕样式规范、无障碍完整度。术语交代方式（什么时候让人物自己解释、什么时候用字幕卡）见 [冲突悬念与信息节奏](../05-叙事结构/冲突悬念与信息节奏.md) §7，解说文本本身见 [解说词写作](../05-叙事结构/解说词写作.md)。工序位置在调色与终混之后（[粗剪到精剪](./粗剪到精剪.md) §7）。

## 1. 为什么是刚需

| 条件 | 后果 | 字幕承担什么 |
| --- | --- | --- |
| 方言与地方口音 | 跨地区观众直接听不懂（粤语、客家话、各地方言词汇） | 唯一的信息通路，不是补充 |
| 车间、菜市场、婚宴音响 | 同期声可懂度天然受限（[同期声与收音](../04-声音/同期声与收音.md)） | 补救听不清，而不是补救没录到 |
| 手机外放与静音观看 | 大量观看在公共场合、外放音量低或直接静音 | 静音状态下字幕即全片 |
| 专有名词与数字 | 人名、地名、金额、日期极易听错（同音字最多） | 书面固定，避免误听导致误解 |
| 听障观众 | 无字幕等于没有内容 | 法定与伦理层面的接入义务（§7） |

一条纪律先说清：**字幕不能补画面没有的事实。** 它转录「说过的话」与「看得见的信息」，不补充解释、不做订正、不加你没有证据的判断。想在字幕里交代背景，那是解说词或说明卡的工作，且要遵守同一套证据纪律（[解说词写作](../05-叙事结构/解说词写作.md) §8）。

## 2. 转写流程：AI 转写 + 人工逐条校对，绝不直接发布

流程五步【操作性建议】：

1. **机器粗转**：全片语音一次性转写，产出带时间码的文本（工具与批量做法见 [AI工具链](../09-技术与设备/AI工具链.md)）。目标是能读，不是能用。
2. **术语预校正**：先跑项目词表替换（[素材管理与日志](./素材管理与日志.md) §5），把行话、人名、地名、数字的常见误转批量改掉。
3. **人工逐条校对，带音频**：不许只看文本校对。只读文本会把错的字当作通顺的话放过——**必须让耳朵参与**，因为你判断的是「他实际说了什么」。
4. **不确定即标注**：听不出的地方写 `[不清]` 或 `[听不出]`，不猜。猜出来的字会以「原话」的身份进入全片，之后无法追溯。
5. **交叉听**：关键指控、数字、金额、日期段落由第二人独立听一遍再定稿。当事人陈述类素材不接受单源定稿。

**为什么方言与专名必错**（通用语音模型的结构性弱点，不是「再优化一下就好」）【通行共识】：

| 错误类别 | 机制 | 纪实内容里的表现 |
| --- | --- | --- |
| 同音/近音替换 | 模型按普通话高频词序列最大化概率 | 「计件」→「计剑」；「押两个月」→「压」 |
| 方言词被映射成最近的普通话词 | 训练分布以标准语为主 | 方言语气词被吞、方言动词被替换成书面近义词，**说话人因此消失** |
| 专名（人名/村名/厂名） | 不在词表内，只能按音拼 | 「白石洲」写成「白石周」；当事人名字写错，是不可撤回的冒犯 |
| 数字与量词 | 语音形态多样 | 金额、日期、吨位错一位，事实级别出错 |
| 沉默、插话、重叠说话 | 端点检测与说话人分离失效 | 把两人的话并成一人，或把停顿填成一句不存在的话 |

第四、五类最危险，因为它们改变的是**谁说了什么**。这也是「绝不能直接发布」的核心理由：机器转写不只是错字，它会错误归属。

红线与纸剪阶段一致：AI 可以帮你生成清单，不能替你判断哪句是真的、哪句承重（[纸剪与结构重组](../05-叙事结构/纸剪与结构重组.md) §2）。字幕稿的每一条引文要能回指素材时间码。

## 3. 样式规范

【操作性建议】以下是一条可在项目里固化的默认，随平台显示区调整；调整的依据只有一个——在真机上、把片子放在最大声源的环境之外看一遍。

| 项 | 规范 | 理由 |
| --- | --- | --- |
| 行数 | 不超过 2 行 | 3 行开始遮挡画面与人脸表情 |
| 单行字数 | 中文约 12–16 字为上限，宁短勿长 | 手机屏宽下超过这个量会换行或缩成一条带 |
| 停留时间 | 按阅读速度给足，短促语气词也不低于约 1 秒；不因音频结束而立刻消失 | 观众读得比听得慢；一句读不完就消失，等于没有 |
| 断句 | **按语义断，不按标点断** | 逗号位置断句会把「两个月，押」这样的短语切散，逼观众重读 |
| 位置 | 底部安全区内，避开说明卡、门牌、文件特写、字幕条、台标 | 纪实画面里的文字常就是证据，压住它就压住了论点 |
| 字号与描边 | 与任何背景都有足够对比；细描边或半透明底二选一，不叠加装饰 | 可读性优先于美观；装饰性阴影在手机上会糊 |
| 说话人切换 | 换人时另起一条，不同说话人不混在一条里 | 混排会让观众误判是谁说的，这与错误归属同级 |
| 歌曲/广播 | 现场播放的歌词、广播内容需区分标注 | 它们是同期声层的来源信息（[声音设计](../04-声音/声音设计.md) §2） |

排版纪律：**不要为了卡住时间点而截断句子**。宁可让字幕跨一个切点存在（J/L-cut 处字幕延续），也不把一句完整的话劈成两半。

## 4. 说明卡：lower-third 与 supercard

说明卡（lower-third，画面下方人名/身份条）与 supercard（画面上的说明字幕）在纪实里有三个合法功能：交代说话人身份、交代时间地点、交代画面里看不出的必要背景。

克制的判据【操作性建议】：

- 一张 10 分钟的单集，说明卡用量在个位数；超过十张说明结构有问题（同 [冲突悬念与信息节奏](../05-叙事结构/冲突悬念与信息节奏.md) §7 的字幕卡判断）。
- 一个人**首次出现时给一次**，之后再出现不重复给；换场、换日后重复给会让观众以为换人了。
- 身份描述写事实，不写评价。写「车间主任」可以，写「坚守二十年的老师傅」不行——后者是你的判断，需要解说或画面承担（[解说词写作](../05-叙事结构/解说词写作.md) §9）。
- 存在时间足够读完，且不许出现在有信息的面部动作上。
- **不许用说明卡补足画面没证明的因果**：「搬迁之后他没拿到钱」若来自转述，就该以他自述+时间标注呈现，不该做成看似客观的说明卡。

说明卡的视觉设计与位置避让与调色一并处理（文字可读性是调色的两条硬线之一，见 [调色与画面处理](./调色与画面处理.md) §1）。

## 5. 说话人标注与化名制度

字幕是化名制度最容易破口的地方，因为它是**明文写入并被平台索引**的文本。

- 对白字幕、说明卡、片尾名单一律使用化名编号后的对外形式；真名不进任何字幕文件与烧录版本。真名 ↔ 化名的映射表加密存放、在项目目录之外（[素材管理与日志](./素材管理与日志.md) §6；PRINCIPLES §2.4 真名静态加密、分析层默认只见化名）。
- 标注口径要统一：一个人不能在对白字幕里是「老周」、在说明卡里是「周某某」、在片尾是「周某」。三种写法会被拼出真身。
- 若当事人明确要求用真名，须在知情同意里留下可回溯记录，并意识到撤回时的影响面（字幕文件与烧录版本都要处理）。授权与撤回流程见 [知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md)。
- 涉未成年人、就医、纠纷他方等情形，默认全部匿名化到「某某，某厂工人」这一级；能否使用可识别信息不属于字幕决定，回伦理与法律篇判断。
- 撤回发生时的处置：从对白字幕、说明卡、导出、烧录版四处同时移除（缺一处即为未执行），并登记处理记录。

## 6. 烧录字幕（burn-in）与软字幕

| | 烧录（burn-in） | 软字幕（sidecar / 平台字幕轨） |
| --- | --- | --- |
| 可控性 | 完全可控，任何终端都在 | 依赖平台是否启用、观众是否打开 |
| 观感 | 压在画面上，字号与位置由你定死，无法关闭 | 可关、可缩放，部分平台样式不可控 |
| 二次分发 | 随画面走，删不掉（包括你的署名与免责信息也一起被搬走） | 复制画面时通常丢失 |
| 修改成本 | 每次改动要重出整片 | 改字幕文件即可 |
| 无障碍 | 对静音观看有效；对读屏/语控无帮助 | 平台可索引用，屏幕阅读器与自动翻译可能依赖它 |

推荐做法【操作性建议】：

1. **母版一律无字幕（clean master）**，这是硬要求；字幕版本另存另出（版本体系见 [交付母版与规格](./交付母版与规格.md) §1）。没有干净母版，日后任何改动（换化名、撤一句话、改字体）都得从调色重做。
2. 长视频优先软字幕 + 上传字幕文件；短视频/竖屏可用烧录，因为自动播放与静音观看占比高、平台字幕轨显示不可控。
3. 同时给软字幕与烧录时，接受「两套文本会漂移」的成本：以字幕文件为准，每次改都同步重出烧录版。
4. 烧录版上的署名与来源标注要写全，因为这一版最容易脱离你的控制传播；不要写入当事人可识别信息。
5. 不要在平台压缩下赌字号：先传一版在目标平台真机上检查是否被压糊、是否被 UI 遮挡（平台压缩与裁切是事实风险，但不提供规避审核的做法；规格核对见 [交付母版与规格](./交付母版与规格.md) §3）。

## 7. 无障碍完整度

### 7.1 听障字幕不只是对白

给听障观众的完整字幕需要包含**非语句信息**，否则你只交付了一半内容：

- 说话人切换提示（谁在说，尤其画外）；
- 承担信息的环境声与音效：`[冲床停]`、`[远处鸣笛]`、`[秤的蜂鸣]`、`[门被推开]`；判断标准同画面——**它是否承载信息**；
- 音乐的出现与来源：`[收音机里播放××]`（现场来源要标明，因为它属于同期声层）；
- 笑声、哭声、沉默这些改变语义的声事件。

写法统一（方括号、短语、现在时），不要一会儿 `[音乐起]` 一会儿 `(配乐)`。

### 7.2 口述影像（audio description）

口述影像是为视障观众补一条「讲清画面里发生了什么」的旁白轨。现实判断：它需要独立录音、独立时间轴与额外一次混音，**对 solo 创作者是最高成本的无障碍项**。可行的处置【操作性建议】：

- 优先级排在听障字幕与可读性之后；先把字幕做完整。
- 如果长期作品要做，选一部代表作做一版，而不是承诺全系列。
- 低成本变体：一条「文字版/图文版」配套发布（关键画面截图 + 事实说明），并在正片里说明这是替代通道。这不是口述影像，不要宣称是。
- 与展映、社区放映结合（[社区放映与参与式传播](../12-发行传播/社区放映与参与式传播.md)），现场解说比后期旁白便宜。

### 7.3 色彩、对比与频闪

- **闪烁与频闪风险**：纪实素材里的现场闪光（焊接、频闪灯、警灯、相机闪光、日光透过转动的风扇叶）以及后期做的明暗闪烁转场，都可能对光敏性观众造成风险。**做法**：避免高频率的明暗交替；无法避免时在片头给光敏性提示。通行无障碍规范中一般以「一秒内不超过三次明暗变化」作为闪烁上限的参照，具体阈值与测试方法请按你所依据的现行规范原文复核【操作性建议·请复核】。
- 不要用纯红/纯绿的高饱和图形承载信息（色觉差异）；给图形同时加形状或文字区分。
- 字幕与说明卡的对比度在手机最低亮度下也要够（[调色与画面处理](./调色与画面处理.md) §8 的出口前扫描）。
- 转场不要依赖颜色变化传达语义（「红色代表停工」这类编码需要文字并列）。
- 关键数据不要只画在小图里；给出可放大的版本或直接在正文写出数值。

## 8. 双语字幕在 P1 阶段的处置

本项目 P1 为中文先行，英文是推迟而非放弃（[../../../PRINCIPLES.md](../../../PRINCIPLES.md) §4）。字幕侧的处置三条【操作性建议】：

1. **P1 只做中文字幕**，不因为「顺手」机翻一层英文一起发。机翻英文进入公开内容即为翻译债的伪完成。
2. **每笔推迟记录在案**：在项目里维护一份 `字幕双语债.md`，写明哪一条已发布内容缺英文版、需要的是哪种（对白字幕 / 口播 / 说明卡），国际化启动后逐项清。
3. **技术上不锁死自己**：中文烧录会占用画面底部安全区——若日后要出英文版，双语并排可能需要更多空间。做法是母版保持无字幕（§6 第 1 条），字幕位置预留双语扩展余地，不要在最底部边缘压死。

发布内容的语言分层（开发日志、演示、田野视频中文先行）与英文口播版本的启动条件，以宪法 §4 为准；本篇不重复规定。

## 9. 常见误区

| 误区 | 事实 |
| --- | --- |
| 机器转写完直接上 | 错的不只是字，还有「谁说的」（§2） |
| 只校对文本不听音频 | 通顺的错字最容易被放过（§2 第 3 步） |
| 听不出就按语境补一个字 | 它以原话身份进入全片且不可追溯；写 `[不清]` |
| 方言「翻成通顺普通话」 | 丢的是说话人；优先保留原话 + 字幕译文（[冲突悬念与信息节奏](../05-叙事结构/冲突悬念与信息节奏.md) §7） |
| 字幕补画面没证明的事实 | 字幕不是证据层，那是解说或说明卡的工作且有证据纪律（§1、§4） |
| 按标点断句 | 语义被切碎，观众要重读（§3） |
| 一条字幕停留 0.6 秒 | 读不完等于没有；短促声也要给到能读完 |
| 说明卡写成评价 | 「坚守二十年的老师傅」是你的判断（§4） |
| 同一个人三种称呼 | 化名口径不统一会被拼出真身（§5） |
| 只出烧录版、没有干净母版 | 改一个字要重做全片（§6） |
| 以为有对白字幕就等于无障碍 | 环境声、说话人切换、音乐来源都在内容里（§7.1） |
| 承诺全系列口述影像 | 一项都做不完；先做字幕，再选一部做（§7.2） |
| 忽略焊接/频闪/闪光灯段落 | 光敏风险，能避则避，不能避就给提示（§7.3） |
| 顺手机翻英文先发 | 违反 P1 双语债的记账方式（§8） |

## 实操要点

- [ ] 转写固定五步：粗转 → 词表预校正 → 带音频逐条校对 → 听不出标 `[不清]` → 关键数字与指控由第二人交叉听。
- [ ] 字幕样式在项目里一次定死：≤2 行、单行约 12–16 字、按语义断句、给足停留时间、位置避开画面内文字与人脸。
- [ ] 母版一律无字幕；烧录版与软字幕各另存版本，改文本时四处（对白字幕、说明卡、烧录、软字幕）同步。
- [ ] 说明卡只写事实不写评价，每人只给一次，用量控制在个位数；因果不靠说明卡补足。
- [ ] 化名口径全片统一，真名不进任何字幕与元数据；映射表加密存在项目目录之外。
- [ ] 听障完整字幕包含说话人切换、承担信息的环境声与音乐来源，写法统一用方括号短语。
- [ ] 焊接、频闪、警灯等高风险段落先尝试避开或缩短；无法避免时在片头给光敏性提示，图表不靠红绿区分信息。
- [ ] P1 只发中文字幕，同时把每条英文缺口记进 `字幕双语债.md`；字幕位置预留双语扩展空间。
