# 混音与终混

> 纪实片的混音不追求好听，追求「每一句证词都能被听懂，且听得出它是在那里说的」。

与 04 章的分工要说清：[声音设计](../04-声音/声音设计.md) 管设计判断与真实契约，[同期声与收音](../04-声音/同期声与收音.md) 管现场怎么录到可用的东西，[音乐与版权](../04-声音/音乐与版权.md) 管音乐该不该用与怎么用得起。本篇只管**已经锁版之后，把录到的东西混成一条能交付的声轨**。为什么「观众容忍坏画面不容忍坏声音」、四层（同期对白/采访/环境声/音效）与音乐层的定义、以及对白与其他层的参考电平数值区间，均见 [声音设计](../04-声音/声音设计.md) §1、§2、§6，本篇不重复，只把它们换成混音工序。

## 1. 对白清晰度是第一优先级：它的工序含义

原则在 04 章已经确立。落到混音台上是三件事：

1. **对白先定，其余全后。** 任何一版混音都从「把对白做到能懂」开始，其他层的相对位置在这之后确定。反过来做（先铺氛围再塞对白）的成品无法修补，因为每层都占着同一块频率与响度位置。
2. **优先级冲突时有明确牺牲顺序。** 环境声细节 > 音效装饰 > 音乐存在感 > 低频重量。必要时把音乐与音效完全静音，也绝不为它们压低一句关键对白。低频最先牺牲，理由见 [声音设计](../04-声音/声音设计.md) §7：手机外放重放不出低频，你在小喇叭上听到的「没了」，就是你为它保留的东西。
3. **可懂度不由你判定。** 检验方法是让没在现场的人复述关键句（[声音设计](../04-声音/声音设计.md) §6 自检法）；本篇补充的是它该在什么时点做：**每次混到自认为完成时，先做这个检验，再做别的。**

## 2. 以对白为锚：用耳朵判断相对位置

不给伪精确的分层 dB 表。理由：不同素材的本底噪声、话筒距离、场景动态差别极大，抄来的数值会让你把注意力放在数字是否吻合，而不是听感是否正确——观众听到的是后者。

工作法【操作性建议】，一轮只做一层：

| 步 | 动作 | 判据 |
| --- | --- | --- |
| 1 | 只留对白轨。把全片响度最不平衡的一段拉平到「正常坐着、安静房间里听得清且不震」 | 此时**不推总体音量**，之后的所有判断都以此为锚 |
| 2 | 加环境声。用推子相对位置往下找，直到「这个空间存在但不抢话」为**止**：往上推到这个空间开始变得值得注意，退回一点 | 关掉环境声再开，画面信息量应当不变、只是「没在那儿了」 |
| 3 | 加采访层。目标是归类而不是匹配：观众要能分辨「这是事后说的」，同时又不觉刺耳 | 音色差异保留一点（房间不同、距离不同），不要磨成同期声 |
| 4 | 加音效。只保留现场录到、且承担信息的具象声；其余删（真实契约见 [声音设计](../04-声音/声音设计.md) §9） | 一轨一条，不叠 |
| 5 | 最后加音乐。加之前先静音测段落是否成立 | 见 [音乐与版权](../04-声音/音乐与版权.md) §1 |

补充两个不需要仪表的技巧：

- **低声压试听**：把监听音量降到「要略微专注才听得清」的程度，重复一遍关键段落。这个音量下仍然突出的元素（一层过响的机器底噪、一个太响的门声）就是超标的那几个。大音量会掩盖层次错误。
- **单声道试听**：切成单声道（mono sum）听一段。相位抵消、某轨只在一边、环境声忽大忽小的问题在这里全部现形（§9）。

## 3. 锁版后的对白整理

真正的混音有一半时间花在这一步。顺序固定【操作性建议】：

1. **同步与清理**：双系统素材按场记/波形做同步后，删掉冗余备份轨（相机内麦）的静音段；清掉剪辑咔哒、喷麦、话筒摩擦、纸张声——**这些属于还原，允许处理**。
2. **标出硬损伤**：削波、断录、掩蔽（现场音响压过人声）当场标记，不要「稍后修」。可挽救的判断在这里做，挽救不了的回 [同期声与收音](../04-声音/同期声与收音.md) §9 的应急思路，落到方案上是三条：字幕、解说自陈缺口、补拍采访并明确标注时间场合（[声音设计](../04-声音/声音设计.md) §9）。
3. **统一归类**：同期对白与采访分成不同总线（bus），后续 EQ/压缩分别处理；轨道命名与分组沿用 `DIA / INT / ATM / FX / MUS`。
4. **高通与让位**：非对白轨统一做低频切，对白可懂度频段（1–4 kHz）被抢时优先做窄带衰减而不是整体压低音量——具体数值参考见 [声音设计](../04-声音/声音设计.md) §6，本篇不重复。

## 4. 降噪与去混响：边界在哪里

**听得出处理痕迹，就是失败。** 这一条覆盖所有情形，包括「确实变干净了」的情况。纪实的声底是现场的一部分：观众可以接受噪、接受混响、接受远处的喧，不接受「他的声音没有房间」。

| 处理 | 属于还原（允许） | 属于加工（不做，或登记后做） |
| --- | --- | --- |
| 降噪 | 去掉设备嗡鸣、电流声、恒定风机底噪的适度衰减 | 减到改变音色、出现金属感/水声（musical noise）、把「房间」抽干 |
| 去混响 | 极轻度抑制，让采访与同期不至于两个世界 | 把一间空厂房的反射抹成小录音棚，等于宣称「这话不是在厂房说的」 |
| 削峰/修复削波 | 修复少量瞬时过载，恢复可懂度 | 用生成模型「补」出没录到的音节或词 |
| 均衡 | 让语音在手机上更清楚 | 把某人声处理成更权威、更年轻、更可信的音色 |
| 时间拉伸 | 修口误重复的接缝 | 改变语速以制造紧迫感 |

判断口诀：**处理之后，这条声音是否仍在陈述「当时录到了什么」？** 若处理让句子从听不清变成听得清，是还原；若它让这段话听起来不像在那个地方说出来，是加工。

工具能力与副作用（尤其重降噪对存证素材的影响）见 [AI工具链](../09-技术与设备/AI工具链.md)；处理登记的要求见 [声音设计](../04-声音/声音设计.md) §9 末条：**经过重处理的同期段落，在交付说明里写一句哪些段落被处理过**。涉及当事人陈述、纠纷现场的段落，默认不处理或只做最轻处理。

## 5. 接缝：用房间音补齐

现场怎么录房间音（时长、状态一致、不换话筒不改增益）见 [声音设计](../04-声音/声音设计.md) §4。混音侧的用法与三条禁忌：

- 用法：在两句被剪断的话之间铺同场景的房间音填补空隙；接缝处用极短交叉淡化，让底声连续而内容断开——观众接受「话跳了」，不接受「声音没了」。
- 忌一：**不许留零**。死寂等于向观众宣告「这里有剪刀」。
- 忌二：**不许循环复制同一段到听得出重复**（空调启停、远处一辆车每次都在同一位置出现）。补缝的段落要错开起止、换不同长度。
- 忌三：**不许跨场景借底声做「连贯」**。把 B 地的底声铺在 A 地之下，是在主张 A、B 同一时空；确实需要时用空间变化提示「这是新段落」（[声音设计](../04-声音/声音设计.md) §9 第三条）。
- 补一条纪律：**每个场景的底声在场景结束时不能突然收干**，随画面淡出一起走完，否则段落边界听成断录。

## 6. 音乐层：默认不加

判据与授权三条路、CC 许可的可执行性、「我用了 15 秒应该没事」的纠正、现场意外收录（有人在场放歌、喇叭里的歌）都归 [音乐与版权](../04-声音/音乐与版权.md)。混音侧只需守两条：

1. 音乐的进入与退出要能被耳朵接受为「结构提示」，不是「情绪指令」（后者是主张，需要解说或人物自述承担）。
2. 全片不用音乐是合法且常见的交付选择；若用了，在附包里备好来源与授权证明（[交付母版与规格](./交付母版与规格.md) §1）。

## 7. 终端冲突：以最差终端为主参考

三种听音环境的失败模式不同（表见 [声音设计](../04-声音/声音设计.md) §7）。本篇要定的是**主参考取哪一个**：

> 对以 B 站 / 抖音 / 视频号发布、且大量观看发生在通勤与外放场景的内容，**主参考取手机外放**，客厅音响与耳机作为二次检查。【操作性建议】

为什么反过来（以耳机/监听为主）会失败：监听环境给你的是最优条件下的细节，你会据此保留低频重量与精细动态，而这些恰好在手机喇叭上最先消失，被设备限幅压平后反而让对白更糊。

以此为主参考带来的四个具体动作【操作性建议】：

| 动作 | 目的 |
| --- | --- |
| 关键信息在中频留对应物（金属摩擦的泛音、结构共振的尖啸、人提高音量），不把意思只压在低频里 | 手机重放不了低频，等于那段信息不存在 |
| 不用「变得更响」做重音，用「别的东西安静下来」做重音 | 小喇叭会自动压平大动态，靠响度的重音必然被吃掉 |
| 混到自认完成后，用真机外放完整听一遍（不用耳机模拟） | 平台编码 + 设备限幅的失真无法在耳机上复现 |
| 在噪声环境下（街上、地铁）听一遍最关键段落 | 你的真实观看条件常包含环境噪声；这一关不过，可懂度就是虚的 |

动态范围的取舍：纪实内容不要按院线/广播的大动态做设计，也不要做成全程压扁。做法是**收窄而不是压死**——把最轻与最响的可懂段差控制在你主参考终端能同时容纳的范围内，用耳朵找，不用表找。

## 8. 响度目标：平台会归一化，交付前核对

必须说清机制，不要背数字【通行共识】：

- 主流视频与流媒体平台普遍会对上传内容做**响度归一化**，即把整条内容的响度拉到各自目标值；你上传时「更响」通常不会更响，反而可能在归一化后损失细节与动态。
- 广播与流媒体的公开规范各不相同（例如 EBU R 128、ATSC A/85 一类的响度规范各有其目标值，平台自定目标也不同）。这些属于**必须按现行规范原文核对**的内容，不是记忆项。国内主流平台未公开统一的归一化目标【通行共识】。
- 因此：**交付前按目标投放平台的现行说明核对一遍**；不同平台需要不同导出时，母版只有一份，归一化差异通过导出版本处理（版本体系见 [交付母版与规格](./交付母版与规格.md) §1）。

若确实需要一个可操作起点【操作性建议】：以你项目的参照段落（最典型的对白场景）定一个总音量档位，全片在此档位上做听感检查，并把该档位在导出时固化为一次设置；不要跨项目复用别处的 LUFS 数字。通行做法是让整片在各终端上的「不需要抬手调音量」作为验收标准——这一条比任何数值都可靠。

## 9. 声道结构与下混

- solo 创作者的默认交付是立体声（stereo）加一条**不压制的干净母版**；单声道版本作为手机/公共喇叭场景的补充导出。
- **必须做一次单声道下混检查**（§2 已给方法）：立体声里靠左右拉开的层次，下混后会互相抵消。
- 多声道（5.1 等）在没有展映需求时不要做：它增加交付件、增加出错面，且几乎不会在你的主参考终端上被播放。
- 真人与设备的左右声道不平衡（一侧话筒坏了、只有单只领夹）在混音时要处理成居中，不要留在一边——手机单体喇叭只播一个声道时可能整轨消失【通行共识：部分设备单声道播放会取单一声道】。

## 10. 终混清单与母版前检查

按顺序过，每项写完再进下一项【操作性建议】：

| # | 检查 | 通过判据 |
| --- | --- | --- |
| 1 | 对白可懂度 | 第三方复述三句关键台词成功；不通过回 §4 |
| 2 | 处理登记 | 所有重降噪/去混响段落已列入交付说明；当事人陈述类默认未处理 |
| 3 | 接缝 | 全片无死寂空隙；无跨场景底声嫁接 |
| 4 | 层级 | 逐层静音测一遍：关掉 ATM 画面信息量不变、关掉 MUS 段落仍成立 |
| 5 | 单声道下混 | 无抵消、无轨偏一侧 |
| 6 | 三终端 | 手机外放 / 耳机 / 客厅音响各完整一遍 |
| 7 | 峰值与越界 | 无爆音；按 §8 核对目标平台响度 |
| 8 | 音画同步 | 声画同期段抽验若干点（口型、拍击、机器启停） |
| 9 | 字幕同步 | 终混可能改断句，字幕在混音后再校一次（[粗剪到精剪](./粗剪到精剪.md) §7） |
| 10 | 分轨导出 | 对白/环境/音乐三组分轨（stems）+ 全片干净立体声母版入档（[交付母版与规格](./交付母版与规格.md) §1） |
| 11 | 归档 | 会话工程、分轨、原始录音位置（`OF_REF`）一起归档（[编码存储与备份](../09-技术与设备/编码存储与备份.md)） |

第 10 项最常被 solo 创作者省掉，代价最大：没有分轨，日后任何一处需要改（法律要求下架某句、当事人撤回同意、要出无障碍旁白版）都得从头重混。

**轨道分组与交付分轨不是一套东西。** [声音设计](../04-声音/声音设计.md) §实操要点的 `DIA / INT / ATM / FX / MUS` 是**时间线上的五组轨道**，为的是混音时能分别推电平；本节导出的**对白 / 环境 / 音乐三组 stems** 是**交付归档单位**，为的是日后能单独重做一类声音。合并规则固定：`DIA + INT → 对白`，`ATM + FX → 环境`，`MUS → 音乐`。FX 不单列，是因为纪实素材的具象声量小且必须与同期环境同进退（见 [声音设计](../04-声音/声音设计.md) §9 的合法用量）。导出前按此三组建好总线（bus），别到导出时才分组。

## 11. 常见误区

| 误区 | 事实 |
| --- | --- |
| 按抄来的 dB 表分层 | 相对位置要听出来；数值是参照不是判据（§2） |
| 先铺氛围再塞对白 | 每层都占好了位置，无法修补（§1） |
| 用降噪「救」现场收音失误 | 减到没房间是加工；三条合法出路是字幕、自陈、补拍（§4） |
| 生成模型补出没录到的字 | 这是伪造同期声（[声音设计](../04-声音/声音设计.md) §9） |
| 接缝留零 | 死寂等于告诉观众这里有剪刀（§5） |
| 一段底声铺全片 | 整片失去空间位移，人一直站在同一间房说话 |
| 以监听耳机为主参考 | 与真实投放终端相反；主参考取手机外放（§7） |
| 关键信息只放低频 | 手机等于不存在（§7） |
| 把片子推到最响 | 平台归一化，且重音靠「别人安静」不靠响度（§7、§8） |
| 混一遍就交付 | 三终端与单声道下混是四遍（§9、§10） |
| 不导出分轨 | 一次撤回或改字幕就得重混全片（§10 第 10 项） |
| 音乐当过渡 | 段落间靠配乐切换是专题片遗留手法（[声音设计](../04-声音/声音设计.md) §10） |
| 混完直接压字幕 | 混音会改断句与时长，字幕要在校对后再走一遍（§10 第 9 项） |

## 实操要点

- [ ] 混音固定顺序：对白定锚 → 环境声 → 采访归类 → 音效 → 音乐；每一层只往上推到「开始值得注意」就退回。
- [ ] 分层相对位置用耳朵与低声压试听判定，不套抄来的 dB 表；每版混音先做第三方复述关键句检验。
- [ ] 处理边界口诀：处理后这条声音是否仍在陈述「当时录到了什么」；重降噪段落全部登记进交付说明。
- [ ] 所有对白接缝用同场景房间音补齐，不留死寂、不跨场景借底声；场景结束时底声随画面淡出走完。
