# 调色与画面处理

> 纪实片的调色目标是「看不出被调过」。你的任务不是给片子一层风格，是把跨日、跨机、跨白平衡的素材拼成同一个世界，并保证每一行字都能读。

工序位置：锁版之后、字幕之前（见 [粗剪到精剪](./粗剪到精剪.md) §7）。色彩作为语言的用法（色温、反差在表达什么）已在 [光线与色彩](../03-电影语言/光线与色彩.md) 展开；现场如何读光、如何把人脸曝光锚定，已在 [非虚构摄影](../07-拍摄执行/非虚构摄影.md) 处理。本篇只讲后期画面处理。

## 1. 目标：一致性与可读性，不是风格

剧情片的调色常承担「世界观」，纪实片的调色承担**证据的可信度**。观众对「这段是不是同一天、同一个地方」的判断，一半来自画面的连续感。跨段落的色偏、亮度跳、对比度变化会被读成「素材是从别处拿来的」，进而怀疑内容的来源。

两条硬线，优先于一切氛围判断：

| 硬线 | 判据 | 失败后果 |
| --- | --- | --- |
| 肤色 | 同一场景内不同机位/不同时间拍的同一人，肤色看起来是同一个人在同一光下 | 观众感到「换天了/换人了」；肤色偏青偏黄最容易引发不适 |
| 文字可读性 | 字幕、说明卡、文件特写、数据图表在任何一段画面上都能一眼读完 | 直接损失信息；纪实片里文件特写常是论点本身（[档案与二次素材](../07-拍摄执行/档案与二次素材.md) §9） |

第二条在纪实里比第一条更常出问题：字幕是后期加的，底色是素材里随机出现的。**可读性检查要在调色末尾做一次全片扫描**（做法见 §8），不要靠「看着还行」。

风格化处理（压暗、去饱和、青橙倾向、颗粒叠加）在纪实里合法的位置很小。判据：**这个处理是在帮观众看清事实，还是在帮观众感到你在场？** 后者删掉。

## 2. 监看环境：不追求绝对准确，追求可复现的相对判断

现实约束：多数 solo 创作者在笔记本或消费级显示器上工作。它们的问题不是「颜色不准」这么简单，而是**你不知道往哪个方向不准**——同一台机器在暗房与白天偏色不同，亮度上限不同，暗部容易糊成一坨，广色域内容可能被错误映射。

替代法（本节全篇的基础）【操作性建议】：**把绝对判断换成两件事。**

1. **相对判断交给眼睛**：你只判断「A 镜和 B 镜看起来是不是同一个光下」。同类比较是消费级显示器仍能胜任的任务，因为它比的是差异，不是绝对值。
2. **绝对判断交给数值**：亮度是否越界、黑电平是否抬死、肤色落在哪，用示波器读数决定（§4）。

配套纪律，四条：

| 纪律 | 做法 | 为什么有效 |
| --- | --- | --- |
| 环境恒定 | 每次调色都在同一房间、同一灯开关状态、同一显示器亮度与配置文件；记在项目里（「显示器型号 + 亮度档位 + 房间灯关」） | 你不需要正确的环境，需要每次都同样的环境，否则版本之间不可比 |
| 参照帧 | 每个场景挑一个「正确」镜头当锚，全片其余镜头向它靠；锚帧截图存进项目目录 | 把无穷比较降成 N-1 次比较，省眼省决策 |
| 关闭美化 | 关掉显示器的高对比/鲜艳模式、夜间护眼滤蓝光、HDR 增强 | 这些设置正是让「相对判断」不可复现的东西 |
| 终端回看 | 每版导出后在手机上看一遍（最低亮度与最高亮度各一次）、在白天户外看一眼 | 纪实内容的真实投放终端是手机；这一步不修风格，只查暗部与字幕读不读得出来 |

不要花预算去追求「绝对准确」的监看。真正的保护来自 §6 的一条：**原始文件永不覆盖**，调色只是可重算的一层参数。

## 3. 一级校色与二级：顺序不可倒

| 级 | 做什么 | 工具 | 判据 |
| --- | --- | --- | --- |
| 一级（primary） | 曝光、黑电平、白平衡、反差——整幅画面的全局修正 | 波形/分量图读数、白平衡取样器 | 先做输入端的还原，让不同日期的素材落到同一个「起点」 |
| 二级（secondary） | 局部：提亮人脸、压背景、分离色调、限定色相范围 | 限定器（qualifier）、遮罩、跟踪 | 只在一级完成后做，且每个二级都能说出理由 |
| 风格层（look/LUT） | 全片的统一倾向 | LUT、输出变换 | 最后加，且要能一键撤掉 |

顺序颠倒的代价：在一级还没还原时做二级，你会把某个素材本身的色偏当成「这个场景的调子」，然后为其余所有素材追一个不存在的匹配。一级做完时先看一次全片粗排——多数「跨镜不接」的问题在这一步之后已经不存在，二级用量会大幅下降。

工作顺序【操作性建议】：按场景批处理，不按时间线顺序。同一个地点的所有镜头一次性排在一起匹配（含不同日期的），因为匹配问题只在同类中才看得清。全片做完一级后，再回头按场景补二级。

## 4. 示波器：读什么，怎么用数值代替眼睛

三张图，够用。

| 图 | 横轴 | 用途 | 纪实片里主要看 |
| --- | --- | --- | --- |
| 波形（luma waveform） | 画面左右位置 | 亮度分布 | 人脸是否在稳定区间；高光是否削顶、暗部是否压死 |
| 分量图（RGB parade） | 画面左右位置 | 三通道分别的亮度 | **跨镜匹配的主工具**：看三通道相对高低是否一致，判断色偏方向 |
| 矢量（vectorscope） | 色相/饱和度极坐标 | 色彩分布 | 肤色线：人脸的色度应落在「肤色线」附近一条带上，偏离方向即偏青/偏品红 |

【通行共识】波形与分量的常见刻度以视频范围 0–100 IRE 表示（8-bit 有限范围对应约 16–235 码值）；「不越界」是通用交付要求，具体上限与容差按你最终投放处的现行规范核对。**不要凭记忆写死某平台的数值。**

亮度目标区间的通用表述【操作性建议】：

- 对话段落的人脸亮度，落在波形中段偏上的一个**你全程不变的区间**里；不顶到上限（高光一旦削掉，皮肤质感永久丢失），也不压到下限（暗部提不起细节）。
- 黑电平不要抬到「发灰」，也不许压成纯黑一片丢细节；纪实现场常有暗角与阴影，允许暗，但要能看出形状。
- 白墙、日光灯反光、纸面文件允许接近上限，但不要长期越过；一张白纸压得太黑，观众读不到字。
- 区间的具体数值随素材来源与投放端变化（手机小屏与投影仪不同），做法是：**在本项目内定一个参照帧，把它的读数抄进项目记录，全片向它靠**，而不是套一个别处的数字。

用数值降眼负荷的三个具体习惯【操作性建议】：

1. 匹配用**差值读数**而不是来回看：开启两镜对比/参考叠加（多数软件支持 A/B 或影像叠加），看三通道曲线是否重合；重合即完成，不再「凝视比较」。
2. 判断「是否越界」只看看波形上下包络，不看画面；这一判断完全不需要细视力。
3. 全片扫一遍用**缩略图加波形读数**（导出时勾选示波器叠加，或按场景截图入库），而不是逐镜头盯画面。

## 5. LUT：三种用途，别混

| 类型 | 用途 | 陷阱 |
| --- | --- | --- |
| 监看 LUT | 让 log/扁平素材在监视器上「能看」 | 只在现场监看时有效；后期必须按原始 log 数据处理，否则等于二次应用 |
| 输入/还原 LUT（如 log → Rec.709 一类） | 把特定机型的对数曲线转到显示空间 | 机型/固件/档位不对应时会把高光压死；换机不换 LUT 是最常见事故 |
| 创意 LUT / look | 全片统一倾向 | 一张 LUT 套全片，等于用不合适的曲线去修正所有素材；且它把「跨日不接」变成「跨日一起不接」，观众仍察觉 |

正确顺序【操作性建议】：**先还原（一级），再匹配，最后才谈 look**。look 一定要能一键撤掉，并留一份「无 look」版本，供 §2 的可读性检查与后续修改使用。

三条硬规则：

- 不要烧死（bake-in）监看 LUT 再进下一道工序；确认最终输出走的是正确的显示变换或输出 LUT，且只走一次。
- 双重应用的症状：画面灰平或高光死白、肤色发橙。看到这两条先查 LUT 链，不要调曝光去救。
- 别人片子的「漂亮 LUT」不是流程工具。它包含的是别人对别人素材的补救。

## 6. 跳色与曝光漂移：纪实里哪些可接受

现场的光一直在变（云、门、车影、日光灯频闪、手机补光）。是否要修，判据不是「技术上不一致」，而是**观众会不会因此误解事实**。

| 现象 | 处理 | 理由 |
| --- | --- | --- |
| 同一次连续拍摄里的曝光漂移（云过、人走近窗） | 不修，或只轻微压差 | 这是现场真实发生的光变化；抹平它会把「阴天在变」这件事抹掉 |
| 同一天不同机位的色偏 | 修，优先修肤色与白平衡 | 观众会读成「不同时间」 |
| 不同日期素材拼接（长期跟拍常态） | 只做到「同一空间的连续感」，不追求完全一致；必要时靠字幕交代时间跨度 | 季节与天气本身是内容；强行统一等于伪造同一天 |
| 曝光不足的暗场（夜里只有手机光） | 提亮到「能看清事件」，允许噪点保留 | 噪点是现场条件，观众容忍；看不清是失职 |
| 死掉的高光（窗外全白） | 不救（不可逆），必要时换镜或缩到局部 | 无信息可恢复；硬拉会引入色斑与边缘发暗 |
| 白平衡在一段内来回摆（自动白平衡未锁） | 修：全段锁到一个方向 | 摇摆是设备失误，不是现场变化 |

一条通用判断【操作性建议】：**能自然解释的不修，一看就是机器犯错才出现的修。** 观众对自然光的容忍度远高于对「画面在呼吸」（自动曝光/自动白平衡未锁的症状）的容忍度。

参数预设的冻结在现场已经决定了一半结果（[非虚构摄影](../07-拍摄执行/非虚构摄影.md) §7 要求快门、光圈、ISO 上限、白平衡在出门前定死）。后期补救的成本随现场偏离程度指数上升。

## 7. 老档案素材：做旧还是修净

档案、翻拍、扫描件与手机旧视频进片时，常见两种相反的错误处理：过度修复（磨平噪点、上色、提锐到失真）和过度做旧（加划痕、加抖动、加暖黄「回忆感」）。

判断表：

| 情况 | 处理 | 理由 |
| --- | --- | --- |
| 档案里的信息要看清（文件、面孔、地点招牌） | 修净到可读：去噪、拉对比、必要时局部提亮；保持灰阶或原始色 | 它的功能是证据，不是氛围 |
| 档案本身的状态是内容（破损、褪色、录像带划痕） | 不修，保留并让观众看见；必要时用字幕说明来源与年代 | 做旧是装饰，不修是记录——但「保留」必须是原始状态，不是你加出来的 |
| 与实拍混剪，观感差异过大 | 只统一亮度与观感方向（不要统一「年代感」） | 差异本身要保留：观众需要知道这是另一个来源 |
| 需要标出「这是档案」 | 用画面框、时长标记、明确来源标注，而不是靠滤镜 | 来源标注是事实陈述，滤镜是暗示（[档案与二次素材](../07-拍摄执行/档案与二次素材.md) §7） |

硬规则：**不许用滤镜制造「这就是当年画面」的印象**。做旧与修复都改变观众对材料真实性的判断，需要修的是可读性，不是年代感。授权与来源说明的处置见 [档案与二次素材](../07-拍摄执行/档案与二次素材.md) §2、§12。

## 8. 900 度近视的实操：这一篇的全部前提

用眼负荷是本项目的硬约束（[现场工作流与安全](../07-拍摄执行/现场工作流与安全.md) §7）。调色是全章最伤眼的工序，因为它要求长时间细视力 + 高对比环境。以下不是建议，是把工序改成能被完成的形状【操作性建议】。

| 措施 | 具体 | 抵消什么 |
| --- | --- | --- |
| 大屏 + 保持距离 | 调色用外接大屏（不要笔记本屏），观看距离不小于屏幕对角线长度量级；画面细节交给放大与示波器，不靠凑近 | 凑近看细节会同时放大调节负担与偏差判断 |
| 每 25 分钟离开屏幕 | 严格 25 分钟一段（番茄钟即可），离屏看 6 米外，至少 3 分钟 | 调色比剪辑更细，所以间隔比 §7 里的 45/50 分钟更短——这是有意收紧，不是矛盾 |
| 数值代替肉眼 | 越界、匹配、肤色方向全部用示波器读数与 A/B 差值判定（§4 三个习惯） | 把「反复凝视比较」换成「读一次数」 |
| 批处理短任务 | 一次只处理一个场景的一级；不跨场景连续匹配；判断完成即退出软件 | 连续跨场景比对最容易失控超时 |
| 手机端代替眼睛 | 暗部与字幕可读性用手机看一遍，而不是在屏前放大找 | 终端回看比目视更可靠，也更省眼 |
| 出口前让别人过一遍 | 定一个人（视力正常）只看两件事：字幕读不读得清、有没有哪一段「跳出来」 | 你判断不了自己因疲劳产生的偏差 |
| 硬停条件 | 视力模糊、头痛、眼干、看字串行——立即结束当日调色，明天继续 | 累加误差会毁掉整批判断，返工成本更高 |

一条时间现实：调色不适合排在晚间（[粗剪到精剪](./粗剪到精剪.md) §8 的分段原则）。把全片调色拆成 3–5 个上午完成，每次只做一个工序（一次只做一级还原、一次只做匹配、一次只做二级），比一次做完三件事更省眼也更不容易做出无法复现的版本。

## 9. 常见误区

| 误区 | 事实 |
| --- | --- |
| 先上风格 LUT 再校曝光 | 在错误的起点上做二级，之后要为不存在的调子追匹配（§3） |
| 追求「电影感」色调 | 青橙不是纪实语言，它会把肤色从「这个人」变成「这类人」 |
| 把噪点磨干净 | 噪点是现场条件；磨到塑料感等于宣称「这不是当时的画质」 |
| 用自动白平衡救现场 | 一段内来回摆是设备失误，后期要锁一个方向（§6） |
| 靠眼睛判断是否越界 | 消费级显示器 + 高近视下不可靠；交给波形读数（§2、§4） |
| 每次在显示器不同设置下调 | 版本之间不可比，等于每次重做一遍（§2 环境恒定） |
| 调色覆盖原始文件 | 原始件永不覆盖、不重编码；调色是可重算的一层（[素材管理与日志](./素材管理与日志.md) §2） |
| 用「漂亮 LUT」套全片 | 它把不匹配变成整体偏移，观众照样察觉（§5） |
| 档案素材加做旧滤镜 | 做旧是暗示，不是记录；要标来源就明确标（§7） |
| 字幕可读性等到最后才查 | 字幕在调色之后加，位置与底色都可能撞画面信息（§1、§8） |
| 熬夜调色 | 疲劳产生的偏差第二天不会承认，只会成为返工（§8 硬停条件） |

## 实操要点

- [ ] 调色前把目标定为两件事：跨镜一致性 + 文字可读性；风格处理必须能回答「它帮观众看清了哪条事实」。
- [ ] 固定调色环境（同一房间、同一灯态、同一显示器设置）并写入项目记录；关闭显示器的美化模式；用参照帧代替绝对判断。
- [ ] 严格按一级还原 → 跨镜匹配 → 二级局部 → 统一 look 的顺序，按场景批处理，不按时间线顺序。
- [ ] 越界、色偏方向、匹配差值全部用示波器读数判定；把参照帧的亮度读数抄进项目，全片向它靠，不套别处的数字。
- [ ] 原始件不被覆盖、不重编码；导出前留一份无 look 版本；监看 LUT 不许被二次应用。
- [ ] 跳色判断口诀：能自然解释的不修，一看就是设备失误的才修；不同日期的素材不强行统一。
- [ ] 调色全程用外接大屏并保持距离，每 25 分钟离屏看 6 米外至少 3 分钟；一次只做一个工序，排在上午，出现视力模糊立即停。
- [ ] 出口前做一次全片手机端扫描：字幕、说明卡、文件特写在最低与最高亮度下能否一眼读完；再请一位视力正常的人复核同两件事。
