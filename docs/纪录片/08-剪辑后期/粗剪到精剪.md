# 粗剪到精剪

> 阶段的价值不在名字，在通过条件。你要知道的是「这一版能不能不再改了」，而不是「今天该剪到第几天」。

本篇是 08 章的工序表：从素材进机到交调色混音之前的全部阶段。判断准则（删与留的边界、试映问什么）在 [剪辑方法论](./剪辑方法论.md)；卡片与顺序比较的方法在 [纸剪与结构重组](../05-叙事结构/纸剪与结构重组.md)，本篇假定纸剪已经完成、结构已有候选。

## 0. 通过条件是状态，不是时间

每个阶段写四条：**输入 / 产出 / 常见卡住信号 / 退出判据**。退出判据必须是可以在屏幕上指认的事实——「感觉差不多了」不算，「全片每个段落都能指出它回答了哪一句未决问题」才算。

一个反直觉但重要的规定：**每个阶段的产出都要留档，不许在同一个工程上原地推进。** 组装剪、结构剪、精剪各存一份工程与一次低码率导出，因为唯一的诊断工具是「退回去看上一版」——上一版被覆盖，你就失去了判断当前版本是否变好的依据。

## 1. 阶段一：素材通读（ingest + read-through）

| | |
| --- | --- |
| 输入 | 已入库、已哈希、已 L1 日志的素材；代理文件；转录稿 |
| 产出 | 每场的主条选定；L2 候选池（带起止 TC）；一份「素材能力清单」（哪些场根本不够用） |
| 卡住信号 | 反复回看最喜欢的那几段；两小时后仍未打点；开始挑镜头而不是挑事件 |
| 退出判据 | 每一场都有一行 L2 记录或明确标「本场无可用」；素材能力清单已写下缺口（缺口处置回纸剪 §10 补拍，不在此阶段解决） |

做法沿用 [剪辑方法论](./剪辑方法论.md) §6：3 倍速通读、只看自我意识最低那条、静音一遍、只听声音版一遍。一人团队的时间参考【操作性建议】：4 小时素材约占一个下午，不要指望「顺手看完」。

## 2. 阶段二：组装剪（assembly edit）

把 L2 候选按**你认为的顺序**全部拼上时间线，一场不删。

| | |
| --- | --- |
| 输入 | L2 候选池、纸剪卡片排定的顺序 |
| 产出 | 一条完整看完的时间线，长度常为成片目标的 **3–6 倍**（20 分钟成片对应 60–120 分钟组装剪）【操作性建议】 |
| 卡住信号 | 忍不住开始精修某一场；给过渡加空镜；担心「太长了」而提前删 |
| 退出判据 | 从头到尾能一次放完不中断；**每个段落都能说出它在回答什么**；长度落在目标 3–6 倍区间内 |

本阶段的唯一纪律是**不删除、只选择**（选条与排序，不砍段）。它的功能有两个：一是把「素材够不够」变成可测量的事实（组装剪只有 1.5 倍，说明你缺料，不缺剪法）；二是给结构剪提供参照物——你必须见过全长的样子，才知道砍掉的是不是承重段。

组装剪阶段允许做的删减只有一类：**同一句台词的重复录制**（选主条，其余移出时间线但不删工程素材）。

## 3. 阶段三：结构剪（structural edit）——整段删除

这是全章密度最高的一段，也是唯一要求「敢删整段」的一段。

| | |
| --- | --- |
| 输入 | 组装剪 |
| 产出 | 接近目标长度的版本（±30% 内）；`REJECTED` 回收段与删除理由表 |
| 卡住信号 | 每次打开只改句子里的刀，不动段落；反复回看被你犹豫的那段而不决定；用「先留着」逃避 |
| 退出判据 | 长度达标；剩余段落按顺序复述能形成一句完整的论点；每一段能指回未决问题的一格 |

操作规定【操作性建议】：

- **按段操作，不按镜头操作。** 本阶段禁止在场景内部剪。把整段拖出去，看时间线剩下什么；如果剩下的反而更清楚，说明原段不承重。
- 删的顺序固定：最贵 → 最好 → 最爱（判据「有没有别处能替代」见 [纸剪与结构重组](../05-叙事结构/纸剪与结构重组.md) §7）。
- **删掉的段落不许消失。** 全部移进同一工程里的 `REJECTED_YYYYMMDD` 序列（或多建一个不导出的时间线），并在删除理由表里写一行：删了什么、多久、理由、可能反悔的条件。
- 加与情绪补洞在本阶段一律禁止（加法冲动的三种形态见 [剪辑方法论](./剪辑方法论.md) §3）。

为什么必须整段删：在场景内部省着删，长度会降但结构不变，你会误以为问题解决。全片最常被高估的是「我辛苦拍的」，最常被低估的是「整段拿掉之后节奏反而成立」。

`REJECTED` 表抄用格式：

| 段名 | 时长 | 删除理由 | 什么条件下恢复 |
| --- | --- | --- | --- |
| S12 老周讲 2019 年工伤 | 2'10" | 与 S27 现场陈述重复，现场版更强 | 若最终版里工伤只剩转述（I 级证据），恢复 |
| S04 村口清晨空镜 | 0'35" | 不承担时空转换，前面已有更清楚的进入镜 | 若开头需要减速，用作第一个镜头 |

理由必须写成可核对的句子。三个月后你想不起为什么删，就会把它拖回去，然后重删一次。

## 4. 阶段四：场景内精剪（in-scene edit）

到这一阶段才允许动句子内部。

| | |
| --- | --- |
| 输入 | 结构剪 |
| 产出 | 每场的「最终内部版本」：句内切点、呼吸保留长度、反应镜位置 |
| 卡住信号 | 逐字修剪口癖导致语气断裂；为构图完美换机位而破坏状态连续；一场改了七遍仍说不出为什么 |
| 退出判据 | 每场静音看一遍仍能看懂；每场至少留一个「不被剪断的时刻」（见 [蒙太奇与长镜头](../03-电影语言/蒙太奇与长镜头.md) §7） |

三条现场判断规则【操作性建议】：

1. **先留完整，再剪。** 情绪高峰（哭、怒、告白）先原样保留一次完整观看，再决定动不动。一剪切就等于你替观众选了看哪里。
2. **口误与重复只删不改义。** 删「这个这个」没问题；删掉他的迟疑就把「他不想说」这条事实剪掉了（[剪辑方法论](./剪辑方法论.md) §3 表格第一行）。
3. **反应镜来自同一场。** 切出去的画面必须属于本场时空，否则成了库存素材（语法见 [蒙太奇与长镜头](../03-电影语言/蒙太奇与长镜头.md) §5）。

## 5. 阶段五：节奏与过渡

| | |
| --- | --- |
| 输入 | 场景内精剪完成的版本 |
| 产出 | 段落进出点、时长曲线、空镜与声桥位置 |
| 卡住信号 | 中段全在 3 秒以内的单调；每处转场都用同一种淡入；靠音乐缝合 |
| 退出判据 | 画一张时长曲线（横轴时间、纵轴镜头长度）后，能看到至少两次明显的「长下来」；每一处跨时空切换都有可指认的提示（光、声、字幕其一） |

做法工具在 [冲突悬念与信息节奏](../05-叙事结构/冲突悬念与信息节奏.md) §5（时长曲线、留白作重音、晚进早出、时间跳接的处理优先级），本篇不重复，只定阶段边界：**过渡问题优先用删除解决，不用素材解决。** 一个转场需要 5 秒空镜才成立，通常是这两段之间没有真实关系。

## 6. 阶段六：终剪（picture lock）

锁版不是「剪完了」，是一个工序承诺：**从这一刻起，任何画面长度的改动都会使下游（调色、混音、字幕）返工。**

| | |
| --- | --- |
| 输入 | 精剪 + 节奏版 |
| 产出 | 锁定工程、锁定导出、锁版记录（时间、时长、哈希） |
| 卡住信号 | 每次重看都想改开头；片尾字幕迟迟不做；因为要给某人看而不敢锁 |
| 退出判据（全部满足） | 见下 |

锁版判据清单【操作性建议】：

- [ ] 长度在目标区间，且不再因为「长了」而删；
- [ ] 一次完整放映的点位表里没有新的结构性问题（同一位置的第三次抱怨已处理）；
- [ ] 解说词定稿（见 [解说词写作](../05-叙事结构/解说词写作.md) §1 的「粗剪定结构之后再动笔」）；
- [ ] 未授权素材扫描为空（见 [素材管理与日志](./素材管理与日志.md) §6）；
- [ ] 事实与引用能回指到素材 TC，字幕卡与来源标注齐（见 [档案与二次素材](../07-拍摄执行/档案与二次素材.md) §7）；
- [ ] 反方/被涉及者已获得回应机会（伦理前提，见 [事实核查与更正](../10-伦理法律/事实核查与更正.md)）。

**破版规则**：允许，但要登记。写明改了哪一段、影响哪些下游工序、是否需要重混重出。破版不登记，锁版就失去意义；三次无登记破版，说明上一版根本不该锁。

## 7. 后期链（锁版之后）

锁版后进入并行的下游，顺序与本篇的分工边界如下【操作性建议】：

| 序 | 工序 | 输入 | 归属文件 |
| --- | --- | --- | --- |
| 1 | 回批/套底（conform）：代理换回原始件 | 锁定工程 + `OF_REF` ↔ 文件映射 | [素材管理与日志](./素材管理与日志.md) §9 |
| 2 | 调色与画面处理 | 回批后的时间线 | [调色与画面处理](./调色与画面处理.md) |
| 3 | 对白整理 → 混音 → 终混 | 锁定工程的音频 + 分轨导出 | [混音与终混](./混音与终混.md) |
| 4 | 字幕与无障碍 | 调色后的画面版 | [字幕与无障碍](./字幕与无障碍.md) |
| 5 | 母版与分发版本 | 全部上游交付件 | [交付母版与规格](./交付母版与规格.md) |

关键顺序依赖：**字幕在调色之后、终混之后各做一次校对**（调色可能改字幕位置的可读性，混音可能暴露听不清而需改字）；回批必须在任何精细处理之前，因为代理与原始件的锐度、噪点、色深不同，在其上做的判断不可迁移。

## 8. solo 的时间分配：把判断留给视力最好的时段

阶段之间的成本完全不同。判断密度：结构剪 > 场景内精剪 > 素材通读 > 节奏过渡 > 锁版执行。用眼负荷：调色与字幕远高于剪。

【操作性建议】按「精力形状」排班，不按「工序顺序」排班：

| 时段 | 做什么 | 为什么 |
| --- | --- | --- |
| 睡眠后第一个整段（多数人上午） | 结构剪、删除决定 | 唯一需要「敢砍」的判断，疲劳会让你选择保守（留住），后果是片子虚长 |
| 第二个整段 | 场景内精剪、试映放映与记点位 | 需要连续注意力但不需要决断力 |
| 下午后段 / 晚间 | 日志、词表、代理整理、字幕排版、导出版本 | 机械型工作，被打断损失小 |
| 极短片段（10 分钟内） | 补 TC、跑未授权扫描 | 填缝，不动判断 |

硬约束沿用项目纪律：取景器/监视器连续 ≤45 分钟、剪辑每 50 分钟起身，累计 ≤10 小时，出现视力模糊、头痛、眼干立即终止当日计划（[现场工作流与安全](../07-拍摄执行/现场工作流与安全.md) §7）。补一条剪辑侧的：**结构剪不放晚间。** 晚上做删除决定最常见的结果是第二天反悔，反悔一次等于两次结构剪。

每周剪辑时段建议配比【操作性建议】：通读 20% / 组装 15% / 结构剪 30% / 精剪 20% / 节奏与锁版 15%。结构剪占比最高是正常的，别为它「进度太慢」自责。

## 9. 何时停止修一版，去做放映

solo 最大的成本错配是**在没人看过的前提下持续自修**。四条停止信号，中一条即导出放映：

1. 同一处连续两轮改动仍不满意——你不知道要什么，观众能告诉你（三问见 [剪辑方法论](./剪辑方法论.md) §7）。
2. 你在开始解释：「这里其实是因为……」。需要旁白解释的版本，问题是结构不是手艺。
3. 单次修改的时间尺度小于 30 秒（挪一帧、调一个淡入），而你已经有两小时没看过整片。
4. 你最后一次完整看整片是三天前。

反过来，「还不想给人看」不是理由。工作版给 3–5 人看的时间越早越便宜——**结构剪完成时放一次、精剪完成时放一次**，两次是下限【操作性建议】。

## 10. 版本记录表（可直接抄用）

每一版一行，放在 `05_DOC/版本.md`。原则：不登记等于没剪过。

| 字段 | 填法 |
| --- | --- |
| 版本 | `A01`（组装）/`S03`（结构）/`F02`（精剪）/`PL`（锁版）/`D01`（交付） |
| 日期与耗时 | `2026-03-12 / 4.5h` |
| 时长 | `62'18"` |
| 工程文件 | 文件名 + 所在目录 |
| 导出 | 低码率放映版文件名 + SHA-256 前 8 位 |
| 本版改动 | 一句话：「删 S04/S19 两段；开场换成 S27」 |
| 改动理由 | 一句话，写给三个月后的自己 |
| 放映 | 看了的人 + 点位（时间戳列表） |
| 下一版动作 | 只写一类问题（结构 / 场景内 / 节奏） |
| 遗留 | 已知缺口、待补拍、待授权 |

版本命名与母版命名的关系：`A/S/F/PL` 是工作版本，允许互相覆盖同名迭代到 `_v03`；`PL` 之后进入交付命名体系，见 [交付母版与规格](./交付母版与规格.md) §5。原始素材在任何版本体系里都不带后缀（[素材管理与日志](./素材管理与日志.md) §2）。

## 11. 常见误区

| 误区 | 事实 |
| --- | --- |
| 从精剪开始 | 跳过组装剪，你不知道砍掉的是不是承重段（§2） |
| 组装剪就担心太长 | 3–6 倍是正常产出，不是问题（§2） |
| 结构剪在场景内部省着删 | 长度降了、结构没变；整段移出去才看得见（§3） |
| 删了的段落直接删文件 | 删除理由没登记，三个月后拖回来重删一次（§3） |
| 靠导出长度判断进度 | 通过条件是状态清单，不是「剪到第几天」（§0） |
| 在代理上做调色与锐度判断 | 回批之前的判断不可迁移（§7） |
| 锁版后偷偷改两帧 | 破版必须登记，否则下游全部对不上（§6） |
| 把结构剪放在晚上 | 疲劳让人保守，产出是虚长的片子（§8） |
| 用「再修一版」替代放映 | 四条停止信号（§9）；自修是最贵的信息获取方式 |
| 一个工程原地推进到底 | 覆盖上一版等于失去比较基准（§0） |
| 字幕等调色混音全做完再加 | 字幕会改混音需求，也要在调色后校可读性（§7） |

## 实操要点

- [ ] 每阶段各存一份工程与一次低码率导出，绝不覆盖上一版；版本记录表每版一行，改动理由写给三个月后的自己。
- [ ] 组装剪只做选择不做删除，长度落在成片 3–6 倍即算完成；组装剪不足 1.5 倍是缺料，回去补拍而不是补剪。
- [ ] 结构剪按段不按镜，删掉的段落全部进 `REJECTED_日期` 序列并写删除理由与恢复条件。
- [ ] 判断型工作（结构剪、删除决定）排在睡眠后第一个整段；晚上只做日志、字幕、导出等机械工序。
- [ ] 锁版前跑完六条判据（长度 / 放映点位 / 解说定稿 / 未授权扫描 / TC 回指 / 反方回应机会），破版一律登记。
- [ ] 中任一停止信号（同处两轮不满意、开始自我解释、单次修改 <30 秒、三天没看整片）即导出放映，不再自修。
- [ ] 锁版后先回批再调色混音；字幕在调色后与终混后各校对一次。
- [ ] 结构剪完成放一次、精剪完成放一次，两次是下限。
