# 稳定器与特种拍摄

> 稳定不是质量指标，是语言选择。这一篇的大半篇幅用来劝你别买稳定器，剩下的部分说明哪几种设备一旦用错，代价不只是画面，还有你与现场的关系。

运动与否、晃动是否可读、快门与运动模糊下限，判断标准在 [摄影机运动与节奏](../03-电影语言/摄影机运动与节奏.md)；本篇只讲**支撑与特种器材的选择、配置、代价与合规边界**。

---

## 一、多数纪录片镜头不需要稳定器

三脚架、稳定器、滑轨的共同问题是：它们把「画面要稳」变成了目标，而纪录片的目标是**这一场没有被漏掉**。03 章已经给出口径——有动机的晃动是语言，没动机的晃动是失控；观众能接受的抖动程度，远高于摄影机自己接受的程度。

| 你以为的问题 | 真实问题 | 结论 |
|---|---|---|
| 画面抖，说明我技术差 | 手抖往往来自负重、憋气、找不到支点 | 先解决负重与呼吸，见 07 章负重线 |
| 稳一点更容易被选中播出 | 过稳的画面取消了在场感，等于宣称「有人在布置」 | 纪录片的呼吸是契约的一部分（[真实契约](../01-理论/真实契约.md)） |
| 有稳定器我就能拍长镜头 | 稳定器让你敢动，不等于你知道为什么动 | 运动要有动机，判据在 03 章 |
| 客户/平台会要稳的 | 你多半没有客户；先按片子本身判断 | 交付规格见 [交付母版与规格](../08-剪辑后期/交付母版与规格.md) |

**判据一句话**：如果你不能在开机前说出「这一镜为什么必须移动」，那稳定的需求不成立，器材也不需要。

## 二、三脚架：值在哪、代价在哪

| 项 | 说明 |
|---|---|
| 液压云台（fluid head）的真实价值 | 不是让摇镜变帅，而是让**等待变得可承受**：可微调、可松手、能在同一机位守二十分钟不累。这是 03 章「三脚架 + 等待」的装备前提 |
| 重量与展开时间 | 展开超过 30 秒的架子，在突发场景等于不存在 |
| 高度 | 坐姿访谈与站立跟随需要两种高度；能快速换比能升到最高重要 |
| 地面 | 油污车间、农田、碎石河滩需要脚垫与配重，比多一节腿有用 |

### 2.1 把三脚架立起来的社交代价

这是全库唯一处展开这件事的位置：**在村里、市场、厂区把三脚架支起来，是一次关系动作，不只是技术动作。**

| 后果 | 表现 | 应对 |
|---|---|---|
| 被当作记者 | 人群聚拢、有人来问「你是哪个台的」、对方突然开始对你讲话而不是对同伴讲话 | 明确身份说明，与 07 章口径一致：「我不是记者，没有记者证，是独立做记录和研究，个人项目。」 |
| 现场权力关系改变 | 当事人开始表演；员工看向门口等老板；受访者从「说给你听」变成「对着摄像机说」 | 先立人后立架；或先用手持完成建立信任的场次 |
| 被要求许可 | 园区、市场管理方、店铺业主来问「谁让你拍的」 | 出示介绍信/说明，当场联系现场负责人；无许可即收起 |
| 无法快速撤离 | 突发冲突时收架 = 丢素材或挨打 | 危险场景禁止上架（07 章安全优先） |

**什么时候换成小型支撑**：桌面三脚、豆袋、把机身放在现有物体上（柜台、砖堆、车前盖）。它们在窄空间、需快速移动、不宜引人注目的场合优于正规三脚架，代价是高度与稳定性有限。**一人首次进一个陌生场地，默认带小支撑，不带正规架子。**

## 三、手持稳定：身体比器材便宜

| 手段 | 效果 |
|---|---|
| 背带绕颈/手腕承重，双手离开机身也能悬停 | 手臂间歇卸力，续航翻倍；07 章「三种挂法」的装备版 |
| 手肘贴肋、脚步走屈膝缓冲 | 消除大部分上下跳动，比多数电子增稳更干净 |
| 走路节奏与呼吸同步、呼气时不做大动作 | 减少可见的躯干起伏 |
| 找现成支点（墙、柱、车、膝） | 最便宜的「云台」，也最不引人注意 |
| 外接监视器置于胸前视线高度 | 不必贴眼取景，头部稳定带动身体稳定（07 章近视替代方案） |

合格线不在这里，在 03 章：每十步少于一次明显跳动为合格。**练两周身体，比买一台稳定器省下的钱和救回的镜头都多。**

## 四、手持稳定器（gimbal）的真实代价

| 代价 | 具体表现 |
|---|---|
| 重量 | 电机 + 电池 + 机器 + 镜头，很快越过 07 章的跟随负重线 |
| 平衡时间 | 换镜头、换滤镜、加麦克风都要重平；一天五次换装就是半小时 |
| 抑制即兴 | 上机后你会等它平衡好才敢拍；突发事件不会等你——这是最贵的隐性代价 |
| 运动词汇 | 03 章已定：稳定器的运动语言属于宣传片与房地产片。要用就按那里的设置走（跟随轴降到最低档、关闭自动回中与轨迹跟随、不做 360° 环绕） |
| 电池 | 多一份要管理的电量与故障点；与灯光、录音的电池规划同口径（见 [灯光与电力](./灯光与电力.md)） |
| 静音 | 电机在极静场合有可闻啸叫与嗡鸣 |
| 通行与安检 | 地铁、车站、园区安检与保安对成组装备询问概率显著上升；大型设备可能要求登记或禁入 |
| 法规与场地 | 部分场馆、机场周边、轨交区域对带支架/长杆设备另有规定，**进场前向场地方询问并要求书面答复**，不要现场争论 |

**结论**：稳定器是「有明确运动设计、且这场允许你花五分钟装机」时才可用的工具。一人长期跟拍的默认答案是**不用**。若确实需要一次可控运动，租一天比买一台合理（方法见 [摄影机与镜头选择](./摄影机与镜头选择.md) 的租买四问）。

## 五、滑轨与自制

| 方案 | 适用 | 陷阱 |
|---|---|---|
| 商品滑轨 | 静物、档案物件、空间展示 | 一人几乎无法同时推轨与跟焦；重量与打包体积不划算 |
| 自制滑轨（滚轮 + 导轨 + 配重） | 你确实反复需要同一类运动时 | 抖动、卡点、不可重复；自制的时间也是资金包里的时间 |
| 身体代替滑轨 | 缓慢前推、退后 | 需要支点与慢速走位；画质上限够用，且不改变现场关系 |
| 后期数码推拉 | 静态画面的小幅运动 | 损失分辨率与构图余量；处理需登记（见 [调色与画面处理](../08-剪辑后期/调色与画面处理.md)） |

**判据**：先问「这个运动能不能用走路完成」。能，就不买、不做。

## 六、延时摄影与无人值守

器材侧的三件事：电量、容量、以及**谁负责这台机器**。前两件是 [编码存储与备份](./编码存储与备份.md) 与 [灯光与电力](./灯光与电力.md) 的常规算术；第三件是这一节存在的理由。

| 项 | 纪律 |
|---|---|
| 许可 | 无人值守固定机位需要现场负责人知情同意；延时同样需要许可与标识（[长期跟拍](../07-拍摄执行/长期跟拍.md)） |
| 标识 | 机器挂可见标识：「正在拍摄，研究者 ×××，电话 ×××」，字要大、夜里要能看清 |
| 反对即停 | 出现明确反对者，按其意愿处理：关机、收走、或删除其可识别片段。**不争论、不拖** |
| 无关第三人 | 不采集无关第三人可识别信息的时段要关机，而不是「回头剪掉」 |
| 隐蔽采集 | **禁止**：不藏机器、不假借身份、不无同意录音（PRINCIPLES §2.4，见 [PRINCIPLES](../../../PRINCIPLES.md)） |
| 器材安全 | 假电池或大容量电源、留足线材余量并固定、防水与遮光罩、防鸟与防风；机器不要悬在通道上方 |
| 检查节奏 | 每 30 分钟看一次在录状态（04 章对表节奏同期）；一次没查就可能丢两小时 |

## 七、运动相机与穿戴机位

| 用处 | 说明 |
|---|---|
| 极端位置 | 手上、胸口、车头、机器内部、狭窄管道——这些位置正规机器进不去 |
| 长时间不换机 | 体积小、发热与续航优势，适合守一个工序 |
| 被摄者适应快 | 几天后没人再注意胸口那块小方块 |

| 滥用 | 表现 |
|---|---|
| 当第二机位随手开 | 素材量翻倍、整理成本翻倍、可用率极低（见 [素材管理与日志](../08-剪辑后期/素材管理与日志.md)） |
| 当「更真实」的证据 | 广角畸变把人与空间都拉变形，声音基本不可用 |
| 当默认视角 | **穿戴视角不属于任何在场者**。第一人称必须有依据（语言、影像或承认的推断），见 [观看位置与视点](../03-电影语言/观看位置与视点.md) |

镜头侧注意：超广角的桶形畸变在人脸贴近时最严重；无 ND 与无浅景深意味着它不适合替代主机的任何一格；电子增稳在大光比与低光下会引入拖影与噪点结构变化。【通行共识】**若用它拍带声音的对话，只当参考轨，不当主轨**（主轨归属见 [收音装备](./收音装备.md)）。

## 八、航拍：只讲合规与风险边界

本篇不提供任何规避监管、绕过审批、关闭识别或绕开执法人员的方法；相关段落一律指向**合法申报与获取同意的路径**。

| 事项 | 事实性边界 |
|---|---|
| 实名登记 | 无人机需在现行监管平台完成实名登记后方可飞行【核验：以现行《无人驾驶航空器飞行管理暂行条例》及配套规定为准，具体条款与流程请复核当期文本】 |
| 空域与管制区 | 机场净空区、军事管理区、政府机关、人群上空、大型活动区域等存在限制或禁飞；飞行前通过当期官方渠道查询并按规定申报或报备 |
| 地方差异 | 城市、省份、园区与景区的规定差别很大；**同一片空域上个月的口头答复不作数**，每次出发前重新确认 |
| 重量与类别 | 不同重量档位的操控员要求、高度限制、夜间与视距内规则不同；以你所持设备铭牌与现行规定为准 |
| 保险与责任 | 坠落对地面人员与牲畜、屋顶、车辆都是现实风险；无第三方责任险不要进人活动区 |
| 电池与运输 | 锂电池随身携带不放托运（与 07 章同口径）；低温与老化下容量骤降，按一半规划（见 [灯光与电力](./灯光与电力.md)） |
| 现场许可 | 村口、厂区、景区还需**场地权利人同意**；无人机从谁的地上起飞，就问谁 |

### 8.1 飞在村庄与厂区上空，对下面的人意味着什么

这是伦理问题，不是画质问题：

- **压迫感是真实的。** 头顶有噪声的机器，会让人立刻意识到「被从上面看」。有人抬头骂、有人躲进屋、有人停下工作看你——这三种反应都是数据，说明它改变了现场。
- **地籍视角。** 03 章已判定：到达一定高度就取消身份识别，给的是地图视角而不是人的视角。它适合交代空间关系，不适合当默认开场。
- **可识别的私人领域。** 院内、屋顶、阳台、窗户内属于居住空间；即使你在自己的空域权利内飞，也不等于对方同意了被拍。同意与遮挡处理见 [知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md)。
- **操作纪律**：起飞前告知在场者并留出拒绝的余地；有明确反对者立即降落并停止；不贴近人、不从人头顶越过、不在争吵与冲突现场升空；飞完当场告诉对方你会怎么用这几段。

## 常见误区

| 误区 | 代价 | 更正 |
|---|---|---|
| 画面抖就买稳定器 | 负重、装机时间、丢掉的即兴 | 先解决负重、支点与步法 |
| 把「稳」当专业标准 | 取消在场感，风格趋同宣传片 | 稳定性是语言选择，判据在 03 章 |
| 一人坚持挑杆上架 | 注意力超载、现场关系被器材改写 | 小支撑 + 机顶麦（见 [收音装备](./收音装备.md)） |
| 三脚架一进场就支 | 立刻被当记者、被要求许可、无法撤离 | 首访默认小支撑；身份口径照念 07 章 |
| 延时机位不留标识不告知 | 违反知情同意，可能构成隐蔽采集 | 许可 + 标识 + 反对即停（07 章长期跟拍） |
| 运动相机当第二机位随手开 | 素材整理成本翻倍、可用率极低 | 每场只允许一个第一任务 |
| 穿戴视角当「更真实」 | 畸变 + 不可用声轨 + 无依据的第一人称 | 视角需要依据，见 03 章 |
| 航拍当默认开场 | 地籍视角与压迫感同时出现 | 只在空间本身是论证对象时 |
| 认为「别人都能飞我也能」 | 违规、被查、连累后续拍摄许可 | 当期官方渠道查询 + 按规定申报 + 场地权利人同意 |
| 电池按标称规划航拍时长 | 返航电量不足、炸机、伤到人 | 一律按标称一半，风与低温再折 |

## 实操要点

- [ ] 每个移动镜头开机前说出动机；说不出就不用稳定器、不架滑轨。
- [ ] 首次进陌生场地只带小支撑；正规三脚架只在已建立关系、且能确认无危险时上架。
- [ ] 练两周手持：负重、步法、支点、背带承重，用 03 章「每十步少于一次明显跳动」验收。
- [ ] 若租稳定器，把平衡与拆装在拍摄前一天做完并计时，超过五分钟的设备不进当天计划。
- [ ] 无人值守与延时：许可、大字标识、留电话、反对即停、无关第三人时段关机；出发前把这几项写在机器挂牌上。
- [ ] 运动相机只在正规机器进不去的位置使用，声音当参考轨，不当主轨。
- [ ] 航拍前完成三件事：当期官方渠道查空域与规定、按规定申报或报备、取得场地权利人同意；现场有反对者立即降落。
- [ ] 每次特种器材变更后重跑 07 章出发前清单，同步更新负重、电量与备份容量。
