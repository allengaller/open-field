# 摄影机与镜头选择

> 选型不是挑参数最高的机器，而是挑那台在你最难受的时刻还能开机、还能看清、还能撑到事件结束的机器。

本篇是全库唯一承载器材经验数值的位置。其它章节凡涉及器材，一律链到这里；本篇只给「选型逻辑 + 判断表 + 踩坑代价」，参数只在它会改变决定的时候出现。声音技术数值不在本篇，见 [同期声与收音](../04-声音/同期声与收音.md)；现场流程、负重与健康阈值见 [现场工作流与安全](../07-拍摄执行/现场工作流与安全.md) 与 [一人团队与单机作业](../07-拍摄执行/一人团队与单机作业.md)。

---

## 一、先从场景反推优先级，再去看机器

一台机器的规格表没有一行能替你回答「我拍不拍得完」。把你要拍的场景写死，淘汰项自己会浮出来。

| 你的场景 | 决定性约束 | 会被这一条直接淘汰的机型类别 |
|---|---|---|
| 车间、作坊、巷道（人贴着人） | 体积与取景距离；机身要能举过头、贴胸口 | 需外接跟焦与大型监视器的电影机 |
| 村里堂屋、夜间灶间（无灯、单一光源） | 高感可用性与噪点形态 | 小底便携机、上一代手机 |
| 突然发生的事（争执、事故、装卸） | 开机到在录的秒数、预录缓存 | 需组合菜单才能开机的机型 |
| 必须极静（会议、访谈、夜里守机位） | 机身风扇与快门声、无机械快门选项 | 风扇高频启停的机型 |
| 一个人拎两小时 | 整机重量与电池位置 | 见 07 章负重线，超线即不用于跟随 |
| 一天八小时不换电 | 电池续航与可换电热插拔 | 只能 USB 供电录制的机型 |

**判断方法**：把上表按你最常遇到的顺序排一遍，第一条与第二条淘汰完之后剩下的类别，才是候选池。多数人的错误是反过来——先选定机器，再给场景找理由。

## 二、传感器尺寸：大底不等于好用

这是器材讨论里被说坏得最厉害的一句。尺寸本身只决定三件事，而且三件事互相冲突。

| 维度 | 大底的真实变化 | 小底的真实变化 | 纪录片判断 |
|---|---|---|---|
| 景深 | 同视角同光圈下更浅 | 更深 | 弱光手持时浅景深是负债：跟焦失败率上升，人物一动就跑出焦外 |
| 高感 | 单像素面积通常更大，信噪比更好 | 噪点更早出现 | 决定可用性的是**噪点形态是否可整理**，不是 ISO 数字 |
| 动态范围 | 通常更宽，暗部可提 | 提暗部易出彩噪与色偏 | 高反差车间、门口逆光场景才吃得满 |
| 体积功耗 | 机身、镜头、散热同步上升 | 整套可入口袋 | 功耗与发热是隐性成本，直接换算成停机次数 |
| 镜头生态 | 大光圈定焦贵且重 | 小镜头便宜轻 | 一只大光圈定焦的重量要计入每日负重 |

一句话结论：**如果你打算弱光手持、并且要拍到人的动作而不是人的鼻尖，中画幅级别的大底不是目标，能稳住的底才是**。全库反复出现的那条优先级仍然成立——在录 > 焦点 > 曝光 > 美感。

## 三、自己测出这台机器的可用感光度上限

厂商给出的高感样片一律不作数：它们的噪点已经过降噪处理，光照条件也是受控的。你要测的是**你自己会拍的那种光**。

**测试流程（一次做完，约一小时）**

1. 找一个真实的暗场景：夜里没开灯的堂屋、只有天窗的库房，别用影棚。
2. 把 18% 灰卡（gray card）放在人物脸部位置，让脸和灰卡同受一种光。
3. 拍一段固定机位的空镜（无事件），保持同一曝光，逐档提升感光度到最高档；每档录 10 秒。
4. 回放在**外接监视器**上看，不在相机三寸屏上看。三寸屏会把噪点全部藏起来。【通行共识】
5. 记录三个断点：肤色色偏开始出现、暗部彩色噪点无法用降噪去掉、纹理被抹平成涂抹感。
6. 以**第一个断点前一档**作为你的日常工作上限，把结论写进 [路书](../../研究/路书.md) 的设备卡。

| 现场光照 | 处理 |
|---|---|
| 上限以内 | 正常曝光，优先保护肤色 |
| 超上限半档到一档 | 可拍。先开大光圈、放慢快门到 07 章的运动模糊下限，再动感光度 |
| 超两档以上 | 拍。但把它标记为「仅存证、不入片」，同时考虑 04 章的补光门槛 |
| 完全看不见 | 不硬拍。换机位到窗口、门口，或改音频优先 |

**踩坑代价**：一场不可替代的争执，用超过上限两档拍完，得到一版色彩分离、字幕都难辨认的素材。这种素材在剪辑台上不是「质量差」，是**不可用**，而它占掉的存储和整理时间和好素材一样。

## 四、机身类别对照（按纪录片在意的差别）

只列会改变决策的差别，不列参数。

| 项目 | 微单 | 便携摄像机 | 口袋运动机 | 手机 | 电影机 |
|---|---|---|---|---|---|
| 续航 | 中，需备多块 | 好，大块可热换 | 差，发热快 | 中，边充边录常见 | 差，需外置供电 |
| 发热停机 | 高温长录常见 | 少 | 常见 | 常见，且先降屏幕亮度 | 视机型 |
| 单次录制上限 | 部分机型有二三十分钟档位限制 | 基本无 | 无 | 无 | 无 |
| XLR 直入 | 多需手柄或转接 | 常见自带 | 无 | 无 | 自带 |
| 内置无级 ND | 少 | 常见 | 无 | 无 | 自带 |
| 防抖 | 机身或镜头，强 | 镜头为主，稳 | 电子增稳，裁切视野 | 计算防抖，裁切且有果冻 | 无（设计上不用） |
| 码流档位 | 全内帧与高位深选项增多 | 中 | 中 | 低到中 | 高 |
| 体积噪声 | 中，快门声明显 | 中，静音好 | 小 | 无声 | 大 |
| 一人手持两小时 | 可（视重量） | 可 | 可 | 可 | 不可 |

各格里「视机型」的部分**以厂商当期手册为准**，本篇不代答。

## 五、镜头：便利与进光的交换

| 选择 | 得到 | 付出 |
|---|---|---|
| 标准变焦 | 机位不动也能改变景别；变焦即改构图 | 光圈小一档到一档半；呼吸效应（focus breathing）明显；最近对焦距离远 |
| 大光圈定焦 | 弱光、可分离主体、手动跟焦有刻度 | 换镜头就是断电重来；一只镜头只服务一种景别 |
| 广角定焦 | 狭窄空间可退身；景深深，脱焦风险低 | 边缘拉伸，人脸贴近时失真 |

**为什么「一只标准变焦 + 一只广角定焦」够一个人用**：一人团队没有换镜头的时间预算。变焦负责所有景别切换，广角定焦只在两件事上出场——弱光到变焦光圈不够、空间窄到退无可退。这两件事合计占你拍摄时间的比例很小，为剩下的部分再买一支长焦，收益远低于它占的重量。

变焦的两条隐蔽代价要提前知道：一是**非齐焦**（varifocal）变焦在拧变焦环时焦点会跑，长焦端尤其明显，买之前现场试：拧到最长端对焦，再快速拧回最短端，看画面是否仍实。二是呼吸效应：变焦改变视角的同时视角场也在变，你以为只是推近，实际是「推近 + 悄悄换了构图」，这在需要精确复现同一机位时是麻烦。【通行共识】

## 六、自动对焦：什么时候敢用

| 情形 | 判断 |
|---|---|
| 人物面谈、坐着不动、脸占画面 1/3 以上 | 敢用，锁定到人脸 |
| 前景有人穿行（车间、市场、街面） | 不敢用。它会跟着最近的陌生人不放 |
| 手持跟拍、你自己走位 | 风险高：抽动与焦点漂移会同时出现 |
| 极弱光、低反差（白墙前的人） | 不可靠，对比检测会来回拉 |
| 无人值守守机位（07 章长期跟拍） | 用超焦距 + 手动，别把整场赌在合焦指示上 |

**结论**：把自动对焦当成「可用但需要负责」的选项。每次开机先看焦点在哪，这是 07 章优先级里的第一任务。近视带来的取景困难，走 [现场工作流与安全](../07-拍摄执行/现场工作流与安全.md) 的三种替代方案（外接监视器置于胸前视线高度、隐形眼镜配合屈光度调节或长眼点距取景器、不取景用超焦距加固定机位），本篇不重复。

## 七、卡口与转接：钱花在看不见的地方

| 项目 | 风险 |
|---|---|
| 机械转接环 | 无电子触点 → 不能机身控光圈，手动对焦，防抖不握手 |
| 带触点转接 | 对焦速度与追焦可靠性常低于原生卡口；机型组合相关，需实测 |
| 转接老镜头 | 体积与重量增加；边缘画质与反差可能不够；无距离刻度则跟焦全靠手感 |
| 减焦增光 / 微距延长 | 画质损失与暗角；纪录片几乎不需要 |

纪律：**转接件不进必备清单**。任何转接方案在出发前跑一遍第六节的自动对焦表；跑不过就不要带进现场。一个不能盲操作的转接环，等于给你多买了一只不能用镜头。

## 八、一台顺手 > 两台互补

「一台主机 + 一台备用」听起来稳，实际成本在迁移：两套菜单、两组电池、两种色温倾向与两套编码参数，加上出门前多检查的二十分钟。

| 方案 | 真实结果 |
|---|---|
| 两台不同类机型（微单 + 口袋机） | 备用机几乎不会被掏出来，因为参数不匹配；两边素材色调与噪声不统一，增加调色与匹配成本 |
| 两台同型号 | 唯一有意义的双机方案：电池、菜单、色准、镜头全共用 |
| 一台 + 手机 | 一人团队的最优解。手机是**另一件事的工具**（见下节），不是备用机 |

**判断标准**：如果第二台机器的唯一理由是「万一坏了」，那答案通常是租一台同型号的备用机（见第九节），而不是买。若确需两台，两台的操作路径必须完全一致。

## 九、什么情况下手机是当前最优解

手机不是弱一档的相机，是另一种工具。以下任一条件成立时，它就是当前最优：

| 情形 | 手机为何赢 |
|---|---|
| 首次接触、对方犹豫 | 手机的拍摄意图解释成本最低。「我用手机记录一下」比掏相机更容易被接受；同意门槛见 [知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md) |
| 极窄空间（摊位内、驾驶室、楼道） | 体积与取景距离无可替代 |
| 需要被摄者放松（年轻人、小孩、街面） | 相机改变现场权力关系，手机改变得更少 |
| 突发且来不及组装 | 从口袋到在录不超过三秒 |
| 只要存证不要成片 | 元数据（时间、地点）完整，够做证据链的附件；见 [证据链与可复核性](../../工程/架构.md) |
| 弱光静态、需多帧合成 | 计算高动态范围在静态场景确实胜过同价位相机；**但一动就出现涂抹与鬼影**，运动场景不适用【通行共识】 |

手机的三条硬限制：**录音不能直入**（需外接，见 [收音装备](./收音装备.md)）；发热时先降屏幕亮度，你看不清构图；来电、通知、后台刷新会打断录制——录前开飞行模式（或免打扰 + 关闭后台自动刷新），并确认电量策略不会在录制中限制性能。存储上手机不是长期介质，当天倒出。

## 十、买还是租：只写方法

不给价格（价格会变），给**四问 + 一条线**。

| 一问 | 判定 |
|---|---|
| 这件器材会每周用到吗？ | 不会 → 租或借；会 → 进买入候选 |
| 它带来的收益是「能拍」还是「拍得更好看」？ | 「能拍」→ 买；「更好看」→ 优先级往后 |
| 它的技术半衰期多短？ | 越短（机身、编码器、AI 功能）越该租或延后 |
| 坏了会不会毁掉一次不可重复的拍摄？ | 会 → 买可换电池、有本地售后的类别；不会 → 租 |

**一条线**：单次尝试的沉没成本上限，以你自己的试错资金包上限为准；具体额度是私人参数，不入公开仓库（机制见 [行动总纲](../../研究/行动总纲.md)）。任何一笔器材支出先问「这笔钱换成一天人工或一次交通，哪个能让素材更多」。多数答案是后者。

**租的三条纪律**：出发前当面验（sensor 坏点、卡口松动、录制上限、电池健康度）；租期第一天当作测试日而非拍摄日；归还前自己复制一遍素材清单并核对校验和（流程见 [编码存储与备份](./编码存储与备份.md)）。

## 十一、菜单与三键预设：为手疼时设计操作

一人拍摄时你看的是现场，不是屏幕。所有需要「进菜单找」的操作，都会在关键时刻变成一次丢失的镜头。

| 键位 | 建议绑定 | 理由 |
|---|---|---|
| Fn1 | 录制启停（与快门键并行） | 戴手套、手疼、单手持时仍能开录 |
| Fn2 | 电平表 / 音频监视 | 04 章的电平阈值要一眼可见 |
| Fn3 | 白平衡预设位（日光 / 荧光灯 / 自定义） | 换屋即换光，自动白平衡会在同一场里漂 |
| 我的菜单首页 | 编码格式、帧率、ND、峰值对焦，四项 | 只在这四项需要改时进菜单 |

**预设冻结**：一旦确定，一个拍摄季不改。理由见 [一人团队与单机作业](../07-拍摄执行/一人团队与单机作业.md)——开机不超过三步、现场只动「对焦与开关机」。三键预设的唯一目的是让**盲操作成立**：你要能在不低头、不看说明书、不摘手套的情况下完成开机、确认在录、看到电平。

## 常见误区

| 误区 | 代价 | 更正 |
|---|---|---|
| 参数党：以规格表排名决定购买 | 花钱买回来用不到的档位，重量与发热全自己扛 | 用第一节场景表反推淘汰项 |
| 买装备当开工 | 器材到位、田野没开始；资金包被折旧吃掉 | 先完成一次真实拍摄，再列缺口 |
| 为不存在的场景配置 | 买了长焦却从不拍远景，买了稳定器却几乎不移动 | 每次配置对应一场已经发生过的、重拍一次的代价 |
| 大底等于好用 | 浅景深导致脱焦、机身重导致手臂抖、发热导致停机 | 第二节的三件事互相冲突 |
| 信厂商高感样片 | 现场发现噪点不可整理，素材只能存证不能入片 | 自己做灰卡 + 肤色测试 |
| 备机买不同型号 | 备用机永不出场，色调还互相拖累 | 同型号，或租 |
| 手机当备用机 | 关键场次交给最不可靠的录音与发热路径 | 手机当「另一件事的工具」 |
| 菜单不设快捷、靠现场找 | 每场丢十几秒，突发事件往往就在这十几秒 | 三键预设 + 预设冻结 |
| 转接环当省钱手段 | 转接后自动对焦与防抖半残，现场不敢用 | 转接件不进必备清单，出发前实测 |
| 用最低码流「省卡」 | 卡钱省下，调色与降噪的上限一起省掉了 | 码流档位与存储规划见 [编码存储与备份](./编码存储与备份.md) |

## 实操要点

- [ ] 用第一节的场景表为候选类别做一次硬淘汰，写下淘汰了谁、为什么。
- [ ] 完成一次灰卡 + 肤色感光度上限测试，用外接监视器判读，把三个断点写进设备卡。
- [ ] 确认整机的开机到在录不超过三步、盲操作三键已绑定并戴手套试过。
- [ ] 变焦镜头现场验非齐焦与呼吸效应；定焦只留一支广角大光圈进必备清单。
- [ ] 自动对焦逐格过一遍第六节表，标出「本场不敢用」的情形并改手动 + 峰值对焦。
- [ ] 任何转接方案在出发前跑完自动对焦表，跑不过就不带。
- [ ] 器材支出前算四问，并与「换成一天人工」比较；上限以你自己的试错资金包为准。
- [ ] 每次器材变更后重跑一遍 07 章出发前清单，把负重与电池数量同步更新。
