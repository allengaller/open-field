# 灯光与电力

> 在非虚构现场，灯的第一个作用不是把画面照亮，而是让你能看清你正在拍的东西；电的第一个难点不是容量，是谁的线、谁的责任。

灯光判断（这是什么光、该不该要这种光）属于 [光线与色彩](../03-电影语言/光线与色彩.md) 与 [非虚构摄影](../07-拍摄执行/非虚构摄影.md)；本篇只讲**灯具与电力器材怎么选、怎么配、代价是什么**。

---

## 一、第一条纪律：不打光优先于打好光

07 章的取舍顺序在这里完全适用：**先读光、跟光、换机位，最后才考虑补光**。补光一旦开始，你就从记录者变成了现场的一个变量。

| 目标 | 是否成立 | 说明 |
|---|---|---|
| 把主体从背景里分离出来 | 成立 | 这是纪录片补光的**首要**目的，不是亮度 |
| 把暗部恢复到有层次 | 成立 | 让人脸不是黑块、衣服有明暗，与 07 章「宁欠半档不过一档」不冲突 |
| 让画面好看 | 不成立 | 一旦以好看为目标，你会开始挪东西、改时间、要求人重来 |
| 改变现场质感 | **禁止** | 把灶间打得像棚拍，等于把这场戏的证据价值削掉一半 |

**绝对不动的东西**：为了打光把当事人从其真实活动中叫出来、等他换个位置、让他「再来一次走进门」，或等他「光好的时候」再干活——**绝不为了打光改变当事人的真实活动顺序**。这条不是美学判断，是伦理与事实判断：改了顺序的画面，讲的是你，不是他。同意与更详细的现场承诺见 [知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md)。

## 二、这些场合干脆别补光

| 场合 | 不补的理由 | 替代 |
|---|---|---|
| 对方刚同意、还在观察你 | 灯一亮，同意就作废了一半 | 手机或高感直出，见 [摄影机与镜头选择](./摄影机与镜头选择.md) 的感光度上限测试 |
| 深夜居住空间、私人哭泣、家庭争执 | 灯是入侵，会把事件打断 | 声音优先（阈值见 [同期声与收音](../04-声音/同期声与收音.md)） |
| 有电焊、粉尘、明火、潮湿地面的产线 | 灯具与线缆自身成为事故源 | 只借现场光，或改时段 |
| 空间只容两人转身 | 灯架 + 人 = 堵住退路 | 手持小面板，不用架 |
| 现场本身有强烈色温信息（钠灯、红光、烛光） | 补白会抹掉这些事实 | 保留色偏，在后期只做有限校正 |

## 三、最小便携灯光组合

一个人、一件行李的额度。按「能用三次以上」才进清单的原则排。

| 件 | 作用 | 淘汰判据 |
|---|---|---|
| 一小面双色温 LED 面板（手掌级） | 补反侧、补眼神光、夜间存证 | 无级调光不线性、低亮度闪、风扇不能关 → 淘汰 |
| 一块柔光扩散片 / 一段柔光布 | 把点光源变成面光源；**没有它，面板只会让脸更油** | 无 |
| 一只小型灯架或柔性三脚（可绑、可夹） | 顶光、侧后方光；能缠在栏杆与横梁上 | 需要工具展开、重、占包 → 不带 |
| 两个魔术贴绑带 + 一小卷 gaffer 胶带 | 把灯固定在任意现有物体上，不留痕 | 用普通透明胶：会留胶，现场不体面 |
| 一只小手电筒（暖光） | 走路、找插座、看接口，**不作为拍摄光** | 白光刺眼款不适合室内 |

**这套组合明确不含**：柔光箱、灯架横臂、旗、反光板大套、双色温管灯、电池一体式大额灯。它们在剧情片里有位置，在「一个人、两小时、随时要走」的纪录片现场基本是负债。

## 四、三个现场套路（背下来，不用想）

| 套路 | 做法 | 判定成功的标准 |
|---|---|---|
| **窗光补反侧** | 人靠窗侧坐，窗是主光。灯放相机另一侧、略低于眼高、加扩散，只补到「暗部有层次」而不是「两边一样亮」 | 亮暗面差约一档左右；关掉灯再对比，确认你补的是层次不是亮度 |
| **顶部柔光** | 夜间门口、摊前、桌案。灯尽量举高并加扩散，让光从上方偏前落下，模拟屋顶灯而不是手电 | 阴影落在下巴下方而不是脸上横着一条；对方不需要眯眼 |
| **手持跟随** | 灯在相机上方偏前 20–40 cm，**永远不直对脸**。跟着人走时光比一直变，靠眼睛看肤色而不是看曝光数值 | 走一圈回来回放，肤色不闪、不过曝、背景没被吃掉 |

手持跟随时灯越近越柔、越远越硬：距离翻倍，光强按平方反比衰减但**相对柔和度上升**（相对光源变大）。所以宁可「近处小声补一点」，不要「远处大功率照一片」——后者会把整个房间的现场光压掉。【通行共识】

## 五、LED 面板的三个真实问题

### 5.1 频闪与快门

廉价面板用脉宽调制（PWM）调光，在低亮度档尤其明显；与卷帘快门（rolling shutter）叠加会出现**滚动横带**，与全局快门叠加会出现亮度抽动。

| 处置 | 说明 |
|---|---|
| 先试高亮度 + 加扩散，而不是低亮度 | 很多面板在满功率时频闪最小 |
| 快门选市电频率的倒数整数倍 | 市电 50 Hz【核验】：优先 1/50、1/100 一类，逐档试到横带消失 |
| 与运动模糊下限冲突时 | 03 章给的快门不低于 1/(2×等效焦距) 是**运动模糊的下限**，频闪修正是**画面完整性的下限**；两者都要满足。做不到就先开大光圈、再动感光度，最后才牺牲其一并记录在案 |
| 现场快速判定 | 举起手机慢动作对着面板看有无条纹；无慢动作就用相机拍一面白墙，改快门逐档看带子 |
| 长期解 | 选支持高频调光或直流调光的类别；以厂商当期手册为准 |

### 5.2 显色与偏绿

用显色指数（Color Rendering Index）作筛选线，一般取 90 以上，并关注红色通道（R9）不为过低值【通行共识】。**双色温面板的老化与混色偏绿是常见故障**：冷暖两排 LED 混合出来的绿偏，白平衡拉不掉，只能靠肤色回听式的人工核对。

| 症状 | 现场判法 | 处置 |
|---|---|---|
| 偏绿 | 拍一张灰卡；灰卡在自定义白平衡后仍带绿 | 换灯或只用单色温；必要时接受并在处理登记里写明 |
| 肤色蜡黄 | 肉眼看比灰卡更可靠 | 降灯功率，让现场光占主导 |
| 不同灯之间色温不一致 | 两张灰卡分别在各灯下拍 | 同一场只用一盏灯；关灯比调灯快 |

### 5.3 风扇与静默

「极静场合」这一条约束会把一半面板淘汰掉。灯的风扇声在话筒里比你在现场听到的更明显，且**风噪声不是低频隆隆而是高频启停**，最难用降噪处理。【通行共识】

- 买之前：把面板调到最低亮度、在无回听的房间静置十分钟，听风扇是否周期性启动。
- 现场：能关风扇就关（多数面板有静音档，代价是降功率）；把灯放低、放偏，别朝话筒方向吹。
- 长期守机位（07 章）：风扇灯不适合，改用现场光或无风扇的被动散热小灯。

## 六、电力：真正的难点不是容量

### 6.1 电量算术（只有一种算法）

所有电池都换算到瓦时（Wh）才能比较与规划：

```
Wh = 标称电压 V × 标称容量 Ah
可用时长 h = Wh × 0.8 ÷ 负载 W
```

**规划线：一律按标称一半**。这与 04 章对无线发射器「按标称一半、常见两小时强制换」是同一条纪律，不是悲观，是低温、老化、放电曲线尾段与厂商测量口径四项叠加后的结果。【操作性建议】

| 因素 | 对容量的影响方向 | 现场后果 |
|---|---|---|
| 低温（冬季户外、清晨守机位） | 显著下降 | 按常温一半再折，多备一组，贴身保温 |
| 循环次数与年限 | 逐步下降 | 电池要有更换记录，别用「还能开机」判断剩余寿命 |
| 边录边充 / 边放边充 | 效率损失 + 发热 | 优先增加电池数量，而不是延长线 |
| 高功率输出（灯全亮、持续录） | 标称值往往在低载下测得 | 用你的实际负载测一次，写进设备卡 |

| 项 | 判据 |
|---|---|
| 当日总电量 | 按 07 章口径备足当日时长的 2 倍以上，分两包；本节的 1.5 倍只是**现场连续工作时段**的换算系数（含准备、回看、重录），不替代 07 章的备量下限 |
| 分装 | 电池分两包（与 07 章「电池 ≥2 倍当日时长分两包」一致） |
| 到线阈值 | 剩余不足返回路程所需时，停止拍摄，不再「再拍一个」 |

### 6.2 取电的合规与责任

农村、市场、厂房的取电不是技术问题，是**许可与责任问题**。

| 情形 | 正当路径 | 明确不做 |
|---|---|---|
| 农户/店铺「你用我们的电」 | 请对方指定**哪一个插座**，当场试一次；口头同意也写进当日记录（谁、何时、哪条线） | 不自行到配电箱、表后开关、总闸处接线 |
| 厂房/园区需接现场电源 | 由现场负责人安排**持证电工**接线，或明确指定可用插座；把这条写进现场负责人知情同意（见 [长期跟拍](../07-拍摄执行/长期跟拍.md)） | 不自行开柜、不停别人的断路器、不改保护接地 |
| 公共区域（市场管理方、街区） | 向管理方申请并留联系人电话 | 不从不属于自己的插座「借用」而不告知 |

**借电话术（照念即可）**：「我有件事想麻烦您——我拍的东西要用电池，今天电量不太够。能不能在您店里借一个插座，我就给我的小灯和充电宝用，线我走墙边，不挡路。大概几点我可以拔？万一跳闸了您跟我说，我马上收。」

这段话做四件事：说明用途、限定负载、承诺不挡道、约定归还时点。**不要说「就充一会儿」然后一整天插着**——一次不守约，这条街上后面几家的门都关。

### 6.3 负载与回路风险

| 风险 | 现场做法 |
|---|---|
| 老屋一个回路带全屋，容量不明 | 只用一个插座，不同时接大功率；先问「这条线上还有什么在用」 |
| 插线板串插线板、多头转接 | **禁止**。一只带过载保护的插线板，一路到设备 |
| 与制冷、焊机、电机、电炉同回路 | 换回路。这些设备启动电流大，跳闸是常态；你这边一断就是丢素材 |
| 潮湿地面、雨天河沿、金属地面 | 灯具与接头离地；接头不进水；有漏电保护器的回路优先 |
| 线缆穿越通道 | 走墙边、贴地、用压线条或胶带压平；没有条件就换机位，不要横拉 |
| 无人看管的通电灯具 | 只要人离位就关灯拔电；灯架配重或绑牢（与 07 章安全检查一致） |

### 6.4 充电宝、假电池与直流供电风险

| 器材 | 用处 | 风险 |
|---|---|---|
| 大容量充电宝 | 灯、监视器、录音机、手机 | 低温掉电；航空随身携带不放托运（07 章） |
| USB 直供相机 | 应急延长 | 电压跌落会让相机**在录制中断电**；一旦供电不稳就拔，别赌 |
| 假电池（dummy battery） | 长时间固定机位、无人值守 | 失去机动性；线材要留足余量并固定，别绷在接口上 |
| 车充 / 逆变器 | 转场路上补电 | 只在车停稳、发动机运行时充大功率设备；注意车辆手册限制 |

**硬纪律（与 07 章一致，不重复论证）**：**录音机与相机分别有独立电源，不共用一块充电宝**。共用一块的结果是：它耗尽时你同时失去画面和声音，且失去的是同一场。

## 常见误区

| 误区 | 代价 | 更正 |
|---|---|---|
| 光线不够就加灯 | 改变现场行为，素材从「记录」变「布置」 | 先读光、跟光、换机位，最后才补 |
| 为了构图等光、等人重来 | 违反不改变活动顺序的纪律 | 时间不够就减范围，见 [路书](../../研究/路书.md) |
| 灯买大了 | 用不了两次，重量与供电需求把整套计划拖垮 | 手掌级面板 + 扩散，够一个人用 |
| 不扩散直接照脸 | 油光、硬影、对方眯眼、真实感全丢 | 无扩散片 = 灯不进清单 |
| 只按标称时长规划电池 | 下午两点没电，或天黑前收不了工 | 一律按标称一半，低温再折 |
| 一个充电宝带所有设备 | 同时失去画面与声音 | 独立电源，分两包 |
| 私自从配电箱取电 | 安全事故 + 关系彻底破裂 + 法律责任 | 只走现场指定插座、由持证电工接线 |
| 插线板串插线板、横拉过道 | 跳闸、绊人、被赶走 | 一路一板、走边压平 |
| 低亮度档用灯不查频闪 | 整场滚动横带，回放才发现 | 白墙 + 逐档快门现场验证 |
| 相信「静音档一点声没有」 | 话筒里全是高频启停 | 静置十分钟实测；能关灯就不开灯 |
| 用灯的多少衡量投入 | 时间花在布光而不是等待和提问 | 一灯一扩散进清单，其余一律不带 |

## 实操要点

- [ ] 出发前用第五节频闪法测一遍手头面板，记下「无横带」的快门档位。
- [ ] 灰卡测一次灯的偏色：白平衡后仍带绿或品红的灯，换掉或限用于单色温场合。
- [ ] 灯光清单封顶：手掌级面板一只 + 扩散片 + 柔性小架 + 绑带与胶带 + 暖光手电，多一件说明理由。
- [ ] 全部电池按标称一半换算成当日总时长，1.5 倍备足，分两包装。
- [ ] 借电话术背熟；每次取电在当日记录里写明谁同意、哪个插座、何时拔。
- [ ] 不自行接触配电箱与总闸；厂房取电必须经现场负责人安排持证电工。
- [ ] 相机与录音机电源严格分开，不共用同一充电宝。
- [ ] 收工时自查一次：今天有没有因为灯而改变当事人的活动顺序；若有，写进更正说明（模板见 [现场工作流与安全](../07-拍摄执行/现场工作流与安全.md)）。
