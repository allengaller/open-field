# 收音装备

> 声音是这部片子里最容易毁掉、也最便宜修复的一环。毁掉它的通常不是话筒不够好，而是一条松掉的线、一块没电的发射器和一次没有监听就开录。

**本篇只管三件事：买什么、怎么配、为什么是这套组合。** 所有运行数值——电平区间、采样率与位深、拾音距离、风级对应、双系统对表步骤——的唯一权威出处是 [同期声与收音](../04-声音/同期声与收音.md)，本篇一律写「阈值见 04 章」，不重复也不覆盖。若日后发现本篇任何一句与 04 章不一致，**以 04 章为准并回来改本篇**。

---

## 一、一条 solo 信号链，以及每一环怎么断

```
声源 → 话筒（换能） → 线/无线链路 → 前级与限位（录音机或相机） → 记录格式与介质
```

| 环节 | 典型故障 | 症状 | 装备侧对策 |
|---|---|---|---|
| 话筒 | 电容头受潮、膜片脏、领夹夹片疲劳 | 单侧忽大忽小、高频消失 | 干燥盒收纳；每次拍摄前对录 60 秒回听（04 章流程） |
| 线 | 插接氧化、XLR 第三脚虚接、3.5 mm 弹片松 | 偶发爆响或单声道丢失 | 每根线备双份；接头定期酒精清洁；不用「晃一晃就好」的线 |
| 无线链路 | 频段拥挤、电池尾段、天线被身体挡住 | 断续、噗声、距离一短就好 | 见第三节；接收端天线朝向与位置是免费增益 |
| 前级 / 限位 | 增益档位选错、限位器被当作救急 | 底噪极高或削波 | 买有**明确增益步进与限位器旁通**的录音机；阈值见 04 章 |
| 记录 | 卡速不足、文件容器不支持多轨、未监视就开录 | 丢帧、断文件、轨数不符预期 | 出发前用满轨最长时长录一次，回放抽检头中尾 |

**装备的第一评估标准不是音质，是「这条链上有多少环节可能悄悄断掉」。** 环节越少越好：能两环解决就不要用五环。

## 二、四类话筒：按场景配，不按爱好配

| 类别 | 用在 | 一个人的现场优点 | 缺点 |
|---|---|---|---|
| 领夹（lavalier） | 面谈、跟随、长时间守机位 | 稳定、不占手、不受机位移动影响 | 衣物噪声与房间混响无法靠后期解决（04 章给出治理顺序） |
| 手持（handheld） | 街头采访、有仪式感的递话筒 | 坚固、指向直觉、防风体内置、离口近 | 入画；每次递出去都是一次关系动作 |
| 枪式 + 挑杆（shotgun on boom） | 可控环境、能借到一只手 | 挑杆位是画外声源，定位最准 | 见第五节：一人操作多数不成立 |
| 环境对录麦（ambience pair） | 集市、机器声、雨、鸟、车间底噪 | 一次收整场，后期做空间层 | 单支无用，必须成对且对称摆放 |

**四个都买是新人最常见的一次浪费。** 一人团队的现实配置是：**领夹为主，手持备一支，机顶枪式兼作挑杆的替代位，环境对录麦可选**。拾音距离与各自适用距离段见 04 章的表，本篇不列数字。

关于「指向性」（polarity pattern / 超指向）：超指向在室内会把混响比例推得更难看，它解决的是「距离远」，不解决「房间差」。04 章的治理顺序（换房间 > 缩短距离 > 关电器 > 加吸声）在装备上的含义是：**先花钱改善位置与房间的选择，再花钱升级话筒。**

## 三、无线系统的购买与配置要点

| 要点 | 判断 |
|---|---|
| 频段与合规 | 只按设备铭牌标注频段与现行无线电管理规定使用；**不提供任何规避审批、私改发射功率或绕开频段限制的方法**。可用频段与功率的现场结论以铭牌及现行规定为准（04 章同口径） |
| 先扫后用 | 支持开机扫频并锁定空闲信道，比「自动跳频」的营销说法更可验证。扫完把可用信道数记下来——04 章的判断是「能协调的最多只有一半」，人群密集场地按这条打折规划 |
| 延迟 | 无线链路存在毫秒级延迟，正常不影响口型同步。若口型对不上，先查相机内音频处理与后期对齐，不要把延迟当借口（同步流程见 04 章双系统六步） |
| 多路互扰 | 同场两套发射时，天线间距、高度与朝向比参数更管用；两套发射器不要贴身对贴胸同侧 |
| 电池策略 | 按标称一半规划，常见两小时强制换（04 章）。装备侧要求：**电池仓可现场盲换、备电与主机同包不同袋**；灯与电力侧同口径见 [灯光与电力](./灯光与电力.md) |
| 接收端挂载 | 热靴位会挡住相机屏与提手；能接受**分离式**（接收机别腰间、短线进相机）就多一个可控自由度，也多一个断点 |
| 接口 | 接收机输出到相机的线**长度越短越好**，接头别用转接叠三层（04 章对 XLR→3.5 mm 线长度与衰减、地隔离有明确要求） |
| 藏麦 | 位置与衣物噪声的物理成因、试录与动作测试流程全部见 04 章；装备侧只有一条：**买带应力释放结构的领夹线，并把 moleskin / 毛毡贴当耗材常备** |

## 四、录音机：通道分配与安全轨

| 通道 | 内容 | 去向 |
|---|---|---|
| 1 | 主话筒（领夹或挑杆位） | 正常电平（阈值见 04 章） |
| 2 | 同路的**安全轨**，与主轨同源、电平更低 | 04 章的原则：一轨正常、一轨降低电平，用动态余量换一次保险 |
| 3 或独立机 | 环境 / 备用话筒 | 单独立分轨，不做有损内录 |

**装备侧对安全轨的取舍**：要买**支持同源多轨且各轨增益可独立设定**的录音机。如果录音机没有这个能力，用 04 章的替代做法（机内一轨 + 录音机一轨）。**不要把安全轨当作电平控制的替代品**——录的时候仍然要监视，阈值见 04 章。

其它选购判据（都在「只有一双手」这一约束下）：

- 有**实体增益旋钮**且旋钮位置可被手摸出来，而不是只能进菜单调。
- 有耳机监听输出，且监听延迟低到能立刻听出问题。07 章说监听耳机是单机性价比最高件，录音机是它的载体。
- 记录格式与位深、采样率起步值见 04 章；存证用分轨，不做有损内录。
- 供电独立，**不与相机共用同一充电宝**（07 章硬纪律）。
- 有外接时码输入（BNC 或经配件）者，才谈得上第八节。

## 五、挑杆加防震架：一个人现实吗

**诚实结论：多数情况下不现实。** 一人同时举杆、控向、跟焦、看电平，超过 07 章「注意力可靠并发上限 2 项」。硬撑的结果是画质声音同时下滑，而且手臂会先输。

| 替代 | 做法 | 适用 |
|---|---|---|
| 机顶短杆枪麦 | 相机上方前伸，指向嘴而不是天花板 | 面谈、2 米内、机位不动 |
| 腰带顶杆尾 | 04 章给出的 solo 组合：小挑杆杆尾顶腰带，可跟一段有限时间 | 需要一点挑杆角度又不加人 |
| 领夹 + 机顶双路 | 一主一备，两套独立电源 | 默认配置 |
| 桌面 / 手持位 | 手持麦递出，或麦放桌面用角度 | 街头、坐谈、桌上有杂物可利用 |
| 真挑杆手 | 只在不可替代场次借人（判据见 07 章「必须加人判据」） | 预算换素材，最划算的一类支出 |

**防震架（shock mount）** 只在挑杆与固定机位上有意义。机顶麦用**带内部悬浮的机顶架**即可；把防震架当通用件买回来，多半变成多占包的重量。

## 六、防风：海绵套不等于防风

风级与对应防护、低切使用全部由 04 章管辖。本篇只补装备侧的三句：

| 场景 | 装备动作 |
|---|---|
| 室内穿堂风 | 关窗优先；装备解决不了（04 章治理顺序） |
| 微风、市场、街口 | 毛衣套（blimp 之外的常规档）随包常备，别在需要时找不到 |
| 大风、屋顶、山口 | 按 04 章风级表升档；**风篮 + 毛衣双层**是一人可操作的上限，再加人就没有第三只手 |

收纳纪律：**防风罩不要压在其他器材下面**，被压扁的毛衣套外形一旦变形，高频风噪就回来了。

## 七、时码与场记板：双系统里它们到底值多少

| 手段 | 装备要求 | 值不值 |
|---|---|---|
| 打板（视觉爆点 + 高频声点） | 零成本，手指或场记板 | **永远做**。04 章要求高频爆点，画面里能看见闭合瞬间最好 |
| 摄影机与录音机同时基对到秒 | 两机能设时间；每 30 分钟重对表（04 章） | **必做**，这是最便宜的时间码 |
| 外接时码盒 / 时码发生器 | 相机有 TC 输入、录音机支持锁码 | **单机长期跟拍不值**。多机、需要频繁同步、或每天几十段双系统才回本 |
| 无线时间码（如厂家生态） | 锁频段、锁电池、锁故障面 | 引入两个新环节；对一人团队通常净负 |

**判据一句话**：如果你每天的素材不超过三四段双系统，人工对表 + 打板就够，省下的钱和重量拿去多买一块电池。同步流程与抽检方法见 04 章，日志字段见 [素材管理与日志](../08-剪辑后期/素材管理与日志.md)。

## 八、备份录音机的放置纪律

备份录音机最大的失败不是没电，是**没开、放错位置、或被自己的衣服盖住**。

| 项 | 纪律 |
|---|---|
| 开机顺序 | 录音机先开、相机后开；收机相反，两头各留时长余量（04 章） |
| 位置 | 与话筒同一侧、不与发射器贴身并排（互扰）；口袋外侧优于内侧 |
| 指示 | 用不反光的胶带把录音状态灯露出来，让自己一低头能看见「在录」 |
| 电源 | 独立电源，不共用充电宝（07 章） |
| 介质 | 备份机的卡单独倒、单独命名（命名规则见 [素材管理与日志](../08-剪辑后期/素材管理与日志.md)） |
| 每天一次 | 空场录 60 秒再回听，确认两机都在写、都有声（与 04 章试录同一条动作） |

## 九、这套配置在只有一双手时的操作顺序

| 步 | 动作 | 完成后你才允许做的事 |
|---|---|---|
| 1 | 装领夹、贴防摩材料、做应力释放 | 现场走动 |
| 2 | 开备份录音机，确认在录（灯 + 回听） | 碰相机 |
| 3 | 开主话筒无线发射，扫频锁定，换电确认 | 举机器 |
| 4 | 开相机，检查时基与两机时间一致 | 调构图 |
| 5 | 打板（或手指），确认画面里可见 | 开始对话 |
| 6 | 前 30 秒内看一次电平，之后靠监听耳机 | 全程注意力给提问与构图 |
| 7 | 收：先停相机，留余量后停录音机 | 当场倒素材、核对（见 [现场工作流与安全](../07-拍摄执行/现场工作流与安全.md)） |

**注意**：录音链永远在摄影链**之前**启动。这是 07 章「在录优先」的装备版，也是唯一一处顺序错误会让你把整场对话丢掉。

## 常见误区

| 误区 | 代价 | 更正 |
|---|---|---|
| 先买最贵话筒 | 房间与位置没变，音质还是不行 | 花钱顺序：位置/房间 > 缩短距离 > 话筒 |
| 四类麦全配齐 | 重量、决策负担、现场找东西的时间 | 领夹为主，手持备一支，机顶枪式可选 |
| 海绵套当防风 | 起风后整段高频风噪 | 风级对应见 04 章，毛衣/风篮分层 |
| 靠限位器与安全轨代替监听 | 削波发生在模拟前级，救不回来（04 章） | 录时必监视；安全轨只是保险 |
| 一人坚持挑杆 | 注意力超载，画面声音同时下滑 | 第五节替代方案，或按判据加人 |
| 接收机贴身与发射器同侧 | 互扰、距离缩短 | 分侧、留天线间距与朝向 |
| 买时码盒当专业 | 多两个环节、多一份电池与故障 | 每天素材量小就人工对表 + 打板 |
| 备份机放在内侧口袋 | 收不到信号、被衣服摩擦、看不见在录 | 外侧、可见、独立电源 |
| 备份机与主机共用充电宝 | 同时失去两路声音 | 独立电源，分两包 |
| 用「听个响」的手机 App 代替有线监听 | 延迟与蓝牙编码让你听不出真实问题 | 监听走有线耳机；阈值与判法见 04 章 |

## 实操要点

- [ ] 画一遍自己的信号链，标出每一环的故障点与备件位置；环节数超过五就找机会砍。
- [ ] 默认配置固定为领夹 + 机顶枪麦 + 独立录音机双记录，动它需要写出理由。
- [ ] 录音机需具备同源多轨、独立增益、实体旋钮、有线监听；不满足不进入清单。
- [ ] 无线设备出发前扫频一次，把可用信道数量记进当日计划；按「能协调的一半」规划多路。
- [ ] 电池按标称一半、常见两小时强制换（04 章），发射器备电与主机同包不同袋。
- [ ] 备份录音机开机在相机之前，位置外侧、灯可见、电源独立。
- [ ] 第九节顺序表抄成卡片放包里，前 20 场照着走，形成肌肉记忆。
- [ ] 每次器材变更后重跑 04 章的试录回听动作（60 秒 + 坐起抱臂各五次），别把变更带进现场。
