# 课程与社群

> 课程与社群是**加速器也是陷阱**：它们能补上你没受过的科班训练，也能吃掉你最贵的资源——现场时间与素材处置权。本篇只给类型、判据与「没有老师时的替代方案」，不给任何具体课程。

上篇 [系列纪实与自媒体案例](../13-案例/系列纪实与自媒体案例.md) 里那条「只在评论区收反馈」的错法，本篇 §6 给它的解法（五人试映制）。

---

## 1. 本篇不给具体名字与价格

| 不给 | 原因 | 换成什么 |
| --- | --- | --- |
| 机构名、课程名、导师名 | 招生信息、师资与开课年份年年变，写进公开知识库就是造一份会腐烂的假依据 | 类型 + 你自己核实的判据（§3） |
| 价格、时长、名额 | 一律以对方当期页面为准；本篇任何数字都会误导排期 | 「按你自己的试错资金包上限换算」这条规则 |
| 结课证书、获奖与入选经历的可兑换性 | 无法核实，且行业价值不稳定 | 只算你能带回现场的三项东西（见 §2 末段） |
| 谁该加入、谁别去 | 与你项目阶段无关的推荐都是噪声 | 阶段匹配表（§2） |

## 2. 六种课程类型：给什么、代价、什么时候值得

| 类型 | 真正给的东西 | 代价与风险 | 什么时候值得 |
| --- | --- | --- | --- |
| 学位与在读项目 | 系统训练、图书馆与数据库、同侪评审、伦理审查的通道、学术身份 | 三到四年不拍现场；理论先行的判断习惯；机会成本极高 | 只有当你确实要进高校或研究所这条道；否则不值得 |
| 高校与学会办的短期训练营 | 密集评片、方法学词汇、跨校同侪 | 通常按学期公告，报名窗口短；对在职者时间不友好 | 你已有素材与问题、需要外部眼睛时，性价比最高 |
| 节展与机构的实验室、提案会 | 一次被专业评审当面问穿的体验；同行密度；后续资金线索 | 交的是「项目」不是成片；材料成本高；常被当成社交活动误报 | 你写得出提案但拿不到反馈时（见 [项目开发提案](../11-生产与资金/项目开发提案.md)） |
| 线上录播课 | 便宜、可暂停、可反复看同一操作 | 无评片、无反馈、完成率极低；内容常是软件教程而非方法 | 只用于学一项具体技能（收音、字幕、编码）；学判断没用 |
| 平台创作者课与付费社群 | 平台规则、变现路径、同侪 | 卖的是焦虑；案例不可核；常索取内容授权作对价 | 你已稳定更新、要解决分发与收入结构时才看 |
| 师徒式跟一位前辈剪或拍一段 | 判断顺序、工序细节、行业话 | 需真正认识；机会稀缺；容易被当成免费劳力 | 遇到愿意看片并当面说问题的人，优先级高于一切课 |

一条硬判据：**这门课带不走三样东西就别报**——一份被人当面批过的片（不是证书）、一个能持续看你片子的人、一条你明天就能改的工序。

## 3. 报名前必查八条【操作性建议】

把每一条的答案抄进你自己的登记表，抄不全即视为未读章程。

| 条 | 查什么 | 踩线判据（出现即不报） |
| --- | --- | --- |
| 1 | 教学大纲是否公开到章 | 只给宣传语，不给逐周内容 |
| 2 | 是否真的逐片评阅，还是只讲不评 | 「学员互评」为主且无教师结论 |
| 3 | 师生比与每次评片实际时长 | 无法给出可核实数字 |
| 4 | 你的素材与作品的著作权归属 | 要求任何形式的内容授权、优先使用权、平台独家 |
| 5 | 课堂放映与录屏的授权范围与期限 | 要求无限期、无地域限制的教学放映授权 |
| 6 | 课程录像的权属与是否二次售卖 | 你的提问与作品被剪进宣传物料 |
| 7 | 退改与中断条款、是否按次扣费 | 口头承诺可退、文本里没有 |
| 8 | 隐形成本（差旅、器材、拷贝、结课展映费用） | 报价与总成本差距需追问才知道 |

第 4、5 条是本库红线：素材是长期项目的资产，**用课程换曝光等于用资产换广告**（[../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.4 把伦理当基础设施，素材处置权是其中一件）。

## 4. 社群的五类与各自的噪声

| 社群类型 | 你能得到 | 噪声在哪 | 正确用法 |
| --- | --- | --- | --- |
| 节展与同行圈 | 放映机会、递片渠道、真实评价 | 圈子话术、首映条款与选送规则常被口传错 | 只当**发现渠道**，条款一律回章程原文（[电影节与展映](../12-发行传播/电影节与展映.md) §2） |
| 独立创作者群 | 器材经验、发布规则变动、情绪支撑 | 数据晒单与互相模仿，容易把定位漂成追热点 | 只问「怎么办到的」，不问「该不该做」 |
| 田野与学术圈（人类学、社会学、口述史） | 方法学语言、伦理审查经验、可引用的分析框架 | 对影像成果的采信度低，容易劝退 | 拿**问题**去，别拿成片去求夸（[影像民族志案例](../13-案例/影像民族志案例.md) §7） |
| 设备与技术群 | 故障排查、参数经验 | 消费建议与真实需要混在一起，升级冲动 | 只在现场出故障时查，非故障期不刷 |
| 平台运营与变现群 | 分发规则、结算口径 | 规则信息最易过期与以讹传讹 | 一律以平台当期规则页为准并截图存档（[自媒体分发](../12-发行传播/自媒体分发.md)） |

判断一个群值不值得留，只看一件事：**过去一年里，它有没有改变过你现场的某个动作**。没有就是社交娱乐，不是资源。

## 5. 信息源分级与留档

| 级别 | 类型 | 用法 |
| --- | --- | --- |
| 一手 | 发布主体自己的当期页面、正式文件、邮件答复 | 唯一可作依据的来源；存快照与访问日期 |
| 二手 | 汇总号、转述帖、聚合平台 | 只当线索，顺着去找一手 |
| 自述 | 个人经验贴、结课感想 | 只用于判断「值不值得投入」，不用于判断条款 |

三条纪律：**口头与社交软件答复不作条款依据**（要一封邮件）；**任何转述的时间与金额都不回填进本库**；**涉及自身义务的信息一律写清来源与核实日期**（对齐 [事实核查与更正](../10-伦理法律/事实核查与更正.md) 的断言分级）。

学术侧的合法身份问题：不在高校也可以用独立研究者身份投稿与登记（例如用公开的学术身份标识），但没有机构邮箱会让部分渠道变慢；这一条属操作性事实，具体做法以各系统当期说明为准。

## 6. 没有老师怎么办：五人试映制

你不是科班出身，也没有固定导师。**把「老师」拆成五个角色**，比找一个人可靠得多。

| 角色 | 选谁 | 只问什么 | 为什么是他 |
| --- | --- | --- | --- |
| 当事人代表 | 与你素材直接相关的那个人（本库一律化名与概括，不留可识别信息） | 有没有哪一处让你觉得被说错了、被露出来了 | 唯一有否决权的人（[知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md)） |
| 同行者 | 做同类田野或同类创作的一人 | 结构走不走得通，哪里开始走神 | 他知道工序，不会只说「挺好」 |
| 外行 | 与你题材无关的一人 | 没听懂的地方、猜不到的因果 | 检验信息供给是否只靠字幕与解说 |
| 方法侧 | 社会学／人类学背景的一人 | 你的证据能不能支撑你的结论 | 提前发现「评审不认影像」那类问题 |
| 技术侧 | 会收音或会剪辑的一人 | 声画有没有明显问题，规格对不对 | 唯一能救发布事故的人 |

流程（每次两小时以内，含讨论）：

1. 提前三天发出粗剪或 10 分钟节选，附**三个具体问题**（不给背景长文，背景长文会引导答案）；
2. 放映时你不解释、不辩护；片长与试映场次按 §7 的眼预算安排，长片只看节选；
3. 每人先说「哪一分钟开始走神」，再说「哪一处不信」，最后才给建议；
4. 你只做一件事：**复述你听到的问题**，确认没理解错；
5. 24 小时内把结论写进登记表：改／不改／存疑，每条写明理由与日期。

| 登记字段 | 说明 |
| --- | --- |
| 场次与日期 | 试映日、被摄者是否在场 |
| 角色 | 五类中的哪一类意见 |
| 问题原文 | 不修饰，保留对方的说法 |
| 判定 | 事实错误／结构问题／伦理问题／口味分歧 |
| 处置 | 改、删、匿名化、保留并注明分歧 |
| 复现标记 | 同类问题第二次出现即记为流程缺陷，改工序而不是改这一处 |

三条禁忌：**不许把五人试映变成夸夸会**（不提出问题不算出席）；**不许拿外行的口味压过当事人的异议**；**不许把当事人意见当授权**——授权走文书，不走在场反应。

## 7. 没有老师时的十二周自训循环

| 周 | 本周唯一约束 | 交付物 |
| --- | --- | --- |
| 1 | 一条片子不许用解说 | 3 分钟节选 |
| 2 | 全程只用一个机位 | 3 分钟 |
| 3 | 只做「只听不看」排表，画面全部后期配 | 声音排表一份 |
| 4 | 每段素材必须有一条依据说明 | 日志字段补全 |
| 5 | 一场戏不许超过两个镜头 | 3 分钟 |
| 6 | 把一集拆成两晚做完，检查断点是否自然 | 分次记录 |
| 7 | 一次不带机器的到访 | 现场笔记 |
| 8 | 全部对白加字幕，检查方言信息损失 | 字幕稿 |
| 9 | 用五人试映制走一次完整流程 | 登记表 |
| 10 | 依据改动工序的判据，重写你的 SOP | SOP 新版 |
| 11 | 重剪第 1 周那条片 | 对照两版 |
| 12 | 回看 11 周：哪条约束留下了，哪条被放弃 | 一页复盘 |

用眼预算：**自训周的成片精修每周不超过两次**，且不与拉片同晚；到期就停。

## 8. 向人请教的提问格式

一句好提问省掉一轮无效来回。**格式固定四段**：约束（我一人、每周发一条、视力受限）→ 已试（我试过什么、结果如何）→ 卡点（具体在哪一分钟、哪个字段）→ 想要什么（只要一个判据／只要一个做法）。

反例：「我这片子是不是节奏有问题？」——这类问题只能得到安慰，得不到工序。

## 9. 常见误区

| 误区 | 为什么错 | 更正 |
| --- | --- | --- |
| 报课等于进入学习状态 | 完课率低，且课不产生素材 | 报名前先定三项可带走的收益（§2 末段） |
| 用课程代替现场 | 课堂上没有准入、没有天气、没有拒绝 | 每周现场天数优先，课排其后 |
| 把社群当评审 | 群里的意见是口味分布，不是判断 | 走五人试映制，逐条登记 |
| 只找懂影像的人看片 | 方法与伦理问题被同好的语言遮蔽 | 五人里必须有方法侧与外行 |
| 请人看完不追问 | 「不错」是礼貌，不是反馈 | 必问「哪一分钟走神、哪一处不信」 |
| 把前辈的答复当条款依据 | 口头经验与当期规则常不一致 | 回一手文本核对并存档 |
| 一有钱就买设备课 | 设备能力不解决结构问题 | 先做 §7 第 2、5 周这类零成本约束 |
| 把课程与社群当成身份 | 简历上的课程不改变被拒次数 | 红线指标仍是现场准入与依据齐备（[失败与教训](../13-案例/失败与教训.md) §13） |

## 10. 实操要点

- [ ] 每季度只允许报一项外部课程或训练，报名理由写成一句「我要带走的那道工序」。
- [ ] 报名前填完 §3 八条表；第 4、5 条踩线即放弃，且把该条款记录在案。
- [ ] 五人试映制名单现在就填齐（含替补），每人一句「只问他什么」。
- [ ] 每次试映后 24 小时内回填登记表；同类问题二次出现即改 SOP，不改这一处片子。
- [ ] 社群时间设上限：每周固定两次、每次不超过 20 分钟，且只在现场遇到问题时查。
- [ ] 所有涉及金额、期限、名额的信息只从一手页面取，截图带访问日期存进项目档案。
- [ ] 自训十二周表贴在工作台，一次只走一周；视力停机信号优先于任何交付。

## 请复核条目

1. 本篇所有课程类型的报名窗口、价格、师资与结课形式——本篇一律不给，须你自己按当期页面核实。
2. 「学会／协会设有影像或视觉人类学相关部门与年会」这一说法的具体组织名称与现状。
3. 节展实验室与提案会的开办主体、周期与是否收费——本篇不点名。
4. 独立研究者身份投稿与学术身份标识的当期规则（各系统要求会变）。
5. 平台规则与结算口径的具体条款——本篇只给「以当期规则页为准」。
6. 五人试映制与「成员核对」（member check）方法学的对应关系表述是否准确（方法学出处见 [../../田野方法/08-信效度.md](../../田野方法/08-信效度.md)）。
7. 十二周自训表中的周次与交付物为经验性安排，需按你自己的身体与现场条件重排。
