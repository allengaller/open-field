# 作者与风格

> 纪录片常被算作「做出来的」而不是「写的」，因此作者性（authorship）在这里是一个有争议的所有权问题。本文给出争议的实际内容、把风格还原为认识论立场的方法，以及一套从五部片子反推形式规则、写成十条戒律的可执行流程。

## 1. 作者论移植到非虚构时的争议

作者策略（politique des auteurs）通常追溯到 François Truffaut 1954 年在《电影手册》的文章，其主张是影片的真正作者是导演而非编剧；后由巴赞等人在论辩中命名。Michel Foucault《What is an Author?》（1969）则把「作者」从个人改为一种**论述的分类原则**（作者功能，author-function）——我们借它来归组、删减、指派责任。【通行共识】

纪录片一侧的争议正来自这个双重性。它长期不拥有作者名分，原因有四：

1. **署名结构**：机构、栏目、电视台品牌优先于个人（格里尔逊体系的公共教育定位，使影片被视为「机构产品」）。
2. **文本属性**：没有剧本，「写」的痕迹被抹掉，于是「作者证据」必须重新发明——它落在**方法与形式的连续性**上。
3. **生产组织**：摄影、录音、剪辑常是他人；一人乐队（one-man band）与集体制作的作者归属规则不同。
4. **责任分配**：非虚构要为真实的人负责，于是「作者」同时也是**责任人**——这一层在剧情片里被淡化了。

对个体创作者的实际含义【操作性建议】：在纪录片里，作者身份不是荣誉称号，而是**可被追问的连续性**——你必须在下一部片子里继续为上一部的形式选择负责。

## 2. 风格是认识论立场：同一场田野，两种知识

把两位方法对立的作者放在同一场景里，风格差异立刻显示为**知识差异**：

| 变量 | Frederick Wiseman 怀斯曼（零介入） | Jean Rouch 鲁什（介入·挑逗） |
| --- | --- | --- |
| 摄影机 | 在场但不发言：不提问、不出镜 | 承认在场并加以使用：提问、递烟、争论 |
| 声音 | 纯同期，无解说，无配乐 | 现场对话为主导，作者声音是文本的一部分 |
| 结构 | 段落并置（机构的切片），因果关系留给观众 | 相遇的序列，问题被明确抛出 |
| 产生的知识 | 流程、节奏、空间、人与人实际的相处方式 | 人们在被追问时如何为自己辩护、如何想象自己 |
| 丢失的知识 | 意图、理由、历史前因 | 未被摄影机扰动时的日常 |
| 伦理姿态 | 「我不改变它」的自律（仍无法回避选择之责） | 「我承认我改变了它」的坦白 |

【通行共识·片例方法描述】怀斯曼作品如《Titicut Follies》（1967）、《Law and Order》（1988，塔尔萨警局）；鲁什与 Morin 的《Chronique d'un été》（夏日纪事，1961）把「摄影机是否像一面镜子」直接作为片中提问。当代的第三种位置是 Errol Morris 的访谈装置（用技术问题逼出矛盾陈述），属于**结构化介入**。

三种知识都真实，且互不替代。**选择风格就是选择你认为哪一种知识更值得付出代价。**

## 3. 形式自查：每一项都是主张

| 形式变量 | 常见取值 | 它主张什么 | 它排除了什么 |
| --- | --- | --- | --- |
| 平均镜头长度与长尾 | 大量 3 秒以下／存在 2 分钟以上长镜 | 判断力在剪辑台上／在现场 | 前者排除身体经验，后者排除信息密度 |
| 景别偏好 | 特写为主／中远景为主 | 情绪即真相／处境即真相 | 特写丢空间关系，远景丢面孔 |
| 机位高度 | 平视／仰／俯 | 与被摄者的权力关系 | — |
| 手持或固定 | 手持／三脚架 | 我在场并移动／我在等待 | 手持常被读作「更真」，这是修辞不是证据 |
| 同期声：解说：音乐 | 三种比例 | 谁在解释这个世界 | 解说比例越高，人物的解释权越少 |
| 是否出镜、是否保留提问 | 4 种组合 | 知识来自相遇／来自观察 | 不提问的采访容易变成演讲 |
| 是否用音乐 | 无／仅源内音乐／配乐 | 情绪由现场给出还是由我加给 | 配乐=未经举证的形容词 |
| 结构 | 线性／切片并置／循环／拼贴 | 世界有单向因果／世界是共时结构 | — |
| 时间的显示方式 | 字幕／自然光／不标 | 观众有权知道压缩 | 不标即谎报同时性（见 [真实契约](./真实契约.md)） |
| 名字的出现方式 | 字幕卡／口头／不出现 | 是否让个体可被识别与追责 | 匿名化也是一种主张 |
| 方言与字幕 | 原声＋译字／配音 | 语言本身是证据还是障碍 | 配音会抹掉说话人的身体 |
| 最后镜头给谁 | 人物／建筑／机器 | 谁被允许拥有结尾 | — |

【操作性建议】上表用于两部片子之间的形式复盘，不用于拍摄中的犹豫。

## 4. 「作者视角」与「当事人的声音」

这是纪录片作者永久的紧张。三种典型失败：

1. **代言**：全片是「我替他们说」，人物只在对解说表示赞同的段落出现。
2. **堆砌**：只有采访，没有结构，作者不敢承担任何判断，于是片子成为材料合集。
3. **覆盖**：作者论点先行，人物被压成例证；这类片子往往「很好剪」。

可用的概念工具是**复调**（polyphony，借自 Bakhtin 的术语，在纪录片批评中被广泛借用）：不是取消作者，而是让**不同声部各自有效且互相不完全溶解**。操作化的分层法【操作性建议】：

- 解说与字幕 = 我的可核查断言，必须举证；
- 同期声 = 他的断言，允许与我的矛盾并被保留；
- 观察段落 = 我们都没说的部分，交给观众判断。

三层的判据是：**观众能否随时说出这句话是谁说的**。

## 5. 一人乐队与集体创作

- **一人团队**（一个人承担摄影、录音、采访、剪辑）：形式一致性最高，现场决策链最短，且伦理责任无可推诿。代价是没有第二双眼睛——现场的伦理判断、坏素材的识别、剪辑的自我说服都缺少制衡。【操作性建议】补救是建立**固定的外部审片人**（2–3 人轮值），而不是靠自觉。
- **共同作者**：摄影师、录音师、剪辑师在纪录片里是实质作者（他们对「何时开机、保留哪条喘息」有决定权）。署名与分成规则应在项目开始时写死，见 [团队组建与合同](../11-生产与资金/团队组建与合同.md)。
- **制片人的作者性**：实际持有者常常是制片人——因为资助方的语言由其引入。若你不是制片人，你的风格会被资助框架部分决定；这属于结构事实，不靠意志力解决。
- **参与式拍摄**：把摄影机交给被摄者（见 [参与式影像](../14-田野与影像/参与式影像.md)）会把作者性问题推到极端——此时诚实的做法是承认这是**协作生产**并在文本内标明谁在拍。

**漂移的来源要归对**。形式随时间变化有三类原因，只有第一类是「风格演化」：（a）你有意识地改；（b）交付规格变了（画幅、时长、平台字幕规则，见 [交付规格表](../15-工具与模板/交付规格表.md)）；（c）你缺乏某种能力（不会收同期声于是靠解说，不敢长镜于是靠剪辑）。复盘时把每处变化归到 a/b/c，归入 b、c 的部分不该写进导演阐述，而该写进设备与流程的待办。

## 6. 如何找到自己的风格

风格不是找出来的，是从你已做过的事里**归纳并加以约束**出来的。五步：

**第 1 步：选五部影响你的片子**。标准：你会在剪辑台上模仿它。别选「你敬佩的」，选「你想得像的」。

**第 2 步：形式反推（量化，不许用形容词）**。对每部片子取一段 10 分钟，统计：

| 统计项 | 片 A | 片 B | 片 C | 片 D | 片 E |
| --- | --- | --- | --- | --- | --- |
| 镜头数 | | | | | |
| 最长单镜头（秒） | | | | | |
| 特写占比 | | | | | |
| 解说句数 | | | | | |
| 提问入声次数 | | | | | |
| 音乐起止次数 | | | | | |
| 出现名字的方式 | | | | | |
| 时间标记次数 | | | | | |

**第 3 步：找共性**。五列里至少三项一致的，就是你的真实倾向（不是理想倾向）。

**第 4 步：写成十条戒律**。戒律必须可违反——即能判断某天的某段素材有没有守。示例（**这是示例，不是模板**，套用别人的戒律等于没有风格）：

1. 不用画面外的音乐，除非声音本身是内容。
2. 不剪掉让我难堪的那句提问。
3. 单个场景至少保留一个 60 秒以上的完整镜头。
4. 不给任何人写他没说的话；解说只写我能举证的。
5. 人物第一次出现时给全名或明确说明为何不给。
6. 空镜只用于时间或空间的交代，每片不超过 N 个。
7. 不拍拒绝被拍的人，包括剪掉也不行。
8. 现场光优先；加灯只用于看不见即无内容的地方。
9. 每片至少保留一处沉默，不解释。
10. 交付前把所有断言列成表，逐条对上素材编号。

**第 5 步：守三部片子再修订**。修订要写下改了什么、为什么改；否则风格会随每一次平台改版漂移。

同时给自己一份**负面清单**（绝不做的事，通常 3–5 条），它比正面宣言更有识别度。

## 7. 常见误区

1. **把风格当视觉签名**（一套 LUT、一种画幅、一种稳定器运动）。这是识别度，不是认识论。
2. **在第一部片子之前定风格**。此时你没有素材证据，只会借来一个姿态。
3. **模仿的错位**：学怀斯曼的长镜头却保留自写的解说；学鲁什的介入却删掉自己的提问。方法必须成套。
4. **把一致性当风格**：很多人的一致性只是习惯（不敢用特写、不会收同期声）。区分方法：能否说出这个习惯排除了什么知识。
5. **用风格问题回避立场问题**：「我这是在探索形式」不能替代「你凭什么这样呈现这个人」（见 [表征的政治](./表征的政治.md)）。
6. **把「作者」当成免于批评的盾**。作者性越强，可追问性越高。

## 实操要点

- [ ] 完成第 6 节的五列量化表，找出不低于三项的共性。
- [ ] 写十条戒律，每条都能被判定「守/没守」；配一份 3–5 条负面清单。
- [ ] 在提案的导演阐述里写方法而非情绪：镜头长度策略、声音配比、出镜与提问规则。
- [ ] 每片建立**声部分层表**：解说=我的断言，同期=他的断言，两者矛盾处不消除。
- [ ] 指定 2–3 位固定外部审片人，弥补一人团队缺少第二双眼睛的结构性缺陷。
- [ ] 合作者（摄影、录音、剪辑）的署名与分成在项目启动时写定。
- [ ] 两部片子之间跑一次第 3 节的自查表，比较漂移方向是有意还是惰性。
