# 交付规格表

> 这张表在导出之前打开、在上传之前填完：一行一个核对项，一列一个版本；标注清单、遮挡核对、分层交付与附包索引跟着它一起走。它不告诉你数值该是多少——数值每次现查。

**数值以 08 章与 04 章为准，本表只做逐版核对，不在此重复数值。** 码率、响度目标（LUFS/dB）、采样率、分辨率与文件大小上限一律按目标投放处**当期**上传说明现场查，填进表里的是「查的日期与依据」，不是记下来的旧数字。规格分层（L0/L1/L2/L3/S/P）、命名规则、校验值五列表与交付前十二项检查，全部在 [交付母版与规格](../08-剪辑后期/交付母版与规格.md)；采集侧的电平与录音规格见 [同期声与收音](../04-声音/同期声与收音.md)，混音侧刻意不给可跨项目复用的响度数值（08 章「混音与终混」§8）。**说明**：本表版式为【操作性建议】。

## 2. 遮挡与变声核对

| 项 | 核对 | 不通过的后果 |
|---|---|---|
| 化名口径 | 同一个人在对白字幕、说明卡、片尾三处写法**必须完全一致** | 三种写法会被拼出真身 |
| 声音可识别性 | 变声后口音＋职务仍可定位；C 档声音按可识别信息处理 | 以为匿了，其实没匿 |
| 背景文字 | D 档「无语句」画面里的单据、工牌、屏幕、快递单是否已遮 | 遮挡对象清单见 §1 末列 |
| 可识别第三人 | 路人、客户、来访者是否可排除；无法排除时是否保留 | 静止机位与延时段的常见漏点 |
| 烧录版 | 烧录进画面的字幕与图形里不得含可识别信息（母版才可外挂） | 烧错不可回退 |
| 能力边界 | 是否对当事人承诺了「一定遮得住」 | 不承诺做不到的事；只承诺做法与复查 |

## 3. 分层交付：公开层 / 研究与教学层 / 当事人层

分层的**前提**是向被摄者说明每一层的可见范围并取得同意，同意档位与撤回写进同意台账（文本骨架见 [授权文书模板](./授权文书模板.md)）。

| 层 | 谁可见 | 常见差异 | 前置条件 | 撤回时 |
|---|---|---|---|---|
| 公开层 | 平台公众 | 正脸按 A/B 档、遮挡最多、断言只留已核 | 逐版发布确认；不承诺传播量 | 撤下＋通知平台＋登记 |
| 研究与教学层 | 特定课程、研究者、放映座谈 | 保留更长片段、更多上下文、未采纳旁证 | 单独说明这一层给谁看、多久；不得默认沿用公开层同意 | 收紧访问并记录 |
| 当事人层 | 被拍的人本人（核验副本） | 低码率可读即可；含与自己有关的全部段落 | 交付时说明「看完可以指出不想用的那一段」 | 优先处理当事人请求 |

**当事人权利优先于场地许可**：冲突时先满足个体的撤回与删除请求，再与场地方另行处理。在项目文书里固定一段「可见范围与保存安排」：

```text
可见范围与保存安排（抄进项目文书，逐层填）
本素材将出现在：□公开层（平台＿＿）□研究与教学层（＿＿）□当事人层（本人副本）
每层可见者：＿＿＿；预计存在时间：＿＿＿；若平台下架，记录仍保存在＿＿＿（离线多副本，仅可追加）
当事人撤回时我做四步：停使用 → 移除导出 → 通知已发布平台 → 台账追加变更行。
我不承诺：一次性删净、永久不可见、任何传播量数字、把任何人拍得「体面」。
```

## 4. 附包（P 层）结构与权利链索引

```text
WET_E02_PKG_20260315/          只增不改
  00_规格自测记录.md            本版在目标平台真机的结论：日期、设备、结论
  01_授权文书包/                每条可发布素材 → 文书影像 + OF_REF 编号
  02_排除说明.md                因未授权或撤回而未用的素材（区分「没有」与「故意不用」）
  03_更正与联系通道.md          公开一处，不依赖私信
  04_素材来源声明.md            拍摄时间范围、地点类型、谁拍的、含哪些第三方素材
  05_音乐与二次素材.md          曲目/来源/授权范围/有效期；档案素材询价与回执
  06_处理登记.md                降噪去混响、画面修复、去交织、AI 参与范围
  07_双语债记录.md              中文先行、英文欠账与记账位置
  08_标注清单.md                §1 的完成态
  09_可见范围与保存安排.md      §3 的段落
  chain_of_title/               权利链（chain of title）
    权利台账.md                 11 列，见下
    授权凭证索引.md             素材条目 → 凭证路径
```

权利台账 11 列（与素材日志共用主键，字段定义在 [版权链与E&O](../10-伦理法律/版权链与E&O.md) §3，本表只列名不重述取值）：`素材/条目｜来源｜许可范围｜期限｜地域｜媒介｜可否商用｜可否二次分发｜凭证文件路径｜到期日期与提醒｜状态`。状态四值 `可发布/受限/未清/已过期`，**凭证路径为空即无凭证即不可发布，没有例外**；「未清」禁止进导出。

授权凭证索引每行：`素材条目 | 人物化名编号 | 授权层级（场所准入/内容准入/人员同意/特殊许可）| 档位 A–E | 形式（书面/录音/文字）| 凭证路径 | 同意版本号 | 状态五值`。E&O（错误与遗漏保险）意义上的「清权」在本仓库等于一件事：**每一行都能点开一个文件**。

## 5. 回滚与重制登记（换版即填五行）

| 项 | 写法 |
|---|---|
| 换的原因 | 事实错误／撤回／授权变化／技术问题／判断改变（不写「优化」） |
| 被换版本 | 文件名 + SHA-256 + 投放处 + 发布日期 |
| 替代版本 | 新文件名 + 与旧版差异一句话 |
| 可见的更正 | 更正与联系通道位置；是否单独说明 |
| 失效标记 | 旧版链接保留还是撤下 |

不要静默替换：URL 不变而内容换掉，所有引用者（包括你自己的笔记）会指向一个不存在的版本。重制以 L0 为源产出新 L0′（新编号、新校验值），旧 L0 不删不覆盖，两者关系写进同一行；周更内容合并进长片属重制。本表在周更流程里的位置（哪一天填、谁提醒你填）见 [单集制作SOP](./单集制作SOP.md)。

## 常见误区

| 误区 | 事实 |
|---|---|
| 把本表当数值来源 | 表里填的是「哪一天查了哪份说明」，不是码率 |
| 母版上烧字幕 | 改一个字要重走调色与混音；L0 干净、字幕外挂 |
| 只在 B 站版做标注 | 逐版标注口径不一致等于对某一版撒谎 |
| 遮挡做完就认为安全 | 变声后口音＋职务仍可定位；背景单据才是常见漏点 |
| 研究层沿用公开层同意 | 每层可见范围要单独说明、单独取得同意 |
| 附包等出事再补 | 「路径为空＝不可发布」在导出扫描时就生效 |
| 换版只在平台重传 | 缺五项登记即视为没有记录；不静默替换 |
| 校验值留在聊天记录里 | 写进 `05_DOC/校验值.md` 并入仅可追加日志；未公开素材的哈希不公开 |

## 实操要点

- [ ] 上传前先建本版那一列，边导边填，不补记。
- [ ] 每一版都跑一遍 §1 标注清单，缺项的字幕当场补，别留给「下一版」。
- [ ] §2 化名口径用搜索核对：对白字幕、说明卡、片尾三处逐字比一遍。
- [ ] 三层的可见范围在拍摄现场就说清，并写进 §3 段落与同意台账。
- [ ] 附包八项建目录即建占位文件，交付前逐项确认非空。
- [ ] 导出前扫权利台账：状态为「未清」或凭证路径为空的素材必须为零。
- [ ] L0 与 L3 的校验值当天写入 `05_DOC/校验值.md` 五列表，记全值。
- [ ] 提交 git 前跑一次文件类型检查：仓库里没有任何音视频文件与网盘直链。
