# 拍摄前清单

> 这份清单只买一样东西：到了现场，你不再需要做任何决定——除了读光、设计提问、和决定什么时候不开机。五个时间段按顺序做，各有一条硬判据：D-7 的事不许挤到 D-1，出发前任一项缺就不出发，开机前五项完不成就不开机。

本篇除注明外全部为【操作性建议】。各判据的权威在括号引用的章节里，本表只负责把它们排进时间轴；电平、响度、编码、备份与交付数值不进这张表（分别以 04 声音两篇、[编码存储与备份](../09-技术与设备/编码存储与备份.md)、[交付母版与规格](../08-剪辑后期/交付母版与规格.md) 为唯一权威），本表只复述不落数字就无法执行的触发线，且随处注明出处。行程、预算、证件、票据与预研以 [路书](../../研究/路书.md) §三 为准——与 [现场工作流与安全](../07-拍摄执行/现场工作流与安全.md) 同一口径：**只补影像项**。**括号内「NN §M」的展开方式见 [场记表与素材日志](./场记表与素材日志.md) 篇首的引用记法。**

完整二十项的权威在《现场工作流与安全》§1，此处只按组打勾，不改它任何一条判据。**任一项缺则不出发**——判据本身也是 §1 的。

- [ ] 电力组：相机与录音机电池按 §1.1 配齐分两包；录音机与相机各用独立电源，不共用一块充电宝（09 §6.4）
- [ ] 存储组：卡总容量与单卡余量按 §1.2；便携 SSD 有空间、手机清出容量（§1.17，口径见《路书》T-1）；标记内袋与卡包防混卡（§1.18）
- [ ] 声音组：领夹麦、指向麦各做十秒试录并**回放**（§1.4）；有线监听左右都响（§1.5）；备用线缆与转接头（§1.6）；电平预设完成、现场不进菜单（§1.8）；防风件按《同期声与收音》分级携带
- [ ] 光学组：清洁三件套（§1.3）；遮光（§1.9）；雨护与干布（§1.10）；脚架垫（§1.11）；软底静音已磨合的鞋（§1.12）

## 四、到场后（门口停五分钟，未完成不进场地）

五件事顺序照《现场工作流与安全》§2，每件约一分钟：

- [ ] 1. 先录三十秒环境音——一进去就有门、人、机器声，补不回来（07 §2；做法见 [空镜与环境影像](../07-拍摄执行/空镜与环境影像.md) §7）
- [ ] 2. 读光：主光方向、强度差、色温混合、云遮蔽趋势，定人脸曝光锚（07 §2；《非虚构摄影》§7）
- [ ] 3. 机位预演：走到你打算站的位置，看影子落哪、挡不挡动线、退路在哪（07 §2）
- [ ] 4. 许可再确认：今天有谁在场可能反对你拍？管理方要不要再打一次招呼？口头准入还在期限内吗（11 §1、§7）
- [ ] 5. 第一任务复述：今天拿什么、放弃什么（07 §2）

进门之后：打招呼、说明来意、聊一刻钟不开机；麦未别上不谈正事（07 §9）。入口告知页贴上；人群场景开拍前口播一次并录进同期声（11 §6）。四层许可任一层现场发生变化，当场缩范围并记台账——撤回处置四步与不争辩纪律见《拍摄许可与场地》§9。

## 五、开机前（五项；「没时间」的版本就是这五项）

没有富余时只执行本节，每项三步按键以内即可完成，符合 [PRINCIPLES.md](../../../PRINCIPLES.md) §2.2 的离线优先要求。冷手、雨里、被人催，做的都是这五条；任一条做不成，本场不开机，把原因记进场记。

- [ ] 1. 每个空间第一条先录房间音（时长口径见《声音设计》§4；换机位或换话筒重录）
- [ ] 2. 两机校时一次、开拍打板一次，多人场合打三次；录音机先开、收机时相机先关（《同期声与收音》§8）
- [ ] 3. 四项自动锁死：AWB、自动增益、自动曝光、自动对焦关闭锁定，不再放开（《光线与色彩》实操 2）；灰卡两秒随场开动作拍掉，K 值进场记 D 组
- [ ] 4. 十秒试录加回放，听底噪、削波、风杂——只听不回放等于没测（07 §1.4、§11）
- [ ] 5. 同意口头确认一句（脚本骨架见 10 §5），本场三行写进场记首行：我想知道什么、什么画面能回答、答不上来我下一步问谁（[失败与教训](../13-案例/失败与教训.md) §1）

敏感场景在开机前多想一步：短开短关的开关时刻按你和当事人的口头约定执行，每次开与关记 HH:MM（《非虚构摄影》§3、./场记表与素材日志.md D 组）。

## 六、恶劣情况取消条件（前夜定死，现场只执行）

| 触发 | 判据 | 动作 | 权威 |
| --- | --- | --- | --- |
| 电力到线 | 剩余不足返回路程所需 | 停止拍摄，不再「再拍一个」 | 09 §6.1 |
| 入夜 | 过当日预设的夜间时刻后不进新场地；只跑已布好的固定机位 | 走灯亮的路线撤离 | 07 §5 |
| 同意失效 | 关键线人无法单独确认，或当场反悔 | 放弃此人素材，或只保留匿名化形态 | 10 §4、§6 |
| 情绪当口 | 对方处于求助、诉苦、情绪崩溃中 | 停：不办手续、不开机、不追问 | 10 §5 三禁忌 |
| 许可被撤 | 管理方或当事人当场撤回 | 立刻停、已拍分层、按约处置、记录；当场不争辩 | 11 §9 |
| 人身风险 | 犬只逼近、酒后人群、车辆动线、吊装区出现 | 按《现场工作流与安全》§5 对应行处置 | 07 §5 |
| 身体信号 | 视力模糊、头痛、眼干任一出现 | 立即终止当日计划，损失记进场记 | 07 §7 |
| 装备故障 | 电池、卡、雨护任一关键件失效且无备份 | 取消本场，不降级硬拍 | 07 §1 |
| 引荐断链 | 引荐人不在且联系不上，进场资格无法确认 | 只拍不涉人的画面与环境声，或放弃本场——没有「来不及告知」的正当版本 | 07 §5；11 §6 |

取消不是失败：场记记一行原因与时刻；造成素材级损失的，按《现场工作流与安全》§8、§10 写事故记录。取消后本周排期怎么降级，见 [单集制作SOP](./单集制作SOP.md)。

## 常见误区

| 误区 | 事实 |
| --- | --- |
| 勾打了就等于准备好了 | 判据看的是东西在不在手边、阈值定没定，不是纸上的钩 |
| D-7 的事留到出发早上 | 许可、文书、告知页都有前置时间，D-7 段没人能替你补 |
| 声音表到了现场再填 | 《声音设计》§12 要求写完再出门；现场定的话筒方案全是将就 |
| 老板点了头就算同意 | 四层许可互相独立，老板答不了员工个人的同意（11 §1；10 §4） |
| 一块充电宝带所有设备 | 它耗尽时你同时失去画面与声音，且失去的是同一场（09 §6.4） |
| 取消条件到现场再看情况 | 「再拍一个」是损失最大的三个字；触发线必须前夜定死 |
| 忘了房间音，回来补录 | 回到同一空间，空调、季节、窗外车流都变了，补的底声不可用（04 §4） |
| 出发前缺一项也照样走 | §1 的判据就是任一项缺则不出发；缺了还走，丢的是整天 |
| 现场凭脑子记触发线 | 冷手、雨里、被人催时人只看得懂卡片；触发线必须誊进随身最小卡 |
