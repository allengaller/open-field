# 场记表与素材日志

> 一张表用在三个场合：开机前写三行、停录时压出几行字、当晚与后期把它补成可检索的日志。它是你和未来的自己之间唯一的接口，也是授权台账与导出扫描的唯一字段来源。

本篇除注明外全部为【操作性建议】。命名规则、授权枚举值、日志时间口径的权威在 [素材管理与日志](../08-剪辑后期/素材管理与日志.md) 与 [现场工作流与安全](../07-拍摄执行/现场工作流与安全.md)，本篇引用不改写；电平、响度、备份与哈希数值一律见各自权威章（04 声音、09 编码存储与备份、08 交付母版与规格），此处不复述。「场记（script supervisor / continuity note）」在单人作业里不是一个岗位，是一行字——判断一行字合格与否的标准只有一条：三个月后、异地、冷启动，你能凭它找回那段素材和它的授权状态。

**引用记法**：为让这张表能打印带到现场，括号内的「NN §M」指该章**默认文书**的第 M 节，展开为——04＝《声音设计》、07＝《现场工作流与安全》、08＝《素材管理与日志》、09＝《灯光与电力》、10＝《知情同意与拍摄授权》、11＝《拍摄许可与场地》、12＝《自媒体分发》。不属这些文书的引用一律写成完整链接或《篇名》。这张对照表只在本篇出现一次，其余各篇同此记法。

## 1. 主字段表

二十二格，分五组。其中八格（文件/场次、起止时间码、地点、人物（化名）、授权状态、内容描述、关键句 + TC、检索关键词）是「八格」最小元数据集，与 [素材管理与日志](../08-剪辑后期/素材管理与日志.md) §3 完全一致；剪辑侧多加的两格（备注/风险、OF_REF）放在当晚入库层，本表一并列出以免后期另起一套字段。

| 组 | 字段 | 填写内容（枚举与示例） | 最低填写层 |
| --- | --- | --- | --- |
| A 身份与时钟 | 文件/场次 | `D03_S12_A_1430`（日_场_机位_开始时间），单机作业机位恒为 `A`；录音机文件 `D03_S12_REC_1428`；场次不够后期追加 `S12b`，不许重排已有编号 | 现场 |
| A | 起止时间码 | 素材内部 TC ＋ wall clock 开始时刻；两者都缺时写 `TIME-UNCERTAIN`，不许猜填 | 当晚 |
| A | 记录时刻 | 与「发生时刻」分列书写，两个时钟永不合并（08 §8） | 当晚 |
| A | 卡号/原片序号 | 「来自哪张卡第几个文件」；卡号是恢复现场顺序的最后手段（08 §2） | 当晚 |
| B 场景内容 | 地点 | 到「哪家」：`深圳/白石洲/××旅馆后巷` | 现场（预印） |
| B | 人物（化名） | `P07-老周` 级化名编号；真名映射不进这张表，另处加密存放（08 §6） | 现场（预印） |
| B | 内容描述 | 一句话：谁，在做什么，事情有无变化 | 现场 |
| B | 关键句 + TC | 抄 ≤20 字原话，带 `00:41:12`；当事人用词不书面化（08 §5） | 现场（有则记） |
| B | 检索关键词 | 3–8 个名词（人、物、工序、地名），取自词表；不用形容词 | 当晚 |
| B | 留/废/待看 | 三值（08 §4 L1）；停在现场层时可以只到本格 | 当晚 |
| C 授权与标记 | 授权状态 | 五值枚举 `GRANTED / VERBAL / NOTASKED / DECLINED / REVOKED`，未知一律按 `NOTASKED`；`_NOCONSENT` 后缀、`RESTRICTED/` 目录、`X_不可发布` 染色 bin 的处置以 08 §6 为准，本表不改写 | 状态变化当场 |
| C | 是否重演 | 默认 `否`；其余取值按 [真实契约](../01-理论/真实契约.md) §5 的分类：`重演 / 搬演 / 场景重建 / 演员出镜 / 示意流程 / 保护当事人 / 合成影像`，非 `否` 者成片必标 | 现场 |
| C | 备注/风险 | 谁在场可能反对、是否含可识别第三人、是否涉未成年人（08 §3） | 当晚 |
| C | OF_REF | 证据层引用编号；本表授权状态只是快照，开剪前从证据层重拉一次（08 §9） | 当晚 |
| D 机位光声 | 轴线与视线方向 | 本场机位在哪一侧、主要视线朝哪；跨轴必须有理由，理由写同一张表（[观看位置与视点](../03-电影语言/观看位置与视点.md) 实操 1） | 现场（场开） |
| D | 灰卡 + K 值 | 每个光位开机先拍 2 秒灰卡，记该光位 K 值（[光线与色彩](../03-电影语言/光线与色彩.md) 实操 1） | 现场（场开） |
| D | 话筒位置与增益 | 话筒型号、位置与距离、增益档位（按设备卡写档位，dB 数值见《同期声与收音》§5，不入本表） | 现场（场开） |
| D | 两机起始 TC 与校时偏差 | 录音机与相机各自的起始时间码；每次重新校时后的偏差值（07 §1.7、04 同期声 §8） | 现场 |
| D | 房间音已录 | 是/否 + 文件名（60–120 秒口径见《声音设计》§4） | 现场 |
| D | 开关机时点 | 敏感场景短开短关，每次开与关各记一个 HH:MM（[非虚构摄影](../07-拍摄执行/非虚构摄影.md) §3） | 现场 |
| E 思考层 | 三行（场级） | 我想知道什么 / 什么画面能回答 / 答不上来我下一步问谁（[失败与教训](../13-案例/失败与教训.md) §1） | 场开 |
| E | 依据说明（段级） | 一句话：这段能证明什么 | 现场或当晚 |

## 2. 三档填写深度（同一套字段，三种深度）

常开策略能成立，前提是这张表存在——素材多了以后，找点的成本由日志承担（[非虚构摄影](../07-拍摄执行/非虚构摄影.md) §3）。档位允许停在上一档（08 §4 的许可），唯一的硬门槛是当晚层必须当日完成。

| 档 | 何时 | 填哪些格 | 时间目标【操作性建议】 |
| --- | --- | --- | --- |
| 现场快记 | 每段停录时；每场开机前另有一次性填写 | 段级：文件/场次、内容描述 5–8 字、关键句（有则抄）、是否重演圈标、开关机时点。场级（场开 2 分钟）：三行、轴线侧、灰卡 K 值、话筒位置与增益、房间音 | 段 ≤30 秒；场额外 ≤2 分钟。手冷、雨里写不了字就只打勾和圈位，当晚补文 |
| 当晚入库 | 每日收工流程（07 §3）第 4 步「场记补全」，目标 30 分钟内（07 §9 的 19:00 行） | 八格补齐 + 记录时刻、卡号、留/废/待看、授权状态终值、备注/风险、OF_REF | 每场约 1 分钟；当日晚于睡觉未完成，次日先补它再开剪 |
| 后期追加 | 粗剪、放映、补签、撤回时 | L2 select 的起止 TC 与主条（时长预算按 08 §4 的 L2 口径，不在本篇复述）；放映补记（§6）；授权状态变更只追加新行，不覆盖旧行 | 按工序需要；不许为「整齐」重排既有行 |

## 3. 填写示例（工厂 / 集市 / 村庄各一行）

示例格值为演示填写，不对应任何真实个人；地点与化名沿用本语料既有示例（三号厂、白石洲、村口小卖部、`P07-老周`）。

**例一 工厂·冲压机位**

| 格 | 填写 |
| --- | --- |
| 文件/场次 | `D03_S12_A_1430`，录音机 `D03_S12_REC_1428` |
| 时间 | 素材 TC 00:41:12–00:49:05；wall clock 14:30 起；记录时刻 21:05；卡 C3/第 07 个文件 |
| 地点/人物 | `深圳/白石洲/三号厂冲压区`；`P07-老周` |
| 内容描述 | 老周演示计件怎么记数，老板中途喊他，数停下来又继续 |
| 关键句 + TC | 「工资押两个月」`00:41:12` |
| 关键词 | 计件、押薪、冲压、工段、老周；留/废：留 |
| 授权/重演 | `VERBAL`（当场录音留痕，档位判据见 10 §2，发布前复核）；重演 `否` |
| 备注/风险 | 00:44 起老板在场，该段不按「单人陈述」使用（权力污染，10 §4） |
| 机位光声 | 轴线：老周面朝东，机位南侧，未跨轴；灰卡 2 秒，K 4300；领夹挂老周、机顶麦备份，增益档位 4；两机校时偏差 2 秒；房间音已录 |
| 三行 | 想知道押薪怎么个押法 / 计件表和这段口述能答 / 答不上问上个月结过账的人 |
| 依据说明 | 证明「押薪」是当事人原话且有时刻锚 |

## 4. 重演与摆拍的标记规则

1. 停录那一刻若画面不是自发发生的，C 组「是否重演」立刻圈标——画一个圈比写一个字快；分类与依据当晚补。记不清是否重演过的段落，一律按重演处理（就严不就宽）。
2. 分类与成片标注义务以 [真实契约](../01-理论/真实契约.md) §5、§8 为准：搬演不充当物证、不用未发生的对白；不可重复事件的缺口不用搬演顶替，改用时间标注 + 当事人陈述（[纸剪与结构重组](../05-叙事结构/纸剪与结构重组.md) 红线）。
3. 「等待事件」的摆拍最易混入自发素材：预演走位、请人重走一遍路线，都算重演，进表。
4. 合成与生成影像的标注口径与交付层统一（见 01 篇《后纪录片》），本表只负责让它们在剪辑前就被认出来。

## 5. 双系统同步规则（对应 D 组话筒与 TC 格）

抄自 [同期声与收音](../04-声音/同期声与收音.md) §8 的场记侧动作，不另立标准：

- 相机与录音机对同一来源校时到秒；每次开机、每次换电池、每 30 分钟重新对一次表，偏差值写进 D 组。
- 支持时间码的设备锁 TC 后自动同步；不支持的走手动打板。
- 每段开拍打一次板：画面里可见、声音有高频爆点；多人场合打三次。
- 录音机先开、相机后开；收机时相机先关、录音机后关，两头各留 5 秒余量。
- 场记五项必填：时间、段落号、两机起始 TC、话筒型号与位置、房间音是否已录。
- 入库后先同步、再做代理；自动同步的段落人工抽查头中尾三处。丢了 TC 又没记校时偏差的素材，标 `TIME-UNCERTAIN`，不猜。

## 6. 放映后怎么补行

[社区放映与参与式传播](../12-发行传播/社区放映与参与式传播.md) §6 要求现场记「谁 + 一句话 + 时刻」——事后就按本表后期追加层的格式补行：人物列写化名编号（场内观众也编号，真名不进表），内容描述记那句话，关键句 + TC 记放映内时刻，授权状态按放映开场宣布的那档记录，口头同意的录音注明同意方式。当事人当场说「这段别用」的，按 `DECLINED` 处置。

## 常见误区

| 误区 | 事实 |
| --- | --- |
| 靠机内卡时间排跨日顺序 | 时钟会漂，校时偏差必须记；两个时钟永不合并（08 §8、07 §1.7） |
| 现场不写，当晚全凭回忆 | 记忆过夜衰减（07 §9）；当晚不做，后期成本翻倍（08 §1） |
| 把原始文件改名成「好读」的样子 | 改名与替换不可区分，哈希失去意义（08 §2） |
| TC 缺了就估一个填上 | 猜错一次，之后所有引用全错；用 `TIME-UNCERTAIN` |
| 关键词写「重要」「感人」 | 检索词必须是名词，形容词搜不出来（08 §11） |
| 真名先写进场记纸 | 纸也会拍照外流；表上只出现化名编号，映射另存加密（08 §6） |
| 授权状态一次填完就稳 | 它是快照，会因撤回过期；开剪与发布前各重拉一次（08 §9） |
| 重演等粗剪再标 | 那时已分不清摆与自发；就严不就宽 |
| 关键句顺手改通顺 | 丢了检索锚点，也丢了一个说话人（08 §5） |
| 把场记当额外负担 | 它买的是常开的入场券与找点的速度；没有表的常开等于堆债 |

## 实操要点

- [ ] 出发前把五组字段预印或手绘成横向大字版面，现场要动笔的只剩四件事：场次、一句话、圈标、HH:MM。
- [ ] 每场开机先花两分钟：三行写在表头，轴线侧、灰卡 K 值、话筒位置与增益各一格。
- [ ] 停录即记：内容描述 5–8 字，有原话就抄一句带 TC，重演画圈，敏感段记开关机时刻。
- [ ] 当晚 30 分钟内补满八格与两时钟行；补不完不清明日 shot list。
- [ ] 双系统按 §5 六条执行，校时偏差与两机 TC 每段成对出现。
- [ ] 授权状态只追加不覆盖；`DECLINED`、`REVOKED` 当场加行并同步文件名与染色 bin（08 §6）。
- [ ] 放映与补签的追加行走同一格式，人物列永不出现真名。
- [ ] 开剪前用本表跑一次未授权扫描，授权列按证据层新快照核对后再进时间线（08 §6、§9）。
