# 单集制作SOP

> 周更是一条流水线，不是灵感输出（[自媒体分发](../12-发行传播/自媒体分发.md)篇首语）。本篇把九个工序钉进日历：发布日固定、倒排工序、降级顺序事先写死、家庭日与回家周按约束而非选项排。单人周更的目标不是「每条都完美」，是「任何一周都不必为发布赶工」。

本篇除注明外全部为【操作性建议】。时间预算按一条中版（《自媒体分发》§1 的时长量级）校准，自行伸缩；各工序的完成判据以引用章节为准，本表只列周更最小集。本篇不写任何金额与收益数字，涉及成本一律「以你自己的试错资金包上限为准」（[预算与制片管理](../11-生产与资金/预算与制片管理.md)开篇规定）。内容形态、标题封面、评论区、私信、平台规则归 12；该篇开篇把工序与档期交给本篇，本篇接管。**括号内「NN §M」的展开方式见 [场记表与素材日志](./场记表与素材日志.md) 篇首的引用记法。**

## 一、周历：九个工序与完成判据

P＝发布日。下表以周六发布为示例；档期一旦选定长期不变，变更要提前告知观众（12 §5）。排历要领：**先填死家庭日、回家周、不可动事件日，再把工序塞进剩余时间**，不是反过来。

| 工序 | 排期 | 时间预算 | 完成判据 | 未达成第一动作 |
| --- | --- | --- | --- | --- |
| 选题与预约 | 周一上午 | 2 小时 | 周一三查全过（§三）；本集一句话论点写成；预约当面或电话确认；四层许可初查——场所准入有无书面、期限是否覆盖本周 | 库存不足 → 本周停新增预约与新增访问，转清积压（12 §5） |
| 拍摄 | 周二全天 | 按 [现场工作流与安全](../07-拍摄执行/现场工作流与安全.md) §9 时间轴 | 按 [拍摄前清单](./拍摄前清单.md) 执行；采集目标 2–3 件各至少一段可用；每个空间房间音齐；触发取消线即撤 | 当日废段不赌补拍；不可重复事件没拿到，记进场记，转 [长期跟拍](../07-拍摄执行/长期跟拍.md) §7 等下一次可预期事件 |
| 入库与日志 | 周二晚＋周三早 | 晚 2 小时＋晨 1 小时 | 每日收工流程七步走完（07 §3）；八格填写率 100%（[场记表与素材日志](./场记表与素材日志.md) §2 当晚层）；留/废/待看标完；未授权与 `DECLINED`、`REVOKED` 段已染色排除 | 本工序不许跳：当晚不清，周三的粗剪等于在垃圾堆里找点 |
| 粗剪 | 周三下午＋周四白天 | 各 3 小时 | 开机前先连一条纯同期声音小样，用声音定段落边界（[声音设计](../04-声音/声音设计.md) §3）；上轨道前查有没有「进门—做事—卡住—解决—离开」五段（[书目与教材](../16-学习资源/书目与教材.md) §9）；全片能一次放完不中断、每段能说出它在回答什么（[粗剪到精剪](../08-剪辑后期/粗剪到精剪.md) §2） | 时间不够 → 先删空镜精修段，保结构剪；结构剪不放晚间（08 §8） |
| 精剪与声音 | 周五 | 4 小时（画面 2＋声音 2） | 画面过《粗剪到精剪》§6 锁版判据清单；声音按层分轨混完，耳机、音响、手机外放三关分别过（《声音设计》§7，数值在其权威章） | 时间不够 → 画面精修降级，声音排表一步不让（§四） |
| 合规与授权复核 | 周六上午 | 1.5 小时 | 从台账重拉本集全部可识别个体的**当前**授权状态（快照会过期，[素材管理与日志](../08-剪辑后期/素材管理与日志.md) §9）；未同意、撤回、待确认一律硬排除（12 §8）；断言清单逐条过（[事实核查与更正](../10-伦理法律/事实核查与更正.md)，分级与判据不在本篇复述）；若配发切片过三问、封面单独拿出来验一遍（12 §2、§3） | 任一断言核不实 → 改写或删该段，不许「先发了再补核」 |
| 字幕 | 周六上午（复核之后） | 1 小时 | 当事人话语逐字；专名、数字、方言三查（12 §9）；化名与匿名化的字幕处理按 [字幕与无障碍](../08-剪辑后期/字幕与无障碍.md) | 机翻字幕未逐条校对 → 本集不发 |
| 发布 | 周六固定时段 | 1 小时 | 三端全部从母版一次导出、不从分发件再导（12 §8；规格见 [交付母版与规格](../08-剪辑后期/交付母版与规格.md)）；各端首发顺序保持一贯（12 §8）；简介区放撤回联系通道 | 导出或上传失败 → 按 §四降级：发库存、本集改期、提前说明 |
| 复盘 | 周日上午 | 30 分钟 | 目标/实际/偏差/应对四格表写一行，应对必须是动作不是态度（《预算与制片管理》§6）；判定有没有流程缺口，有 → 次日补丁（§四与 [拍摄前清单](./拍摄前清单.md) 各归各的） | 越落后越要写：跳过复盘的落后会在下周翻倍 |

周日剩余时间为家庭日，不进剪辑房、不排任何生产任务。

## 二、写进日历的硬约束（不可谈判项）

| 约束 | 规则 | 权威 |
| --- | --- | --- |
| 家庭日 | 每周周日不排生产；复盘以嘴记与四格表为限 | 本 SOP 结构 |
| 强制回家周 | 每在外一个月必须回家一周，写进日历占位、不可用任何事由替换；该周不排访问、剪辑定档、交付，**也不排发布任务**——用库存覆盖，不用深夜剪辑覆盖 | 《预算与制片管理》§5.1；12 §5 |
| 休整周 | 允许一周中断，提前向观众说明；静默消失会把关系与信任一起耗掉 | 12 §5；[长期跟拍](../07-拍摄执行/长期跟拍.md) §10 |
| 缺席日 | 本 SOP 每周只排一次进场，天然满足《长期跟拍》§3 的每周至少一个整天不去现场；要加访问，先过周一库存检查 | 07 §3 |
| 不可动事件日 | 发薪日、赶集日、庭审、年检优先于任何计划内拍摄：可挪工序，不可挪事件日 | 《预算与制片管理》§5.3 |
| 缓冲日 | 每次外拍前后各留一天用于备份、台账、失败重访；周三上午的入库尾工就占在缓冲里 | 《预算与制片管理》§5.4 |
| 身体 | 盯屏工时与姿势上限见 07 §7 与 08 §8，数值不在本篇复述；剪辑日不与长途驾驶同日（12 §5） | 07 §7；08 §8 |
| 采集方式 | **隐蔽采集不进任何档期**：藏机器、假借身份、无同意录音被仓库宪章明确禁止；来不及告知就只拍不涉人的画面与环境声，或者放弃本集 | [PRINCIPLES.md](../../../PRINCIPLES.md) §2.4；[拍摄许可与场地](../11-生产与资金/拍摄许可与场地.md) §6 |

## 三、周一三查（本周能不能全开的闸门）

- [ ] 库存数字：≥2 条成片＋≥1 条已拍未剪。低于即停新增合作与新增访问，本周转清积压（12 §5）。
- [ ] 本周日历里有没有回家周、事件日、缓冲日与工序冲突；有 → 先动工序。
- [ ] 本集三行写在选题纸条首行：我想知道什么、什么画面能回答、答不上来我下一步问谁（[失败与教训](../13-案例/失败与教训.md) §1）。

## 四、降级路径：砍什么，永远不砍什么

本周的时间、视力、电力、关系任何一项不够时，按顺序降，先牺牲的一律是画面精修：

1. **画面精修**：调色、二次构图、空镜节奏打磨。这一层没有也发得出去；声音糊了发不出去。
2. **短切片与竖屏改编**：挪到下周，不占本集关键路径（12 §1、§9）。
3. **本周新增访问与新预约**：选题顺延，库存顶上。
4. **单集长度与结构**：收成单论点短版；结构让位，但声音不让位。

**永不降级的四项**：声音排表与混音（[世界经典案例](../13-案例/世界经典案例.md) §10 要求把这条写进本 SOP：每周更新时优先做声音排表，画面精修降级）；入库与八格日志；合规与授权复核；房间音与原声回听。四项都保不住时，降级的不是工序，是**档期**：本集改期、发库存、提前说明。不静默断更，也不跳工序赶档。

## 五、应急分支：撤回、删除请求、事实错误

触发：当事人要求删除或撤回、发现事实错误、被摄者或其关联方出现在评论区。顺序固定，不并行走：

1. 当日回应，先私聊再公开；不在评论区与第三方争论当事人的说法（12 §6）。
2. 从台账拉本集授权现状；状态变化**只追加新行不覆盖旧行**，`REVOKED` 的处置三件套按《素材管理与日志》§6 执行——素材保留、永不进导出、不删盘上原始。
3. 发布层面的撤回按《知情同意与拍摄授权》§8 流程走；场地方撤回按《拍摄许可与场地》§9 四步走；两者冲突时，**当事人权利优先于场地许可**（11 §9）。
4. 涉事实错误的，按《事实核查与更正》的断言分级与更正骨架处理，本篇不复述其条文；该删的版本与保留的版本，以该篇处置规则与台账记录为准，不做静默替换。
5. 更正说明在三端同步挂出，位置与首发简介区一致（12 §8）。
6. 涉设备冲突或人身风险的，回到 07 §4、§5 的应答与撤离动作；造成素材损失或授权暴露的，按 07 §10 模板写事故记录（`INC-` 编号）。
7. 错误记入台账（机制见《事实核查与更正》），可核查的更正走该篇流程。
8. 复盘只问一句：流程缺口还是执行缺口。流程缺口 → 48 小时内把补丁写进本 SOP 或《拍摄前清单》（07 §8：每丢一次，改一条 SOP）。

## 六、导出前单集检查表

导出母版前逐项打勾，任何一项空着就不导：

- [ ] 论点：一句话说得清本集回答什么问题；前六十秒把这个问题交代给了观众（12 §1）。
- [ ] 授权：本集每个可识别个体有当前状态记录；未同意、待确认、撤回的镜头已硬排除。
- [ ] 重演：所有非自发段落已按《场记表与素材日志》C 组标记，成片标注义务按 [真实契约](../01-理论/真实契约.md) §5 履行。
- [ ] 事实：断言清单逐条有依据或已降级表述（《事实核查与更正》）。
- [ ] 声音：三关听检过；关键信息不在只靠低频成立的段落下（《声音设计》§7）。
- [ ] 逐字：字幕当事人原话未改字、未拼句（12 §2、§9）。
- [ ] 封面：单独拿出来给一个人看，他以为的内容与本集一致（12 §3）。
- [ ] 切片（如随发）：过 12 §2 三问。
- [ ] 母版：三端分发件均从母版一次导出；分发件带轻标识、母版无水印（12 §8）。
- [ ] 库存：发布后剩余成片库存与已拍未剪数仍满足 ≥2＋1；不满足 → 下周预约挂起。

## 七、库存水位与月度节奏

发布日固定，你和「为发布赶工」之间唯一的缓冲就是库存。水位口径是《自媒体分发》§5 的阈值，本表只规定每档触发什么动作；数字看台账，不看感觉。

| 水位 | 台账状态 | 本周动作 |
| --- | --- | --- |
| 正常 | ≥2 条成片＋≥1 条已拍未剪 | 按 §一 九个工序全开 |
| 警戒 | 成片少于 2 条，或已拍未剪归零 | 停新增访问与远征拍摄；周四、周五转去把已有素材剪成交付件 |
| 应急 | 成片为零且本周导出不可能 | 不加班补：发库存或提前说明改期（12 §5，不静默断更）；本周只排一件事——把库存洞补上 |

月度节奏检查（每月最后一个周日，复盘加 30 分钟）：

- [ ] 台账全对：本月授权状态追加行与场记逐场对上；`PENDING` 待确认挂了几个、由谁负责本周关掉。
- [ ] 卡与盘的健康、格式化与备份态：口径以 [编码存储与备份](../09-技术与设备/编码存储与备份.md) 为准，本篇不复述。
- [ ] 更正与事故记录各回看一遍（《事实核查与更正》的错误台账；07 §10 的 `INC-` 条目），确认当时的补丁还活着。
- [ ] 下一个回家周：日历占位、库存覆盖清单、给观众的提前说明，三样都落定（§二；《预算与制片管理》§5.1）。

## 常见误区

| 误区 | 事实 |
| --- | --- |
| 状态好就多拍一条访问 | 库存与缺席日先于状态；多跑一次现场，少一周判断力 |
| 画面没修好不能发 | 降级顺序写死在 §四：观众容忍脏画面，不容忍糊声音（《声音设计》§1） |
| 合规复核压到导出前十分钟 | 授权状态是快照，发布前必须重拉（08 §9）；十分钟查不完台账 |
| 这一条剪不完，深夜再战 | 结构剪与删除决定不放晚间（08 §8）；深夜剪出的片子第二天反悔 |
| 回家周用深夜剪辑覆盖 | 回家周是排期约束不是休息建议；覆盖它的是库存（《预算与制片管理》§5.1） |
| 为赶档期悄悄换发布日 | 档期不因单集改；要改节律就提前说明（12 §5） |
| 来不及告知，先偷录一段 | 没有正当版本（PRINCIPLES §2.4）；改拍空镜或放弃本集 |
| 落后了就把复盘省掉 | 越落后越需要那 30 分钟；省掉它的下周更落后 |
| 库存数凭感觉报 | 水位三档全看台账数字；感觉里有 2 条、台账里只有 1 条，是应急档 |
| 回家周到了才开始找库存 | 覆盖回家周的是提前落定的库存与说明，不是回家路上的手机剪辑 |

## 实操要点

- [ ] 日历先填不可谈判项（家庭日、回家周、事件日、缓冲日），再塞九个工序。
- [ ] 周一三查固定周一上午做，不挪到周四；库存数字看台账不看感觉。
- [ ] 降级按 §四顺序执行；声音、日志、合规、原声回听四项不做交易。
- [ ] 发布日的复核与字幕在上午完成，下午只留导出与上传的余量。
- [ ] 复盘 30 分钟写四格表；流程缺口 48 小时内落成清单或本 SOP 的一条改动。
- [ ] 休整与改期永远提前说明；一周中断便宜，静默断更贵。
- [ ] 涉及钱的表述一律「以你自己的试错资金包上限为准」，本文件不存金额。
- [ ] 本 SOP 失效时先查 §二 的约束是不是被挤掉了，再怀疑自己的纪律。
