# 授权文书模板

> 这套骨架在「该掏一张纸了」的节点拿出来：给被拍的人签、给场地方盖章、给合作方填、给档案素材的授权方回。判断该不该签、缺哪一项就不算拿到，在各章正文；这里只给能抄、能填空、能当面读完的文本。

**说明**：以下所有版式与措辞均为【操作性建议】——是结构提示，不是法律意见，不是可以照抄就生效的现成合同。凡数字由法律或属地规定决定的（税率、违约金比例、登记期限、授权年限的法定上限、赔付标准），本包一律**留空格并写「以现行有效文本与属地要求为准，签约前核对」**，不在此填值。条文与法条编号也不写在这里；风险提示的边界见 [中国法律边界](../10-伦理法律/中国法律边界.md)。

填空约定：`＿＿` 手写；`□` 勾选；`××` 必填替换。打印口径见 §0。

---

## 0. 先读这一段：这套骨架才有人真的会用

- **一页纸原则**。一条视频对应一张纸，不做四页密表；做长表的人不会在现场掏出来。
- **可打印版式**：A4 单面、正文不小于 14pt、行距 1.5、签字区留 3 厘米高。骑摩托车到现场时，纸要能对折塞进口袋。
- **对方读得懂优先于条款周延**。凡是对方可能不懂的词，换成口语；实在要留术语，后面括号里写人话。
- **每份骨架后面都有一段「这份纸其实无效的情形」**——那一段比骨架本身重要，签之前默念一遍。
- 签署完成后：拍照进 `01_ORIGINALS/STILL/`（做法见 [现场工作流与安全](../07-拍摄执行/现场工作流与安全.md)），并在同意台账落一行（§1 末尾）。台账字段与素材日志共用主键（[素材管理与日志](../08-剪辑后期/素材管理与日志.md) §6）。
- 该给谁哪份：人员→§1 或 §6；场地→§2；说过什么话→§3；用了别人的素材→§4；找了人帮忙→§5。出发前把要打印的纸列进 [拍摄前清单](./拍摄前清单.md)；现场的登记格式与授权状态字段见 [场记表与素材日志](./场记表与素材日志.md)。

## 1. 人员知情同意书（书面版）

适用于可识别度高、敏感度高或传播范围宽的场合（判据见 [知情同意与拍摄授权](../10-伦理法律/知情同意与拍摄授权.md) §2）。涉及未成年人、患者、被监护者，本骨架不够用，改走机构与监护人双侧同意的附加页（[弱势群体与儿童](../10-伦理法律/弱势群体与儿童.md)）。

```text
知情同意书   版本 v＿＿   编号＿＿＿＿（与台账「人物化名编号」一致，例 P07-老周）

拍摄者：曹亚仑   联系电话＿＿＿＿   我做的栏目：××（B站/抖音/视频号 账号名＿＿＿）
被拍摄人：姓名＿＿＿＿＿＿   片中使用名字（化名，可留空）＿＿＿＿＿＿
项目：《××××》——我一个人拍的日常记录，不是别人雇我拍的。

一、我要拍什么
  画面：□正脸  □侧脸或背影  □只拍手和活儿  □不拍画面
  声音：□录你说的话  □只录现场声（你不说话）
二、拍完发到哪儿（用途，可多选；用途变了我要重新问你）
  □我自己账号上的纪实栏目（不收费）
  □比赛、展览、教学与学术用途
  □将来可能的发行或商用；若产生收益，另写一页约定＿＿＿＿＿＿
三、期限：自＿＿年＿＿月起，共＿＿年（期限数值以现行有效文本与属地要求为准，签约前核对；
  不确定就填一个你敢承诺的短期限，到期我再来找你）。
四、你可以选哪一档（只勾一个；这一档可往上调，不可被默认往下调）
  □A 真名＋正脸   □B 化名＋正脸   □C 只出声音   □D 有画面无语句   □E 这次不参加
  E 是合法选择，选了不影响我们的关系。
五、你可以随时改主意（撤回）
  怎么撤：微信、电话、或告诉＿＿＿＿（你信得过的中间人）都行，不用解释理由。
  我收到后做四步：停止使用 → 从工程与导出中移除并处理已发布版本 → 通知已发布平台
  → 在台账追加一行变更记录（记所撤版本号，不抹旧行）。
  我能做到的说清楚：撤下需要平台处理时间；原始素材我不会私下销毁，销毁需有书面手续，
  并保留我方一份完整哈希记录。
六、报酬与致谢：□无报酬  □报酬＿＿＿＿（性质：劳务/补贴/资料费）  □片尾署名或致谢
七、我是否听懂了（这一条由被拍摄人自己说，拍摄者记录原话）
  拍摄者已逐条解释上面各项。我能用自己的话说出发到哪儿、我能不能反悔：
  原话记录：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
  我签字时旁边没有需要我看脸色的人：□是（单独确认） □否（另约场合再签）

签名或手印＿＿＿＿＿＿   日期＿＿＿＿＿＿   拍摄者签名＿＿＿＿＿＿
一式两份；现场给不了纸，就拍照回传并当场把照片给对方看。
```

**这份纸其实无效的情形**：只写了「同意拍摄并放弃肖像权」（放弃式条款，两方都不保护）；没有版本号或没有撤回联系方式（伦理上无效）；老板、工头、房东在场时员工签的字（权力污染，换场合重谈）；对方签字快、复述不出用途（理解不足，按未同意处理）；情绪高点、诉苦当口掏出来的纸（时机倒置）；用途后来变了却没新增版本——以上任一，纸就是废纸。

**签完立刻落的台账行**（`05_DOC/同意台账.md`，一行一档，六字段照填）：`人物化名编号 / 事项×四事（同意·授权·发布·撤回各自的当前状态） / 时点与形式 / 范围摘要（A–E 档位） / 变更历史（只追加） / 凭证路径（文件名或 OF- 引用编号）`。授权状态五值取 `GRANTED / VERBAL / NOTASKED / DECLINED / REVOKED`。

## 2. 场所准入书面文件（一页版）

判断清单（缺哪一项就不算拿到）在 [拍摄许可与场地](../11-生产与资金/拍摄许可与场地.md) §7，本节只给文本。四层许可互相独立：这份纸只解决第一层与部分第二层，**它替代不了任何一个人的 §1 同意书**。

```text
拍摄准入确认单   版本 v＿＿   编号＿＿＿＿

场地方：单位/铺名＿＿＿＿＿＿   地址＿＿＿＿＿＿＿＿
出具人：姓名＿＿＿＿ 职务＿＿＿＿  能否代表上级或业主：□能（附凭证＿＿）□不能
拍摄方：曹亚仑（个人拍摄），联系方式＿＿＿＿＿＿，项目《××××》

1 范围：可拍区域＿＿＿＿＿＿＿＿；明确不可拍区域与对象＿＿＿＿＿＿＿＿
       （如：单据、屏幕、内部代号、财务角、员工休息区）
       可涉及人员范围：＿＿＿＿＿＿（涉及个人仍须本人另行同意）
2 方式：□手持 □脚架 □无人机（需主管部门书面批准，批文编号＿＿）□延时/无人值守
       是否允许录音 □是 □否；是否可用灯光与市电 □是 □否
3 期限：自＿＿年＿＿月＿＿日至＿＿年＿＿月＿＿日；□可重复使用 □每次另行确认
4 保密与排除：我方的排除清单即第1条；拍摄方现场执行方式：发现误拍当场删除预览片段
   并记录（不删除原始文件，处理按约定）
5 发布与致谢：拍摄方承诺——事先告知拍摄范围与用途；现场可停（说停就停，不问理由）；
   可要求去除某段（记入承诺表）；发布前告知渠道与时间；放映回场＿＿次。
   拍摄方不承诺——播出与否及时点；形象好坏；内容取舍由场地方决定；无限期保密。
6 放映与审片界线（原话照抄即可）：
   「我可以给贵方一次内部放映，针对事实性错误和贵方主张的商业秘密、内部管理信息提出
   意见，我逐条核对并书面回复；但内容取舍与最终剪辑由我定。」
7 撤回：贵方撤回方式＿＿＿＿；撤回后我停止进入，已拍素材按第 5 条与承诺表处置。
   员工个人的可识别素材不因场地方撤回而自动可删，按本人同意状态单独判定。
8 责任与安全：场地损坏与安全责任＿＿＿＿；是否要求保险 □是 □否（金额与险种按属地与
   对方要求核对后填写）；易燃/粉尘/洁净区限制＿＿＿＿＿＿

场地方签字盖章＿＿＿＿＿＿ 日期＿＿＿＿ 拍摄方签字＿＿＿＿＿＿ 日期＿＿＿＿
```

**这份纸其实无效的情形**：签字的人只看得出是「现场负责人」却答不了能否代表上级（权限不明，等于没拿到）；范围一栏写「按有关规定」；给了审片权（一给就毁掉作品，且无法对所有合作方履行）；把这份纸当成员工同意；无人机、道路占用无批准文件就填了「可拍」。拿不到正式书面时退一档留证：负责人签字的备注页、往来消息截图、开拍口播入同期声——**退档必须记进台账**，且不能顶替第三层个人同意。

## 3. 承诺表（你说过什么，双方各一份）

长期跟拍里承诺会遗忘，纠纷都从「说好的呢」开始（管理规则见 [长期跟拍](../07-拍摄执行/长期跟拍.md) §5）。一张表三列，当场手写，一式两份。

```text
承诺表  编号＿＿（对应人物化名编号 P＿＿-＿＿）  版本 v＿＿
日期＿＿＿＿  场合＿＿＿＿＿＿
对方原话（尽量逐字）：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
我的答复（逐字，能做到的才写）：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
兑现节点：□已完成（完成日期＿＿）□待做（何时＿＿）□做不到（已于＿＿告知对方并说明原因）
```

不能承诺的四条线：不承诺播出、不承诺形象、不承诺期限以外的无限保密、**不承诺你做不到的一次性删净，也不隐瞒你已持有的副本**。

**这份纸其实无效的情形**：只记你的答复不记对方原话（日后各说各话）；写了做不到的承诺用来换取开机；只有你这一份，对方那一份没给；承诺兑现了没记完成日期。

## 4. 二次素材使用授权（档案、他人拍摄、图片库）

询价七步与清权自查在 [档案与二次素材](../07-拍摄执行/档案与二次素材.md)；本节是往来文本。

```text
素材授权询价（发给授权方的内容，五句话说完）
1 我是谁、做什么：个人纪录片《××××》，一个人拍摄。
2 想要哪一段：素材编号/时间码＿＿＿＿＿，用途（□完整片段 □几秒引用 □静帧 □不剪仅展示）。
3 请求的权利：性质（□非商用 □商用 □教学）；地域＿＿；期限＿＿；媒介（□网络
   □放映 □比赛）；是否需要独家（我通常不需要）。
4 剪辑与改动：我是否需要事先送审；能否配字幕、调色、变速、遮挡。
5 署名与水印、费用与发票、可否留档副本用于核验。
（费率、发票口径、著作权登记要求随属地与主体变化，以现行有效文本与对方要求为准，签约前核对。）

授权回执留档四件（缺一件即「未清」，不可进导出）：
□授权书正本（扫描件进 05_DOC/权利文件/，编号 OF_REF-＿＿）
□付款凭证或发票
□来源页面截图（含日期与 URL）
□联系记录（往来消息或邮件，能证明对方同意的是你用的这一版）
```

**这份纸其实无效的情形**：授权范围写「宣传用途」没写媒介与期限；口头同意「你拿去用吧」；授权书里同意的人和素材的权利人不是一回事（继承、单位、拍摄者三方常分离，见 [口述史访谈](../06-采访方法/口述史访谈.md) §7）；只留了授权书没留来源截图；水印与署名被成片裁掉。状态一律记进权利台账（11 列，字段见 [版权链与E&O](../10-伦理法律/版权链与E&O.md) §7），凭证路径为空的条目按「不可发布」处理。

## 5. 协作三件套（摄影、录音、剪辑的劳务与权利）

条款要点与评审五问在 [团队组建与合同](../11-生产与资金/团队组建与合同.md) §3、§4。三件套可以是三份纸，也可以是一份纸的三段，但**内容一项不能少**；默认按交付物的外包，定性差别见同章 §2。

```text
（一）制作服务约定
  委托方：曹亚仑   承接方：＿＿＿＿（姓名/团队，联系方式＿＿＿＿）
  工作内容：□摄影 □录音 □剪辑 □字幕/转写 □调色 □其他＿＿
  交付物（文件级清单，不接受「成片一支」）：工程文件□ 导出片□ 字幕文件□
    混音分轨□ 素材整理表□ 插件与字体清单□
  验收判据（客观可查）：时长＿＿、规格按 08 章「交付母版与规格」的核对表、
    声道＿＿、字幕逐字率＿＿、通过哪一轮检查＿＿
  修改轮次：共＿＿轮，结构性修改与微调分开算；超出后费率＿＿＿＿
  付款节点：定金＿＿＿ / 中期＿＿＿ / 尾款＿＿＿，触发条件各写一句（全款前置与全款后付都别选）
  延期与终止：延期定义＿＿；终止时已付款与已交付处理＿＿；素材归还与删除期限＿＿
  （税费、社保、发票口径以现行有效文本与属地要求为准，签约前核对；
   是否构成劳动关系以实际用工形态认定，不由合同标题决定。）

（二）著作权与授权约定
  署名方式与位置：＿＿＿＿
  素材原件与工程文件归属：归委托方□；承接方留存范围与期限＿＿（工程文件不给，你永远依赖这个人）
  后续衍生权利（短片、海报、课程、再剪辑）：＿＿＿＿
  承接方作品集使用：可否□、范围＿＿、起始时间＿＿
  第三方素材谁负责清权：＿＿＿＿
  红线：不约定转让全部著作财产权、不要求任何一方放弃署名。

（三）保密与个人信息约定
  不得留存素材副本；不得上传公共网盘或在线工具（工具链数据边界见 09 章「AI 工具链」）；
  不得向第三方播放（包括朋友）；不得对外谈论未发布内容与当事人身份。
  项目终止后＿＿日内删除并出具一行书面确认。
  个人信息处理遵循最小必要：真名默认化名、删除全程可审计（项目准则 §2.4）。

（四）熟人/志愿者一页纸（不给报酬也要写清是无偿）
  做什么＿＿ 到什么时候结束＿＿ 给什么（钱/署名/拷贝）＿＿
  素材能否留存：不能。 三样不给熟人：素材原件访问权、当事人联系方式、发布决定权。
  签字（双方各签一名，日期）＿＿＿＿
```

**这份纸其实无效的情形**：只有微信里一句「帮我剪个片」；验收判据写成「满意为止」；工程文件与素材归属没写；终止时没说已付款怎么处理（「双方协商解决」等于没写）；外包结束没走验收单五项（文件齐、规格对、工程可续、事实无误、无留存）就付了尾款——「无留存」那条从此再补不回来。

## 6. 街采口头同意（话术 + 台账行）

街采不必掏纸，但话要说全、要录进同期声（完整语境见 [街头采访与素人](../06-采访方法/街头采访与素人.md) §10）。开机后先录这段，语气平、不催促。

```text
「您好，我是曹亚仑，自己在做一个记录（菜市场／工厂／写字楼）日常的纪实视频，
会发到 B 站、抖音、视频号上。相机现在就开着，画面里是您的脸和您的摊儿。
我想问您两个具体问题，几十秒。您同意我拍、并且同意我把您说的话播出去吗？」
对方：（等一句明确的「可以」或「不可以」）
「好，那称呼上您想用真名还是不方便？」
（若犹豫）「不方便就不拍，完全没事。」
（结束时）「刚才说的这些我准备播，您有没有哪句不想播的？」
```

三条底线：**平台要说出名字**、「会播出去」必须在许可之前说清、拒绝之后不再追问。禁止任何隐蔽采集（[../../../PRINCIPLES.md](../../../PRINCIPLES.md) §2.4）——「来不及告知」没有正当版本，只拍不涉人的空镜或者放弃这一场。

当场落台账（形式记 `VERBAL`，时间码即凭证路径）：

| 时间码 | 化名编号 | 档位 | 平台（说出名字的） | 形式 | 备注 |
|---|---|---|---|---|---|
| `D03_S12_A_1430` | `P12-摊主` | B 化名 | B站、抖音 | VERBAL＋录音 | 对方要求不出现摊位招牌 |

**这条同意其实无效的情形**：只问「能拍吗」没问「能播吗」；平台写成「发到网上」；对方在忙、在躲、在被喊话时随口答的「哎，你拍吧」；镜头里有可识别第三人却只登记了受访者；犹豫之后继续追问直到对方让步。

## 常见误区

| 误区 | 更正 |
|---|---|
| 一张总约管一年 | 长期跟拍每次公开发布前各确认一次；总约属理解不足型假同意高发区 |
| 同意书越长越安全 | 长到对方不读，效力反而更低；用 §0 的大字号与一页纸 |
| 场地方的纸能盖住人的纸 | 四层许可互相独立，当事人权利优先于场地许可 |
| 匿名化是我给对方面子 | 匿名化是对方菜单上的正当选项（A–E 档） |
| 授权范围写大点省事 | 超用途即无权；档位可升不可默降 |
| 撤回要对方先讲理由 | 撤回只能被兑现，不能被作废；不追问、不施压 |
| 拍照回传不算签 | 现场无纸时拍照回传并当场展示即可，但要入 `01_ORIGINALS/STILL/` 并落台账 |
| 模板填完就能用 | 骨架是结构提示；重大事项（商用发行、纠纷、涉未成年人）签约前找执业律师看一次 |
