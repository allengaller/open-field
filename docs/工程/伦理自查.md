# Ethics Self-Review Checklist

**伦理自查清单**

> **Referenced by PRINCIPLES.md §7.**
> Any PR touching **data handling, AI integration, or user-facing copy** must complete this checklist before review. Reviewers: treat an unchecked applicable item as a blocking issue.
>
> 依据 PRINCIPLES.md 第 7 节。任何涉及**数据处理、AI 集成或用户可见文案**的 PR，评审前必须完成本清单。评审者请注意：适用项未勾选 = 阻断性缺陷，不予合入。

## How to Use（使用方式）

1. The [PR template](../../.github/PULL_REQUEST_TEMPLATE.md) already embeds the **PR Checklist Block** (bottom of this file); if you are not using the template, copy the block into your PR description.
   [PR 模板](../../.github/PULL_REQUEST_TEMPLATE.md)已内嵌文末的 **PR 清单块**；若未使用模板，请手动将清单块复制到你的 PR 描述中。
2. For each item: check ✅ if satisfied, mark **N/A** with a one-line justification if not applicable, or leave unchecked and explain why in the PR body.
   每项：满足则勾选 ✅；不适用请标 **N/A** 并附一句理由；未满足的项请在 PR 正文中说明原因与计划。
3. If any item in §1–§4 cannot be satisfied, the PR requires **Maintainer Ethics Review** — do not merge on approval alone.
   若第 1–4 节中任何一项无法满足，该 PR 必须进入 **Maintainer Ethics Review**（维护者伦理评审）——仅有代码 Approve 不得合入。

## 1. Evidence Integrity（证据完整性）

**Principle ref:** §2.1 Chain of Custody

- [ ] Originals are immutable. No code path can overwrite, delete, or re-encode an original artifact; editing produces a new version, and the original stays read-only.

  原始件不可变。任何代码路径都不得覆盖、删除或重编码原始采集物；编辑只产生新版本，原始件保持只读。

- [ ] Freezing happens at capture. SHA-256, timestamp, GPS, and device fingerprint are written to the evidence log the moment an artifact is saved — before sync, export, or any processing.

  采集即固化。采集物保存瞬间即向证据日志写入 SHA-256 哈希、可信时间戳、GPS 与设备指纹——先于同步、导出与一切处理。

- [ ] The evidence log stays append-only. No UPDATE or DELETE path was introduced against the log; corrections are new entries, not edits.

  证据日志仅可追加。不得对日志新增任何 UPDATE/DELETE 路径；纠错以追加新记录实现，而非修改旧记录。

- [ ] Artifact IDs stay stable and citable. Any change to the ID scheme ships with a migration and an audit trail; existing IDs never break.

  采集物编号稳定可引用。编号规则的任何变更必须附带迁移方案与审计痕迹；既有编号永不失效。

## 2. Collection & Consent（采集与知情同意）

**Principle ref:** §2.3 Rigorous for the Researcher, Invisible to the Participant; §2.4 Ethics as Infrastructure

- [ ] Consent precedes capture. No code path allows recording or photographing a participant before a consent record exists. Consent is never retroactive.

  同意先于采集。任何代码路径都不允许在同意记录存在之前对受访者录音/拍照。同意永不补录。

- [ ] Consent is scoped and versioned. Changes to consent templates bump the version; previously signed consents remain immutable.

  同意有范围、有版本。模板变更须升版本号；已签署的同意书不可变。

- [ ] Revocation is honored end-to-end. If this PR touches deletion logic: participant withdrawal triggers complete, auditable erasure across artifacts, transcripts, memos, and derived data — while preserving the audit trail of the erasure itself.

  撤回全链路生效。若本 PR 涉及删除逻辑：受访者撤回须触发采集物、转写、备忘录及衍生数据的完整可审计清除——同时保留"清除行为本身"的审计痕迹。

- [ ] No covert collection introduced. No background capture, no hidden indicators, no "always-listening" buffer. If the mic or camera is hot, the UI says so.

  不引入隐蔽采集。禁止后台录制、隐藏指示器或"常听"缓冲。麦克风或摄像头处于工作状态时，界面必须有明确标识。

## 3. Privacy & Compliance（隐私与合规）

**Principle ref:** §2.4 Ethics & Compliance as Infrastructure; §3 Local-first storage

- [ ] Real names encrypted at rest. Any new field storing direct identifiers uses the established encryption path — never plaintext, never in filenames, never in logs.

  真名静态加密。新增的任何直接标识符字段必须走既有加密通道——禁止明文、禁止出现在文件名或日志中。

- [ ] Analysis layer sees pseudonyms only. New features, exports, and log output expose pseudonyms by default; the mapping from pseudonym to real identity stays inside the encrypted store and is never sent to an AI model or third-party service.

  分析层只见化名。新功能、导出物与日志输出默认只暴露化名；"化名 → 真名"的映射仅存于加密存储内，绝不发给任何模型或第三方服务。

- [ ] Storage stays local and encrypted. New data paths use the encrypted local database (SQLCipher-class); cloud sync is end-to-end encrypted and opt-in — no silent uploads, ever.

  存储本地且加密。新增数据路径必须走加密本地数据库（SQLCipher 级别）；云端同步端到端加密且需用户主动开启——绝不静默上传。

- [ ] Remote wipe still reaches every copy. If this PR touches sync, export, or caching: device-loss wipe must remain able to cover all data the device has produced.

  远程擦除仍覆盖每一份数据。若本 PR 涉及同步、导出或缓存：设备丢失后的远程擦除必须仍能覆盖该设备产生的全部数据。

## 4. AI Integration（AI 集成）

**Principle ref:** §1 An AI coworker, not an oracle; §3 Confirm before acting; §3 Model-agnostic safety; §6 Non-Goals

- [ ] Every AI output is a proposal. Nothing an AI generates enters the evidence or knowledge layer without recorded human confirmation, and the AI-draft → human-confirm trail is preserved in memos.

  AI 输出皆为提案。任何 AI 生成内容未经人工确认不得进入证据层或知识层；"AI 草稿 → 人工确认"的轨迹须在备忘录中完整保留。

- [ ] Confirm before acting. Any AI-driven or destructive operation in this PR implements: preview → explicit confirmation → reversible execution → full audit log.

  先确认，再执行。本 PR 中的 AI 驱动或破坏性操作必须实现：预览 → 显式确认 → 可回滚 → 全程留痕。

- [ ] Safety survives model swaps. Ethics checks, privacy filters, and methodological validation live in middleware — not in prompts to one particular model — so the guardrails hold no matter which LLM sits behind the interface.

  底线不随模型更换。伦理校验、隐私过滤与方法论校验位于中间件层，而非针对某个特定模型的提示词——无论接口后面是哪家 LLM，防线都成立。

- [ ] Participant data is never repurposed. AI features use only the pseudonymized, minimized data the research task requires; participant data is never used for model training, growth analytics, or anything beyond the study — unless separately, explicitly consented and logged.

  受访者数据不挪作他用。AI 功能只使用研究任务所需的、化名化且最小化的数据；受访者数据绝不用于模型训练、增长分析或研究之外的任何用途——除非另行获得明确授权并留痕。

## 5. User-Facing Copy（用户可见文案）

**Principle ref:** §4 Bilingual Convention; §2.3 Rigorous for the Researcher, Invisible to the Participant

- [ ] Bilingual copy follows the phased convention. Current phase: Chinese-first — every new user-facing string ships in Chinese; English is tracked as debt, never silently dropped. From international launch, parity in the same PR is enforced.

  文案遵循分阶段双语规范。当前阶段：中文先行——新增用户可见文案必须交付中文；英文记为翻译债、逐项跟踪，绝不无声放弃。自国际化启动起，双语同 PR 对等交付。

- [ ] The copy sounds like a scholar, not a growth hacker. UI copy is native, concise, action-oriented; Chinese uses accepted academic terms (no translationese, no internet jargon); standard qualitative-research vocabulary is used, with English noted at first mention.

  文案像学者，不像增长黑客。界面文案地道、简洁、行动导向；中文用学界通用术语（无翻译腔、无互联网黑话）；质性研究标准词汇首次出现括注英文。

- [ ] The machinery stays invisible to participants. Participant-facing screens (consent, recording states) are honest and calm: recording indicators are always visible (see §2), while hashes, timestamps, GPS, and audit mechanics never surface in participant-facing UI.

  后台机制对受访者无感。面向受访者的界面（同意流程、录制状态）诚实而克制：录制指示始终可见（见第 2 节），而哈希、时间戳、GPS 等取证机制绝不出现在受访者可见的界面上。
